MasterMind for the Series 5 (FREEWARE)
--------------------------------------

Installing MasterMind:
----------------------
1. Make sure you have access to the System directory. For this, goto the preferences in the system screen. Check the 'Show 'System' folder' option.
2. Got the System\Apps directory and create a new directory called 'Master'.
3. Switch to this directory and copy all the supplied files to this directory.
4. The program should now appear on the Extras bar.
5. Ready.

Read the supplied help file.
Have fun.
