Atomic v1.4
-----------
Freeware (C) Uk 1998 Steve Litchfield

You know the game, if not the name. Falling blocks and lots of points!
Atomic's raison d'etre is that it's honed for fast and frantic gameplay.
No more boring 15 minute games waiting for things to get tricky! 8-))

To install:

1) Make sure viewing of the \System folder is enabled on the system
screen ('Preferences')

2) Go into \System\Apps and make a new folder called "Atomic"

3) Stick all files *apart* from the Sysram1.opx file in the
aforementioned \System\Apps\Atomic folder. Note that the best way of doing
this is to highlight them in PsiWin (hold the <Control> key down and click
each of them) and then drag and drop using the *right* mouse button. This
has the effect of bringing up a mini-menu etc, where you can choose 'copy' or
'move'. 

4) If your Psion 5 hasn't already been upgraded with the Sysram1.opx OPL
patch, use the copy I supply. Put it in \System\Opx on your internal C
drive. Its function is to add extra capabilities to OPL/32 on your
machine and is well worth having. Documentation for the OPX (if you're
a programmer and are curious) is on my OPL/32 programming page.

That's it! Have fun!

All the help you need to play Atomic is in the on-line help...
