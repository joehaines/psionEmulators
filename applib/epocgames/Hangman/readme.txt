Hangman V1.0

This is the PSION Series 5 version of the popular pen and paper game Hangman. 

Hangman v1.0 features bitmapped gallows. Different parts of which are displayed every time a wrong letter is provided by user.
Categories available in the unregistered version are British TV Programmes, Computers, Sports and Leisure and Capital Cities.
Categories and words can be added to and edited by accessing the file 'Hangman_wds' on the Data subdirectory.

See help files for author and registration information.
All Programming, Design and Graphics by Matt Thomas.

INSTALLATION

Before you begin to install please make sure you have the following files.

Hangman.app	The run-time executable
Hangman.aif	Needed by the run-time executable
These files are to be on C:\System\Apps\Hangman
