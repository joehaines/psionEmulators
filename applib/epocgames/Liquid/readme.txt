Liquid V2.0

Install the directry structure into system\apps\liquid and run from the extras bar.

Keys:

ESC - Quits

P - Pauses

Tab - Clears Screen

Space - Change modules

Enter  - Bring up Options


If you dont like the starting splash screen delete splash.opo and/or splash.mbm


Thats all there is. Have Fun
