"Pipe" is a Strategy game. It is a Freeware.
Aim of the game is to built a pipeline as long as you can built before time runs out.


========================
To install…
========================

1) Make sure the "\System" folder is shown on your Series 5 system screen.
If it's not, go to system menu and "Preferences" and check "Show "system" folder" box.

2) "Pipe5" must have unzipped in the folder call "\Pipe5". If so, then copy whole "Pipe5" folder in your "\System\Apps\" folder. Pipe5 icon will appear in the Extrabar.

3) If you are installing this game to the D drive, make sure you create folder call "\System\Apps" first in the D drive. In order to run  "Pipe5" smoothly, it must be installed in "\System\Apps" folder in any drive. (E.g. any drive:\System\Apps\Pipe5\*.*)

4) To copy all files manually, create folder called "Pipe5" in "\System\Apps" folder and copy all files listed below in this folder.
