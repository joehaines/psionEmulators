PsiBio V1.22
============

PsiBio is an application which calculates your personal biorhythm and gives a graphical representation of it based on your date of birth.

The aim of the application is to recognize a persons caution days using their biorhythm.

Reporting bugs
==============

I want to ask anyone who finds a bug in the program, to report it to me. It is necessary to give me a description as exactly as possible.

My email address is: 
    michael.maehrlein@mail.rmc.de

The following information is very useful for locating bugs:
   - language, i. e. German, English, American
   - memory: 8 MB/4 MB model
   - free memory on the drive
   - installation drive
   - software version (System -> Information -> Machine -> Software version) and
   - of course the exact description of the bug.
