PsiBio V1.22
============

PsiBio est une application qui calcule vos biorythmes personnels et les présente sous forme graphique, basé sur votre date de naissance.

Le but de cette application est de reconnaître les jours de prudence de votre biorythme.

Je ne donne aucune garantie en cas d'erreur provoquée par ce logiciel. Je décline toute responsabilité en cas d'anomalie. Vous utilisez le programme à vos risques et périls.

Me rapporter les erreurs (bugs)
===============================

Je demande à toute personne qui trouve des erreurs dans le programme de me rapporter. Il est nécessaire de me donner une description aussi précise que possible.

Mon adresse électronique est :
    michael.maehrlein@mail.rmc.de

Les informations suivantes sont très utiles pour localiser une erreur :
	
   - le langage, c-à-d german, english, american ou francais
   - la mémoire : modèle 8 MB/4 MB
   - la mémoire disponible sur le disque
   - le disque d'installation
   - la version du logiciel (Système -> Informations -> Machine -> Version du logiciel) et
   - bien sûr une description précise de l'erreur.
