ABOUT
=====

Super Puzzle Engine ver. 1.00 is a one or two player Tetris clone for the
EPOC 32 operating system.

It features a single player game, and a two player game where you can play
against a human competitor or the computer. There are a lot of gameplay
settings that can be changed, these are described in the game itself.

Online help is included in the game from the "Help" menu.


QUICK INSTALL
=============

Make a new directory in "\system\apps\" called "puzzle", and copy all the
files there.


PAST
====

I started writing this as a single player game before there were any Tetris
variants available for the Series 5, as a way to learn some OPL. As more of
the Tetris variants arrived, I decided that there were too many to justify
releasing another one, so I changed it to be a two player game.

FUTURE
======

Potential future changes:

- Improved computer AI. Could be tricky to do and still have a fast game :)
- Faster two player gameplay. This is my first attempt at OPL so I have most
  likely missed out some things that could potentially increase the speed.
  Having said that, the two player is always going to be a bit slower than
  the single player.
- More games! Tetris is ok, but there are a lot of other nice puzzle games
  out there! I've called this "Super Puzzle Engine" for the reason that I
  might add different games to the same program in future releases, possibly
  under a module based system.

Please don't email me asking when these will be added, they are just ideas
for the time being, which I may or may not be able to do.
