===========================================
ROBO DUNGEON - V 1.0 for the Psion Series 5
===========================================

An Arcade / Strategy game - Escape from 999 Dungeons, each with 20 levels,
with ever increasing numbers of robots chasing you, you have a map, a short
range teleporter, and a some bombs to help you escape. - With high quality
graphics, speech, and sound effects. * Addictive gameplay *

============
INSTALLATION
============

Turn on your Series 5, press the System icon (bottom left of the
screen), press the Menu key, under 'Tools' select 'Preferences',
make sure that there is a tick next to 'show system folder' and click
on 'OK'.

Go into either C:\System\Apps\ or D:\System\Apps\

From the menu, under 'File' select 'Make new folder' name it ROBO.

Copy all the files except README.TXT into this directory.

Pressing the 'Extras' button (bottom right of screen) will now reveal
this programs icon, select it to begin.

If you have difficulty with installation, re-read and follow carefully
the above instructions, you have probably put the files in the wrong place,
or named the folder incorectly.

If you install to C: and want to change to D: or vise versa, copy the files
over, delete the directory that you copied the files from, then rename the new
directory to a different name, wait a few moments, then rename it to the
correct name. If you don't do this your Series 5 may get confused and look to
the wrong device.
