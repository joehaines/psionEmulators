          S5 Diamonds v1.0

               Outline

Diamonds is a scrolling platform game for the
Psion Series 5 machine. The player has to
jump around each level collecting diamonds
and avoiding spikes and blades. There is also
a strategy element to the game. At the start
of each level you get some extra blocks and
and remove blocks. These are used to reach
inaccessible areas of the playfield. Use them
in the wrong places and you could run out
making the level impossible to complete!


               Installing

Unzip all the files and you should end up with
all the files in a folder called diamonds.
Simply drag this folder into your Psion`s
system/apps directory on any drive. You should
then end up with all the files in your Psion`s
system/apps/diamonds directory. The game icon
should now appear on the extras bar.

                 Playing.

All game instructions can be accessed from the
games menu when running.
