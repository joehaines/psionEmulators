Slated V2.0

This is the PSION Series 5 version of the classic PC 'Mosaic' game

The objective of the game is to sort the grid(s) into the correct order
in the least moves possible. 

The game features 8 different grids of varying difficulty and content,
sound effects, statistics logging high scores and number of moves taken
and superb graphics.

See help files for author and registration information.
All Programming, Design and Graphics by Matt Thomas.
