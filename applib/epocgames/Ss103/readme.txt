Installation:
-------------

Using PsiWin2, copy the entire SeaStrke directory (including the directory itself) to the
SYSTEM\APPS directory.

Upgrading from V1.02:
---------------------
Delete the following files prior to installation:
	SeaStrke.app
	SeaStrke (the file with no extension after it)
	Prefs (again, with no extension)

Then, copy SeaStrke.app, SeaStrke.hlp and prefs to SYSTEM\APPS\SEASTRKE
