Installation

To install WildReels on your Series 5, create a directory c:\system\apps\WildReels or D:\system\apps\WildReels on your psion (C: is the internal RAM and D: is a flash disk).
Then simply copy all the files from the zip archive into this directory. Voila, you should see an icon appear in the task bar of your Psion 5.
Please email d.g.wild@hw.ac.uk me with any problems.

Please note that you should register the program if you use it for more than 7 days.
