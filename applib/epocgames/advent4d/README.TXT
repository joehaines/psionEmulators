Adventures in 4 Dimensions Version 8.0
(9/26/98) is a freeware adventure game for
the Psion Series 5.  The object of the game
is to bring all the treasures to the
starting point while visiting all of the
locations in a reasonable number of moves.
Changing the game number changes the
connections between locations.  OPL source
code is included.

To install, create the directory
C:\System\Apps\Advent4D and copy the
following to that directory:

     Advent4D.aif
     Advent4D.app
     Advent4D.hlp
     Advent4D.mbm

Advent4D should now appear under Extras.

If you want to view or change the program,
copy the following to C:\Documents:


     Advent4D.opl -- the OPL source code
     Advent4D.txt -- text version of source

Feel free to change the descriptions of the
locations, treasures, etc. and make your own
games!
