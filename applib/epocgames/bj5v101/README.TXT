--Introduction-
BlackJack 5 is a multiplayer game of the classic card game blackjack. BlackJack 5 has a large variety of options to configure the game to how you want it. The objective of the game is to win money by beating the banker in having a total of cards valuing as close to 21 without going over.

Further help is availble in the in-game help option. (Menu -> Tools -> Help)
For the latest information and updates please visit:
http://ds.dial.pipex.com/town/avenue/zc15/

--Installation--
Files in this distribution: bankrupt.snd, bj.snd, BlackJack 5.hlp, BlackJack5.aif,  BlackJack5.app, bust.snd, dealcard.snd, images.dat, startup.snd, readme.txt, systinfo.sis

To install onto Cor Ddrive

1) If you have not already done so, set the option to view the system folder ON.
To do this go to the system screen, go to preferences (CTRL-K) and tick the box labelled 'Show 'System' folder'
2) Create a new folder in \System\Apps\ called BlackJack5 (without a space)
3) Unzip all files  into \System\Apps\BlackJack5\
4) Go into the \System\Apps\BlackJack5\ folder and double tap on Systinfo.sis to install a required OPX.
NOTE: If when trying to open this file it reports that it can't open this type of file, please visit my web site for further instructions to download INST_TE.EXE produced by Psion. This file enables you to install sis files, which many authors and companies distribute their software in. To get to the download from my web site go to http://ds.dial.pipex.com/dl.htm

5) Now from the Extras bar an icon labelled BlackJack 5 should appear. Tap on it to run the game!

If you wish to copy BlackJack 5 to another drive, simply copy the BlackJack5 folder onto the drive in \System\Apps\BlackJack5\
Make sure you delete it from the other drive, so the game does not get confused.
