Installation:
-------------

To install or upgrade Clueless onto either the C or D drive of your Psion.

1. Insure that you have set the option to view the System Folder ON.
     To do this go to the system screen, go to preferences (CTRL-K)
     and tick the box labelled 'Show System folder'.
     
2. Create a new folder in \System\Apps\ called Clueless. If you are
     upgrading from a previous version you may skip this step.

3. Unzip all files into the \System\Apps\Clueless\ folder. 
     Another folder under Clueless will be created called Puzzles. If you
     are upgrading from a previous version, any existing puzzles in the
     Puzzles directory that you may have collected will not be deleted.
     
4. Now Clueless should appear on the Extras bar. Tap on it to run Clueless.

5. Enjoy.
