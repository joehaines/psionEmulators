Notes of changes made to Clueless by version.

Version 1.0
-----------
- Fixed bug reading .puz files with long author or description which caused clues to be out of sync when loaded.
- Fixed bug when opening a new crossword after the 'Hide ToolBar' option was chosen. ClueList size did not adjust correctly.
- Added option to display messages in different corners of the screen so that the messages do not obsure the crossword.
- Added option to check a single letter in a word.
- Added the ability to zoom the font in the ClueList.
