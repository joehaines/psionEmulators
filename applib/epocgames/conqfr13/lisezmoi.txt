Installation
------------
Créez un sous-répertoire \Conquete (sans accent) dans le répertoire \system\apps. Il est possible que vous deviez rendre ce répertoire visible si ce n'est pas le cas. Référez-vous à la documentation de votre Psion pour ce faire. Copiez tous les fichiers sauf le lisezmoi.txt que vous lisez actuellement dans le répertoire Conquete. N'importe quelle unité peut être utilisée (le c: interne, le d: en CompactFlash ou tout autre unité).

Les fichiers sons ne sont pas nécessaires.

Notez que vous pouvez utiliser un autre répertoire que \System\Apps\Conquete, mais vous ne verrez plus l'icône Conquête depuis la barre Extras.

Un fichier de sauvegarde est automatiquement créé si besoin (..\Conquete\Conquete.sav).

Instructions
------------

Le but du jeu est de conquérir la planète Terre en éliminant vos adversaires. 117 pays sont représentés. Vous disposez de troupes en début de jeu pour attaquer et occuper les pays.

Le déroulement du jeu est assez facile à comprendre, très intuitif, tout se joue au stylet. Un fichier d'aide (accessible par le Menu) vous apportera tous les compléments nécessaires.
