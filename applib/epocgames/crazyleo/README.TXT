Installation Instructions:
--------------------------

The 6 distributed files are CrazyLeo.app, CrazyLeo.aif, cul.mbm, culicon.mbm,TOOLBAR.MBM & crazyleo.set

1) Make sure you can see the System folder on the Psion by using the check box
   in the System menu -> Tools -> Preferences -> Show 'System' folder.
2) Create a new folder called 'CrazyLeo' under C:\System\Apps thus C:\System\Apps\CrazyLeo
3) Copy all the files from the distribution to this folder with PsiWin.
4) Now you should see the 'CrazyLeo' Icon in the Extra Toolbar.

Game Description:
-----------------
Crazy Uncle Leo is a stock trading game.

Your Crazy long lost Uncle Leo left you money. However he has specified a list of rules you must follow before you actually get any money. Crazy Leo has provided a list of 10 companies. You must make 27 stock trades (buys-B or sells-S) on these companies. Whatever you have left in cash after the 27 trades is yours!  Also, Uncle Leo set a rule that you can only hold 5000 shares at one time. All of the stocks Crazy Uncle Leo has chosen have the potential to make or loose alot of money. Some of the companies can even go bankrupt. So invest wisely.
