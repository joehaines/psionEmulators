OVERVIEW

Cricket Statistics allows the user to track the performance of a cricket
team in limited over games.  The program records a mini scoresheet of
each game and uses that to calculate bowling and batting statistics
of each player.

INSTALLATION INSTRUCTIONS

This program is packages as a SIS file; the standard way to install
EPOC programs.  If your Psion Series 5 have the Install/remove
component in the Control Panel, then you can proceed to the next
paragraph.  If you don't have that component, you'll need to download
it from the Psion web site and install it on your Psion.

Copy this file to your Psion (root directory) and run the sis file from 
the Psion.  The program will be installed in the correct directories and
the installation file will be deleted.

If you want to remove CricketStatistics, open the Control Panel on the
Psion, select the Install/remove component and select Cricket Statistics
from the list.  Press the delete button.
