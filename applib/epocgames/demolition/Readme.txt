          S5 Demolition v1.0

               Installing

Unzip all the files and you should end up with
all the files in a folder called demolition.
Simply drag this folder into your Psion`s
system/apps directory on any drive. You should
then end up with all the files in your Psion`s
system/apps/demolition directory. The game icon
should now appear on the extras bar.

                 Playing.

All game instructions can be accessed from the
help file when running.

                Performance.

The Series 5 is a slow machine when it comes to
fast moving arcade games (that`s why there are
so few written). Demolition is fastest when
programs running in the background are shut down.
Also try the different settings in the Sound menu
as this greatly effects playing speed. Changing
the screen contrast also improves visibility.
