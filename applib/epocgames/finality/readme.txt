I Presentation

Finality is a small and simple logic game. A series of bars are dispayed on the screen, and when playing against the computer, you have to remove between 1 and 3 bars. The object is to let the computer remove the last bar. You will see that the principle is easy but to win a game is quite difficult.



II Installation

Finality is distributed in a sis file. To install it directly on your machine or from the PC (you must have psiwin 2.1 or more), simply open Finality.sis and follow the instructions.



III Freeware

Finality is a freeware, you can use and distribute it freely. But you mustn't modify the source code which is the property of the author.
