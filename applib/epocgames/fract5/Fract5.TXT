1. About Fract5
   ================================
   Fract5 produces different fractal images. Included in this version
   are 4 "orbit" type fractals: Hopalong, Threeply, Quadruptwo and Chip.
   I got the names and formulas of the orbit type fractals from the great
   PC software FRACTINT.

   ============

   Just copy at least one of the following files to your Psion palmtop:

	Fract5		OPL source code in EPOC format.
	Fract5.opl	OPL source code in plain text format.
	Fract5.opo	Compiled OPL file.
