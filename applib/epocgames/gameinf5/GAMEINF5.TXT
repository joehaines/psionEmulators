                                  GameInfo 5 (Version 1.0)
                        -The codes and cheats database-

Welcome to GameInfo, a database of cheats and level codes for Psion games.
At the moment, the database is small, but with your help it can grow bigger.
The database covers cheats for games (such as health or level skips) and
codes for games that need codes (Jumpy!, Dungeons etc.)

Installation:
Place the GameInfo file in your Documents directory on any drive. Then go to
the System screen, and select the Documents folder, then tap the GameInfo
icon to launch the database.

Using the database:
It is easiest to use the List view to select the record you need.
Each record has the name of the game, with the name of the author in
brackets. Underneath this, there is a list of the platforms that the cheats
work for. These include 3 (Series 3/3s), 3a/c (Series 3a/3c), Siena (Siena)
and 5 (Series 5).
This database is only for the Series 5.

Adding to the database:
If you are a software author, or have discovered codes/cheats in programs
not listed so far (especially ones for the 5), please send any codes/cheats
to me for inclusion in future updates of GameInfo. You will get your name
in the "contributers" section, plus your info could help many Psion gamers!
