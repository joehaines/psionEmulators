Gamesets


INSTALLING

Install the gameset file (*.gs) in the gamesets directory
(c:\gamesets or d:\gamesets) of your Epoc device using the 
connectivity package supplied by your device manufacturer.


RUNNING

Start the program by selecting 'Extras' from the Application
bar and then selecting GemTile.


ADDING GAMESETS

You can download free gamesets and play them with GemTile.
Please follow this steps:

1. Go http://www.beelogic.com
2. Visit the Gamesets page
3. Download as many free gamesets as you want
4. Follow the Installation procedure quoted above


BUILD YOUR OWN GAMESETS

You can build your own gamesets and play them with GemTile. 
Just follow this basic steps:

1. Use your favourite graphics package to build up to 16 bitmaps
    of 480 x 240 pixels.
2. Reduce the number of colours of your graphic files to 4 colours
    (levels of gray).
3. Save your files as Windows Bitmaps (BMP).
4. Use BMCONV.EXE (or the equivalent) program (included in your
    PsiWIN software) to create a Epoc MultiBitmap file with your BMPs
    (please refer to your PsiWIN documentation for information on how
    to use BMCONV).
5. Rename the MBM file as mygameset.gs
6. Follow the Installation procedure quoted above
