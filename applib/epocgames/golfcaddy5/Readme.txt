DESCRIPTION
--------------------

What is GolfCaddy5?
 It’s a electronic Golfcard and  Caddy for you to carry on the golf course, which automatically takes away the pain of  totaling up your game score during and at the end of play. You can also record extra detail about your round which will allow you to completely analyse  your short and long term game.

It provides the following features:

1.	Automatic Scoring carried out. Games supported are Stableford, Matchplay ,Medal stroke play  and other. Automatic selection of  handicap allowance with over ride (Full,7/8,3/4,7/16,3/8,none.)
2.	Up to 500 Blank Course Cards can be Entered, Each card will save yardage, Par, & stroke index information etc. You can add notes about each hole. Enter information about the course. This will all be held with the card.
3.	Up to 1000 marked  Cards can be saved to be analysed  later. (Analyse planned for future version). 
4.	Quick view table
5.	Nett score viewing for either Marker , Player A or Player B or All in a small format
6.	Quick entering on card with pen or via keyboard
7. 	Lots of Graphical  Analysis functions
8.	Upto Four player game recording/scoring
9.	Caddy function, fully adjustable by user
10.	Hole Memo, History and stroke detail

INSTALLATION
----------------------
You can  install GolfCaddy5 on the C: or D: drive
If unzipping using 'PsiZip' for automatic extraction to the correct places.,tick the Restore folders box and choose the drive.
Were to put the files are saved on the Zip file under Folder.The following below is for your information if extracting manually.Becareful to name all folders correctly.

Unzip all files

press 'SYSTEM' icon
press 'MENU'  under tools select 'PREFERENCES' and tick 'SHOW SYSTEM FOLDER'
press 'OK'

go to System\apps\ on either the C or D drive.
Create folder called  ‘GolfCaddy5’
Copy  the following files in to GolfCaddy5. The following is an example of installing it into the C drive.

C:System/apps/GolfCaddy5
GolfCaddy5.aif
GolfCaddy5.app
GolfCaddy5.icn
Create FOLDER  ‘CardData’
Create FOLDER ‘Pic’

				Buttons.mbm
				Title.mbm
C:System/apps/GolfCaddy5/CardData
				Options
				Cardlist
				Caddy
				CourseList
				Rounddata4
				Clubs
				Create FOLDER ‘CARD28081’
C:System/apps/GolfCaddy5/CardData/Card28081
				Data

Pressing the Extra’s bar should reveal the Icon for GolfCaddy5

If you want the program to work on drive D and have installed it on Drive C, Goto C:\system\apps\   ,Highlight the GolfCaddy5 folder . Press 'Ctrl+x' (Cut) .  Goto Drive D:\system\apps . Press Ctrl+v (Paste) .

***********Upgrading V1.21 to V2.0***************
Please do the following in the selected folders:

In the Folder 'System/apps/GolfCaddy5'
REPLACE FILE  GolfCaddy5.app
REPLACE FILE GolfCaddy5.aif

In the Folder 'System/apps/GolfCaddy5/Pic'
REPLACE FILE Buttons.mbm
DELETE FILE background2.mbm

In the Folder 'System/apps/GolfCaddy5/Carddata'
DELETE FILE Clubyards
ADD FILE Clubs
ADD FILE Caddy


You may have noticed a file called ROUNDDATA4, do NOT install this file if upgrading. The program will automaically upgrade your existing ROUNDDATA file.

BUG REPORTING
------------------------
Please be aware that you may encounter a 'General Failure' within the program . This is due to you having extremley low batteries on your machine and the application  attempting to write to the D Drive. I have not yet installed a fix for this. Do not take your machine on the golfcourse with low batteries.The program will lose all unsaved data if this happens.

Before reporting any calculation errors Please ensure that the game type is the one you want. Also the correct Handicap allowance has been selected. All handicaps entered correctly .
Hopefully there will be few bugs with this version but a lot has been changed , if you find any please notify me by Email with a fully description of what happened.

If you have trouble installing GolfCaddy5 please ensure all folders created by yourselves have been named correctly and all files are in there correct location. Also if you have installed from CD rom please change all file properties to'Modify'.  Also please make sure that  all the files are either all on the C drive or all on the  D drive.Do NOT mix!!  If you still have no luck then please Email me for a quick response.

AQUICK DEMO
---------------------
Once you have got past all the registration pages press (Ctrl+L) and select the demo preiously played round.

Press (Ctrl+g) to view various game types
Press (Ctrl+v) for quickview
Press (Ctrl+w) for Card analysis
Press (Ctrl+x) for Card group analysis. This selection needs at least 10 rounds of data to work well

Some quick tips:
Instead of tapping the column to enter the score try pressing 'S'
Scroll up and down the card using the arrow keys on the keyboard.
Turn off Green recording and small nett scores to speed up the 'update' of the card.
If entering old marked golfcards ,enter them in date order,oldest first.
For the first few rounds on the golfcourse mark another card just in case you don't get on with the program!!
