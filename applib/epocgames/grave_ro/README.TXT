GRAVE ROBBERGrave Robber is an old-school text adventure game for the Psion Series 5 palmtop computer, which uses a 'classic' (ie, simple) VERB-NOUN parser to interpret your commands. No graphics, no pen support, no flashy effects - just text, puzzles and your brain.INSTALLATIONGrave Robber is a single translated OPL program file. It can be put anywhere on your Psion's C: drive, but I'd recommend putting it inside an Applications or Games folder. I'd also recommend keeping the program inside the folder it should (hopefully - I've never done this before) appear in when unzipped, as it creates data files for use with a saved game.PLAYAt the start, you're asked if you want to load a saved game. If Grave Robber can't find the correct save game files, it will tell you so, then start the game from the beginning. You can load a saved game at any time by typing QUIT, pressing Y when asked if you want to play again, then pressing Y at the 'Load Saved Game?' prompt. To save a game at any time during play, just type SAVE.NB: Because of the limitations of my current knowledge of OPL (this is my first proper program) you can only have one saved game file on the Psion at once. I may fix this in later versions.All the commands you need to complete the game are listed when you type HELP. No trying to work out what obscure verb the programmer wants you to use in this game! I've tried to make the game as logical as possible - all the clues you need to solve a puzzle should be there if you look.CONTACTIf you find any bugs, spelling mistakes, things that don't seem to work right or whatever, let me know at andymc@paragon.co.uk and I'll try to fix them for the next update.
