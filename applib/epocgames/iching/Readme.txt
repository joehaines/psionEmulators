Introduction
------------
Thanks for trying I Ching.

The Zip file you have just opened should contain the following files:

	Iching.sis
	Pscape.sis
	Readme.txt (the text file you are now reading)

Installation
------------
Using PsiWin:

	Double-click the Iching.sis file in Explorer. This will start the EPOC
	Installer and ask you which drive you wish to install the program to.
	Follow the on-screen instructions to complete the installation. When the
	Install program asks if you'd like to install another program, select Yes
	and select the Pscape.sis file. Once this has finished, installation is
	complete.

Using the Series 5:

	Copy the Iching.sis and Pscape.sis files to any location on your Psion.
	Double-tap each of them in turn to install the SeaStrike application and
	Palmscape common library files.

Un-installing
-------------
To remove I Ching from your Series 5, either:

	Open Control Panel. Select the Add/remove icon. Search through the list until
	you find the entry for I Ching. Select it and tap the Remove button.

	Or

	Ensure you can see the System folder. If not, press the System icon, press
	the Menu key, select Preferences from the Tools menu and place a tick in
	the Show 'System' folder check box. Click OK. Navigate to the System/Apps
	directory on the drive you installed the program to and delete the contents
	of the IChing directory.

In either case, it is best to leave the files installed from the Pscape.sis file
on your Series 5. If these files are removed, it will affect the functionality
of other Palmscape products.
