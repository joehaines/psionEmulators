jS Solutions jsLogix 1.0
------------------------
(shareware)

jsLogix is a classical and simple logical game for shortening your idle time. Your task is to puzzle out which stones should be placed in which holes in a row...

Current version of jsLogix supports full range of Epoc Release 3 - Release 5 equipped computers including Psion Revo and netBook.


Installation
------------
Simply run jsLogix.sis and follow the instructions.


Starting jsLogix
----------------
You can run jsLogix from the Extras bar as usual.
