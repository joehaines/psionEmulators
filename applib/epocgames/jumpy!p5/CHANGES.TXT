Version 3.00F      6th November 1998
-------------      -----------------
 o  We now have a Siena, 3a/c/mx and Series 5 versions!
 o  Released as a Palmscape application (http://www.palmscape.com).
 o  Junked upgradable file structure, as it caused more problems than it
    solved, espcially with all the new features.
 o  Added Jumpy! Plus, featuring:
	- 36 more levels
	- new graphics
	- animated levels
	- sticky blocks
	- vertically moving creatures
	- toggle switches
	- push switches
	- switchable walls
	- switchable floors
	- conveyor belts
	- springs (I like these.  They're fun. :))
	- crumbling floors
	- ladders
 o  Rewrote a little more of the engine in C for speed.
 o  Many more minor changes and additions.

Version 2.00F           5th January 1998
-------------           -----------------
 o  Rewrote part of the game engine in C, resulting in much faster gameplay.
    Now runs at up to 12fps, making it extremely playable.
 o  Added optional digital sound effects.
 o  Game screen does not "wrap round" - ie. you can't see one side of the
    level when you're at the other.
 o  Fixed bug that occurred when the ini file was corrupted, and added some
    robustness to the writing of the high score table and ini file.
 o  Rewrote some of the help screens and part of the manual.
 o  Changed score table menus and added "Reset scores" and a
    "Return to title" options.
 o  The game now pauses properly when you switch to another task.
 o  Shifted functions between JumpyX.OPA and Classic.OPO so add-on packs
    are more effective.  Means that future add-ons won't work with 1.00
    versions, but the user will be warned about this.  Old reg codes still
    work.
