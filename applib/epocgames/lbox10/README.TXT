LIGHTBOX V1.0 (Psion 5)
======================

"LightBox" is a fast paced puzzle game where you have
to think against the clock.  A beam of light enters the box from
the left, you must ensure that it exits from the right.  It's just
a shame about all those blocks and mirrors in the way...  Still, at
least there are bonuses available.  If you've time to think about them.

INSTALLATION
============

1)  From the system screen menu, ensure that "Show hidden files" and
"Show 'System' folder" are both checked.  (These are under Tools-
Preferences).

2)  Make a new directory \System\Apps\LightBox

3)  Copy all files from the distribution except this one (readme.txt)
into the new folder.

"LightBox" should now appear on the extras bar.  Select this and the
game will start in PAUSE mode.  Once you toggle pause off, simply tap
on the screen to rotate blocks and mirrors.  Further information on
how to play is in the help file.
