Qu'est ce que "MBornes5" ?
--------------------------
MBornes5 est une contraction de Mille Bornes pour Serie5. C'est une adaptation libre du jeu de Mille Bornes, très populaire il y a une vingtaine d'années, et créé par Dujardin International. Mille Bornes existe déjà pour les Psion Serie 3a/c (mais pas sur le Siena du fait des limitations par la taille de l'écran), et MBornes5 est la version sur machines à base d'EPOC32.

MBornes5 nécessite un écran de 640x240. Il est donc censé fonctionner sur tout Serie5. Il devrait également tourner sur le Geofox (640x320), et sur toute machine équipée d'une écran de résolution supérieure à 640x240 (bien que ceci n'ait été testé que sous l'émulateur support de développement WINS)

Installation
------------

* Le plus simple, si vous disposez d'un PC sous Windows 95/98, est d'utiliser le package MBornes5.sis : l'installation est automatique.

* Sinon, suivez les recommandations qui suivent...
Créez un sous-répertoire \Mbornes5 dans le répertoire \system\apps. Il est possible que vous deviez rendre ce répertoire visible si ce n'est pas le cas. Référez-vous à la documentation de votre Psion pour ce faire. Copiez tous les fichiers sauf le lisezmoi.txt que vous lisez actuellement et son équivalent anglais (readme.txt) dans le répertoire MBornes5. N'importe quel unité peut être utilisée (le c: interne, le d: en CompactFlash ou tout autre unité).

Les fichiers sons ne sont pas nécessaires, mais le jeu perd de son intérêt s'ils manquent !

Notez que vous pouvez utiliser un autre répertoire que \System\Apps\MBornes5, mais vous ne verrez plus l'icône MBornes5 depuis la barre Extras.

Un fichier de configuration est automatiquement crée (\MBornes5\MBornes5.ini) lorque le jeu est lancé pour la première fois.

Instructions
------------
Le but du jeu est d'atteindre 1000 bornes avant votre adversaire, ou à défaut d'aller plus loin que lui. Une partie se compose de 5 manches.

Le concept du jeu est très simple. Vous devez placer une carte feu vert pour démarrer, et placer ensuite vos bornes. Votre adversaire peut vous arrêter en plaçant différentes cartes d'attaque. Vous pouvez les contrer avec des cartes remèdes, et vous avez bien sûr la possibilité d'attaquer également votre adversaire.

Référez-vous à la documentation en ligne dans le jeu pour plus de détails sur le jeu et les cartes (appuyez sur la touche Menu ou tapez sur l'icône menu, et choisissez "aide Détaillée").

Pour jouer, cliquez sur la carte que vous désirez placer, puis à l'endroit où vous voulez la déposer. Vous serez guidé dans votre choix par un clignotement des mouvements autorisés.

Vous pouvez choisir entre le Français ou l'Anglais (mais vous devrez effectuer le choix vous-même, dans la mesure où aucun appel système n'est disponible dans la version de base de l'Opl - et dans la mesure où je n'utilise par la bibliothèque sysram1.opx).
