What is "MBornes5"?
------------------
MBornes5 stands for Mille Bornes for Serie5. This is a free adaptation of a French cards game which was quite popular 20 years ago, created by Dujardin International. Mille Bornes already exists on Serie3a/c (not Siena due to screen size restrictions), and MBornes5 is a port on EPOC32 machines.

MBornes5 requires a 640x240 screen. Thus should work on any Psion Serie5 machine. It should work on Geofox as well (640x320), and any screen resolution larger than 640x240 (though this has only been tested on EpocWorld's WINS emulator development tool).

Installation
------------
* If you own a PC under Windows 95/98, just double-click on the MBornes5.sis to launch the automated installation process.

* Otherwise you can do this...
Create a \MBornes5 sub-directory in your \system\apps directory. You may need to make the \system directory visible, please check your Psion manual if you've never done this before. Copy all files but this readme.txt and its french equivalent (lisezmoi.txt) in the Mbornes5 directory. Any drive can be used (internal c:, CompactFlash d: or any other drive).

Sound files are not required. Though the game is much more enjoyable with them.

Note that you can use any directory rather than \System\Apps\MBornes5, but you won't see MBornes5 from your Extras bar...

One configuration file is automatically added (\MBornes5\MBornes5.ini) when the game is run for the first time.

Game instructions
-----------------

"Bornes" stands for kilometers or miles (depending on your country's system). The goal is to drive 1000 bornes before your opponent does, or at least drive farther than he does. There are five races in one game.

The concept is rather simple. You have to place a green traffic light to start, then start to place bornes to drive. Your opponent can stop you using various annoying cards. You counter those attacks with remedies, and are able to attack your opponent as well.

Check the online docs in the game (hit Menu key or tap on the menu icon, then select "Detailed help".

To play, just click on the card you want to use then where you want to place it.
You'll be helped in your choices by flashing cards indicating what you are allowed to play.

You can choose between English or French language (but you'll have to do it yourself as no localization system call is provided in the basic Opl manual yet - and I'm not using sysram1.opx).
