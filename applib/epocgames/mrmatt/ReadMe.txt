Introduction

Mr Matt is a puzzle game in which you control the eponymous hero, digging
through earth to reach apples while avoiding being crushed under rocks.
Unlike many similar games, it is a purely mental exercise, as there are
no enemies to avoid, time limits to beat, or lives to lose. Full
instructions are in the online help.


Installation

To install Mr Matt, copy the file MrMatt.sis on to your EPOC machine and
run it, or install it via PsiWin (or equivalent program) from your
desktop computer. Once installed, a Mr Matt icon will appear on the
Extras bar; tap it to start Mr Matt.

The game should run on any EPOC machine (release 5 or earlier).
