      Othello Version 2 Readme

   Installation

It's really very simple.  Just go to '\system\apps' on either C or D and create a directory called 'Othello'.  Copy the following files into this directory :

	othello.app	
	othello.aif
	othello.hlp
	graphics.mbm

That's it, now just select the icon from the Extra's Bar.

For more details on Othello, please see the help file.
