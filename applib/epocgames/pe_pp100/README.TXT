Psimple Psimon v1.00
====================

Overview
--------

Psimple Psimon is based on an old memory game. You have to watch the computer display
a certain pattern of lights (and sounds) on the screen and repeat it. This game is
highly addictive and helps to improve your memory.


Installation
------------

As you are reading this, I am assuming that you have unzipped Psimple Psimon, or your
version has been distributed in an uncompressed form.

However, you should now be able to see two files:

pe_pp100.sis  - Psimple Psimon installation
Readme.txt    - This file

If you have PsiWin version 2.1 then you should be covered and can click on the
pe_pp100.sis from either your PC or the Psion. This will start up the EPOC installer
program and the rest is easy. However, if you do not have PsiWin 2.1 then you need
to get your hands on the "Add remove control panel" add-on. This can be obtained
from Psion free of charge and you can find a link on my web site under the title
"If you have downloaded Psimple Psimon and cannot install it then read below!".

Basically you copy this file to your Psion and double click it... thus adding the
"Add remove control panel" add-on to your Psion. However, if you are an information
junkie like myself and want to browse through the official manual on the program that
you may want to look at the other link on my page.

When you have added the program mentioned above, you can copy the pe_pp100.sis file
onto your Psion and double click it, starting the installation process.

Troubleshooting
---------------

If you need any help installing Psimple Psimon, take a look at the Psimple Psimon
web site, http://www.planetepoc.com/psimple/ or send an email to
psimplepsimon@planetepoc.com

When you have installed Psimple Psimon, take a look at the on-line help (CTRL+SHIFT+H)
