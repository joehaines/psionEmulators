PEBBLES ON THE MOVE

Around the end of the nineteenth century, a group of games
collectively called "hop over" puzzles became popular. These were
solitaire games, the object of which was to move a set of pieces on a
board so that their positions were swapped, taking as few moves as
possible. Pebbles on the move brings one of these charming puzzles to
your Psion compatible hand held computer.  You can visit its home page
at:

		  http://pebbles.snigfarp.karoo.net/

    * Psion Revo Plus
    * Diamond Mako
    * Ericsson MC218
    * Psion Series 7
    * Psion Netbook
    * Geofox One
    * Oregon Scientific Osaris

INSTALLATION

You can install this game either using PsiWin or on the EPOC machine
itself.  In either case, follow these steps:

1. You should have received Pebbles On The Move as a ZIP file.
   Inside this is an SIS file; extract the SIS file from the ZIP.
   This can be done using WinZip on a PC, or RMRZip on the handheld.

2. Double click on the SIS file on the PC or the handheld.  Follow the
   on screen instructions to install the package.  You will be asked
   which graphics set(s) you want to install: make sure that you
   install the correct ones for your machine.

3. Now you should be able to run Pebbles On The Move from the Extras
   bar.
