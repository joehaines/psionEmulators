Introduction

Pipeline is an enjoyable puzzle game for the EPOC32 range of palmtops. What
you have to do is connect together the piping to transport the fuel through
the levels.
You can play One-player or Two-player co-operative through the 50 different
levels (until you have registered this is limited to 10 levels).
Or you can battle out head to head on 10 unique battle levels on the
Two-player vs games.


Installation instructions

If you have not already unzipped the contents of this zip file please unzip
it now to a temporary directory.

To install SIS files you will need either Psiwin 2.1 (or greater), EPOC
Connect or Add/Remove Programs on your EPOC32 control panel. See the
instructions below relevant to your situation for how to get one of these
and how to install a .SIS file using it.

For PC Users - Windows 95/98/NT

If you do not have Psiwin 2.1, get it from www.psion.com and install it on
your computer.

   1.Locate the PIPELINE.SIS in Explorer. 
   2.Double-click to install the file. 
   3.You will be guided through the installation and the program will be
   installed.
   4.Additional you need to install SYSRAM1.SIS, so locate it in Explorer.
   5.Double-click to install the file.
   6.Finished - it's as easy as that. Select Pipeline from you Extras bar to
   play Pipeline. I recommend reading the help file before playing. The help
   file can be accessed inside Pipeline from the Toolbar or from Help under
   the Tools menu (Shift+Ctrl+H).
Note: You will need to install SYSRAM1.SIS, unless you are sure you have
already installed SYSRAM1.OPX to C:\SYSTEM\OPX - in which case miss out
steps 4 and 5.

When you want to uninstall the program simply open up your Control Panel,
open Add/Remove and uninstall the relevant program from the list.

For Mac users

You will need MacConnect - which is currently not free unlike Psiwin. If you
do not have it - don't worry you can still use the Add/Remove on your Psion,
see 'For other users' for instructions on how to do this.

   1.Select PsiTools from the Psion menu. 
   2.Press the Install button and locate the .SIS file you wish to install. 
   3.Select the PIPELINE.SIS file and click Open. 
   4.Follow the instructions and you will be guided through the installation. 
   5.Now also install SYSRAM1.SIS, as you did above for PIPELINE.SIS
   6.Select Pipeline from you Extras bar to play Pipeline. I recommend
   reading the help file before playing. The help file can be accessed inside
   Pipeline from the Toolbar or from Help under the Tools menu (Shift+Ctrl+H).
Note: You will need to install SYSRAM1.SIS, unless you are sure you have
already installed SYSRAM1.OPX to C:\SYSTEM\OPX - in which case miss out
step 5.

For other users

You will need the Add/Remove Programs on Control panel installed on your
machine. If you don't have it then follow these instructions:-

   1.Download inst_te.exe (this is an EPOC32 .EXE file NOT a PC .EXE file). 
   2.Copy this file across to the root "\" of your EPOC32 machine. 
   3.Locate the file in system and press Enter to run it. 
   4.After a few moments the file will disappear and you will have Add/Remove
   added to your Control panel.

Now that you have Add/Remove in your Control Panel to install a .SIS file
follow these instructions:-

   1.Copy PIPELINE.SIS and SYSRAM1.SIS to the root, "\" on your EPOC32
   machine.
   2.Select the PIPELINE.SIS on the System screen and press Enter. 
   3.Follow the on-screen instructions and the program will install.
   4.Select the SYSRAM1.SIS from the System screen and press Enter, as before.
   5.The .SIS files will deleted after installation to save disk space. You
   can now use the program. Select Pipeline from you Extras bar to play
   Pipeline. I recommend reading the help file before playing. The help file
   can be accessed inside Pipeline from the Toolbar or from Help under the
   Tools menu (Shift+Ctrl+H).
Note: You will need to install SYSRAM1.SIS, unless you are sure you have
already installed SYSRAM1.OPX to C:\SYSTEM\OPX - in which case miss out
step 4.


Registering

This program is Shareware and consequently until you have paid you are
limited to only the first 10 of 50 levels. For full details on how to
register, install and run Pipeline, and from Tools menu choose Register
(Ctrl+R) then choose Info (Ctrl+I). Alternatively all that information is
available in the help file under 'Registration'. The help file can be
accessed inside Pipeline from the Toolbar or from Help under the Tools
menu (Shift+Ctrl+H).
