Installation/Upgrade procedure
------------------------------
If upgrading then first make sure that PocketChess is not running.

The easiest and best way to install/upgrade is to use the SIS package. 

Otherwise, to install/upgrade manually do the following:
The 12 distributed files are PKTCHESS.APP, PKTCHESS.RSC, PKTCHESS.AIF,
OPEN.MVS, CHESS.HLP, README.TXT, LICENSE.TXT,
CHECK.SND, MATE.SND, PROMOTE.SND, CAPTURE.SND, 
PBOARD.MBM, PBOARDALT.MBM, PBOARDSMALL.MBM, PBOARDALTS.MBM

1) Make sure you can see the System folder on the Psion by using the check box
   in the System menu -> Tools -> Preferences -> Show 'System' folder.
2) If you are upgrading then delete everything in C:\SYSTEM\APPS\PKTCHESS\ 
   then go to step 4.
3) Create a new folder called 'PKTCHESS' under C:\SYSTEM\APPS 
   thus C:\SYSTEM\APPS\PKTCHESS (or on a CF card: D:\SYSTEM\APPS\PKTCHESS).
4) Copy all the files from the distribution to this folder with PsiWin.
5) Now you should see the 'Chess' Icon in the Extra Toolbar.


General Notes
-------------
You can call the online help from the "Tools" menu for further explanations.

The default chess piece set is shaded, an alternative plainer but clearer
set is available when you select "TOOLS/ALTERNATE PIECES" from the menus.
