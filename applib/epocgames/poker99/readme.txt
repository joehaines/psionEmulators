   1. General information

   Poker99 is a card game for EPOC 32 based computers. This fascinating 
program will amuse you at home and entertain during a long trip. 
Although Poker99 is easy to play, it have extended help system (rules, 
scoring, customizing etc.) This version is equipped with such powerful 
features as "virtual victory analyzer" and "statistics". 
   Poker99 supports two languages - English and Russian. When program 
starts it asks you which language you prefer to use. You need to have a 
Cyrillic driver for your system to display symbols correctly when 
Poker99 is in Russian language mode. This version of game was tested to 
work with Konstantin Saliy's RusLat Cyrillic driver.
   For more information visit Poker99 web site:
   http://www.geocities.com/SiliconValley/Lakes/7023/poker99.htm


   2. Installation

   2.1 Check your software and connections. You will need EPOC Connect 
or PsiWin (v. 2.1 or later). If you have these programs installed on 
your computer then simply connect EPOC machine (Psion Series 5/5mx, 
Ericsson MC218, etc.) to your PC.
   2.2 Extract "Poker99.SIS" from the zip archive.
   2.3 Double-click on Poker99.SIS in Windows Explorer*. Poker99.SIS 
will initiate the EPOC add/remove program, which will guide you through 
the installation process.
   2.4 Tap on "Extras" button on your EPOC machine (bottom right corner 
of the screen); find Poker99 icon on Extras bar and tap on it. The game 
starts.
-----------------------------------------------------------------------
*) It is possible to start Poker99.SIS directly from EPOC machine - 
copy Poker99.SIS to any place on EPOC machine and then tap on it. (You 
need to have add/remove program installed on your EPOC machine).
