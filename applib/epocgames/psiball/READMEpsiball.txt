PsiBall
=======
Version 2.2 - May 2001

Introduction
------------
Shareware version 2.2 for the Series 5, Series 5mx, Revo, Revo Plus, Diamond Mako,
Series 7 and NetBook.
This is my Psion version of one of my favorite PC games.  It started off life
on my 3c but the speed of that machine was not enough and the game was too slow.
The Series 5 presents a much better platform for the game, however, it will be
best placed on the Series 5mx with its much faster processor!  Enjoy!

Enhancements
------------
Version 2.2
1) Improved to animation speed.
2) Added colour graphics for the Series 7 & netBook.
3) Added Revo compatability.

Version 2.0 was updated from the beta version 1.0 for the Series 3c to add
better control using the pen and to take advantage of the larger screen and faster
processor.  It is also designed to run on future machines where the processor speed
will increase but the game play speed will remain the same.

INSTALLATION
------------
To install the program simply double-click PsiBall.sis file to install all the
required files.  Or use the "Install New Program" option in PSIWIN (EPOC Install).
If you have the latest PSIWIN or EPOC Install then everything will happen
automatically.  If you don't have these then you need to get the installation file
SETUP.EXE, which can be downloaded from Pocket IQ's Home Page or from www.psion.com.

You can also copy the SIS files directly to your Psion 5, 5mx, GeoFox
Series 7 or NetBook and double select them to launch the install program.

This will install the program and also install the PIQinfo.SIS file for the
essential Pocket IQ common files and the  SYSRAM1.SIS file to install the essential
system files.

The graphics file for either Black & White (Series 5 and 5mx), Small (Revo) or
colour (Series 7 and Netbook), if you wish to use PsiBall on a different machine
type you will have to re-install to get the correct graphics loaded. The redundent
graphics files will be removed the first time you run PsiBall as to save disk space.

Please note, that if you try to run the game in a machine that requires different
graphics then when you run PsiBall you will see an error message telling you that
program files are missing: Please re-install.

Features
========
Object of the Game
------------------
Clear 75% or more of the game area trapping the balls, and avoiding loosing all the lives in one level.  Lives are allocated for each level and the number given depends on the current game level.  Lives are lost when a ball touches a 'wall builder', or its trail, before the edge of the chamber is reached and the wall completed.  The higher the level, the more balls!

Movement
--------
The following keys are used to control the game action:
	For moving the cursor:~
		Left arrow - Move the cursor to the left
		Right arrow - Move the cursor to the right
		Up arrow - Move the cursor up
		Down arrow - Move the cursor down

	For building the wall:~
		Space Bar - Change the direction the wall will be built in
		Enter - Set wall builders off in direction of arrows.

Touching the screen will position the cursor under the pen, also, two buttons on the
score pannel can be used to rotate the cursor  and start the wall builder  as an
alternative to the keys.

Special Features
----------------
The following can be set:
	sound effects volume ~ high, medium, low or off;
	the speed of the game ~ slow, normal or fast;
	the keys for rotating the cursor and build the wall can be re-defined.
