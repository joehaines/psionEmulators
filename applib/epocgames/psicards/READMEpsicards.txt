PsiCards
========
Version 1.50 - September 2000

from PocketIQ 

Introduction
------------
This program, Shareware version 1.50 for the Series 5, GeoFox, Osaris, 
Series 5mx, Revo, Series 7 and NetBook.

This is designed to be the untimate card game program for EPOC machines.
The Pack Of Cards In Your Hand!  What makes it so is its impressive list
of features:
- Seven card games in one place: Spider, Montana, Solitare, FreeCell, Pyramid,
  Armistice and TriPeaks;
- Full colour support for the Series 7, NetBook and any future Colour Devices;
- Full support for the larger Series 7 & NetBook screens;
- Full support for the smaller Revo and Osaris screens;
- Full Scroll bar support for when cards do 'off' the bottom of the screen;
- Full pen and keyboard control;
- Full card animation;
- Sound;
- Full Game save feature (Registered users only);
- User selectable animation speed and animated dealing (Registered users only);
- Switch between Tap and drag card selection modes (Registered users only);
- User selectable front screen picture, background colour (ER5 and later) and
  Card backs;
- Multiple card layouts giving instant access to more then one game from the
  front screen;
- High score tables (Registered users only) and game statistics;
- The program is still evolving!  This is your chance to influence the direction
  the development takes, including what future Card games are supported.

INSTALLATION
------------
To install the program simply double-click PsiCards.sis file to install all the
required files.  Or use the "Install New Program" option in PSIWIN (EPOC Install).
If you have the latest PSIWIN or EPOC Install then everything will happen
automatically.  If you don't have these then you need to get the installation file
SETUP.EXE, which can be downloaded from Pocket IQ's Home Page or from www.psion.com.

You can also copy the SIS files directly to your Psion 5, 5mx, Revo, Osaris, GeoFox
Series 7 or NetBook and double select them to launch the install program.

This will install the program and also install the PIQinfo.SIS file for the
essential Pocket IQ common files and the  SYSRAM1.SIS file to install the essential
system files.

The graphics file for either Black & White (Series 5 and 5mx, colour (Series 7 and
Netbook), Revo or Osaris will be installed, if you wish to use PsiCards on a
different machine type you will have to re-install to get the correct graphics.

Please note, that if you try to run the game in a machine that requires different
graphics then when you run PsiCards you will see an error message telling you that
program files are missing: Please re-install.


RUNNING THE PROGRAM
-------------------
Start the program by selecting the 'Extras' from the Application bar and then
'PsiCards'.

You are now ready to play!

Full On-line help is provided and can be accessed from the Help menu.
