3. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. If you have a PC, you can install it using the 'Install New Program'
   command in PsiWin 2.1 or newer. If you have a Macintosh Computer, you 
   can install it using Psion MacConnect. If you have another computer, 
   you must have software to copy the .SIS file to the EPOC machine, once
   copied tap the .SIS file icon to install. 

   The following software can be downloaded from Psion's site: 
   http://www.psion.com if you do not have up to date software on your PC
   or EPOC machine.
   
   - PsiWin 2.1
   - Add remove icon (for installing directly from a EPOC machine) 
   - Epoc install (for installing from a PC)

2. Finally press Extras|PsiTris, to play.

3. To uninstall goto the Control Panel, tap the Add/Remove icon, select 
   PsiTris and finally press the Remove button.
