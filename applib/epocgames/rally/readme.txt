Installation Instructions

1. Unpack the Zip file to your PC or your Psion.

2. On the PC:
   Double click on the file Rally.SIS. This will start the PC
   automatic installation of Rally.

   On the Psion:
   Double tap on the file Rally.SIS. This will start the Psion
   automatic installation of Rally.

Rally should now be accessible to you from the Extras icon.
