INTRODUCTION
------------
RMRBoxx is a classic puzzle game: help Joey Boxx, the warehouse keeper, push
boxes to their destination in a warehouse, sounds simple? It's not because
the boxes are so heavy Joey can only push not pull making it possible to trap
them therefore logic is required to complete the job.

Features:
- Pen and/or keyboard control.
- High score table
- Position mark feature
- Unlimited undo
- Redo
- Play large levels, up to 50x50
- Auto screen resizing
- Auto resume from last position
- Export moves as lrup or as hjkl (XSokoban)
- Download free levels from the Internet
- Supports .txt and .xsb Sokoban formats

INSTALLATION
------------
To install the program simply double-click on the RMRBoxx.SIS or select the "Install New Program" option in PsiWin/EPOC Install.

RUNNING THE PROGRAM
-------------------
Start the program by selecting 'Extras' from the Application bar and then selecting RMRBoxx
