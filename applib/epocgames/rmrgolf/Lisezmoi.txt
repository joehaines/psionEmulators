INTRODUCTION
------------            
Ce programme est une version "badgée" RMR Software du fameux jeu de Golf pour EPOC de Ian Webster. 

Cette version Shareware est totalement fonctionnelle sans aucune limitation. Toutefois, après 30 jours d'utilisation, il commencera à vous rappeler "gentiment" qu'il est temps de vous enregister, pour soutenir le principe du Shareware et pour nous encourager à vous fournir des programmes de qualité.

            
DETAILS DE FICHIERS
-------------------            
L'archive doit contenir les fichiers suivants :
            
RMRGolf.sis     Le programme
Lisezmoi.txt   Instructions en français

(Et les diffÚrentes versions internationales du fichier Lisezmoi.txt)

Un fois installé, vous verrez que le programme est constitué des fichiers essentiels suivants : (/System/Apps/RMRGolf/)

RMRGolf.app     - Le fichier de programme principal
RMRGolf.mbm     - Les icônes utilisées dans le programme
RMRGolf.aif     - Les icônes utilisées dans l'écran System
RMRGolf.rsc     - Le fichier de ressource de langage

Ainsi que le fichier optionnel qui peut être lancé à la demande:

RMRGolf.hlp     - Fichier d'aide optionnel

Pour éviter que le fichier de distribution .SIS ne soit trop important, il ne contient que la version anglaise du fichier d'aide et des instructions.  Dans la plupart des cas, les versions internationales de ces fichiers sont disponibles depuis leurs pages à http://www.rmrsoft.com/  ou en envoyant une disquette à l'adresse anglaise indiquée dans le fichier d'aide.
            
INSTALLATION
------------            
Pour installer le programme; double-cliquez sur le fichier RMGolf.sis ou choisissez "Installer Nouveau Programme" dans PSIWIN (EPOC Install).

            
LANCEMENT DU PROGRAMME
----------------------            
Lancez le programme en choisissant RMRGolfl depuis la barre d'Extras.
