INTRODUCTION

Welcome to our 'Snake' program for the EPOC Series of handheld computers.

As it stands, this Shareware version is almost fully-working, but will allow only a limited number of levels, to enable you to try the program out.  Please note that registration does not involve reloading the program, but simply selecting the'Register' menu option and  typing in a registration code to release the 'lock'.

FILE DETAILS

The archive file should contain files:

RMRSnake.sis   The program
Readme.txt     English Instructions
(and possibly other international Readme files)

Once installed. you will see the program consists of the following essential files: (in \System\Apps\RMRSnake\)

RMRSnake.app  - The main program file
RMRSnake.mbm  - The icons used within the program
RMRSnake.aif  - The icons used in the System screen
RMRSnake.rsc  - The text resource file used within the program
/Levels/  A folder to contain the various levels

And the following optional files which you may have installed and can be deleted later:

RMRSnake.hlp     - Help File

INSTALLATION

To install the program simply double-click on the RMRSnake.sis file or select the "Install New Program" option in PSIWIN (EPOC Install). 

RUNNING THE PROGRAM

Start the program by selecting the 'Extras' from the Application bar and then 'RMRSnake'
