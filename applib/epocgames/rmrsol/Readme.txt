INTRODUCTION

This program is an RMR Software 'badged' version of Ian Webster's very successful Solitaire game for the EPOC Series. V2.0 simply adds EPOCRelease 5 (ER5) compatibility, there are no other enhancements.

As it stands, this Shareware version is fully-working with no disabled functions. However, after 30 days of use it will start to 'gently' remind you that it is time you registered, to support the Shareware principle and encourage us to provide you will more quality programs.

FILE DETAILS

The archive file should contain files:

RMRSol.SIS   The program
ReadMe.txt   English Instructions 
(plus other language README files)

Once installed. you will see the program consists of the following essential files: (all in /System/Apps/RMRSol/)

RMRSol.app     - The main program file
RMRSol.mbm     - The icons used within the program
RMRSol.aif     - The icons used in the System screen
RMRSol.rsc     - The language resource file

And the following optional files which can be loaded as required:

RMRSol.hlp     - Optional Help File

INSTALLATION

To install the program simply double-click on the RMRSol.sis file or select the "Install New Program" option in PSIWIN (EPOC Install).

To ensure the SIS file does not get too large, this contains only English versions of the Help file and any instructions. In most cases international versions of these files are available and can be downloaded from the appropriate national page at http://www.rmrsoft.com/ or by sending a disc to the UK address in the Help file.

RUNNING THE PROGRAM

Start the program by selecting the 'Extras' from the Application bar and then 'RMRSol'.

You can learn everything you need to about the program by playing with it and checking the effect of each MENU selection, particularly the 'Game preferences' and 'View preferences' options. We have not written any separate instructions, as we believe all the information you need is in the on-line Help file.
