==========================================================
REVERSI - V 1.2 for the Psion Series 5 & 5mx & compatibles
==========================================================

A Classic game, also known as Othello. Capture your opponents pieces between
your existing pieces and the piece you are placing, they then become yours.

Easy to play, but hard to master. With 10 skill levels ranging from Beginner
to Genius. The higher skill levels use advanced, unique, and fast artificial
intelligence to play a powerful, human like game. The Genius levels take
approximately 5 seconds to make a move (2 seconds on a 5mx).

Includes a 2 player game option.

High quality speech provides a female opponent that will, if you wish, comment
as the game progresses. Can be played with your Series 5 pen or the keyboard.

Includes lot's of options so that you can customise the the game to just how
you like it.

============
INSTALLATION
============

The minimum installation is 60k.

If upgrading from an earlier version, delete the previous version (YOU MAY KEEP
THE FILE RV-REG TO SAVE ENTERING YOUR REGISTRATION CODE AGAIN), before following
the installation instructions below.

Turn on your Series 5, press the System icon (bottom left of the screen),
press the Menu key, under 'Tools' select 'Preferences', make sure that there is
a tick next to 'show system folder' and click on 'OK'.

Go into either C:\System\Apps\ or D:\System\Apps\

From the menu, under 'File' select 'Make new folder' name it Reversi.

Copy all the files except README.TXT into this directory.

If you wish to save space, you may omit some or all of the sound files, but I
recomend trying the game with the sounds as they make it more fun.

Pressing the 'Extras' button (bottom right of screen) will now reveal
this programs icon, select it to begin.

If the program does not run, try renaming its folder to a different name,
wait a few moments, then rename it back to the correct name.

If you have difficulty with installation, re-read and follow carefully
the above instructions, you have probably put the files in the wrong place,
or named the folder incorectly.
