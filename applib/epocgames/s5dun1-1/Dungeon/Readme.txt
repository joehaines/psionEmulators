
                     S5 DUNGEON v1.1
                     ----------------


Introduction.
-----------------

  Dungeon is a  3d graphical monster shoot-em-up.
The object of the game is to search each dungeon
level collecting energy orbs. When these are all
collected you are able to enter the teleport and
beam to the next level. Each level, however, is
inhabited by nasty monsters intent on killing you.
You have a choice. Run away, or blow them away
with your shotgun! 
  The monsters are quite persistent and can creep
up from behind or from the side as well as straight
ahead. They can't harm you if they are diagonally 
away from you. You can  hear them coming and
there are also monster attack indicators around
the playscreen indicating the direction the  
monster attacks are coming from. On the right side
of the screen is an automap showing your direction,
current position and areas explored.
The game ends when your strength reaches zero.
This only goes up when you start a new level so
keep an eye on this. Your shotgun ammo also goes
down, but collecting an energy orb  will increase it.
  The teleport looks like an electric field and can
only be stepped into when all the orbs are collected.
Killing monsters may take several shots depending
on the monster strength chosen using the options.


Options.
----------

  When the game starts the menu screen appears
and presents you with several menus. Most are
self explanatory. Some menus are only available to
registered users. Unregistered users can only play
the first dungeon (There are twenty levels). Also, 
they cannot jump to other levels using the code words 
given during the game. Orb positions
are also fixed, and will be the same each time. All
the other options are available as normal.
Registered users can enter level codes to play where
they left off previously. Also they can
randomise orb positions making levels more interesting 
when played again. 
  All users can increase the number of monsters their 
strength and speed, but be prepared for a tough game!
Upon registering, you will receive your own personal 
access code which will free the whole game from all 
restrictions.


Control Keys.
-----------------

Use the up and down cursor keys for forward and
back.

Left and right cursor keys to turn sideways.

Fn key plus cursor left or right to step sideways.

Spacebar to fire the gun.
(Shotgun range is two places.)


Esc or menu quits to main menu.

You can also control the whole game using the pen.
Just tap the on screen direction arrows or fire
to make the appropriate move.
 This can be sensitive, so watch for double moves.
With a bit of practise I think this method works 
very well and becomes second nature.


Installing.
-------------

The game consists of the following files.

Dungeon.app
Dungeon.dat
Gun
Attack
Far
Wall

Readme.txt

These files should have unzipped into a directory
called Dungeon. Simply drag this whole directory
onto your Psion`s SYSTEM/APPS directory using explorer.

You should end up with the directory

C:\system\apps\dungeon

on your Psion containing all the game files.

If you have any extra memory, you can also install it
on your D drive using the above method.

Dungeon will also create a small file in your System 
directory when first run for registration purposes.

When installed, Dungeon will add an icon to the extras
bar. Just select this to run the program.

Updating
--------
When updating from version 1.0, just replace the files
Dungeon.app and Dungeon.dat
