Released as freeware July 1997 ...

To install Poker:

1) Make sure the \System folder is shown on your Series 5 system screen.
   If it's not, enable it in the 'Preferences' dialog.
2) Go into \System\Apps and make a new folder called "Poker"
3) Using PsiWin, copy across all the files from this distribution into
   the new \System\Apps\Poker folder.
4) That's it! Hopefully, you'll have a new icon on your Extras bar.

On-line support for Poker can be found on the World-Wide-Web at
http://3lib.ukonline.co.uk/

Have fun! My highest score is only around 380, I'm sure you'll have no
trouble beating that. Ali Manson claims a score of over 665, so mail me
if you can compete with that! 8-)
