SENET ON THE MOVE

Senet on the move brings to life for Psion computers the game of
Senet, which amused Egyptians for over three thousand years. Senet is
a board game of skill and chance, and bears some resemblance to our
modern game of Backgammon.

		  http://senet.snigfarp.karoo.net/

SYSTEM REQUIREMENTS

The game requires an EPOC handheld computer to run. It is known to be
compatible with the following models:

    * Psion Series 5
    * Psion Series 5mx
    * Psion Netpad (in monochrome)
    * Psion Revo
    * Psion Revo Plus
    * Diamond Mako
    * Ericsson MC218
    * Psion Series 7
    * Psion Netbook
    * Geofox One
    * Oregon Scientific Osaris

INSTALLATION

You can install this game either using PsiWin or on the EPOC machine
itself.  In either case, follow these steps:

1. You should have received Senet On The Move as a ZIP file.
   Inside this is an SIS file; extract the SIS file from the ZIP.
   This can be done using WinZip on a PC, or RMRZip on the handheld.

2. Double click on the SIS file on the PC or the handheld.  Follow the
   on screen instructions to install the package.  You will be asked
   which graphics set(s) you want to install: make sure that you
   install the correct ones for your machine.

3. Now you should be able to run Senet On The Move from the Extras
   bar.
