2. INSTALLATION
---------------
You must have Solitaire Deluxe installed first before installing any
tables and remember Solitaire Deluxe can only detect upto 8 tables so delete
what you don't want.
               
1. If your Show 'system' folder is not ticked then goto Menu | Tools | 
   Preferences and tick the Show 'system' folder.
2. Copy all the files (above) except for readme.txt, this file, into 
   apps\system\SolDX directory.
3. Press Extras | Solitaire DX, to play, Solitaire Deluxe will detect the new
   table(s) automatically.
