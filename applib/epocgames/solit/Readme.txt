								Solitaire
								---------
Introdution

In one of my lectures at university, we were shown how to solve solitaire.  Since I had never actually managed this myself, and I didnt have a board handy to test the solution on, I decided to write the program on the Psion to test the solution.  It worked.  You can see it using the 'solve' button on the toolbar.
If you are ambitious, you can try and beat my best time of ***16Seconds*** to complete the game.
Enjoy it, and please comment to pmyrrcl@pmn1.nott.ac.uk

Installation

Create a directory called "Solitaire" in the "system\apps" directory on either C or D.  Copy the following files into this directory :

			solitaire.app
			solitaire.aif
			sol.mbm

An icon will appear on the extra's bar, from which you can run Solitaire
