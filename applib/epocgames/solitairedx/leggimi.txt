2. INTRODUZIONE
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Solitaire Deluxe è il non plus ultra dei giochi di carte di tipo 
Solitario per macchine EPOC. Usa un sistema di plug-ins che ti permette 
di giocare immediatamente grazie al meccanismo 'Plug and Play'.Quando è 
disponibile un nuovo plug-ins , Solitaire Deluxe lo riconosce 
automaticamente.
            
I Plug-ins salvano spazio ed hanno una interfaccia molto semplice
            
Ma il massimo è che  Solitaire Deluxe è FREEWARE! Se ti piace ed hai 
un tuo sito web, crea un link con il nostro sito <http://www.fatcatz.tm> 
così più persone potranno unirsi a noi e divertirsi.
            
Ulteriori plug-ins sono disponibili e scaricabili gratuitamente dalla 
nostra pagina web.

3. AGGIORNAMENTO
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Se stai aggiornando una versione precedente del programma assicurati di 
cacellare la directory System\Apps\SolDX e tutti i file in essa 
contenuti. Se desideri tenere i file con i tuoi tempi migliori allora 
sposta tutti i file *.hst in una directory temporanea.Occorrerà inoltre 
reinstallare tutti i Plug-ins precedentemente installati.
            
Ora puoi installare l'ultima versione del programma senza problemi 
seguendo le indicazioni del punto 4. Una volta effettuata 
l'installazione ricordati di spostare i tuoi file *.hst nella nuova 
directory C:\System\Apps\SolitaireDX, se invece hai installato Solitaire Deluxe sul disco D allora devi creare questa directory sul drive C e spostarci poi i file *.hst .

4. INSTALLAZIONE
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. Ci sono 2 modi per installare Solitaire Deluxe che dipendono da dove è collocato il file.sis e da quale impostazione hai;
               
   - Sul PC con PsiWin
     Da Gestione Risorse fai doppio clic sul file .sis in modo che 
     Solitaire Deluxe venga installato sulla tua macchina EPOC. Se cio' 
     non dovesse funzionare allora vai sull'icona My Psion , clicca il 
     tasto destro e seleziona Istalla Nuovo Programma.
     Se non hai l'opzione Installa Nuovo Programma allora vai al nostro 
     sito o al sito <http://www.psion.com> e scarica il file 
     Setup.exe. Installalo e prova di nuovo ad installare Solitaire 
     Deluxe.
   - Da una macchina EPOC  
     Clicca su file .sis per instalare il programma.Se non funzina 
     significa che non hai l'utility Add/Remove, in questo caso scarica 
     il file instexe.exe dal nostro sito o da quello della Psion 
     <http://www.psion.com> e copialo nella tua macchina. Poi prova 
     ancora. 
            
2. Ora premi Altro|Solitaire DX, per giocare.
            
3. Per disinstallare il programma vai al Pannello di Controllo e clicca 
   sull'icona Add/Remove icon, seleziona Solitaire DX e infine premi il 
   tasto Remove.
