2. Einführung
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Solitaire Deluxe ist das ultimative Solitaire Kartenspiel für EPOC. Es verwendet ein plug-in System, welches Ihnen "Plug and Play" spielen von Solitaire Spielen erlaubt. Wenn neue plub-ins verfügbar sind, können diese einfach installiert werden, Solitaire Deluxe findet diese plug-ins automatisch. 
Plug-ins sparen Platz und offerieren Ihnen eine einfache, einheitliche Oberfläche.

Das Beste an Solitaire Deluxe: es ist FREEWARE! Wenn Sie es mögen und eine Webseite haben, bitte fügen Sie doch einen Link auf Ihre Seite ein
<http://www.fatcatz.tm> sodass noch mehr Personen Solitaire Deluxe spielen können.

Weitere plug-ins können auf unserer Seite zum freien download gefunden werden.

3. AKTUALISIERUNG
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Wenn Sie von einer früheren Version aufdatieren, versichern Sie sich, dass das Verzeichnis System\Apps\SolDX mit allen Dateien gelöscht ist. Ebenso müssen alle plug-ins wieder installiert werden, nachdem die neue Version geladen wurde. Wenn Sie Ihre "Rekord"-Datei behalten wollen, kopieren Sie sie alle *.hst-Dateien in ein temporäres Verzeichnis.

Sie können jetzt die neue Version installlieren wie in Abschnitt 4 erklärt wird. Nach der Installation kopieren Sie *.hst-Dateien zurück in das neu erstellte Verzeichnis C:\System\Apps\SolitaireDX. Falls Sie Solitaire Delluxe auf D:\ installiert haben, müssen  Sie dieses Verzeichnis auf C:\ erstellen und die *.hst-Dateien in dieses Verzeichnis kopieren.

4. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. Es gibt 2 Arten, Solitaire Deluxe zu installieren, je nachdem, wohin Sie die .sis-Datei kopiert haben und was für ein Setup Sie haben:
   
   - Auf einem PC mit PsiWin
     Doppelklicken Sie im Windows Explorer die .sis-Datei. Dadurch wird
     Solitaire Deluxe automatisch auf Ihre Maschine kopiert. Wenn das nicht
     richtig funktioniert, klicken Sie auf die Psion Arbeitsplatz-Ikone und
     wählen Sie die "Neues Programm installieren"-Option. Wenn Sie diese
     Option nicht haben, laden Sie von der Psion-Seite <http://www.psion.com>
     die Datei setup.exe herunter, installieren sie und versuchen es
     nocheinmal.

   - Auf einer EPOC32 Maschine
     Klicken Sie auf die .sis-Datei, um das programm zu installieren. Wenn
     das nicht funktioniert, fehlt Ihnen das Hinzufügen/Entfernen-
     Hilfsprogramm. In diesem Fall laden Sie instexe.exe von unserer Seite
     und von Psion's Seite <http://www.psion.com> herunter, kopieren es auf
     Ihre Maschine und versuchen es nocheinmal.

2. Drücken Sie jetzt Extras|Solitaire DX, um zu spielen.

4. Um es zu deinstallieren, gehen Sie in die Systemsteuerung, klicken auf die Hinzufügen/Entfernen-Ikone, wählen sie Solitaire DX und drücken den Entfernen-Knopf
