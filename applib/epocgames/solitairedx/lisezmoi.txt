2. INTRODUCTION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Solitaire Deluxe est le jeu ultime de solitaire pour EPOC, il utilise un système de plug-in qui vous permet d'installer des jeux de solitaire 'Plug and Play'. Dès que de nouveaux plug-in's sont disponibles, vous n'avez qu'à les installer et Solitaire Deluxe les détecte automatiquement.

Les plug-in's économisent de l'espace et vous offrent une interface commune simple.

Mais le plus beau est que Solitaire Deluxe est FREEWARE! Si vous l'appréciez et avez un site web, ajoutez un lien vers notre site <http://www.fatcatz.tm> pour que d'autres puissent l'apprécier aussi.

D'autres plug-in's peuvent être téléchargés gratuitement depuis notre site.


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
3. MISE A JOUR
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Si vous mettez à jour depuis une version précédente, assurez-vous d'effacer le dossier System\Apps\SolDX avec tous les fichiers s'y trouvant. Si vous voulez garder vos meilleurs temps, copiez tous les fichiers *.hst dans un dossier temporaire. Vous devrez aussi ré-installer les plug-in's une fois la nouvelle version installée.
Vous pouvez maintenant installer la dernière version de Solitaire Deluxe en suivant le Chapitre 4. Une fois l'installation terminée, n'oubliez pas de re-déplacer vos fichiers *.hst vers le nouveau dossier \System\Apps\SolitaireDX.


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
4. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. Il existe deux moyens d'installer Solitaire Deluxe.

   - Depuis un PC avec PsiWin
     Double-cliquez sur le fichier .sis file pour démarrer l'installation
     automatique. Si çà ne fonctionne pas bien, faites un clic droit sur l'icône
     Mon Psion et cliquez sur l'option Installer Nouveau Programme.
     Si vous ne disposez pas de cette option, téléchargez le fichier
     setup.exe depuis notre site ou celui de Psion <http://www.psion.com>,
     installez-le et ré-essayez.

   - Sur une machine EPOC32
     Cliquez sur le fichier .sis pour l'installer. Si çà ne donne rien, c'est que
     vous n'avez pas l'icône Ajout./Suppr dans le Panneau de Configuration.
     Dans ce cas, téléchargez-le depuis notre site ou celui de Psion
     <http://www.psion.com>, copiez-le sur votre machine et recommencez.

2. Cliquez maintenant sur l'icône Solitaire DX de la barre Extras pour jouer.

3. Pour désinstaller le programme, allez dans le Panneau de Configuration,
   cliquez sur l'icône Ajout./Suppr., choisissez Solitaire DX et cliquez sur le
   bouton Supprimer.
