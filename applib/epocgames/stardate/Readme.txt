============
INSTALLATION
============

Turn on your Series 5, press the System icon (bottom left of the screen),
press the Menu key, under 'Tools' select 'Preferences', make sure that there is
a tick next to 'show system folder' and click on 'OK'.

Go into either C:\System\Apps\ or D:\System\Apps\

From the menu, under 'File' select 'Make new folder' name it 'Stardate'.

Copy all the files except README.TXT into this directory.

Pressing the 'Extras' button (bottom right of screen) will now reveal
this programs icon, select it to begin.

If Stardate does not run, try renaming its folder to a different name,
wait a few seconds and then rename it back to the correct name.

If you have difficulty with installation, re-read and follow carefully
the above instructions, you have probably put the files in the wrong place,
or named the folder incorectly.

If upgrading from Version 2.0, you need only copy Stardate.app and Stardate.aif into your stardate folder, overwriting the existing files, otherwise delete your previous version and then follow the installation instructions above.

===============
TROUBLESHOOTING
===============

If you have a problem, check that your batteries are not low, and that there is
plenty of memory available to the program. Sometimes the Series 5 fails to play
sounds when batteries are becoming low, but are not quite low enough for the
Series 5 to report them as low. If in doubt, change the batteries.

Check that you have followed the installation instructions correctly.
