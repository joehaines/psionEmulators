Installation
	Unzip the archive (if you haven't already done so), and
	extract the SIS file
.
	Transfer the file to you Psion, and install it like any other
	SIS package (double-tap).  Alternatively, you may install
	it using PsiWin 2.x.

-=- -=- -=- -=- -=- -=- -=- -=- -=- -=- -=- -=- -=- -=- -=- -=- -=-
Use
	This program is really damn simple.  Enter in the number of 
dice you wish to roll (up to 20), and the target difficulty.  Hit the roll
button to (you guessed it) roll the dice.
	You may also specify either six-sided (d6), ten-sided (d10) dice or
twenty-sided (d20) dice, and whether or not botches are to be taken into
consideration.  For those who don't know, botches are basically 'negative'
successes.  In other words, for every 1 rolled, you lose a success.
