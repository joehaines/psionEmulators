Target v3.0 for the Psion Series 5
==================================
Written by Steven Prudames
==========================

Installation instructions
-------------------------
The program will run off either the C: or D: drives with no problems! I hope ;-)

To install, either copy the "Target.sis" file to your Psion and double click it or if you have PsiWin 2.1 or above, just double-click on the "Target.sis" file in windows to launch EPOC Install on the PC itself and to complete the installation of Target.

No special OPX's are needed to run Target and it should also work on the EPOC Emulator (release 3 and 5)

Once installed you should get an icon on the extra's bar called Target, run it and have fun.
Full instructions for the game can be found in the help file.
