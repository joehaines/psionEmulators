Installation

	Install the went.sis file by double clicking it in windows,
	or transferring it to your psion and double-tapping it
	there.

	If this does not work, you will need to install add/remove
	program support, which may be downloaded from
	http://www.psion.com/

Quick start
	If you already know how to play Go, Went will be fairly
intuitive (I hope).  Simply touch the pen to the board (after
starting a new game) to make a move.  To undo a move, hit
Ctrl-Z, or the second toolbar button.  Everything is more or
less automatic.

	If you do not know how to play Go, go through the quick
"How to Play Go" lessons in the help file.  I do not claim to
be an expert, or even a good teacher, so I have also included
a bunch of websites in the help file.  Look at them.  Learn.

Keys
	Ctrl-A	:	opens the About dialog box
	Ctrl-C	:	Counts the stones on the board
	Ctrl-D	:	toggles Direct-input mode
	Ctrl-E	:	Exit
	Ctrl-G	:	Goto turn #
	Ctrl-L	:	Load SGF file (note that it leaves you on the last turn once loaded)	
	Ctrl-N	:	New game
	Ctrl-O	:	Open Went file
	Ctrl-S	:	Save Went file
	Menu	:	Opens the menu (surprise)
	?	:	help!!

	Ctrl-R, Enter		: forward one move
	Ctrl-Z,	Backspace	: back one move
