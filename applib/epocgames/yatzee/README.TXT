The UID for this program is 1000048F

Released as FreeWare in September '97

To install Yatzee:

1) Make sure the \System folder is shown on your Series 5 system screen.
   If it's not, enable it in the 'Preferences' dialog.
2) Go into \System\Apps and make a new folder called "Yatzee"
3) Using PsiWin, copy across all the files from this distribution into
   the new \System\Apps\Yatzee folder.
4) That's it! There will be a new icon on your Extras bar.

What is Yatzee:
----------------
Yatzee is playing poker with dice (sort of).
You have to fill up 13 categories, 6 in the left column and 7 in the
right. The game ends when all the categories have been filled.

Scoring in the left column:
If you want to score the 'Five's', only the five's in the hand will count.
So, three five's will give 15 points in the 'Five's' category.
63 points or more in the left column gives you a bonus of 35 points.

Scoring in the right column:
----------------------------
Three of a kind   : Scores points in hand if you have three dice of the
                    same kind.
                    e.g. 5-5-5-4-2 scores 21 points.
Four of a kind    : Scores points in hand if you have four dice of the
                    same kind.
                    e.g. 6-6-6-6-3 scores 27 points.
Small straight    : Scores a fixed 25 points if you have 4 dice on a row.
                    e.g. 1-2-3-4-6.
Large straight    : Scores 30 points if you have 5 dice on a row.
                    e.g. 2-3-4-5-6.
Full house        : Scores a fixed 25 points if you have 3 of a kind AND
                    2 of a kind.
                    e.g. 3-3-3-5-5
Yatzee           :  Scores a fixed 50 points if you have 5 of a kind.
                    e.g. 4-4-4-4-4
                    This is the only category to which you can score
                    more than once.
Chance            : Any combination is valid. Scores points in hand.


Playing:
--------

After rolling the dices, mark the dices you want to keep with the keys 1-5.
or touch the screen with a pen. Then roll again the unmarked dice with the
SPACE key. There is a maximum of three rolls.
Then you have to assign the score to a category. Use the Arrow Keys to do
the allocating.
You can score to an invalid category it will enter 0 points, e.g. allocate
to the 'Five's' category, without having any five's or to the 'Yatzee'
without having a Yatzee.

Toolbar:
--------

1. Button) 	Restarts Yatzee
2. Button)	Opens option screen - turns sound on/off or resets High Score
3. Button) 	Calls up High Score Table
4. Button) 	Quits Yatzee



Hotkey(s)
---------	Ctrl+E - Quits game
