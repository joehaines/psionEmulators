Installation Instructions

1. Unpack the Zip file to your PC or your Psion.

2. On the PC:
   Double click on the file Zheroes.sis. This will start the PC
   automatic installation of Zherÿes.

   On the Psion:
   Double tap on the file Zheroes.sis. This will start the Psion
   automatic installation of Zherÿes.

Zherÿes will now be accessible to you from the Extras icon.
