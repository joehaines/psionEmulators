Installation instructions

1. Unpack the .zip file to your PC or your machine.

2. On the PC:
    Double click on the file Doodler.sis.  This will start the 
    EPOC Install installation of Doodler.

3. On the machine:
    Double tap on the file Doodler.sis This will start the EPOC
    installation of Doodler.

4. Doodler will now be accessible to you from the Extras bar. 

Note:

5.  Doodler requires the shared file Neuon.opx,  which is 
    automatically installed as part of Doodler.sis.

6.  After installation, to maintain the system's control of versions
    and use of shared files, do not move, delete or rename the file 
    C:\System\Install\Doodler.sis
