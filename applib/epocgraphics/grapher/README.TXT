GRAPHER for the PSION 5 (version 1.36)
======================================
======================================
Welcome to Grapher, the Psion 5 function graphing application.
A full manual is available from inside the application, so this
file only gives installation instructions and other miscellaneous
items.  There is a separate tutorial zip file for new users
available from my homepage.


INSTALLATION
============
- Connect up the Psion, and turn on the link.
- Create a new folder called \System\Apps\Grapher
  on the disc you want.
- Copy the files
  icons.mbm
  grapher.hlp
  grapher.app
  grapher.aif
    to the folder \System\Apps\Grapher\ which you just
    created.
- Turn off the link and disconnect the Psion.
- The Grapher icon should appear in the Extras bar with
  the icon of a graph.

You can get the full manual by choosing Help from the Tools menu
inside Grapher, or press Shift+Ctrl+H.
