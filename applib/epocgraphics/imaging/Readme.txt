Thank you for trying Imaging, an image viewer for Symbian OS v5 machines. Imaging allows you to view EPOC Picture Files (MBM), EPOC Sketch files, ROM Picture files, Application Information Files (AIF) and JPEG files. Imaging can also modify and manage Multi-Bitmap files (MBM) by adding and removing images. Slideshow of a folder is supported as well as automatic scrolling and running as a video.

Imaging can run on the following machines:
	Psion Series 5mx
	Psion Series 5mx Pro
	Psion Series 7
	Psion NetBook
	Psion Revo
	Ericsson MC218 Communicator
	Diamond Mako
	Other ER5 machines...
Do not install on the following machines:
	Psion Series 5
	Geofox One
	Oregon Osaris
	Other EPOC versions less than ER5...
	WINS Emulator (a version for WINS is available seperately)

Although Imaging will run on a Psion Revo and Diamond Mako, the dialogs and other user interface elements have not been designed with this smaller screen in mind.  If you can help, please e-mail me describing which user interface elements need updating.

Please appreciate that Imaging is a memory intensive application. You will need 400 to 600 kB just to load Imaging and additional memory available for the open image and temporary files. A minimum of 3 MB system memory is suggested to install and run for normal use without running into memory restrictions.
