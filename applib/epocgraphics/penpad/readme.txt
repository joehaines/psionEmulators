Installing penpad v3.0

1: Copy Penpad.opx into either c:\system\opx\ or d:\system\opx\.
	If the Directory does not exist then it must be created.

2: Copy All other files into either C:\system\apps\Penpad\ or D:\system\apps\Penpad\

NOTE: If you are installing over an old version of PenPad you MUST manually delete the PenPad directory prior to installation.

Mail any problems to penpad@salted.net

Thanks, and please register.


Mat Ripley


In case you have problems here are the file locations en toto:

C:\system\apps\penpad\PenPad.app
C:\system\apps\penpad\PenPad.aif
C:\system\apps\penpad\PenPad.hlp
C:\system\apps\penpad\tool
C:\system\apps\penpad\base.bit
C:\system\opx\penpad.opx


NOTE: In all of the above C:\ can be replaced with D:\
