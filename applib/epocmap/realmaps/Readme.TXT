EPOC Machines : RealMaps.SIS
WINS Emulator : RealMapsW.SIS

*** NB: If you have a modified version of WorldCities.S5 in an existing installation, you must make a backup before upgrading (RealMaps now creates a basic WorldCities.S5 database using information from the EPOC Time application so that it is localised for the machine where possible) ***

Double click on the SIS file to install; any existing MapList will be retained. If you wish to install any additional languages, please copy the appropriate RM-RSC.* file across to your Psion's \System\Apps\RealMaps folder.

Additional help files for some languages and other utilities and information are available from the author's web site at :- http://www.realmaps.co.uk

If you are using an unregistered version of RealMaps you can delete IconLayout and OverlayIcons.MBM to save space but you will need to reinstate them (or reinstall RealMaps) if you decide to register.
