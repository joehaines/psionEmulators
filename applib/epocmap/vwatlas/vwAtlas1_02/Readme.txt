What is vwATLAS?
----------------
vwATLAS is a little atlas in your pocket.
It handles maps (different scales), locations from a database (countries, cities, ...) and tracks (from waypoints and GPS).

Who needs vwATLAS?
------------------
Everyone who is (as I am) visual oriented and wants to see locations on a map. 

Installation
------------
Run vwATLAS.SIS. These folders will be created:
\System\Apps\vwATLAS: all program files and language specific help files.
\Documents\vwATLAS\DATA: example databases with cities (WORLD.dat, D.dat, USA.dat).
\Documents\vwATLAS\MAPS: example maps (WORLD.mbm, ...).
\Documents\vwATLAS\TRACKS: example tracks (ROUNDTRIP.trk).

Updating
--------
Please note, that all files in the installation package will overwrite files with the same name in the the same folder. This is especially important for ALL files in "Documents/vwATLAS". If you want to save your files with your data, always rename them or copy them to a different location before installation!
See Version History below for "What`s New".

Online Help
-----------
Standard installation of the online helpfile (vwATLAS.hlp) is the englisch version. If you want to use another helpfile, delete the current file "vwATLAS.hlp" (or better rename to "vwATLAS_E.hlp) and rename the desired language file back to "vwATLAS.hlp"!
The following files with these languages are currently available:
vwATLAS.hlp (English)
vwATLAS_D.hlp (German, NOT AVAILABLE YET!)

How to start
------------
The best way to learn the program, is to use it!
Navigate with the cursor, Zoom in and out and search (Find) for any locations!
Use the online help file!
