Installation Instructions

1. Unzip the 5Time zip file.

2. Either:

i. Copy all the .sis file to your Epoc machine and double it to install the
necessary application files to your computer.

OR

ii. Connect your Epoc machine to a PC or Mac. Double click the .sis file to 
automatically install all the necessary application files.


3. 5Time will now be available for use.

Please note that 5Time will create a number of application files the first
time it is run. This takes a few moments. Please allow enough time for these
files to be created.
