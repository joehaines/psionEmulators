Welcome to Dialler:

Unzipping using PsiZip:
If you are unzipping Dialler on your Psion, using PsiZip, go into PsiZip and open the Dialler.zip archive. Once all files are displayed, highlight them in the usual way and choose "Extract File". Leave the top line of the extract file dialog blank, choose which drive you want Dialler to go onto then make sure the "Restore Folder" option is checked. (i.e There is a tick in the box), now just press enter. PsiZip will now unzip Dialler placing all files where they should go.  However if you are unzipping to the "D"drive you must now move the file "SysRam1.opx" which is now in the folder \SYSTEM\OPX\ to the internal drive. 
 The Word file for Dialler will go into the top level system screen folder. Please read this file carefully!
Unzipping on a PC:
To unzip Dialler on a PC just unzip the whole file into a folder of your choice. Make sure when unzipping you set the unzipper to "Discard Directory" information Otherwise it will create sub-directories of the folder you are unzipping into.
Once unzipped create a new folder on your Psion called "\SYSTEM\APPS\DIALLER" on any drive and copy all of the files execept the "Dialler_Inst" file and the "SysRAM1.opx" file  into it. Now move the file Dialler_Inst to a more commonly used folder. This file is the Instruction/Word file and you may need to access it more often so it helps to have it to hand. Finally create a new folder on the internal drive called "\SYSTEM\OPX" and put the file "sysRAM1.opx" into it. This file is imperative it is a Psion bugfix header file.

That's it!
