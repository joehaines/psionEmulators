It allows you to 'attach' pain text files and load/edit/save them in it's built in text editor.The first version of the Psion EPOC shell uses special bytes at the start of files to identify their type, the icon to use for them, and how to open them. Since text files do not have this special infomation in their headers, the EPOC shell gives them an icon with a "?" in a document and refuses to upen them.  DSTEDIT Files do not contain text files, nor does DSTEDIT import/export them like word. DSTEDIT files contain links to other text files. These text files are known as attached files. The EPOC shell shows  DSTEDIT with an icon which is supposed to represent a group of text files tied together with string.When you open a DSTEDIT file you are in effect opening a group of attached files.  You can switch between these attached files, edit and save them. DSTEDIT files can be used to manage groups of C++ files, HTML files etc. Alternativly just one file can be attached, in which case DSTEDIT acts like a alias or shortcut to that file. This is usefull when using DSTEDIT as a reader for text files that would otherwise need to be loaded into the Word app.Registering sharware--------------------DSTEdit is shareware it is NOT free.
