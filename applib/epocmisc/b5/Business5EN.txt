Installing QuickP :
--------------------
1. Install AGENDA2.OPX, launch PsiWin Installer and select AGENDA2.SIS
2. Install APPINFO.OPX, launch PsiWin Installer and select APPINFO.SIS
3. Install PSCAPE.OPO,  launch PsiWin Installer and select PSCAPE.SIS
4. Make sure you have access to the system directory.
   You can enable this in the system preferences using
   CTRL+K. Tick 'Show "System" directory'
5. Create a new directory: \system\apps\Business5 on
   drive C: or D:
6. Copy all the files to this new directory.
7. The program should now be visible in the extras bar.
8. Start the program
9. Read the help file.
