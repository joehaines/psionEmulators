Einleitung:
========
- Dieser Text ist im einfachen MS-DOS Textformat erstellt. 
Dabei der Erstellung nur ca.60 Zeichen je Zeile benutzt wurden 
läßt sich dieser Text auch auf dem Psion recht komfortabel lesen, 
ohne ständig scrollen zu müssen.
- Installieren Sie am besten den Symbian Texteditor (im BIKLOG 
Programmset enthalten) um diese Datei auf dem Psion zu lesen.

BIKLOG5 ist für Fahrradfahrer entwickelt worden, um diesen
zu ermöglichen über einen langen Zeitraum ihre zurückgelegten 
Fahrradstrecken zu überwachen. Gerade für Tranings- und 
Statistikzwecke eine sehr hilfreiche Software. Es ist hierzu 
*nicht notwendig* den Handheldcomputer während der Fahrt auf dem 
Fahrrad mitzuführen. Bei der entwickelten Software handelt sich 
sich vielmehr um ein Statistik und Analyseprogramm. Geben Sie 
einfach am Ende eines Fahrradtages ihre Kilometer ein und Sie 
können, bei akurater Datenerfassung einen optimalen Überblick 
über die von Ihnen zurückgelegten Strecken gewinnen. Durch die hier 
vorliegende Version 3.0 des BIKLOG5-Programms sind die Diagnose
und Statistikfunktionen nochmals erheblich erweitert worden.
Besonders für Betrachtungen die sich über einen längeren Zeitraum 
erstrecken ist dem Programmierer von BIKLOG5 ein großer Wurf
gelungen.
Version 3.2 ist ein kleiner Upgrade um auch den Benutzern von 
Serie7 / netBook die vollen grafischen Möglichkeiten von BIKLOG5 
zugänglich zu machen. Zusätzlich ist das Programmsymbol auf dem 
Systemdesktop bzw. der Extraleiste in dieser Version farbig, 
wenn das Display eine farbige Darstellung erlaubt.

Sie können diese Software durch die Umbenennung einiger Begriffe
in ihrer Oberfläche auch für andere Hobbyanwendungen benutzen, die
nicht viel mit dem Fahrrad gemeinsam haben. So könnten z.B. 
Triathleten ihren "Fahrrädern" die Namen "Schwimmen", "Laufen" und
"Fahrrad" geben und die BIKLOG5 Software dann auch gut für ihre
Sportart einsetzen.

Die Version 3 ist ein grundlegender Update des Programms. Ab jetzt
stehen dem Benutzer in der Datenbank 7 zusätzliche Felder zur 
Verfügung, die er nach eingenem Wunsch konfigurieren kann. Der 
Daten IMPORT/EXPORT von Datenbanken im Textformat ist jetzt 
ebenfalls möglich. Ein Wunsch den viele Anwender an den Entwickler
herangetragen haben. Um die Übernahme von alten Datenbankdateien
möglichst einfach zu gestalten hat Jaap Lameries auch daran gedacht
ein entsprechendes Upgrade-Programm in die Version 3.0 zu
integrieren. Wenn Sie alte Datenbanken übernehmen wollen, so ist es
zwingend notwendig diese umzuwandeln. Die entsprechende
Upgradefunktion finden die in der Menuleiste von BIKLOG5 Version 3 ! 

Diese überarbeitete Version von BIKLOG5 basiert ursprünglich auf 
einem Psion Serie 3. Die entwickelte Software, die damals BIKLOG3
getauft wurde dann für die Psion5 und Revo angepasst. Mit Version
3.0 ist das Produkt auch auf der Serie7 und dem Netbook 
funktionsfähig. Es war das erste umfangreichere Programm welches 
Jaap Lameris unter OPL entwickelt hat.

Programm so verändert, das es auch auf diesem Produkt der Firma 
Psion eingesetzt werden konnte. Besonders das nochmals verbesserte
Handeling des Bedienstift und die deutlich verbesserte Datenbank
ist für den Benutzer eine große Erleichterung.
In Version 2.1 wurden dann erstmals Statistikfunktion im Ausgabe
und Anzeigebereich des Programms angeboten. Damit für den Benutzer
auch ein Ziel vorhanden ist besteht seit dieser Version auch die
Möglichkeit entsprechende Werte bei der Neuparametrierung des
Programms vorzugeben.
Mit Version 2.4 wurde BIKLOG dann auch für den Revo (+) verfügbar,
da diese Variante die beschränkteren Grafikeigenschaften (kleiner

INSTALLATION :
==============
Nachfolgend ist eine Dateiliste abgedruckt, die alle Dateien
angibt, die sich in der aktuellen Version von BIKLOG5 befinden
sollten. In dem rausgegeben ZIP-file (name:biklg532.ZIP) sind
folgende Dateien zusammengefasst:

biklog5.sis                         SIS installation file
editor.zip                          Zipped SIS installation file 
                                    for Symbian editor
biklog5_readme.txt                  this file
biklog5_leesmij.txt                 this file in Dutch
biklog5_liesmich.txt                this file in German
biklog5_lisezmoi.txt                this file in French

Auch sind die Pfade für eine korrekte Installation voreingestellt.
Wenn Sie PsiWin 2.x unter Windows benutzen dann brauchen Sie nur
einen Click auf die Datei biklog5.sis zu machen und ihr System 
(einwandfreie Installation vorausgesetzt) führt die notwenigen
Datenübertragungen selbsttätig aus. 
Nach kompletter Installation erscheint das Programm im "normalen"
Extra-Bar des Psion.
Alternativ zu dieser Installation können Sie auch die BIKLOG5.SIS 
Datei zunächst auf ihren Psion kopieren und dann erst dort per 
Doppelclick starten. Dieses Vorgehen ist z.B. für User 
empfehlendswert die ihren Psion in Verbindung mit einem 
DOS-Betriebssystem :-) benutzen. In diesem Falle achten Sie dann
bitte darauf, das sich das Programm INS_TE.EXE bereits auf ihrem 
Psion installiert ist. Diese Software entschlüsselt den .SIS File
und macht die dort gespeicherten Daten für den Psion (oder eine 
andere EPOC32-Maschine) zugänglich.

Egal welche Installationweise Sie gewählt haben. Bei korrekter
Installation sollten Sie folgende Dateien auf ihrem EPOC32-PDA 
finden.

* = C or D Laufwerk
*:\system\apps\biklog5\biklog5.APP       Hauptprogrammteil
*:\system\apps\biklog5\biklog5.AIF	 Extra-Bar Verknüpfung
*:\system\apps\biklog5\biklog5.MBM       Grafikdatei
*:\system\apps\biklog5\biklog5.HLP       BIKLOG Hilfedatei
c:\system\apps\biklog5\biklog.ini        Voreinstellte 
					 Konfiguratungsdatei
c:\system\apps\biklog5\biklog5.ini       Ini-Datei mit den 
					 zuletzt benutzten Datei-
					 einstellungen.
c:\biklog\example                        Beispieldatenbank
c:\system\apps\biklog5\example.ini       Beispiel Konfigurations-
					 datei
c:\system\apps\biklog5\example_d.txt     Beispiel Tagebuchdatei

*:\system\opm\ini.opm                    ini.opm (support file)
*:\system\opm\iqgrid.opm                 iqgrid.opm (support file)
*:\system\apps\biklog5\efm.mbm           Grafikunterstützung
*:\system\opx\gprinter.opx               grafische Druckerunterstützung
                                         module
*:\system\opx\nmpd.rsc                   support RSC file for NMPD module
*:\system\opl\nmpd.oxh                   support OHX file for NMPD module
*:\system\opl\nmpdconstants.oxh          support OHX file for NMPD module
*:\system\opm\readwrite.opm              support OPM file for READWRITE 

Außer den *.ini Dateien, können alle anderen Dateien können
wahlweise entweder auch dem C: oder D: Laufwerk platziertent werden.
Die zu BIKLOG5 gehörigen Datenbanken können an jedem beliebigen
Platz (auch Pfad) auf ihrem PDA abgelegt werden (ab Version 2.2).
Ich empfehle die Ablage der Daten auf der CF-Disk, da Sie dann auch
bei Batterieausfall (Sicherungsbatterie) erhalten bleiben.



UPGRADE FROM OLDER VERSIONS
==============================

Ab Version 2.5 finden Sie in den Druckereinstellungen die Anzahl
der Nachkommastellen, die Sie in ihrem Ausdruck abbilden möchten. 
Diese Einstellung wird zusätzlich in der Datei "biklog5.ini" 
gesichert.
Um von Version 2.4 upzudaten schlage ich vor auch die biklog5.ini 
Datei unter Zuhilfenahme der Datei upgrad25.opo in der 
Verzeichniss c:\system\apps\bikelog5.ini zu übertragen.
Für ER5 Maschinen (5mx, REVO (+) and Netbook/S7) läuft dieser
Vorgang automatisch ab, sobald die eigentliche Installation 
durchgeführt wurde.
Für Maschinen des ER3 Typs muß der Vorgang manuell durch einen
doppelten Click auf die Datei upgrad25.opo ausgelöst werden.
Alternativ besteht für Sie ntürlich auch die Möglichkeit die
Voreinstellungen (Preferences) des Programmes durch den 
entsprechenden Menupunkt im BIKLOG5 Programm selbst einzustellen.

Ich empfehle Ihnen alle Datenbanken Ihrer Kontrolldateien die mit
Versionen V2.4 oder früher erstellt wurden durch die 
UPGRADE-Funktion des Biklog5 Programms umwandeln zu lassen. Ab
Version 2.3 ist der Datenfile ein offizelles BikLog5 Dokument. In 
Version 2.4 wurde dem Dokument eine offizelle Symbian UID-Nummer
zugeteilt, was das upgraden von alten Datenbanken notwendig machte.
Ab Version 2.5 wird das Druckausgabegerät und die Anzahl der 
Dezimalstellen in der Datei biklog5.ini eingestellt !


TASTERTURREFERENZ-LISTE :
==========================

Die meisten und wichtigsten Benutzerinformationen, die eine Arbeit
mit  dem BikLog5 Programm komfortabel machen sind in der 
Online-Hilfe des Programms enthalten.

Hier folgt eine kurze Zusammenfassung der Hotkey Funktionen 
(Tastensteuerung). Die Beschreibung ist alphabetisch nach den 
Tastenkombinationen geordnet, die gedrückt werden müßen um
eine der beschriebenen Funktionen zu erreichen.

	
Ctl-A    Hinzufügen eines Datensatzes
	- Hier geben Sie Datum, den Fahrradnamen, die Tourenart,
	die Tourenlänge und die Fahrzeit oder ihre
	Durchschnittsgeschwindigkeit ein sowie eine kurze
	Beschreibung (von maximal 40 Zeichen).
	Ab BIKLOG 3.0 können Sie in den Voreinstellungen wählen,
	welche Eingaben Sie in der aktiven Datenbank vornehmen
	möchten. 5 Einstellungen sind wählbar:
	(1) Eingeben der Startzeit
	(2) Der Inhalt von 4 zusätzlichen Datenfeldern (wenn in
	    den Voreinstellungen gewählt)
	(3) Der Inhalt eines logischen Datenfeldes (wenn in den
	    Voreinstellungen gewählt)
	(4) Eine von 6 voreingestellten Wahlmöglichkeiten im
	    Bedingungsfeld "Wetter" (wenn in den Voreinstellungen
	    gewählt)
	(5) Bis zu 255 Zeichen auf der Tagebuchseite des
	    Datensatzes (wenn in den Voreinstellungen gewählt) 
	Voreingestellt ist das aktuelle Datum des Eingabetages die
	übrigen Werte werden aus ihrer letzten Eingabe übernommen.
	Zwischen Fahrzeit und Durchnittsgeschwindigkeit kann
	gewählt werden. Eine der beiden Angaben ist ausreichend.

Shft-Ctl-A    Ändern oder Modifizieren eines Datensatzes
	- Hier bekommt der Programmbenutzer die Möglichkeit einen
	bereits eingegeben Datensatz nachträglich zu Verändern,
	wenn z.B. bei der Ersteingabe ein Fehler unterlaufen ist.

Ctl-B    Schaltet den Toolbar ein/aus
	Die Werkzeugleiste (Bildschirmbuttons am rechten Bildrand)
	werden je nach gerade sichtbarer Darstellung entweder
	Ein- oder Ausgeschaltet.

Ctl-C    Schliessen der aktiven Datenbank
	- Nur nötig wenn Sie auf eine andere biklog5-Datenbank
	umschalten möchten, oder eine aktuelle Datei gelöscht
	werden soll.

Ctrl-D	Editieren eines Tagebucheintrages
	- Erst ab Version höher 2.80 verfügbar. Die Funktion startet den
	den Texteditor der Firma Symbian um Änderungen in den Tagebuch
	einträgen zuzulassen. Beim Tagebuch handelt es sich um eine
	einfache Textdatei (so wie bei diesem Liesmich-File auch), die
	mit jedem Texteditor bearbeitet werden kann. Der Symbian Text-
	editor stellt bereits eine recht komfortable Textbearbeitung zur
	Verfügung.

Shft-Ctl-D    Löschen einer Datei
	- Löscht eine biklog5-Datenbank (Datei).

Ctl-E	 Exit (Programm beenden)
	-BIKLOG-Programm verlassen. Programm wird beendet. Alle
	Datenbanken geschlossen und die Steuerung an das Psion
	Betriebssystem zurückgegeben. Das Programm "merkt" sich
	die Einstellungen in der INI-Datei und öffnet bei einem
	erneuten Aufruf die BIKLOG-Datenbanken die beim Verlassen
	des Programms aktiv waren. 

Shft-Ctl-E    Löschen (Erase) eines Datensatzes
	- Löscht einen bereits existierenden Datensatz aus der
	Datenbank.

Ctl-F    Suchen (Find) eines Textes in den Datensätzen
	 -Benutzen Sie diese Funktion um einen beliebigen Text
	 in einem oder mehreren Datensätzen ihrer aktiven BIKLOG
	 Datenbank zu finden.

Shft-Ctrl-F Vorhersagen
	-Mal ganz ehrlich. Welchen Fahrradfahrer interessiert es nicht,
	wieviel er schon von seinen persönlichen Zielvorgaben erreicht
	hat und wieviel er wohl noch leisten kann. Diese Funktion
	berechnet eine Antwort auf diese Fragen auf Basis der vom 
	Benutzer angegebenen Zielwerte.

Ctl-G    Graphikausgabe der Datenbankinhalte
	- Gibt bis zu 10 verschiedene Plotdarstellungen je nach 
	Fahrrad oder Tourentyp spezifiziert aus.
	-Zunächst das Start und Enddatum des Betrachtungszeitraumes
	angeben. Die Zeitachse ist die X-Achse die in Tagen, Wochen
	oder Monaten dargestellt wird. Die Zeitachse darf die Länge
	von 400 Tagen nicht überschreiten. Voreingestellt wird der
	1.Januar des Eingabejahres. Das Enddatum ist das aktuelle
	Tagesdatum. Als Plotkriterium kann zwischen den Fahrradnamen
	oder dem Tourentyp ausgewählt werden.
	-Im Feld Plotfunktion bestimmen Sie welches Datenbankfeld
	ihrer aktiven Datenbank als Graphik ausgegeben werden soll.
	-Kumulativwerte werden aus allen Fahrrädern addiert, die in
	der Datenbank eine Fahrtstreckenerfassung (mit mehr als
	0 Km Länge) besitzen.
	- Hinweis: Bei der Ausgabe von kummulativen Werten ist eine
	Anzeige in Säulenform *nicht* möglich. Wenn der Benutzer bei
	kumulativen Werten die Säulenausgabe anwählt, so wird die 
	Darstellung automatisch auf Liniendarstellung umgeschaltet.
	- Mit den <Cursor> können Sie sich in den angezeigten
	Tabellen bewegen. <ESC> bringt das Menu zurück. Jede andere
 	Taste zeigt einen Informationsbildschirm mit den möglichen
	Tastenfunktionen.

Shft-Ctl-G  Druckt die grafische Ergebnissanzeige aus.
	- Dazu wird die interne Psion Druckroutine in Verbindung mit
	gprinter.opx verwendet. Fehlt Ihnen das entsprechende OPX-Modul
	sind Schwierigkeiten nicht zu vermeiden.
	Zudem ist es wichtig zu wissen, das der Grafikdruck nur dann
	arbeitet, wenn Sie die auszudruckende Grafik direkt vorher auf
	dem Bildschirm ihres Kleincomputers betrachtet haben. 
	-Grundsätzlich die der Grafikdruck als Linien- oder 
	Balkendiagramm darstellbar. Bei den kummulativen Datenwerten der
	Datenbank ist allerdings nur die Linienausgabe verfügbar. Wird
	bei Kummulativwerten die Balkenanzeige gewählt, so erscheint die
	Grafik trotzdem als Liniendarstellung auf dem Bildschirm und 
	ebenso auf dem Papier.
	- Ingesamt zeigen Ihnen 8 verschiedene Statistikdaten angezeigt
	(Anzahl der Fahrten, Kummulative und einzelne Fahrtstrecke sowie
	Fahrzeit für alle Fahrräder und alle Tourentypen.
	Zusätzlich erhalten Sie Informationen über die Gesamtfahrstrecke
	und Durchschnittsgeschwindigkeit per Fahrrad und Monat. Der 
	folgende Bildschirm ist ein Cross-Plot aus Gesamtstrecken als
	Funktion nach Fahrradtypen und Tourenart.
	- Ein neuer (ab V2.82) Statistikbildschirm zeigt jetzt auch die längste,
	Kürzesteste, schnellste und langsamste Strecke in der Datenbank für
	Jeden Fahrradtyp einzeln aufgeschlüsselt.
	- Zusätzlich wird noch ein Statistikbild geliefert welches die 
	Persönlichen Zielvorgaben auswertet und in Relation zu den bis jetzt
	erreichten Werten des Betrachtungsjahres stellt.
	- Als Filter werden folgende Variablen unterstützt: Zeitperiode, Fahr-
	Radtyp, Tourentyp, Zusatzwert und das logische Datenfeld der 
	Datenbank. Es ist dabei möglich alle Werte der Variablen zu 
	berücksichtigen (dazu einfach den Kasten "alle" markieren). Ebenso
	 ist es möglich bestimmte Variablen einzelnen anzugeben.
	Bei den beiden letzten Variablentypen (Zusatz und logisches Feld)
	kann unterschieden werden ob alle Zusätze und alle logischen Daten-
	zustände (yes + no) berücksichtigt werden sollen. Die letzten Optionen
	sind als aktiv voreingestellt.
		
Ctrl-H   Ändern der Defenitionen von Kopf und Fusszeile im Ausdruck
	Mit dieser Tastenkombination können Sie die Kopf und Fußzeile
	im Ausdruck der Tabellendaten ihrer Kilometerdatenbank nach
	eigenem Wunsch gestalten. Der Ausdruck von Statistik und
	Grafiktabellen erfolgt in Version 2.92 ohne Kopf- und Fuß-
	zeilen.

Shft-Ctrl-H    Hilfe (Online) aufrufen

Ctrl-H	Voreingestellte Kopf und Fußzeile ändern
	- Hier lassen sich die voreingestellten Kopf und Fußzeilen des
	BIKLOG 5 Programms verändern. Sie erscheinen beim Ausdruck
	ihrer Datenbank im Tabellenformat.
	- Hinweis: Diese Funktion ist nicht über die Menuleiste zugänglich.

Ctrl-I    Infobildschirm des Programms
	Die Tastenkombination zeigt einen kleinen Hilfsbildschirm 
	zum Programm an. Neben den Autorendaten erhält der Anwender
	auch eine Information auf welche Fahrdaten-Datenbank zurück-
	gegriffen wird. Wie die benutzte INI-Datei des Programmaufrufes
	heisst und welche Tagebuchdatei verwendet wird.

Shft-Ctl-I    Import einer Datenbank
	Beim Import von Daten kann sich der Benutzer entscheiden,
	ob er:
	(1) die empfangen Daten in eine neue BIKLOG-Datei schreiben
	möchte
	(2) die empfangen Daten an die aktive BIKLOG-Datenbank 
	anhängen möchte.
	Achten Sie bei dem Import von Daten auf eine korrekte
	Einstellung des Feldtrenners (Beschrieben bei der EXPORT
	Funktion). Ein Fehler bei der Angabe dieses Zeichens führt
	üblicherweise zu eingentümlichen Einleseergebnissen.
	- Beachten Sie das eine Datei in die Sie Daten importieren 
	möchten zum Zeitpunkt des Importes nicht geöffnet sein darf.
	Die Importroutine fragt nach nach dem Namen der Datenbank
	an die Sie die Importdaten anfügen möchten. Ein Import von
	Daten an die momentan im BIKLOG5 Programm geöffnete Datei
	ist aus programmtechnischen Gründen nicht möglich.
	-Hinweis: Wenn Sie eine bereits existierende Datei 
	schliessen und *ohne* das Programm zu beenden, einen
	Datenimport durchführen, so werden die Voreinstellungen der
	zuletzt geöffneten Datenbank übernommen. Verlassen Sie aber
	BIKLOG und Starten Sie das Programm vor dem Datenimport neu,
	dann werden die Grundeinstellungen bei den Voreinstellungen
	benutzt, die in BIKLOG als Konstanten vereinbart sind.

Ctl-N    Erstellen einer neuen Datei
	 - Nachdem Sie den Dateinamen und den Speicherort (Pfad)
	 der neuen Datei (sozusagen einer biklog5-Datenbank) müssen
	 Sie die Grundeinstellungen der Datenerfassung eingeben.
	 Gefragt wird nach dem Namen von bis zu 4 Fahrrädern in
	 ihrem Haushalt, der Art ihrer Fahrten (wie z.B. Allgemein,
	 Training, Rennen, Clubfahrten) wo Sie maximal 5 
	 Voreinstellungen defenieren können.
	 -Hinweis: Wenn Sie eine bereits existierende Datei 
	 schliessen und *ohne* das Programm zu beenden eine neue
	 Datenbank erstellen, so werden die Voreinstellungen von
	 der zuletzt geöffneten Datenbank übernommen. Verlassen
	 Sie BIKLOG und Starten Sie das Programm zum Anlegen der
	 neuen Datenbank, dann werden die Grundeinstellungen 
	 benutzt, die in BIKLOG als Konstanten vereinbart sind.

Ctl-O    Öffnen einer exestierenden Datei
	   - Immer notwendig, außer Sie erstellen eine neue Datei !
           Geben Sie den Dateinamen ein oder benutzen Sie <TAB> um 
	   durch exestierende Dateien zu blättern.

Ctl-S   Scannen der Datensätze
	- Es erscheint eine Liste alller Datensätze in der 
	benutzten Datenbank entsprechend der Filter die Sie bei der
	Anwahl des Scanmodes gewählt haben (Zeitraum oder Fahrrad-
	bzw. Tourentyp). Innerhalb der angezeigten Datensätze 
	können Sie sich mit dem <Cursor> und <PgUp> <PgDn> bewegen
	und so die  Sätze scrollen. <Home> bringt Sie zum ersten 
	Datensatz. <End> zum letzten. Mit <ESC> verlassen Sie den 
	Scanmodus des BikLog5 Programms. <s> zeigt ihnen einige 
	statistische Angaben über die aktuelle Datenbank. <n> zeigt
	den Fahrradtyp und die Bemerkungszeile des aktivierten 
	Datensatzes im Scan-Mode.

Shft-Ctl-S    Sortieren der aktiven Datenbank
	- Diese Funktion sortiert ihre Eingaben in der Datenbank 
	nach aufsteigendem Datum der Eingabe. Die Druckausgabe als
	Diagramm erwartet die Datenbank in dieser Art sortiert.
	Es ist denkbar, das Sie werden eigentümlich aussehende
	Diagramme auf dem Bildschirm sehen, wenn Sie eine 
	unsortierte Datenbank anzeigen lassen.
	- Hinweis: Sollte direkt nach dem Start des
	Sortiervorganges vom BIKLOG Programm eine Fehlermeldung in
	der Programmprozedur BIKLOG5/SORT vom Fehlertyp: "Feld
	nicht gefunden" gemeldet werden, so überprüfen Sie bitte
	ob Sie nicht versehentlich versuchen eine Datenbank mit der
	alten Datenbankstruktur (eher als Version 3.0) sortieren
	zu lassen. Bei diesen Datenbanken muss dieser Fehler
	zwingend auftreten, da erwartete Datenbankfelder nicht 
	vorhanden sind.   

Ctl-T    Filter auf Tabelle
	-Hier können Sie eine Tabelle Ihrer Datenbank erstellen
	lassen. Dabei besteht ab Version 3.0 des BIKLOG die 
	Möglichkeit die gesamte Tabelle erstellen zu lassen, oder
	einzelne Bereiche herauszufiltern. In BIKLOG5 V3.0 sind
	Filter auf:
	(1) Fahrradname
	(2) Tourentyp
	(3) Start- und Enddatum
	(4) Benutzerdefiniertes Logikfeld der Datenbank
	(5) Benutzerdefiniertes echtes Datenfeld der Datenbank
	möglich.
	In der dargestellten Tabelle werden dann alle zur Auswahl
	passenden Datensätze mit allen erfassten Werten
	aufgelistet.
	Alle Einträge werden Zeile für Zeile aufgelistet. Mit den
	Cursortasten können Sie sich durch die Tabelle rollen. Die
	<HOME> und <END> bringen Sie an den ersten oder letzten 
	Eintrag in der Tabelle.
	mit <ESC> beenden Sie die Tabellendarstellung und kehren
	zum BIKLOG Hauptbildschirm zurück.

Shft-Ctl-T  Drucken der Statistikseiten
	-Ausdruck der Daten erfolgt über die Psion-interne
	Druckfunktion mit Unterstützung von "gprinter.opx".
	- Diese Funktion ist nur verfügbar wenn Sie zuvor die Statisk
	auf dem Bildschirm angezeigt haben, da die interne Psion
	Druckfunktion ein entsprechendes Speichabbild ihres PDA zum
	Ausdruck der Daten heranzieht.

Ctl-U    UPGRADE von alten Versionen
	-Seit Version 2.3 ist biklog5 eine offizelle Symbian Datenbank mit 
	zugeordneter UID. Damit dieser Vorteil auch auf den vorher 
	Erstellten Datenbanken genutzt werden kann, müßen diese in das
	neue Datenformat konvertiert werden.
	-Das geschied ganz einfach dadurch, das Sie einen Doppelclick auf das
	ICON der alten Datei ausführen. UPGRADE wird die alte Datei dann
	konvertieren, die ist zu diesem Zeitpunkt mit einem Fragezeichen 
	im Systemnildschirm des Psion erschienen sind. Nach einen korrekten
	Konvertierung erhalten die Datenbänke auch bei der Darstellung auf 
	den Psion Systemseiten der biklog5 Logo und Sie so einfacher
	 in ihrer Bestimmung zu erkennen.
	- Ab Version 2.80 ist die Datenbank um 7 neue Datenfelder
	 erweitert die für jeden alten Datensatz hinzugefügt werden müssen.
	- Eine Bachupkopie des ursprünglichen Files wird unter der Endung
        	".bak" im Orginalverzeichniss erstellt.

Ctrl-V 	Voreinstellungen aufrufen
	- Mit dieser Funktion kommen Sie in den Voreinstellungsbreich von
	BIKLOG. Dort können Sie Fahrradnamen und Tourentypen sowie
	alle weiteren benutzerspezifischen Voreinstellungen durchgeführt 
	werden.
	-Dieser Menupunkt ist zu den bisherigen BIKLOG-Versionen in den
	Versionen ab 2.80 erheblich erweitert worden, da die neue Daten-
	bankstruktur erheblich mehr Dateneingaben zuläßt.
	-Benutzen Sie diese Funktion um die Fahrradnamen (Reiter: FAHRRAD)
	nach ihrem Belieben einzustellen.
	- Die möglichen Tourennamen stellen Sie ab jetzt unter dem
	Reiter: TOUR ein.
	- Für Eingabeeinheit und Papierformat beim Ausdruck sowie die
	Dezimalstellenvoreinstellung wird der Reiter: EINHEIT verwendet.
	An dieser Stelle entscheiden Sie auch über die Entfernungseinheit
	(Kilometer oder Milen).
	- Die Einstellung der Zielvorgaben finden Sie unter dem
	Reiter: Ziele.
	- Unter dem Reiter: VERSCHIEDENES geben Sie vor welche Datenfelder
	bei der datenerfassung ihrer Fahrdaten verwendet werden sollen. 
	Standartmäßig sind alle 3 Möglichkeiten Startzeit nutzen / 
	Nutzerdaten sichtbar / logisches Feld nutzen aktiv, was durch ein
	Häckchen im entsprechenden Kasten angedeutet wird. Ein Druck mit 
	dem Eingabestift auf das Kästchen schaltet die gewählte
	Voreinstellung um.
	- Die Voreinstellung der Nutzerfelder geschied unter den Reitern:
	NUTZER-1 bis Nutzer-3. Dort wird sowohl der Name des Datenfeldes als
	auch die zugehörige Maßeinheit abgefragt. Unter dem Reiter NUTZER-3
	tragen Sie bitte die Zustände ein, die in ihrem logischen Datenfeld
	Verwendung finden sollen. Ich benutze dieses Datenfeld zur Erfassung
	der Witterungsverhältnisse, was die gewählten Begriffe in der 
	deutschen BIKLOG Version erklärt. Bitte achten Sie bei den Eingaben
	unter dem Reiter: NUTZER-3 auf identische Namenslängen. Nur dann
	bekommen Sie im Ausdruck auch eine gut lesbare Tabelle geliefert.     

SHFT-CTRL-V    Druckvorschau "Tabellenausdruck"
	Durch diese Tastenkombination kommen Sie an die Seitenansicht des
	Tabellenausdrucks. Hier kann der Drucker eingerichtet und der 
	Ausdruck gestartet werden. Funktion auch übe die Menuleiste:
	Ansicht - Druck Tabelle - Druckvorschau erreichbar.

Shft-Ctl-Y	Export der aktiven Datenbank
	Diese Funktion ist erst ab BIKLOG Version 3.0 verfügbar.
	Beim Datenexport können Sie zwischen 2 unterschiedlichen
	Exportformaten wählen:
	(1) Benutzung des EPOC Formates (EPOC Datumszahl und 
	Integerwerte für die Feldinhalte)
	(2) Benutzung des TEXT Formates (alle Datenbankfeldinhalte
	als Strings in der entstehenden Textdatei)
	Die 2 Exportart ist besonders zu empfehlen, wenn die
	exportierten Daten in eine Teballenkalkulation eines
	fremden Softwareproduzenten übermittelt werden sollen oder
	für eine Datenanalyse in Fremdprogrammen benuztzt werden
	sollen.
	Die erste Exportmöglichkeit bietet sich an wenn Daten aus
	der aktiven Datenbank z.B. in eine neu erstellte BIKLOG
	Datenbank übernommen werden sollen.
	Das EPOC Datumszahlenformat ist die Anzahl der vergangen
	Tage seit dem 1. Januar 1900, während das EPOC Zeitformat
	die vergangen Sekunden seit Mitternacht als Zahlenwert
	anzeigt.
	Die Trennung der Datenfelder in einem Datensatz kann durch
	verschiedene Feldtrenner erfolgen. Der Benutzer kann per
	Auswahl zwischen "," , ";" , ":" , "tab" auswählen.



Allgemeiner Hinweis zu allen Druckfunktionen:
Die Druckfunktion von BIKLOG5 greift jetzt auf die systeminternen
Druckfunktionen des Psion5 zurück um so den Ausdruck zu optimieren.
Bitte beachten Sie, das Sie zunächst in den Grafik, Scan oder Statistikmode
des BIKLOG5 Programms gewechselt haben müssen, bevor Sie die Grafik oder 
Tabellendaten ausdrucken können.

Ich möchte noch mal besonders darauf hinweisen, das Ihnen die Onlinehilfe
des biklog5 Programms bei vielen Problemen hilfreich zur Seite stehen wird,
solange Sie mit der Benutzung des Programms noch nicht vollständig vertraut
Sind. Ansonsten gilt bei dieser Software, was auch für viele andere Produkte
gilt: "Probieren geht über Studieren". Sollten Sie bei Ihrem Studium auf sinn-
volle Erweiterungsideen stoßen, so haben Sie keine Scheu dem
Programmauthor ihre Ideen mitzuteilen. Vielleicht sind Sie schon in der 
nächsten Programmversion von BIKLOG5 integriert und so profitieren
alle Nutzer von ihrer Idee.

Warum registieren?

Auch wenn BIKLOG5 FREEware ist, bin ich sehr glücklich, wenn Sie sich 
registieren lassen. So bekommt der Programmautor einen besseren Überlick
darüber wie sich seine Programme verbreiten und wie intensiv Sie benutzt
werden.
Als erstes ist es für mich eine Befriedigung zu sehen, das ich nach all
den Stunden der Programmierarbeit auch anderen Personen mit dieser Arbeit
einen Gefallen getan habe.
Zweitens beflügelt mich diese Bestätigung an der Entwickelung von Bikelog5
weiterzuarbeiten, weil ich so erfahre, das auch andere Psion-Benutzer
Interesse an solcher Software besitzen.
Drittens ist es ein Vorteil für den Benutzer. Wer registiert ist, der erhält
automatisch Informationen (per Email) darüber, wenn eine neue Version dieser
Software heausgekommen ist und kann so schnell besonders schnell von den
Veränderungen profitieren.
