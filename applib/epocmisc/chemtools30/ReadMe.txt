ChemTools 3.0 by Guillaume Sabouraud

ChemTools is a program dedicated to chemists/biochemists and any other scientists who have to do with the materials in in a molecular point of view.

*** How to install ***
This software is distributed in a SIS package. To install it, you must have the EPOC installer on you system (your desktop computer or your EPOC32 machine) ; the EPOC installer is integrated to PsiWin 2.1 and further versions.
The easiest way to proceed is to copy the ChemTools.sis package to your machine and to run it. For this, you must have the Add/Remove control panel distributed by Psion. A copy can be found on my homepage.

*** Warning ***
ChemTools will automatically bring the help file to the foreground the first time you run it. Be sure to read it carefully and to set the preferences correctly before using the program.
