CixEd OPL Source files

You have just installed CixEd source files

The two files have been installed to the Documents folder
and can be moved to any folder you wish. Note that to translate
the program you will also require two header files to be
installed in your System/Opl folder. These are the header files
for the opx's used for spell checking and system indormation
and can be obtained from the RMR Software site at www.rmrsoft.com

If you feel you have any contributions you wish to may to the
program, then by all means feel free. Please use the
CixEd/development conference to advise and chat with other
developers.

At the moment, I am providing an "anchor" for the development 
work, and will continue to distribute final versions from both
the files list on Cix and through my web site at www.psicix.com.

Please report all bugs to the Cixed/development conf.
