A conversion utility for the Psion Series 5

INSTALLATION:

1. Create a new folder on the Psion "C:\System\Apps\S5Convert\"
(You can do this from the PC or Mac in PsiWin, or on the Psion - Go to Menu\Preferences and ensure "Show System Folder" is checked. Then navigate to System\Apps and create the folder "S5Convert"

2. Copy (do not convert) all the files to this folder.

3. Tap the new "Convert" icon on the Extras bar.

Anything else you need to know can be found  by pressing Help from the menu bar.
