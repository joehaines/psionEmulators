Programm-Beschreibung
---------------------
DiabetesManager ist ein Diabetesmanagement-Programm
für den Psion Serie 5/mx und den Psion Revo/Plus.


Dateien
-------
Die entpackte Datei "DiabetesManager.zip" enthält die
folgenden Dateien:

DiabetesManager.sis            Installationsdatei

Liesmich.txt                   Diese Hinweis-Datei

ConvertArchivDM_201_221.opo	   Update von Version 2.01 zu 2.21



Installation
------------
Zunächst wird eine Verbindung zwischen Psion und PC
mit dem seriellen Link-Kabel hergestellt.
Von PsiWin (ab Version 2.1) bzw. Windows Explorer
aus wird die Datei "DiabetesManager.sis" angeklickt.
Das Programm EPOC Install wird damit automatisch
aufgerufen und übernimmt die automatische
Installation von DiabetesManager auf dem Psion. Bitte
den Instruktionen von EPOC Install folgen.
