Descrizione del programma
---------------------
DiabetesManager è un programma di gestione e
controllo del diabete perPsion Serie 5/mx e Psion Revo/Plus.



Files
-------
Il file "DiabetesManager.zip" contiene i seguenti files:

DiabetesManager.sis     		    File di installazione

Leggimi.txt		  					 			Questo file

ConvertArchivDM_201_221.opo	    Programma di aggiornamento v. 2.01 -> v. 2.21



Installazione
--------------
Prima collegatevi con il PC con il cavo in dotazione
In PsiWin (versione 2.1 o superiori) o in Windows Explorer
cliccate sul file "DiabetesManager.sis". 
Il programma sarà installato automaticamente sul vostro Psion.
Seguite comunque le seguenti istruzioni.
