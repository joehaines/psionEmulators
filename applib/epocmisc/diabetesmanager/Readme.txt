Program description
---------------------
DiabetesManager is a Diabetes Management Programm
for the Psion Serie 5/mx and the Psion Revo/Plus.



Files
-------
The unziped file "DiabetesManager.zip" contains the
following files:

DiabetesManager.sis             Installation file

Readme.txt                 		  This English file

ConvertArchivDM_201_220.opo	    Update from version 2.01 to 2.21



Installation
------------
First please connect the Psion with PC bei the link
cable. 
In PsiWin (version 2.1 an higher) or Windows Explorer
tap the file "DiabetesManager.sis". The program EPOC install
will than be called and installs DiabetesManager automatically
to the Psion. Please follow the instructions of
EPOC install.
