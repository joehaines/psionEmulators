EBook v2.3 für EPOC
-------------------
EBook ist ein Programm zum Lesen von elektronischen Büchern (eTexte / eBücher). Es unterstützt Palm DOC (Aportis)-Dokumente, wie sie normalerweise auf Palm-Geräten verwendet werden, speziell komprimierte TCR-Dokumente und normale Textdokumente (z.B. ".txt"-Dateien, die von den meisten Textverarbeitungsprogrammen erzeugt werden können).  

Merkmale:
* Unterstützt komprimierte und unkomprimierte Palm DOC-Dateien (.prc bzw. .pdb)
* Unterstützt TCR-Dateien
* Unterstützt reine ASCII-Textdateien (.txt--Dateien)
* Automatisches Scrollen
* Navigieren mit der Bildlaufleiste
* Kopieren in die Zwischenablage und Kopieren in Datei
* Umfassende Verwaltung von Lesezeichen
* 80 Lesezeichen pro Dokument
* Palm DOC & TCR-Erkennung auf ER5-Geräten (Revo/Mako/MC218/S5mx/S7/netBook)
* Eingebettete bzw. gespeicherte Lesezeichen wie bei Palm DOC-Dateien
* Unterstützung für Zeichensätze nach Codepage 850
* Unterstützung für EPOC-Schriftarten (.gdr) - ermöglicht die Verwendung von Nicht-Latin-Schriften usw., etwa russische
* Online-Hilfe
* Geringer Speicherbedarf, abhängig von der Größe des betrachteten Dokumentes
* Geschrieben in C++ für optimale Geschwindigkeit


Bitte lesen Sie die Datei LIZENZ.TXT, bevor Sie die Software verwenden.


Installation
------------
Um das Programm zu installieren, lesen Sie bitte das Dokument INSTALLDEUTSCH.TXT

Gebrauchsinformationen
----------------------
Eine Online-Hilfe wird mit dem Programm mitgeliefert.

Registrierung
-------------
EBook für EPOC ist Shareware. Die Registrierung 10 britische Pfund. 

Aportis DOC-Dateien erzeugen
----------------------------
Ich habe das populäre MAKEDOC Tool nach EPOC portiert - es ist auf der Homepage von EBook verfügbar.

Diese EPOC-Portierung benötigt eshell.exe und STDLIB - diese sind ebenfalls auf der EBook-Homepage verfügbar.

Weiters gibt es eine Menge ähnlicher Werkzeuge auf verschiedenen Plattformen, die es ermöglichen, Aportis DOC-Dateien zu erzeugen.


Weitere wichtige Punkte
-----------------------
* EBook wurde als Leseprogramm für Bücher entwickelt, und die Formatierungsfunktion wurde für das Lesen vom Beginn zum Ende entworfen. Daher kann die Formatierung von Absätzen etwas durcheinander geraten, wenn Sie sich in Gegenrichtung durch das Dokument bewegen.
* Das Öffnen von ausführbaren Dateien, DLLs und sonstigen binären Daten kann das Programm zum Absturz bringen. Lösung: ...vermeiden! 
* Die Angabe der Position im Dokument kann bei TCR-Dateien ungenau sein; dies liegt am Fehlen von Informationen über die Originalgröße. 
* Defekte TCR-Dateien können das Programm zum Absturz bringen, wenn sie zum ersten Mal geöffnet werden.
