Installing EBook using a Win 95/NT PC
=====================================
You must have PsiWin v2.X installed on your PC.

PsiWin 2.1 (and above), and other Psion programs now include "EPOC Install" 
which you can use to install programs from your PC to the handheld. 

You can now use the "Install New Program" option, or double-click on a
.SIS file in Windows Explorer to install EBook on your handheld. 


Installing EBook using other computers
======================================

You must have software installed on your computer to copy files to your 
handheld, and a suitable cable to connect your computer to the handheld.
 
- If you have a Windows 3.xx PC, you can use PsiWin 1.xx.

- If you have a Macintosh computer, you can use PsiMac or Psion MacConnect.


MacConnect users only:
======================
You can install EBook from the .SIS file using MacConnect's 
install feature.

Select PsiTools from the Psion menu, click the Install button, and
navigate to the folder in which you have saved the sis file. Select this
file and click Open. Follow the on screen instructions to install EBook on your handheld.


Installation for other users:
=============================
1. Copy the sis file to your handheld.
If the file is on your PC, you should do this using PsiWin 2.x

2. Select the sis file in the System screen, then tap on it
again. The installation begins. Follow the instructions on
screen, making sure that you use the same disk for each component. 

Note: The sis file will be deleted once EBook has been installed.
To prevent this:
1. Open the 'Add/Remove' section of the Control panel on your handheld and tap on 'Prefs'
2. Remove the tick from the 'Delete .SIS installation file?' box.
Note: Removing the tick from this option means that you need approximately double the
recommended amount of disk space free to keep both the installed version of 
the software and the installation file on your machine.


Setting the Remote Link
=======================
You need to set the Remote link on your handheld to install programs using EPOC Install.
To set the Remote link:
1. Select Remote loink on the Tools menu in the System screen.
2. Set the 'link' line to 'Cable'
Make sure that the handheld is connected to your PC.
