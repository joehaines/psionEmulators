EBook unter Win 95/NT installieren
==================================
Sie müssen PsiWin v2.X auf Ihrem PC installiert haben.

PsiWin 2.1 (und darüber) bzw. andere Psion Programme enthalten "EPOC 
Install", das Sie verwenden können, um Programm vom PC aus auf Ihrem 
EPOC-Gerät zu installieren.

Sie können die Option "Neues Programm installieren" verwenden oder im 
Windows Explorer auf eine .SIS-Datei doppelklicken, um EBook auf Ihrem 
EPOC-Gerät zu installieren.


EBook mit Hilfe anderer Computer installieren
=============================================

Sie müssen auf Ihrem Computer Software installiert haben, die es Ihnen 
ermöglicht, Dateien auf Ihr EPOC-Gerät zu kopieren, und ein passendes 
Kabel, um Ihren Computer mit dem EPOC-Gerät zu verbinden.

- Falls Sie einen PC mit Windows 3.xx haben, können Sie PsiWin 
  v1.xx verwenden.

- Falls Sie einen Macintosh Computer haben, können Sie PsiMac oder 
  Psion MacConnect verwenden.


Für Benutzer von MacConnect:
============================
Sie können Ebook aus der .SIS-Datei heraus installieren, indem Sie die 
Installationsfunktion von MacConnect verwenden.

Wählen Sie PsiTools aus dem Psion Menü, klicken Sie auf den 
Installations-Knopf und navigieren Sie zu dem Ordner, in dem Sie die 
SIS-Datei gespeichert haben. Wählen Sie diese Datei und klicken Sie 
Öffnen. Folgen Sie den Anweisungen am Bildschirm, um EBook auf Ihrem 
EPOC-Gerät zu installieren. 


Installation für andere Anwender:
=================================
1. Kopieren Sie die SIS-Datei auf Ihr EPOC-Gerät.
   Falls die Datei auf Ihrem PC liegt, verwenden Sie PsiWin 2.x

2. Wählen Sie die SIS-Datei im Systembildschirm des EPOC-Geräts und 
   klicken Sie darauf. Die Installation beginnt. Folgen Sie den 
   Anweisungen am Bildschirm und verwenden Sie dasselbe Laufwerk 
   für jede Komponente.

Anmerkung: Die SIS-Datei wird nach der Installation von EBook am
EPOC-Gerät gelöscht.
Um dies zu vermeiden:
1. Öffnen Sie 'Hinzu./Entf.' in der Systemsteuerung auf Ihrem EPOC- 
   Gerät und klicken Sie auf 'Einstellungen'
2. Entfernen Sie die Markierung bei ".SIS-Installationsdatei 
   löschen?"
   Anmerkung: Wenn Sie die Markierung bei dieser Option entfernen, 
   benötigen Sie ungefähr die doppelte Menge an Speicherplatz auf 
   Ihrem EPOC-Gerät, um sowohl die installierte Version als auch die  
   Installationsdatei zu behalten.


Kommunikation einschalten
=========================
Sie müssen die Kommunikation auf Ihrem EPOC-Gerät aktivieren, um mit 
Hilfe von EPOC Install Programme installieren zu können.
Um die Kommunikation zu aktivieren:
1. Wählen Sie Kommunikation im Extras-Menü am Systembildschirm
2. Setzen Sie die Zeile 'Link' auf 'Kabel'
Stellen Sie sicher, dass das EPOC-Gerät mit dem PC verbunden ist.
