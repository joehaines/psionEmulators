EBook v2.3 для EPOC
-------------------
EBook является программой для чтения электронных книг для EPOC. Она поддерживает обычный текстовый формат, формат Aportis (в этом формате распространяются книги для Palm), формат TCR (максимально сжатый документ).

Особенности программы:
- поддержка сжатых и обычных файлов Aportis Palm DOC (.prc и .pdb);
- поддержка TCR-документов;
- поддержка текстовых документов;
- поддержка документов в формате Unicode (в виде отдельного SIS-пакета);
- автоматическое распознавание формата файла;
- масштабирование экранного шрифта;
- режим автоматической прокрутки;
- перемещение посредством полосы прокрутки;
- копирование в буфер и в файл;
- расширенные средства работы с закладками;
- 80 закладок на документ;
- автоматическое распознавание формата файлов Palm DOC и TCR на устройствах с ER5 (Revo/Mako/MC218/S5mx/S7/netBook);
- внедрение закладок в стиле Palm DOC;
- хранение закладок Palm DOC;
- поддержка различных шрифтов в формате EPOC (.gdr), позволяющих пользоваться любыми шрифтами;
- интерактивная справка;
- занимает мало памяти и быстро работает.

Пожалуйста, прочтите LICENSE.txt перед использованием.


Установка
---------
Для установки обратитесь, пожалуйста, к документу INSTALLATION.TXT


Инструкции по использованию
---------------------------
Справка на русском языке предоставляется вместе с программой.


Регистрация
-----------
EBook для EPOC является условно-бесплатной программой. Регистрация стоит 10 английских фунтов стерлингов. 


Создание файлов Palm DOC
------------------------
Утилита MAKEDOC для создания этих файлов доступна на домашней странице EBook.
Она требует файлы eshell.exe и STDLIB, которые имеются там же.
Существует множество других утилит для различных платформ, предназначенных для создания файлов Aportis.


Проблемы
--------
* EBook спроектирована как программа для чтения книг и алгоритм форматирования рассчитан на то, что вы читаете сверху вниз. Если вы листаете книгу в обратном направлении, то форматирование параграфов может быть немного некорректным.
* Попытка открыть файлы EXE, DLL и другие двоичные может вызвать сбой программы. Не пытайтесь открыть такие файлы!
* Информация о текущей позиции в файлах TCR может быть не совсем точной из-за отсутствия информации о реальном размере этого файла.
* Поврежденные файлы TCR могут вызывать сбой программы при первом запуске.
* Выравнивание текста в вертикальном режиме не работает из-за ошибки в EPOC.


Изменения с версии v2.2
-----------------------
* Четырехкратное увеличение скорости работы на Series 7 и netBook.
* Выравнивание текста по обеим границам.
* Определяемая граница поля текста.
* Улучшенный диалог закладок для Series 5 и Series 7/netBook.
* Клавиша для команды, которая позволяет удалить заголовок электронных текстов, подготовленных в рамках проекта "Гуттенберг" (Guttenberg).
* Перемещение на последнюю прочитанную позицию.

Изменения с версии v2.1
-----------------------
Новые возможности:
* Полностью русифицированная версия.
* Доступна Unicode-версия с поддержкой японского и китайского языков. Это отдельный SIS-пакет, доступный с домашней страницы EBook.
* Меню "История", в котором содержатся имена пяти последних открытых файлов.
* Если не заполнить поле "Папка с книгами", то запомнится последняя папка, к которой было обращение.
* В диалоговое окно "Информация о документе" добавлена дата последней модификации документа, удалена графа "Записи".

Дополнительные возможности Unicode-версии:
* Поддержка и автоматическое распознавание документов в форматах ShiftJIS, JIS, EUC, UTF-8, EUCKR (CP949), BIG5 и GB2313.

Исправлено:
* Система распознавания файлов теперь всегда устанавливается на диск C:, так как могла вызывать проблемы при установке на диск D:.
* Исправлена возможная ошибка при чтении закладок PalmDOC.

Изменения с версии v2.0
-----------------------
Новые возможности:
* Переименование закладок.
* Изменены горячие клавиши для перемещения по закладкам (теперь это выполняется нажатием одной клавиши).
* Минимальная скорость автопрокрутки снижена до 0.5 сек.

Исправлено:
* Восстанавливается потерянное место между параграфами при выборе форматирования по параграфам.
* Исправлена проблема с верхней строкой, которая могла быть пустой в случае выбора форматирования, как в оригинале.

Изменения с версии v1.2
-----------------------
Новые возможности:
* Улучшена навигация по закладкам.
* Чтение закладок Palm DOC.
* Полоса прокрутки.
* Копирование в буфер и в файл.
* Автопрокрутка.
* Поддержка кодовой страницы 850.
* Поддержка шрифтов в формате EPOC (.gdr) - можно использовать любые шрифты, к примеру, русские.
* Улучшены настройки просмотра.

Исправлено:
* Улучшена система поиска, теперь показывается с начала строки, где найдено слово.
* То же самое касается полосы прокрутки и перехода по процентному отношению.
* Документ теперь всегда показывается, начиная с верхней части экрана (раньше были проблемы при листании страниц вверх).
* Не производится повторное сканирование закладок в случае ошибки, устранена также ошибка с поиском документа, если его нет на положенном месте.
* Меню "Искать следующее" неактивно, если нечего искать.
* Исправлены некоторые сбои при перемещении по документам TCR.
