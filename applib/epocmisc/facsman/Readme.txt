                 Facilities Manager for Series 5
                 
This is version 5.21 of Facilities Manager for the Psion Series 5.

Version 5.21 has the following improvements:-

	Colour support on Series 7 and other colour machines

	Support for the smaller screens of the Revo and Osaris

	Installation via .SIS file

	Some minor bug fixes

Version 5.20 had two major new features:-

        The ability to print the Facilities Manager chart.
	
        The ability to attach memos to entries in the chart. 
	
Version 5.21 is supplied as a SIS file which may be installed like 
other EPOC programs.

This zip contains the following files:-

README.TXT                              This file
FACSMAN.SIS				The Installation file

Once installed it will comprise the following files:-

SYSTEM\
       APPS\
            FACSMAN\
                    FACSMAN.APP         The application itself
                    FACSMAN.OVL         A support file
                    FACSMAN.AIF         The application's icon
                    FACSMAN.MBM         Graphics used in the program
                    FACSMAN.HLP         The Help file for Facsman
       DATA\
            MEMOS.HLP                   An empty memo data file

       OPX\
           SYSRAM1.OPX                  The OPX used by the program

DOCUMENTS\
          FACSMAN.DOC                   The manual in Psion 5 Word 
                                         format
          
Once you have installed Facsman, the program's icon should appear in 
the Extras bar. Tap the Icon to start the program, which will 
initially open its help file. Tap 'Go back' to return to the program.

Please report to me any problems you encounter. I am particularly 
interested in how the program performs on non-U.K. machines, how it 
performs on 'clone' machines such as the Geofox and Osaris and whether 
you encounter any file location problems when using a Compact Flash 
card.
