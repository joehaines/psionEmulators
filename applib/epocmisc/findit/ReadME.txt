            Installation Instructions
            
            1. Unpack the Zip file to your PC or your Psion.
            
            2. On the PC:
               Double click on the file FindIT.SIS. This will start the PC
               automatic installation of FindIT.
               On the Psion:
               Double tap on the file FindIT.SIS. This will start the Psion
               automatic installation of FindIT.
	
            3. Repeat step 2 with the file SysRAM1.SIS
            
            4. Repeat step 2 with the file Systinfo.SIS

            5. Repeat step 2 with the file pc_bar.SIS
       

            FindIT should now be accessible to you from the Extras icon.
