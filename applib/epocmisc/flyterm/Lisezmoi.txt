    Merci de choisir d'installer flyTERM.
               
               
FlyTERM est un émulateur de terminal qui supporte toutes les 
séquences d'échappement importantes vt100/VT200/ANSI/ADM3A/VTI950
et qui est optimisé avec des mémoires tampon d'entrée importantes
pour les utilisateurs sans fil. La communication avec un téléphone
mobile est plus facile via la connexion Infra-Rouge (IrDa), et
c'est justement le but majeur de flyTERM. Pour ette raison,
vous ne pouvez installer ce programme que si la partie TCP/IP
de la version 1.52 de l'application "Message Suite" de PSION
est installée.
               
INSTALLATION
============
Pour installer le package flyterm.sis, le plus facile consiste
à utiliser le logiciel PC PsiWin fourni par PSION. Depuis la
version 2.1, ce programme vous guide dans l'installtion de vos
nouveaux logiciels sur le PSION Series 5, 5mx, 5mxPRO, Revo,ou 
le Geofox, en vérifiant automatiquement toutes les dépendances. 
Si vous avez une version plus ancienne de Psiin, vous pouvez 
télécharger les versions ou mises à jour nécessaires sur le site
de PSION <http://www.psion.com>.
Si vous n'avez pas installé le logiciel PsiWin vous pouvez aussi
cpier le package flyterm.sis sur votre Series 5 ou votre Geofox
via un transfert infrarouge depuis une autre machine, et utiliser
le bouton "Ajouter" un programme.
