      Thank you for installing flyTERM.


FlyTERM is a terminal emulator that supports all the 
important vt100/VT200/VT52/ADM3A/VTI950, and ANSI
escape sequences and is optimised for the wireless user.
The communication to the mobile telefon is easiest via
the Infrared (IrDa) connection, and this is therefore
the focus of flyTERM. For this reason you can only
install this program when the TCP/IP application from
PSION is installed.


PREREQUISITE SOFTWARE
=====================
Message Suite V1.52 and the IrDa Update must both be 
installed on older PSION Serie 5. On all newer EPOC32
products supporting the Internet Communications v2.0 this
then replaces the message suite, and should therefore be
installed instead. In this case the IrDa Update should NOT
be installed.

INSTALLATION
============
To install the flyterm.sis package, it is easiest to use the
PsiWin PC-software from PSION. As from the v2.1, this package
will help you install new software on the PSION Serie 5, or
Geofox. If you have
an older version of PsiWin you can copy the necessary software
from the www.psion.com web page.
If you do not have the PsiWin software installed then you can
copy the flyterm.sis package onto the PSION, or Geofox over
the Infrared connection from another machine, and use the "add"
software button.
