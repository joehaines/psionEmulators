      Danke, daß Sie flyTERM installiert haben.


FlyTERM ist ein Bildschirm-Emulator, welcher alle wichtigen vt100/
VT200/ VT52/ ANSI/ ADM3A/ VTI950 "Escape Sequences" unterstützt und für
die drahtlose Kommunikation optimiert wurde. Die Kommunikation mit dem
Mobiltelefon erfolgt am einfachsten über eine Infrarotverbindung 
(IrDa), daher liegt hier der Schwerpunkt von flyTERM.
Aus diesem Grund können Sie dieses Programm nur benutzen, wenn Sie den
TCP/IP  des PSION installiert haben.

PSION Serie 5MxPro und Revo

INSTALLATION
============
Um das Paket flyterm.sis zu installieren, verwenden Sie am besten die 
PsiWin PC-Software von PSION. Ab der Version v2.1 können Sie mit Hilfe 
dieses Paketes neue Software auf dem PSION Serie 5 oder dem Geofox
installieren. 
Falls Sie eine ältere Version von PsiWin haben, können Sie die 
notwendige Software von der Web-Seite www.psion.com web page kopieren.
Falls Sie das Programm PsiWin nicht installiert haben, können Sie das
Paket flyterm.sis von einem anderen Handheld über die Infrarotverbindung
auf den PSION oder Geofox kopieren und das Software-Icon "add" benutzen.


Falls Sie Probleme oder Vorschläge haben, bitte eine Mail an mich senden unter
info@newnet-marketing.de
