1. INTRODUCTION

fMat is an electronic handbook for handhelds consisting a database with data of a large number of metals, a materials selection module and a glossary of terms related to materials and processes.

fMat is shareware. To make fully use of all possibilities of fMat you need to register. 


2. INSTALLATION

To install the program simply double-click on the .sis file or select the "Install New Program" option in PsiWin (EPOC Install). If you have PsiWin/EPOC Install v2.1 or above, then everything will happen automatically. If you have an earlier version, you will need to get the installation file SETUP.EXE, which can be downloaded from the psion website: http://www.psion.com/


3. RUNNING THE PROGRAM

Start the program by selecting 'Extras' from the Application bar and then selecting fMat.
