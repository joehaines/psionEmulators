README.TXT: Overview instructions for GenMVD 2.00
=================================================

Program:    GenMVD
Version:    2.00
Date:       12 January 2000
Platforms:  Psion 3a/3c/3mx/Siena and Acorn Pocketbook II
Programmer: Martin N Dunstan (mnd@dcs.st-and.ac.uk)
Designer:   Vivienne S Dunstan (viv.dunstan@one-name.org)
Home page:  http://www-theory.dcs.st-and.ac.uk/~mnd/export/genmvd/
Status:     Shareware (see REGISTER.TXT for more details)
Notes:      This program WILL NOT run on the Psion 5, the old
            Psion 3 or the Workabout Series.

GenMVD is a fully-fledged genealogical database browser for the Psion
Series 3 palmtop computers. It is designed to be a portable companion to
your desktop genealogy program and will allow you to carry your family
tree around with you in a compact and easily accessible format. Since
GenMVD was intended to be used with large databases (those containing
more than 5000 individuals and families) it should be quick and
responsive whatever size of database you have. Indeed GenMVD is quicker
than the authors' desktop genealogy program!

You are allowed to use GenMVD to browse to 100 individuals (that is 100
different people or the same person 100 times!) before you must register
your copy. If you do not do so GenMVD will stop working except to allow
you to register and to read the online help. Once registered GenMVD will
return to full functionality and you won't be nagged every time you start
the program. Upgrades to future versions are completely free and so is
technical assistance.

All the information that you need for installing and using this program
can be found in the manual. This is an HTML (WWW) document which can be
viewed using a program such as Internet Explorer or Netscape. If you don't
have such a program then please contact the programmer who will send you a
copy of the manual in a format that you can read!

If you currently using an earlier version of GenMVD please read the UPGRADE
section of the manual which explains how to upgrade to this version without
losing all your registration details.

Please read the installation instructions CAREFULLY. If you are still stuck
you may need to refer to the manuals which came with your Psion and PsiWin
(if appropriate) to see if they can help. If all this fails then please don't
hesitate to contact the programmer for more advice.

FINALLY: please drop in on the GenMVD home page now and again for news.
