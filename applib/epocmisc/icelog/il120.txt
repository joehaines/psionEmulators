1. INTRODUCTION

IceLog allows you to record time spent on different tasks using up to
6 timers.  Timers can be configured to run concurrently or singly.

Timers have tasks attached to them.  A task can carry an hourly rate which
is used to calculate the charge for a timer (rate multiplied by accumulated
time).

Each timer, running or not, can be saved to a Log file.

Log files can be organized in any way you wish.  You could save Timers by
Project, Week Started, Month Started, Task or by any other rule you desire.

2. PREREQUISITES

IceLog requires the DBUtils OPX to be installed.  This will be done automatically during installation.  Icelog does not require any other software to be installed before
it can be run on an EPOC machine.  However, to install from a PC, you will need
a copy of EPOC Connect (such as PsiWin) and a comms connection between the PC and your EPOC machine.

3. INSTALLATION

IceLog is available for installation in two forms.  A standard EPOC
installation (SIS) file and a compressed (ZIP) file. The SIS file is for
installing directly on an EPOC machine (or via a PC) if you do not have
access to an unzipping program such as WinZip on the PC, or RMRZip
under EPOC.  The Zip file contains the SIS file plus this readme.txt file.
It is significantly smaller than the uncompressed SIS file, making it faster
to download.

To install IceLog:

* If you have the zip file unzip it to a temporary folder

* Either double click or tap on the SIS file

The installation routine will guide you through installing IceLog.
