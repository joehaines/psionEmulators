1. A propos de IPContact
------------------------
   - IPContact est un gestionnaire d'adresses 'relationnel' pour les systèmes EPOC32.
   - Il vous permet de tenir à jour votre carnet d'adresses et d'associer plusieurs personnes avec une société donnée...


2. Installation
---------------
   Ce programme peut être installé de deux façons:

   - Dans le menu PSIWIN de votre PC, sélectionnez '\Psion\Installer une application' puis sélectionnez IPContact.SIS

      OU

   - Copiez le fichier 'IPContact.SIS' vers votre Psion, et activez-le.


3. Mise à jour depuis la v0.86
------------------------------   

      En raison d'un changement de la structure de la base de données et du
   fichier INI, il est impératif de supprimer complètement l'ancienne version
   de l'application, tout en conservant et convertissant vos fichiers de
   données.
      La suppression de l'ancienne application s'effectue depuis le panneau
   de configuration (Config dans la barre d'outils du Psion puis Add/remove).
      Installez ensuite (depuis le panneau de commande ou depuis PsiWin)
   l'application de conversion qui se trouve dans le fichier IPCnvrt.SIS.
      Après avoir converti tous vos fichiers de données avec IPCnvrt, vous
   pouvez d'une part effacer cette application devenue inutile (même méthode 
   que ci-dessus, et installer la nouvelle version de l'application en 
   utilisant cette fois le fichier IPContact.SIS.


4. Utilisation
--------------
   - Toutes les opérations sont accessibles depuis le menu, et sont (je l'espère) suffisamment explicites pour ne pas nécessiter d'explications.
   - Les raccourcis utiles :
        Ctrl + flèches         ... change la vue courante
        Ctrl + Maj + flèches   ... change la taille de la fenêtre
        PageAvant, PageArrière ... déplace la fenêtre
        Tab, Maj + Tab, et flèches 
        Gauche et Droite       ... bascule entre fenêtres
        Eff                    ... identique à Ctrl+D
        Flèches Haut et Bas    ... déplacement haut/bas dans les entrées de la base                                    de données

   - Tous les champs de la base peuvent faire l'objet d'une recherche (sociétés et individus)
   - Pour rechercher une entrée, il vous suffit de taper les premiers caractères.
   - Les fenêtres peuvent être déplacées et redimensionnées avec le stylet.

    Note: une indication comme [23]/30 dans le titre signifie qu'il s'agit de
    l'enregistrement numéro 23 (ID=23) dans une base contenant 30 enregistrements. 
    Le numéro entre crochets N'EST PAS forcémént le rang de l'enregistrement,
    Lorsque vous ajoutez ou retirez des enregistrements, ce numéro peut devenir plus
    élevé que le nombre total, puisque les identifiants libérés ne sont pas recyclés.
    Les enregistrements seront renumérotés lorsque vous effectuerez une ré-indexation
    de la base de données (Menu > Outils > Réindexer la base.)
