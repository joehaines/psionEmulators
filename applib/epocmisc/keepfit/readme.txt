HOW TO INSTALL
--------------------------

     The delivery files are provided in the form of a self extracting archive. 
     In order to install KeepFit V1.0 these files must be extracted to a 
     directory on the user's PC. This will provide him with two files :
   
     - fittracker.sis - Main installation file.
     - Readme.txt   - This file.

     To install KeepFit do one of the following :    
     
     1) Connect your Psion Series 5 machine to your PC.
        Now goto the 'Psi Win' menu in your Start/Programs menu and select the
        'Install New Program' option. Follow the instructions to install.

     2) Copy fittracker.sis file to you Psion machine . Now go to Control Panel and select 
        'Add/Remove Program' option. Follow the on screen instructions to install.

GETTING STARTED
==========================================================================

a) Choose the Workout tool button.It will display slide menu containing options as:
   New,Open.
(b) Choose New for creating the new user log. Fill all the entries click next to define your workout preferences. Add all your workouts in the workout list.
 Note: These will be the only the workouts that will be displayed to you for data input. Click on Save to save these and press Done. 
(c) Choose open to view the existing user's log.Select your log and go to the record display form
    ,Choose new to add new entry and save it.	
(d) Analyse option is used to display the graph of existing log.
(e) Spl. Functions option contains the following features:
	1. Body Composition :-Uses "Skin Caliper Method"  to analyse the body composition of user. To get help select About Test button. Perform the test and
					fill up the readings.Click on "Result" it will display you your body percent fat, fat weight and lean body mass.
	
	2. Fitness Test
		(i)	CardioVascular Test:- Perform the test fill the reading and click on result.
		(ii)	Flexibility Test:-Gives your flexibility.
		(iii) 	Muscular Strength :- Gives you the muscles strength.
	2. Race Calculator :- Race calculator calculates the Pace for the entered readings.
	3. Perfect Shape:- It allows you to analyse your body Stat. over a period,Just fill up 			   your daily readings and save it.In this "Trainer" will suggest you 			                              different exercises.Anayser will show you the graph.
