Lifeguide
------------------------------------------------------------
v1.0 for Series 5 and compatibles, Feb 24th 1999

Freeware by Steve Litchfield, a guide to life, based on the opening
sections of the Gideon bibles often found in hotel rooms.

Installation
------------
If you unzipped Lifeguide OK, you should have ended up with
2 separate files. One will be this text file 8-)

The other one is a SIS file.

(Experts)
If you know what a .SIS file is, just double-click on it in Win95 Explorer
or tap on it on the Series 5 and you'll be installed in no time.

(Beginners)
If you *don't* know what a .SIS file is, this must be one of the very first
third party applications you've ever installed. Don't worry, it's all quite 
painless:

  IF you have PsiWin 2.1 or above, just double-click on the "lifeguide.sis"
  file to launch EPOC Install on the PC and to complete the installation.
  
  IF you have the 'older' PsiWin 2.01 or if you've downloaded Lifeguide directly
  onto the Psion 5, the best way to proceed is to copy the "lifeguide.sis" file into a
  suitable place on your Psion. If the file appears on the system screen
  with a question mark beside it, this just means you haven't yet upgraded your
  Series 5 to accept EPOC install files. Grab a copy of the special INSTEXE.EXE
  program from the same place as you obtained Lifeguide and tap on it on your Psion.
  You should now see a nice little icon beside the "lifeguide.sis" file and can tap
  on it to complete your installation.

If all went well, you should now have a new "Lifeguide" icon on your
Extras bar.
