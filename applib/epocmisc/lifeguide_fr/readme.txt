Lifeguide
------------------------------------------------------------
v1.0 pour le Series 5 et compatibles, 24 Fév 1999

Ce logiciel est un "freeware" créé par Steve Litchfield. Son contenu
est basé sur l'introduction des bibles Gideon que l'on trouve
fréquemment dans les chambres d'hôtel anglo-saxonnes... Il fournit
quelques lectures bibliques pour toutes les circonstances de la vie.

Installation
------------

Si vous avez correctement décompressé le fichier "ZIP", vous devez
obtenir deux fichiers. L'un d'eux est ce fichier 8-)

L'autre est un fichier SIS.

Experts :
---------

Si vous connaissez les fichiers SIS, double-cliquez dessus dans
l'Explorateur Windows ou sur le Psion si vous l'y avez transféré.

Débutants :
-----------

Si vous ne connaissez pas ce genre de fichiers, suivez le guide :

Si vous avez PsiWin version 2.1 ou supérieure, il suffit de connecter
votre Psion et de double-cliquer sur l'icône de ce fichier qui 
apparaît dans l'Explorateur Windows.

Si vous avez une version plus ancienne de PsiWin, le mieux est de
copier directement le fichier "lifeguide.sis" dans un répertoire
quelconque de votre Psion.

Si l'icône du fichier apparaît sur votre Psion accompagnée d'un point
d'interrogation, c'est que vous n'avez pas mis à jour votre machine
avec le programme d'installation. Vous devez récupérer le programme
INSTEXE.EXE (disponible notamment sur le site où vous avez trouvé
Lifeguide), puis l'exécuter sur le Psion. Vous devez à présent voir
une icône spéciale pour "Lifeguide.sis". Double-cliquez dessus avec
le stylet pour lancer l'installation.

A la fin de l'installation, une nouvelle icône "Lifeguide" doit
apparaître dans la barre "Extra".


Vous trouverez d'autres logiciels pour le Series 5, gratuits ou payants
sur :

http://3lib.ukonline.co.uk/
