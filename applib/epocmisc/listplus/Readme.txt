Installation Instructions

1. Unzip the ListPlus Zip file.

2. Either:

i. Copy all the .sis files to your Epoc machineand double click each one it
turn to install the necessary application files to your computer.

OR

ii. Connect your Epoc machine to a PC or Mac. Double click each .sis file to
automatically install all the necessary application files.


3. ListPlus will now be available for use.
