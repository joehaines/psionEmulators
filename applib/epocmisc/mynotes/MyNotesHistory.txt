Changes in version 3.05

* Added a link to the Agenda application; notes can
now be sent directly to the Agenda, in the form of
an Event, an Appointment or a ToDo item.

* Added a user-definable hotkey, to return MyNotes 
to the foreground (default is Ctrl+Fn+M).

* Pressing Ctrl+Delete deletes a note without 
sending it to the Trash.

* It is now possible to hide priorities.

* When selecting a file to import, there is a 
preview button in the file selection dialog.

* Notes having priorities can be ticked but still 
maintain their priority.

* Removed link to PostIt, due to release of a 
completely different PostIt application.

* Improved colour support.

* Added memory checks before and during memory 
intensive operations (sorting, merging etc.)

* Various bug fixes.

Changes in version 3.04

* It is now possible to select whether the
list should be displayed on the left or right
side or the screen. 

* Improved the way in which the position of the 
partition between the two windows is set. 

* The Find function now supports the use of 
Boolean operators.

* Changed Lock Up to Ctrl+U and Open URL...
to Shift+Ctrl+U, as this is slightly more 
consistent.

* There is now a progress bar when printing 
and importing a file.

* Fixed various bugs in the Open File dialog.

* Various other bug fixes.

Changes in version 3.03

* Finally managed to fix a long-standing 
problem, which stopped MyNotes from running 
on a Series 5. 

* Added a Find by Date... option, which allows 
notes to be located by to their date, without 
having to sort the file according to date. 

Changes in version 3.02

* First version released under FreEPOC.

* Fixed problems with printing; it is now possible 
to print attached sketches. 

* Fixed various other minor issues, and improved 
the "Open Embedded File..." and "Open URL..." 
options.

Changes in version 3.01

* Minor improvement to the properties bar.

Changes in version 3.00

* Added a small sketch module, which allows
sketches to be added to a note. 

* Fixed some small bugs. 

* Added more support for colour screens.

Changes in version 2.50

* Added an extra scroll bar, so that the 
bottom lines of long notes can be seen when
a large zoom ratio is used. Note: this feature
is not available when editing a note, due to 
problems with implementing a scroll function 
in the editor module.

Changes in version 2.49 

* Uses my new OPM, VScrollBar.

Changes in version 2.48

* Added a "Send To (ticked notes)..." option.

* Added the possibility for a specific file to
appear at switch on. 

* It is now possible to use mixed case letters 
in filenames, although the first letter is still 
always changed to upper-case.

Changes in version 2.47

* Added a Recent Files option (File|Recent Files
or Shift+Fn+R).

* Uses a new version of ProgBar.opm.

Changes in version 2.46

* All OPMs are now installed using a single SIS 
file. 

* Fixed bugs in the paste, dialling, new note 
and screen handling routines. 

* Improved the keyboard handling again.

Changes in version 2.45

* Added an encryption algorithm; files which
are password protected are encrypted when saved
and decrypted when opened. This provides better
protection of private or confidential data, as
password protected files could be opened in the
past with a text editor or hex editor.

Changes in version 2.44

* The scroll-bar buttons are now animated.

* Several small bug fixes.

Changes in version 2.43

* Fixed bug in paste, which caused note to have
wrong priority. 

* Fixed bug which could cause all of the buttons
in the "details" bar to appear be pushed in when 
one button was tapped. 

* Fixed problem with changing the priority using 
Shift+0 to Shift+5 on non-English machines. 

* Tidied up the way the progress monitor works 
during sorting.

* Added a popup menu option to the "double-tap"
possibilities. 

* It is now possible to show faint lines, which 
may increase the legibility of text.

* The colour of a note is now displayed correctly
during editing.

Changes in version 2.42

* It is now possible to change the priority of 
notes using Shift+0 to Shift+5.

Changes in version 2.41

* Added a Trash folder; all deleted notes are 
automatically copied here, and remain there
until the Trash is emptied. 

* It is now possible to combine styles and 
priorities. 

* Also fixed a bug which caused the preferences 
to be reset when 'None' was set as the priority 
for new notes.

Changes in version 2.40

* Added a proper "progress monitor".

Changes in version 2.39

* modified the screen layout, so that files
containing more than 1000 notes are displayed
correctly.

* One or two bug fixes.

Changes in version 2.38 

* Added an extra zoom level, so that there are
now 4 zoom levels. 

* Notes are now word-wrapped using the characters 
!?.,:;-@/\ as well as spaces and carriage returns. 

* There is now a popup menu, which can be shown by 
tapping in the right window. 

* Fixed a bug which caused the filename to disappear 
if Save as... was cancelled.

Changes in version 2.37 

* It is now possible to enter filenames in upper-
and lower-case, although the first letter is still
converted to upper-case.

Changes in version 2.36 

* Modified the display routine, so that notes 
containing carriage returns are displayed correctly
in the left-hand window; ie. they are truncated at
the first carriage return. 

* Also fixed a bug in the editor, which allowed the 
end of the text to be lost when it disappeared off 
the screen. The maximum number of lines for a note 
has been increased from 10 to 20.

* Improved the Copy URL function.

Changes in version 2.35

* It is now possible to format a note by entering
carriage returns, using Shift+Enter; to save the note, 
use Enter or File|Save and Close Editor (Ctrl+S). 

* Fixed bug in initialisation routine.

Changes in version 2.34

* Moved the scroll bar to the left-hand side of 
the screen, which seems to be a more logical 
location for it.

* Also fixed bugs in the "Open 'Embedded' File" and 
Zoom routines. 

* The status of the 'Details' toolbar is now saved
on closing. 

* It is also possible to change the layout of the

Changes in version 2.33
