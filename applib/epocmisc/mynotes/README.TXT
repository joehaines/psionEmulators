Description of the program 

MyNotes allows short notes (up to 255 characters) to be entered. On the left side of the screen the notes are listed, while on the right side of the screen the whole of the currently selected note is displayed. 

Notes may be displayed in one of five different styles (Normal, Ticked, Striped out, Bold or Italic) and one of three fonts (Arial, Times New Roman or Courier). Notes can also be assigned a priority; priorities are numbered from 1-5, with 1 having the highest priority.

Multiple files (a file is a list of notes) may be created; a file called MyNotes is created automatically when the program is run for the first time, but the user may create as many files as necessary. Existing files may be copied or renamed, and those files which are no longer required can be deleted. 

MyNotes includes a clipboard feature. This enables notes to be copied (or cut) and pasted, either to the current file or to another file. The contents of the clipboard can now also be pasted into another application (ie. Agenda, Word etc.) Files may also be combined by using the Merge facility.

Using Export File..., it is possible to save a file either as a text document, as a comma separated variable (CSV) file, which can then be imported into the Data application, or as an HTML file, which can be viewed in Web or Opera; most URLs (but not all) are clickable.

MyNotes has an extensive sort capability, enabling notes to be sorted according to priority, alphabetically or by date.

If desired, MyNotes may be password protected. This stops MyNotes from being started (or unlocked) without authorisation, and may be used to protect individual files.

MyNotes can be configured to appear at switch on.
