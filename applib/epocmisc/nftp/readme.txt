Installation Instructions

1. Unpack the Zip file to your PC or your Psion.

2. On the PC:
   Double click on the file nFTP.SIS. This will start the PC
   automatic installation of nFTP.
   On the Psion:
   Double tap on the file nFTP.SIS. This will start the Psion
   automatic installation of nFTP.  Install all components.

nFTP should now be accessible to you from the Extras icon.
