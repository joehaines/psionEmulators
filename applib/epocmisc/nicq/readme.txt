Installation Instructions

1. Unpack the Zip file to your PC or your Psion.

2. On the PC:
   Double click on the file nICQ.SIS. This will start the PC
   automatic installation of nICQ.
   On the Psion:
   Double tap on the file nICQ.SIS. This will start the Psion
   automatic installation of nICQ.

nICQ should now be accessible to you from the Extras icon. 

________________________
Upgrading from pre V2.00 

IMPORTANT: This version of nICQ will try to locate the files from a older
version of nICQ, but will only convert the current active registered UIN
and the contacts list. Messages for each contact will NOT be converted.
If you do want to read old messages and have already upgraded you can
uninstall this version of nICQ and install the old version and you
should be able to read all your messages.
