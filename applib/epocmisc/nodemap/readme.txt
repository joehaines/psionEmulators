INSTALLATION
------------

The installation is supplied as two .sis files, 
NodeMapx.xx.sis which contains the main NodeMap application
and support files, and StandardNMXsx.xx.sis, which installs
two NodeMap extensions, TextMutator and AgendaLink.  The
latter .sis file is optional.

As long as you have EPOC Connect (PsiWin) installed on 
your PC, all you should need to do is double click on the 
.sis file(s) from this zip archive and follow the on-screen 
instructions

If you *don't*, then use the instexe.exe file included with
this archive.  Unzip it to a folder on your EPOC machine
and double-tap it.  You should then be able to double-tap
on .sis files to install them.

And, er, that's it.
