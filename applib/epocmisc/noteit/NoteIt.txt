
Note-It version 1.0

To install Note-It either copy the NoteIt.sis file to your Epoc device and open it from the system screen or install from your PC using PsiWin.

For information on using Note-It please install the program and select 'Help' from the 'Tools' menu.

http://www.palmscape.com/

IMPORTANT:
To register Note-It you need to include your Note-It serial number on the registration form. This is a simple four digit number you can find by selecting 'Register' from the 'Tools' menu in the program.
