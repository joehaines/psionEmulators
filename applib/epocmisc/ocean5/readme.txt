Ocean for S5 Version 3.02  English version, September 1999

SHAREWARE version

Prediction of tides using harmonic constants method.

INSTALLATION :
To install Ocean, double-click on the file Ocean.SIS on
your PC (if PsiWin 2.x is installed). Or double-click Ocean.SIS
on the Series 5 (if there is an Add/Remove icon in the Control
panel).

Read the built-in help for instructions.

ABOUT OCEAN :
Ocean computes sea height and tides for a day, a week or a month.
Accuracy is about 5 to 20 minutes in comparison with official tide tables.
File Ocean.dbf contains constants for several English and German ports.
Some others ports are available after registration. Read Help to get more instructions.
