What is pdf+?
-------------
Pdf+ is a viewer for Portable Document Format (PDF) version 1.3 files.
These are also sometimes also called 'Acrobat' files, from the name of 
Adobe's PDF software.

There's also a less capable flavor called Pdf available. Pdf cannot print, 
copy text to other applications, follow links or handle bookmarks.
Check the website for details.

Compatibility
-------------
Pdf+ is known to run on almost all current EPOC PDA's, such as the 
Psion series 5, series 5mx, series 5mx Pro, series 7, netBook, Revo and
the new Revo Plus, the Ericsson MC218 and the Oregon Scientific Osaris. 
Pdf should run on the Diamond Mako (as this is a rebadged Revo Plus) and 
the GeoFox, but at the time of writing this is not confirmed.

Pdf+ does not run on the recently announced ER5u and ER6 machines like the 
Ericsson R380 and Nokia 9200 Series communicator. Check the website for 
availability.


Installation
-------------
Install the pdf+.sis file in the usual way. Check your manual if you 
are unsure how to install a program on your EPOC PDA.

On the Series 7 it is possible that the installation programs hangs 
while displaying the message "Checking dependencies". If this happens 
to you, copy pdf+.sis to your Series 7 and install it from there, by 
tapping twice on it. You might want to delete this file afterwards.

The file Pdf+.pdf is a quick-start guide to using Pdf+. Copy it to
your EPOC PDA and run it by tapping twice on it.


Running
-------
Pdf files have their own icon in the System screen (but not on a 
Series 5 or a GeoFox). Tap twice on a pdf file to start Pdf+ with 
that file. Pdf+ will load the file (this might take a while) and 
display it (this migth take a while too). Check the menu and the 
help text (Ctrl+Shift+H) for an overview of the commands available.
You can also start Pdf+ via the Extras bar.
