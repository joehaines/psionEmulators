Installation

1. Stellen Sie sicher, daß Sie Zugang zum Systemverzeichnis haben, indem Sie die Option in den Einstellungen aktivieren. (Strg+K)
2. Erstellen Sie ein Verzeichnis Periodic in \System\Apps\ auf Disk C: oder D:
3. Kopieren sie alle Dateien mit dem Namen "Periodic" in das Verzeichnis \System\Apps\Periodic\
4. Starten Sie Periodic aus der Extras-Leiste. Fertig!
