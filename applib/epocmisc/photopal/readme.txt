Introduction

PhotoPal is a simple collection of utilities designed for serious amateur or
professional photographers. Calculates hyperfocal distance, depth of field,
aperture, flash distance, flash aperture, bounce distance and angle, close-up
ratio, luminescence values, focal length, film speed, scanning sizes. It also
features a built-in audible second ticker for bulb timing.

____________
Installation

The installation file is Photopal21.SIS. There are two ways of using a *.SIS
installation file:
- from a PC (if PsiWin is installed), double-click on the *.SIS file (this
  can be done from the WinZip window, even without unzipping the *.SIS file)
- from the Epoc machine itself (if there is an Add/Remove icon in the Control
  panel): copy the *.SIS file anywhere on your Epoc device and double-tap it.

What's new?

v2.1:

*  The EV difference calculator now calculates everything in 1/3 or 1/2 EV
   steps. You can also enter the EV compensation that you have dialled in
   on your photo camera.

v2.0:

*  The depth of field calculation has been redesigned. There are now separate
   hyperfocal and distance calculators, and a new reverse depth of field
   calculator has also been adedd that calculates aperture and focus from the
   required distance values.

*  Film speed converter to convert between ISO and DIN (thank you for György
   Fleischman for this idea).

*  The second ticker has been redesigned, it displays the elapsed seconds in
   a window. The dictaphone LED also blinks if desired, and it can be used
   even in mute mode when only the LED blinks at every second.

*  New film formats were added including movie 16 mm and movie 35 mm formats.

*  Three new scanning calculations: file size, resolution on screen, resolution
   for printing.

*  The program can launch your favourite photo databases. There is a reciprocity
   failure table already included, and up to 5 new databases can be defined.

*  New interface, new graphical background, use of menus and toolbar.

*  A Help has been added to the program.

________
Features

*  Depth of field calculations: hyperfocal distance, near and far distance, focus
   and aperture calculators.

*  Flash calculations: flash distance, flash aperture, flash bounce calculators.

*  General calculations: lens choice, film speed, close-up ratio, EV difference
   calculators. 

*  Scanning calculations: file size, resolution on screen, resolution for printing
   calculators.

*  Launch of databases, one database included (Reciprocity failure or films), up
   to 5 more databases configurable.

*  Second ticker, useful for better timing of long (bulb) exposures. Audible
   signal and/or LED blinking, display of elapsed seconds.

*  Help included with the program.
