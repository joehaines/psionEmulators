PIP (Patient Information Program) v1.01
-------------

PIP v1.01 is a patient information program designed to temporarily store patient information while oncall. It is designed for GPs, but could be used for ward work.

PIP incorporates Boxy v1.0 which manages a database on the drugs in your box/bag, adding them to a patients record & telling you which drugs to restock on.

I have updated the program to record TR patients, fixed bugs in the load & save screens, and  updated the patient details to record TR patients, the consultation mode & to work out the age for you.

Installation:
-------------

Once unzipped you should have 7 files:
Pip.app
Pip.aif
Pip2.mbm
Pip.hlp
Tele.hlp
Medic.hlp
ReadMe.txt

To install Pip, place the 6 Psion files in \System\Apps\Pip & away you go.
NB Don't include this ReadMe.txt file.


Usage:
------
Pip includes features too:

Add, delete & change patients details in the current database file.

Direct access to a personalisable telephone database so you don't have to search for the database each time you need it.

Access to a medical database for the GP Registrar on call.

Value screens for looking up common haematology & biochemistry values.

Work out the EDD from the LMP without the use of a wheel.

Printing of the patients details & clinical data for input into the local surgery computer.

Among other features....

Planned enhancements :
----------------------
At present you can calculate a ladies EDD from her LMP without having to search for a wheel. 
I hope to add centiles, PEFR etc in later versions.

Also, next will come screens to manage data needed for GP Registrar logbooks, such as recording minor surgery done, tutorials & admissions/referrals.
