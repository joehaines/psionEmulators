Description:

	Plan5 is a project planning tool for EPOC (Psion Series 5, 5mx,
	5mx Pro, 7, Netbook, Ericsson MC218, Revo, Osaris, Geofox-One...).
	(A separate version is also available for the Psion
	3a/3c/3mx/Siena). Given a set of tasks, and resources working
	on those tasks, Plan will calculate the schedule for each
	task and the project as a whole, taking into consideration
	dependencies between tasks, resource work hours and holidays etc.
	Plan5 is similar to and compatible with Microsoft Project.


Whats new in version 5.8?:

	- Colour support!
	- Numerous small improvements to graphics
	- Changes for REVO screen size
	- New CSV import/export facility (needed for MSProject 2000)
	  (See section 15.1 of P5Manual for details)
	- Some minor bug fixes
	- Additional support for MPX files in Italian

Packaging

	Plan5 is supplied as a SIS file contained within a ZIP file.
		
	If you have a PC then double clicking from Windows Explorer
	on the SIS file extracted from the Plan5.zip file will
	install the software to your Psion automatically. For
	this to work you will need either PsiWin 2.1 or greater
	to have previously installed Psion's Message Suite software.
	
	If your PC doesn't recognise the SIS file then you need to
	download the necessary installation software for your PC.
	This can be obtained from the download section of the
	Twiddlebit web site:
	
		http://www.twiddlebit.com

	Alternatively you can copy the SIS file to your EPOC machine
	and install it from there by clicking on the SIS file from
	the system screen.

User guide & sample plan

	The user guide is supplied with the software in Psion Word
	format. You can read and print this on your Psion. The manual
	will be installed to:
	
		\Documents\P5Manual

	A sample plan is also installed to:
	
		\Documents\P5Sample

Upgrading from Plan for the Series 3a/3c/3mx/Siena:

	You cannot copy Plan files from the 3a/3c/Siena version
	of Plan onto your EPOC machine and use them with Plan5. What
	you need to do is to make use of the MPX module to
	export the data to an MPX file on the 3a and then import
	that file into a newly create plan in Plan5.
