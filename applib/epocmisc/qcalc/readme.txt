Installation Instructions

1. Unpack the Zip file to your PC or your Psion.

2. If using the PC:
   Double click on the file Q-CALC.SIS. This will start the
   automatic installation of Q-Calc from the PC.

   If using the Psion:
   Double tap on the file Q-CALC.SIS. This will start the
   automatic installation of Q-Calc from the Psion if the
   Add/Remove Control Panel is installed.

Q-Calc should now be accessible to you from the Extras icon.
