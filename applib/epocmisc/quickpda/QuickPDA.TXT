Installer QuickP :
------------------------
1. Installer AGENDA2.OPX, start "PsiWin Installer" og vælg AGENDA2.SIS
2. Installer APPINFO.OPX, start "PsiWin Installer" og vælg APPINFO.SIS
3. Installer APPINFO.OPX, start "PsiWin Installer" og vælg PSCAPE.SIS
4. Husk at du skal have adgang til system directory (biblioteket).
   Du kan aktivere dette ved i system vinduet at trykke 
   CTRL+K. Vælg 'Show "System" directory'
5. Opret et nyt directory(bibliotek): \system\apps\QuickP på
   drev C: eller D:
6. Kopier alle filer til dette nye directory/bibliotek.
7. Du burde nu kunne se programmet i extras bar/liste.
8. Start programmet
9. Læs hjælpe filen.

Tidligere QuickP brugere:
-----------------------------------
QuickP 3.0 databasen har et andet format end tidligere versioner af QuickP,
for at flytte dine data fra en tidligere version af QuickP database til 3.0, skal du bruge CONVERT.OPO programmet. Installer og kør dette program på disken.

Konverterings instruktioner :

For registerede brugere, H U S K dit brugernavn (username) og password,
Noter det evt. på papir.

1) Slet QuickP.INI i C:\SYSTEM\APPS\QUICKP
2) Start QuickP 3.0
3) Opret en ny tom fil/projekt med QuickP 3.0
4) Afslut QuickP 3.0
5) Start Convert.opo
6) Vælg den tidligere version af QuickP, vælg din gamle QuickP Database,
    Vælg den nye QuickP database fil (oprette i pkt. 3), tryk Enter
7) Start QuickP 3.0, nu skulle du gerne se dine gamle data i det nye dataformat.
