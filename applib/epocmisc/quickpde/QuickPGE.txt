Installieren von QuickP :
-------------------------
0. bitte prüfen, dass agenda2.opx, appinfo.opx, music.opx, sysram1.opx
   im Verzeichnis c:\system\opx oder d:\system\opx nicht vorhanden sind und wenn, dann bitte löschen, bevor die Installation gestartet wird (oder die "Entfernen"-Funktion benützen). Damit ist sichergestellt, dass die neuesten Versionen dieser Dateien kopiert werden können.
   
1. PsiWin Installationsprogramm starten
2. Installieren von AGENDA2
3. Installieren von APPINFO
4. Installieren von PSCINFO
5. Installieren von MUSIC
6. Installieren von SYSRAM1
7. Install QUICKP
8. Start the program
9. Read the help file.

Für Anwender einer älteren QuickP-Version :
-------------------------------------------
QuickP 3.4 hat ein anderes Datenbankformat als die vorangegangenen QuickP-Versionen. Um die vorhandenen QuickP Dateien zu konvertieren, wird die Datei UpdTo34.OPO benötigt, welche unter c:\ oder d:\ zu finden ist (jenachdem, welches Laufwerk bei der Installation gewählt wurde). UpdTo34.OPO auf dem entsprechenden Laufwerk starten.

Konvertierungsinstruktionen:
Für registrierte Anwender: Bitte Username und Passwort nicht vergessen, dieses muss wieder eingegeben werden (am Besten vorher auf einen Zettel notieren).

0 Machen Sie ein backup Ihrer Projektumgebung (Projektordner, QuickP Datenbanken)
1) Starten Sie QuickP 3.4
2) Erstellen Sie eine neue Datei mit QuickP 3.4
3) Klicken Sie auf "Abbrechen" in der Dialogbox "Projekt hinzufügen"
4) Verlassen Sie QuickP 3.4
5) Starten Sie UpdTo34.opo
6) Wählen Sie Ihre vorangegangene Version von QuickP, tragen Sie Ihren alten QuickP Datenbank Dateinamen ein, und geben Sie den neuen QuickP Datenbanknamen ein. Drücken Sie "Enter"
7) Öffnen Sie QuickP 3.4 wieder und Sie haben Ihre bisherigen Daten im neuen Datenbankformat

Änderungen in Version 3.4:
--------------------------
* Diese Software arbeiten nun auf dem Psion Serie 5, 5mx, 5mxPRO, REVO, Serie 7 und Geofox one.

* 2 neue Listen wurden hinzugefügt: Eine Zeiteintrag-Liste und eine Trouble Tickets-Liste

* Die Dauer von Anlässen wurde ersetzt durch das Enddatum und Zeit

* Das Sortieren der Aufgaben wurde geändert

* Import und Export von Textdateien

* Neue Werkzeugleiste hinzugefügt

* "Ansicht Bestellungen": Aufgabenreferenz in dieser Liste wurde entfernt. Sie müssen die Aufgabenreferenz in Pensum in "Zeiteintrag" bearbeiten.

* Um das Programm zu beschleunigen, erscheint das Verknüpfungssymbol in den verschiedenen Listen nicht mehr

* Die Hilfedatei wurde gesamthaft überarbeitet und erweitert

* Sortieren: Alle Datenkolonnen können nun auf- oder absteigend sortiert werden. Dasselbe gilt für Prioritäten- und Aufgabenreferenzkolonne

* Kategorien können  nun für eine einzelne Position geändert werden mit dem 5. Knopf "Art setzen..."

Beseitigte Bugs:

* Sie werden nun gewarnt, wenn Sie versuchen, ein aktuelles Projekt zu löschen
* In der Kostenliste sind nun Kategorien verfügbar
* Stammverzeichnis für das Projektverzeichnis
* Anwenden von Filtern in Kategorien funktioniert nun
* FAX und MOBILE-Kolonnen für die Kontaktliste können nun gut sortiert werden.
