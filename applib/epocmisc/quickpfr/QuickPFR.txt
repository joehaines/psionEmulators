Installation de QuickP :
------------------------
0. Verifiez S.V.P que agenda2.opx, appinfo.opx, music.opx, sysram1.opx
   n'existent pas déjà dans c:\system\opx or d:\system\opx, si oui, supprimez les
   avant le lancement de cette installation (ou utilisez le desinstalleur dans le
   panneau de configuration)
1. Lancez l'installateur PsiWin
2. Installez AGENDA2
3. Installez APPINFO
4. Installez PSINFO
5. Installez MUSIC
6. Installez SYSRAM1
7. Installez QUICKP
8. Lancer le programme
9. Lisez le fichier d'aide.

Pour les anciens utilisateurs de QuickP :
---------------------------------------------------------
Le format de base de données de QuickP 3.4 est différent des versions antérieures de QuickP.
Pour convertir votre ancienne base de données QuickP vers la version 3.4,
utilisez S.V.P le programme UpdTo34.opo situé sur C:\ ou D:\ selon le choix du disque d'install.

Pour les utilisateurs enregistrés, veuillez S.V.P noter sur un papier,
votre nom d'utilisateur et votre mot de passe.

0) Effectuez tout d'abords un backup de votre environnement de projets
(dossiers et base de données QuickP)
1) Lancez QuickP 3.4
2) Créez un nouveau fichier vide avec QuickP 3.4
3) Cliquez Annuler dans la boite de création d'un nouveau projet.
4) Sortez de QuickP 3.4
5) Lancez UpdateQuickPTo33.opo
6) Selectionnez la version antérieure, entrer le chemin complet d'accès à l'ancienne
   base de données QuickP,
   entrer le chemin complet d'accès à la nouvelle base de données QuickP 3.4
   puis clicker sur Entrée.
7) Relancez QuickP 3.4, vous devez retrouver vos anciennes données dans le 
   nouveau format de base de données.
