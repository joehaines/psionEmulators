QuoteOn version 1.30

INSTALLATION 1 - The Easy Way

Double click on the SIS file and follow the instructions on Psions Installation file

INSTALLATION 2 - The Hard Way

1. Create a folder System\Apps\QuoteOn on your series 5

2. Copy the following files to that folder:

	QuoteOn.app
	QuoteOn.mbm
	QuoteOn.aif

3. Optionally copy the files below to the same folder:

	QuoteOn.hlp (Help file)

4. Create a subdirectory System\Apps\QuoteOn\Data

5. Copy the Quotes database (Quotes) to this folder on your Psion 

UPGRADING FROM EARLIER VERSIONS

This version of QuoteOn allows you to display quotes from several file all of which have to
be located in one directory. The default directory is System\Apps\QuoteOn\Data. If you wish to
use this directory copy your existing quote files to this folder. Otherwise select Preferences
from the Tools menu and set the data directory wherever you want.

REGISTRATION
