GP - Green Pages Version 1.05 (inc patch)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


For the Psion Series 5 (Untested on GeoFox)

30 April 1998

More details are available in the on-line help file included with the program.


Installation of Program
~~~~~~~~~~~~~~~~~~~~~~~


DELETE previous versions of GPUK (unless you have V1.04 in which case you can keep your folder.ini and code.ini).

Step 1.

Open your zip program and extract everything to an temporary directory.

Step 2.

Connect your Psion to your PC with PsiWin.

Step 3.

Create a directory on your Psion C:\System\Apps\GP and copy everything to there apart from this readme file (readme.txt) and the SysRAM1.opx.

Step 4.

If you don't already have it, copy the file SysRAM1.opx to your Psion.  It needs to go in C:\System\opx


Running GP
~~~~~~~~~~


The application can now be launched via the extras menu bar.

Version History
~~~~~~~~~~~~~~~

25 April 1998
V1.05 released.  Well, this version was produced before the official release of V1.04 so it's been released as an entire download.  This minor update improves the favourite database selector allowing up to 8 favourites to be launched quickly.  Help file updated.  Typo in Birthday fun spotted and removed!

21 April 1998
V1.04 released.  Got it wrong - another version released!  General tweaks made to speed things up/make it run better.  Birthday Fun added.  Changed name to Green Pages from Green Pages UK.  Help file updated.

16 April 1998
V1.03 released.  No more versions for a while!  Password option added to save there needing to be 2 versions (shareware and registered).  More categories added (for those of you with lots of databases).  The way they are configured also improved.  Conversions program made easier to read and help file updated (converted to English!).  This version is definitely the version to have.

V1.02 released.  Ctrl+t bug removed.  Help file revised.  Improved customisable directories feature (added a 'Create Folder' option).  Auto & Manual Compression options added. Favourite Database launcher improved allowing the user to specify the path of their favourite database (works well with UK Pocket Directory).  Conversions error bug fixed (Km/h -> M/s).  'File New' problem solved (GPUK would show up!).  Shareware version updated.
