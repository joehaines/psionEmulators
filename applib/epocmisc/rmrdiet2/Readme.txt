INTRODUCTION
------------
Welcome to our Diet/Weight/Exercise Tracking program for the EPOC Series of handheld computers.

As it stands, this Shareware version is fully functional but limits you to a few entries for each screen to enable you to try out the program before registering. Please note that registration does not involve reloading the program, but simply selecting the 'Register' menu option and typing in a registration code to release the 'lock'.

FILE DETAILS
------------
The archive file should contain the following files:

RMRDiet.sis      The program
RMRDietData.sis  Sample Food and Activity data files
Readme.txt       English Instructions

Once installed. you will see the program consists of the following essential files: (All in the \System\Apps\RMRDiet\ folder)

RMRDiet.app	- The main program file
RMRDiet.mbm	- The icons used within the program
RMRDiet.aif	- The icons used in the System screen
RMRDiet.rsc	- The Language resource file

And the following optional files which you may have installed and can be deleted later:

RMRDiet.hlp	- Help File

and in the C:\System\Apps\RMRDiet\

activity.dat     A database of activities and associated calories
food.dat         A database of foods and associated calories

To ensure the SIS file does not get too large, this contains only English versions of the Help file and any instructions. In most cases international versions of these files are available and can be downloaded from the appropriate national page at http://www.rmrsoft.com/ or by sending a disc to the UK address in the Help file. 

INSTALLATION
------------
To install the program simply double-click on the RMRDiet.sis file or select the "Install New Program" option in PsiWin (EPOC Install). 

We stongly recommend you then install the sample data files using RMRDietData.sis, as these will save you a lot of work in building your own.  If you are upgrading from a previous version then obviously you will NOT install these as they will overwrite your personal ones.

RUNNING THE PROGRAM
-------------------
Start the program by selecting 'Extras' from the Application bar and then selecting RMRDiet.
