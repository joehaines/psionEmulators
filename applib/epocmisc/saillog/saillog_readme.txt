INTRODUCTION
============
SAILLOG is a small utility primarily intended to 
track your personal sailing experience, based 
on the Royal Yachting Association's paper 
logbooks and qualification requirements. If you 
own your own boat, Saillog will also allow you 
to log the cumulative miles and engine hours 
of your boat, and gives a reminder when service 
intervals arise. If you charter your boat to a 
third party, these details can also be logged 
in the vessel record without affecting your 
personal sailing totals.

INSTALLATION
============

Below is a list if files supplied in the distribution ZIP
file (The file saillog10.zip) and the directories
they should be placed in after the installation.

saillog.sis                         SIS installation file
editor.zip                          Zipped SIS installation 
                                    file for Symbian editor
Saillog_readme.txt                  this file


If using Psiwin 2.x within windows then just click on the 
SAILLOG10.SIS file. The program will appear in the "normal" Extras 
bar after the installation. 
Alternatively, you may copy the SAILLOG10.SIS to your EPOC machine 
and double tab it. If installing from somewhere other than Windows 
then you will need to obtain INS_TE.EXE and install that on your 
EPOC32 machine. This will enable.SIS files to be decoded using the 
EPOC32 machine.

If you don´t have installed the Symbian Text editor on your machine 
and you want to use the new diary file function within saillog, you 
have also install the Editor installation file editor.sis, packed in 
the editor.zip file!


After installation you should have on your machine the following files:
* = C or D (or E for the series 7/ netBook users)
*:\system\apps\saillog\saillog.APP       Main application file.
*:\system\apps\saillog\saillog.AIF
*:\system\apps\saillog\saillog.MBM       graphics file
*:\system\apps\saillog\saillog.HLP       saillog help file.
*:\system\apps\saillog\saillog.rsc       saillog resource file 
c:\system\apps\saillog\saillog.ini       default configuration file
c:\system\apps\saillog\saillogx.ini      ini file with last used filename
*:\system\apps\saillog\efm.mbm           graphics support file

c:\saillog\exam.odb                       example database
c:\system\apps\saillog\exam.ini          example configuration file
c:\system\apps\saillog\exam_d.txt        example diary file

*:\system\opm\ini.opm                    ini.opm (support file)
*:\system\opm\iqgrid.opm                 iqgrid.opm (support file)
*:\system\opx\gprinter.opx               support OPX file for printing
*:\system\opx\nmpd.rsc                   support RSC file for NMPD module
*:\system\opl\nmpd.oxh                   support OHX file for NMPD module
*:\system\opl\nmpdconstants.oxh          support OHX file for NMPD module
*:\system\opm\readwrite.opm              support OPM file for READWRITE module


Except for the *.ini files, all other files may be located on the
C or D drive. The database files may be located in any (sub)directory. 
The directory "*:\saillog\ " is recommended to be the location for the 
database file.
