Readme file notes
------------------------------------------------------------
Please read the notes in the README.HTM file (also contained
in this distribution) before you install this software for
conditions of use and installation instructions.

The main README.HTM document is an HTML file so I recommend
you view it with your favourite web browser. However, if you
don't have one handy then you'll still be able to read it
with a normal text file viewer (such as the one you're
using to read this).

Unfortunately, README.HTM seems to gets truncated by
Opera for EPOC on my Series 5mx. It's fine in EPOC Web and
all PC browsers I've tried. I've removed some of the more
esoteric formatting but, for the moment, it still stops half-
way through. So, you may have to resort to a text viewer if 
Opera for EPOC is you're only browser. Sorry.

Thank you for trying Solun and good stargazing!
