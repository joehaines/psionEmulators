The Song Writer's And Poet's Handbook (SWAPH) is a
phonetic word finder which has a multitude of uses. Not
only will it find a rhyming match to your word, you can
also specify how many syllables to search for. Comes
complete with a 12,000 word dictionary!

#1 INSTALLATION:
================
To install SWAPH you will need the EPOC add/remove
installation shell which is supplied with PsiWin v2.1,
or an installed copy of Message Suite. You may obtain
these at the Psion website: http://www.psion.com/ or
download the EPOC add/remove program at my website:
http://www.i27.com/download/inst_te.zip Then:
                 
1. Extract "Swaph.SIS" and "Popup.SIS" from the zip
   archive. Running "Swaph.SIS" will initiate the EPOC
   add/remove program shell which will guide you through
   the installation. You must also install "Popup.SIS".
                 
2. Run SWAPH from the Extras bar.
                 
3. Run SWAPH from the Extras bar again and press SHIFT+CTRL+H
   to launch the help file - there is IMPORTANT information
   there so please make sure you read it.
                 
4. Enjoy! - Write a brilliant song, sell millions, and
   perhaps donate £50,000 to i27 ;-)
