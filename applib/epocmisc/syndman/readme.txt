=========================================
Software Installation Information
=========================================

This programme uses approximately 21K of disk memory
(46K if the Help file is loaded)

To install Syndicate Manager create a Syndmanager subdirectory off the
\system\APP directory on either the internal drive or plug
in memory card (the programme detects the drive used).
Load the following files into your Psion 5 into this
directory:

	     FILE       SIZE 
	Syndmanager.app 16K   	 The prog
	Synd Icons.mbm  1K       The toolbar icons
	synman.mbm     	1K       More toolbar icons
	startupscn.mbm  4K       The title screen
	Synd5.hlp       24K      The Help file (optional)


----------------------------------------------------
Overview
----------------------------------------------------

Syndicate Manager for Psion 5 is a programme to assist anyone
who handles a UK National Lottery Syndicate keep track
of the members numbers and check the draw.

The programme can handle up to 99 syndicate members (expandible)
and allows you to;
Add, delete and update member's numbers
Select random numbers generated by the Psion
Print out the members numbers
Enter the Lottery numbers for the programme to check
Show the statistics of the syndicate (how many of each
number 1-49 the syndicate holds)
Full Help within the programme

For detail on the programme open the synd5.hlp file
