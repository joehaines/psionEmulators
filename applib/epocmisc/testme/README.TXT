========================
TestMe V 5.5 for Epoc 32
========================

A very useful program that helps you learn things, such as French
vocabulary or Physics Equations. It can also act as a good database
program for things like Website addresses.

This Program is FREEWARE.

============
INSTALLATION
============

With this zip file you should have found a .SIS installation file. To
install Testme just open this file in Windows explorer.

If you get an "open with" dialog come up when you try and open the SIS
file then you must be using the older version of PsiWin (v2.01). To 
sort this out all you have to do is go to Psion's website 
(http://www.psion.com) and download the latest version of PsiWin
(Version 2.3.2). You should then be able to install as explained above.

Included in this SIS file are some optional example files. You will be
asked if you want to install them during the install process.
The examples are:
  "French Test" - A 2000 word French to English dictionary
  "German Test" - A 2000 word German to English dictionary
  "Physics Test" - Physics Equations required for British GCSEs

These files are put into the root of the C: drive if you allow the 
installation procedure to install the files.
