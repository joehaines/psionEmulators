What new and exciting features can I expect from Tickle Version 2
?????

  1) Improved file management.

This means smaller file sizes, and faster access when ticking and unticking.  Also, some progress bars when sorting and saving so you have some idea of how long it is going to take.  Note that Tickle now works more like Word or Sheet in terms of saving files, where you save the file when you exit.  Changes are kept in memory until you select Save or you exit Tickle.  This also means you can use the Revert option to revert to the saved version of your list.

   2) Advanced Sorting.
Sorting is faster, and you can now sort by more than one column.

   3) Manual Sorting Tools.
You can now use the Up and Down arrows on the toolbar to move entries in your list up and down manually as well as using the built in sorting methods.

   4) Multi-Ticker.
This feature allows you to tick / untick an entire column.
