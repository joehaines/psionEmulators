Components and Installation.
----------------------------
If you unzipped Trivopaedia OK, you should have ended up with 2
separate files. One will be this text file 8-)

The other is an SIS file.

(Experts)
If you know what a .SIS file is, just double-click on it in Windows
Explorer or tap on it on the EPOC palmtop and you'll be installed in no
time.

(Beginners)
If you *don't* know what a .SIS file is, this must be one of the very
first third party applications you've ever installed. Don't worry,
it's all quite painless.

Just double-click on the "trivia.sis" file to launch EPOC Install
on Windows and to complete the installation. If you use a Macintosh, 
then simply copy the SIS file over to your palmtop and double-tap on
it on the System screen.

-----
If all went well, you should now have a new Trivopaedia icon on your
Extras bar.
