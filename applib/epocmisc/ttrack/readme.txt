INTRODUCTION
------------
Welcome to TTrack a Time Tracking Utility. It may be used to keep track of your
daily working time. It is specially designed for those being on a certain target
time - which has to be invoiced to customers. This targets may be set and the
time invoiced may be recorded as well. You will allways keep track of the Ratio
between target and invoiced.

FILE DETAILS
------------
The archive file should contain the following:
- Readme.txt
- Liesmich.txt
- TTrackEn.SIS
- TTrackDe.SIS
The two SIS files ar for the different languages supported. TTrackEn for English
as anybody may have assumed anyhow and the other for German (DE)

Once installed you will find the following files in the App\TTrack directory:
TTrack.app
TTrack.aif
TTrack.mbm
TTrackIcon.mbm
TTrack.hlp

and you will find the
- GPrinter.opx 
installed as it is used for printouts. Thanks to twiddlebit here.

All files are either for the english or the German version whatever SIS file
you have used for installation.

INSTALLATION
------------
Chose the respective SIS file for the language you want an double-click on it.
The program allows to be installed on C: or on CF drives (D:)

RUNNING THE PROGRAM:
--------------------
Start the program by selecting it from the extras bar.
