VReader5 est un lecteur "vertical" pour les Psion Series5 et Geofox One.

Il permet la lecture de livres électroniques (eBooks) dans différents styles d'affichage et orientations, avec fonctions de recherche, signets et défilement automatique.

Les formats de fichiers supportés dans cette version sont les suivants:
- ASCII simple
- source OPL
- format "TCR" (principalement utilisé par l'application Reader pour le Series3)
- format "Aportis doc" (principalement utilisé sur le Palm Pilot)

Le fichier SIS inclus permet une installation en Anglais, Américain, Allemand, Suisse-Allemand, Italien, Norvégien, Finnois, Belge-Français, Suisse-Français, Français.
Si vous n'avez installé ni MessageSuite ni PsiWin, vous devrez d'abord vous procurer l'application INSTEXE.EXE depuis un site distribuant des programmes shareware/freeware pour le Psion pour pouvoir effectuer l'installation.

Le nom du traducteur de chaque version est affiché dans l'écran "A propos".

Veuillez noter que si vous utilisez un fichier pour un langage donné sur un Series5 équipé d'un clavier prévu pour une autre langue, vous devrez éditer une chaîne de caractères dans le fichier de messages pour pouvoir utiliser l'accès rapide aux signets. Référez-vous au fichier d'aide pour les détails.

L'aide n'est actuellement disponible qu'en Anglais et Français, son installation est optionnelle. Egalement en option lors de l'installation, un fichier prototype de messages ne vous sera nécessaire que si vous envisagez de traduire VReader5 dans une langue non actuellement supportée.
