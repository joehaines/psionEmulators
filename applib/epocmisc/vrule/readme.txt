4. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
To install the program simply double-click on the VRule.SIS file or select
the "Install New Program" option in PsiWin/EPOC Install.

To uninstall goto the Control Panel, tap the Add/Remove icon, select VRule
and finally press the Remove button.
