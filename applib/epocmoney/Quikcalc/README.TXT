This is update 1 of QuikCalc for EPOC 32, this release changes the following:
PsiSetup is no longer used
QuikCalc can now be installed to your D: drive (Compact Flash card)
Updates the help to work properly
several bugs were fixed.

To install
(You may have to use the preferences on your Series 5 to "Show" the System folder)
	
Using PsiWin 2 (or the forthcoming PsiMac) drag the following folders to the following locations:
QuikCalc --> drag to System\Apps
QIF --> drag to the root of your drive
OPX --> drag to your System folder
Drag the QCReadMe file anywhere you'd like, it's just a word document

Please install all folders to the same drive!

To start QuikCalc, choose it from your Extras bar...

********Quicken users*******
If you use Quicken on your desktop, you can export your 
account names and categories and have QuikCalc import them.
Do the following steps:
1. In this directory, you'll find a file named "Catlist.txt",
rename this file to "Catlist.def"
2. Launch Quicken on your desktop and export your account
names and categories (don't export transactions), name the
file "Catlist.txt" and place it in this directory.
3. Run PsiSetup, once installed, your account names will
attempt to be imported, if there are any error messages
read the readme file.  Please note, that this may not work
for all versions of Quicken.  If it fails, delete the
QuikCalc folder in your System folder on your Series 5.  
Next rename "Catlist.def" to "Catlist.txt" on your PC
and run PsiSetup again,
