Installing XChange
==================

1) Turn on your Series 5, press the System button, press the Menu key,
under 'Tools' select 'Preferences', make sure that the 'show system folder'
option is 'OK'. This will make the System folder visible on your Psion.

2) Create a new \SYSTEM\APPS\XChange folder on your C: drive

3) Copy all the files from the xchg11.zip file, except this readme file and,
into the new \SYSTEM\APPS\XCHANGE folder on your Psion.

4) The XChange icon will now appear on your Extra's Bar, ready to use.
