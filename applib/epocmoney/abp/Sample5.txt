An example of using investments with abp
----------------------------------------

The included file SAMPLE5.ABP shows how investments can be used in abp.  
It's entirely optional, but if you would like to experiment, then proceed as follows:

1. Install abp version 5.xx.

2. Copy SAMPLE5.ABP to your ER5 computer.

3. Highlight this file and press Enter.

4. Check the Menu option "Invest" to use the new investment options

5. When finished, you can go back to your previous data file by CTRL+O again
