Readme file for ABP euro conversion program version 1.03
========================================================

This program converts an ABP data file (version 5.xx) to the euro currency.  
Before using the program, please read the file abpeuronotes.html which gives 
detailed instructions for use.

This zip file contains the following:

1. abpeuroer5.opo (the Epoc Release 5 version)
2. abpeuroer6.opo (the Epoc Release 6 version)
3. abpeuronotes.html (instructions for use)
4. readme.txt (this file)

The Epoc Release 5 version is suitable for the Series 5, 5mx, MC218,
Revo, Mako, Series 7, netBook.

The Epoc Release 6 version is suitable for the Nokia 9210.

Installation
------------

Copy the relevant opo file to any directory on your Epoc computer.  Highlight
the file and press Enter to run the conversion.
