INTRODUCTION
------------
CodeCheck is a useful tool for anybody who is concerned about
being ripped off by unscrupulous companies, or for anyone who
runs a small business. You can use it to perform a number of
handy finance-related tasks, including:

CREDIT CARDS: Check whether a credit card number is valid.
MOBILE PHONES: Find out what network a mobile phone uses.
VAT NUMBERS: Test the validity of VAT registration numbers.

You can record the results of these tests in an optional log
file for future reference.


INSTALLATION
------------
CodeCheck should run on all Epoc-based palmtop computers, like
the Psion S5, 5mx, Revo, S7, and so forth.

To install the program simply double-click on the CODECHECK.SIS
icon, or select the "Install New Program" option in PsiSwin.

Run the program by selecting its icon from the 'Extras' bar.
