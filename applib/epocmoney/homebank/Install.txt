*************************************************************************************************

  Existing Beta users of Version 1.0 and below need to read this very carefully :

1. Installation for existing users only
:
	a. You need to delete your three *.mbm files and replace with the four new ones 
	b. You need to replace HomeBank.app, HomeBank.aif and HomeBank.hlp
	c. YOU MUST RUN Convert.opo WHICH CONVERTS YOUR EXISTING DATAFILES. IF YOU DO NOT THEN
	HOMEBANK WILL NOT RUN. Convert.opo may be run from any Directory be double tapping on it
	or pressing RETURN when highlighted. The conversion should take about a minute.
