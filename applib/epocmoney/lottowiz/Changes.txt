Version 2.10:
- added various items to the 'preferences' menu.  Compacting has been removed since this is now done automatically.
- you can now create an unlimited number of result files.  Useful if you are playing more than one Lottery.
- added the 'Show number coverage' item, that shows a graph of the numbers you cover with your recent playslip.
- you can print your playslip now.
- added an 'avoid sequences' feature in the random or optimiser number generation system for users who prefer to play numbers without sequences (like 21,22,23...)
- Incorporated a hidden feature you can access by pressing 'Tab'.
- simplified the 'sort entries' dialog and renamed it to 're-order datafiles'.
- incorporated the 'IQdrawPad' by RedFoot Software and Pocket IQ.  You can now scribble down Lottery results with your pen for faster input.
- LW now has a new registration system, based on the unique machine ID of each Psion.

Version 2.00:
- added the 'Optimiser', that will generate 'optimised' lines based on past Lottery draws. It uses various calculations like the positional analysis or adjacent numbers to find the best no's for the next draw.
- added the 'Adjacent' feature in the 'create new lines' menu item.  This feature will calculate the adjacent no's to the last draw result and then choose one of 6 different wheels to wheel these numbers.  Another good system to find winning no's.
- added the completely new menu item 'Game optimiser' where you can store or edit previous draw results that later can be used by the 'Optimiser' or the 'Adjacent' no's wheels.
- added a 'Statistical analysis'. This will create some graphs on number appearances or lets you choose to analyse the appearance and position of one single number in past draws.
- you can now generate up to 100 lines.
- when creating new lines you can now choose if you want to keep, to be asked to delete or just delete your old lines.
- added various items to the 'Preferences' menu that allows you to adjust the program to your liking.
- added new 'sort' options.
- added a new item in the 'Setup bank account' menu, where you can input the number of lines you usually play which makes new ticket entries even faster.
- added menu item 'Information' that gives you some info on your datafiles.
- added menu item 'Compress', where you can compress your data files.
- renamed 'boards' to lines for non UK-lottery players.
- various small interface changes.
