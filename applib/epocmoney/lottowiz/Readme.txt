Description

Bankroll management is an essential element of gambling. LottoWizard is a program that will provide you with a lot of useful information on how you are doing with your National Lottery. It basically is a gambling money management system but also includes the 'Optimiser' that will calculate the best numbers for the next draw based on past drawn no's and various other powerful number generating tools. The program also provides statistics and graphs on past draws and your chosen numbers.


Installation

Unzip the files and install the program using the included 'lottowiz.sis' file.

Pressing the ‘Extra’s bar’ should now reveal the Icon for 'LottoWizard'.

A detailed information on every feature of the program can be found in the program's online help which will be installed on your Psion together with the application.
