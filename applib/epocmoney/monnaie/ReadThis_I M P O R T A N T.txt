1. Important for **registered users** of versions older
   than 5.05:

  Your registration code is not valid for this version
  of Monnaie. To receive a free new code, send an
  e-mail to monnaie@kylom.com, with your name and the
  unique Id number of your machine. You can find this
  number from the main screen of your machine with the
  command Menu > Information > Machine. An Id number
  looks like this: 1000118A-EDD5FEF4


2. If you install Monnaie on a Series 5 "Classic"
   (Epoc Release 3):

- in all cases you must use the included file named
  monnaie_er3.opx:
  a. first install Monnaie with the file Monnaie.sis
  a. copy the file monnaie_er3.opx to the folder
     \system\opx\ of your machine, which already contains
     a file named Monnaie.opx
  b. delete the existing file Monnaie.opx
  c. rename the file monnaie_er3.opx to Monnaie.opx

- if you have not installed Message Suite on your machine,
  you will also need to copy the included files Insock.dll
  and NifMan.dll to a folder \system\libs\. Note that
  Monnaie will work normally, but its command "Import from
  Internet" will not...
