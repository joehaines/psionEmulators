Monnaie
=======

The simplest to use, yet the most powerful and most
useful currency conversion application for Psion Series 5
and most Epoc machines: 5mx, revo, Series 7, Geofox One,...

Shareware proposed by Kylom

E-mail          : Guillaume@kylom.com
Homepage        : http://www.kylom.com
Latest version  : v.5.05


Content:
========
- Monnaie.SIS is the installation file for the application.
- changes.txt describes all changes since the older versions.



Installation:
=============
To install Monnaie, double-click on the file Monnaie.SIS on
your PC (if PsiWin 2.x is installed). Or double-click Monnaie.SIS
on the Series 5 (if there is an Add/Remove icon in the Control
panel).

A database with 66 currencies is proposed for installation. If you
had already created your own base with a previous version of Monnaie
answer <No>, when the question is asked...



Operation:
==========
Start Monnaie like any other application, from the Extras toolbar.
Key in an amount and tap a the currency on the list. That's all!

See the online Help for all the other functions.
