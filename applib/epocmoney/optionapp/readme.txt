
OptionApp Version 1.0 for Psion REVO, 01/11/2000

Abstract:
=========
This tool implements the Black-Scholes formula for Put and Call options with
a dividend and the Binomial algorithm for American and European options without dividend.  
This Black-Scholes algorithm is taken from the spreadsheets available at www.numa.com.
The tool calculates price, premium, delta, gamma, theta, vega, gearing and many other 
parameters and allows to depict the results graphically.


Installation Instructions:
==========================
Create a directory /System/Apps/OptionApp
Copy OptionApp.mbm, OptionApp.aif, OptionApp.app,OptionApp.ini and OptionApp.hlp to your REVO.
Double-click on the "Options" icon in the Extras bar to start OptionApp.
