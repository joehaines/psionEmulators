1. Important for registered users of versions older
than 5.13:

Your registration code is not valid for this version
of Porfolio. To receive a free new code, send an
e-mail to porfolio@kylom.com, with your name and the
unique Id number of your machine. You can find this
number from the main screen of your machine with the
command Menu > Information > Machine. An Id number
looks like this: 1000118A-EDD5FEF4

If you request your new code BEFORE installing this
new version, you will avoid any interruption in the
use of Porfolio...

If you have ALREADY installed and registered version
5.13 or later, you do NOT need a new code. You can
install this version "on top" of the existing one, 
without deleting any file.



2. Installation on a Series 5 "Classic":

If the program does not start and issues a message
like "...\Pktfolio.OPX  file does not exist", you will
have to copy the included files NifMan.dll and
Insock.dll to a folder d:\system\libs\ or
c:\system\libs\ (if you do not see the folder \system\,
use the command Menu > Tools > Preferences from the
main screen and tick "show System folder").

It may be necessary to use also the file PktfolioER3.opx:
- copy this file to the folder \system\opx\ where a file
  Pktfolio.opx already exists
- delete the existing file Pktfolio.opx
- rename PktfolioER3.opx to Pktfolio.opx
