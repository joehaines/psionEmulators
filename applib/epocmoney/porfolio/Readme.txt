Porfolio for Epoc
=================

Management of a portfolio of shares on a Psion Series 5,
5mx, revo, Series 7 or GeoFOX One.

Installation:
=============

This zip archive includes the following files:

- Porfolio.SIS
- Changes.txt
- ReadMe.txt

Major changes from previous versions are summarized in Changes.txt.

The installation file for the programme is Porfolio.SIS.

There are two ways of using a **.SIS installation file:
- from a PC (if PsiWin 2.x is installed), double-click on the file
  **.SIS (this can be done from the WinZip window, even without
  unzipping the **.SIS file)
- from the Series 5 itself (if there is an Add/Remove icon in the
  Control panel): copy the **.SIS file anywhere on your Series 5 and
  double-tap it.

The advantage of the first method is that it requires the minimum
number of actions from the user. The disadvantage is that it stops
all running applications on the Series 5 before installing the new
files.

The advantage of the second method is that it does not close all
applications on the Series 5. The disadvantage is that it requires
unzipping the **.SIS file and copying it to the Series 5... 



Startup:
========

After a correct installation, you should have the following files in
the following folders on your machine:

\System\Apps\PorFolio\PorFolio.aif
\System\Apps\PorFolio\PorFolio.app
\System\Apps\PorFolio\PorFolio.hlp
\System\Apps\PorFolio\PorfOnce.opo
\System\Opx\GPrinter.opx
\System\Opx\SysRAM1.opx
\System\Opx\Dbutils.opx
\system\Opx\PktFolio.opx
\system\Opx\PktFolio.rsc
\system\Opx\Kylom.mbm
\system\Opx\KylomUtils.opx
\System\Opm\pc_bar.opm

When the installation is complete, you will find a Porfolio icon in the
Extras bar. Tap on it to start Porfolio. You will be asked to name your
home currency. Answer with 3 letters (eg DEM, FRF, USD,...) and press
Enter.

Press Ctrl+H to open the Help data file, which contains a very
comprehensive description of the application. Do not hesitate to enter
any keyword you fancy... To return to the application, press Ctrl+B, if
you want to keep Help running in the background, or Ctrl+E to stop it.

Note that after the first run of Porfolio, the file PorfOnce.opo has been
automatically deleted, and a new sub-folder has been created:
\System\Apps\Porfolio\Data\



Note for users of a previous version:
=====================================
From version 5.4, all data are moved to a \System\Apps\Porfolio\Data
folder. The move is made automatically by Porfolio, and the folder
\Data\Porfolio is deleted. If you had put other files into
\Data\Porfolio\, you will find them in \System\Apps\Porfolio\Data.
