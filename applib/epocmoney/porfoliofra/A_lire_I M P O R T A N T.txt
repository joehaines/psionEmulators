1. Important pour les utilisateurs enregistrés 
   de versions antérieures à 5.13:

Votre code d'enregistrement n'est plus valable pour
cette version. Vous pouvez obtenir gratuitement un
nouveau code en écrivant à porfolio@kylom.com un
e-mail ou vous indiquerez votre nom d'utilisateur
enregistré et le numéro d'identification de votre
machine. On peut lire ce numéro à partir du menu
dans l'écran principal du Psion: Menu > Information
> Machine. Un numéro d'identification a la forme
1000118A-EDD5FEF4

Si vous demandez votre code AVANT d'installer cette
nouvelle version, vous éviterez toute discontinuité
dans l'utilisation de Porfolio...


2. Installation sur un Series 5 "Classic":

Si le programme ne démarre pas et bloque sur un
message "...PktFolio.OPX le fichier n'existe pas", vous
devrez copier les fichiers NifMan.dll et Insock.dll
dans un répertoire d:\system\libs\ ou c:\system\libs\
(si vous ne voyez pas le répertoire \system\, utilisez
la commande Menu > Outils > Preferences depuis l'écran
principal, et cochez "voir le dossier System").

Il peut être nécessaire d'utiliser aussi le fichier
joint PktFolioER3.opx:
- copier ce fichier dans le répertoire \system\opx\
  où réside le fichier pktfolio.opx
- supprimer le fichier pktfolio.opx existant
- renommer PktFolioER3.opx en pktfolio.opx
