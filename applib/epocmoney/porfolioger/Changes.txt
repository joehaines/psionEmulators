Version 5.4:
- the promised module for handling the "Euro big bang"
  will come with a later version... but before the D Day!
- the layout of files and icons has been completely
  reviewed: all data files will now be in a
  \system\apps\porfolio\data\ folder, saving the need
  for a \data\ folder in the main system screen. Also
  the default folder for account icons can now be
  selected by the user, and modified at any time with
  the (more) "Preferences" command.
- the upgrade from an earlier version is now more
  user friendly, and the application file is smaller: the
  application is distributed with one single conversion
  program called PorfOnce.opo, which is called by
  Porfolio once only, and then deleted. PorfOnce.opo
  takes care of all database structure changes from any
  previous version.
- new hot key: <Shift+Enter> when a list of shares is
  displayed (all accounts by share, performance,..) shows
  a selector with the list of the accounts, where
  transactions on the highlighted share have been
  recorded. The number of shares presently in hand is
  shown for each account. Note: this hot key has the
  same effect in Chart mode.
- "bug" fixed: commas are now forbidden in all names.
- bug fixed: <Tab> selected the wrong chart in the
  "all shares by category" summary.
