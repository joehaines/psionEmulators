1. Wichtige Information für registrierte Benutzer
von älteren Versionen als 5.13:

Ihr Registrierungscode ist für diese Version von
Porfolio nicht mehr gültig. Um einen neuen Code
zu erhalten (gratis), senden Sie eine e-mail an
porfolio@kylom.com. Geben Sie Ihren Namen und Ihre
Maschinen-ID Nummer an. Sie finden diese Nummer
unter Menü > Information > Computer. Eine ID-Nummer
sieht so aus: 1000118A-EDD5FEF4

Wenn Sie Ihren neuen Code anfordern BEVOR Sie diese
neue Version installieren, vermeiden Sie jede
Unterbrechung in der Benutzung von Porfolio...

2. Installation on a Series 5 "Classic":

If the program does not start and issues a message
like "...\Pktfolio.OPX  file does not exist", you will
have to copy the included files NifMan.dll and
Insock.dll to a folder d:\system\libs\ or
c:\system\libs\ (if you do not see the folder \system\,
use the command Menu > Tools > Preferences from the
main screen and tick "show System folder").
