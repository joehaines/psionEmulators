WARUM WURDE PSIBANK ENTWICKELT

PsiBank ist ein einfacher und leicht zu bedienender Bankkontenmanager. Es ist aus einem guten Grund einfach geblieben: Viele andere Programme protzen mit mächtigen Funktionen, wie Mehrwertsteuer-Handhabung, Budgetierung etc., aber es gab keinen einfachen Bankkontenmanager, ich programmierte einen.


ÜBERSICHT

PsiBank bietet Ihnen folgende Feature an:

- Unterstützung für bis zu 5 Gruppen, die jeweils maximal 15 Konten enthalten dürfen;
- Unterstützung für bis zu 20 Kategorien;
- eine Kategorienansicht, die die Einnahmen und Ausgaben, nach Kategorien unterteilt, zeigt;
- eine Bilanzansicht, die die Bilanzen von allen Konten in der gegenwärtigen Gruppe zeigt;
- eine Bilanzansicht, die die Bilanz eines Kontos über einen definierten Zeitraum, zeigt;
- eine Eingang/Ausgang Grafik, wobei man Einnahmen und Ausgaben graphisch darstellt;
- Zahlung von Daueraufträgen;
- eine Import/Export Funktion;
- Druckmöglichkeit;
- Passwortschutz mit verschiedenen Sicherheitsstufen;


INSTALLATION

1) Stellen sie sicher, daß Sie Zugriff auf den \System-Ordner am Systemschirm haben (siehe Einstellungen).

2) Wechseln Sie zum Ordner \System\Apps und erstellen sie ein neues Verzeichnis "PsiBank".

3) Kopieren Sie alle Dateien, außer dieser, ins \System\Apps\Psibank-Verzeichnis. Sie können "Psibank.hlp" weglassen, wenn Sie keine Hilfe benötigen, ebenso kann "Psibank.ovl" weggelassen werden, wenn Sie nicht die Import/Export Funktion benutzen wollen.

4) Benützer von PsiBank für die Serie 3a/3c können die Dateien des "BANK"-Verzeichnisses in das PsiBank Verzeichnis des Serie 5 kopieren, dies ist allerdings nur möglich, wenn Sie Version 2.0 für die Serie 3a/3c benutzt haben. Machen Sie bitte ein Upgrade zu dieser Version, vor dem Transfer zu Ihrem Serie 5.


ERSTE SCHRITTE

Das erste Mal, wenn Sie PsiBank starten, werden Sie gebeten, Ihre Kontendaten und - wenn Sie es wünschen - auch die Kategorien zu definieren. Anschließend werden die Präferenzen abgefragt. Diese Präferenzen werden für die meisten von ihnen richtig voreingestellt sein, überprüfen Sie sie aber bitte trotzdem.

Nachfolgend werden Sie nach einigen Internationalen Einstellungen gefragt und es kann los gehen!!


BUCHUNGSEINGABE

Um Buchungen einzugeben, können Sie Hotkeys benutzen, wie sie im Menü "Buchung" erscheinen. 
Diese sind: Strg-N für eine neue Buchung, Strg-T für einen Übertrag, Strg-U um eine Buchung zu erneuern, und Strg-D um eine Buchung zu löschen.

Sie können aber auch die Eingabe-Taste benutzen, um eine Buchung zu aktualisieren. Wenn eine leere Zeile gewählt ist, wird die Eingabe-Taste eine Buchung hinzufügen. Außerdem entfernt die Entf-Taste Buchungen genauso wie der Hotkey Strg-D.
In den Präferenzen können Sie einstellen, ob Sie Entf als Hotkey verwenden möchten, oder nicht. Verwenden Sie diese Option nicht, wenn Sie Angst haben, Buchungen möglicherweise zu leicht zu löschen.


HANDHABUNG VON DAUERAUFTRÄGEN

Daueraufträge sind Buchungen, die oft vorkommen, regulär aber auch unregelmäßig. Diese Definition ist hier umfassender als in meisten Bankkontenmanagern. 

Buchungen, von denen Sie wissen, daß Sie sie immer wieder in PsiBank bezahlen müssen, können hier definiert werden. Dazu tun Sie folgendes:

Verwenden Sie Umschalt-Strg-S, um Daueraufträge zu definieren. Drücken Sie Enter auf einer leeren Zeile, um einen neuen Dauerauftrag zu definieren. Zuallererst geben Sie das Datum ein, wann der Dauerauftrag üblicherweise gezahlt werden soll. Dann geben Sie die Beschreibung ein, den Betrag, den Typ (Soll/Haben), die Kategorie und das Konto. 

Dann geben Sie die Anzahl von Tagen ein, bevor PsiBank Sie an die Zahlung eines Dauerauftrags erinnern soll, und die Anzahl der Tage im Voraus, an denen PsiBank Sie über den bevorstehenden Dauerauftrag warnen soll. (Sie können eine Zahl zwischen 0 und 14 eingeben.)

Der letzte Eintrag, den Sie eingeben, betrifft die Monate, in denen der Dauerauftrag gezahlt werden sollte. Wählen sie "ja" für jeden Monat, indem der Dauerauftrag gültig sein soll.

Wenn Sie Daueraufträge eingegeben haben, wird PsiBank bei jedem Start eine Überprüfung ausführen. Wenn es an der Zeit ist, Sie zu bezahlen, oder Sie über offene Daueraufträge zu warnen, werden Sie darüber rechtzeitig informiert werden. Sie können dann zu dieser Zeit den Dauerauftrag bezahlen, oder die Bezahlung des Dauerauftrages auf einen späteren Zeitpunkt verschieben.

Um beim vorgegebenen Zeitpunkt einen Dauerauftrag zu bezahlen, benutzen Sie Umschalt-Strg-S und wählen Sie den entsprechenden Dauerauftrag. Dann drücken Sie Strg-P, um diesen Dauerauftrag in Ihre Buchungsliste einzufügen.


IMPORT/EXPORT

Die Import Funktion für "Komma begrenzte" Daten können sie unter folgenden Umständen benützen:
- der Betrag muß einen Dezimalpunkt beinhalten, aber kein Komma, da das das Trennzeichen ist.
- Beschreibungen dürfen nur dann ein Komma enthalten, wenn die Beschreibung unter Anführungszeichen gesetzt ist.

Neben einer Dateibezeichnung und einem Datumsbereich werden sie auch noch um die Felder für die Beschreibung, Kategorie und Betrag gefragt. Wenn Sie diese Werte akzeptieren, werden sie für eine spätere Verwendung gespeichert. Das heißt, daß sie das nächste Mal als Vorgaben benutzt werden, wenn Sie eine Datei importieren möchten.

Die Export Funktion erzeugt eine "Komma begrenzte" Datei. Ein Dezimalpunkt wird im Betrag benutzt, Beschreibungen werden in Anführungszeichen gesetzt. Dateien zu exportieren ist sehr einfach: einfach die Dateibezeichnung eingeben, den Datumsbereich, und ob Kategorien und Bilanzen ebenso in der Datei abgespeichert werden sollen, oder nicht. 


FUNKTIONEN

Datei:

- Öffne Gruppe			Kontengruppe zum bearbeiten auswählen.
- Konto verschieben		Verschiebt das Konto zu einer anderen Gruppe.
- Konto öffnen			Konto zum bearbeiten auswählen.
- Konto verkleinern		Löscht alle Buchungen vor einem definierten Datum.
- Konto Information		Zeigt Beschreibung, volle Dateibezeichnung, Dateilänge und 				die Anzahl von Buchungen.
- Beenden			Beendet PsiBank.

Buchung:

- Neu				Erstellt neue Buchung.
- Übertrag			Verschiebt Buchung in ein anderes Konto.
- Erneuern			Erneuert eine Buchung.
- Löschen			Löscht eine Buchung.
- Suchen			Zeigt alle Buchungen, die Ihren Suchkriterien entsprechen.
- Gehe zu...			Geht zur Buchung eines bestimmten Datums.

Ansicht:

- Kategorien			Kategorienansicht im Detail, wo Sie Ihr Geld ausgeben und 				von wo sie es bekommen.
- Bilanz ab...			Zeigt die Bilanz aller Konten.
- Bilanz Grafik			Erstellt ein Diagramm der Bilanzen über 1, 3, 6 oder 12 				Monate.
- Eing/Ausg Grafik		Zeigt Grafik der Ein- und Ausgänge.
- Drucken			Druckt alle Einträge im gewählten Zeitraum.


Einstellungen:

- Gruppen			Gruppen hinzufügen, ersetzen oder löschen.
- Konten			Konten hinzufügen, ersetzen oder löschen.
- Kategorien			Kategorien hinzufügen, ersetzen oder löschen.
- Daueraufträge			Daueraufträge hinzufügen, ersetzen oder löschen.
- Import & Export		Allgemeine Import und Export Einstellungen.
- Präferenzen			Allgemeine PsiBank Einstellungen.
- International			Einstellungen für Datums- und Währungsformate.
- Passwort			Passwort aktivieren oder ändern.


Extras:

- Import			Importiert eine "Komma begrenzte" Datei.
- Export			Erzeugt eine "Komma begrenzte" Export Datei.
- Über PsiBank			Zeigt Programm Informationen.
- PsiBank Hilfe			Zeigt die PsiBank Hilfe Datei an.



Die folgenden Hotkeys können benutzt werden:

- Enter				Wenn die Markierung auf einer Buchung ist, wird der 					gegenwärtige Eintrag aktualisiert.
				Wenn die Markierung auf einer leeren Zeile ist, wird ein 				neuer Eintrag geöffnet.

- Tab				Wenn die Markierung auf einer leeren Zeile ist, aktivieren 				Sie einen Übertragung.

- Entf				Löscht die markierte Buchung. (Abhängig von der Einstellung 				in den Präferenzen)
