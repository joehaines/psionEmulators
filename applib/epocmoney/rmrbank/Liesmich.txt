EINFÜHRUNG

Willkommen zu meinem Finanzverwaltungs Programm für den EPOC. 

So wie sie das Programm hier vorfinden, ist diese Shareware Version völlig funktionsfähig, d.h. es wurden keinerlei Funktionen deaktiviert. Jedoch erlaubt Ihnen die Shareware Version nur eine bgrenzte Zahl von Einträgen, als da wären : 3 Konten, 5 Daueraufträge, 5 Budgetkategorien, 5 Aktien und 5 Räume für das Hausinventar etc.  Wenn Sie sich registrieren lassen, können sie den vollen Umfang des Programms nutzen : 20 Konten, 50 Daueraufträge in jeder Gruppe, 50 Budgetkategorien, 50 Aktien und 20 Räume. Um das Programm zu registrieren brauchen sie es nicht erneut zu installieren; Sie müssen lediglich einen Registrierungscode eingeben um das Programm "aufzuschließen".

Erweiterte Funktionen

Das Erweiterte Funktionen Modul 1 bietet Ihnen die folgenden erweiterten Funktionen :

    + Einen "Vorschau" Modus, für eine Vorhersage der zukünftigen Entwicklung Ihrer Finanzen.
    + Standard Buchungen, zum Hinzufügen von wiederkehrenden, vordefinierten Einträgen
    + Eine "Wiederhole letzte Buchung" Funktion
    + Eine pull down Seite mit Kontodetails, auf der sie z.b. Ihre Kontonummer speichern können.
    + Eine automatische Nummerierung ( Hauptsächlich für Schecks, in meinem Fall aber z.B. für
      Registrierungen )
    + Eine "Finden" Funktion im Archiv Bildschirm
    + Ein konfigurierbares "Popup" Menü für die Ansicht Schaltfläche auf der Symbolleiste

Das Erweiterte Funktionen Modul 2 bietet Ihnen die folgenden erweiterten Funktionen :

    + Eine Export- und Importfunktion für zahlreiche Formate, einschließlich Quicken
    + Eine "Rechnungen bezahlen" Funktion, gleich dem, welches in MS Money Verwendung findet.
    + Möglichkeit einer Buchung einen Steuersatz zuzuordnen (Mwst., VAT, etc. )
    + Pull down Infofenster, daß Auskunft über die Einstellungen der Gruppe, oder Konten gibt

Starten Sie das Programm, indem, Sie "Extras" aus der Programmsymbolleiste und dann "RMRBank" auswählen.

Wenn Sie die Herausforderung lieben, können Sie alles über das Programm durch Ausprobieren herausfinden und die Effekte der verschieden MENÜS und des Drückens von <ENTER>, <ENTF>, <TAB>, oder <ESC>, in den verschieden Ansichten, oder auch das "Tippen" mit dem Stift in verschieden Bereiche beobachten.

WICHTIGE PUNKTE

Bitte beachten Sie fogende Punkte :

1.    Die Konfigurationsdatei (Accounts.ini) und Registrierungsdetails (Accounts.reg) werden im selben Verzeichnis wie die Programmdateien gespeichert (\System\Apps\RMRBank\), also seien Sie nicht überrascht, wenn sie Konfigurationsdaten und Ihre Registrierung verlieren, wenn sie diese Dateien löschen.

2.    Bitte ändern sie nicht den Namen einer Gruppe von der System Ansicht aus, indem sie lediglich die Dokument Datei ändern. Den Namen, welchen sie für eine Gruppe benutzen, wird für alle Daten benutzt, nicht nur für diejenigen im Dokument Ordner. Wenn Sie eine Gruppe umbenennen wollen, dann benutzen sie einfach den "Sichern als" Befehl in RMRBank selbst. Danach wechseln sie zu der neu gespeicherten Gruppe und benutzen dann den "Lösche Gruppe" Befehl, um das Original los zu werden.

3.    Ich habe eine BACKUP und RESTORE option (<Shift+Strg+B> und <Shift+Strg+R> in der Konten Ansicht ) eingebaut, um eine klomplette Kopie all´ Ihrer Daten zu gewährleisten.
