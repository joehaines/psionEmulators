INTRODUCTION

Bienvenue dans mon programme de Gestion de Compte Personnel pour le EPOC 32. 

Tel qu’il est, cette version ‘Shareware’ (ou Logiciel-à participation-s'il-plait..) est complète, sans fonctions désactivées, mais permet seulement un nombre limité d’entrées, par exemple 3 Comptes, 5 Prélèvements automatiques, 5 Catégories de Budget, 5 Titres Boursiers et 5 pièces pour l’inventaire de la maison etc.  L’enregistrement vous autorisera accès à des valeurs plus réalistes, telles que 20 Comptes, 50 Prélèvements automatiques, 50 Catégories de Budget, 50 Titres Boursiers et 20 pièces. Notez cependant que l’enregistrement ne signifie pas qu’il faille recharger le programme, mais le simple fait de taper le code d’enregistrement suffit à lever les ‘limitations’.

Le Module 1 d’Options avancées ajoute les fonctions suivantes :

·	Un mode ‘Visualisation Future’ pour prédire l’état de vos finances dans le futur.
·	Des Transactions par Défaut pour ajouter régulièrement des entrées prédéterminées.
·	Une page complète de Détails sur le Compte où vous pourrez stocker des choses comme les numéros de comptes.
·	Numérotation automatique (surtout pour les chèques, ou dans mon cas vos enregistrements !)
·	Une fonction ‘Trouver’ dans les écrans d’Archives.
·	Un menu configurable pour le bouton ‘Vue’ de la Barre d’Outils.

Le Module 2 d’Options avancées ajoute les fonctions suivantes :

·	Exportation et Importation dans différents formats, y compris Quicken.
·	Une option ‘Payer factures’, semblable à celle utilisée dans MS Money.
·	Possibilité d’associer des taxes (TVA, autres..) aux transactions.
·	Fenêtres d’Info donnant les paramètres de chaque Groupe ou Compte.

INSTALLATION

Si vous faites une mise Ó jour depuis S5Bank (ou GeoBank) vous DEVEZ copie le fichier RMRBank.sis sur votre machine EPOC et lancer l'installation sur votre machine EPOC. Si vous installez depuis le PC, les anciennes versions ne seront pas ÚcrasÚes.  Assurez-vous aussi que la langue choisie dans l'option 'Préférences' de l'icône 'Ajout./Suppr.' du Panneau de Configuration est correcte, et cochez la case 'Supprimer le fichier d'installation SIS.

Pour installer le programme, double-cliquez simplement sur le fichier RMRBank.sis.

Pour éviter que le fichier de distribution .sis ne soit trop important, il ne contient que la version anglaise du fichier d'aide et des instructions.  Dans la plupart des cas, les versions internationales de ces fichiers sont disponibles depuis leurs pages à http://www.rmrsoft.com/  ou en envoyant une disquette à l'adresse anglaise indiquée dans le fichier d'aide.

LANCER LE PROGRAMME

Lancer le programme via la touche ‘Extras’ de la Barre d’Applications, et désignez ensuite ‘RMRBank’.

Si le challenge vous amuse, vous pouvez apprendre tout ce qu’il vous faut savoir à propos de ce programme en ‘jouant avec’, en testant l’effet de chaque option des Menus, ainsi que l’effet des touches <ENTRÉE>, <EFFACER>, <TAB> ou <ESC> dans chaque écran de même que ce qui se passe en ‘tapotant’ directement différentes parties de l’écran avec le ‘stylo-Psion’ et enfin en lisant le fichier d’Aide. Mais de toute façon, SVP SVP SVP au moins lisez le reste de ce premier fichier d’abord pour les informations essentielles. Mon conseil est ensuite d’utiliser la partie 1, Apprentissage, qui vous familiarisera avec les capacités basiques du programme. Si vous le faîtes ‘à l’aveuglette’ et que vous rencontrez des problèmes, s’il vous plaît lisez le reste des instructions avant de me demander de l’aide. En particulier, si vous cherchez une fonction particulière, elle est probablement là, quelque part, aussi lisez les instructions avant de me la suggérer !

Tous les commentaires et, bien sûr, les enregistrements sont absolument bienvenus.

POINTS IMPORTANTS

Notez les points suivants :

1.	Le fichier de configuration (Accounts.ini) et celui d’enregistrement (Accounts.reg) sont sauvegardés dans le même répertoire que les fichiers d’application (C:\System\Apps\RMRBank\), aussi ne soyez pas surpris de perdre ces informations et l’enregistrement si vous effacez ces fichiers.

2.	SVP, n’essayez pas de changer le nom d’un groupe depuis l’écran système en renommant un fichier. Le titre donné à un groupe est utilisé par tous les fichiers de données, pas uniquement dans le répertoire ‘Documents’. Si vous voulez renommer un groupe, utilisez la commande ‘Sauvez sous’ à l’intérieur du programme pour sauver le groupe sous un nouveau nom, ouvrir ce nouveau groupe et ensuite utilisez la commande ‘Effacer un Groupe’ pour virer l’original.

3.	J’ai inclus une option de SAUVEGARDE et de RESAURATION (<Maj+Ctrl+B> et <Maj+Ctrl+R> dans l’écran principal de Comptes. Pour vous permettre d’avoir une copie complète de vos fichiers de données ailleurs dans votre système. Bien qu’il n’y ait eu que 4 cas connus de perte totale de données avec S3ABANK, je n’ai pas l’arrogance de dire que le portage vers un système 32bit a été parfait et qu’il ne reste pas un ‘bug’ planqué quelque part attendant de piéger un non-prévenu. Personnellement j’utilise cette option tous les 15 jours, de même que je fais une sauvegarde de mon PC ! Je pense réellement que le programme est ‘sain’, mais je ne lui fais jamais complètement confiance. Simplement, si vous perdez des données et que vous n’avez pas fait de sauvegarde d’aucune sorte, n’attendez aucune sympathie de ma part !
