INTRODUCTION
------------
Welcome to our Personal Accounts Suite for the EPOC series of computers

As it stands, this Shareware version is fully-working with no disabled functions, but will allow only a limited number of entries, such as 3 Accounts, 5 Standing Orders, 5 Budget Categories, 5 Shares and 5 Rooms for the Home Inventory etc.  Registration will give you more realistic values, such as 20 Accounts and 50 Standing Orders in each Group, and 50 Budget Items, 50 Shares and 20 Rooms.  Please note that registration does not involve reloading the program, but simply typing in a registration code to release the 'lock'.

If you have any problems, first visit the Frequently Asked Questions (FAQ) section of our Home Page (www.rmrsoft.com) and if that doesn't answer the question then contact us at support@rmrsoft.com. 

Advanced Features

The Advanced Options Module 1 offers you the following additional functions:

	A 'Look Ahead' mode to predict the state of your finances sometime in the future.
	Default Transactions for adding regular, pre-defined entries.
    	A 'Last Transaction Repeat' function
    	A pull-down page of Account details where you can store such things as Account numbers.
    	Automatic numbering (primarily for cheques (checks), or in our case registrations!)
	A 'Find' function in the Archive screens.
	A configurable 'popup' menu for the Toolbar 'View' button.

The Advanced Options Module 2 offers you the following additional functions:

	Export and Import function in various formats, including Quicken.
	A 'Pay Bills' option, similar to that used in MS Money.
	Ability to allocate tax (VAT, GST etc) to transactions.
	Pull-down Info windows giving settings for each Group and Account.

INSTALLATION
------------
If you are upgrading from S5Bank (or GeoBank) you MUST first  copy the RMRBank.sis file to the EPOC Platform (Series 5, GeoFox etc) and run the installation from there.  If you install directly from the PC the previous program will not be overwritten.

To install the program simply double-click on the RMRBank.sis  file.   

To ensure the SIS file does not get too large, it contains only English versions of the Help file and any instructions. In most cases international versions of these files are available and can be downloaded from the appropriate national page at http://www.rmrsoft.com/ or by sending a disc to the UK address in the Help file. 


RUNNING THE PROGRAM
-------------------
Start the program by selecting the 'Extras' from the Application bar and then 'RMRBank'.

If you fancy a challenge, you can learn everything you need to about the program by playing with it and checking the effect of each MENU selection, as well as the effect of pressing <ENTER>, <DELETE>, <TAB>, or <ESC>, in each screen, by observing the effect of touching various parts of the screen with the pen, and by reading the on-line Help file.  However, PLEASE, PLEASE, PLEASE, at least read the rest of this file first, for some very important information.  Our advice is that you then work through the tutorial in Part 1 of the instructions, which will familiarize you with all the basic capabilities of the program.  If you do 'fly blind' and get into trouble, please read the rest of the instructions and the FAQ in Part 4, before asking for help.  In particular, if you think there should be a specific function, it is probably there somewhere, so check the instructions before you suggest it to us !!
