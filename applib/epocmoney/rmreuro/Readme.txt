INTRODUCTION
------------
Welcome to our Euro converter for RMR ER5 Programs.

If you have any problems, first visit the Frequently Asked Questions 
(FAQ) section of our Home Page (www.rmrsoft.com) and if that doesn't 
answer the question then contact us at support@rmrsoft.com.

INSTALLATION
------------
To install the program simply double-click on the RMREURO.SIS file or 
select the "Install New Program" option in PSIWIN (EPOC Install).

RUNNING THE PROGRAM
-------------------
Start the program by selecting the 'Extras' from the Application bar and 
then RMREuro.   Select your nation, amend the exchnage rate if it is incorrect and then select the program to convert.  Then select the data file and the data will be converted to Euros.  Repeat the operaiton for each data file.
