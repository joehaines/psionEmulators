TVM for the PSION 5 (version 1.00)
==================================

Welcome TVM, Time Value of Money (Loan calculator).

A full manual is available from inside the application, so this
file only gives installation instructions and other miscellaneous
items.  There is a separate tutorial zip file for new users
available from my homepage.


INSTALLATION
============
- Connect up the Psion, and turn on the link.
- Create a new folder called C:\System\Apps\TVM (or D:\System\Apps\TVM )
- Copy the files
  TVM.aif
  TVM.app
  TVM.hlp
  TVM.mbm
    to the folder C:\System\Apps\TVM\
- Turn off the link and disconnect the Psion.
- The TVM app icon should appear in the Extras bar.

You can get the full manual by choosing Help from the Extras menu
inside TVM, or press Shift+Ctrl+H.
