Charmap is a freeware programmers tool - Use and distribute freely.


CharMap is a simple ASCII Character Map for the Psion Series 5.
It is Pen compatible, and you can use the copy/paste button on the screen
to copy the highlighted character to the clipboard.

Use the arrow keys to move through table, PageUp,PageDown,Home, and End all
work.


Installation:
-------------

Create the \System\Apps\charmap and \System\Opx directories. Copy the 
following files into the directories listed.

Charmap.app	\System\Apps\Charmap
Charmap.aif	\System\Apps\Charmap
SysRam1.opx	\System\Opx\

If you can't see the System folder you'll need to set the preferences on 
the system screen, and check the box that says "Show hidden files".
