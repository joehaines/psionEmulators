		CNVOPL32.EXE 

A DOS program to convert native Psion format OPL32 source code
from a Psion series 5 to plain text.
Should run on any version of MS-DOS.
Written in QuickBasic v4.5 and compiled to a standalone .EXE file.

Simply enter...

	CNVOPL32

...to see full usage instructions.


Oh, and I do NOT have a Series 5 (yet)...
