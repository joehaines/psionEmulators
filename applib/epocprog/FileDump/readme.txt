FileDump displays the contents of a file as a hexadecimal
dump, and allows it to be edited.

The program is freeware and copyright J.D.Medhurst 1998

To install this program:

1. Create a new folder in the \SYSTEM\APPS folder called
   'FileDump'. If the SYSTEM folder is not visible then
   enable it from PREFERENCES in the TOOLS menu on the
   system screen.
2. Copy all the files (except this one) from the zip file
   into the new folder.
