Helpedit is a small programmers utility for the Psion Series 5 which 
makes it easy to create and edit a help file for an OPL32 application.

This Zip includes:-

                    Readme.txt   -   This file.		

                    Helpedit.opo -   The Helpedit utility.

                    Helpedit.hlp -   A sample help file with useful 
                                      information on Help.
                    Helpshow.opl -   An example routine to display 
                                      Help
