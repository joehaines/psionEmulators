HexEd 0.99 beta 3
---------------
Freeware hexadecimal viewer/editor.
The program allows you to edit files on RAM drive (C: and D:)
and to view files on the ROM drive (Z:).

History
-------

9. Feb 98 v0.99 beta

There was a small bug in HexEd v0.99 beta which prevented the

This has been corrected (in a hurry) in the present release.

Installation :
--------------
Create a directory called /System/Apps/Hexed on C: or D:
then copy the files distributed in this package to this new 
directory.
Package content:
  HexEd.app
  HexEd.aif
  HexEd.hlp
  Progress.opo
  ScrollBar.mbm
  he_icons.mbm

Features :
----------
* unlimited undo buffer
* 6 zoom levels
* vertical scrollbar
* auto-repeat scrollbar button
* fast dragging scollbar navigation
* remember 4 last files used
* revert to save"

Limitations :
-------------
* files limited to 64Ko (larger files possible but edition 
  limited to the first 64Ko)
* you cannot increase or decrease the size of the file you are 
  editing (you are just allowed to replace)
* slow display especially when redrawing the whole screen
* slow initialisation
