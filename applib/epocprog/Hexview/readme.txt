Hexview is a simple hexadecimal file viewing program.

Installation.
Make sure your system folder is visible on the series 5
(from the system menu select tools,preferences and "tick" show "System" folder.
Under the system folder create an Apps\hexview folder
Copy the files
Hexview.app
Decimal.mbm
Decimalmask.mbm
Exit.mbm
Folder.mbm
Foldermask.mbm
Goto.mbm
Gotomask.mbm
into this folder

The hexview icon should now appear on your extras bar.

Operation should be obvious!
