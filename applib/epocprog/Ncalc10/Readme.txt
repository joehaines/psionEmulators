* nCalc version 1.0 for the Psion Series 5

* 30th July 1997

* Introduction

nCalc is a freeware multi-base 'programmers' calculator for the Psion Series 5. Please see the online help for more details. Press Ctrl+Shift+H from within the application to view it.

* Installation

Copy the nCalc folder from this zip file to the \System\Apps\ directory on any of your Psion's drives. nCalc will then appear on the extras bar automatically.
