OPL Reference Manual in Psion 5 Data Format
-------------------------------------------

I produced this for my own use but I thought others
might benefit from it.  You can program till
your heart's content on the bus or train...

I have removed most of the references to Series 3
except where it is useful information to a Serices 5
owner.

You may want to rename the file with a .hlp suffix which
makes Data treat it as a help file like the system
help file - but - be careful always to exit the database
when you are finished with it rather than let the system
close it when you open another Data application. There is 
a bug which makes the system think the file is in use
when it actually isn't.

The usual disclaimers apply!

Hope it's useful to you...
