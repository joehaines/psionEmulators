Distributed with kind permission from Psion Software.

Any queries should be addressed to the maintainers of the
EPOC World web site 

http://www.software.psion.com/EPOCWorld/

The OPX file is the one to ship with your programs, and should
be placed by the users in c:\system\opx

The OXH file is the one to INCLUDE at the top of your source code

The SYSRAM1 Word file contains detailed instructions on how to use
each new OPL/32 function
