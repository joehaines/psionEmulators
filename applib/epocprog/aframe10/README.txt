AFrame 1.0(UK)      -      Aug 1998      -      Steve Hawtin

"AFrame" is a framework for developing OPL applications on the 
Psion 5.  The package simplifies the creation of complete Psion 5 
applications.  It provides functions for creating a toolbar and 
menu, supporting hot keys, file based applications and pen based 
interactions.  The package includes all the necessary software, 
documentation on how to create new Psion 5 applications and three 
example OPL applications.  AFrame is free software and may be used 
for any purpose.  This is AFrame 1.0, the first public release of 
AFrame.  The software is fully tested and mostly debugged, the 
documentation should be considered as being at Beta level.

AFrame is Open Source software and may be modified provided
certain restrictions on redistribution are followed.  The 
documentation explains what these restrictions are.


Installation
************

The AFrame software includes four distinct packages.  The first 
thing you should do is to check that your copy has all the 
components.  If it does not then please contact the place where 
you obtained the software and tell them they have an illegal copy.

Version 1.0(UK) contains the following files:

    README.TXT     This file
    AFrame.opo     A framework module for applications
    AFrame.oph     The definition of the functions
    AFrameUK.wrd   Documentation
    AFrame.opl     The source to the opo file
    AfEmpty        A directory containing an example application
    DocTour        A directory, Psion 5 UID database maintainer
    CharMap        A directory, Psion 5 character map viewer

You will need to create a target directory C:\System\OPL.  If you 
cannot find the C:\System directory try setting "Show 'System' 
Folder" in the Tools->Preferences dialog from the system screen.

Copy all four files and three directories into the directory 
C:\System\OPL.  The AFrameUK.wrd file contains complete 
documentation for the system, it will describe what all the files
do.  Once you have read this you can delete the files you do not 
require.
