Bin-Hex-Dec converter for Epoc © Richard Wakelin 2000

BaseConv is available in two versions.

BaseConv5 is for the Series5, 5mx, MC218 and Geofox1 computers.

BaseConv7 is a colour version for the Series7 and Netbook.

Both versions will work on the Epoc emulator (ER5 only for BaseConv7).

Both versions can be installed together on the Series7 or Netbook and will run as separate programs.

The minimum screen requirements are 640x240 pixels (Series5,5mx minimum).
