#1 INSTALLATION:
================
1. UnZip Clipboard.OPM and Example.OPL
2. Copy Clipboard.OPM to "C:\System\OPM\" on the Psion
   (you may have to create the directory)
3. Copy Example.OPL to any directory on the Psion


#2 IMPLEMENTATION
=================
Load and translate Example.OPL for details on how to use
Clipboard.OPM.
