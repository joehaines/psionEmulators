* EikonWizard 1.2 Readme *

* What is EikonWizard?

EikonWizard is a way of creating a Visual C++ 5.0
project for a ready-to-run, minimal, EPOC application.

The project will be identical to one produced with the
actual SDK tools, and is easy to extend - eg to add
multiple document support. 

* Installing EikonWizard

Copy the two files:

EikonWizard.awx
EikonWizard.hlp

to your Visual Studio templates directory, usually:
\Program Files\DevStudio\SharedIDE\Template
When you next use File:New, the projects tab should
contain an entry for 'EPOC Eikon Wizard'. Select
this and proceed as normal when creating projects. 
Be sure to follow the special instructions (basically to close the 
workspace and run a batch file) at the end of the wizard to get a 
working project.
