            Installation Instructions
            
            1. Unpack the Zip file to your PC or your Psion.
            
            2. On the PC:
               Double click on the file MakePKG.SIS. This will start the PC
               automatic installation of MakePKG.
               On the Psion:
               Double tap on the file MakePKG.SIS. This will start the Psion
               automatic installation of MakePKG.
	
            3. Repeat step 2 with the file Systinfo1.SIS (or Systinfow.sis if
               using on the emulator)
            
            4. Repeat step 2 with the file pc_bar.SIS
            
            5. Repeat step 2 with the file nMPD.SIS

       

            MakePKG should now be accessible to you from the Extras icon.
