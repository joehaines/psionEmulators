Instructions
............

Fill in each menu card from left to right.

All mCASC cards must come before any mCARD'S.

Type in each item WITHOUT quote "" marks (as shown in the example).

Each items hot key is as for standard OPL syntax i.e %a - %z, %A - %Z or 1 - 32 and should be negated, i.e -%a or -12 to draw an underlined menu item.

Each flag, if given, should be a global variable that can be assigned a value to enable/disable, tick/untick ect, each menu item (see OPL help for these values)

When finished, realcaculate the spreadsheet and copy the output to your program file.
