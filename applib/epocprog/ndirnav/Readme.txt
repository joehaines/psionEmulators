 What is nDirNav OPX?
---------------------
 nDirNav comprises tools for the creation and management of dynamic 
 directory navigator and file management dialogs.  

 Contents
---------
 nDirNav.sis		packaged MARM build opx for machine and 
			distribution contains nDirNav.opx and nDirNav.rsc
 
 nDirNav - Wins.zip	contains the WINS (release) variants of the OPX for
			both ER3 and ER5 emulators. 

 For Licensee's personal use only:

 Readme.txt		this file
 nDirNav.oxh		header file
 nDirNav.hlp		developer's guide in EPOC Help format
 nDirNav Demo		OPL demonstration program
 
 Installation
-------------
 For MARM development	Install nDirNav.sis
			Copy nDirNav.oxh to \system\opl\
			Copy nDirNav.hlp as required
			Copy nDirNav demo as required
				
 For WINS development 	Unzip nDirNav - Wins.zip to stored paths
			Copy nDirNav.oxh to C:\system\opl\
			Copy nDirNav.hlp as required
			Copy nDirNav demo as required
