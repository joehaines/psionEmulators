What is nListbox OPX?
---------------------
 nListbox comprises tools for both the creation and management of dynamic 
 string arrays, and for interactive, multi-column listboxes.  

Contents
--------

 nListboxWins.zip		opx for WINS Release (emulator) and distribution

For Developer's personal use only:
