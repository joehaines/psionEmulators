 What is nMPD.opx?
__________________
 nMPD.opx comprises tools for the creation and management of dynamic 
 multi-page dialogs.  

 Contents
_________
 nMPD.sis		packaged MARM build opx for machine and 
			distribution - contains nMPD.opx and nMPD.rsc

 nMPDWinsRelER5.zip	WINS opx and nMPD.rsc for WINS and 
			distribution. NOTE: ER3 distribution is no
			longer supplied.

 Installation
_____________
 For machine development:
			Install nMPD.sis
			Copy nMPD.oxh to \system\opl\
			Copy nMPDConstants.oxh to \system\opl\
			Copy nMPDOpx.hlp as required
			Copy nMPDdemo as required
			Copy Bitmaps.mbm & Neuon.mbm to same folder as
			nMPDdemo
				
 For WINS development:
			Unzip nMPDWins.zip to stored paths
			Copy nMPD.oxh to \system\opl\
			Copy nMPDConstants.oxh to \system\opl\
			Copy nMPDOpx.hlp as required
			Copy nMPDdemo as required
			Copy Bitmaps.mbm & Neuon.mbm to same folder as
			nMPDdemo
