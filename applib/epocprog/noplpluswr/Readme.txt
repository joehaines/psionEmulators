Installation instructions

1. Unpack the .zip file to your PC or your machine.

2. On the PC:
    Double click on the file nOPLPlus.sis.  This will start the 
    EPOC Install installation of nOPLPlus.

3. On the machine:
    Double tap on the file nOPLPlus.sis This will start the PC
    installation of nOPLPlus.

4. nOPLPlus will now be accessible from the Extras bar.
