What is nScrollbar OPM?
-----------------------
nScrollbar is an OPM module for putting up to 10 scrollbars
in your application with full EIKON compliance.
nScrollbar provides all features for any application
requiring fully-functional scrollbars.


Contents

nScrollbar.hlp      Developer's guide in Psion Help format
nScrollbarTest      Sample source code to show a scrolling bitmap window
