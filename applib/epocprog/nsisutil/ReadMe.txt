Installation Instructions

1. Unpack the Zip file to your PC or your Psion.

2. On the PC:
   Double click on the file nSISUtil.SIS. This will start the
   automatic installation of nSISUtil from the PC.
   On the Psion:
   Double tap on the file nSISUtil.SIS. This will start the
   automatic installation of nSISUtil from the Psion if the Add/Remove
   Control Panel is installed.

nSISUtil should now be accessible to you from the Extras icon.
