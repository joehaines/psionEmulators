Introduction
OPLcolour is a tool to help OPL programmers devise a colour
scheme for their programs.  Working out the exact RGB colour component is no easy task, but hopefully this tool will go some way to make the job easier,with it's colour chart and RGB tool for fine tuning a colour to your requirements.

Suitable machines
The most suitable platform for OPLcolour is obviously the
Series 7 or Netbook as they the only ER5 machines with a full colour screen.However, the program will also run on Series 5mx or compatible machine, but you will not get the full benefit from the program.

Installation
OPL colour is supplied as an sis installation file. which
contains the following:
OPLcolour.aif
OPLcolour.app
To install, copy the OPLcolour folder to your ER5 machine. Double tap on the OPLcolour.sis file to start the automatic installation.  Once installed, the program will be accessible from the extras bar.
