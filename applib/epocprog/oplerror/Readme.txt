This is an OPL programmers utility which displays a full list of the OPL error codes and their text explanation in your language. This provides a reference when interpreting or returning error codes within your OPL programs. The list is split into relevant sections for quick access and supports full text search.

This updated version now includes "Const.oph" references and a copy to clipboard feature. EPOC error codes can now be displayed in addition to OPL error codes. Font size can be changed.
