2	Installation

To install vBASE, copy the files to any folder, preferably the
c:\system\apps\vbase\     folder, open vBASE under OPL, and then
translate. For those who are working under the OPL+ environment, I have
included the source in "text" format as well !!

3	What is it??

vBASE is basically the core database engine of my own vMEMO program. It
allows you to add entries to a database, extract them and print them to
the screen, use the arrow keys to select certain entries, and can be
used for an unlimited number of records. 

I have designed it to be relatively configurable, but a reasonably high
level of OPL experience is required to understand what I have written.
For those of you who have used Jason Kneen's excellent Coolbar.opo
utility, which helps authors with the EPOC toolbar, you can look at
vBASE as the database equivalent!! Although it is not a work of art,
and I have probably done things in a different way to the norm, vBASE
works, and works quite well may I add :-)
It certainly helped me with my OPL Programming and I am sure it will
help you as well!!

4	Usage

The way vBASE was designed to be used, was to aid programmers with the
sometimes tricky subject of database extraction, and printing to the 
screen, especially when the number of entries spans over more than one
page!!

I have included the full source code of vBASE, thus offering authors
the opportunity to "learn" how to write database code, rather than 
using a third party application to write the code for them!! So what
you are meant to do is read and understand what I have written in the
source, translate it, and see how vBASE works. You can then configure
vBASE to your program's needs (eg: Change the gAT statements for 
positioning the extracted database entries, change the font size, 
change the number of entries to be displayed on the screen at any one 
time etc).
Once configured, you can then copy and paste the vBASE code to your 
app, and hey presto, you have a fully working database engine capable
of handling an unlimited number of records, and is VERY quick as well!!

This version of vBASE is based on a database for Names and email 
addresses. When you first start up, vBASE will ask you to add some
entries into the database, so you can view them etc. Please add in
quite a few entries, in order for vBASE to show how it works. If you
only have one entry, you will not see vBASE working at its best !!
