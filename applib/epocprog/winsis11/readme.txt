Winsis.exe v1.01 by Richard Wakelin December 1998. Public domain software.

WinSis.exe is a simple Windows front end for Makesis.exe. This allows for the quick creation of SIS installation files.

Upgrading from v1.0
....................
v1.0 contained a bug which meant that Makesis.exe sometimes did not execute when clicking the makesis button. Remove all the old files from the application folder and replace them with the files in this zip. Winsis.bat is no longer needed. The output sis file (winsis.sis) is now created in the same folder as Winsis.exe. Rename winsis.sis to a name of your choice.


Installation
............
Place winsis.exe, winsis.hlp and a copy of Makesis.exe (not supplied) in the same folder on any disk. It is probably best to create a new folder called Winsis! To place the Winsis icon on the desktop right click winsis.exe in windows explorer and choose send to...desktop as shortcut. After starting Winsis READ THE HELP FILE for instructions on use.
Source.zip contains the Delphi2 source code.
