\Library\EPOCutil - EPOC utilities

The text list below shows what's available in the folder on the CD in this category.

Minimise this browser window when ready and then use PsiWin/Explorer or PsiMac to browse the folder structure of the CD and copy the program files of your choice onto your palmtop. Note that Windows may set all files taken from this CD to 'read-only'. If this causes a problem for you or for a particular program, just use the "Properties" command to remove this attribute.
