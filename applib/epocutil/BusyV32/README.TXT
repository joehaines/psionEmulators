BusyView gives four new views on your Agenda,
which were missed by Psion. Well, here they are!

1. The busy view
2. The calendar view
3. The list view
4. Horizontal view

Installing BusyView:
--------------------
Copy the sis file to your PC or Series 5 and execute it.
If installation fails due to problems with 'BusyView.hlp' pleae check if this file is already installed and if it is read-only. If so, please bring up its properties and untick the read-only attribute. Then try installing again.

After installing BusyView:
--------------------------
Please read the help file. It is full of information you should know.
One thing you should do is change (if necessary) the 'Agenda go to date key' in the preferences. This contains the (CTRL+)key that brings the 'Go to date' dialog box in the Agenda app. Check your Agenda application to see what key is used. In English and Dutch this is CTRL+G and therefor a 'g' is entered.
