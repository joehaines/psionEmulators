                          Converti 
                          ========
                 Unit conversion application
            for Psion S3a and S3c    :  Version 1.3
            for Psion Series 5       :  Version 5.1
           
             Freeware proposed by Guillaume Dupont
              e-mail:100740.1033@compuserve.com



Content:
========
This zip archive includes all the files necessary to install
and run Converti

on a Psion Series 3a or 3c:  - Converti.opa

or on a Psion Series 5:      - Converti.app
                             - Converti.aif
                             - Converti.ico

See changes.txt for changes from last versions.


Installation on a Psion 3a or 3c:
=================================
- copy converti.opa to any \app\ directory
- install Converti like any other Psion application
  (press Psion-I in the system screen, select Converti..).
- start Converti
- press Help or Menu for instructions.



Installation on a Psion 5:
==========================
- create a \system\apps\converti\ folder on the disk c:
  (if necessary, make the 'system' folder visible: press
  Menu from the System screen, then Tools, Preferences, and
  tick  "Show 'System' folder"...)
- copy Converti.app, Converti.aif and Converti.ico to the
  \system\apps\converti\ folder
- you should now have a "Converti" icon in the Extras toolbar.
- start it and press the Help icon in the toolbar.
