Welcome to Desktop utilities plus, the definitive suite of
utility applications for the EPOC platform.

This text file will give you the information that you need to
install Desktop onto your palmtop, and how to get started.

Installing Desktop
==================

1)	Turn on your Series 5, press the System button, press the Menu key,
	under 'Tools' select 'Preferences', make sure that the 'show system
	folder'option is 'OK'. This will make the System folder visible on
	your Psion.

2)	Create a new \SYSTEM\APPS\Desktop folder.

3)	Copy all the files from the ZIP file into this new folder,
	except the sysram1.opx file which should be placed in the
	\SYSTEM\OPX\ folder on your C: drive (if you have not have
	it already).
