Welcome to Easy Note, the original scribble pad application for
the EPOC range of palmtop computers. Easy Note allows you to take
short text or voice notes, without having to create whole word
documents for a quick scribble. You will quickly find Easy Note
to be one of the most used applications on your extra's bar !


This text file will give you the information that you need to
install Desktop onto your palmtop, and how to get started.

There now follows instructions on either installing Easy Note for the first
time or upgrading from version 1.3 or earlier. Choose the instructions which
apply to you ...


Installing Easy Note
====================

1)	Turn on your Series 5, press the System button, press the Menu key,
	under 'Tools' select 'Preferences', make sure that the 'show system
	folder’ option is 'OK'. This will make the System folder visible on
	your Psion.

2)	Create a new folder called \SYSTEM\APPS\EasyNote on either drive.

3)	Copy all the files from the ZIP file into this new folder,
	except ...

4)	Place the ps.opo and ps.mbm files in the C:\SYSTEM\OPL\ folder,
	if you do not already have them.

5)	The Easy Note .zip file includes a small upgrade.opo file. You do
	not need this UNLESS you are upgrading from Easy Note v1.3 or earlier.


Upgrading from Easy Note v1.3 or earlier
========================================

1)	Turn on your Series 5, press the System button, press the Menu key,
	under 'Tools' select 'Preferences', make sure that the 'show system
	folder’ option is 'OK'. This will make the System folder visible on
	your Psion.

2)	Delete all files from your \SYSTEM\APPS\EasyNote folder
	EXCEPT easynote.reg.

3)	Copy all the files from the ZIP file into this new folder,
	except ...

4)	Place the ps.opo and ps.mbm files in the C:\SYSTEM\OPL\ folder,
	if you do not already have them.

5)	The Easy Note .zip file also includes an upgrade wizard to upgrade
	your v1.3 or earlier Easy Note files to work with v2.0. Place the
	upgrade.opo file anywhere on your palmtop. Run this file to upgrade
	your files, and then you may delete it.
