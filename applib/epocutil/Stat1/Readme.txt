* StationeryPad version 1.0 for the Psion Series 5

* 7th October 1997

* Introduction

StationeryPad is a general way of adding templates to any Series 5 application. Use it to store letterheads, fax cover sheets and so on. It is intended to work like the Extra's bar, and can also be accessed via the 'New File' dialog. More details are in the online help.

* Installation

Copy the StationeryPad folder from this zip file to the \System\Apps\ directory on any of your Psion's drives. StationeryPad will then appear on the extras bar automatically.
