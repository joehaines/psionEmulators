SysBack per EPOC v2.10F, Build 0707

Note dell'ultimo minuto
=======================
Se stai aggiornando una versione precedente di SysBack, installa quella nuova usando il file SIS incluso (vedi sotto). Puoi tranquillamente cancellare il vecchio file SysBack.opo e anche il file chiamato C:\System\SysBack.ini. Per questa nuova versione devi reinserire i valori di default poiche' il vecchio file INI non e'compatibile con il nuovo. Questa operazione verra' fatta solo la prima volta che SysBack verra' usato .

Installazione di SysBack con i file SIS forniti
===============================================
Il file ZIP che accompagna questo testo contiene:

SysBack.sis		- File principale di installazione di SysBack
LeggiMi.txt		- Questo file

Se NON hai l'icona Add/remove nel pannello di controllo del tuo Series 5/Geofox-One (p.e. non hai il Message Suite installato o stai usando una versione di PsiWin/EPOC Connect precedente alla versione 2.1) dovrai rivisitare il mio sito web e scaricare il file "INSTEXE.EXE". L' icona  Add/remove e' indispensabile per le installazioni SIS.
 
Supponendo che hai ora l'icona Add/remove sulla tua macchina, copia semplicemente SysBack.sis nel tuo Series 5/Geofox-One e fai un doppio click sul file della schermata di sistema. Il programma di installazione fara' il resto.
