SysBack pour EPOC v2.10F, Build 0707

Notes de dernière minute
========================
Si vous mettez à jour une précédente version de SysBack, installez la nouvelle version depuis les fichiers SIS (voir ci-dessous). Vous pourrez ensuite effacer l'ancien fichier SysBack.opo file, ainsi que le fichiers C:\System\SysBack.ini.

Pour cette nouvelle version, vous devrez re-saisir vos valeurs par défaut car l'ancien fichier INI n'est pas compatible. Cette opération ne sera à faire qu'à la première utilisation de SysBack.

Installation
============
Le fichier .ZIP joint doit contenir 2 éléments:

SysBack.sis		- Le fichier d'installation principal de SysBack
LisezMoi.txt	- Ce fichier

Si vous n'avez PAS l'icône "Ajout/Suppr." dans le Panneau de Configuration de votre Series 5/Geofox One (c.a.d. si vous n'avez pas installé Message et vous utilisez une version de PsiWin/EPOC Connect antérieure à la V2.1), vous devrez revisiter mon site et télécharger le fichier "INSTEXE.EXE". L'icône "Ajout/Suppr." est indispensable au fonctionnement des fichiers d'installation SIS.

Ceci fait, copiez le fichier SysBack.sis vers votre Series 5/Geofox-One double-cliquez dessus depuis l'écran Système. Le programme d'installation fera le reste.
