SysBack for EPOC v2.10F, Build 0707

Last Minute Release Notes
=========================
If you're upgrading from an earlier release of SysBack, install the new copy via the SIS files provided (see below). Then you can safely delete the old SysBack.opo file, and also the file called C:\System\SysBack.ini.

For this new version, you will have to re-enter the default values since the old INI file is not compatiable. This, however, only has to be done the first time SysBack is used.

Installing SysBack from the SIS file provided
=============================================
The .ZIP file which accompanied this text file should contain 2 items:

SysBack.sis		- The main SysBack install data
ReadThis.txt	- This file

If you do NOT have the "Add/remove" icon in the Control Panel of your Series 5/Geofox-One (i.e. you've not got Message Suite installed and are using a version of PsiWin/EPOC Connect prior to 2.1), you will need to re-visit my web site to download the "INSTEXE.EXE" file. The Add/remove icon in Control Panel is vital for SIS installations to work.

Assuming you now have that Add/remove icon, simply copy SysBack.sis to your Series 5/Geofox-One and double-tap it from the System screen. The install program will do the rest.
