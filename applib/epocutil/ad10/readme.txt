*** Installation

You need to unzip the ZIP file into a directory.  You have already
done this, or you would not be reading this file.  You then need
to follow these instructions:

   1. Startup PsiWin.
   2. Create a directory named "\System\Apps\AgnDump" on either
      the C: or the D: drive on the Psion, if you need to.
   3. Move all the unzipped files -- except this README -- into 
      the directory you just created.
   4. Close down PsiWin.

That's it.  You should now have the AgnDump icon on the Extras bar.

*** Usage

Tapping the AgnDump icon on the Extras bar will start the AgnDump
application.  If this is the first time this release is run,
a dialog window will pop up and ask you what Agenda file you want
to open.  AgnDump will close down Agenda apps that are running.

Once you have started AgnDump, the functions should be self-
explanatory.  There is a HELP file that can be accessed through
the "Tools" menu or by using the Ctrl-H key sequence.
