AgnClean v1.00 - Freeware

Introduction:
-----------------

Welcome to AgnClean!
This is a program for cleaning agenda files from certain entries.
The entries can be specified by symbol or a search text.
It's possible for example to delete all entries with the symbol "p",
or containing the text "privat".
To reduce the risk of data loss, the program always makes a copy
of your agenda, called the "target file". Entries are deleted only in
the target file, the source file keeps unchanged.




Features:
--------------
-deletes entries specified by symbol or search text
-saves all user settings

Known problems:
-------------------------
AgnClean uses Agenda2.OPX and has therefore some limitations.
When there is an update for Agenda2.OPX , I will write a new version.

1.AgnClean does not work on a revo if the today-view is activated.
   workaround: deactivate the today-view.

	

Installation:
----------------

The distribution comes as an .zip file, containing the following files:

AgnClean.sis
ReadMe.txt (this file)
Liesmich.txt

There are two ways to install:

1. open AgnClean.zip
2. doubleclick AgnClean.sis
3. follow instructions
or:
1. unzip AgnClean.zip
2. copy AgnClean.sis to your PDA
3. doubleclick AgnClean.sis
4. follow instructions
