AgnPrint v1.03 - Freeware

Introduction:
-----------------

Welcome to AgnPrint!
This is a program for printing agenda files.
I wrote it, because I need access to my appointments all the time,
but I don´t like to carry my PDA everywhere I go.

What´s new in Version 1.03:
--------------
-Version 1.03 can be installed over an existing version without any
problems. It is not necessary to deinstall a previous version.
-additional output in a text file

What´s new in Version 1.02:
--------------
-can print anniversaries now, with some restrictions mentioned
below under "known problems"
-search function

What's new in Version 1.01:
--------------

-the bug which shows if you print entries wich are not in the current year
has been fixed.
-you can select symbols to be printed.

Features:
--------------
-prints agenda files in a list view (similar to the built-in print function)
-choose font and fontheight
-can print only selected smbols
-can print a search result
-can print in a text file
-prints appointments, events and anniversaries - but no to-do entries or repeated entries
-offers more suggestions for date range to print
-saves all user settings

Known problems:
-------------------------
AgnPrint uses Agenda2.OPX and has therefore some limitations.
When there is an update for Agenda2.OPX , I will write a new version.

1.AgnPrint does not work on a revo if the today-view is activated.
   workaround: deactivate the today-view.
2.AgnPrint detects untimed entries by there start and end time being
   00.00. Unfortunately, sometimes untimed entries are read with another
   start time, which is equal to the time set as "time slot for untimed entries".
   You can go to the "Tools / Preferences Entries / Day Entries" menu and change
   the time for "time slot for untimed entries" to 00.00 and all Entries
   made from then will be detected correctly.
3.Anniversaries are sometimes printed more than once, especially if they
   have been changed.
   Workaround: Make a printout of the anniversaries, delete them all using
   the "Tidy" function of the agenda and enter them again by hand.
	

Installation:
----------------

The distribution comes as an .zip file, containing the following files:

AgnPrint.sis
ReadMe.txt (this file)
Liesmich.txt

There are two ways to install:

1. open AgnPrint.zip
2. doubleclick AgnPrint.sis
3. follow instructions
or:
1. unzip AgnPrint.zip
2. copy AgnPrint.sis to your PDA
3. doubleclick AgnPrint.sis
4. follow instructions
