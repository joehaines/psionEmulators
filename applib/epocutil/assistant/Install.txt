 ***Installation***
 You may have to install INST.EXE first, if you don't have the item ADD/REMOVE in your System control panel.

1. From PC or Psion:
Extract Assistant.sis from the Archive, and doubleclick it to install. 
You are strongly advised, to CLOSE ALL APPLICATIONS. Otherwise any older OPX version cannot be upgraded! If you get errors on trying to run Assistant, or calling some functions, it is mostly caused by older OPX files, that could not be upgraded.
If you are upgrading:
If you get errors, accessing menu items or functions:
Delete Assistant.ini
If you still get errors:
Reinstall Macro5Lib.sis from the Zip
If you want to run Escript macros, you will have to install  Escript.sis. You can get it from Jason Kneen at http://www.epocplus.com
or from my Homepage at :
http://www.psionwelt.net/MarioCollado/
If you have any problems with installation: I cant say it often enough: Close all programs and reinstall all *sis files. The problem is, that although you will not get any errors on installing a sis file, the files will remain the old ones, if they were in use. Further, it might help, to delete the ini file.
