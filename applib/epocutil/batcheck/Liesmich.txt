             BatCheck für Psion Serie 5 v1.2de
                      18. September 1999
      *****************************************************



BatCheck ist ein kleines nützliches Utility, daß die Haupt- und
Sicherungsbatterie überprüft.

Möglichkeiten:

 * Während andere Programme die Batterien nur im Vordergrund prüfen,
   überwacht BatCheck den Status der Batterien im Hintergrund in frei
   wählbaren Zeitintervallen (1 bis 60 Minuten).

 * Normalerweise befindet sich das Programm im Hintergrund, aktiviert sich
   wenn es Zeit für eine Überprüfung ist und begibt sich, wenn die Batterien
   in Ordnung sind, wieder in den Hintergrund, ohne Sie zu stören.
   Wenn die Batterien nicht mehr in Ordnung sind, gibt das Programm verschiedene
   Warnungen aus.

 * (NEU!) Sie können ein oberes Limit für die Hauptbatterien einstellen, um 
   ein unbeabsichtigtes Überladen von wiederaufladbaren Batterien zu vermeiden.

 * Sie können zwei Warnstufen definieren, jeweils für die Hauptbatterien und
   für die Sicherungsbatterie. Die erste Warnstufe weist Sie auf schwache
   Batterien hin, die zweite Warnstufe fordert Sie zum Batteriewechsel auf.
   Dies ist sehr nützlich, wenn Sie mit wiederaufladbaren Batterien arbeiten,
   deren Spannung gegen Ende rapid abfällt. Wenn Sie Werte einstellen, die
   höher sind, als die im Psion serienmäßig eingestellten Werte, können Sie
   Datenverlust vorbeugen, der bei plötzlichem Spannungsabfall unter die
   Mindestgrenze eintreten könnte.

 * Sie können auch das Programm veranlassen, Sie nur einmal zu warnen.
   Die nächste Warnung erhalten sie dann erst wieder, wenn der Psion dazwischen
   einmal ausgeschaltet war.
 
 * Sie können einen Batterietest bei jedem Einschalten veranlassen. Wenn
   Sie mehrere Programme automatisch starten lassen, können sie in BatCheck eine
   Startverzögerung (0 bis 20 Sekunden) einstellen, damit die Batterieüberprüfung
   erst aktiviert wird, wenn alle Ihre Programme gestartet sind und Sie damit
   eventuelle Batteriewarnungen nicht übersehen.

 * Sie können BatCheck auch veranlassen, das Vorhandensein des externen Netzteils
   permanent zu überprüfen. Dies kann sehr nützlich sein, wenn Sie mit dem Netzteil
   arbeiten und der Stecker unbeabsichtigt rausrutschen sollte, ohne das Sie es
   bemerken.

 * Das Programm zeigt Ihnen die Voltwerte in zwei Dezimalstellen, für größere
   Genauigkeit, an (z.B. 2.28 Volt).
 
 * Unterstützung einer Menüleiste und volle System Integrierung.


Versuchen Sie BatCheck, und Sie haben eine Sorge weniger!



INSTALLATION
************

    1) BatCheck wird entweder als ZIP-Datei, oder als Psions SIS-Installationsdatei
       ausgeliefert. Kopieren sie die SIS-Datei auf Ihren Serie 5. Markieren Sie sie
       und drücken Sie Enter. Das Programm wird automatisch installiert. (Wenn Sie
       das Hinzu./Entf. Kontrollelement nicht installiert haben, können Sie es auf
       der offiziellen Psion Webseite herunterladen.)
       Stellen Sie bitte sicher, daß Sie auch sysram1.sis und systinfo.sis installiert haben.

    2) Wenn Sie das ZIP-File haben, kopieren Sie bitte die Dateien per Hand in folgende
       Verzeichnisse:
       Sysram1.opx, Systinfo.opx: C:\SYSTEM\OPX\ (oder D:)
       Alle anderen Dateien: C:\SYSTEM\APPS\BATCHECK\ (oder D:)

    3) Wenn Sie eine frühere Version bereits besitzen, löschen Sie bitte
       c:\system\apps\batcheck.ini (oder d:) per Hand. Das Programm würde sonst eine
       Fehlermeldung ausgeben und nicht starten.

    4) BatCheck kann jetzt gestartet werden. Sie sollten das Programmicon in der 
       Extras-Leiste sehen, klicken sie darauf!
