Readme for C2F version 1.09
---------------------------

C2F is a small freeware application by Malcolm Bryant which reads your
Contacts database 
and writes user-selected fields to a standard comma or tab-delimited ASCII
file.  You can 
then import them into Data or any other program which imports standard ASCII
files.

Installation
------------

Install as for all .sis files; either double-click the c2f.sis file in
Windows Explorer
or move the c2f.sis file to your Psion and select it from there.  If you don't
already have
contact.opx on your machine, then install it from the supplied contact.sis
file.  Once
installed, the program will appear in your Extras Bar.

C2F will only operate on Epoc Release 5 machines such as the 5mx, Revo, 7 
and Netbook.  It will not run on the Series 5 or the Geofox One.

Intructions for use
-------------------

Follow the on-screen instructions.  Note that the option "Combine last and
first names"
appears because the Contacts database holds last and first names as two
separate fields,
but you may prefer to export them in the form "Last Name, First Name".

Contactstemplate
----------------

A template for the Psion's Data application is included.  If you use the Select All Fields
option then you can import the resulting ASCII file into this template.

I hope you find this small application useful.  Comments or suggestions are
welcome.
