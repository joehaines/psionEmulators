CapsView v1.00
--------------

This very small utility is meant for those who use
CapsLock and never know in wich mode they are.
It displays in one of the screen corners an icon
that indicates the state of CapsLock.
It allows also to toggle the state of CapsLock
by clicking with the pen on the icon.


Installation:
-------------
Install the packages CapsView.sis and Macro5Lib.sis
as you do with all SIS files : double-click on them either
on the PC or on the Series 5.


Usage:
------
Just start CapsView from the Extras-bar and an icon
will show up in one of the screen corners.
To display the control panel of CapsView, either
double click on the icon ot press Fn+Tab twice.
Then press :

   -> Enter to set the preferences
   -> Esc to dismiss the control panel
   -> Del to close CapsView
