2. INTRODUCTION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
ClipIt stores predefined text into the clipboard.
As one can imagine this little app is designed for people who do repetative
stuf often. Think of storing OPL commands in a database of this app and 
your programming will advance much faster.

Type it ones and use it again later!

The first time you start ClipIt you will be asked to provide a directory.
This folder will be the folder where the databases (plugins) will be stored.
One (DataOPX.dbf) database is provided. Copy this file to the folder you
picked.

Plug-ins will be provided as I make them. Visit www.settings.tmfweb.nl often
to watch for plugins

4. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. There are 2 methods to install ClipIt depending on where you
   have copied the .sis file and what setup you have;
   
   - On a PC with PsiWin
     From the Windows Explorer double click the .sis file, this will 
     automatically install ClipIt onto your machine. If that
     doesn't work right click the My Psion icon and click the Install New 
     Program option.
     If you do not have the Install New Program option then download
     setup.exe from our site or from Psion's site <http://www.psion.com>
     install it and try again.
   - On a EPOC machine
     Tap the .sis file to install, if this does not work then you do not
     have the Add/Remove utility, in this case download
     instexe.exe from our site, or psion's site <http://www.psion.com> and
     copy it to your machine and try again. 
     
2. Now You can start the app from the extrasbar

3. To uninstall goto the Control Panel, tap the Add/Remove icon, select 
   ClipIt and finally press the Remove button.
