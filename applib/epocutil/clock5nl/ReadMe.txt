Clock5   v1.73
====================================

Clock 5 is een Series 5 /
Geofox wachtwoord-beveiligde screensaver - die erg veel lijkt op die voor
de Mac en Windows.  Natuurlijk heb je niet echt een screensaver nodig, want waarom heeft een Psion Series 5 of een 'Fox' scherm eigenlijk bescherming nodig ?
Met dit in gedachten, dacht ik dat het wel iets zou zijn, met een grote klok op het scherm...

Dit idee is grotendeels gebaseerd op Dan Comiskey's 'Clock' programma voor de Psion Series 3a/c/mx. Er zijn een aantal plannen voor veranderingen voor toekomstige versies, dus bezoek A.U.B. Pscience5 op:-
http://ourworld.compuserve.com/homepages/martin_guthrie
voor meer informatie en updates.

Installatie
============
De installatie gaat nu via de standaard .SIS methode.
Er zijn 6 bestanden:-
Clock5.sis			(Clock5's installatie bestand)en
SysRAM1.sis		(Psion's opx bestand)
Systinfo.sis			(RMR's opx bestand)
RMRAlarm.sis		(RMR's opx bestand)
ReadMe.txt			(dit bestand)
Changes.txt			(veranderingen sinds de laatste uitgave (Engelstalig)

Maak een directory genaamd:  'Clock5' op je Series 5 / 'fox.
Voorbeeld: ---- System/Apps/Clock5
(Op de C of D drive) en kopieer de eerste 6 bestanden er in.

Maak nu een directory genaamd "Voice" in je "Clock5" directory en
UN-ZIP Voice.zip hier in. (Er horen nu 28 voice-bestanden hier in te zitten).

Als je je eigen logo's wilt toevoegen aan de standaard ingebouwde logo's in
Clock5, maak dan een nieuwe directory genaamd: 'Logos' in de reeds bestaande System\Apps\Clock5\ directory en gebruik  .mbm bestanden hierin.
Ze zullen automatisch door Clock5 gevonden worden.

Clock5.sis, Systinfo.sis, SysRAM1.sis, en RMRAlarm.sis kunnen  ge-installeerd worden op je machine door Psion's EPOC install programma te gebruiken
(dat geleverd wordt met PsiWin 2.1) of door het Add/Remove ikoon in je Psion's configuratiescherm te gebruiken, als je tenminste Psion's Message Suite ge-installeerd hebt op je machine.
Als dat het geval is, kopieer dan de .SIS bestanden naar je Psion en gebruik ze door het Add/Remove ikoon in je Psion's configuratiescherm te gebruiken, of tik gewoon tweemaal op de .SIS bestanden voor de 'auto-run the install routine'.

N.B.: Als je SysRam1, Systinfo of RMRAlarm niet installeerd, dan zal Clock5 niet werken.

During the installation of Clock5, you will be given the option of installing
voice files.  These enable Clock5 to be used a speaking clock when in its
'Sweet Dreams' mode.  The files are quite large however (~100Kb) so
there's an option not to install them.  Clock5 will work without them minus
this particular feature.

Tijdens de installatie van Clock5, zal de optie worden aangeboden, om voice bestanden te installeren. Deze geven Clock5 de mogelijkheid om als een sprekende klok gebruikt te worden, wanneer het in de 'Sweet Dreams' mode is. De bestanden zijn tamelijk groot evenwel (~100 kB) dus er is een optie om ze niet te installeren. Clock5 zal zonder ze werken, maar die particuliere optie is dan ook niet meer aanwezig.

Het Clock5 ikoon zal nu in de Extras Bar verschenen zijn, klaar om te starten.

Als je je eigen logo's wilt toevoegen aan de standaard ingebouwde logo's in
Clock5, maak dan een nieuwe directory genaamd: 'Logos' in de reeds bestaande System\Apps\Clock5\ directory en gebruik  .mbm bestanden hierin.
Ze zullen automatisch door Clock5 gevonden worden. Er zijn een paar voorbeeld logo's verkrijgbaar op de Pscience5 web site.
