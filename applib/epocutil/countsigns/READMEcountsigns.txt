CountSigns
==========
Version 1.0 - November 2000

from PocketIQ 

Introduction
------------
This program, Freeware version 1.0 for the Series 5, GeoFox, Osaris, 
Series 5mx, Revo, Series 7 and NetBook.

CountSigns is designed with the Journalist in mind, this little application will
count Signs (text, spaces and punctuation), words, sentences and paragraphs in any
EPOC Word file.

When run while a word file is open is will allow the Signs in that document to be
counted.  If it is run while no Word documents are open then a dialog is shown to
allow one to be chosen.

Download Zip File Details
=========================
The zip file should contain the following files:

	READMEcountsigns.txt (this file)
	CountSigns.SIS (installation file for CountSigns)


INSTALLATION
------------
To install the program simply double-click CountSigns.sis file to install all the
required files.  Or use the "Install New Program" option in PSIWIN (EPOC Install).
If you have the latest PSIWIN or EPOC Install then everything will happen
automatically.  If you don't have these then you need to get the installation file
SETUP.EXE, which can be downloaded from Pocket IQ's Home Page or from www.psion.com.

You can also copy the SIS files directly to your Psion 5, 5mx, Revo, Osaris, GeoFox
Series 7 or NetBook and double select them to launch the install program.

This will install the program and also install the PIQinfo.SIS file for the
essential Pocket IQ common files and the  SYSRAM1.SIS file to install the essential
system files.


RUNNING THE PROGRAM
-------------------
Start the program by selecting the 'Extras' from the Application bar and then
'CountSigns'.

Full On-line help is provided and can be accessed from the Help file.
