HOW TO INSTALL
--------------------------

     The delivery files are provided in the form of a self extracting archive. 
     In order to install DATAFILEMANAGER 1.0 these files must be extracted to a 
     directory on the user's PC. This will provide him with two files :
   
     - DATAFILEMANAGER.sis - Main installation file.
     - Readme.txt   - This file.

     To install DATAFILEMANAGER do one of the following :    
     
     1) Connect your Psion Series 5 machine to your PC.
        Now goto the 'Psi Win' menu in your Start/Programs menu and select the
        'Install New Program' option. Follow the instructions to install.

     2) Copy DATAFILEMANAGER.sis file to you Psion machine . Now go to Control Panel and select 
        'Add/Remove Program' option. Follow the on screen instructions to install.
