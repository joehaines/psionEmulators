DayCount v2.20
--------------
- DayCount is compatible with the Psion Series 5, 5mx and 5mxPRO.
- It is a small countdown program that tells you how many
  days you have to wait until a specified date in the future, not
  later than 2100/01/01. ;-)
- DayCount uses an official UID.


Installation:
-------------
1. To install DayCount.sis from your PC using PsiWin earlier
   than v2.1 you need to download "EPOC Install" from my homepage.
   This program requires Win 95/98.
   If you would like to install DayCount.sis directly from your
   Psion, make sure you have an add/remove icon in the Control Panel.
   If not, download "Add/remove Control panel" from my homepage.
2. Either way, run DayCount.sis.
3. That's it! There will be a new icon on your Extras bar.


Usage:
------
Run DayCount from System or the Extras bar.
Go to "Preferences" to start a new countdown.


UID:
----
DayCount uses the official UID 268457350.
If you experience any conflicts with other applications, please
let me know.
