Medialinx Defrag5 (Freeware)
Version 1.00 for EPOC/32


Overview
========

Defrag5 is a small EPOC/32 utility designed to "defragment" or
reclaim unused memory on your computer. It works by clearing
allocated memory blocks that are not used anymore.


Installation
============

To install Defrag5 on to your computer you must follow these
simple steps:

1. Create a directory called Defrag5 in your System\Apps
   directory.

2. Copy Defrag5.app, Defrag5.mbm and Defrag5.aif to this
   directory.

3. Install the RMR Software SYSTINFO OPX file by running
   Systinfo.sis from the System Screen. You cannot use Defrag5
   without this file.


Defragmenting your memory
=========================

1. To defragment your memory run Defrag5 by clicking on
   the Defrag5 icon in the Extras bar.
   
2. Click on the "Defragment memory" button once Defrag5 has
   loaded.

3. Wait until Defrag5 returns a message telling you that it has
   finished defragmenting your memory.
