4. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
To install the program simply double-click on the EpocBackupDemo.SIS file or 
select the "Install New Program" option in PsiWin/EPOC Install.

For Series 7/netBook owners use the EpocBackupDemo.SIS in the zip file 
Series7-netBook.zip 

To uninstall goto the Control Panel, tap the Add/Remove icon, select 
EpocBackup and finally press the Remove button.
