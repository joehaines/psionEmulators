Readme file for EpocSync - version 3.04
---------------------------------------

Welcome to EpocSync - one step file synchronisation for your EPOC 
machines.  If you are currently using EpocSync version 1.00 or 2.00 then please
remove this program (using Control Panel>Add/Remove Programs) before
installing EpocSync version 3.04

EpocSync is supplied as a standard EPOC installation file called
epocsync.sis.  To install on your EPOC machine, follow these instructions:

* Connect your EPOC computer to a Windows PC using Psiwin

Then either

* On your Windows PC, double-click on the file epocsync.sis

or

* Copy epocsync.sis to your EPOC computer, highlight it, and press
Enter

If you want to synchronise your EPOC machine to an FTP server then you
will also need to install file ftp.sis.

Once installed, run EpocSync from your Extras bar and follow the
onscreen instructions.  Of course, to get full use from the program
you need to install it on a second EPOC computer as well ;-))

To run EpocSync on the EPOC Emulator, copy epocsync.sis to the
appropriate "emulated" directory on your Windows PC (refer to the
Emulator documentation if necessary).  You do not need to install ftp.sis.  
Start the EPOC Emulator, highlight epocsync.sis and then press Enter.  

You can obtain a free download of the Windows Epoc Emulator from 
the following URL: http://www.symbiandevnet.com


The User Manual
---------------

The user manual is in Epoc Word format.


System requirements
-------------------

The program files occupy about 81K of disk space, of which 
22K is for the Help file.  The optional FTP components occupy
a further 12K (ie. if you install FTP.SIS).

In use, the memory requirements vary according to the EPOC computer
on which you are running the program.  This is due to the memory
allocated to windows that are larger on the Series 7/netBook and
correspondingly smaller on other machines.  The Series 7/netBook
will require about 1M of free memory to run the program.  At the
other extreme, the Revo only requires about 360K of free memory.
