FileSwitch enables you to switch between open files or
programs by pressing Ctrl+Space in a similar way to
Alt+Tab in Windows95.

To install this program run FileDump.sis

If you have any problems or comments email tixy@clara.net

--------------------------------------------------------

How to use FileSwitch

As FileSwitch should only need to be run after a reset
or backup I have not made it appear in the Extras Bar
in order to reduce clutter. Instead a short file called
'FileSwitch' is installed on drive C: which can be run
to start the program. You can move this to any folder
you choose.

(Due to requests from some users the installation process
now lets you choose to have FileLink appear on the Extras
Bar.) 

Whilst FileSwitch is running, hold down the Ctrl key and
press Space a number of times. On each key press the name
of a currently open file or program will be displayed.
When you see the one you want release the Ctrl key and
it will be brought to the foreground. 

(You can change the keys used to switch between files
from Ctrl+Space to Ctrl+Tab if you wish.)

You can select programs that you wish FileSwitch to
exclude from the list that it cycles through. This
is useful if you have certain programs running all the
time but never want to switch to them. e.g. by default
FileSwitch ignores itself.

To edit this 'excluded programs' list you need to select
'Preferences' from the FileSwitch dialog box. This box
appears if you run the program when it is already active
or by pressing the Enter key whilst you are cycling
between files with the Ctrl+Space keys. (Keep the Ctrl
key held down when pressing Enter.)

In 'Prefences' you can also change the keys used to switch
between files from Ctrl+Space to Ctrl+Tab if you wish.

Revision history.

Version 2.10 - 30th March 1999
  * Added the option to change the 'switching' keys from
    Ctrl+Space to Ctrl+Tab

Version 2.01 - 10th March 1999
  * Changed the installation process to give a choice of whether
    FileSwitch should appear on the extras bar or not.
  * A couple of very minor changes to the program.
    
Version 2.00 - 30th Jan 1999
  * Added the facility to exclude programs from 'switching'
    so users can automatically skip those that they would never
    wish to switch to. e.g. Programs that run hidden like
    FileSwitch itself.
  * Made FileSwitch an 'application' and provided a shortcut
    file to run the program so it doesn't have to take up space
    on the extras bar.

Version 1.04 - 13th Jan 1999
  * Made FileSwitch more recognisable as an OPL program
    so it can be launched by some third party software
    that was having problems.

Version 1.03 - 19th August 1998
  * Reduced the memory used when program is running.
  * Replaced initial dialogue box with a two second
    message so that people who use programs to re-launch
    FileSwitch after backups can do so without any user
    input.

Version 1.02 - 11th June 1998
  * Made FileSwitch more responsive and it now acts
    almost instantly when Ctrl-Space is pressed.

Version 1.01 - 4th June 1998
  * Changed the order of file switching to make it easier
    to toggle between a pair of open files.
  * Fixed a bug that on rare occasions caused the Psion
    to lock up and wait for the Ctrl key to be pressed.

Version 1.00 - 2nd June 1998
  * Initial release.
