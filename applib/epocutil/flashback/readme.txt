Please read this file,  it contains important information about the program.
I kept this readme short because most people don't like long manuals. Please
also read the Help file included with the program.

FlashBack is a fully customisable compact flash-based backup utility for the
Psion Series 5, 5mx and compatible machines. It is sophisticated yet easy to
use.  You just define personal profiles containing single files,  folders or
entire folder trees, and FlashBack takes care of the rest.  It  closes files
that are open,  backs up the  profile,  encrypts the files, then reopens the
files it closed earlier. It reminds you whenever a backup is due.  It checks
the battery status to make sure that you never start a backup with low  main
batteries.  You can also create shortcuts in your favourite folder: just one
click on a shortcut,  FlashBack starts,  and performs the backup without one
more keypress required.  A detailed Help and Topic Help screens help you get
started. Try FlashBack and never lose data again!


WHAT'S NEW?
***********

v1.2:  * A true synchronise mode has been added:  FlashBack can remove files
         in  the destination folders that no longer exist in their  original
         location.

       * Option to archive 2 versions of the  file:  if an older  version of
         the file exists in the destination folder, it will be renamed,  and
         the new version backed up to the folder.

       * The progress window now shows only those file names that are indeed
         backed up, not every file the program is examining.

       * The Create shortcut dialog has been improved,  and no longer causes
         a crash when the name of the profile contains spaces.

       * Folder trees are now scanned using a new, improved algorithm.

       * Contacts, Email and ExtraBars applications are correctly closed and
         restarted.

       * "Working..." is displayed during a backup.


INSTALLATION
************

    1) The installation file is Flashback12.SIS. There are two ways of using
       a **.SIS installation file:
       - from a PC (if PsiWin is installed), double-click on the **.SIS file
         (this can be done from the  WinZip  window,  even without unzipping
         the **.SIS file)
       - from the Epoc machine itself (if there is an Add/Remove icon in the
         Control panel): copy the  **.SIS  file anywhere on your Epoc device
         and double-tap it.

       Important! If you try to use more than one flash disk for backup, the
       program must be installed to the C: drive, otherwise upon removing of
       the flash disk the program will stop working. If your flash disk will
       never be removed during backup, you can install the program to D:

    2) You are now ready to run  FlashBack!  It's  icon should appear on the
       Extras bar, so just click on it! Please read the Help file before you
       use the program.

       If you are upgrading from an  earlier version,  your profiles will be
       preserved and the  Flashback.ini  file automatically converted to the
       new version when the program is first launched.
