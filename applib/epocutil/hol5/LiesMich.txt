* HOL - Eintragen von Feiertagen in die Psion S5 Agenda

** Dateien

Diese Ausgabe sollte die folgenden Dateien enthalten:

  HOL5.SIS			Programm
  HOL5DEF.SIS			Feiertagsdateien
  HOL5SRC.SIS			Quellcode von HOL5
  Agenda2.SIS
  SystInfo.SIS
  Changes.txt			Änderungsgeschichte (englisch)
  License.txt			Softwarelizenz
  Readme/LiesMich/LisezMoi.txt	Diese Datei (englisch, deutsch und französisch)

Die sogenannten Feiertagsdateien definieren Regeln für die Feiertage. 
Diese Ausgabe enthält Feiertagsdateien für diverse  Länder, Regionen, 
Kirchen und Religionen.

Die Feiertagsdateien sind reine Textdateien. Diese können mit Hilfe 
eines  Texteditors (z.B. RMRText von www.rmrsoft.com) an spezifische 
Bedürfnisse angepasst werden. Auch die Import und Export Funktion 
der S5 Textverarbeitung Word können diesem Zweck dienen. 
Einzelheiten über die Feiertagsdateien erfahren Sie über die 
eingebaute Hilfefunktion des Programms.

** Installation

Falls Sie eine Feiertagsdatei einer früheren Version aus irgend-
welchen Gründen unverändert behalten wollen, z.B. weil Sie diese
selbst auf Ihre Bedürfnisse angepasst haben, dann stellen Sie 
sicher, dass der Name dieser Datei *nicht identisch* ist, mit
dem Namen irgendeiner Feiertagsdatei in dieser Version!

Durch das Dekomprimieren von Hol5.zip entstehen die Dateien,
die am Beginn dieser Beschreibung aufgelistet sind.

(Experten)
   Falls Sie wissen, was eine .SIS Datei ist, dann doppelklicken Sie
   jede von diesen in Ihrem Windows Explorer oder auf Ihrem Psion S5
   und der Rest ist schnell erledigt.
   Beachten Sie, dass Sie diejenigen .SIS Upgrades nicht mehr zu
   installieren brauchen, welche Sie schon installiert haben. Mit
   Ausnahme von "Hol5.SIS" natürlich, denn diese Datei enthält
   das Programm und *muss* auf jeden Fall installiert werden.

(Anfänger)
   Falls Sie *nicht* wissen, was eine .SIS Datei ist, so ist dies 
   vermutlich eine Ihrer ersten Applikationen, die Sie selber 
   installieren. Keine Bange, es ist alles ganz einfach:

   Falls Sie das 'ältere' PsiWin 2.01 benützen oder falls Sie Hol5
   direkt  auf Ihren Psion heruntergeladen haben, dann ist es am
   besten, wenn Sie die Datei "Hol5.SIS" an einen geeigneten Ort
   auf Ihrem Psion kopieren. Falls die Datei auf dem Bildschirm mit
   einem Fragezeichen angezeigt wird, haben Sie Ihren Psion S5 
   noch nicht eingerichtet zum Verwenden von "EPOC Install".    
   Beschaffen Sie sich das INSTEXE.EXE Programm von 
   http://3lib.ukonline.co.uk/find/instexe.exe und klicken Sie dieses auf 
   Ihrem Psion an. Jetzt sollten Sie eine kleine Ikone bei der   
   "Hol5.SIS" Datei sehen. Diese klicken Sie an um die Installation 
   durchzuführen. Wiederholen Sie den Prozess für die Dateien 
   "Agenda2.SIS" und SistInfo.SIS, falls Sie diese nicht schon installiert 
   haben. Diese Dateien enthalten wichtige "Zutaten" ohne welche Hol5 
   nicht richtig arbeitet.

   Falls Sie PsiWin 2.1 verwenden, doppelklicken Sie die Datei 
   "Hol5.SIS" um "EPOC Install" auf Ihrem PC zu starten, und 
   folgen Sie den Instruktionen. Wiederholen Sie den Prozess für die 
   Dateien "Agenda2.SIS" und SistInfo.SIS, falls Sie diese nicht schon 
   installiert haben.
   
   Die Datei "Hol5Src.SIS" wird vom Programm nicht benötigt -
   aber vielleicht interessiert Sie der Quellcode?

   Falls alles gut ging, sollten Sie jetzt eine "Hol5" Ikone auf Ihrer
   Extraleiste finden.

** Entfernen

Wie jedes Programm, das über .SIS Dateien installiert wurde, lässt sich 
Hol5 am einfachsten entfernen über die "Hinzu./Entf." Option im
"System" auf der Symbolleiste: Programmnamen selektieren, und dann 
den "Entf." Knopf wählen.

** Upgrade vom Psion 3 zum Psion 5
 
Das Format der Psion 5 Feiertagsdateien ist rückwärts kompatibel zum
Format das Odd Gripenstams Programm für den Psion 3 verwendet.
Aber die Zeichensätze der beiden Maschinen sind verschieden - dies
betrifft alle Umlaute und andere spezielle Buchstaben.
Sie können also Ihre Feiertagsdateien vom Psion 3 auf den Psion 5 kopieren,
vergessen Sie aber nicht, diese gegebenenfalls zu editieren (sie 
können als Textdatei in die Psion Textverarbeitung Word 
importiert werden).

definiert. Einzelheiten sind in der Hilfedatei von Hol5 beschrieben.
