* HOL - calcul et report dans l'agenda des dates des fêtes 

** Fichiers contenus dans la distribution

Vous devriez avoir reçu les fichiers suivants:

  HOL5.SIS			L'application
  HOL5DEF.SIS			Les fichiers de définition des fêtes
  HOL5SRC.SIS			Le code source de HOL5
  Agenda2.SIS
  SystInfo.SIS
  Changes.txt			L'historique des modifications
  License.txt			Les conditions de licence
  Readme/LiesMich/LisezMoi.txt	Ce fichier en Anglais,Allemand,Français


Cette distribution de Hol5 contient un jeu de fichiers définissant les dates 
des fêtes pour différents pays, régions et religions.

Ces fichiers de définition sont des fichiers texte. Ils peuvent être adaptés
pour un besoin spécifique avec un simple éditeur, comme par exemple RMRText de
www.rmrsoft.com, ou par importation puis exportation dans l'application Texte 
du Psion5. Référez-vous à l'aide intégrée pour plus de détails.

** Installation

Avant toute chose, si vous avez modifié un fichier de définition venant
d'une version précédente, faites-en une copie de sauvegarde ou vérifiez
que son nom est différent de tout autre fichier inclus dans la présente
distribution

Après avoir "dézippé" Hol5.zip, vous devez disposer des fichiers mentionnés
au début de ce texte.

(Experts)
   Si vous savez ce qu'est un fichier SIS, double-cliquez dessus dans
   l'Explorateur Windows ou tapez sur son icône dans le Psion5 pour lancer
   la procédure d'installation.
   Si vous aviez installé précédemment des mises à jour intermédiaires pour la
   version précédente au format SIS, celles-ci sont incluses dans cette
   distribution. Le fichier "Hol5.SIS" contient l'ensemble de l'application
   à installer. Les fichiers de définition des fêtes sont inclus dans 
   "Hol5Def.SIS" qui est lancé par "Hol5.SIS" en cours de l'installation.

(Débutants)
   Si vous ne savez pas ce qu'est un fichier SIS, ceci doit être une des
   premières applications que vous installez sur votre Psion. Pas d'inquiétude,
   une telle installation est très simple:

   SI vous utilisez la version "ancienne" de PsiWin 2.01, ou encore si vous avez
   téléchargé Hol5 directement sur le Psion5, la première chose à faire est de
   placer le fichier "Hol5.SIS" dans un dossier de travail du Psion. Si l'icône
   associée au fichier représente un point d'interrogation, cela signifie que
   votre Psion n'est pas équipé du programme d'installation EPOC.
   Récupérez une copie du programme INSTEXE.EXE par exemple sur 
   	http://3lib.ukonline.co.uk/find/instexe.exe
   et exécutez-le sur le Psion.
   Vous devez obtenir une jolie icône associée au fichier "Hol5.SIS", et en la
   tapant avec le stylet vous lancerez l'installation de Hol5. REPETEZ ces
   opérations avec les fichiers "Agenda2.SIS" et "SistInfo.SIS", si ces deux
   modules ne sont pas déjà installés (ils contiennent les ingrédients magiques
   nécessaires pour que Hol5 puisse fonctionner.)

   SI vous utilisez PsiWin dans sa version 2.1, il vous suffit de cliquer deux
   fois sur l'icône de "Hol5.SIS" dans l'Explorateur pour installer Hol5
   depuis le PC sur le Psion. REPETEZ cette opération pour les deux fichiers
   "Agenda2.SIS" et "SistInfo.SIS", si ces deux modules ne sont pas déjà
   installés sur le Psion5.

   Hol5Src.SIS n'est pas nécessaire pour que Hol5 fonctionne, mais peut-être
   êtes-vous intéressé par la source du programme ? Ce fichier s'installe de
   la même façon...

   Si tout s'est bien passé, vous devez maintenant disposer de l'icône Hol5
   dans la barre Extras.

** Suppression

Comme pour toute application installée par un fichier SIS, il est recommandé
d'utiliser l'option Add/remove du panneau de configuration pour retirer Hol5.
Après avoir lancé ce programme, choisissez Hol5 dans la liste qui apparaît, puis
appuyez sur le bouton "Remove".

** Mise à jour du Psion 3 au Psion 5
 
Le format des fichiers de définition des fêtes de Hol5 pour le Psion5 
est compatible avec celui des fichiers de Hol pour le Psion3, MAIS 
les caractères accentués ou "spéciaux" sont codés de façon différente 
entre ces deux machines.
Si vous souhaitez continuer à utiliser les fichiers de définition que vous
aviez sur votre Psion3, vous devrez les éditer pour corriger ces caractères.
Pour ce faire, il suffit de les importer dans l'application interne Texte,
puis de les exporter au format texte après correction.
