JS Solutions jsBattery 1.0
--------------------------
(shareware)

jsBattery is the professional battery manager for Psion Series 5/5mx/5mx Pro
and Ericsson MC218 pocket computers. Besides common battery monitoring facilities
(including a graph view), it provides a number of advanced functions for getting
better information on batteries and better battery management.


Installation
------------
Simply run step-by-step all three supplied SIS files and follow the instructions.

Important: jsBattery is designed to run still on background whilst using your
pocket computer. Therefore it is strongly recommended to install jsBattery
on disk C instead of Compact Flast card (disk D). Running from CF card may also
disable the auto switch-off function of your pocket computer.


Starting jsBattery
------------------
You can run jsBattery from the Extras bar as usual.
