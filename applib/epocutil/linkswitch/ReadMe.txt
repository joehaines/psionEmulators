LinkSwitch v3.00
----------------
- LinkSwitch is compatible with the Psion Series 5, 5mx and 5mxPRO.
- With LinkSwitch you have a comfortable tool to control the remote
  link of your Psion.
- LinkSwitch uses an official UID.


Installation:
-------------
1. To install LinkSwitch.sis from your PC using PsiWin earlier
   than v2.1 you need to download "EPOC Install" from my homepage.
   This program requires Win 95/98.
   If you would like to install LinkSwitch.sis directly from your
   Psion, make sure you have an add/remove icon in the Control Panel.
   If not, download "Add/remove Control panel" from my homepage.
2. Either way, double-click LinkSwitch.sis.
3. SystInfo.sis and Sysram1.sis will be installed, too.
4. That's it! There will be a new icon on your Extras bar.


Usage:
------
Run LinkSwitch from System or the Extras bar.
If you disabled "Always start dialog first" AND "Wait for shortcut",
you will have to delete LinkSwitch.ini in the
\System\Apps\LinkSwitch folder to return to the dialog.
The LinkSwitch icon may indicate a wrong link status until you run
LinkSwitch for the first time.
Especially the Psion S5 needs a few seconds to change the icon.


UID:
----
LinkSwitch uses the official UID 268457349.
If you experience any conflicts with other applications, please
let me know.
