Locker v1.00
------------

This very small utility is meant for those who
need to protect their machines with a password
but find that the option 'Once a day' is not
enough and the option 'At switch on' is too much.

Locker will trigger the password identification
only if the machine is not used for a period of time.

It is based on the system password, so :

   - there is only one password to remember
   - it is fully proof, even against soft resets
   - it is compatible with all applications


Installation:
-------------
1 - Install the packages Locker.sis and Macro5Lib.sis
    as you do with all SIS files : double-click on them
    either on the PC or on the Series 5.
2 - If you don't already have them, install also SysRam1.sis
    and SystInfo.sis.


Usage:
------
Just start Locker from the Extras-bar.
Nothing will happen but the program
will be running. You can switch to
it and press :

   -> Enter to set the preferences or change the password
   -> Esc to switch back to the former task
   -> Del to quit

Shift+Esc will lock and switch off the machine.

When Locker exits, it restores the password mode
to the value set in Preferences.

You can set Locker not to close for the backups but
in this case it will also not close when you try
to do it from the tasklist.

Advanced feature : you can remove Locker from the tasklist
by pressing Tab when you are in Locker. When you've done
this, you cannot switch to Locker anymore. If you need to
change the preferences of Locker, close Locker and restart it.
When it is hidden, the only way to close Locker is to switch
to system, select the file \System\Apps\Locker\Locker.app
and use Menu->File->Close->File. If Locker is hidden, it
will not be closed by PsiWin for the backups.
