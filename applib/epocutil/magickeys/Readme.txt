2. INTRODUCTION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
MagicKeys performs two functions: 1) It offers a way to store and quickly 
insert text, sketch, and other items that you use frequently. 2) It can also 
collect and paste multiple items.

MagicKeys can be used in many tasks; inserting addresses, paragraphs, 
letterheads, e-mail addresses, and the list goes on. MagicKeys reduces 
keystrokes reducing errors in your typing.


The following are just some of the features MagicKeys provides:

- Create up to 999 entries per file.
- Create as many different files as you want.
- Text entries can be up to 5000 characters long.
- Insert time/date stamps into your documents using Plug-ins, or create your 
  own plug-ins!

4. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
1. If you are installing to a netBook or Series 7 unzip the file 
   netBook-Series7.zip and install that file instead.

2. There are 2 methods to install MagicKeys depending on where you have 
   copied the .sis file and what setup you have;
   
   - On a PC with PsiWin
     From the Windows Explorer double click the .sis file, this will 
     automatically install MagicKeys onto your machine. If that doesn't work 
     right click the My Psion icon and click the Install New Program option.
     If you do not have the Install New Program option then download
     setup.exe from our site or from Psion's site <http://www.psion.com>
     install it and try again.
   - On a EPOC machine
     Tap the .sis file to install, if this does not work then you do not
     have the Add/Remove utility, in this case download
     instexe.exe from our site, or psion's site <http://www.psion.com> and
     copy it to your machine and try again. 

3. Now press Extras|MagicKeys, to open.

4. To uninstall go to the Control Panel, tap the Add/Remove icon, select 
   MagicKeys and finally press the Remove button.


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
5. UPGRADING
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Upgrading from a previous releases is very simple just install the new 
version over the old version.

MagicKeys 2.XX file format is not the same as previous releases however 
MagicKeys will automatically upgrade your files when you open them for the 
first time. In the unlikely event that the conversion process fails your
original file will have the extension '.old'.
