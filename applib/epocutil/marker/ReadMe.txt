Installation Instructions

1. Unpack the Zip file to your PC or your Psion.

2. On the PC:
   Double click on the file Marker.SIS. This will start the
   automatic installation of Marker from the PC.
   On the Psion:
   Double tap on the file Marker.SIS. This will start the
   automatic installation of Marker from the Psion if the Add/Remove
   Control Panel is installed.

Marker should now be accessible to you from the Extras icon.
