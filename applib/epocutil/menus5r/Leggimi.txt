MENUS5 - Programma di avvio applicazioni (versione 2.6)
-------------------------------------------------------

Il file "MenuS5.zip" contiene i files di installazione per le macchine
Series5/5mx o MC218.
The file "MenuS5R.zip" contiene i files di installazione per il Revo.
The file "MenuS5s7.zip" contiene i files di installazione per le macchine
Series7 o netBook.

Per quanto concerne Revo, netBook and Series7, ovviamente non tenete
conto delle informazioni che riguardano la retroilluminazione e che sono
menzionate in questo file.


Siete stanchi di ricercare i programmi nella Barra Altro (visto, poi,
che si spostano ogni volta che ne installate uno di nuovo) ? allora usate MenuS5 !

-----------------
L'archivio dovrebbe contenere i seguenti files:
(MenuS5.sis include anche i seguenti files OPX)
SHPro.sis      	OPX file
AppInfo.sis	OPX file
Sysram1.sis    	OPX file
Systinfo.sis   	OPX file
Alarm.sis	OPX file

MenuS5.sis      Il programma 
Readme.txt      Istruzioni in Inglese
lisezmoi.txt    Istruzioni in Francese
liesmich.txt    Istruzioni in Tedesco

Una volta installato, vedrete che il programma consta dei seguenti files:

\System\Apps\Menus5\Menus5.app
\System\Apps\Menus5\Menus5.mbm
\System\Apps\Menus5\Menus5.aif
\System\Apps\Menus5\Menus5.hlp
\System\Apps\Menus5\Menusw.opo
\System\Apps\Menus5\Menus5.rsc
\System\Apps\Menus5\Morp.opo

I Cinque files OPX verranno installati nella cartella \System\Opx

INSTALLAZIONE
-------------
Il programma può essere installato in Inglese, Francese, Tedesco o Italiano.
Per installarlo è sufficiente dare doppio clic sul file Menus5.sis o selezionare
l'opzione "Installa nuovo programma" in PsiWin (EPOC Install).
Se avete PsiWin/EPOC Install v2.1 o superiore, l'operazione dovrebbe avvenire
automaticamente. Se ne avete una versione precedente vi serve il file di
installazione SETUP.EXE,che potete scaricare dalla Home Page di Psion
(http://www.psion.com).
Per installare direttamente sulla macchina EPOC, date doppio clic sul
file .sis; se l'installazione non avviene, probabilmente non avete l'utility
Aggiungi/Rimuovi nel Pannello di Controllo: in questo caso, scaricate il file
INSTEXE.EXE dalla Home Page di Psion (http://www.psion.com), copiatelo sulla
vostra macchina, installatelo e riprovate.

AVVIO DEL PROGRAMMA
-------------------
Potete avviare il programma Selezionando 'Extra' dalla barra dei programmi
e poi scegliendo Menus5.
