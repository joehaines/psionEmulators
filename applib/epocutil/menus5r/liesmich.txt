MENUS5 - Launcher (version 2.6)
-------------------------------

Die Datei "MenuS5.zip" enthält die Installationsdateien für
die Serie 5/5mx oder MC218 Maschinen.
Die Datei "MenuS5R.zip" enthält die Installationsdateien für
die revo/revoPLUS Maschinen.
Die Datei "MenuS5s7.zip" enthält die Installationsdateien für
die Serie 7 und netBook Maschinen.

Revo, netBook und Serie7 Benutzer können Hinweise betreffend
Hintergrundbleuchtung übergehen.

Müde, in der Extrasleiste Ihre Programme zu suchen (welche jedesmal,
wenn ein Neues hinzugefügt wird, wieder verschoben werden)?
Dann ist MenuS5 das Richtige!

INSTALLATION
------------
Das Programm kann in englisch, französisch oder deutsch installiert werden.
Um es zu installieren, kann einfach auf die Datei Menus5.sis geklickt
werden oder in PsiWin die 'Neues Programm installieren' Option gewählt
werden (EPOC Install).
Wenn Sie PsiWin/EPOC Install v2.1 oder höher haben, wird alles automatisch
ablaufen. Falls Sie eine ältere Version besitzen, benötigen Sie die
Installationsdatei SETUP.EXE, welche Sie auf der Psion Homepage
(http://www.psion.com) herunerladen können.
Wollen Sie MenuS5 direkt auf Ihrer EPCOC Maschine installieren,
doppelklicken Sie die .sis Datei. Funktioniert dies nicht, ist das
Hinzufügen/Entfernen Hilfsprogramm nicht installiert. In diesem Fall
laden Sie INSTEXE.EXE von der Psion Homepage (http://www.psion.com)
herunter, kopieren diese Datei auf Ihre Maschine, starten die Datei
und versuchen es nochmals.

Das Programm starten
--------------------
Um das Programm zu starten, wählen Sie die Folientaste 'Extras'
und klicken dort MenuS5 an.
