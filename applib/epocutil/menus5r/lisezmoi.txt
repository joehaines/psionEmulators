MENUS5 - Lanceur d'applications (version 2.6)
---------------------------------------------

Le fichier "MenuS5.zip" contient les fichiers d'installation
pour les machines suivantes: Series5/5mx et MC218.
Le fichier "MenuS5R.zip" contient les fichiers d'installation
pour la machine suivante: Revo.
Le fichier "MenuS5S7.zip" contient les fichiers d'installation
pour les machines suivantes: Series7 et netBook.

En ce qui concerne le Revo, veuillez ne pas tenir compte des
indications du présent fichier se rapportant au rétro-éclairage.



Fatigué de chercher vos programmes dans la barre d'Extra
(qui changent d'ordre chaque fois que vous en ajouter un) ?
Alors, utilisez MenuS5 !

Ce programme est propriété d'Henri Spagnolo.

tenu responsable en cas d'erreurs causées par ce programme
et pouvant résulter à des pertes de données ou a tout autre
problème que ce soit.

Quoi de neuf dans la version 2.6
- Correction d'un petit problème avec les liens sur les dossiers (avec la

Quoi de neuf dans la version 2.5

- Modification de la function Julien, il est possible maintenant d'utiliser
  en entrée soit la date, soit le julien.
- Modification de la fonction "Quitter", la boîte de dialogue "sauvegarde"
  peut être désactivée dorénavant. Afin de la réactiver, une entrée à été
  ajoutée dans le menu.

MISE A JOUR
-----------
Lors de l'installation d'une nouvelle version (mise à jour), veuillez
fermer le programme, puis installer la mise à jour, sur le même disque
que la précédente version, SANS DESINSTALLER l'ancienne version.

INTRODUCTION
------------
Bienvenu dans MenuS5, lanceur d'applications et de documents pour
les machines EPOC (Psion Series 5).
MenuS5 inclu un bon nombre d'autres utilitaires.

DETAILS DES FICHIERS
--------------------
Le fichier compressé (archive) doit contenir les fichiers suivants:
(le fichier MenuS5.sis contient les fichiers SIS ci-dessous)
  SHPro.sis       	Fichier OPX
  AppInfo.sis		Fichier OPX
  Sysram1.sis     	Fichier OPX
  Systinfo.sis    	Fichier OPX
  Alarm.sis	    	Fichier OPX

MenuS5.sis       	Le programme
Readme.txt      	Instructions en anglais
lisezmoi.txt    	Instructions en français
liesmich.txt    	Instructions en allemand
leggimi.txt		Instructions en italien

Liste des fichiers une fois l'installation effectuée:

\System\Apps\Menus5\Menus5.app
\System\Apps\Menus5\Menus5.mbm
\System\Apps\Menus5\Menus5.aif
\System\Apps\Menus5\Menus5.hlp
\System\Apps\Menus5\Menusw.opo
\System\Apps\Menus5\Menus5.rsc
\System\Apps\Menus5\Morp.opo
\System\Apps\Menus5\empty


Les cinq autres fichier OPX seront installé dans \System\Opx

INSTALLATION
------------
Le programme peut être installé en français ou en anglais.
Afin d'installer le programme, double-cliquez simplement sur le
fichier MenuS5.SIS ou sélectionnez l'option "Installer un nouveau
programme" dans PsiWin.
Si vous êtes en possession de PsiWin v2.1 ou supérieure, l'installation
se fera automatiquement.
Si vous avez une version antérieure, vous devrez alors lancé le
programme d'installation SETUP.EXE, qui peut être téléchargé sur la
Home Page de Psion (http://www.psion.com).
Si vous désirez l'installer directement depuis votre Psion, copiez
les fichiers décompressés dans un répertoire de votre choix,
puis cliquez sur les fichiers SIS, si cela ne fonctionne pas,
vous devrez télécharger le fichier INSTEXE.EXE, qui peut être téléchargé
sur la Home Page de Psion (http://www.psion.com).

LANCER LE PROGRAMME
-------------------
Lancer le programme en sélectionnant MenuS5 depuis la barre
d'Extra.
