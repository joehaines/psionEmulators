2. Einführung
-------------
MagicKeys führt zwei Funktionen aus: 1) Es ist ein Makroprogramm, um 
schnell Text in eine Applikation einzufügen (Autotext-Funktion). 2) Es 
ist auch ein Zwischenablage-Utility, welches sich an alle Daten erinnert,
die in die Zwischenablage kopiert oder ausgeschnitten wurden.

Dies sind nur einige Eigenschaften von MagicKeys:
- Speichern von bis zu 999 verschiedenen Texten pro Datei
- Sie können soviele Dateien kreieren, wie Sie wollen
- Einsetzen von Zeit/Datum in Ihre Dokumente
- Ausschneiden oder Kopieren von Text: MagicKeys erinnert sich

4. INSTALLATION
---------------               
1. Je nach dem, wohin Sie die .sis Datei kopiert haben, gibt es zwei 
   Möglichkeiten Magickeys zu installieren:
   
   - Auf einem PC mit PsiWin
     Ein Doppelklick auf die .sis Datei im Windows Explorer installiert 
     MagicKeys automatisch auf Ihrer Maschine. Sollte das nicht 
     funktionieren, klicken Sie auf den Psion Arbeitsplatz und benützen 
     Sie die Option "Neues Programm installieren" Fehlt diese Option, 
     laden Sie setup.exe von Psions Seite <http://www.psion.com> 
     herunter, installieren Sie diese Datei und versuchen es nocheinmal.
     
   - Auf einer EPOC32 Maschine
     Klicken Sie die .sis Datei um zu installieren, Wenn das nicht 
     funktioniert, haben Sie das Hinzufügen/Entfernen-Utility
     noch nicht. In diesem Fall können Sie instexe.exe von unserer
     Seeite oder von Psions Seite <http://www.psion.com>
     herunterladen, auf Ihre Maschine kopieren und nochmals versuchen. 

3. Folgende 1 OPX müssen ebenfalls installiert werden:Y
   VWin.sis können wie MagicKeys.sis installiert werden.

4. Um MagicKeys zu benützen, einfach Extras|MagicKeys drücken

5. Um zu entfernen, in die Systemsteuerung gehen, das 
   Hinzufügen/Entfernen-Icon drücken, MagicKeys auswählen und den
   Entfernen-Knopf drücken.
