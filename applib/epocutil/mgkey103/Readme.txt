2. INTRODUCTION
---------------
MagicKeys performs two functions: 1) It is a macro program for quickly 
inserting text unsing only a few keystrokes. 2) It is also a clipboard 
utility remembering every piece of data that you cut or copy!

The following are just some of the features MagicKeys provides:

- Store up to 999 text replacements per file.
- Create as many different text replacement files as you want.
- Text replacements can be up to 3000 characters long.
- Insert time/date stamps into your documents.
- Cut or copy text remembering every piece of data.

4. INSTALLATION
---------------               
1. There are 2 methods to install MagicKeys depending on where you have 
   copied the .sis file and what setup you have;
   
   - On a PC with PsiWin
     From the Windows Explorer double click the .sis file, this will 
     automatically install MagicKeys onto your machine. If that
     doesn't work right click the My Psion icon and click the Install New 
     Program option.
     If you do not have the Install New Program option then download
     setup.exe from our site or from Psion's site <http://www.psion.com>
     install it and try again.
   - On a EPOC32 Machine
     Tap the .sis file to install, if this does not work then you do not
     have the Add/Remove utility, in this case download
     instexe.exe from our site, or psion's site <http://www.psion.com> and
     copy it to your machine and try again. 

3. You also need to install 1 OPX:
   For VWin.sis just install using the same procedure as for installing 
   MagicKeys.sis

4. Now press Extras|MagicKeys, to use.

5. To uninstall go to the Control Panel, tap the Add/Remove icon, select 
   MagicKeys and finally press the Remove button.


For the latest version of MagicKeys visit: <http://www.fatcatz.tm>
