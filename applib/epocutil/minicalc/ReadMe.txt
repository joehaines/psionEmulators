MiniCalc
========

A mini calculator and a powerful Business & Finance calculator
for all Epoc machines: Psion Series 5 and 5mx, GeoFox-One,
Revo and Series 7, 

Shareware proposed by Kylom and Pocket IQ.

E-mail         : Kylom@pocketIQ.com
Homepage       : http//www.kylom.com
Latest version : v5.10b

MiniCalc is a mimic of the Calc standard application of Psion
Series 5. The difference is that it takes only a fraction of
the screen surface...

With its "BusFin" screens, MiniCalc is also a very powerful
Business and Finance calculator. Press Ctrl+P...

See Changes.txt for changes from older versions.


Installation:
=============
The installation file is MiniCalc.SIS.

There are two ways of using a **.SIS installation file:
- from a PC (if PsiWin 2.x is installed), double-click on the file
  **.SIS (this can be done from the WinZip window, even without
  unzipping the **.SIS file)
- from the Epoc machine itself (if there is an Add/Remove icon in the
  Control panel): copy the **.SIS file anywhere on your Series 5 and
  double-tap it.

The advantage of the first method is that it requires the minimum
number of actions from the user. The disadvantage is that it stops
all running applications on the Epoc machine before installing the
new files.

The advantage of the second method is that it does not close all
applications on the Epoc machine. The disadvantage is that it requires
unzipping the **.SIS file and copying it to the Series 5... 


Note to the users of versions before 5.09: 
==========================================
Before version 5.09, the BusFin screens were stored in a file called
MiniCalc.dbf, installed by an installation file called BusFin.SIS.
This version of MiniCalc uses a file called MiniBase, which is built
during the first run with data available in MiniData. During the first
run, MiniCalc also looks for any existing MiniCalc.dbf file. If it finds
one, it offers the user to convert the exiting BusFin data from this file
to the new format. The user can chose to do so if he has already created
his own BusFin screens with an older version of MiniCalc. Otherwise, he
can chose to use the fresh data.

After the first run, MiniCalc.dbf and MiniData are deleted. All data are
in MiniBase.

The user can also complete the cleanup of his machine by "removing"
BusFin with the command Add/remove in the Control Panel.


Startup
=======
After a correct installation, you should have the following files in
the following folders on your machine:

\System\Apps\MiniCalc\MiniCalc.aif
\System\Apps\MiniCalc\MiniCalc.app
\System\Apps\MiniCalc\MiniCalc.hlp
\System\Apps\MiniCalc\MiniData  (renamed to MiniBase after the first run) 
\System\Opx\SysRAM1.opx

Start MiniCalc like any other application, from the Extras toolbar.
You can use it like Calc, either from the keyboard, or with the
pen. Press Ctrl+Esc, or Ctrl+B, or tap the screen outside of MiniCalc
to send it to the background. Press Ctrl+Fn+M to call it back...
Press Ctrl+S to make it even smaller... Use the pointer (in the display
window of MiniCalc) or the arrows (with Fn or Ctrl+Fn for speed) to
move it around the screen...

Ctrl+H opens the online Help with all necessary instructions.
