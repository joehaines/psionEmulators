Introduction
MiniCalc is a 8 digit floating point calculator for EPOC machines. The calculator supports the four basic arithmetic operators, plus squares, square roots, percentage and memory functions with memory content display. The calculator is operated by tapping the on-screen keypad with the pen pointer.
It's not necessary to include a help file with the program.

Suitable EPOC machines
Minicalc will run on all of the following machines:
Series 7/Netbook
Series 5/5mx
Revo/Revo Plus
MC218
Geofox one
Osarsis

Installation instructions
Copy the Minicalc folder to the EPOC machine.
Double tap on the MiniCalc.sis file.  This will start the automatic installation of MiniCalc.
When installed, MiniCalc will be accessible from the Extras bar.
