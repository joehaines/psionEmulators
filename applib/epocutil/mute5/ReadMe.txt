Mute5 v1.00
--------------
- Mute5 is compatible with the Psion Series 5, 5mx and 5mxPRO.
- With Mute5 you can switch the sound on or off with one single
  click on the Mute5 icon. Moreover the icon shows you whether the
  sound is switched on or off.
- Mute5 uses an official UID.


Installation:
-------------
1. To install Mute5.sis from your PC using PsiWin earlier
   than v2.1 you need to download "EPOC Install" from my homepage.
   This program requires Win 95/98.
   If you would like to install Mute5.sis directly from your
   Psion, make sure you have an add/remove icon in the Control Panel.
   If not, download "Add/remove Control panel" from my homepage.
2. Either way, run Mute5.sis.
3. Systinfo.sis will be installed, too.
4. That's it! There will be a new icon on your Extras bar.


Usage:
------
Run Mute5 from System or the Extras bar.
When you run Mute5 for the first time, an information dialog will be
displayed.
The Mute5 icon may indicate a wrong sound status until you run Mute5
for the first time.
Especially the Psion S5 needs a few seconds to change the icon.


UID:
----
Mute5 uses the official UID 268457352.
If you experience any conflicts with other applications, please
let me know.
