NoteIt V1.04 Lite Freeware
==========================

NoteIt simply do:

- Add, Edit or Delete a list of dated notes
- Order notes
- View a specific dated notes
- Attach object Word,Sheet,Sketch or Record
- Find facility
- Export notes as text file
- Merge in NoteIt file

----------------------------------------------------------------------------------------
INSTALLATION
----------------------------------------------------------------------------------------

To install, copy the following files into <any drive>:\System\Apps\NoteIt folder.

NoteIt.app		- Application file
NoteIt.mbm		- Bitmaps and Icons
NoteIt.aif		- Information file
NoteIt.hlp		- help file

Copy the following file into a c:\System\Opx folder.

sysram1.opx		- System opx file



IMPORTANT NOTE FOR USERS OF PREVIOUSLY VERSION !!!
--------------------------------------------------

From 1.03 version the NoteIt datafile has changed and the program will convert old files automatically. The old files will come renamed with the extension ~bak.
Make sure that all linked documents are closed otherwise it won't come saved correctly.
