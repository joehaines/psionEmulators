What is NightKeys?

NightKeys is a utility program for the Psion Series 5
which provides an on screen keyboard.  It is designed to
allow key input in the dark when the keyboard is not
visible - hence the name.

_________________________
Installation Instructions.

1. Install NightKeys.sis
2. Install Neuon.sis
3. If you already have sysram1.opx in \system\opx\ then installation is
   complete.  Otherwise, install sysram1.sis

NightKeys should now be accessible to you from the Extras icon.

_______________
Program History

This is the first upgrade of NightKeys.  The changes since
version 1.0 are as follows:

1) The application now makes use of OPL+
2) The internal structure of the application has been improved
3) An application resource file is now used
4) The application's appearance has been improved
5) The following features have been added
    o  Stay-on-top has been implemented
    o  Control,Shift and Function keys have been added
    o  A help file has been included
    o  Move to background has been implemented
    o  Shift lock and Function lock are provided
    o  Control keys (and Shift+Ctrl keys) can now be generated
    o  Moving the application off screen iconises the application
