NoMore
	Freeware from H2 Software

What is it?
	Hides/restores  programs on the Extras bar and automatically 
	cretes a link (aka  shortcut) so they can be run from within 
	a folder instead.  

	Works with programs installed on drives C:\ & D:\
	See the Help file for hiding ROM based  (drive Z:\) programs 
	(e.g. Spell, Program, Comms, Record, Bombs)

Installation
	Install the following files to \System\Apps\NoMore\
		NoMore.app
		NoMore.aif
		NoMore.hlp
		NoMore.mbm

Please read the Help file topic "Important notes" 
and  report any difficult programs, bugs or problems
