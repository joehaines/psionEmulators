NumLock v2.00
-------------

Ce petit utilitaire a été conçu spécialement
pour les claviers AZERTY. Il permet d'inverser
le mode normal/majuscule de la rangée supérieure
du clavier de manière à pouvoir entrer les nombres
sans avoir à appuyer sur la touche Maj.


Installation:
-------------
Exécuter les fichiers NumLock.sis et Macro5Lib.sis
en double cliquant dessus, soit à partir de votre
PC (si PsiWin >= 2.1 est installé), soit directement
sur votre Series 5 (si il y a une icône Add/Remove
dans le panneau de configuration).


Utilisation :
-------------
Démarrez simplement NumLock à partir de l'Extras-bar
ou de l'écran système. Une icône apparaîtra en
haut à droite de l'écran pour indiquer le mode
courant :

   -   = mode normal
   - A = mode majuscule
   - 5 = mode numérique

Pour changer de mode, appuyez sur Fn+Tab ou cliquez
sur l'icône :

   - mode normal, clic court => mode majuscule
                       long  => mode numérique

   - mode majuscule, clic court => mode normal
                          long  => mode numérique

   - mode numérique, clic court => mode majuscule
                          long  => mode normal

En résumé, un clic court fait passer du mode normal au mode
majuscule et réciproquement. Un clic long (>300 ms) active
ou désactive le mode numérique.

Un clic de plus d'une seconde fait appaître le panneau
de commandes :

   - 'Esc' cache le panneau de commande
   - 'Eff' ferme NumLock
   - 'Entrée' affiche le panneau de configuration :
        + Délais clic long (1/100s) : temps maximum d'un clic court
                                            minimum d'un clic long
        + Clic court/long : affecte les clics courts/longs aux modes majuscule/numérique
        + Cacher icône après 2s : inhibe l'affichage permanent de l'icône
        + Position icône : position de l'icône dans l'un des 4 coins de l'écran
        + Démarrer en mode Num : démarre Numlock en mode numérique
        + Inverser ; et . en mode Num : facilite l'entrée des nombres décimals


Améliorations prévues :
-----------------------
Aucune, mais j'attends vos suggestions.


Problèmes connus :
------------------
Lorsque NumLock est lancé, la rangée supérieure
du clavier est inopérante pour la saisie du mot
de passe système. En conséquence, n'utilisez pas
les caractères de cette rangée pour votre mot de
passe. Si par mégarde vous avez choisi l'un de
ces caractères et que le système vous refuse
l'accès à votre machine, effectuez simplement
une remise à zéro sans pertes de données. Cela
arrêtera NumLock et vous permettra d'entrer
votre mot de passe.
