Introduction
PBcalc is an 8-digit floating-point calculator for EPOC. The calculator supports the four basic arithmetic operators, plus squares, square roots, percentage and memory functions with memory content display. The calculator is operated by tapping the on-screen keypad with the pen pointer.
It is not necessary to include a help file with the program.

PBcalc will run on all of the following EPOC machines:
Series 7/Netbook
Series 5/5mx
Revo/Revo Plus
Diamond Mako
MC218
Osarsis

Installation instructions
Copy the PBcalc folder to the EPOC machine.
If you already have an Add/Remove control panel on your palmtop, simply double tap on the PBcalc.sis file.  This will start the automatic installation of PBcalc.

NOTE: If you do not have an Add/Remove control panel on your palmtop machine, copy the instexe.exe file direct to your palmtop computer (you will find a copy on the Palmtop CD). Open instexe.exe - it will install the control panel and then delete itself.

When installed, PBcalc will be accessible from the Extras bar.
