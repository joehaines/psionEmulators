Series 5 printer driver enhancements
=====================================

Since the release of ROM version 1.01(145) a number of enhancements have been made to the printer drivers for use with the Series 5.  These enhanced drivers have now been made available to Psion Computers, who in turn are releasing them free of charge to Series 5 customers.


A description of the enhancements can be found on www.psion.com

INSTALLATION
============

The enhanced drivers will be distributed by means of a .sis file - Updated Printer Drivers 1.00

1. Copy the file Printers.sis to a temporary folder on your PC
2. Using MacConnect or PsiWin 2.1 and above double-click on the .sis to install the new drivers


The .sis file will install the drivers to any drive in \system\printers\ 
Updated Printer Drivers 1.00 will appear in the add/remove programs in the control panel.
