PsiBATT Version 1.01

Features:

1. scrollable diagram width, up to 57h
2. adjustable update interval (60 sec. to 3 min.)
3. adjustable alarm in 0.1V steps, from 3.0V up to 2.0V
4. supports the toolbar, menu, pen events, and key events
5. tip on the screen, between the toolbar and the right 
   edge of the screen (with your thumbnail) to bring PsiBATT 
   to the foreground

Installation:

1. after extracting the zip file, copy all files into one folder
2. zip file contains the files: PsiBatt.mbm
				PsiBatt.aif
				PsiBatt.app
				readme.txt
3. the Sysinfo1.opx must be installed
