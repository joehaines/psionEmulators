PsiWallpaper
============
Version 1.0 -July 1999

Introduction
------------
This program, version 1.0, is written specifially for the Series 5mx.  It is
a small, but fun utility to change the wallpaper, displayed on the system
screen, when you switch on you Psion.  This will mean that you will never get
bored with the same old picture or the EPOC logo!  The wallpapers are at
there best when your 5mx is in 16 Grey mode, more on that later.

File Details
============
The zip file should contain the following files:

	READMEwallpaperSIS.txt (this file)
	PsiWallpaper.SIS (instalation file for PsiWallpaper)
	Pictures.sis (instalation file for my designed wallapers)
	16GreysINI.sis (instalation file for 16 Grey scale mode)
	pscape.SIS (instalation file for shaired Palmscape files)

INSTALLATION
------------
To install the program simply double-click on the PsiWallpaper.SIS file or
select the "Install New Program" option in PSIWIN (EPOC Install).   If you
have the latest PSIWIN or EPOC Install then everything will happen
automatically.    If you don't have these then you need to get the
installation file SETUP.EXE, which can be downloaded from PalmScape's Home
Page.

Then double-click on the Pscape.SIS to install the essential Pamscape shared
files.

Then double-click on the Pictures.SIS to install my specially designed
wallpaper pictures.  Remember, you can always create your own and can delete
any of the ones supplied here - please reefer to your Psion Series 5mx
handbook for information on how to do this (Sketch section).

Then double-click on the 16GreysINI.SIS to install the special initialisation
file.  This file gives you a new system initialisation file for your Psion
with an added line to put your Psion in 16 Grey Scale mode, rather then 4
Greys.  This file is only read when the 5mx boots or is re-set, therefore it
is essential that this is carried out with due care.  First, it is recomended
that you install this on a compact flash (disk D:), this way, if the Psion
fails to re-start, you can just remove the card and try again then delete the
file (System\Data\Wsini.ini).  Once this file has been installed you will
need to re-set your Psion to activate this.  First ensure that all your data
is backed up (preferabbly do this before you install 16GreysINI.sis, that
way, if there is a problem it should not re-occur once the data has been
restored) and that no programs are running, then and only then find the reset
point (the little gold tab in the backup battery compartment), switch the
Psion off and press it gently with a suitably thin object.  Close the cover
and then switch the Psion back on, after a few moments, you will see the 5mx
screen and then the System screen will be displayed - allow about 30 seconds
for this.  All you will loose is the display settings on the System screen
and some of the changes on the Extras Bar if you have customised the position
of the program icons.  I have carried out this process on my 5mx with no
problems.

You can also copy the SIS files directly to your Psion 5mx and double select
them to launch the install program.

RUNNING THE PROGRAM
-------------------
Start the program by selecting the 'Extras' from the Application bar and then
'PsiWallpaper'.

Enjoy!

On-line help is provided and can be accessed from Help button.
