QuickNote is a program that lets you quickly make simple
notes by drawing on the screen and typing text.

To install this program run QuickNote.sis

If you have any problems email tixy@clara.net

For the latest version check www.tixy.clara.net/psion

-------------------------------------------------------------

Revision history. 

Version 1.13 - 15th July 1999 
  * Fixed a bug which meant changes to the current page were
    lost if QuickNote was closed from the 'Open files/programs'
    list or closed by PsiWin.

Version 1.12 - 5th July 1999 
  * Fixed a bug that caused a 'Folder does not exist' error. 

Version 1.11 - 1st May 1999
  * Made the Ctrl+Left and Ctrl+Right keys move between pages.
  * Fixed a bug that occurred when inserting a page after the
    last one in the notebook.

Version 1.10 - 18th April 1999
  * Added the facility to time-stamp notes.
  * Fixed a bug that an error when both 'Bring to foreground at
    switch on' and 'Always start on new page' options were set
    and the last notebook page had not been saved. (This caused
    an 'End of file' error whenever QuickNote was started.)

Version 1.01 - 14th April 1999 
  * Fixed a bug that meant the 'Bring to foreground at switch on'
    option was always set.

Version 1.00 - 13th April 1999 
  * Initial release.
