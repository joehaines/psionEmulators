Installation
------------
If the QuickLink.zip file was unzipped successfully, you should have this text file
and two SIS installation files - Systinfo.sis (by Otfried Cheong) and QuickLink.sis
The Systinfo.sis file installs the Systinfo.opx which is REQUIRED by QuickLink

If you know what a SIS file is, just double click on each SIS file in Explorer
or tap on it on your Psion 5, and QuickLink will be installed either to the C: or D:
drive (depending on your choice).

If you don't know what a SIS file is, follow these instructions:

If you have PsiWin 2.1, double click on the QuickLink.sis file from Explorer to
install it directly to your Psion.

If you have PsiWin 2.0 or if you have the QuickLink.sis file on your Psion 5 with a 
question mark alongside it, you do not yet have the facility to install SIS files to
your Psion 5 ...

* Grab a copy of the INSTEXE.EXE file from http://www.skilton.net and tap on it on
  your Psion 5. After installation, an icon should appear alongside the QuickLink.sis
  file.
* Tap on this file to install QuickLink - select the drive you want to install to, and
  the installation should proceed successfully!

If everything proceeded successfully, you should have the QuickLink icon in your Extras
bar, ready to run!

Note that you must install both the QuickLink.sis file and the Systinfo.sis file (which
installs the REQUIRED Systinfo.opx file by Otfried Cheong)
