Installation
------------
If the QuickSound.zip file was unzipped successfully, you should have this text file
and the SIS installation file - QuickSound.sis

If you know what a SIS file is, just double click on QuickSound.sis in Explorer
or tap on it on your Psion 5, and QuickSound will be installed either to the C: or D:
drive (depending on your choice).

If you don't know what a SIS file is, follow these instructions:

If you have PsiWin 2.1, double click on the QuickSound.sis file from Explorer to
install it directly to your Psion.

If you have PsiWin 2.0 or if you have the QuickSound.sis file on your Psion 5 with a 
question mark alongside it, you do not yet have the facility to install SIS files to
your Psion 5 ...

* Grab a copy of the INSTEXE.EXE file from http://www.skilton.net and tap on it on
  your Psion 5. After installation, an icon should appear alongside the QuickSound.sis
  file.
* Tap on this file to install QuickSound - select the drive you want to install to, and
  the installation should proceed successfully!

If everything proceeded successfully, you should have the QuickSound icon in your Extras
bar, ready to run!
