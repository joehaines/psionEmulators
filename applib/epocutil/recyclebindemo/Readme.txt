INSTALLATION

There are two ways to install Recycle Bin on your device. The first way:

1. Download the RecycleBin.zip file to your PC.
2. Unpack the Zip file contents, and double click on RecycleBin.SIS file.
3. Follow the instructions which will guide you through the installation process.

The second way:

1. Download the RecycleBin.zip file to your PC.
2. Unpack the Zip file contents.
3. Upload RecycleBin.SIS file on your device.
4. Double click on RecycleBin.SIS file there.
5. Follow the instructions which will guide you through the installation process.

DESCRIPTION

Have you ever deleted your file by accident? Do you want to protect yourself from such
problems? Recycle Bin will protect you! It's almost like Recycle Bin in Windows 95.

File or folder you delete in System are stored in Recycle Bin. They are not removed from
your disk until you empty Recycle Bin. You can restore deleted files and folders from
Recycle Bin at any time.

REQUIREMENTS

Psion Series 5/5mx, Revo, Series 7 or netBook.

LIMITATIONS

Recycle Bin does not work on Ericsson MC 218 devices.
