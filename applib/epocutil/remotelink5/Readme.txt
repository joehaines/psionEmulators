Medialinx RemoteLink5 (Freeware)
Version 1.00 for EPOC/32


Overview
========

RemoteLink5 is a small EPOC/32 utility that automatically
disables your Remote Link everytime you turn on your Psion. The
reason I wrote this program was because I always forget to turn
my Remote Link off when I have finished using it. The Remote Link
uses memory and power even when it is not plugged in. So this
program was designed to save battery power and memory.


Installation
============

To install RemoteLink5 on to your computer you must follow these
simple steps:

1. Create a directory called RemoteLink5 in your System\Apps
   directory.

2. Copy RemoteLink5.app, RemoteLink5.mbm and RemoteLink5.aif to
   this directory.

3. Install the RMR Software SYSTINFO OPX file by running
   Systinfo.sis from the System Screen. You cannot use RemoteLink5
   without this file.


Executing RemoteLink5
=====================

1. To disable the Remote Link on startup run RemoteLink5 from
   the Extras bar.
   
2. Select YES and leave RemoteLink5 running in the background.

3. If you want to exit RemoteLink5 simply select NO from the
   RemoteLink5 dialog.
