INSTALLATION

There are two ways to install Restart on your device. The first way:

1. Download the Restart.zip file to your PC.
2. Unpack the Zip file contents, and double click on Restart.SIS file.
3. Follow the instructions which will guide you through the installation process.

The second way:

1. Download the Restart.zip file to your PC.
2. Unpack the Zip file contents.
3. Upload Restart.SIS file on your device.
4. Double click on Restart.SIS file there.
5. Follow the instructions which will guide you through the installation process.

DESCRIPTION

Restart is a small utility, which allows you to restart (reboot, reload,
perform a soft reset) your Psion palmtop.

There are two reasons why you need this program:

1. You installed some third party software and it doesn't work properly. It does
not want to exit or it damaged your System somehow. Restart your device. It will
close all programs and clean your System!

2. You noticed that the space on the disk is reducing. The reason is that some
third party software have memory leakages. They allocate memory and do not free it.
Restart your device. It will free all the lost memory!

Of course, you can perform soft reset manually by pressing a hidden Reset button with
paper-clip. It will have the same results as using Restart utility. But:

1. Using Restart is much easier and faster.
2. You can break the device if performing manual soft reset regularly.

USAGE

You can access Restart through the Control panel.

Warning: Close all open documents before restarting the device, otherwise
all changes will be lost!
