INTRODUCTION
------------
RMRMonth is the perfect companion for EPOC's Agenda application, 
providing many new features to help schedule your day to day entries 
more quickly and efficiently.

The following are just some of the features RMRMonth provides:

- Month view (Month-at-a-glance)
- List view for day and month
- Improved to-do listing
- Planner  
- Many print options for printing the month and to-do views
- Private entries
- Multiple zooms
- Auto text wrapping to fix as much text in a cell
- Export as text
- Full pen and/or keyboard control
- and much much more!


As it stands, this Shareware version is is fully functional however it reminds you to register:

- Future dates cannot be viewed.
- A nag screen will appear when RMRMonth is first started.
- A nag message will be printed when you use the print features.

Please note that registration does not involve reloading the program, but simply selecting the 'Register' menu option and typing in a registration code to release the 'lock'.

INSTALLATION
------------

***********************************************************
* If you are upgrading please re-install all the .sis file *
***********************************************************

To install the program simply double-click on the RMRMonth.SIS file or select the "Install New Program" option in PsiWin (EPOC Install). If you have PsiWin/EPOC Install v2.1 or above, then everything will happen automatically. If you have an earlier version, you will need to get the installation file SETUP.EXE, which can be downloaded from our Home Page. If you are unsure, then go to http://www.rmrsoft.com/ and follow the link to the 'SIS' page for a full explanation of the installation procedure.

Once the program is installed, just repeat the operation for the RMROpx.sis, Agenda2.sis, Gprinter.sis and VWin.sis files as well. These OPXs are installed separately. so that a subsequent removal of the main program using the "Add/Remove" option on Control Panel will not delete these OPX files, some of which are used by other programs. Under no circumstances should you use the "Add/Remove" option on the RMROPX file entry.


RUNNING THE PROGRAM
-------------------
Start the program by selecting 'Extras' from the Application bar and then selecting RMRMonth
