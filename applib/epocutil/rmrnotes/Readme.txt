INTRODUCTION

Welcome to my 'Jotter' program for the EPOC Series of handheld computers.

As it stands, this Shareware version is fully-working with no disabled functions, but will allow only a limited number of entries, to enable you to try the program out.  Please note that registration does not involve reloading the program, but simply selecting the'Register' menu option and  typing in a registration code to release the 'lock'.

INSTALLATION

To install the program simply double-click on the RMRNotes.sis file or select the "Install New Program" option in PSIWIN (EPOC Install). 

RUNNING THE PROGRAM

Start the program by selecting the 'Extras' from the Application bar and then 'RMRNotes'

If you fancy a challenge, you can learn everything you need to about the program by playing with it and checking the effect of each MENU selection, as well as the effect of pressing <ENTER>, <DELETE>, <TAB>, or <ESC>, in each screen, by observing the effect of touching various parts of the screen with the pen, and by reading the on-line Help file.  However, PLEASE, PLEASE, PLEASE, at least read the rest of this file first, for some very important information.

IMPORTANT POINTS

Please note the following:

1.    The configuration file (RMRNotes.ini) and registration details (RMRNotes.reg) are saved in the same folder as the application files, but on the C: drive  (C:\System\Apps\RMRNotes\), so don't be surprised if you lose that information (and registration) if you delete these files.

2.    Please  do NOT try changing the name of, or moving,  a Group from the system screen just by renaming the document file.  The title you use for a Group is used for all the data files, not just the one in the document folder.  If you do wish to move or  rename a Group, simply use the "Move group" or 'Save as' file command from within the Program.

3.    I have provided a BACKUP and RESTORE option (<Shift+Ctrl+B> and <Shift+Ctrl+R> in the main screen) to enable you to keep a COMPLETE copy of all your data files somewhere else on the system.  Although there were only 2 recorded cases of complete data loss in S3ANOTES, I am not so arrogant as to say that the transfer to the 32-bit system was perfect and there isn't a 'bug' lurking in there waiting to trap the unwary. Personally I use this option every couple of days, as well as backing up regularly on a PC. I do think the program is safe, but even I still wouldn't trust it completely.  Basically, if you lose some data and you haven't kept a backup of some description, don't expect any sympathy from me !!
