INTRODUCTION
------------
Velkommen til vår Hex/Tekst Editor for EPOC Serien av håndholdte datamaskiner. 

FIL DETALJER
------------
Dette arkivet skal inneholde følgende filer:

RMRText.sis    Selve programmet
Lesmeg.txt     Instruksjoner på norsk

(and other international versions of the Readme file)

Programmet vil ferdig installert inneholde følgende filer: (i \System\Apps\RMRText\)

RMRText.app	- Selve programfilen
RMRText.mbm	- Ikoner benyttet i programmet
RMRText.aif	- Ikoner benyttet i System skjermbildet
RMRText.rsc	- Språkfil

Og følgende valgfrie tillegsfiler du muligens har installert - og som kan slettes senere:

RMRText.hlp	- Hjelp

For at ikke SIS filen skal bli for stor inneholder den bare Engelske versjoner av Hjelp og Instruksjoner. Andre språkvarianter av disse filene kan lastes ned fra http://www.rmrsoft.com/ eller ved å sende en diskett til den engelske adressen som er nevnt senere i denne teksten.

INSTALLASJON
------------
For å installere programmet - dobbeltklikk på filen RMRText.sis file eller velg "Install New Program" i PsiWin (EPOC Install). 

For å forhindre at denne SIS filen ble for stor, inneholder den kun engelske hjelpefiler og instruksjoner. I de fleste tilfeller vil det finnes en versjon for ditt språk.

BRUKEN AV PROGRAMMET
-------------------
Start programmet ved å klikke på 'Extras' fra Program hurtigmenyen og velg RMRText
