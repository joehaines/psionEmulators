EINFÜHRUNG
----------
Willkommen zu meinem Hex and Text Editor für EPOC Serie Palmtops.

DATEI DETAILS
-------------
Die Archivdatei die Sie bekommen haben, sollte folgende Dateien enthalten :

RMRText.sis   Das Programm
Liesmich.txt   Deutsche Anweisungen

(und zahlreiche internationale Versionen der Liesmich.txt Datei)
Wenn Sie die Dateien installiert haben, dann sollten Sie folgende Dateien sehen : (\System\Apps\RMRText\)

RMRText.app   -  Die Hauptprogramm Datei
RMRText.mbm   -  Die Icons, die im Programm verwendet werden
RMRText.aif   -  Die Icons die auf dem Systembildschirm verwendet werden.
RMRText.rsc   -  Die Language Datei.   

und die folgenden optional zu installierenden Dateien, soweit sie benötigt werden :

RMRText.hlp	  - Hilfedatei

Um sicherzustellen, daß die SIS Dateien nicht zu groß werden, enthalten Sie zwar das Hauptprogramm in verschiedenen Sprachen, die Hilfedatei und die Anleitungen sind jedoch nur in Englisch enthalten. Die jeweilige Version der Hilfedatei und der Anleitung können in verschiedenen Sprachen von der jeweiligen Sprachseite auf http://www.rmrsoft heruntergeladen werden. Sie können auch eine Diskette an die englische Adresse von RMRSoft senden findet sich in der Hilfedatei ) und die jeweilige Sprachversion wird ihnen dann zugeschickt.


INSTALLATION
------------
Um das Programm zu installieren doppelklicken Sie auf die RMRText.sis Datei, oder wõhlen Sie "Neues Programm installieren" in PSIWIN aus (EPOC-Install). 

PROGRAMM STARTEN
----------------
Starten Sie das Programm, indem, Sie "Extras" aus dem  Programmleiste und dann RMRText auswõhlen.
