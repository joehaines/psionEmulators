INTRODUCTION
------------
Welcome to our Hex/Text Editor for the EPOC Series of handheld computers.

FILE DETAILS
------------
The archive file should contain the following files:

RMRText.sis  The program
Readme.txt     English Instructions

(and other international versions of the Readme file)

Once installed. you will see the program consists of the following essential files: (\System\Apps\RMRText\)

RMRText.app	- The main program file
RMRText.mbm	- The icons used within the program
RMRText.aif	- The icons used in the System screen
RMRText.rsc	- The Language resource file 

And the following optional files which you may have installed and can be deleted later:

RMRText.hlp	- Help File

To ensure the SIS file does not get too large, this contains only English versions of the Help file and any instructions. In most cases international versions of these files are available and can be downloaded from the appropriate national page at http://www.rmrsoft.com/ or by sending a disc to the UK address in the Help file. 

INSTALLATION
------------
To install the program simply double-click on the RMRText.sis file or select the "Install New Program" option in PsiWin (EPOC Install).

RUNNING THE PROGRAM
-------------------
Start the program by selecting 'Extras' from the Application bar and then selecting RMRText
