RMRUtils per EPOC v2.10F (Build 1530)

Informazioni dell'ultimo minuto
===============================
Queste informazion sono molto importanti per gli utenti che vogliono installare RMRUtils attraverso il file .SIS. Leggere questo documento con estrema attenzione:

RMRUtils è la nuova versione di S5Utils e GeoUtils della RMR Software. Questa versione funziona correttamente sia su macchine Series 5 che su macchine Geofox-One. Non sono più necessarie versioni diverse a seconda del tipo di macchina.

Se sei un utilizzatore di S5Utils o GeoUtils, devi, prima di installare RMRUtils, fare un paio di cosette:

1) Rinomina la cartella \System\Apps\S5Utils\ o \System\Apps\GeoUtils\ in \System\Apps\RMRUtils\. Per fare questo è necessario che sia spuntata l'opzione 'Mostra Cartella di Sistema' nel menù Preferenze di Sistema.

2) Se sei registrato, rinomina il file S5Utils.reg o GeoUtils.reg in RMRUtils.reg. Se desideri mantenere le tue precedenti impostazioni, allora rinomina S5Utils.ini o GeoUtils.ini in RMRUtils.ini.

3) Poi, cancella tutti i files nella rinominata cartella \System\Apps\RMRUtils\ , ECCETTO i due files sopra citati nel caso tu abbia deciso di rinominarli, e inoltre conserva il file Currency.dat se desideri conservare i dati di conversione delle valute.

NOTA: Potresti dover togliere l'attributo di sola lettura alle proprietà del file S5Utils.hlp/GeoUtils.hlp. Usa, prima di cancellarlo, la finestra Proprietà dalla schermata di Sistema per controllare che il file non sia di Sola Lettura.

NON CI SONO ALTRE PARTICOLARI OSSERVAZIONI SU QUESTA VERSIONE.

Un ulteriore file di spiegazione verrà mostrato una volta installato RMRUtils (vedi sotto). Se hai bisogno di ulteriori informazioni su come registrare RMRUtils consulta il file di Aiuto ,accessibile dal programma una volta installato. Questo ti fornirà anche preziose informazioni su come usare al meglio il programma.

Installazione di RMRUtils con i file SIS forniti
================================================
Il file .ZIP che accompagna questo file contiene inoltre:

RMRUtils.sis	- File installazione principale
LeggiMI.txt		- Questo file

Se NON hai l'icona Add/remove nel pannello di controllo del tuo Series5/Geofox-One ( p.e. non hai il Message Suite installato o stai usando una versione di PsiWin/EPOC Connect precedente alla versione 2.1) dovrai rivisitare il nostro sito web e scaricare il file "INSTEXE.EXE". L'icona Add/remove è indispensabile per le installazioni SIS. Segui semplicemente i links per la nostra pagina 'SIS' da:

http://www.rmrsoft.com/

Supponendo che hai ora l'icona Add/remove sulla tua macchina, copia semplicemente RMRUtils.sis nel tuo Series 5/Geofox-One e fai un doppio click sul file della schermata di sistema. Il programma farà il resto.
