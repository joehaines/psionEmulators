RMRUtils for EPOC v2.10F (Build 1530)

Notes de dernière minute
========================
Ces notes sont TRES IMPORTANTE pour les utilisateurs installant RMRUtils via un fichier SIS. Lisez ce qui suit très attentivement:

RMRUtils remplace S5Utils et GeoUtils de RMR Software. Cette version tourne aussi bien sur le Series 5 que le Geofox-One, donc les versions séparées ne sont plus nécessaires.

Si vous êtes utilisateur de S5Utils ou de GeoUtils, vous devez faire ces quelques actions avant d'installer RMRUtils.

1) Renommez les dossiers \System\Apps\S5Utils\ ou \System\Apps\GeoUtils\ en \System\Apps\RMRUtils\. Pour ce faire, vous devrez vous assurer que l'option "Afficher dossier 'Système' " des Préférences du Système est cochée

2) Si vous êtes enregistré, renommez le fichier S5Utils.reg ou GeoUtils.reg en RMRUtils.reg. Si vous souhaitez garder vos réglages, renommez S5Utils.ini ou GeoUtils.ini en RMRUtils.ini

3) Ensuite, effacez les fichiers du dossier renommé \System\Apps\RMRUtils\ , SAUF les deux fichiers indiqués ci-dessus, ainsi que le fichier Currency.dat si vous désirez garder votre base de données de devises.

NOTE: Il se peut que vous deviez décocher la Propriété LECTURE SEULE du fichier S5Utils.hlp/GeoUtils.hlp. Faites Ctrl+P depuis l'écran Système pour modifier les propriétés de ce fichier avant de l'effacer.

PAS D'AUTRES NOTES POUR CETTE VERSION.

Une fois que vous installé RMRUtils depuis le fichier SIS (voir ci-dessus), lisez le fichier d'aide en ligne qui vous donne les détails sur l'enregistrement ainsi que bon nombre d'informations sur le programme.

Installation de RMRUtils depuis les fichier SIS fournis
=======================================================
Le fichier .ZIP qu accompagne ce fichier texte doit contenir 2 éléments:

RMRUtils.sis	- Le fichier d'installation des données
LisezMoi.txt	- Ce fichier

Si vous n'avez PAS l'icône "Ajout./Suppr." du Panneau de Configuration, vous devrez revenir sur notre site web pour télécharger le fichier "INSTEXE.EXE". Suivez le lien vers notre page 'SIS' à:

http://www.rmrsoft.com/

Une fois cett option installée, double- cliquez sur le fichier RMRUtils.sis depuis l'écran Système. Le programme d'installation fera le reste.

Vous devez maintenant voir l'icône RMRUtils dans la barre d'Extras.
