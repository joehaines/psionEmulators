RMRUtils for EPOC v2.10F (Build 1530)

Last Minute Release Notes
=========================
These are VERY IMPORTANT notes for users installing RMRUtils via a SIS file. Please read these carefully (and turn 'Word wrap' on in your text viewer if possible to make it easier to read):

RMRUtils is the new, renamed, replacement for S5Utils and GeoUtils from RMR Software. This version will run on both the Series 5 and Geofox-One machines, so separate versions are no longer needed.

If you are an existing user of either S5Utils or GeoUtils, then you will need to do a couple of things before installing RMRUtils.

1) Rename the folders \System\Apps\S5Utils\ or \System\Apps\GeoUtils\ to \System\Apps\RMRUtils\. To do this, you will need to ensure that the Preferences from the System shell has "Show 'System' folder" ticked

2) If you are registered, rename the S5Utils.reg or GeoUtils.reg file to RMRUtils.reg. If you wish to keep your settings, then rename S5Utils.ini or GeoUtils.ini to RMRUtils.ini

3) Next, delete all the files in the newly renamed \System\Apps\RMRUtils\ folder, EXCEPT the above 2 files if you chose to rename them, and also Currency.dat if you wish to keep your existing currencies database.

NOTE: You may have to set the Properties of the file S5Utils.hlp/GeoUtils.hlp to *TURN OFF* the 'Read-only' attribute. Use the Properties dialog from the System screen to make sure there is no tick in the Read-only box for this file before you try to delete it.

NO OTHER RELEASE NOTES FOR THIS VERSION.

Once you have installed RMRUtils with the SIS file (see below), please take a look at the on-line help file, this gives details about how to register if you haven't already, and also in-depth information about using the program.

Installing RMRUtils from the SIS file provided
==============================================
The .ZIP file which accompanied this text file should contain 2 items:

RMRUtils.sis	- The main install data file
ReadThis.txt	- This file

If you do NOT have the "Add/remove" icon in the Control Panel of your Series 5/Geofox-One (i.e. you've not got Message Suite installed and are using a version of PsiWin/EPOC Connect prior to 2.1), you will need to re-visit our web site to download the "INSTEXE.EXE" file since the Add/remove icon in Control Panel is vital for SIS installations to work. Just follow the links to our 'SIS' page at:

http://www.rmrsoft.com/

Assuming you now have that Add/remove icon, simply copy RMRUtils.sis to your Series 5/Geofox-One and double-tap it from the System screen. The install program will do the rest.

You should now be ready to run RMRUtils, and its icon should have appeared on the Extras bar.
