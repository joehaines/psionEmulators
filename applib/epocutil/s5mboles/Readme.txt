Dear S5mboles user,

Attached is a new update of S5mboles. Installation proceeds via
a SIS file. Please note that it is assumed that your macros are
in a folder named \Macros\ in the root of the C: or D: drive.
If not, don't worry and proceed with the installation. You only
have to copy the contents of the newly created folder \Macros\
to the actual macro folder on you machine afterwards.

Double click S5mboles.SIS, either on the PC or on your Epoc machine,
and S5mboles will be installed automatically. Four language versions
are included (English, French, German, and Dutch). During
installation from the PC you can choose which language version to
install; on the Epoc machine only the corresponding language version
will be installed.

Four icon sets will also be installed. These are named Set 1, Set 2,
Set 3, and Huub's font (F). The first three are improved versions of
previous sets named accordingly. When you update and have modified
these sets on your machine, it's better to rename them before
installing the new version. Huub's font (F) is a letter set
incorporated to show additional functionality of S5mboles.

For more information, please refer to the S5mboles.wrd file which
you can find in folder \Macros\S5mboles\ or view after tapping the
"Manual" button in the "About" dialog.

You have been added to the S5mboles users list. You'll receive
future free updates by email.

Please let me know if you like this program, find bugs, or have
ideas for improvements or enhancements

Enjoy S5mboles,
