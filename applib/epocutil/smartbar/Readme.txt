Installation Instructions

1. Unzip the Smartbar Zip file.

2. Either:

i. Copy all the .sis files to your Epoc release 5 (or higher) machine
   and double click each one it turn to install the necessary application
   files to your computer.

OR

ii. Connect your Epoc release 5 (or higher) machine to a PC containing the
    various .sis files and double click each .sis file to automatically install
    all the necessary application files.


3. Smartbar will now be available for use.


The first time you run Smartbar a WORD file will be opened to give you a brief over view
on how to use Smartbar. This file will be installed to C:\SmartbarIntro. Once you are happy
with the contents of this file you may delete it.
