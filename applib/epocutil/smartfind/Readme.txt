INSTALLATION

There are two ways to install Find on your device. The first way:

1. Download the SmartFind.zip file to your PC.
2. Unpack the Zip file contents, and double click on SmartFind.SIS file.
3. Follow the instructions which will guide you through the installation process.

The second way:

1. Download the SmartFind.zip file to your PC.
2. Unpack the Zip file contents.
3. Upload SmartFind.SIS file on your device.
4. Double click on SmartFind.SIS file there.
5. Follow the instructions which will guide you through the installation process.

DESCRIPTION

A Search Engine for Your Psion!

Smart Find is a global search utility that searches for files, folders and file contents.
Smart Find brings Internet search functionality to your Psion. Search for a file name,
type, size, attribute, modification date and CONTENT. Smart Find allows you to search for
any number of words or phrases simultaneously. You can specify Internet-like search
expressions with AND and OR Boolean operators. Double-tap on found file for immediate
access to the information. Smart Find application allows you to locate files easily on your Psion.

FEATURES

Search the contents of your Psion.
Search documents, databases, spreadsheets, e-mails, folders and more.
Customize your search by specifying file types, locations, size, attributes and modification date.
Search for any number of words or phrases simultaneously.
Specify Internet-like search expressions with AND and OR Boolean operators.
Sort found files by name, location, type, size, modification date and RELEVANCY.
Double-tap on found file for immediate access to the information.
