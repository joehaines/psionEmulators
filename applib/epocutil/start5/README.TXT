1. Installation

Create a new folder named "Start5" in "SYSTEM\APPS\" on a drive of 
your choice.
Copy "Start5.app", "Start5.aif" and "Start5.hlp" to this directory.
Start5 should now appear in your Extras bar.

2. User Manual
Please read the included helpfile. To view it, launch Start5, press the
Start5 button and select Help.
IMPORTANT NOTE: The helpfile included in this ZIP is not for v1.0F but for
v1.0B. v1.0F can do all things that are written down in this helpfile, but
there are some advanced features like the possibility to have an AutoStart
folder that are not yet described in the help. An updated version of the
helpfile will be available from Start5's Homepage soon.
