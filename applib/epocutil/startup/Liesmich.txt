Einführung
----------

Willkommen zu StartUp!

StartUp ist ein Werkzeug um eine unlimitierte Anzahl
Programme und Dateien gemeinsam zu starten.

Ich habe dieses Programm geschrieben, weil ich fast täglich
eine Datensicherung meines Serie 5 mache und nicht verstehen 
konnte, dass PsiWin 2.1 alle offenen Dateien schliessen aber
nicht wieder zu öffnen vermochte. StartUp hatte ich als
Alternative implementiert.

Verwenden Sie StartUp um ihre bevorzugten Programme und
Dateien nach einem Backup, Soft Reset oder was auch immer zu
starten. Sie können so viele Sets definieren, wie sie
möchten, z.B. für geschäftliche und private Zwecke.

StartUp lässt ihren EPOC Rechner hart arbeiten und es ist
immer wieder faszinierend zu sehen, was diese Maschine zu
leisten vermag. - Viel Vergnügen mit StartUp!


Release Information
-------------------

V2.06 Production - 29. Dezember 1999

Was gibt's neues?

- Purple Software's PowerBase Dateien sind jetzt vollständig 
  unterstützt. Der Fehler, welcher in vorherigen Versionen 
  eine 'nicht gefunden' Meldung ausgelöst hat, ist behoben.
  
- Wenn StartUp das erste Mal via die Extras Leiste 
  aufgerufen wird, versucht StartUp im Standardordner 
  (normalerweise C:\Dokumente) eine Datei names 'StartUp' 
  anzulegen. Falls eine Datei oder ein Verzeichnis mit 
  diesem Namen bereits existiert, wird kein Fehler mehr 
  ausgelöst. Statt dessen wird eine Datei mit dem Namen 
  'StartUp(01)' erstellt.
  
- Der Standard Alias für eine OPL OPO Datei enthält jetzt 
  den Programm Namen. Beispiel: Der Standard Alias für eine 
  Datei namens MeinProg.opo ist 'OPL - MeinProg.opo' statt 
  einfach 'OPL'.
  

Kompatibilität zu älteren Versionen

- Diese Version ist vollständig kompatibel zu älteren
  Versionen

- Die Dateistruktur von StartUp hat nicht geändert

- StartUp prüft die Version der StartUp Datei beim Aufruf
  und migriert die Daten sofern notwendig automatisch auf 
  die neue Datenstruktur. Unabhängig davon empfiehlt es 
  sich in jedem Fall als erstes eine Datensicherung 
  durchzuführen.

- Die globalen Einstellungen in der .ini Datei werden 
  während er der Installation auf Standardwerte 
  zurückgesetzt. Bitte benutzen Sie die entsprechenden
  Funktionen, um die notwendigen Änderungen
  durchzuführen.

  
Funktionalität

- Einlesen geöffneter Programme und Dateien

- Einlesen von Verzeichnisbäumen

- Starten von Programmen und Dateien

- Automatische Ausführung beim Aufstarten aufgrund
  dateispezifischer Einstellungen
  
- Schliessen aller geöffneten Programme und Dateien

- Schliessen von Programmen und Dateien, die nicht in der
  aktuellen StartUp Datei definiert sind
  
- Drei verschiedene Ansichten

- Fünf verschiedene Sortiermöglichkeiten

- Alternative Bezeichnung der Einträge

- Eintragswahl durch die Eingabe des Anfangsbuchstabens

- Allgemeine und dateispezifische Einstellungen

- Frei definierbare Tastenkombination um StartUp zu
  aktivieren
  
- Unbeschränkte Anzahl von StartUp Dateien

- Unbeschränkte Anzahl von Einträgen in einer StartUp Datei

- Läuft unter 

    - EPOC Release 3 (z.B. Serie 5) 
    - EPOC Release 5 (z.B. Serie 5mx)
    - EPOC Emulator Release 5 (WINS)

- Verfügbar in Deutsch, Englisch, Französisch und 
  Portugiesisch (Brasilianisch)
 

Installation
------------

Die Distribution von StartUp erfolgt via eine .zip Datei
die folgende .sis Installationsdateien beinhaltet:

- StartUp.sis          für EPOC Rechner (z.B. Serie 5)
- StartUpEmulator.sis  für EPOC Emulator R5 auf einem PC

Um StartUp von einem 32-bit MS-Windows PC zu installieren,
öffnen Sie die .sis Datei und folgen den Instruktionen des
Installationsprogramms.

Um StartUp von Ihrem EPOC Rechner oder EPOC Emulator zu 
installieren, öffnen Sie die .sis Datei und folgen den 
Instruktionen des Installationsprogramms.

Nach der Installation sollte ein neues Symbol in der
Extras-Leiste erscheinen.

Kopieren Sie das entsprechende Installationsprogramm von
meiner Web Site http://salvis.com/ falls .sis Dateien von
Ihrer PsiWin Version oder Ihrem EPOC Rechner nicht
unterstützt werden.

Wichtig: Der alte EPOC Emulator Release 3 wird nicht mehr
