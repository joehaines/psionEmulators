What's new in StartUp V2.06 (December 29, 1999)?

  • Purple Software's PowerBase files are fully supported now. The bug which caused a 'not found' message in prior releases is fixed.
     
  • When launching StartUp the first time from the Extras bar, StartUp tries to create a file named 'StartUp' in the default folder (usually C:\Documents). In case a file or folder named 'StartUp' already exists StartUp does not raises an error anymore. Instead a file named 'StartUp(01)' will be created.
     
  • The default alias name for OPL OPO files does contain the program name now. Example: The default alias name for a file named MyProg.opo is 'OPL - MyProg.opo' instead of simply 'OPL'.



What's new in StartUp V2.05 (November 13, 1999)?

  • Folders containing space characters are fully supported
     
  • EPOC Emulator Release 5 is fully supported. The following bugs are fixed:
    • StartUp does not crash on exit anymore
    • EPOC programs may be added to the StartUp file
  • Default alias name is created from the program name used in the Extras bar
     
  • StartUp does not crash anymore when long files or folders are stored in the \System\App folder
     
  • The StartUp window stays on top of all other windows during
    • Capture open files
    • Capture folders
    • Launch all entries
    • Close all open files
    • Close other files
  • 'Close all open files' and 'Close other files' do not cause multiple unsuccessful close trials anymore
     
  • 'Close all open files' and 'Close other files' do kill a program after unsuccessful friendly close requests
     
  • 'Close other files' does not close open document files when the appropriate program (.app) is defined in the current StartUp file
     
  • Document files cannot be added to a StartUp file when the appropriate program (.app) is already defined (and vice versa)



What's new in StartUp V2.01 (June 20, 1999)?

  • This release supports the new Serie 5mx and other machines running under EPOC Release 5 



What's new in StartUp V2.00 (June 22, 1998)?

  • Option 'Close other files...' added to the tools menu. This option closes all open programs and files which are not defined in the current StartUp file. This option is also used on opening of a StartUp file instead of the 'Close all open files' feature. This option may be used as a 'clean up' function and improves the performance when working with several StartUp files with one or more identical entries in each file (e.g. Macro5 or other useful programs and files you want to be open for quick access).
     
  • Programs with an open modal dialog box may be closed now, when no additional dialogs are shown on exit.
     
  • Navigation speed improved slightly when the vertical scroll bar is not visible.
     
  • Some GUI items and shortcuts have been renamed according to Psion's style guide.
     
  • StartUp is now available in German too. Both language versions are distributed together in a single installation file.
     
  • Release numbering system changed to the one Psion's Installation programs are using. This release is therefor called V2.00 instead of V2.0.0.



What's new in StartUp V1.1.2 (May 22, 1998)?

  • Database preferences are taken into account when a database is opened via extras bar or open dialog according to the appropriate new global preferences
     
  • Overflow error in the procedures CalcVSliderPos and VSliderNavigate eliminated when scrolling in databases with more than 200 entries
     
  • Database "ask" preferences will not be overwritten anymore when confirmation dialogs are disabled
     
  • Error message is not suppressed anymore when selecting an unsupported file in the edit entry and new entry dialog
     
  • Previous release informations are made available in the help file as an embedded word document Paragraph formatting in the help file is now independent of the current view settings (card width percentage)

  • Auto execution on opening according to database preferences
     
  • Capture apps and/or docs in a directory tree
     
  • Navigate to entries by pressing first letter
     
  • Three different views
     
  • Five sort options
     
  • New item alias as an alternative for file name in the alias view
     
  • Customizable hotkey to switch to StartUp
     
  • Switch to open help files is supported now
     
  • Capture running task does not create empty entries for open help files anymore
     
  • Capture running task does not cause an error anymore when the web browser is active
     
  • "folder does not exist" messages eliminated
     
  • Other StartUp databases may be opened now from system screen when StartUp is running
     
  • Global and database preferences are handled separately now
     
  • Customizable vertical scroll bar with standard EPOC32 behaviour
     
  • Navigation speed improved
     
  • Cancel option implemented for
     
  • Run all files
     
  • Capture running tasks
     
  • Close running tasks
     
  • View options are saved as global preferences
     
  • Several minor improvements

 



What's new in StartUp V1.0.2 (March 28, 1998)?

  • OPL OPO applications (like Theslink for example) added to the list of supported application types.
     
  • Applications on drive D: are scanned and recognized now
     
  • Documents with spaces in path and/or filename are fully supported now
     
  • Check for duplicate entries is not case sensitive on "Edit entry" anymore
     
  • "Run selected file" does not cause an error after document launching anymore
     



What's new in StartUp V1.0.1 (March 25, 1998)?

  • "Run selected file" brings running task to the foreground
     
  • Full support for EPOC32 machines without a compact flash card (D: drive)
     
  • Error message on creating StartUp.ini eliminated
     
  • Duplicate entries will be rejected
     
  • Drive letters now saved as uppercase



What's new in StartUp V1.0.0 (March 23, 1998 - Initial Release)?

  • Capture running applications and documents from system task list to be stored in your StartUp database
     
  • Launch applications and documents Close running tasks
     
  • Preferences dialog for customization
     
  • Unlimited number of StartUp sets (=StartUp documents)
     
  • Unlimited number of StartUp entries (=definitions within a StartUp document)
     
  • Supposed to work on all EPOC32 machines (Psion Series 5 and Geofox one)
