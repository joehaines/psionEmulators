INSTALLATION of SWITCHON PRO
----------------------------

Just unpack the zip archive and run the .sis file.

To improve the speed of the installation we suggest that you first copy the .sis file onto your EPOC device and then doubleclick on it on the EPOC device. For unknown reasons the dependency check is much faster and so will be the installation onboard EPOC instead of PC.

If you encounter any problems with SwitchOn Pro after the installation, we suggest that you first uninstall the program from the system/ Add/remove program and then reinstall the .sis file.

SwitchOn Pro is shareware and must be registered after 21 days of trial.
Registration can be obtained via our website www.vorbauer.com
