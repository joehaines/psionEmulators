Symlink Readme
For Symlink v1.26. Feb 2000
Overview
Symlink is a tool that provides two key additions to the Psion 5 system:
1.	Hyperlink style links within applications, as well as inline display of some types of external files.
2.	Shortcut/symbolic link style entries within folders.
The application is designed to be relatively intuitive to the user. Depending on the settings, the application itself may only be seen when creating new links or changing properties: it is possible to directly launch files without further user interference.
Before installing the tool, you should read the legal notice below. If you do not accept the terms then please do not install the software.
Installation
Symlink itself is installed by installing the <?PC850(147)>symlink.sis<?PC850(148)> file via the <?PC850(147)>Install New Program<?PC850(148)> option of PsiWin 2.1 - just opening the file normally invokes this. Alternatively you can transfer it to the a Psion and use the <?PC850(147)>Add/remove<?PC850(148)> control panel that is normally installed as part of the Message Suite installation - the Install tool can be downloaded separately from http://www.psion.com if required. A second module, TreesoftSupport will also be created. Normally this is invisible, but you may get a dialogue that you have a later version installed and asking whether to continue. This should only come about if you have installed other software by Treesoft, and you should not install an old version or that software will cease to work. A third <?PC850(147)>module<?PC850(148)> relates to the documentation files <?PC850(150)> installation is optional but you are advised to install them, at least initially.
Installation will create a folder \System\Apps\Symlink that contains the program and help files - TreesoftSupport will be installed in C:\System\Libs. These takes about 150K of file space. The documentation files are copied into \Documents\Symlink Docs: including Symlink Readme and Symlink Manual. Symlink Readme is the Psion version of the Readme file on the PC. There is also a Symlink file called <?PC850(147)>Link to Symlink Manual<?PC850(148)>. Note that you can remove the module <?PC850(147)>Symlink Docs<?PC850(148)> via the Add/Remove control panel. Its absense will not affect the working of the program <?PC850(150)> ignore the warning that it might stop other programs from working. Also note that if you are upgrading from earlier versions of Symlink, you might need to delete the folder <?PC850(147)>C:\Documents\Symlink Data<?PC850(148)> that is no longer used. Furthermore, depending on your setup, your Preferences may return to their default settings <?PC850(150)> in which case you should enter Symlink and modify them as appropriate.
