Installation Instructions

1. Unpack the Zip file to your PC or your Psion. 

2. On the PC:
   
	Double click on the file ThesLink.SIS. This will
	start the PC automatic installation of ThesLink. 
   
   On the Psion:
	
	Double tap on the file ThesLink.SIS. This will start
	the Psion automatic installation of ThesLink.

ThesLink should now be accessible to you from the Extras icon.
