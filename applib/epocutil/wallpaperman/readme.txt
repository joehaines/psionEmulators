2. INTRODUCTION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
WallpaperMan is an advance wallpaper management system for your EPOC device.
WallpaperMan will also automatically change your System wallpaper either at
switch on, on a daily, weekly, or monthly basis. A hotkey is also provided 
to change your System wallpaper. 

Worried about your wallpapers taking too much disk space but don’t want to 
see the same wallpaper every day? WallpaperMan has the solution with its 
build in fractal generator, the System screen will never be the same again
and you won't need to install a single wallpaper!

Liven you EPOC device with WallpaperMan.


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
3. INSTALLATION
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
To install the program simply double-click on the WPMan.SIS file or 
select the "Install New Program" option in PsiWin/EPOC Install.

To uninstall goto the Control Panel, tap the Add/Remove icon, select 
WPMan and finally press the Remove button.

If you are upgrading from a previous version, before installing this new 
version you need to un-install the old version first. You also need to delete
the directory /System/Apps/WallpaperMan/ in all drives.
