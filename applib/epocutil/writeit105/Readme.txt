Description:
------------

WriteIt is a utility program for the Psion Series 5
which provides handwritten input to any open application.

For full details refer to the help file. You will need to read this before starting: when WriteIt is open press ctrl+shift+H.

Installation:
-------------

Unzip WriteIt.zip into a folder called WriteIt, then simply copy this folder (complete folder) in the Psion's existing C:\System\Apps
Note: you may need to set the System folder visible in Tools|Preferences...

You should end up with the following:
C:\System\Apps\WriteIt\Icon.mbm
C:\System\Apps\WriteIt\main.mbm
C:\System\Apps\WriteIt\title.mbm
C:\System\Apps\WriteIt\WriteIt.aif
C:\System\Apps\WriteIt\WriteIt.app
C:\System\Apps\WriteIt\WriteIt.hlp

It should now be accessible to you from the Extras bar.
(once open, press ctrl+shift+H to read the help file)
