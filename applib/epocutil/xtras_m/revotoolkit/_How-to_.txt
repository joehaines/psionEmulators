How to create custom Iconpack for Xtras.
========================================

Please replace the following bitmaps with
your custom ones. (Most file names are
self-explanatory).
All icons are color 24x24 pixels for 5mx, netBook,
etc. and 16x16 for revo.
XIcon is the only icon 48x48 pixels.


XIcon.bmp		- Main Xtras icon for About dialog
PrGroup.bmp		- Program group (folder) menu icon
Help.bmp		- Epoc help menu icon
HelpXt.bmp		- Xtras help menu icon
Settings.bmp	- Settings menu icon
Cpl.bmp			- Control panel menu icon
Config.bmp		- Configuration menu icon
RestNow.bmp		- Warm reset menu icon
About.bmp		- About menu icon
Link.bmp		- Link menu icon (cascade)
LinkOff.bmp		- Link Off menu icon
LinkIr.bmp		- Link InfraRed menu icon
LinkCable.bmp	- Link Serial menu icon
Sound.bmp		- Sound menu item (cascade)
SoundOn.bmp		- Sound on menu icon
SoundOff.bmp	- SOund off menu icon
SoundSilence.bmp- Silence for menu icon
System.bmp		- Switch to System menu icon
Tasks.bmp		- Tasks menu icon
PrefGen.bmp		- General preferences menu icon
PrefPrg.bmp		- Program settings menu icon
App.bmp			- Default application icon
Exit.bmp		- Exit Xtras menu icon

Once you have all the icons the way you like,
send all the files to:
support@multicontacts.net
