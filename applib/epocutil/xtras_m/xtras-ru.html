О программе Xtras

.

Xtras - это альтернативный лончер программ для EPOC. Концепция и стиль программы соответствуют кнопке "Пуск" MS Windows.

Xtras также реализует несколько основных, наиболее часто используемых управляющих функций, таких как управление звуками и связью с ПК.

"С места в карьер"

  1. Запустите Xtras, нажав иконку ‘Xtras’ на панели Extras.
  2. При первом запуске программы на конкретном устройстве на экране появится содержимое файла помощи Xtras.
  3. Активизируйте Xtras, нажав трафаретную иконку ‘System’ или клавишную комбинацию CTRL+Menu. Имейте в виду, что пока на экран выводится мерцающее сообщение "Сбор информации о приложениях…", программа производит поиск установленных на устройстве приложений.
  4. Задайте рабочие настройки программы, выбрав: Сервис > Управление > Настройки… (описание всех параметров настройки приведено в файле помощи). Нажмите OK по завершении.
  5. Задайте настройки для каждого приложения и, при необходимости, организуйте приложения в папки: Сервис > Управление > Приложения…
Note:
При конфигурировании нескольких приложений по очереди не закрывайте окно диалога ‘Настройки приложений’. Настройки выбранного приложения автоматически сохранятся при переходе к следующему.

6. Теперь программой Xtras можно пользоваться как кнопкой ‘Пуск’.

Обзор главного меню

Приложения

Меню приложений включает в себя все приложения, установленные на устройстве в данный момент. У пользователя есть возможность создавать папки приложений и назначать приложения этим папкам (группировка приложений по какому-либо принципу). Имеется также возможность скрыть какие-то приложения или, наоборот, сделать их всегда видимыми. Кроме того, приложениям можно давать альтернативные названия.

Tip:
Подробности приведены в разделе ‘Настройка приложений’.

Задачи

В меню задач отображаются все активные и видимые задачи (приложения Eikon), которые в данный момент выполняются. Если приложение работает с файлом, и этот файл открыт, то имя открытого файла отображается всегда.

В данном меню пользователь может переключиться в другое приложение, закрыть или принудительно завершить его.

Note:
Если имя файла слишком длинное и не помещается в окно, оно обрезается так, чтобы была видна его левая часть.

Панель упр.[авления]

Данный пункт меню вызывает панель управления системы

Система

Данный пункт меню отображается только, если программа Xtras связана с трафаретной иконкой System. Этот пункт дает доступ к системному экрану устройства.

Сервис

Данный пункт меню обеспечивает прямой доступ к некоторым функциям конфигурации и управления системой.

Он также дает возможность выйти из программы.

Обзор меню ‘Cервис’

Помощь

Предоставляет доступ к

  • Файлу помощи Xtras (данный файл)
  • Системному файлу помощи EPOC
  • Информации о программе

Связь с ПК

  • Отключить - выключает связь с ПК
  • Кабель - включает связь с РС через последовательный порт
  • ИК порт - включает связь с РС через инфракрасный порт

Сигналы оповещения

  • Выключить - выключает звуковые оповещения
  • Включить – включает звуковые оповещения
  • Приглушить на… - выключает звуковые оповещения на заданный промежуток времени
Note:
Данная опция выключает НЕ драйвер звука, а только сигналы оповещения. Ее действие подобно действию функции разрешения / запрещения сигналов приложения EPOC Time

Управление

Данное меню дает доступ к таким функциям, как Сброс (мягкий сброс устройства), Выход (выход из программы) и функциям общих настроек программы и специфических настроек приложений.

Общие настройки

Закладка Активизация:

Здесь можно задать способы активизации меню Xtras.

Трафаретная кнопка - позволяет выбрать трафаретную иконку, которая будет использоваться для активизации Xtras.

Модификаторы - позволяет выбрать, какой модификатор (кнопка или комбинация кнопок) будет использоваться вместе с заданной трафаретной кнопкой. Возможные варианты: Ctrl, Shift и Fn, а также любые их комбинации.

Shift - позволяет уточнить, какая из клавиш Shift будет использоваться: любая, левая или правая.

Кнопка клавиатуры - позволяет выбрать кнопку на клавиатуре, которая будет использоваться для активизации Xtras.

Note:
Для активации Xtras можно использовать только некоторые из специальных кнопок.

Модификаторы - позволяет выбрать, какой модификатор (кнопка или комбинация кнопок) будет использоваться вместе с заданной кнопкой клавиатуры. Возможные варианты: Ctrl, Shift и Fn, а также любые их комбинации.

Shift - позволяет уточнить, какая из клавиш Shift будет использоваться: любая, левая или правая.

Note:
Запретить активизацию программы одновременно с клавиатуры и с трафаретной иконки невозможно.

Закладка Отображение:

Угол появления меню - позволяет выбрать место на экране, где появляется меню Xtras. Возможные варианты - четыре угла экрана.

Меню по умолчанию - позволяет выбрать, какое из меню программы будет всегда появляться при активизации главного меню Xtras. Возможные варианты: Приложения, Задачи и Сервис.

Шрифт меню - позволяет выбрать один из трех стандартных шрифтов для отображения панелей меню: Нормальный, Жирный или Уплотненный.

Использовать альтернативное название - позволяет выбрать использование оригинального или альтернативного названия приложения (если последнее задано).

Note:
Если альтернативное название приложения не задано, всегда используется оригинальное.

Скрыть название приложения в списке задач - позволяет задать, будет ли отображаться в списке задач только имя открытого файла или, и название приложения, и имя файла. Обычно по иконке приложения, связанного с именем файла, можно судить о том, какое приложение использует данный файл.

Note:
Если приложение не использует файлов, его название отображается в любом случае.

Отображать иконку приложения - для повышения скорости работы Xtras можно использовать общую иконку приложений вместо индивидуальных.

Note:
Данная опция предназначена для использования владельцами Revo, Revo+ и Mako. На этих устройствах программе Xtras требуется дополнительное время для масштабирования изображений иконок перед их прорисовкой.

Закладка Сортировка/поиск:

Порядок сортировки - позволяет задать порядок в котором сортируются приложения. Сортировка всегда выполняется по алфавиту, ключевое слово - название приложения. Сортировка по другим критериям не поддерживается.

Метод сортировки - позволяет выбрать, будут ли приложения и папки сортироваться единым списком, или же папки будут сгруппированы вместе в начале или конце списка.

Метод поиска - позволяет выбрать способ просмотра списков приложений и папок: только по первому символу или последовательно по всем символам по мере их ввода.

Note:
Если искомый символ отсутствует в списке, то устройство может сообщить об этом коротким звуковым сигналом (см. ниже). Буфер поиска можно обнулить, переместив курсор на одну строку выше или ниже.

Сигнал, если не найдено – позволяет включить подачу короткого звукового сигнала при каждом несовпадении вводимого символа при последовательном методе поиска. Выключение данной опции позволяет сэкономить заряд батарей.

Закладка Управление:

Подтверждать каждое изменение - позволяет задать режим явного подтверждения изменений настроек, касающихся как КАЖДОГО приложения в списке приложений, так и в других списках. Данная опция влияет, в основном, на диалог настройки приложений.

Функциональные иконки - позволяет задать, будет ли нажатие на иконку приложения или папки вызывать контекстно-зависимую функцию, или ее поведение будет обычным.

Note:
Контекстно-зависимые функции всегда доступны при нажатии кнопки ‘Menu’.

Фоновый режим отменяет диалоги - позволяет задать автоматическую отмену диалогов Xtras при переходе приложения в фоновый режим.

Показывать в списке задач – по умолчанию программа Xtras не отображается в списке задач EPOC. Однако, при этом некоторые программы (например, CyrLat) не могут корректно обнаружить и отработать переключение контекста приложения при активизации Xtras. При необходимости назначения программе Xtras собственного контекста следует разрешить данную опцию.

Настройка приложений

Диалог настройки приложений дает возможность задать отображение и поведение приложений в меню Xtras.

Для настройки приложения необходимо, как правило, выполнить следующие шаги:

1. Выбрать приложение из списка.

Note:
Проверьте UID приложения и флаг "видимости"

2. Задать альтернативное название, если нужно.

3. Выбрать вид отображения приложения. Возможные варианты: всегда скрытое, всегда видимое, вид по умолчанию.

4. Назначить приложению папку.

При помощи кнопки Папки пользователь может создать, изменить или удалить папку. Программа поддерживает иерархию папок глубиной до 20 уровней вложения.

Note:
При присвоении одной папки другой (вложение папок) необходимо убедиться, что она не "выпадает" из иерархии. Папки, лежащие вне иерархии, и поддеревья таких папок программой не поддерживаются.
Note:
При удалении папки, все поддерево, лежащее внутри, переприсваиваится папке более высокого уровня.
Note:
Программа Xtras сохраняет информацию об удаленных приложениях на случай их повторной переустановки или, если они находятся на извлеченной в данный момент CF-карте. Эта информация может быть удалена независимо.
Note:
Папки не являют собой никакой особой концепции. Каждая папка создается для конкретного приложения. Поэтому конфигурация полностью управляется приложениями.

Контекстно-зависимые функциональные иконки

Xtras поддерживает идею контекстно-зависимых функциональных иконок. С каждой иконкой в любом меню связана специальная функция. Эта функция отличается от функции пункта меню по умолчанию.

Такая ‘особая’ функция вызывается при нажатии не на пункт меню, а на саму иконку, или на кнопку ‘Menu’, когда соответствующий пункт выделен.

Функция пункта меню по умолчанию вызывается при нажатии на область названия пункта меню или на кнопку ‘Enter’.

Поддержка нажатий иконок настраивается и может быть выключена, а кнопка ‘Menu’ активна в любом случае.

Аварийное завершение программы

Для выхода из программы Xtras в ситуации, когда ее основное меню по каким-то причинам недоступно, необходимо нажать комбинацию Fn+’k’ пять раз в течение двух секунд. Такое действие или завершит программу Xtras принудительно или, по крайней мере, сделает ее видимой в списке задач, где она может быть завершена обычным способом.
