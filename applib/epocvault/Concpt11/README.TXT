Concept! is a inovative development assistant based on a graphical user
interface. The basic principle is best described as a family tree of
ideas / thoughts / plans. Each concept! file starts with a top level
entry which represents the main thought or idea. From there various
ideas will "branch" off to create pathways of logical thoughts. To make
it all easy to understand concept! displays all the information graphically,
and in a logical format. The use of Concept! is limited only by your
imagination. It can be used to plan projects, structure your ideas, keep
track of your contacts. You could even use it to simply keep notes in a
logical order. An example concept! file has been included to show you some
of the powerful, yet simple to use feature of Concept!


Installing Concept!
===================

1)	Turn on your Series 5, press the System button, press the Menu key,
	under 'Tools' select 'Preferences', make sure that the 'show system
	folder'option is 'OK'. This will make the System folder visible on
	your Psion.

2)	Create a new \SYSTEM\APPS\Concept folder.

3)	Copy the following files from ConcptXX.zip into this new folder:

	concept.app - Essential program file
	concept.aif - Essential program file
	concept.mbm - Essential program file
	concept.hlp - Optional help file

4)	An example concept! file has also been included. It is recommended
	that you copy this to your Psion to give a quick demonstration of
	some of concept! main features. You should copy both the EXAMPLE
	file and the EXAMPLE.MBM files to your C:/ folder. Please ensure
	that the .MBM file in particular is copied to the correct location.

5)	If you have copied the example file to your Psion you should tap
	its icon on your system screen to start it, else you can simply
	tap the Concept! icon on the extra's bar.



Getting Started
===============

Concept! has been designed to be very easy to use. Full on-line help
is available, and you will quickly find yourself at home with all the
main functions. To help you familiarise yourself an example file has
been enclosed in the distribution .zip file. Follow the installation
instructions above, at start the example file to find out more. Once
you are familiar with the main functions you can create your own files
and you're away....
