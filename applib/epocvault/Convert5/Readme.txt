"Convert5" is a small unit conversion program. It is a shareware.

It has been release for Evaluation purpose for 21 days. If you decide not to register, it will stop working after 21 days. Please delete "Convert5" from your Psion Series 5.

========================
To install…
========================

1) Make sure the "\System" folder is shown on your Series 5 system screen.
If it's not, go to system menu and "Preferences" and check "Show "system" folder" box.

2) "Convert5" must have unzipped in the folder call "\Convert5". If so, delete this "Readme" file first from the folder and then copy whole "Convert5" folder in your "\System\Apps\" folder. Convert5 icon will appear in the Extrabar.

3) If you are installing this program to the D drive, make sure you create folder call "\System\Apps" first in the D drive. In order to run  "Convert5" smoothly, it must be installed in "\System\Apps" folder in any drive. (E.g. any drive:\System\Apps\Convert5\*.*)

4) To copy all files manually, create folder called "Convert5" in "\System\Apps" folder and copy all files listed below in this folder.
