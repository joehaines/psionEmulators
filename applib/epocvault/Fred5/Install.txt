Compactor Instalation
---------------------
1. Make a directory called Compactor in your \System\Apps\ directory.
(Make sure that the System folder is shown, if not make it so from the
Preferences dialog Ctrl+K)
2. Copy the files Compactor.aif and Compactor.app into it.
3. Copy SysRAM1.opx into \System\OPX\, if you don't already have it.  
4. Make sure the files are named properly as shown above.
5. Run Compactor from the extra's bar and see what you think.
6. I hope you find it useful, it is FREE smile ware, so if you like it SMILE!
