HecaTris is a 'sideways' Tetris variant.

1. Installation

Unzip the HECATRIS.ZIP file.  Create a HecaTris directory in the
\System\Apps directory on your Psion 5, and copy the unzipped files 
into this directory.  You can now start HecaTris from the Extras bar.

2. Usage

   Default Key           Action
   -----------           ------
   Arrow Up              Move block up
   Arrow Down            Move block down
   Arrow Right           Drop block
   Arrow Left            Turn block counter-clockwise
   . (dot)               Turn block clockwise
   Space                 Pause game
   Menu                  Game options
   Esc                   Quit game
