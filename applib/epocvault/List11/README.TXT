Psi-List is a simple to use list manager for the Psion series 5.
We are all addicted to making lists, we can't help it! Psi-List
helps feed our addiction by making our lists easy to manage and access.

Psi-List does exactly what you expect it to do, nothing more and nothing
less. It includes all the normal Psion features, pen and keyboard access,
toolbar, scollbar and easy to use menus, etc.

Psi-List is one of those applications you find yourself using everyday.


Installing Psi-List
===================

1) Turn on your Series 5, press the System button, press the Menu key,
under 'Tools' select 'Preferences', make sure that the 'show system folder'
option is 'OK'. This will make the System folder visible on your Psion.

2) Create a new \SYSTEM\APPS\PSILIST folder.

3) Copy all the files from the listxx.zip file, except this readme file,
into the new \SYSTEM\APPS\PSILIST folder on your Psion.

4) The Psi-List icon will now appear on your Extra's Bar, ready to use.


Getting Started
===============

Psi-List has been designed to be very easy to use. Full on-line help
is available, and you will quickly find yourself at home with all the
main functions. To create your first Psi-List entry simply tap the "Add
item" button from the toolbar, and enter your list item. That's it!!
