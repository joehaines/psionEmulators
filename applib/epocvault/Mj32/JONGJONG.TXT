INSTALLATION
------------
- Copy all files into \system\apps\mahjong directory
- exclude this file.

INTRODUCTION
============
This software is a Mahjong game for PSION Series 5.

Start the game in the extra menu, and at the start-up dialog, 
choice the language used, choice game levels and switch on/off sound.

Key usage :-

  use left/right arrow to move cursor of selection.
  use return/space key for throw tiles.

  while chow/pong/kong/win menu come up,
    use up/down arrow to move cursor of selection.
    press return/space for confirm you selection.
    press ESC for cancel menu.


Pen Usage :-
  click the tile to change selection.
  while cursor on the selected tile, click again throw it.

  while chow/pong/kong/win menu come up.
    click the function you need.
    while cursor on the selected function, click again for confirm.

Use Menu Key or left top corner icon for Game Menu.
  You can start a new game with different level.
  or switch sound on/off.
  or password for special function, (mainly for Program test purpose).


Screen Layout :-

  Top tiles, computer's tiles.
  Bottom tiles, user's tiles.

  Tiles beside the middle bar, tiles that has throw.

  Right hand side, 
    top face, computer's face.
    bottom face, user's face.
  
  Digits beside the face is the money of the player.

Game is over when you lose all your money.
When computer lose all it's money, it will change face, and with more money.
