MMM Sticker v4.13


1. INSTALLATION
===============
There was four files include in the zip file,

    STICKER.TXT                         this file
    MMM Sticker.aif
    MMM Sticker.app
    Sticker.mbm
    SYSRAM1.OPX

Copy "MMM Sticker.aif",
     "MMM Sticker.app",
     "Sticker.mbm"     into "\SYSTEM\APPS\MMM Sticker" of your PSION S5.

Copy "SYSRAM1.OPX" into "\SYSTEM\OPX" of your PSION S5

2. INTRODUCTION
===============
MMM Sticker main purpose is use as a memo sticker for your PSION S5.
After several months later, it have become a multi-purpose utility for
your powerful PSION Series 5.

When you using Series 5, you will find a place to store something immediately.
So MMM Sticker is the best solution for this kind of usage, cause, you can jot
notes by typing or handwritting and exchange with other applications while you
have spare time.

Additional, there was a quick reference calendar, and data view card.

If you have MMM Sticker, your PSION Series 5 will help you a lot while you just
flip open it.

3. FEATURES
===========
   1. Switch to foreground when turn-on.    (Selectable)
   2. Switch to background while idle.      (Selectable)
   3. Switch on backlight with schedule.    (Selectable)
   4. Play power-on music.                  (Selectable)
   5. LCD Contrast Setting with schedule.   (Selectable)
   6. Power-on Main Batteries Status.       (Selectable)
   7. Status Window for indicators.         (Selectable)
   8. Hand-writting notes.
   9. Zoom individual sticker.
  10. Live Calendar Card.
  11. Live Data view Card.
  12. Support Clipboard for exchange data with other applications.
  13. Status windows at bottom of screen.
      Main Batteries, Backup Batteries Status.
      Disk indicator, Caps Lock indicator.
  14. Move you sticker freely with stylus, or arrow keys (with Ctrl key).
  15. Maximum up to 55 stickers.
  16. Additional option for turn on/off Sticker Shadow.  (for speed up response).
  17. Selectable Hot-key for switch back to MMM Sticker.

4. USAGE
========
[Fn]+[S] 	   : Hot-Key to switch to MMM Sticker (Default Setting).
[Tab]/[Shift][Tab] : Switch Sticker
[Esc]		   : Switch MMM Sticker to background
[Ctrl][Tab]        : Sticker List.
Arrow key          : Move Sticker.

Any Typeable character : Start New Text Sticker.

5. NOTES
========
Selected Sticker will come foreground, and with a Cursor Blinking.
Each Sticker have a time stamp.

Individual Sticker can be zoom small/large, 
  include text, picture, draw, calendar, and data view stickers.

Power-on idle time is equal to half of normal idle time.

Draw sticker use full screen dialog, 
  and sticker will fit to your drawing, it will not waste your S5 memory.

Power-on Battery Status.

Copy sticker content into clipboard.

Copy Sticker Seleted content into clipboard.

Live Calendar Sticker.

Help Screen Added.

LCD Contrast auto timer added.

Battery Checking Switch added.

Status Windows for Cap. Lock/Compact Disk/Main & Backup Battries...

Version 4 cannot run on PSION Emulator.

Mini-Calculator with quick access.  (User define position)
  *  For Non-UK S5 Users, press Fn+... for your operators to let MiniCalc
     know which key for operators.

Draw Memo Dialog have different line width.
