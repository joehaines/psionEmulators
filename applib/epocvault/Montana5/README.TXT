How to install Montana 5
========================

1) Make sure viewing of the \System folder is enabled on the system
   screen (Use 'Preferences').

2) Go into \System\Apps and make a new folder called "Montana5".

3) Copy all the supplied files into the \System\Apps\Montana5 folder.
   NOTE: If you are upgrading from an earlier registered version do
   not copy the REGISTER.DAT file.

4) The game will now be available from the "Extras" bar.


Playing Montana 5

Please see the help file (available from the Tools, Help menu
