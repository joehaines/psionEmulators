pSketch Photo5 plugin Version 1.00
----------------------------------

-What is pSketch?
 pSketch enables you to load and save Sketch files in Photo5.

-What do I need to run pSketch?
 You need (obviously) the Photo5 application from Mat Ripley to have
 any use for this plugin. (And read the manual...)

Installing:
Install pSketch.opo in the \system\apps\photo5\plugs directory.

Running pSketch:
Start the plugin in the usual way from the Photo5 application. It gives
you three option:
1. Load Sketch
2. Save as Sketch
3. An about box.

pSketch creates a small ini file on the internal drive (in the plugs\ 
directory), to store the last used directory and some options.
That's all.
And last but not least: It is freeware!

Have fun.
