RealTime Instalation
---------------------
1. Make a directory called RealTime in your \System\Apps\ directory.
(Make sure that the System folder is shown, if not make it show from the
Preferences dialog Ctrl+K)
2. Copy the files RealTime.aif, RealTime.app, RealTime.hlp and
RealTime.mbm
3. Copy SysRAM1.opx into \System\OPX\, if you don't already have it.  
4. Make sure the files are named properly as shown above.
5. Run RealTime from the extra's bar and see what you think.
6. I hope you find it useful, and decide to register this wonderful program.
