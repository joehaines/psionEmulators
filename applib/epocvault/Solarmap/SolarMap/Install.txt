SolarMap V2.0 10th November 1997

Installing
You should install everything except the maps to a directory called SolarMap in System/Apps, this will need to be created the first time, it can be on the C or D drive. In the SolarMap directory you will need another sub-directory called Maps, put all the maps in this directory. SolarMap should now appear on your Extras list. Please read SolarMap-ReadMe for more information.
