Installation
-----------
1. Make a folder called Timecalc5 in your
\System\Apps\ folder.
(Make sure that the System folder is visible. If not,
press Ctrl+K in the system screen and select Show
'System' folder from the Preferences dialogue).

2. Copy the files Timecalc5.aif,Timecalc5.app and
Timecalc5.hlp into the new Timecalc5 folder.
Overwrite any files of the same name remaining from
the evaluation copy.

3. Run Timecalc5 from the new Timecalc5 icon on the
extras bar.
