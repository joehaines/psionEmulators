How to install Web World
========================

1) Make sure viewing of the \System folder is enabled on the system
   screen (Use 'Preferences').

2) Go into \System\Apps and make a new folder called "WebWorld".

3) Copy all the supplied files into the \System\Apps\WebWorld folder.

4) The game will now be available from the "Extras" bar.

The Story
=========

Web World has enjoyed many years of peace due to the presence of the
Mystic Orb which has protected the people from evil. One day, the evil
mage Hasatan managed to steal the orb and before draining it's energy
used it to transform the people into evil monsters.

Your task is to locate the Orb, re-energise it and escape using the
teleportation device Hasatan used to flee.

The transformed people are out to stop you and will drain your energy,
you also have a limited time before the changes become permanent!
     
                  
Playing Web World
=================

Web World is a large arcade adventure, the game consists of a hundred
interlinked screens. These can be navigated around but there are many
objects to find and puzzles to solve before the game can be completed.

To move around, use the cursor keys, the Fn key to jump and space to
pick up and drop objects.

To make life more difficult, you have a limited amount of energy which
is depleted by running into the many monsters and there is also a very
severe time limit!

Hint: Draw a map, you'll need it!



History
=======

??? 1985 A screen engine was developed for the Acorn Electron to allow
         the rapid development of arcade adventures in a very small
         amount of memory (codenamed QuAD) leading to 100 screens 
         being stored in around 1.5Kb.         

Jun 1996 WebWorld was created for the Psion Series 3a/c using the same
         engine - leading to a full arcade adventure in 35Kb.

May 1997 Windows 3.1x / 95 / NT 4 version released using the same data
         files and graphics as the Series 3a/c version as an 
         intellectual exercise.

Oct 1997 Series 5 conversion performed with all new graphics and screen
         layout to take advantage of the S5 display.
