AgendaSync V1.00
===================

Bemerkung:
-----------------
Sie müssen dieses Plugin auf dem selben Laufwerk installieren, 
wie auch Notepad von Pelican Software Inc. installiert ist. 
Falls Sie ein anderes Laufwerk gewählt haben, dann 
deinstallieren das Plugin bitte nochmals und installieren
Sie es erneut auf dem Laufwerk, auf dem auch Notepad 
installiert ist.

Desweiteren benötigen Sie das OPX Agenda2 von Andy Clarkson.
Dieses OPX muß vor der Installation von AgendaSync 
installiert sein.
