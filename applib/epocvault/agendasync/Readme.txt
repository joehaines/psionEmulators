AgendaSync V1.00
==================

Note:
--------
You must install this plugin at the same drive as you have 
installed Notepad from Pelican Software Inc. If you have
choosen another drive, then please uninstall it and
install it onto the right drive again. 

Also you need the OPX Agenda2 von Andy Clarkson.
This OPX must be installed before you can install
AgendaSync.
