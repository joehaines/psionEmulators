Installation
Make a directory with the name of AO Psion program name in your \System\Apps\ directory. (you may need to turn on viewing of the normally 'hidden' system area in your system screen preferences). 

For the AONONO program, the folder is:

\SYSTEM\APPS\AONONO

If all is well, the AP program icon will appear in your Extras bar. 

Make a directory for nonograms:

\DOCUMENTS\AONONO
