BattGauge 1.1

This program displays the estimated battery run time, and the battery voltage status in the right upper corner of the display for a few seconds.
Since the battery run time is very strongly dependent on the battery type, it can be adjusted, NiHH Akkus runs on my Psion for approx. 10 hours, Alkaline approx. 20.  The upper and lower-volt-delimitation and the Battery-empty-warning limit (Alarmtriggervoltage) can be adjusted. Battery Gauge does not drain your battery, because it runs only once when invoket.The Settings can be changet when batteries are changet, first time invoket, or when you delete the C:\System\BG.ini file.

Installation:
Best to use with the marvelous Macro5, so every time the Psion is switched on it shortly appears.
Battgauge can also be started from the System screen by just tipping on it.
