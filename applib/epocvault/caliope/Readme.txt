Introduction

Caliope is a musician's utility. It provides a one octave piano and a
simple metronome.


Installation

To install Caliope, copy the file Caliope.sis on to your EPOC machine
and run it, or install it via PsiWin (or equivalent program) from your
desktop computer. Once installed, a Caliope icon will appear on the
Extras bar; tap it to start Caliope.

The program should run on any EPOC machine (release 5 or earlier).
