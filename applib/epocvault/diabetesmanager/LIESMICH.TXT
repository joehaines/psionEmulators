Programm-Beschreibung
---------------------
DiabetesManager ist ein Persönlicher Diabetes Manager
für den Psion Serie 5(mx). DiabetesManager ist eine
Fortführung des Vorgängerprogramms ZuckTag5.



Dateien
-------
Die entpackte Datei "DiabetesManager.zip" enthält die
folgenden Dateien:

DiabetesManager.sis            Installationsdatei

Konvert_ZT120a_DM200.opo       Update-Programm für 
                               registrierte Nutzer
                               der dt. Version
                               ZuckTag5 1.20a

Liesmich.txt                   Diese Hinweis-Datei

Readme.txt                     Englische Hinweisdatei



Neuinstallation
---------------
Zunächst wird eine Verbindung zwischen Psion und PC
mit dem seriellen Link-Kabel hergestellt. Dann gibt
es 2 Wege zur automatischen Installation:

1. Von PsiWin (ab Version 2.1) bzw. Windows Explorer
   aus wird die Datei "DiabetesManager.sis" angeklickt.
   Das Programm EPOC Install wird damit automatisch
   aufgerufen und übernimmt die automatische
   Installation von DiabetesManager auf dem Psion. Bitte
   den Instruktionen von EPOC Install folgen.
   (Dieser Installationsweg wird empfohlen)

2. Die Datei "DiabetesManager.sis" wird vom PC auf den Psion
   kopiert. Auf dem Psion wird dann über die 
   "Syst.-steuer." das Programm "Add/remove"
   aufgerufen. Von dort wird die Datei "DiabetesManager.sis"
   neu installiert.
   


Update-Installation von Version ZuckTag5 1.20a
nach DiabetesManager 2.00
-----------------------------------------------
ZUNÄCHST MUSS eine Neuinstallation von
DiabetesManager 2.00 wie oben beschrieben durch-
geführt werden (alle Daten und Einstellungen
der alten Version 1.20a werden dabei NICHT
gelöscht!).

ANSCHLISSEND wird das Konvertierungs-Programm
"Konvert_ZT120a_DM200.opo" zum Psion kopiert und
dort durch doppeltes Antippen mit dem Stift
aufgerufen. Bitte den Instruktionen folgen.
Das Konvertierungsprogramm sorgt dafür, daß
die alten Daten und Einstellungen an die neue
Version "übergeben" werden.

Da das Passwort-Verfahren geändert wurde, muß der
registrierte Nutzer (leider) ein neues (kostenloses)
Passwort anfordern. Dazu bitte eine E-mail an den Autor,
die den vollen Psion Benutzernamen des Nutzers enthält,
wie er vom Systembildschirm aus unter dem Menüpunkt
"Informationen" -> "Benutzer" in der 1. Zeile
eingegeben ist. Das vergebene Passwort bezieht sich
auf diesen Benutzernamen-Eintrag.



Registrierung
-------------
Die Demo-Version von DiabetesManager ist bezgl. des
Funktionsspektrums ohne Einschränkungen. Begrenzt
ist die Zahl der möglichen Einträge bei einigen
Funktionen.

Nach der Registrierung erhält der Nutzer sein
Passwort und eine fertige Lebensmittel-Datei mit
über 900 Lebensmitteln. Nach Eingabe des Passwortes
werden alle Eingabebeschränkungen aufgehoben.
