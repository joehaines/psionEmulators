Installation
---------------
First please connect the Psion with PC bei the link
cable. Then there are two ways of automatical
installation:

1. In PsiWin (version 2.1 an higher) or Windows Explorer
   tap the file "DiabetesManager.sis". The program EPOC install
   will than be called and installs DiabetesManager automatically
   to the Psion. Please follow the instructions of
   EPOC install.
   (This way of installation is recommended)

2. The file "DiabetesManager.sis" has to be copied from the
   PC to the Psion. From the Psion then the program
   "Add/remove" must be called via the "Control panel".
   Select the file "DiabetesManager.sis" for new installation.
