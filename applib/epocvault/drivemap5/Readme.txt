Medialinx DriveMap5 (Freeware)
Version 1.00 for EPOC/32


Overview
========

DriveMap5 is a small EPOC/32 utility that adds Windows style Drive
Mapping to your palmtop computer. The program can be activated
from the Extras bar and allows you to map or unmap drives H to Y.


Installation
============

To install DriveMap5 on to your computer you must follow these
simple steps:

1. Create a directory called DriveMap5 in your System\Apps
   directory.

2. Copy DriveMap5.app, DriveMap5.mbm and DriveMap5.aif to this
   directory.

3. Install the RMR Software SUBST OPX file by running
   RMRSust.sis from the System Screen. You cannot use DriveMap5
   without this file.


Mapping a drive
===============

1. To map a local or network drive run DriveMap5 by clicking on
   the DriveMap5 icon in the Extras bar.
   
2. Select the drive that you would like to map from the list.

3. Enter the path that you would like to map that drive to. If
   this is not a valid drive/path DriveMap5 will tell you so.
   
4. If you want to unmap an already mapped drive check the
   "Disconnect" check box. If you try to unmap a non-mapped
   drive DriveMap5 will raise an error.
