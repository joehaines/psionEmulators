Readme file for EPOC32 Periodic Table BETA 2 (shareware)
--------------------------------------------------------

  July 14th, 1998

There are a few things you should note before using the
included software.

- The software is BETA. It has been tested, and it is not
  anticipated that there are any serious bugs in it, but
  of course this can never be known for certain. Use it
  only if you understand the risks involved in using beta
  software. For updated versions, see contact information
  below.

- This the *shareware* version of the program. The only
  difference between this and the release version is that
  the shareware version has only half of the properties
  available for viewing (or searching, or graphing). The
  registered version contains all properties. For
  registration information, see contact information below.

- For the beta version, there is no automated installation.
  To install the program, first create a folder titled
  "EPTable" under System\Apps (i.e. \System\Apps\EPTable\).
  After this has been done, transfer the following files
  over to this folder using the appropriate software:
  
    eptable.app
    eptable.rsc
    eptable.hlp
    eptable.aif
    eptable.mbm
    perlib.bkp
  
  You should now have an EPTable icon in your Extras bar.

Please send any bug reports to psion@orbit.org

For the latest version of the program, and ordering information,
visit the program's web site at:

  http://www.orbit.org/perlib/

Thank you for your support!
