1. INTRODUCTION

fMat is an extensive database with mechanical, physical, thermal and fatigue data of a large number of metals.
fMat also provides a glossary of terms related to materials and processes.

The demo version is not fully functional.
Please note that registration involves reloading the program. 


2. INSTALLATION

To install the program simply double-click on the .sis file or select the "Install New Program" option in PsiWin (EPOC Install). If you have PsiWin/EPOC Install v2.1 or above, then everything will happen automatically. If you have an earlier version, you will need to get the installation file SETUP.EXE, which can be downloaded from our Home Page. If you are unsure, then go to http://www.rmrsoft.com/ and follow the link to the 'SIS' page for a full explanation of the installation procedure.


3. RUNNING THE PROGRAM

Start the program by selecting 'Extras' from the Application bar and then selecting fMat.
