1. About FPlot5
   ================================
   FPlot5 is a simple function plotter. You can specify a function 
   like y=sin(x)/x and the axis ranges. If y-min and y-max are identical
   the actual y range is computed before the function is plotted.
   By selecting the plot option "Add" more than one function can be displayed
   at the same time.
