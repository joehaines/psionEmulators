HVAC/Building Services and Architectural Software by Silverglance Software
==========================================================================

Software for the Psion Series 5, 5mx and Geofox One 
===================================================

Having unzipped the file HVAC5.ZIP, the following files will be present:


Blowpip5.EXE        Pipe and pump calculations
Fanfare5.EXE        Duct and Fan calculations
Utopia5.EXE         U-value and condensation calculatoins
Vertigo5.EXE        Unit conversions

Double-click on each file to unzip the program files, and read the accompanying
installation notes, eg. Blowpip5.TXT etc.
