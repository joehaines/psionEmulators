Move 1.0  Add-on for Notepad

Released on May 16th, 1999
File size:  1759 bytes
Requirements:  Notepad v1.01 for the S5, Rev 3 or higher
--------------------------------------------------

The 'Move' add-on is a free add-on for Notepad Deluxe for the Psion
Series 5. Move gives Notepad extra functionality when choosing 'Cut'
from the Edit menu. Instead of just cutting the note, Notepad will
prompt you to move the note to a different notepad. If you only want
to cut the note to the Notepad clipboard, press Control-X twice
when cutting instead of once. Otherwise, select the notepad to move 
the note to, and press Enter to make the move.

Note: This is NOT a plugin, so don't copy the file to the directory
      where plugins are copied. Follow the instructions below for
      installing the add-on.


Installing the Move add-on
---------------------------

Note: Notepad does NOT need to be closed when you copy the move.opo file
      to the Psion for the first time

1. Using PsiWin, copy the move.opo file to the \System\Apps\Notepad 
   folder on the Psion. That's it. When using the 'Cut' option from the 
   'Edit' menu, Notepad will offer to move the note.


Uninstalling the Move add-on
----------------------------

If you decide that you don't want to be prompted to move a note when
choosing the 'cut' option, just delete the file...

	\System\Apps\Notepad\move.opo
