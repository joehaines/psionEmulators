OptionCalculator for the Psion Series 5 (Version 5.01)


Installation
------------
After unzipping you should have the following files:
- OptionCalc.app
- OptionCalc.aif
- OptionCalc.hlp
- OptionCalc.mbm
- AEX
- Register.txt
- Register.doc (Microsoft Word version 6.0)
- Readme.txt (this file)

The installation of OptionCalculator is simple if you perform the following steps:

1. Check if the Show 'System' folder (Ctrl-K from System) is enabled
2. Create a new folder called '\System\Apps\OptionCalc\' on the C or D disk
3. Unzip OptionCalc5v01.zip on your PC
4. Place the following files in the folder '\System\Apps\OptionCalc\' :
        OptionCalc.app
        OptionCalc.hlp
        OptionCalc.mbm
        OptionCalc.aif
5. Place the file AEX in the C:\Documents\ folder
6. Double-click on AEX and OptionCalculator will be executed automatically. Fill in your registration number and you have direct access to the full functionality of OptionCalculator.

Upgrading
---------
If you have a previous version of OptionCalculator, please take the following steps:
1. Unzip OptionCalc5v01.zip on your PC
2. Place the following files in the folder '\System\Apps\OptionCalc\' :
        OptionCalc.app
        OptionCalc.hlp
        OptionCalc.mbm
        OptionCalc.aif
