Pad 

Quick Notepad
By Steve Beadle
steve_beadle@iee.org
http://www.biblet.freeserve.co.uk
What does it do?
Saves up to two text notes via a simple dialog with configurable size and location.
Installation
Copy all files to a new folder called x:\System\Apps\Pad where x: is any drive.  You may need to make the System folder visible from the System Preferences menu.

Pad should then appear as an Extras icon.
How to use it
The buttons should be self explanatory, except for the '>' button which swaps between the two notes.  Pressing 'Esc' will cancel pad *without* saving the text - save by pressing 'Save' or 'Ctrl-S'.
