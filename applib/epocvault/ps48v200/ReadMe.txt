Psion48V2 is the first release of Psion48 for Epoc32.
Psion48 is an advanced scientific calculator, a sort
of clone of the HP48 from Hewlett Packard. It allows
to perform calculations on integers in any base and
in any word size (up to 32 bits), on compound numbers,
vectors, matrices [etc] as easily as on simple reals.
It uses a stack and RPN (Reverse Polish Notation).
It has not been fully tested, then do consider it as a
Beta release, and tell me if you find bugs.

Installation:
Create the directory c:\System\Apps\Psion48
Copy into it these files:
	- Psion48.app
	- Psion48.aif
	- Psion48.hlp
	- Psion48.mes
Create a directory C:\Psion48.
This will be the working directory (HOME)
of Psion48.

Psion48 is Shareware.
Use the 'help' command under Psion48 for details.
