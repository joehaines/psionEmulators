PsiFS: *Commands

*NameDisc
*NameDisc
Changes a disc's name

Syntax:*NameDisc disc_spec new_name

Parameters:disc_spec the present name of the disc or letter of the disc drive
new_name the new name of the disc, which may be up to 11 characters long

Use:*NameDisc (or alternatively *NameDisk) changes a disc's name.

Example:*NameDisc :C Internal

Related commands:None
