Web Page

A web page giving information about the current version of PsiFS, links to copies available for download, and details of future developments, exists at:
http://www.thouky.btinternet.co.uk/software/psifs/
A reasonably complete description of the Psion Link Protocol is also available from this site.

The PsiFS desktop filer requires copies of the Acorn Toolbox modules. These are already present in RISC OS 3.6 and above, but must be placed in the !System directory on older machines. A copy may be downloaded from the above location.
