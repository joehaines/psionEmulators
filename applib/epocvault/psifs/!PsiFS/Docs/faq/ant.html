PsiFS: Frequently Asked Questions

Serial Port Clashes

Why does the computer hang when PsiFS is enabled?

PsiFS does not support the device claim protocol. This means that PsiFS may attempt to use the serial port when another task is already using it, and will not prevent other applications from starting to use the serial port.

If a clash over use of the serial port occurs then the computer may appear to hang. Press Escape to regain control, then save any work and reboot the computer.

A common cause of this kind of problem is if the ANT Internet Suite is being used. !InetSuite accesses the serial port even when it is not using the modem, so it must be quit before enabling PsiFS. It is recommended that !InetSuite and PsiFS are never loaded at the same time.
