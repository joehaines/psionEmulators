PsiFS: Known Problems

Problems With This Version

See the frequently asked questions for details of other problems that may be experienced.
  • Quickly enabling and disabling the remote link (or vice versa) can cause the PsiFS module to hang. Press Escape to regain control, then save any work and reboot the computer.
  • Under RISC OS 4 enabling the printer mirror without an active printer connected can result in an infinite error loop. This is probably due to the new parallel port error detection.
  • Performing a backup makes sub-StrongARM machines almost unusable due to the excessive processor usage. An option to slow down the backup may be useful.

Missing Features

  • The device claim protocol is not supported. This means that PsiFS may attempt to use the serial port when another task is already using it, and will not prevent other applications from starting to use the serial port. This may be fixed in a later version for the serial block driver, but is unlikely to be corrected for the printer mirror destination.
  • There is no interface to allow third party file format converters to be added. This will probably be added to a future version.
  • An option to disable the constant polling of the SIBO or EPOC device (or at least slow it down) would be useful to allow interactive use of the remote machine. This should probably be a configuration option to set the default mode (perhaps a slider), with an option on the drive menu to change it temporarily.
  • It may be useful to allow just part of a disc to be backed up.
