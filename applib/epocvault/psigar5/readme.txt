Psigar 5 Beta

This version of Psigar for the Series 5 is released as a very early BETA version.

As such it must be understood that it is used entirely at the users own risk.

I am not responsibile for any loss or corruption of data you may suffer as a result
of using this program.

This software is definitely not ready for release! I have only made it available as it is usable in a limited manner and is as such better than nothing!


Installation

Make a Psigar5 directory under System\Apps on either the C or D drive.
Copy all the .mbm files into this directory.
Copy Psigar5 into this directory.


HELP.
Not Available.
The main functionality is pretty much as with the Series 3 version except that there is no way of editing anything other than waypoints.
