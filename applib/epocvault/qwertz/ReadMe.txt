Qwertz v1.01
------------

This very small utility allows you
to use the EPOC32 emulator with
a QWERTZ keyboard.


Installation:
-------------
Copy Qwertz.aif and Qwertz.app
in \System\Apps\Qwertz.


Usage:
------
Just start Qwertz from the Extras-bar.
Nothing will happen but the program
will be running. You can switch to
it and use :

   -> Esc to switch back to the former task.
   -> Del to quit.


Planned enhancements :
----------------------
None, but I'm waiting for your suggestions.


Known issues :
--------------
- Some conflicts may arise with hotkeys that differ
  on QWERTY and QWERTZ keyboards and you should avoid
  such keys. If you do use them anyway :

    + Start Qwertz before the concerned applications,
      otherwise Qwertz will cancel their hotkeys.
  
    + When an application set a hotkey, it uses the QWERTY layout.
      Therefore, if you want to set the hotkey 'Fn+Z', you must
      type 'Fn+Y'. The hotkey will be Fn+Z outside the application
      but Fn+Y inside.

- Qwertz uses the temporary UID &FEDCBA9.
