INTRODUCTION
I wrote this since I couldn't be bothered to look up a chart every time I looked at resistors and tried to figure what type it was.  Yeah, I know, it's easy to remember 1k, 10k etc but it's just to save thinking!
Oh, if there are any bugs, e-mail me.

INSTALLATION
Make a folder called ResCodes in your System/Apps folder.  
Copy 
		Rescodes.aif
		Rescodes.app
		Rescodes.opo
into this folder.  You'll find the app under the Extras bar.  The icon was created using good ol' 3DS Max.
