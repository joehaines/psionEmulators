First of all: Please excuse my very bad english, but in austria it's german ;-)

S5TIE is a strategy-thinking game where you need a little luck too.

From 27 tiles with different numbercombinations, you put 19 on the board.
After finishing, all rows containing the same numbercolumn are scored.

A spuer game for little breaks!

Installation:
	Supported Files:
		Directoy Grafik with 27 files (123.mbm - 978.mbm)
		S5TIE.aif
		S5TIE.app
		TB.mbm
		TBAll.mbm
		S5TIEGer.hlp
		S5TIEEng.hlp

1. Make shure, you have access to the System directory
	(Menu 'Extras' / preferences / Folder 'System' show aktivated)
2. Create a Directory 'S5TIE' in C:\SYSTEM\APPS (or. D:\SYSTEM\APPS)
3. Copy ALL files/dirctories in this directory (see supported files),
	without ReadMeGer.txt + ReadMeEng.txt

A new Programmicon appears in your Extrabar


Have fun beating the Highscores!
