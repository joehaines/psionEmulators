What does it do?
A variety of things - mainly self explanatory  SBUtilities is 'dialogware' - interacting via simple dialogs over the top of the current application.
Installation
Copy all files to a new folder called x:\System\Apps\PowerLink where x: is any drive.  You may need to make the System folder visible from the System Preferences menu.

SBUtilities should then appear as an Extras icon.
