TADS Interpreter by Michael J. Roberts, EPOC version by Simon Quinn
-------------------------------------------------------------------

TADS v2.5.03a Release 1, 13/01/01

This is the EPOC port of Michael J. Roberts's TADS Interactive Fiction interpreter. Code was ported from the Unix version.

To run this version you'll need STDLIB.SIS and ESHELL.EXE, both supplied in the ZIP file. 

Very little use is made of the the EPOC/EIKON environment, no graphics and not even any file dialogs so it'll keep you command line junkies happy ;-)


INSTALLATION
------------
* Install STDLIB.SIS first
* Copy the file TADS.EXE into \SYSTEM\PROGRAMS\
* Copy the file ESHELL.EXE anywhere


RUNNING THE GAME
----------------
You'll need some TADS adventures, plenty can be found at ftp.gmd.de/games/TADS. Their file extensions end in GAM.

Copy the files into a directory, i.e. \TADS onto your EPOC device.

Start ESHELL.EXE and enter "TADS /TADS/guilty", for example, to start a game. The / is important, don't use \ for directories. NOTE: TADS games end with the extension HEX.

Help is usually supplied in the game itself, type HELP.

BUGS
----
* A few adventures are currently known to crash the EPOC version, i.e. Arrival.
