Backup...

Selecting the Backup... menu entry opens the PsiFS backup window. This allows applications on the SIBO or EPOC device to be automatically shutdown and restarted; it does not yet perform a backup of the remote device. This is an experimental feature; use it at your own risk!

The top section of the window displays the current status, and the two buttons at the bottom of the window change depending on context:

  • Shutdown - Initiate a shutdown of all applications either on the selected drive (SIBO) or on all drives (EPOC).
  • Restart - Restart the previously closed applications.
  • Close - Close the window. Do not close the window between shutting down the applications and restarting them.
  • Abort - Abort any operation being performed.
Please read the known problems before attempting to use this feature.
