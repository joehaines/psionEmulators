PsiFS: Known Problems

Problems With This Version

  • The Psion 3-Link cable does not work with the serial port of older machines. This is due to the incorrect operation of the serial port, so it may not be possible to resolve this problem in software.
  • Applications written in OPL are not automatically restarted on EPOC devices. PsiWin exhibits similar behaviour, so there probably isn't anything that can be done to improve the situation.
  • The task shutdown behaves differently with SIBO and EPOC devices; on the former it closes applications on a single drive, but closes all applications on the latter.
  • Quickly enabling and disabling the remote link (or vice versa) can cause the PsiFS module to hang. Press Escape to regain control, then save any work and reboot the computer.

Missing Features

  • The device claim protocol is not supported. This means that PsiFS may attempt to use the serial port when another task is already using it, and will not prevent other applications from starting to use the serial port. This may be fixed in a later version for the serial block driver, but is unlikely to be corrected for the printer mirror destination.
  • The backup option has not been finished. A later version will support tar files for automatic incremental backups.
  • There is no support for file format converters. There is no intention to include file format converters within PsiFS, but an interface to allow use of third party converters may be added in the future.
  • An option to disable the constant polling of the SIBO or EPOC device (or at least slow it down) would be useful to allow interactive use of the remote machine. This should probably be a configuration option to set the default mode (perhaps a slider), with an option on the drive menu to change it temporarily.
