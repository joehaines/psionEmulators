PsiFS: SWI Calls

SWI Calls

The following SWIs are implemented by the PsiFS module. These are mainly intended for use by the desktop filer, but may be used by other clients.
  • PsiFS_Register
  • PsiFS_Unregister
  • PsiFS_Set
  • PsiFS_Get
  • PsiFS_Mode
  • PsiFS_AsyncStart
  • PsiFS_AsyncEnd
  • PsiFS_AsyncPoll
  • PsiFS_AsyncControl

A comprehensive OSLib interface (assembler header file and C veneers) to all of the PsiFS SWIs is available on request.
