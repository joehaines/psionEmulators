
*** TICKLE VERSION 1.1 ***

INSTALLATION

Copy the files "VWin.oph" and "VWin.opo" to "\system\opl\" on either C or D.

Copy the files "Tickle.app", "Tickle.aif", "Tickle.hlp" and "Tickle.mbm" to "\system\apps\Tickle" on either C or D.

Select Tickle from the Extra's Bar.

Please see the help for more information on how to use and register Tickle.
