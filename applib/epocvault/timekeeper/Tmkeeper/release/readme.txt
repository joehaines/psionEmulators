*** Installation

You need to unzip the ZIP file into a directory.  You have already
done this, or you would not be reading this file.  You then need
to follow these instructions:

   1. Startup PsiWin.
   2. Create a directory named "\System\Apps\Tmkeeper" on either
      the C: or the D: drive on the Psion, if you need to.
   3. Move all the unzipped files -- except this README -- into 
      the directory you just created.
   4. Close down PsiWin.

That's it.  You should now have the Time Keeper icon on the Extras bar.

*** Usage

Tapping the Time Keeper icon on the Extras bar will start the Time
Keeper application.  

Once you have started Time Keeper, the functions should be self-
explanatory.  The "Config" button will allow you to set the Network
Time protocol server on the net (although one is set when the app
runs).  Press the "Set Time" button to set the time.
