            Installation Instructions
            
            1. Unpack the Zip file to your PC.
            
            2. Double click on the file vpm.sis. This will start the PC
               automatic installation of appname.
	       Alternatively: copy the file vpm.sis to your Psion and double tap it,
	       this will start the Psion automatic installation of VPM.

	    3. Unpack vpmpc.zip to a temporary folder on your PC.
	       Double click on setup.exe; this will start the installation of the PC
	       component of VPM.
	       Follow the on-screen instructions to complete the installation.
            
            VPM should now be accessible to you from the Extras icon on your Psion and 
	    from the Start menu on your PC.
