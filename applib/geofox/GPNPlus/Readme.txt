GPNPlus V1.0 Freeware Readme.Txt
-------------------------------------------
 
This version of PNPlus has been adapted for the Geofox One by Ad Bosch. Thanks to Ad 
for the re-compiling and fixing the bugs.  All other documentation stands.

This application is very simple and very small (7Kb) - just a series of Screen Buttons.
The secret is in what they do. If you use Purplesoft's Navigator Application and are
like me then you will have set the 'Capture System Button' option. This (IMHO) has 
certain limitations, mainly the ability to switch the Remote Link on / off easily and 
check the battery status. Well you can now run this app in background from a shortcut
on your Workspace and have access to all these functions of your Series 5. Just press 
one of the screen buttons and get a Real Time status.

This is not a knock at Navigator, which I prefer to use than the Epoc32 System Screen 
but a suppliment to it.

--------------------------------------------------------------------------------------
Know Problems with V1.0 
---------------------------------
* Closure is by the screen button or the Esc key only at this time.
* It is set to run only from the internal drive - however with the small space taken
  up this should not be an issue.
* Help is on board and not a seperate file - I expect to keep it this way.
* Switching the Link on defaults to Cable at 115.2Kb
--------------------------------------------------------------------------------------


Installation.
-------------
To install, create a c:\system\apps\PNPLus directory and copy in the following files: 

PNPlus.app		- Main app
MPNPlus.aif		- Application information file
PNPlus.mbm		- Bitmap file.
EFM.mbm			- Epoc Freeware Movement Bitmap file.

Create a c:\system\opx directory and copy in the following files: 

Sysinfo1.Opx		- Otfried Cheong OPX Code
