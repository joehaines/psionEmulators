Geofox-One OPL 16 Patch
=======================

This patch fixes system crashes when using 16 color applications.

This file contains two files:
apprun.exe
d_patvc.ldd

Copy apprun.exe to \System\Programs, replacing the existing file, 
and copy d_patvc.ldd to \System\Libs.  Then soft reset your system
by pressing an unfolded paper clip into the reset hole on the bottom
of your system.
