Included here are three useful tools which run under DOS:

	1) BMCONV.EXE
	2) WVECONV.EXE
	3) WAV2WVE.EXE

They all display usage instructions if you run them without specifying
any files for conversion.

BMCONV
======
This utility converts between the PC bitmap file format "BMP" and the
Series 5 picture file format "MBM". The utility works in both directions.
MBM files can be imported and exported from the Series 5 Sketch 
application. By pressing Ctrl+Shift+Fn+S on the Series 5 you can
create an MBM file, which you can then convert to BMP format using
BMCONV, which is useful if you want to include Series 5 screenshots
in a magazine article or in an instruction manual for example.

WVECONV
=======
This utility converts between the Series 3a/3c sound file format "WVE"
and the Series 5 sound file format used by the Record application. This
is useful if you want to upgrade your alarm sounds from a Series 3a/3c, or
if you want to share your Series 5 sounds with Series 3a/3c owners.

WAV2WVE
=======
This utility converts between the Series 3a/3c sound file format "WVE" and
the PC sound file format "WAV". In conjunction with the WVECONV utility
described earlier, this provides a means for both Series 3a/3c owners and
Series 5 owners to exchange sound files to and from a desktop PC.

These utilities were not designed to be released to the general public,
but as they have proved themselves invaluable to many Psion Software 
developers, they have been included here for completeness. We hope that 
you will find them useful.
