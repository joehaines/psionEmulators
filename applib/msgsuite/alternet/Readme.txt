Installation Instructions

1. Unpack the Zip file to your PC or your Psion. 

2. On the PC:
   
	Double click on the file AlterNet.SIS. 	This will
	start the PC automatic installation of AlterNet. 
   
   On the Psion:
	
	Double tap on the file AlterNet.SIS. This will start
	the Psion automatic installation of AlterNet.


AlterNet should now be accessible to you from the Extras icon.
