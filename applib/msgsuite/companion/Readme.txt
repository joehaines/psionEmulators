
	*** Companion Verison 1.6 ***

   INSTALLATION

You need to install both VWin.SIS and CompanionV1.6.SIS  To do this, simple double click on them and the standard Psion installer will appear.

When correctly installed the companion icon, should appear on the extra's bar.

When you first run Compaion you **MUST** make sure that you select the version of the Email program you are using on your Psion.

If you are using an Email program on you Psion with Version earlier than V2.00 - ie if you own an original Psion, or a Geofox - you should go to 'Options' in Compaion and select Email Version 1.xx

If you are using an Email program on your Psion which is V2.00 or later - ie if you have a Psion 5mx or a Series 7, or a newer EPOC machine - you should go to 'Options' in Compaion and select Email Verison 2.xx

If you select the wrong version, you will simply get an error "Email App Not Running" when you try to insert your signatures or addresses.  If this happens, try the other version setting.
