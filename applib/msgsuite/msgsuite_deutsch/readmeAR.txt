Psion Serie 5 Systemsteuerungssymbol "Hinzu/Entf." 
============================================
Juni 1998
Dokument-Version 1.1.

Die Funktion "Hinzu./Entf." in der Systemsteuerung des Serie 5 ermöglicht
die automatische Installation und Deinstallation neuer, in Form von 
SIS-Dateien herausgegebener Programme.

Die Installation des Systemsteuerungssymbol "Hinzu./Entf." 
============================================

Wenn Sie PsiWin 2.1 oder höher benutzen, so wird das Systemsteuerungssymbol 
"Hinzu./Entf." automatisch beim ersten Anschließen des PCs an den Serie 5 installiert.

Wenn Sie PsiWin 2.1 oder höher nicht haben, brauchen Sie Software
auf Ihrem Computer, mit der Sie Dateien auf Ihren Serie 5 kopieren
können, und ein geeignetes Kabel, um den Serie 5 an den Computer
anzuschließen.

Beispiele:
- PC mit Windows 3.xx: Sie können PsiWin 1.xx verwenden.
- DOS: Verwenden Sie RCom.
- Macintosh: Sie können PsiMac oder Psion MacConnect verwenden.
- Für andere Computer wie Unix-, Amiga- und Atari-Computer gibt es eine
Reihe von Shareware-/Freeware-Programmen.

1. Schließen Sie den Serie 5 an den PC an, und kopieren Sie die Datei
instexe.exe auf den Serie 5. Am besten kopieren Sie die Datei in den
Ordner "\" (Wurzelverzeichnis).
2. Suchen Sie dann die Datei auf dem Systembildschirm, wählen Sie
sie aus, und drücken Sie die ENTER-Taste, um sie auszuführen. Nach
ein paar Momenten verschwindet die Datei vom Bildschirm. 

Nun wurde das Symbol "Hinzu./Entf." der Systemsteuerung des Serie 5
hinzugefügt.

Installieren neuer Software in Form von SIS-Dateien
================================================

Auf einem Windows 95/NT4.0 PC
------------------------
Wenn PsiWin 2.1 oder höher auf Ihrem PC installiert ist:
- Doppelklicken Sie im Windows Explorer auf eine .SIS-Datei,
um Programme auf Ihrem Serie 5 zu installieren.

Wenn PsiWin 2.0 auf Ihrem PC installiert ist:
- Installieren Sie zuerst das Programm 'EPOC Install'. Führen Sie dazu
die Datei SETUP.EXE aus. Erst dann können Sie neue Programme installieren.
- Nun können Sie im Windows Explorer auf eine .SIS-Datei doppelklicken,
um Programme auf Ihrem Serie 5 zu installieren.

Wenn Sie zum ersten Mal ein Programm oder eine Datei mit 'EPOC Install' oder
PsiWin 2.1 oder höher installieren, wird das Symbol "Hinzu./Entf." der 
Systemsteuerung des Serie 5 hinzugefügt.

Mit einem Macintosh
----------------

Sie können .SIS-Dateien mit der Installationsfunktion von MacConnect
wie folgt installieren:

- Wählen Sie PsiTools im Psion-Menü, klicken Sie auf "Installieren", und
gehen Sie zu dem Ordner, in dem Sie die Datei xxxx.SIS gespeichert haben.
- Wählen Sie diese Datei, und klicken Sie auf "Öffnen".
- Befolgen Sie die auf dem Bildschirm erscheinenden Anweisungen, um die
Programme auf Ihrem Serie 5 zu installieren.

Wenn Sie MacConnect nicht haben, können Sie trotzdem neue Programme
installieren, vorausgesetzt, Sie haben das Symbol "Hinzu./Entf." in der
Systemsteuerung Ihres Serie 5 installiert.

Der Gebrauch des Systemsteuerungssymbols "Hinzu./Entf." des Serie 5
mit anderen Computern
----------------------------------------------------------------
Sie müssen zuvor das Symbol "Hinzu./Entf." in der Systemsteuerung Ihres Serie 5
installiert haben (siehe oben).

1.  Kopieren Sie die SIS-Datei auf den Serie 5 (wiederum am besten in den
Ordner "\").
2.  Wählen Sie die Datei im Systembildschirm aus, und drücken Sie die 
ENTER-Taste. Nun beginnt die Installation des Programms bzw. der Programme.
3. Befolgen Sie die auf dem Bildschirm erscheinenden Anweisungen.

Die .SIS-Datei wird nach beendeter Installation gelöscht, um
Festplattenspeicher zu sparen.

Die neuesten Informationen erhalten Sie unter http://www.psion.com/international
