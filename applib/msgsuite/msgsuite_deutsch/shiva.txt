Psion Serie 5 Message Suite - Router-Upgrade (1.00)

Für Message Suite 1.0 und 1.1

Dieses Upgrade für Message Suite behebt ein Problem, das auftreten kann, 
wenn ein Internet Service Provider oder Unternehmensnetzwerk einen Shiva 
Internet-Router einsetzt. Das Upgrade bringt keine zusätzliche Funktionalität 
und wirkt sich nicht auf den Betrieb von Message Suite mit anderen Internet-Routern 
aus.

Falls Probleme beim Aufrechterhalten einer Verbindung auftreten, d.h. wenn 
die Verbindung hergestellt, jedoch nach ein paar Minuten wieder getrennt wird, 
sollten Sie dieses Upgrade installieren.

ACHTUNG: Diese .SIS-Datei enthält nur die Upgrade-Dateien, so daß Sie Message Suite 
vor dem Router-Upgrade NICHT deinstallieren sollten. Bei der Installation des 
Upgrades werden die Programmeinstellungen in keinster Weise geändert.

Dieses Upgrade ist für die Message Suite Versionen 1.0 und 1.1 geeignet. Wenn Sie 
derzeit mit Message Suite 1.0 arbeiten und später zu 1.1 aufrüsten, müssen Sie 
das Router-Upgrade nach der Installation der Version 1.1 erneut installieren. 

Router-Upgrade installieren

Das Upgrade wird in Form einer .SIS-Datei geliefert.

Wenn Sie einen PC haben, können Sie es mit dem Befehl 'Neues Programm installieren' 
in PsiWin 2.1 installieren. Klicken Sie die rechte Maustaste auf 'Psion Arbeitsplatz' 
und wählen Sie 'Neues Programm installieren'.

Wenn Sie einen Macintosh Computer haben, können Sie die Software mit Psion MacConnect 
installieren. Wählen Sie im Psion-Menü 'PsiTools', und klicken Sie auf 'Installieren'.

Haben Sie einen anderen Computer, so brauchen Sie die entsprechende Software und ein 
geeignetes Verbindungskabel, um die SIS-Datei auf den Serie 5 zu kopieren. Doppelklicken 
Sie dann auf dem Systembildschirm auf die Datei, um sie aufzurufen.

Weitere Informationen über die Installation von SIS-Dateien finden Sie in der Message 
Suite Datei Liesmich.txt und in der Hilfe zu PsiWin 2.1.
