Psion Series 5 Add/remove control panel icon
============================================
Last updated 12th August 1998
Document version 1.2
Authors - Ian Fogg and Velma Allen


Add/remove is a function for the Series 5 control panel which enables
you to automatically install, or uninstall, new programs distributed as
SIS files.


To install the Add/remove control panel icon
============================================

If you have PsiWin 2.1 (or above), the Add/remove control panel icon
will be automatically installed when you first connect your PC to your
Series 5. 

If you do not have PsiWin 2.1 (or above):
You must have software installed on your computer to copy files to your 
Series 5, and a suitable cable to connect your computer to the Series 5.

Examples:
- Windows 3.xx PC: you can use PsiWin 1.xx.
- DOS: use RCom
- Macintosh: you can use PsiMac or Psion MacConnect.
- For other machines, such as Unix, Amiga and Atari computers there are a
number of shareware/freeware packages available.

1. Connect the Series 5 and copy the file inst_te.exe to the Series 5. It
is best to copy the file to the "\" (root) folder.
2. Then, locate the file in the System screen, select it and press Enter
to run the file. After a few moments, the file will disappear from view.

This has installed the Add/remove icon to your Series 5's Control panel.


Installing new software distributed as SIS files
================================================

With a Windows 95/NT4 PC
------------------------
If you have PsiWin 2.1 (or newer) installed on your pc:
- Double-click on an .SIS file in Windows Explorer
to install programs on to your Series 5.

If you have PsiWin 2.0 installed on your PC:
- First, install the 'EPOC install' program by running SETUP.EXE.
You will need to do this before you can install new programs.
- You will now be able to double-click on an .SIS file in Windows Explorer
to install programs on to your Series 5.

The first time you install a program or file using EPOC install, or
PsiWin 2.1, the Add/remove icon is added to the Series 5 Control panel.

With a Macintosh
----------------
You can install .SIS files using MacConnect's install feature:

- Select PsiTools on the Psion menu, press the Install button, and
navigate to the folder in which you have saved the xxxx.SIS file.
- Select this file and click Open. 
- Follow the on screen instructions to install the programs on your
Series 5.

If you do not have MacConnect, you can still install new programs,
provided you have installed the Add/remove control panel icon on your
Series 5.

With other Machines, using the Series 5 Add/remove control panel
----------------------------------------------------------------
You must have the Add/remove control panel icon already installed onto your
Series 5 (see above).

1. Copy the SIS file to the Series 5 (again, it is best to copy it to
the "\" folder).
2. Select the file in the System screen and press Enter. This will start
installing the program(s). 
3. Follow the instructions on screen.
 
The .SIS file will be deleted when the installation is complete to
conserve disk space.
