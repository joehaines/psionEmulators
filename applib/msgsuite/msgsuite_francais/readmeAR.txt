Icône Ajout./Suppr. du panneau de configuration pour le Series 5
============================================
18 juin 1998
Document : version 1.1

La fonction Ajout./Suppr. sur le panneau de configuration du Series 5 vous permet d’installer ou de désinstaller
 automatiquement des programmes sous forme de fichiers SIS.


Pour installer l’icône Ajout./Suppr. du panneau de configuration
============================================

Si vous disposez de la version 2.1 ou d’une version ultérieure de PsiWin, l’icône Ajout./Suppr. s’installera 
automatiquement dans le panneau de configuration lors de la première connexion entre votre PC et le Series 5. 

Si vous ne disposez pas de la version 2.1 ou d’une version ultérieure de PsiWin :
Vous devez impérativement avoir installé sur votre ordinateur un logiciel permettant de copier des fichiers sur 
le Series 5 et vous procurer un câble adéquat pour relier le Series 5 à l’ordinateur.

Exemples :
- PC sous Windows 3.xx : vous pouvez vous servir de PsiWin 1.xx.
- DOS : utilisez RCom
- Mac : vous pouvez vous servir de PsiMac ou Psion MacConnect.
- Pour les autres machines (Unix, Amiga et Atari) il existe plusieurs logiciels (partagiciels/graticiels) 
disponibles à cet effet.

1. Connectez le Series 5 et copiez le fichier instexe.exe sur le Series 5. Il est recommandé de copier le fichier 
dans le dossier "\" (racine).
2. Localisez ensuite le fichier dans l’écran Système, sélectionnez-le et appuyez sur Entrée pour l’exécuter. Au bout 
de quelques instants, le fichier disparaîtra de l’écran.

L’icône Ajout./Suppr. est désormais installée dans le panneau de configuration du Series 5.

Installation d’un nouveau logiciel sous forme de fichier SIS
================================================

Ordinateurs PC sous Windows 95/NT4
------------------------
Si PsiWin 2.1 ou une version ultérieure de PsiWin est installée sur votre PC :
- Cliquez deux fois sur un fichier .SIS à partir de l’Explorateur Windows pour installer le programme correspondant 
sur le Series 5.

Si PsiWin 2.0 est installé sur votre PC :
- Installez d’abord le programme "EPOC install" en lançant SETUP.EXE.

Cette étape est indispensable pour pouvoir installer des nouveaux programmes sur le Series 5.

- Vous pouvez ensuite cliquer deux fois sur un fichier .SIS à partir de l’Explorateur Windows pour installer le programme 
correspondant sur le Series 5.

A la première installation d’un programme ou d’un fichier à l’aide d’EPOC Install, 
de PsiWin 2.1 ou version ultérieure, l’icône Ajout./Suppr. est ajoutée dans le panneau de configuration du Series 5.

Ordinateurs Mac
----------------
Vous pouvez installer les fichiers .SIS à l’aide de la fonction d’installation MacConnect :

- Sélectionnez PsiTools dans le menu Psion, appuyez sur le bouton Installer, puis localisez le dossier dans lequel vous avez 
sauvegardé le fichier xxxx.SIS.
- Sélectionnez ce fichier et cliquez sur Ouvrir. 
- Respectez les instructions qui s’affichent à l’écran pour installer le nouveau programme sur le 
Series 5.

Vous pouvez installer des nouveaux programmes sur le Series 5 même si vous n’avez pas MacConnect, à condition d’avoir 
installé l’icône Ajout./Suppr. dans le panneau de configuration du Series 5.

Autres Machines, en utilisant Ajout./Suppr. du panneau de configuration du Series 5
----------------------------------------------------------------
Il faut que l’icône Ajout./Suppr. soit déjà installée dans le panneau de configuration du Series 5 (voir ci-dessus).

1. Copiez le fichier .SIS sur le Series 5 (il est recommandé de le copier dans le dossier "\").
2. Sélectionnez le fichier dans l’écran Système et appuyez sur Entrée. Ceci lance l’installation du ou des programmes. 
3. Suivez les instructions qui s’affichent à l’écran.
 
Le fichier .SIS sera effacé après l’installation pour économiser l’espace disque.

Pour obtenir les informations les plus récentes, rendez-nous visite sur le site Psion à l’adresse 
http://www.psion.com/international
