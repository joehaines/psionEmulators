SignIt--------
SignIt is a small freeware application to enable signatures to be inserted into e-mails created by Message Suite.
SignIt can store up to 3 signatures which can be edited, deleted etc.
SignIt is supplied in a SIS format.
After installation run SignIt from the Extras Bar. Select the Config Toolbar and add up to 3 signatures as required.
As you enter a new signature the selected code will appear on the next available toolbar button.
To insert a signature when you have created a new e-mail in Message Suite run SignIt. Select a signature to insert by tapping the appropriate toolbar button. The signature will be automatically be added to the email.
(Note: you must still be in the New e-mail screen with the cursor placed where you want the signature inserted)
To speed up the use of SignIt I would suggest that if you are running Macro5 that you assign SignIt to a HotKey. All that is then necessary is to use the HotKey to bring the signature options to the foreground.
