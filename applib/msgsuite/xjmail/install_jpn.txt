1. インストール概要
-------------------

1.1. 基本インストール
---------------------

  使用機種と環境により、最低限必要なインストール作業に違いが
  あります。

  * Enfour社のUniFEP V2(日本語版)か5mx Pro日本語版のユーザー:
    xjmail.sis      [2.1. 参照]   と
    テキストエディタ[2.2.1. 参照] のみ。
 

  * 上記以外で、5mx/ 5mx Pro/ MC218/ Revo/ Revo Plus/ Mako/ 
    Series 7/ netBook/ netPad のユーザー: 
    xjmail.sis      [2.1. 参照]   と
    テキストエディタ[2.2.1. 参照] と
    日本語フォント  [2.2.2. 参照]。

  * Series 5 (5mxではなく、俗に5 Classicと呼ばれる機種)、
    Geofox One、Osarisの3機種のユーザー:
    xjmail.sis      [2.1. 参照]   と
    テキストエディタ[2.2.1. 参照] と
    日本語フォント  [2.2.2. 参照] と
    MessageSuite    [2.2.3. 参照]。

  インストールの順序は重要ではありません。

1.2. 高度な機能とカスタマイズ概要
--------------------------------

  必要と御好みとに応じて、各種モジュールを追加したり入れ替え
  る事で機能変更/拡張する事が出来ます。
  ご使用のプロバイダによっては APOP [3.1.1.1 参照]や
  SMTP AUTH モジュール [3.1.1.2 参照] のインストールが必要に
  なるかもしれません。

2. 基本インストール
-------------------

2.1. xjmail.sisのインストール(必須)
-----------------------------------

  XJMail バイナリパッケージには 様々なファイルが含まれていま
  すが、最低限必要なのは xjmail.sisだけです。
  まず xjmail.sisをお好きなドライブにインストールして下さい。
  (SISファイルのインストール方法が判らない場合には、
  "補遺1. SISファイルのインストール" を 参照して下さい。)

  これにより、

  XJMail 1.31
  MailHelper OPX 1.04
  JPPrint OPX 1.05
  JPPrint Control Panel 1.00
  FileFolder OPX 1.02
  CDescriptor OPX 1.00
  CSocket OPX 1.09
  Buffer OPX 5.0
  Systinfo OPX 5.0

  がインストールされます。
  この段階ではまだXJMailを起動せず、
  "2.2. XJMail パッケージ以外に必要なもの" にお進みください。

  注) 以前のバージョンの XJMailでは、各種 OPX は XJMail 本体
      とは別に インストールしていましたが、 本バージョンから
      全ての OPXが XJMail本体と同時に インストールされる様に
      なりましたので御注意ください。

2.2. XJMail パッケージ以外に必要なもの
--------------------------------------

  御使用の環境に応じ、以下のものを別途インストールして下さい。

  * テキストエディタ(必須)                     [2.2.1. 参照]

  * フォント(日本語版やUniFEP V2環境では不要、そうで無い場合
    は必須)                                    [2.2.2. 参照]

  * MessageSuite(Series5/Geofox One/Osarisの3機種のみ必須)
                                               [2.2.3. 参照]

  以下に、それぞれについての詳細を記します。

2.2.1. テキストエディタ(必須)
-----------------------------

  XJMailでは、メイルの編集にユ－ザが指定したテキストエディタ
  を使用します。日本語のメイルを書くためには、SJISテキストを
  直接編集出来て、他のプログラムから呼び出す事の出来るエディ
  タが一つはインストールされていなければなりません。
  XJMail開発者は、その様なエディタとして

  * JMemo Private Patch版
  * Note (以上両方とも 
       <http://www.hi-ho.ne.jp/~ktkawabe/> から取得可)
  * UniED (<http://homepage2.nifty.com/cars/> から取得可)

  を配布しています。 他に何があるのか知りたければ、 
  あけぼのの里 <http://psion.itatei.gr.jp/>
  Psi'F'Rush   <http://www.psifrush.com>
 等の日本語レビューサイトを御覧になると良いでしょう。

  日本語を書く必要が無いのであれば、Symbian Text Editor等の
  SHIFT_JISに対応していないエディタを使う事も出来ます。

  EPOC標準の Word(ワ－ド)はテキストを直接出力する事が出来ませ
  んので、XJMailで使うためには適していません。

2.2.2. フォント
     (日本語版やUniFEP V2環境では不要、そうで無い場合は必須
------------------------------------------------------------

  日本語版製品やUniFEP V2環境では UniFEPのフォントを使用する
  事が出来ますので、新たにフォントをインストールする必要はあ
  りません(もちろん、以下に示すjiskan フォント類を新たにイン
  ストールしてそれを使う事も可能です)。
  それ以外の環境では、日本語表示のためにjiskan.gdrまたはその
  互換フォントをインストールする事が必要です。

  jiskan.gdrは、開発者の小山忠義氏のホームページ
  <http://antenna.infocity.co.jp/antenna_series5.htm>
  もしくは googo氏の Psion Search
  <http://www.wotakara.com/googo/navi/navi.cgi>
  から取得可能です
  (追記:  2002年11月現在、小山氏のサイトはフォント類の配布を
  停止しています)。

  また、様々な字体とサイズのjiskan互換フォントが有志の方々に
  より配布されています。
  これらのjiskan互換フォントの入手先については、
  <http://www.hi-ho.ne.jp/~ktkawabe/k/jiskan.html>
  を参照してください。

  注) jiskanフォントのインストール法
      c:\System\jfonts\, d:\System\jfonts\, c:\System\fonts\,
      d:\System\fonts\ の いずれかのフォルダに jiskan.gdr を
      コピーします。フォントのインストール場所によってシステ
      ムの挙動に多少の違いが出ます。

      \system\fontsにフォントを置いた場合、ER5(Series 5MX系
      /Revo系/netBook系)ではPsiWinを用いたバックアップが出来
      なくなりますので、\system\jfonts に フォントを置く方が
      良いでしょう。しかし、こうすると KEditが使えなくなりま
      す(JMemoは問題無く使用出来ます)。

  注) Psion上で Systemフォルダが見えない場合、システム画面で
      menu-> tools-> preferences
      で表示される設定項目のうち、
      show hidden files とshow "System" folder
      にチェックすると良いことがあるやもしれません。

2.2.3. MessageSuite(Series5/Geofox One/Osarisの3機種のみ必須)
------------------------------------------------------------

  Psion Series5 (初代Series5の意味です。Series 5MXの事ではあ
  りません。)、Osaris、Geofox Oneの3機種に限って、 Psionから
  配布されている MessageSuite というソフトウェアを一旦インス
  トールしなければなりません。
  MessageSuiteは 大抵の場合これらの機種に付属のCDROMに入って
  いますが、CDROMを持っていない場合には Psion Digital のweb
  ページ
  <http://www.psion.com>
  からダウンロードページを探して取って来て下さい。

  MessageSuiteは上記3機種専用のソフトウェアです。
  それ以外の機種では最初から入っている機能と競合するので
  MessageSuiteをインストールしないで下さい。

  注) 上記3機種に MessageSuiteをインストールすると、
      "EMail" および "Web" と、
      "Networking Component" (TCP/IPスタック)がイン
      ストールされます。このうち XJMailの動作に必要
      なのはTCP/IPスタックのみですから、EMailと Web
      は不要なら後からアンインストールしても構いま
      せん。

3. 高度な機能とカスタマイズ
---------------------------

3.1. その他に XJMail パッケージに入っているもの
-----------------------------------------------

  XJMailパッケージには、APOP/SMTP AUTHのためのモジュール
  (xjm_auth.zip)とフォルダセレクタを入れ替えるためのモジュー
  ル(fdlg_???.zip)が用意されています。
  必要とお好みに応じてインストールして下さい。

    xjm_auth.zip       (APOP/SMTP AUTHモジュール)
    fdlg_ndirnav.zip   (nDirNav版フォルダセレクタ)
    fdlg_std.zip       (EPOC標準フォルダセレクタ)
    fdlg_ff.zip        (FileFolder版フォルダセレクタ)

3.1.1. 各種認証モジュール(お好みで、プロバイダによっては必須)
-------------------------------------------------------------

  XJMailでは、一般性の高くない認証機構 (APOPおよびSMTP AUTH)
  を別モジュールとして提供しています。
  これらのモジュールは全て xjm_auth.zipの中に入っています。
  APOPと SMTP AUTHは別々にインストールする事が可能です。

  xjm_auth.zipには、以下の7つのファイルが含まれます。

    XJM_APOP.opo     (APOPモジュールのバイナリ)
    xjm_SMTPA.opo    (SMTP AUTHモジュールのバイナリ)
    md5opx-v0.02.sis (近藤作のMD5OPX)

    XJM_APOP         (APOPモジュールのソース)
    xjm_SMTPA        (SMTP AUTHモジュールのソース)
    md5opx-ja.txt    (同OPXのドキュメント)
    md5opx-en.txt    (同OPXのドキュメント、英語版)

    注) MD5OPXは、XJMail開発者の一人である近藤 個人に
        よる、XJMailとは別の著作物です。
        配布条件や利用条件は XJMail使用許諾書
        (XJM_COPY.TXT)に矛盾しないので、そのままXJMail
        配布パッケージに含めて配布しております。
        MD5OPXは APOPや SMTP AUTH (CRAM-MD5) に必要な
        MD5 message digest を計算するため、
        RSA Data Security Inc. の著作物を使用しており
        ます。これらの点につきましては、md5opx-ja.txt
        を御覧下さい。

  以下にそれぞれのモジュールについて述べます。

3.1.1.1. APOP (お好みで、プロバイダによっては必須)
--------------------------------------------------

  APOPサポートが必要な場合、本配布パッケージに含まれる
  xjm_auth.zip から XJM_APOP.opoを取り出して XJMailをインス
  トールしたドライブの  \System\Apps\XJMail  ディレクトリに
  コピーするとともに、同zipファイルから md5opx-v0.02.sisを
  取り出してインストールします。

  以上で、APOPの使用準備が整いました。 APOP を使用するための
  設定等につきましては、xjm_hlp.txt の受信設定の項を参照して
  下さい。

    注)APOPとは、POP3 にパスワード盗聴防止のための仕組
       みを付加したものです。
       通常の POP3 では、パスワードが平文のままインター
       ネット上を流れるため、容易に盗聴可能であるという
       欠点があります。APOP を使えば パスワードが暗号化
       されるので、悪意を持った人にパスワードを盗聴され
       ることを防ぐことができます。
       しかし、APOPの普及度はPOP3ほどではなく、プロバイ
       ダの対応状況も、外部からの接続には APOP を必須と
       しているところがある一方で、APOP自体を認めていな
       いところも存在するなど、様々です。
       APOPを使うべきかPOP3にするべきかについては、お使
       いのプロバイダにお問い合わせの上判断してください。
       判らない場合は、APOP を使わない設定が無難です。

3.1.1.2. SMTP AUTHモジュール
         (お好みで、プロバイダによっては必須)
---------------------------------------------

  XJMailは、送信にSMTP認証 (SMTP AUTH)をサポートしています。
  サポートされる認証機構はCRAM-MD5とLOGINのみです。

  SMTP認証が必要な場合、本パッケージに含まれる xjm_auth.zip
  から xjm_SMTPA.opo を取り出して XJMailをインストールした
  ドライブの   \System\Apps\XJMail ディレクトリにコピーする
  とともに、同zipファイルから md5opx-v0.02.sis を取り出して
  インストールします。

  以上で、SMTP AUTHの使用準備が整いました。 実際にSMTP AUTH
  を使用するには、xjm_hlp.txtの 送信設定の項を参照して下さい。

    注) SMTP認証とは、SMTPサーバーを使用してメイルを送信
        する時に、許可されたユーザーだけに送信を許す仕組
        みです。サーバー管理者側から見れば、SPAMやウィル
        スメイル等を含む「迷惑な」メイルが無制限に転送さ
        れる確率を小さくする事が出来るというメリットがあ
        ります。
        SMTP 認証の採用状況は サーバーによってまちまちで
        あり、使えない場合もありますし、必須である場合も
        あります。SMTP AUTH を使わねばならないのかどうか
        については、お使いのプロバイダにお問い合わせの上
        判断してください。判らない場合は、まずSMTP AUTH
        を使わない設定で送信してみるのが良いでしょう。

    注) SMTP認証を使う場合にはまずCRAM-MD5を試し、うまく
        いかない場合にLOGINを試してみるのが良いでしょう。
        CRAM-MD5認証方式では認証のために必要な(パスワード
        等の)情報は暗号化されてサーバーに送らます。
        一方、LOGIN認証では、認証のための情報は全く暗号化
        されずに送られます。このため、もし SMTP認証を使わ
        ねばならないのであれば、CRAM-MD5の方が LOGINより
        も遥かに安全です。
        プロバイダによっては CRAM-MD5をサポートしないが
        LOGIN認証はサポートされている場合がありますので、
        LOGIN認証はそのような場合にだけ仕方なく使うもの
        だと考えてください。

  SMTP認証とは違いますが、もう一つの弱い認証機構である
  POP before SMTPもサポートされております。
  POP before SMTP を利用するだけであれば、余計なモジュールを
  インストールする必要はありません。


3.1.2. フォルダセレクタモジュール(お好みで)
-------------------------------------------

  ユーザーが好みに合わせてユーザーインターフェイスを選択出来
  る様に、フォルダ/ファイルセレクタの部分は インストールドラ
  イブの
  \system\apps\XJMail\xjm_fdlg.opo
  というモジュールとして提供されます。EPOC標準のフォルダセレ
  クタには、大きな CF (NetBook では大容量の microdrive等) を
  使用している場合に動作が大変遅くなるという欠点があり、この
  問題を回避するためにデフォールトでは FileFolderOPXに含まれ
  る GUI セレクタがインストールされますが、 上記モジュールを
  別のものと入れ替える事で、他のものを使用する事が可能です。
  2002年11月30日現在、FileFolder OPX版を含めて以下の三つのも
  のが提供されています。

    fdlg_std.zip     (EPOC標準、使いやすいが大変遅い)
    fdlg_ndirnav.zip (nDirNav版 GUIセレクタ)
    fdlg_ff.zip      (FileFolder版 GUIセレクタ)

  使用法については、これらのファイルを解凍して得られるドキュ
  メントを参照して ください。
  デフォールトでインストールされるFileFolder版のセレクタは、
  使用法を読まずともそれなりに使用する事が可能だと思いますが、
  使用法を理解して使えば作業効率を大幅に向上させる事が可能で
  す。是非folderselector.txtをお読みになる事をお勧めします。

3.2. XJMail パッケージには入っていないもの
------------------------------------------

3.2.1. Importerモジュール(お好みで)
-----------------------------------

  XJMailでは、 他のメイラのデータを XJMailが扱える形式に変換
  して、XJMail のメッセージフォルダにコピーするためのモジュー
  ル(importerモジュールと呼びます)をサポートします。
  XJMailを配布しているのと同じところ、例えば
  <http://www.hi-ho.ne.jp/ktkawabe/densha.html>
  に、XJMailのためのimporterのリストがあります。
  Importerモジュールは、XJMailの動作そのものには必須ではあり
  ませんので、最初のうちは無視してください。
  慣れてきたら、適当なimporterをインストールなさるなり御自分
  で開発するなりしてください。
  Importerモジュールのインストールについては、各モジュールの
  ドキュメントに従って下さい。

4. アンインストール
-------------------

  \system\apps\XJMail\importerフォルダが存在する場合には、先
  にそのフォルダと中身を全て削除してください。  その後、コン
  トロールパネルのadd/removeで XJMail をアンインストールして
  下さい。

  \system\apps\XJMail\XJMail.act
  \system\apps\XJMail\*.ini
  が残っていれば、それも全て削除して下さい。

補遺1. SISファイルのインストールについて
----------------------------------------

  EPOCデバイス上でのインストール、PsiWinを使ったインストール、
  MacConnectを 使ったインストールについて、注意点を述べます。

補遺1.1. 一般的な注意
---------------------

  インストールがうまく行かなかった場合、まずはダウンロードや
  解凍が正しく行われたかどうか確認して下さい。
  あなたがインストールした SISファイルのタイムスタンプやサイ
  ズが、補遺2.に記述されているものと違う場合には、ダウンロー
  ドか解凍の少なくともどちらか一方が正しく行われていません。

補遺1.2. EPOCデバイスでのインストールの注意点
---------------------------------------------

  ここで言う EPOCデバイスとは、あなたの 5mxや Revoなど、実際
  に XJMailがインストールされるものの事を指します。
  XJMail作者は EPOCデバイスでのインストールを推薦します。
  やり方は大変簡単です。
  SISファイルをEPOCデバイスに転送します。
  EPOCデバイス上でSISファイルをペンでタップするとか何とかする
  と、そのファイルがインストールされます。これだけです。

  Series 5 もしくは Geofox ONE を御使用の場合に限り予想される
  トラブルとしまして、SIS ファイルのアイコンが "?" マークで、
  タップしてもインストールされた様子が無い、 というものがあり
  ます。
  この場合、 ご使用になられている EPOC デバイスにインストーラ
  プログラムがインストールされておりません。
  Symbianのwebサイトからinst_te.exeというプログラムを取得し、
  まずこれをインストールする必要があります。

  <http://www.psion.com/downloads/epoc32/add_remove_control_panel/inst_te.exe>

  EPOCデバイスで直接ダウンロードするとか、PCから転送する等、
  任意の方法で inst_te.exeをEPOCマシン上に置き、タップします。
  何の表示も無しにこのファイルは消えてしまいますが、コントロー
  ルパネルを開くと  Add/Remove というアイコンが出来ており、
  SISファイルのアイコンも、 ？ではなくそれらしいものに変わる
  はずです。

  ER5デバイス(Series5MX/5MX Pro, Revo/RevoPlus/mako, Series7,
  Netbook, MC218, netPad) では、inst_te.exe のインストールは
  不要です。この点を知っていれば、あとはトラブルの心配は無い
  でしょう。

補遺1.3. PsiWinでのインストールの注意点
---------------------------------------

  Windows上で適当なフォルダに SIS ファイルを置き、ケーブルや
  赤外線などで PCと EPOC デバイスを接続した上で、SISファイル
  をダブルクリックするとインストールが始まります。

  XJMailのインストールに関する限り 特に注意点はありませんが、
  PsiWinのインストーラを使用すると Symbian のknowledge base

  <http://www3.symbian.com/faq.nsf/51681023dd5b127980256a64005ac61c/24a8ea95df0953ad80256a570051b8bf?OpenDocument&Highlight=2,pkg,file>

  に示されている様に、アンインストール時にファイルの依存性が
  正しく解決されない場合がありますので、PsiWinでのインストー
  ルよりはデバイス上でのインストールの方が良いでしょう。

補遺1.4. MacConnectでのインストールの注意点
-------------------------------------------

  MacConnectにはPsiWinと同様のインストール機能があるのでそれ
  を使用するか、または SIS ファイルを EPOCデバイスに転送した
  上で EPOCデバイス上でインストール作業を行います。 

  初期バージョンのMacConnectとMacOS8.5の組み合わせでは、不具
  合が生じる事があります。この場合、MacConnectを最新のものに
  入れかえるのが良いでしょう。

  特定のファイルについて、MacConnectのpsitoolsを使わない、つ
  まりMacConnectの提供するインストール機能を使用しなければう
  まく行くという御報告を受けた事もあるので、うまく行かない場
  合これを試してみるのも良いでしょう。具体的には、sis ファイ
  ルをデスクトップに解凍後、psitoolsを使わずに sisファイルを
  EPOCデバイスに転送し、その後に EPOCデバイスの上でインストー
  ルを行います。EPOCデバイスでのインストールについては、
  補遺1.2. を御参照下さい。

補遺3. コンポーネントのバージョン

  XJMail起動後、"About" ダイアログ (Shift+Ctrl+A)で、XJMail
  の各コンポーネントのバージョンを知る事が出来ます。
  XJMail 1.31 だけをインストールした状態では、以下のコンポー
  ネントがインストールされています。

  XJMail version 1.31.0 (20021226)
  xjmview.opo 1.2+rey20020818
  xjm_SMTP.opo 1.31.0 (20021228)
  xjm_POP.opo 1.30.0 (20021201)
  xjm_sock.opo 1.11
  xjm_fdlg.opo 0.9 (20011026, FileFolder OPX version)

  "About"ダイアログが表示された直後に Ctrl+Cを押す事で、ダイ
  アログの内容をコピーする事が出来ます。この情報は XJMailの
  不具合報告等の場合に役に立ちます。
