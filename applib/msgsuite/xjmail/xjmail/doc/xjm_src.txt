1: 利用法
1-1: 配布条件

  XJMailソースパッケージ(ファイル名 "xjm???s.zip"、???の部分
  はバージョン名を表す2桁もしくは3桁の数字) が提供するソース
  コードの配布条件等は、  本パッケージ内に添付されております
  著作権に関するドキュメント

  XJM_COPY.TXT

  に従います。 XJM_COPY.TXTの内容に抵触しない限り、 どの様に
  利用なさっても構いません。

1-2: ビルド

  XJMail配布パッケージをビルドするには、EPOC Release5 C++ SDK
  が必要です。同SDKは、Psion Teklogix社 の Partner Program
  (無料) に登録する事で、同社のwebページからダウンロード出来
  ます。
  <http://www.psionteklogix.com>

  ビルドには、本パッケージに含まれるものとは別に以下のものが
  必要です。
  Symbianが配布しているもの:
     systinfo opx
     buffer opx
     <http://www.symbian.com/developer/downloads/projectopx_rel.html>
  Keith Walkerが配布しているもの:
     CDescriptor opx
     CSocket opx
     <http://www.starship.freeserve.co.uk/>
  ktkawabeが配布しているもの(ソースもインストールする事):
     JPPrint opx
     FileFolder opx
     <http://www.hi-ho.ne.jp/~ktkawabe/densha.html>

  上記 OPXの WINS版をエミュレータ上にインストールすると共に、
  Systinfo/buffer/CDescriptor/CSocket
  の 4つについては、SDKがインストールされたドライブの下に
  \opx_marm
  というフォルダを作成し、そこにMARM向けSISをコピーしておい
  て下さい。

  また、各 OPX に対応する OXH ファイルをエミュレータの
  C:\System\OPL
  にインストールする事をお忘れなく。

  以下に配布パッケージのリビルドを行う方法を記します。
  注) あなたの目的が あるコンポーネントに変更を施す事だけな
      のであれば、配布パッケージのリビルドは必要ありません。
      そのコンポーネントだけをリビルドし、実機にコピーするだ
      けで事足りると思われます。

1-2-1: パッケージを解凍する
  本パッケージをエミュレータがインストールされたドライブの
  ルートにディレクトリ構造を保存したまま解凍します。
  \xjmail\xjmail
  \xjmail\xjmail\doc
  \xjmail\xjmail\OPL
  というフォルダが作成されます。

1-2-2: mailhelper OPXのリビルド
  パッケージ解凍後、\xjmail\xjmail に mailhelper OPX のソー
  スコード
  mailhelper_s.zip
  が出来ています。これをエミュレータがインストールされている
  ドライブのルート以下に展開します。この操作により、
  \xjmail\opx
  というフォルダが作成されます。

  \xjmail\opx に移動した上で、MARM 向けには
      makmake -makework mailhelper marm
      makmake mailhelper marm
      nmake -f mailhelper.marm
  で MARMバイナリをビルドする事が出来るでしょう。
  WINS向けには
      makmake -makework mailhelper vc5
      makmake mailhelper vc5
  とした上で VC++ の IDE から WINS 向けバイナリのビルドを行
  うか、
      makmake -makework mailhelper wins
      makmake mailhelper wins
      nmake -f mailhelper.wins
  とします。

1-2-3: OPLソースのトランスレート
  \xjmail\xjmail\OPLには、 以下のOPLソースが含まれます:
     XJMail    (本体)
     xjmview   (ビューアモジュール)
     xjm_sock  (ソケットモジュール)
     xjm_SMTP  (SMTPモジュール)
     xjm_SMTPA (SMTP認証モジュール)
     xjm_POP   (POPモジュール)
     xjm_fdlg  (デフォールトのフォルダセレクタ)

  また、以下のデータが含まれます:
     appicons.mbm
               (aif用のアイコンデータ)
     xjmbmps.mbm
               (その他のアイコンデータ)

  \xjmail\xjmail\docフォルダには、以下のファイルが含まれます:
     xjm_hlp.txt
               (helpファイル)

  \xjmail\xjmailには、以下の追加 OPLパッケージが含まれます:
     fdlg_ff.zip
               (デフォールトのフォルダセレクタパッケージ)
     fdlg_std.zip
               (EPOC標準フォルダセレクタパッケージ)
     fdlg_ndirnav.zip
               (NDirNav版フォルダセレクタパッケージ)
     xjm_AUTH.zip
               (APOPと SMTP AUTH用のモジュールパッケージ)

  OPL ソースを全て、appicons.mbmとともにエミュレータの適当な
  フォルダに移動した上で、手でトランスレートします。
  必要なら追加パッケージの中身も手でトランスレートします。
  (OPL ソースを 一括してトランスレートする様な スクリプトは
  用意されておりません。個別にトランスレートして下さい。)

  xjmview.opo
  xjm_sock.opo
  xjm_SMTP.opo
  xjm_POP.opo
  xjm_fdlg.opo
  が生成されますので、xjmbmps.mbmおよび xjm_hlp.txt と一緒に
  全てエミュレータの
  C:\System\Apps\XJMail
  フォルダに移動して下さい。

1-2-4: 配布パッケージの作成
  MAKEFILEというファイルが添付されていますが、このファイルは
  OPL ソースが全てトランスレートされた状態から XJMail 配布パッ
  ケージを作成するためのものです。
  中身のフォルダ定義を適当に書き換えて下さい。
  nmake latest_s.zip
  nmake latest_b.zip
  nmake latest_w.zip
  でそれぞれソースパッケージ、バイナリパッケージ、WINSバイナ
  リパッケージを作成します。
  nmake all
  で上記 3つを全て作成します。
  Windows 2000 Professional 英語版の Command Promptから、
  Visual C++ 6.0付属の nmake で(だけ)動作確認しております。

2: より自分好みな、もしくは有用なXJMailを使用したい場合には

  XJM_COPY.TXT の内容に従う限り、あなたがXJMailをもとにして
  お書きになったものを、 ktkawabeの配布パッケージとは別にご
  自分で配布なさる事には、何の問題もありません。

2-1: ソースコードの寄稿

  XJMail そのものに対して有用な機能付加や改変をなさった場合、
  以下の点A)およびB)について あらかじめ御了承いただける場合
  には、 是非 ktkawabe の配布パッケージに含めて配布する事を
  御検討いただければ嬉しいです。

  A) あなたがお書きになったものは、XJMail の ktkawabeによる
     配布パッケージの一部としてXJM_COPY.TXTに従って配布され
     る可能性があります。

  B) あなたがお書きになったものが取り入れられた XJMail が
     ktkawabe からリリースされた場合には、 以下の事を御了承
     いただく事になります。

     B-1) あなたが書いた部分については、 短期的には (少なく
          ともリリース後一月程度は)バグ報告への対応を含め、
          あなたが御自分で責任を持ってメンテナンスを行って
          いただく。
     B-2) あなたが書いた部分について、 あなた御自身にドキュ
          メントの原案を書いていただく。
     B-3) ソースコードを寄稿した人として、あなたの御名前
          ( もしくは別名、 渾名、 ハンドル等)が、更に御了承
          いただければemailアドレスが、XJMailのドキュメント
          に記載される。
     B-4) あなたの書いたものが含まれるバージョンの XJMailに
          ついて問題(XJM_COPY.TXTの内容を無視した著作権侵害
          等)が生じた場合について、 あらかじめ 2-3:の条項に
          同意する。

  以上の条項に同意する事が出来て、 なおかつ ktkawabe の配布
  パッケージの充実に貢献してやっても良いという奇特な方は、
  ktkawabe もしくは 3: に示すメイリングリストにその旨を表明
  して下さい。

  御寄せいただいたものを配布パッケージに入れるかどうかは、
  開発者間で協議の上、最終的に ktkawabeが判断させていただき
  ます。
  御寄せいただいたものと同様の機能が ほとんど実装済みである
  という場合がある事も予想されますし、 上記の条件が満たされ
  ていても 全ての contribution を取り入れる事は御約束出来ま
  せんが、 有用なものは基本的に取り入れさせていただきたいと
  思います。

2-2: ドキュメントの寄稿

  ソースコードと同様の重要性を持つのが、ユーザーマニュアル
  やインストール法などのドキュメントです。
  ドキュメントの不備を見つけたとか、より適切な記述法のアイ
  デアを御持ちである、などという場合には、是非教えてくださ
  い。
  また、ドキュメント書きに一肌脱いでやろう、という奇特な方
  は、2-1:に示しましたA)B)の条件を満たす場合には御連絡下さ
  い。
  (B各項内の「ソースコードを寄稿」は、「ドキュメントを寄稿」
  と読み替えてください。)

2-3: 問題が生じたら

  楽しい話ではありませんが、一応注意しておかねばなりません。
  あなたがソースコードやドキュメントを寄稿したバージョンの
  XJMailについて、問題 (XJM_COPY.TXTの内容を無視した著作権
  侵害等)が絶対に起きないとは言えません。

  そのような場合、あなたが寄稿した時期がいつだったかに関わ
  らず、 対応に関する議論に あなた自身が主体的に加わるか、
  もしくは 特定の誰かに対応を一任するかを 速やかに表明して
  下さるように御願いします。 表明しない場合には ktkawabeに
  一任するとみなされます。

3: 情報交換のためのメイリングリスト

  XJMailに関する情報交換のためのメイリングリストを用意いた
  しました。
  このメイリングリストには、原則としてどなたでも参加する事
  が出来ます(所謂オープンソースや所謂「フリーソフトウェア」
  に限らず、「ソースの公開されたソフトウェア」に関する作者
  の広い意味での権利を尊重しない考えの方に対しては、参加を
  御断りする場合もあります)。

  XJMailの開発、ソースやドキュメントの加筆修正などに関する
  議論、ベータ版のテスト等の議論はここで行いますが、開発に
  関する話だけではなく、XJMail のバグの話や 質問等も、
  ユーザー間の情報交換の範囲内で行って下さって構いません。

  このメイリングリストは、XJMailの「苦情処理」「ユーザーの
  問題の、 開発者による解決」 という意味でのサポートを意図
  したものでは無い事を御理解下さい。

  詳細につきましては、
  <http://www.hi-ho.ne.jp/ktkawabe/XJMail/ML.html>
  を御覧下さい。
