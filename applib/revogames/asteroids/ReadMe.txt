Installation Instructions

NB: Please fully uninstall any beta versions of Asteroids
you may have on your machine before installing this release version.

1. Unpack the Zip file to your PC or your Psion.

2. On the PC:
   Double click on the file Asteroids.SIS. This will start the PC
   automatic installation of Asteroids.
   On the Psion:
   Double tap on the file Asteroids.SIS. This will start the Psion
   automatic installation of Asteroids.

Asteroids should now be accessible to you from the Extras icon.
