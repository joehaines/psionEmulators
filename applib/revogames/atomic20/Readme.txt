Atomic 2.0: Tetris clone (arcade game) for Psion Revo
-----------------------------------------------------
Oct 29 1999

Freeware by Steve Litchfield

(Also runs on Series 5mx, although in a 480x160 pixel window. Separate version [1.4] available for Series 5 'classic'.)

Installation
------------
If you unzipped Atomic OK, you should have ended up with
3 separate files. One will be this text file 8-)

The other two are SIS files.

If you *don't* know what a .SIS file is, this must be one of the very first
third party applications you've ever installed. Don't worry, it's all quite 
painless. Just double-click on the "atomic.sis" file to launch
EPOC Install on the PC itself and to complete the installation. If you
haven't yet upgraded your Revo with the special "sysram1" OPX, you'll need to 
double-click on "sysram1.sis" as well.

If all went well, you should now have a new "Atomic" icon on your
Extras bar.


Expert troubleshooting
----------------------
[For the technically minded, after installation all Atomic program files should exist
in \system\apps\atomic, apart from the sysram1.opx OPL/32 extension, which is needed
to play digital sound files and should live in \system\opx ]
