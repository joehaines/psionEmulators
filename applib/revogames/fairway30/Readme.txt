Fairway 3.0: Golf game/simulation for Psion Revo
------------------------------------------------
Oct 28 1999

Shareware by Steve Litchfield


What's new for 3.0 since v2.4?
------------------------------
Most obviously, this runs on the new Psion Revo instead of the
older Psion Series 3a/3c models. Also added water features and
mulligan option, plus improved graphics throughout.


Installation
------------
If you unzipped Fairway OK, you should have ended up with
3 separate files. One will be this text file 8-)

The other two are SIS files.

If you *don't* know what a .SIS file is, this must be one of the very first
third party applications you've ever installed. Don't worry, it's all quite 
painless. Just double-click on the "fairway.sis" file to launch
EPOC Install on the PC itself and to complete the installation. If you
haven't yet upgraded your Revo with the special "sysram1" OPX, you'll need to 
double-click on "sysram1.sis" as well.

If all went well, you should now have a new "Fairway" icon on your
Extras bar.


Expert troubleshooting
----------------------
[For the technically minded, after installation all Fairway program files should exist
in \system\apps\fairway, apart from the sysram1.opx OPL/32 extension, which is needed
to play digital sound files and should live in \system\opx ]
