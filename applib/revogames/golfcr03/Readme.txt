GolfCard & Analyst
==================
This is version 1.03 of GolfCard for the Psion Revo released 14 December
1999.

With GolfCard you can:

1) Build your personal lifetime golf database.
2) Save the scorecards for 1000s of matches, and the course details for as
   many courses as you play.
3) Score a match with up to 4 players in any of the standard formats,
   Stableford, Stroke Play, Match Play, Bogey/Par, Foursomes,
   4 Ball Better Ball etc, with proper allowance for handicaps.
4) Score a match as you play, or alternatively enter the scorecard
   when you get home.
5) Review any previously saved match and analyse each player's performance.
6) Print a scorecard at any time.
7) Record performance information about each hole played: The number of
   putts, whether or not the tee shot hit the fairway, and whether or
   not you reached the green in regulation.

With Golfcard Analyst you can:

1) View all of a player's scores on one course together.
2) Work out averages, eclectic scores, personal stroke index etc.
3) Compare performance from one period to the next using the
   GolfCard Performance Index.
4) Track Gents (CONGU) and Ladies (LGU) exact handicaps, using the
   methods in operation in UK. Handicap adjustments by the committee, 
   and Stableford Adjustments to medal scores all included.
5) Print a handicap record sheet.
6) Calculate statistics for any player in any of the recorded matches.

For more information see our web page:
   
   www.cix.co.uk/~mpsystems/golfcard/

Installation Instructions
-------------------------
1) Install the GolfCR03.sis file.
2) Run GolfCard from the Extras bar and enter your User Name as one
   Christian Name followed by your surname. (eg John Smith) Don't attempt
   to run Analyst until you have completed this step.
3) Prior to registration you can score, save and analyse up to 2 matches.

Registration Procedure
----------------------

can start to build your lifetime golfing database. This is done by
entering your unique number at the Main Menu item -- 'Register'.
The cost to register is 39.95 GB Pounds, or 34.00 GB Pounds if you live
outside the EC.
