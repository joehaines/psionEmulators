===============
1) INSTALLATION
===============

Turn on your Revo, press the System icon (bottom left of the
screen), press the Menu key, under 'Tools' select 'Preferences',
make sure that there is a tick next to 'show system folder' and click
on 'OK'.

Go into C:\System\Apps\

From the menu, under 'File' select 'Make new folder' name it Psi-Jong.

For a full installation...

Copy all the files except README.TXT into this directory, which will be...

C:\System\Apps\Psi-Jong\

-----------------
I strongly recomend that you do a full install, but, if you wish to
save space, the only files you need to copy are as follows...

PSI-JONG.APP
PSI-JONG.AIF
SH-PREFS
SH-DONE1
SH-DONE2
SH-DONE3
SH-DONE4
SH-DONE5
SH-DONE6
SH-DONE7
SH-DONE8
MAHJONGG.TLS
SHADOW.GFX
BAKBAR.GFX
BAR.GFX

If you wish to add extra tilesets, copy some or all of the other files ending
with .TLS.

If you wish to include sounds, copy some or all of the the files that are named
with just 2 characters.

If you wish to include background pictures, copy copy some or all of the files
ending with .BGP


-----------------


Pressing the 'Extras' button (bottom right of screen) will now reveal
this programs icon, select it to begin.

If the program does not run, rename its folder to a different name, wait
a few seconds, then rename it back to its correct name and try again.

If you have difficulty with installation, re-read and follow carefully
the above instructions, you have probably put the files in the wrong place,
or named the folder incorectly. See the troubleshooting section below.

If you have named the folder correctly, but the Psi-Jong icon does not appear
on the Extra's Bar, rename the Psi-Jong folder to a different name, wait a
few seconds, then rename it to Psi-Jong again. The icon should now appear.

3) TROUBESHOOTING
=================

If you have a problem, check that your batteries are not low, and that there is
plenty of memory available to the program. Sometimes the Revo fails to play
sounds when batteries are becoming low, but are not quite low enough for the
Revo to report them as low. If in doubt, charge the batteries.

Check that you have followed the installation instructions correctly.

Check my web site to see if you are using the latest version of this program.

HTTP://WWW.BJV.BTINTERNET.CO.UK/

If you still have a problem after checking the above, send me an email, explaining
the problem in as much detail as possible, stateing what machine you are running
the program on, what version you are running, what files have been put where, at
what point in the programs execution the error happened, and what error messages
were given.
