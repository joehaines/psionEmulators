Welcome to the PsiMail Internet Web browser

The Internet In Your Pocket
This startup page includes links to interesting pages on the Internet, and a brief explanation of how to navigate to other pages.

To use the browser:

  1. Use the arrow keys to move up and down a page.
  2. Press Tab to highlight a link (they're underlined).
  3. Press Tab again to move to the next link. Shift-Tab moves in the reverse direction.
  4. To 'follow' a highlighted link, and go to another page, press Enter.
  5. If you want to go directly to a particular page select 'Get page' on the 'Browser' menu, type the Web page address on the 'Address' line and press Enter.
For more information press the Help button on the Psion's keyboard.

Connecting

Before you select a link make sure you are ready to dial up the Internet:
  • Your modem should be switched on, and connected to both the Psion and a telephone socket.
  • Your Internet account settings must be ready for use - if not please use the Wizard in the Setup application.
