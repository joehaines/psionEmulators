Notes for Upgraders
-------------------

The only files that have changed for this from version 1.47 are 
BACKGAMM.OPA and ADAM.PLR.  Files BOB.PLR and CHRIS.PLR have been
been added, but are optional.

*******IMPORTANT********

ADAM.PLR,BOB.PLR,CHRIS.PLR  have changed and old versions are
INCOMPATIBLE with the new program, you MUST update ADAM.PLR to use the
new BACKGAMM.OPA, any old versions may cause the program to crash (with
an error like: "DADAM: procedure not found")


Installation
------------

BGINST.BAT is an RCOM batch script to install all backgammon files on 
your series 3a

usage:

BGINST drive:

Where drive: is a S3a drive, for example BGINST I:

Then use Psion+I on the system screen to install the application.

PsiWin users
------------

RCOM is included on the first disk of your PsiWin disks.
Alternatively you may install the files manually, the following are 
needed:

\APP\BACKGAMM.OPA
\APP\BACKGAMM\1.PIC
\APP\BACKGAMM\2.PIC
\APP\BACKGAMM\3.PIC
\APP\BACKGAMM\4.PIC
\APP\BACKGAMM\5.PIC
\APP\BACKGAMM\6.PIC
\APP\BACKGAMM\BOARD.PIC
\APP\BACKGAMM\BLACK.PIC
\APP\BACKGAMM\WHITE.PIC
\APP\BACKGAMM\POINT.PIC
\APP\BACKGAMM\BACKGAMM.RSC
\APP\BACKGAMM\ADAM.PLR
\APP\BACKGAMM\BOB.PLR
\APP\BACKGAMM\CHRIS.PLR
\APP\BACKGAMM\DIANA.PLR

Optional
\WVE\PIECE2.WVE
\WVE\DICE2.WVE
