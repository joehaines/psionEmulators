Description:-

An absorbing way to while away those spare minutes (days?) ...

Installation:-

1) Copy the files "Block.pic" and "Cursor.pic" into the \OPD directory.
2) Copy the file "Blox.opa" into the \APP directory on the same disk.
3) Select the APPS (Install) menu option to install the "Blox" game.

How to play:-

Blox is a cross between a sliding block puzzle and Rubik's cube.

The aim of the game is to re-arrange the grid into numerical order after it has been shuffled by the computer. Sounds easy, huh?

The game has two modes - MOVE and SLIDE.

1) MOVE the cursor (circled tile) using the cursor keys.
2) SLIDE the current cursor row or column using SHIFT + the cursor keys.

If you find this all too easy (!), use the "Settings" menu to increase the difficulty and grid sizes.

"QuickShuffle ON" speeds up the initialization phase by hiding the grid as it rearranges the tiles.

Use "Clear records" to reset the highscores (held in the "Blxscore" files in the \OPD directory).
