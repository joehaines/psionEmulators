            Diamonds v1.2

               Outline

Diamonds is a scrolling platform game for the
Psion Series 3a/c machines. The player has to
jump around each level collecting diamonds
and avoiding spikes and blades. There is also
a strategy element to the game. At the start
of each level you get some extra blocks and
and remove blocks. These are used to reach
inaccessible areas of the playfield. Use them
in the wrong places and you could run out
making the level impossible to complete!
The game requires around 100k free RAM 
to run.


               Installing

In the App directory on any drive, make a
sub-directory called diamonds. Copy the
following files into it..

Dead.wve
Pop.wve
Quake.wve
Yeah.wve
Diamond.pic

Copy the file Diamonds.opa directly into the
App directory. Then install the game from the
main menu using Apps/Install.

The files ending in .wve are optional and can
be left out if sounds are not wanted.


                 Playing.

Run the game and the intro screen will appear.
Most of the choices are obvious. Continue game
carries on from the last level played. Select level
lets you play any level already completed.

Press the help key for quick instructions or 
read on!

Select New Game and the game starts!
There are three modes to the gameplay selected
as follows..

Play Mode (default mode)

 Use the cursor left and right keys to move left and right
 Use the cursor up key to jump
 The TAB key displays or removes the info window
 The q key selects a quit/restart/exit dialog
 Esc quits the above dialog.
    
Edit Mode

Pressing the Psion key enters this mode. 
Use cursor keys to select a block to alter. Then 
enter to make the change or esc to return to
play mode. You can edit any block except the
borders or one containing a diamond.

View mode

Press and hold the diamond key to enter this
mode. Then use the cursor keys to scroll around
the playfield. This mode is used for planning
how you can solve each level! Simply release
the diamond key to return to play mode.

Notes..

 The menu key is'nt used in the game proper
as the game uses the Psion key for edit mode.
For maximum game speed, close all other apps
while running diamonds. You don't have to do
this but it can make a slight difference. A small
file is also created in the OPD directory when the
game is first run.
