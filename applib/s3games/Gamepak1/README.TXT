INSTALLATION
============

Installation is very simple, first you will need an APP directory and a PSITECHA
directory.

Here is how to create them...

-----

Press the SYSTEM button

Press the MENU key

Under 'Disk', select 'make directory' and press ENTER

Next to 'Name' type APP

Select the disk you wish to use, 'Internal, A or B' and press ENTER

Now use the same method to create a directory called PSITECHA, this time typing
PSITECHA next to 'Name' instead of APP.

-----

The PSITECHA directory does not need to be on the same disk as the APP directory

You may only have 1 PSITECHA directory, either in the Internal memory (M) or (A)
or (B).

Now you need to copy over the files, if you don't know how to do this, look in
your users manual.

Copy all the files ending with .OPA to the APP directory.

For a FULL INSTALLATION (403k), copy all the remaining files except this one
into the Psitecha directory.

For a MEDIUM INSTALLATION (320k), as above, but do not copy LV.SDN and the
number files 01.SDN to 50.SDN.

For a SMALL INSTALLATION (157k), as above, but the only files ending with .SDN
that should be copied are Z1.SDN, Z2.SDN, Z3.SDN.

For a MINIMUM INSTALLATION (146k), as above, but do not copy any files ending
with .SDN.
