About HUNGRY
------------

HUNGRY is an eating dor snake game, where the Psion can
simulate up to two snakes.
On line Help gives more information about how to play.

Installation
------------

- Copy the file Hungry.app to your \APP\ directory
- Copy the file Hungry.pic to your \OPD\ directory
- If you want to use the sound option,
  copy the wve files form the WVE directory of the distibution
  package to any \WVE\ directory on your Psion.

Use psion-I to install HUNGRY as usual.

HUNGRY will also create several files in the \OPD\ directory of the
internal disk.
