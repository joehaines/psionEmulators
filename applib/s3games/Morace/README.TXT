How to install Morace on an S3a
-------------------------------

To install Morace copy MORACE.OPA to the \APP directory on any drive. On the
Same drive make a directory \APP\MORACE and copy the following files into that
directory:
MORACE.PIC, GREY.PIC, BLACK.PIC, HMLEVELS.LEV
Finally install the Morace icon to the system screen using Install
app (PSION-I)

A batch file which runs under RCOM is included which will copy all files
for you. Type HMRCOM for more help.

Morace
------

Morace is a cross between Hungry Horace and Pac-Man. Guide Morace around the
maze eating all of the food and avoiding the ghosts. Look out for bonus food
and extra lives. There are 30+ levels. Keys are initially the cursor keys
but the game is more playable if you redefine these to Q,A,O,P.
Please feel free to share Morace among your friends. I hope that you enjoy
playing Morace as much as I have enjoyed writing it. Morace is free
but if you do find Morace enjoyable any money like contributions
would be greatly appreciated and may persuade me to write a few more
games. All comments both good and bad are more than welcome.
Look out for another game I have written called Blitz and my forthcoming
release called Bunnies. For anyone interested in puzzle type games
Sokoban written by Gareth is very good.
