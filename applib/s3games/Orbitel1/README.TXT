How to install Orbitel on S3a
=============================

To install, copy ORBITEL.OPA to the \APP directory on any drive. On the
same drive make a directory \APP\ORBITEL and copy the following files into
it:
                  ORBITEL.DBF    (Levels file)
                  ICON.PIC       (S3a Icon)
                  ORBITEL.PIC    (Orbitel Sprites)
                  TPAGE.PIC      (Title Page)

To add an icon to the system screen, press PSION-I on the system screen
and select ORBITEL using the cursor keys and ENTER.


Playing Orbitel
===============

Orbitel is a 3D isometric game based around a 3D 8x8 grid. The aim of the
game is to move around, using teleports and destinators, collecting the
gems for no real reson whatsoever. Barring your way are monsters and
pitfalls.

Orbitel is a weak and deliate being and can only fall down one level and
cannot climb at all. The monsters, being of stromger stuff, can not only
fall by a single level but also climb by one!

To move around, use the A, Z, K and M keys. These may seem strange but
will make sense when you see the screen.

Once a new level is reached a password is given which can be used to re-
start at that point in subsequent games.

There is a time limit of 150 seconds for each level and three lives are
given to complete each level.


History
=======

Orbitel has a very long history, it begins in 1989 when Impact Software
released OrbitAl for the Acorn Electron. At this time I worte a clone
in BBC BASIC / Assembler which was published in the November 1989
edition of Electron User. This Psion version is a complete re-write
but preserves the spirit of the other versions!


Levels
======

The file ORBITAL.DBF is a standard Psion database which you may wish to
look at / edit to create your own levels.
