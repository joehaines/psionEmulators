SUPERSLOTS... by Michael Waite - 74647,2510


This is my first attempt at programming with the PSION 3A.  Originally, 
I wrote this program solely for my entertainment.  After discovering the 
PSION conference on Compuserve, I decided to make a few changes that would
allow others to use it.  This program was written entirely on the 3A, a lot
of work I don't care to repeat... time for a compiler!


**********
Since I am more than interested on feedback about this program, I am 
offering it as is, without any shareware nags.  So please, send me some E-Mail
if you like it with your comments/suggestions!  This will help me decide
if I should continue my programming efforts with the 3A (I love this machine),
and also tell me how many people are enjoying it.
**********


NOTE : The wve files are fairly large, as this was my personal preference
before offering this program to the public.  My plan was to offer two sets of
wve files, original and short versions. However, in converting the files in and
out of wav format (my only method available to reduce wve files at this time), 
the sound quality dropped below acceptable levels.  If memory is an issue with
many people, I will continue to address this. Optionally, the wve files could 
be substituted for other, shorter files, but then this would change the feel of 
the game, so I hope that doesn't happen.



Installation of SUPERSLOTS :

   1. Copy ALL files to any '\app\slots' directory.

   2. Optionally, install Slots.opa in any '\app' directory.

   3. Install Application the usual way.



Instructions for playing SUPERSLOTS :

   One to four can play, including the computer. The help file in the program 
should offer enough clues as to how to play. It is intuitive, once you figure
out what you are looking at, you will find it easy and FUN to play!  (Be sure
to check out all options in the menu before you play, so you will know what 
your reels are worth). Program requires about 55K during play.
