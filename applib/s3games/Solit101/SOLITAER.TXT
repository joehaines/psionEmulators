Solitaer 1.01 (Freeware)

The classic game Solitair for the 3a or 3c.

Installation
------------

Copy SOLITAER.OPA to \APP on any drive.
Create a directory \APP\SOLITAER on the same drive.
Copy SOLITAER.ODB and SOLITAER.RES to \APP\SOLITAER.
This files can also reside on a SSD.

If version 1.00 was installed on your Psion, you have to delete the files
\OPD\SOLITAER.ODB and \OPD\SOLITAER.RES on the internal disk. 

A file named \OPD\SOLITAER.STA will be created on the internal disk
when you run the program the first time. It contains statistical
information.

Playing
-------

Remove all balls but one from the board by jumping over it with
another ball.

Move the arrow to the ball you want to move with the cursor keys.
Move the ball by pressing Psion and a cursor key (Home, End, PgUp, PgDn).
You can also press Shift and a cursor key to move the ball.

Select one of 20 different arrangements. Each of them is solvable. 
If you know other ones, please send me a sketch via email.

You can take back up to twenty moves.

The best five results are stored for each arrangement. If yours is
better than a stored one, you are prompted to enter your name and
the current result is added to this "hall of fame" ;-)
