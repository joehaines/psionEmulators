Tetrums revision 2.02

The original Psion 3a Tetris combined with Columns to form one
application. You can switch from one to the other with the press
of a key. Separate high scores kept for each game.

CONDITIONS OF USE:

This version is hereby released to the public domain without any
need to register.  Donations are gratefully received however and
will do no harm to my eagerness to make more public domain software.

INSTALLATION:

Copy the Tetrums.app file into any \APP directory and install in
the normal way.

Run the game and press Help for further information.
