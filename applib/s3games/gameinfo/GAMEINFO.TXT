                                   GameInfo  (Version 1.0)
                        -The codes and cheats database-

Welcome to GameInfo, a database of cheats and level codes for Psion games.
At the moment, the database is small, but with your help it can grow bigger.
The database covers cheats for games (such as health or level skips) and
codes for games that need codes (Jumpy!, Dungeons etc.)

Installation:
Place the GameInfo.DBF file in a \DAT\ directory on any drive. Then go to
the System screen, update lists if necessary by pressing the System button,
and select the GameInfo entry under the DATA icon.

Using the database:
On a 3c, it is easiest to use the List view to select the record you need,
whilst 3a/Siena users should use the Find function.
Each record has the name of the game, with the name of the author in
brackets. Underneath this, there is a list of the platforms that the cheats
work for. These include 3 (Series 3/3s), 3a/c (Series 3a/3c), Siena (Siena)
and 5 (Series 5).
The database is only for the Series 3a/c/Siena.

Adding to the database:
If you are a software author, or have discovered codes/cheats in programs
not listed so far, please send any codes/cheats to me for inclusion in future
updates of GameInfo. You will get your name in the "contributers" section,
plus your info could help many Psion gamers!
