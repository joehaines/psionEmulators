Hang2 v2.0
a Hangman game for 1 or 2 Psion computers

Overview
This is a version of the classic word game Hangman. It runs equally on the Series 5 and Series 3a. It can even be run on two computers simultaneously, linked by a serial cable, with one player setting the word for the other to crack on the other computer.
Note that the game can be played by two users, one on a 5 and the other on a 3.

Installation
Apart from the ReadMe files, you should find the following files in the zip package:
hang2.opa	 program for Series 3a machineshead.picdead.pic		graphics files for  3a version
hang2.apphang2.aif		program files for Series 5 machineshead.mbmdead.mbm	graphics files for Series 5 version
For Series 3a machines, copy hang2.opa to the \app\ directory, and the two graphics files to \app\hang2\. Install the program on the system screen with Psion-I.
For Series 5 machines, copy all the files to \system\apps\hang2\. The icon will appear on the extras bar.
If you are intending on playing the two computer version, you should connect the two with the normal serial leads, connected to each other via a null modem cable. The remote link on both machines should be set to off.

Playing
On starting the game, you will be asked whether you are using one or two computers. If you are only using one, it is straightforward. If you are using two, you must select "2" on each machine. If the two users disagree, the machine expecting to play the 2 player game will get stuck, and will have to be released by using the standard escape sequence.
If both players choose the 2 player option, each is asked which user will set the word for the other to guess. If the two users disagree, the one who answers second will tend to override the first. The appropriate user will be prompted to set the word, and which is then sent to the other computer for the other user to guess. The whole game is shown on both machines, so both players know how the game is progressing.

At the conclusion of the game, both players have to acknowledge the dialog boxes to restart the game or quit as appropriate.
