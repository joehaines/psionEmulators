The Game
--------

The idea of the game is to buy and sell things to make lots of money!.
If you do well at this game perhaps you should think about setting up
a shop in real life.

Installation
------------

Firstly unzip the LetsS10.zip file (You should have done this by now).
The zip file should contain this readme file and a directory called
app. All you have to do is copy this app directory into the root
directory of your Psion

Alternatively you could copy the Letsshop.opa file into the app 
directory on your Psion.

Next you should go to your Psion's system screen and press Psion-i 
(Install). Then in the "File: Name" Box choose "Letsshop.opa" and
then press Enter. Now all you have to do is go to the Letsshop icon
and press Enter.

When first run the program will take a long time initialising. This is
because the program creates some pic files. These extra files are saved
in an "APP/Letsshop" directory that the program creates. Other files
are also created and put here later on in the game. In total the
program creates 1.7ks worth of extra files. (As long as you have enough
space on your internal drive you have no need to worry about this)
