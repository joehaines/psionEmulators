Minimum Requirements
=====================

Pacman requires:

        - A Psion 3mx (also runs on Psion 3a/3c, but quite slow)
        - Minimal installation (without sound): 
	    -  63KB of free disk space
	    -  75KB of free system memory while running
	  Normal  installation (with sound):
	    - 212KB of free disk space
	    - 101KB of free system memory while running


Installation
=============

Extract the files from the archive PACMAN.ZIP.
Copy the files onto your Psion to the destination given below.

Destination			Files
-----------			------
                 
\APP\				Pacman.opa

\APP\PACMAN\			Pacman.rsc

\APP\PACMAN\LEVEL\		Lev1.odb, Lev2.odb, Lev3.odb

\APP\PACMAN\PIC\		Lev1.pic, Lev2.pic, Lev3.pic
				Pacman.pic
				Title.pic

\APP\PACMAN\WVE\		Pdie.wve, Peat3.wve, Peat4.wve		*
				Peatm.wve, Pextral.wve, Pfruit.wve	*
				Pintro.wve, Pintro2.wve, Pmdie.wve	*
				Ptitle.wve				*

*  These files are optional sound effects and can be removed to save disk space.

Now, go to the system screen, move the cursor to where you want the Pacman
icon to appear and press PSION+I. In the Dialog box that appears make sure
that the file-name is PACMAN.OPA and then press ENTER.

Pacman can be installed on any disk (intern, A or B). However, during runtime the
following directory and files are created if not extant:

LOC::M:\APP\PACMAN\		Hscore.odb
				Options.odb

For further instructions, look through the online help during the game.

Enjoy playing Pacman.
