INTRODUCTION
------------

An updated version of the classic snake game - eat the bugs, but avoid the
deadly poisonous mushrooms! Features include three difficulty settings
(each with its own high score table), numerous bonus objects, and a secret
sillyness mode!

You are a snake in an enclosed garden containing lots of tasty beetles.
There are also lots of mushrooms growing in the garden, which are deadly
poisonous to the snake.

You must eat the beetles and avoid the deadly mushrooms. Every time you eat
a beetle the snake grows slightly longer, making it more and more difficult
to avoid eating your own tail.

Various bonus objects will appear from time to time, which have various
useful (or not so useful!) effects on the snake and mushrooms.


CONTROLS
--------

Use the cursor keys to control the snake, or define your own keys using
Psion-K. Press return to pause the game.

Once you've started moving, the snake continues moving in that direction
until you either pause the game or change direction.

Full help support is available by pressing the Help key.

There is a cheat mode, but I will leave it to you to work out how to use
it!


BONUS OBJECTS
-------------

Bonus objects will appear on the screen from time-to-time, which do various
useful (or not so useful!) things when you eat them:

    DIET PILL - Shorten the snake.

    SKULL & CROSSBONES - Instant death, avoid.

    SHOVEL - Kill some of the mushrooms.

    SNAIL - Slow down the snake.

    RUNNING MAN - Speed up the snake.

    SMILEY FACE - Eat it and see what happens... :-)

    ARROWS - Reverse the control keys, nasty.

    LONG SNAKE - Snake grows even faster.


GAME OPTIONS
------------

Pressing Psion-O will display the game options window. Here, you can select
the following options:

  Sound       ->  On/Off

  Difficulty  ->  Easy/Normal/Hard

If you change the difficulty in the middle of a game, then a new game will
be automatically started for you.

Each difficulty setting has its own seperate high score table.


INSTALLATION
------------

The game is compatible with the Psion S3a and S3c. I'm afraid that it won't
work on the Siena, sorry.

The game can be installed onto SSD, all you have to do is copy the files
into the following dirs on any drive:

    SNAKE.OPA    ->  \APP\

    ALIEN.WVE    ->  \APP\SNAKE\
    PIP.WVE      ->  \APP\SNAKE\
    SNAKE.FON    ->  \APP\SNAKE\
    TITLE.PIC    ->  \APP\SNAKE\
    VIPVIP.WVE   ->  \APP\SNAKE\

    SNAKE.HLP    ->  \HLP\
    SYS$HELP.OPO ->  \OPO\

Now install it in the normal way by pressing Psion-I on the System screen.
