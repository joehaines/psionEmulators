Introduction
------------

"WordFind" is a word-finding puzzle game for your Psion 3c.  Your task
is to find 17 words hidden in a grid of 40x17 random letters.  The 17
words are randomly generated so that the game never plays the same
twice.  (Note: This also means that using your own custom words is NOT
supported).  The random words can be either phonetically created for
easy play (eg. "bigun") or totally random for hard play (eg. "mrfps").
In addition, each word can be mixed (ie. its letters jumbled up, for
example "bigun" could be hidden in the grid as "inbgu") so that
locating them is even harder!  :)



Installation
------------

(1) Put the "WordFind.opa" file inside the "App" directory of any disk
on your Psion 3c.  The program does not write to this disk when
running, so you can safely install it to a Flash SSD if desired.

(2) Install the program icon by pressing Psion-I at the System Screen.



Using The Program
-----------------

When you first run it, you will see the message "Creating New Game" in
the lower-left corner.  At the right you'll see a growing list of 17
randomly-created words appear, and then the game grid will be drawn.
You are then ready to start playing.

To play, first note that there's a small grey square in the centre of
the grid.  This is the cursor which you move around with the arrow
keys.  If you press Psion with the arrow keys, you'll move the cursor
in steps of 4 letters instead of 1 (for faster movement).  What you
have to do is put the cursor on the FIRST LETTER of a found word, and
then press Enter to signify that you've found the word.  If you did
find a correct word, it becomes grey in both the grid and side list,
otherwise nothing happens.

Continue this process until all 17 words are found.  You can then
start a new game by pressing Psion-N (if desired).  Sounds can be
disabled (and re-enabled) with Psion-S.



Game Variations
---------------

There are 4 different ways (skill levels) to play the game:

Easy Words: The 17 words are created in a phonetic format, meaning
            that they can be spoken aloud easily.  This means finding
            them is fairly easy because they appear English-like.

Easy + Mixed: As above but the letters of each word are also jumbled.
              This means they are not so obvious to find in the grid.

Hard Words: The 17 words are created of totally random letters.  This
            means they are hard to distinguish amongst the grid's own
            random letters.

Hard + Mixed: As above but the letters of each word are also jumbled.
              This means they are even harder to find in the grid.
