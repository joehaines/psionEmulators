The Game
--------

The idea of the game is to guide your worm around the screen safely
without crashing into any other worms. It sounds simple, however it 
is great fun. You can have up to three human players and three
computer players all at once.

Installation
------------

Firstly unzip the Worm.zip file (You should have done this by now).
The zip file should contain this readme file and a directory called
app. All you have to do is copy this app directory into the root
directory of your Psion, or alternatively copy the worm.opa file 
into the app directory on your Psion. Then you should go to your 
Psion's system screen and press Psion-i (Install). Then in the 
"File: Name" Box choose "Worm.opa" and then press Enter. Now all 
you have to do is go to the Worm icon and press Enter.
