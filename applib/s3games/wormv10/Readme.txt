ABOUT WORM
----------

In this game you have to collect all the apples
and apple cores to complete the level. If you
didn't guess, you are the worm. Read the help
(press HELP key) in game for full information.

INSTALLATION
------------

To install this game put the following objects
in the following places:

WORM.opa -------> M:\APP\
WORM\ ----------> M:\APP\

To put it simpler, put the WORM.opa file and
the WORM folder in the APP directory on your
psion.
