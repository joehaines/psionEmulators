To view this file at best (on the Psion), zoom out as far as possible (using
Shift-Psion-Z), turn the status window off (using Control-Menu) and set the
character widths to `Monospaced' (using Psion-Q).

Browse shows all the pictures in a directory as thumbnails (48x48 pixels in
size).  It can also show the pictures full size, even if they are bigger than
the screen and it allows you to copy, move, delete and rename the files.

1. Installation:
================
If you have unzipped the ZIP file with the `recreate directory' option (`-d'
with PKUNZIP) then you can simply copy the files across.  For a partial
installation, or if you cannot `recreate directory', here are the details of
where the files must go.

(a) Copy BROWSE.OPA to the \APP\ directory on your Psion (on any drive).
(b) Make a directory \OPD\ on your Psion (on any drive).
(c) Copy BROWSE.RSC to this directory if you want to use the help system.
		I STRONGLY ADVISE YOU INSTALL THIS FILE, at least until you have read
		it, to ensure that you use Browse to its full potential.
(d) In the Psion System Screen, press Psion-I or select `Install'
    from the `Apps' menu.  Choose BROWSE.OPA as the filename and
    press Enter.  The Browse icon will appear on the system screen.
    Press Enter on it to start the application.

Please see the help file for operating instructions.

Note:
-----
	Browse will create a small file on the Internal drive to store the most
	recent settings.

See the help file for uninstall instructions.

BROWSE.OPA takes up about 8k on disk, and BROWSE.RSC takes up 3k.  The program requires
a minimum of about 40k free for it to run but it needs more to display large PIC files at
full size.
