GPIC DYLs
---------
The "gpicsrc" directory contains the source code for the two supplied
DYLs in SIBO SDK format. In addition the file "usage.txt" explains
the GPIC interface and the file "oplgpic.opl" demonstrates how to use
the DYLs from OPL on a Series 3a or WorkAbout computer.

To write your own DYLs based on the supplied ones, you will need the
SIBO SDK (and obviously a PC). If you want help writing your own, 
please contact me by e-mail (baldwina@cix.compulink.co.uk).
If you do write new DYLs for the program, please contact me so that
they can be distributed with future versions of the program
(you're not allowed to sell any DYLs based on any of the supplied 
code.)
