QCD-Read by Kevin Millican
In the Public Domain - Enjoy

This OPL routine allows the Psion 3A/3C (+ Siena, I think!) to read and display QuickCAD v2 files scaled to fit. QuickCAD is an object-orientated sketching package for the PC running under Windows and can be obtained from Compuserve or from my web page on

http://ourworld.compuserve.com/homepages/KMILLICAN/

QuickCAD files are extremely easy to produce and understand. Also, being completely text based, they are easy to transfer across the Internet and are very compact.

There are limitations in this version but the source code is included so if you need additional features then feel free to modify the code. If you do use any of this code please acknowledge my work (especially the three point curve calculations).

INSTALLATION

Copy QCD-READ.OPA to your \APPS directory on the Psion
Create a \QCAD directory in the root directory of the Psion
Copy any *.QCD files to the \QCAD directory
Install QCD-READ from the Psions system screen.

USE

Select the desired QuickCAD file from the system screen and press <return> to load. <Esc> or <Psion-X> exits. You may associate QCD file type with the application from the file manager utility on the 3C if desired.
