Routes - The Psionavigator
This zip file contains four files 
Readme.txt      this file 
Routes.doc      instructions & guide in Psion wrd format 
Routes_1.spr    spreadsheet for mode 1 
Routes_2.spr    spreadsheet for mode 2  
Routes is an aid to navigation in that you can store the 
details of a planned route and also calculate average speed,
time & distance travelled, as well as your estimated time
of arrival.
