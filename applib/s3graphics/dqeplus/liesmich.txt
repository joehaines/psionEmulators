1. Ueberblick
Dieses Programm bietet Ihnen einen schnellen Zugriff auf Suchanfragen an eine PSION-Datenbank.
Suchvorgaenge koennen in einem Profil gespeichert werden und direkt vom Systembildschirm des PSION gestartet werden.
Desweiteren bietet DQEPlus einige Werkzeuge zur Auswertung einer Datenbank.

2. Installation
Kopieren Sie die Datei Dqeplus.opa (unbedingt) in das Verzeichnis:
a) M:\APP
b) Installieren Sie das Programm indem Sie PSION-I ausfuehren.
c) Durch Starten des Programms wird das Verzeichnis "M:\APP\DQEP"
    erzeugt.
d) Kopieren Sie nun die Datei   "dqehilfe.rsc" in das
Verzeichnis "M:\APP\DQEP"

3. Schnellstart
Starten Sie das Programm indem Sie auf die Datei "Dqueplus" unter dem Programmsymbol "klicken". Mit PSION-O waehlen Sie die Datenbank, welche Sie abfragen moechten. Nach dem ôffen der Datenbank, kînnen Sie eine Suchanfrage
starten. Druecken Sie z.B. PSION-S und geben Sie Ihre Suchkriterien ein. Mit "Enter" beginnt die Suche. Als Ergebnis erhalten Sie eine geoffnete neue Datenbank mit allen gefundenen
Datensaetzen, die Ihren Suchkriterien entspricht. Schliessen Sie diese Datei mit PSION-X (gross X). Beenden Sie nun DQEPlus ebenfalls mit PSION-X (auch gross X).
Das Programm wird beendet und Sie muessten rechts unten eine Meldung sehen, dass ihr Profil gespeichert wurde. Wieder auf der Systemebene des PSION "klicken" Sie nun auf "ihr"
Profil. Die von Ihnen gespeicherte Suche wird nun wieder ausgefuehrt und Sie erhalten das Ergebnis auf dem Bildschirm. Das Schliessen der Ergebnisdatei beendet nun auch das Programm.


3.A. Statusanzeigen
Das Programm verfuegt ueber eine Statusanzeige (links unten) und eine Verlaufsanzeige (rechts unten),
die Sie ueber den jeweiligen Zustand des Programms informiert.
Die Statusanzeige informiert Sie ueber die Art des aktuellen Profils. Auf diese Weise haben Sie vor
dem Speichern eines Profils die Moeglichkeit sich ueber den Inhalt zu vergewisssern.
Die Statusanzeige kann folgende Werte anzeigen:

"X": Keine Such- oder andere Funktion gewaehlt. Eine Profilerstellung ist unmoeglich.
"S": Textsuche aktiv
"F": Filter aktiviert (dient zur Eingrenzung der Suche, siehe weiter unten)
        "F" kann auch in Kombination mit anderen Werten angezeigt werden:
        z.B. "FS" bedeutet, dass eine Filter aktiviert ist und eine Suche durchgefuert wurde.
"DZ": Zahlen- oder Datumssuche
"RE": Rechenfunktion aktiv
"ST": Statistikfunktion aktiv
"SE": Suche- und Ersetzefunktion aktiv
"FR": Haeufigkeitsfunktion aktiv (FR=Frequenz)

Exportprofile (siehe weiter unten) sind zusaetzlich mit einem "Kaestchen" dahinter gekennzeichnet.

Die VERLAUFSANZEIGE
Unten rechts sehen Sie bei jeder Suche oder anderen Aktion ein Zahlenfeld. Hier bekommen Sie
Informationen ueber den Fortschritt der Operation. Diese Anzeige kann bis zu drei Werte darstellen.
Erster Wert: Aktuell bearbeiteter Datensatz, zweiter Wert: Anzahl Datensaetze, die zu bearbeiten sind.
Der moegliche dritte Wert zeigt Ihnen die Anzahl der gefundenen Datensaetze, die Ihren Kriterien
entsprechen (bei der Textsuche).



4.  Beschreibung der Funktionen

NEUES PROFIL
Hiermit benennen, bzw. erstellen  Sie ein neues Profil. Ein so erstelltes Profil kann erst wirklich gespeichert werden, wenn Sie eine Datenbank geoeffnet und eine
Suche, bzw. eine andere speicherbare Aktion durchgefuehrt haben.
Die Reihenfolge einer Profilerstellung sieht schematisch folgendermassen aus:
1. Neues Profil
2. Datenbank oeffnen
3. Suche oder andere Aktion
4. Profil speichern
 oder
5. Beenden und speichern
Diese Vorgehensweise entspricht der Aufzeichnung eines Makros, d.h. Sie muessen immer erst eine Suche oder andere Aktion durchgefuehrt haben,
bevor ein Profil gespeichert werden kann.
ALTERNATIVE: Sie koennen vom Systembildschirm ein neues Profil anlegen, indem Sie (wie bei anderen PSION-Applikationen) PSION-N druecken.
In diesem Fall werden Sie aufgefordert einen Namen anzugeben. Beachten Sie, daﬂ Sie zu jedem Profil eine eigene Kurzbeschreibung eingeben koennen,
die Sie spaeter mit PROFILINFORMATION ansehen koennen. Falls Sie vom Systembildschirm aus ein neues Profil anlegen, koennen Sie diese
Beschreibung "nachholen", indem Sie nach dem Programmstart "NEUES PROFIL" waehlen. Sie erhalten dann eine Dialogbox, in der ihr Profilname
erscheint und Sie koennen eine Kurzbeschreibung eingeben.

PROFIL SPEICHERN
Speichert das Profil unter dem gewaehlten Namen.

VERWERFEN
Alle Suchparameter werden zurÅckgesetzt, eine aktivierter Filter wird ausgeschaltet. Eine geoeffnete Datenbank bleibt aber weiterhin offen.

PROFIL AUSFUEHREN
Ein gewaehltes Profil wird ausgefuehrt. Nach der Ausfuehrung sind die im Profil gespeicherten Suchparameter aktuell. Damit haben Sie so die
Moeglichkeit bestehende Profile zu aendern.

ALLE PROFILE AKTUALISIEREN
Diese Funktion aktualisiert alle Profile, die die als Ausgabeform die EXPORTFUNKTION benutzen. Wichtig: Es wurden nur die Profile aktualisiert,
die im Pfad "M:\APP\DQE" gespeichert wurden. Diese Funktion ermoeglicht Ihnen "Knopfdruck" eine gro·e Datenbank in mehrere kleine Datenbanken
zu zerlegen.
Ein Beispiel: Sie haben eine Kundendatenbank mit Kunden aus verschiedenen Staedten. Nun moechten Sie diese Datenbank in z.B.
Hamburger, Berliner und Muenchener Kunden aufteilen. Zunaechst erstellen Sie fuer die jeweilige Stadt ein eigenes Profil und aktivieren die Ausgabeform
"Export". So koennten Sie drei Profile, z.B. "KunHam", KunBln", "KunMue" erstellt haben.
Jedes Profil kann nun einzeln ausgefuehrt werden und das Ergebnis der Suche wird in die entsprechende Exportdatei geschrieben.
Mit ALLE PROFILE AKTUALISIEREN werden jedoch alle diese Exportprofile mit einem Mal nacheinander ausgefuehrt. Fuer Routineaufgaben
ein ideales Mittel.
Diese Funktion setzt voraus, dass Sie sich auf der Programmoberflaeche von DQEPLUS befinden. Falls Sie nur "Alle Profile aktualisieren" ausfuehren
moechten, gehen Sie am besten folgendermassen vor:
Geben Sie "PSION-N" unter dem Programmsymbol von DQEPLUS ein, als ob Sie ein neues Profil erstellen wollten. Geben Sie iregendeinen Profilnamen
an. Nun befinden Sie sich auf der Programmoberflaeche von DQEPLUS. Fuehren Sie nun "Alle Profile aktualisieren aus". Die Funktion arbeitet
nun alle Exportprofile ab und verbeleibt anschliessend im Programm. Um das Programm zu beenden bet‰tigen Sie PSION-X (Beenden & Verwerfen).
Falls Sie "Beenden & Speichern" waehlen, wird das letzte ausgefuehrte Exportprofil als neues Profil gespeichert!

PROFILINFORMATION
Die Profilinformation bietet einen Einblick in die Suchkriterien eines Profils. Im Auswahlfeld des angezeigten Dialogs waehlen Sie das Profil, dessen
Inhalt Sie betrachten muessen. Bei Profilen, die eine Textsuche beinhalten bekommen Sie eine detaillierte Auskunft. Bei anderen Profilen ist es
wichtig, dass Sie in der Profilbeschreibung eine aussagekraeftige eigene Beschreibung angeben. Dies gilt besonders fuer die Funktion "Rechnen" und
bei Zahlen-, bzw. Datumssuche!

DATENBANK OEFFNEN
Oeffnet eine PSION-Datenbank. Diese Datenbank wird fuer die anschliessend gewaehlte Aktion verwendet.
Hinweis: Falls ein Filter aktiviert ist und Sie dann die aktuelle Datenbak wechseln, wird der Filter deaktiviert!

SUCHEN TEXT
Mit dieser Funktion koennen Sie nach Text in der geoffneten Datenbank suchen.
Hierbei koennen zwei Begriffe verknuepft werden. Mit dem Auswahlfeld waehlen Sie die Art der Verknuepfung
(UND, ODER, NICHT). Verwenden Sie nur einen Suchbegriff sollte der zweite eine "*" sein.
GRAPHIE: Hier koennen Sie waehlen, ob Gro·- und Kleinschreibung bei der Suche beachtet werden soll.
AUSGABEFORM: Angabe, ob das Suchergebnis angezeigt oder in eine Datei geschrieben werden soll.
In letzterem Fall werden Sie zur Eingabe eines Namens fuer die Exportdatei aufgefordert. Mit ZAEHLEN koennen
Sie auch nur die Haeufigkeit Ihrer Suchkriterien anzeigen lassen.
FELDER: Angabe der zu beruecksichtigenden Suchfelder. Auf diese Weise kann die Suche beschleunigt werden,
wenn Sie nur das fuer Sie relevante Feld angeben.
ALLGEMEINER HINWEIS:
Die Anzeige von Suchergebnissen erfolgt in einer eigenen Ergebnisdatenbank, dessen Oeffnungsverhalten sich
nach dem Ihrer gewaehlten Datenbank richtet. Angenommen Ihre zu durchsuchende PSION-Datenbank wird
nach dem Oeffen immer sortiert, so wird auch eine Ergebnisdatenbank (das Suchergebnis) entsprechend
ihrer Datenbank sortiert werden. Das Oeffnungsverhalten der Ergebnisdatenbank haengt immer von dem
Verhalten der geoeffneten Datenbank ab und laesst sich nicht individuell veraendern.

SUCHEN ZAHLEN + DATUM
Diese Funktion ermoeglicht die Suche nach Zahlen oder Datumsangaben.
Im ersten Auswahl geben Sie an, ob Zahlen oder ein Datums(bereich) gesucht werden soll.
Ausgabeform: Analog SUCHEN TEXT.
Die Ausgabeform kann auch ein FILTER sein. In diesem Fall wird Ihre Datenbank vorselektiert.
Ist ein Filter aktiv, werden bei einer nachfolgenden Suche nur die Datensaetze beruecksichtigt,
welche durch den Filter spezifiziert worden sind.
FELD: Feld, welches abgefragt werden soll.
OPERATOR: Hier geben Sie den Vergleichsoperaor ein (logische Verknuepfungen).
1. WERT: Erstes Suchkriterium
2. WERT: Zweites Suchkriterium
HINWEIS: In der Regel wird nur das erste Suchkriterium benutzt. NUR bei der Intervall-Suche,
d.h. Zahlen- oder Datumsbereichen (z.B. 1.10.1990 bis 31.11.1991) werden beide Werte
benutzt.

TEXTFILTER
Aktiviert einen Filter, der die gewaehlte Datenbank vorselektiert. Bei einer nachfolgenden
Suche ist die Menge der zu durchsuchenden Datensaetze durch den Filter verkleinert.
Auf diese Weise koennen Sie gezielter Suchen.
Beispiel: Adressendatenbank mit Staedtenamen. Sie haben mehrere Bremer Adressen,
aber auch viele andere vertretene Staedte in ihrer Datenbank.
Aktivieren Sie einen Filter mit den Suchkriterien "Bremen" UND "*" so werden
bei einer folgenden regulaeren Suche nur die Datensaetze beruecksichtigt, welche
die FILTER-KRITERIEN "Bremen" enthalten, alle anderen Datensaetze werden
ignoriert.
Hinweis: Der Filter wird aktiviert, indem Sie in der untersten Zeile des Dialogs den
entsprechenden Schalter auf "EIN" setzten.
Das Deaktivieren eines Schalters geschieht, indem Sie diesen Schalter auf "AUS" setzen.
Ein aktiver Filter kann nur von der Funktion "Text suchen" genutzt werden. Zusatz-
funktionen ("Suche und Ersetzen", "Statistik" usw.) deaktivieren jeden Filter und
bearbeiten immer Fall die Gesamtheit der Datensaetze.

SUCHE UND ERSETZEN
Ersetzt einen Begriff in Ihrer Datenbank durch einen anderen.Sie koennen waehlen,
ob bei der Suche Gross-/Kleinschreibung (Graphie) unterschieden werden soll und
Sie koennen das abzusuchende Feld angeben. Bei einem Sucherfolg wird Ihnen
das entsprechende Feld angezeigt und Sie koennen ueber das weitere Vorgehen
entscheiden. 
HINWEIS: Ein aktivierter Filter wird vor dem Ausfuehren der Funktion deaktiviert!

RECHNEN
Sie koennen einem Feld Ihrer Datenbank eine Berechnung zuweisen.
Im entsprechenden Dialog geben Sie unter FELD das Feld an, in welches
das Ergebnis ihrer Berechnung eingetragen werden soll.
Hinter dem "=" geben Sie Ihre Rechenformel ein. Sie koennen in dieser
Rechenformel auch andere Feldnamen (Bezeichner) verwenden.
Ein Beispiel:
Sie haben eine Datenbank mit den Feldern:
Menge, Preis und Endpreis
Eine Berechnung koennte folgendermassen aussehen:

Feld: -Endpreis-
=
"Menge"*"Preis"

In diesem Fall wuerde in jedem Datensatz Ihrer geoeffneten Datenbank
dem Feld (Bezeichner) Endpreis, das Produkt aus Menge*Preis, zugewiesen.
Beachten Sie das Sie mit dieser Funktion Ihre Datenbank veraendern, indem
ein Feldinhalt veraendert wird. Legen Sie eine Sicherheitskopie an, um
Ihre Berechnung zu pruefen.
FEHLERMELDUNG:
Ergibt sich in einer Berechnung eine Fehler, so wird das Ergebnis im entsprechenden
Datensatz als "Fehler" eingetragen. Moegliche Ursachen sind:
Das Feld in einer Rechenformel ist nicht vorhanden, eine Rechenfunktion ist
nicht verfuegbar oder ein Rechenfehler (z.B. Division durch 0)  tritt auf.
Die Rechenformel kann alle auf dem PSION zulaessigen Funktionen
enthalten. Falls Sie in der Formel Felder verwenden, muessen diese in Anfuehrungsstriche
gesetzt werden ("Preis") nicht (Preis)!
HINWEIS: Die Rechenformel kann ein Laenge von 255 Zeichen besitzen.
Aber: Die eingebene Rechenformel wird innerhalb des Programms in seine
berechenbare Form gebracht, d.h. vorhandene Feldnamen werden durch
tatsaechliche Zahlen ersetzt. Das heisst eine scheinbar korrekt lange Formel
kann doch im Ergebnis einen Fehler produzieren. Betrachten Sie folgendes
Beispiel:
Sie geben an: Endpreis = "Preis"*"Menge"
Z.B. lautet der Preis im ersten Datensatz 5500000 und Menge ist gleich 10000.
dann wuerde die konkrete Rechenformel folgendes Aussehen haben:
Endpreis= 55000000*1000000, dh. eine Laenge von 15 Zeichen, waehrend
ihre eingegebene Formel nur 14 Zeichen besitzt. In sehr unguenstigen
Faellen koennen Sie dementsprechend eine Fehlermeldung bekommen, wenn
die tatsaechliche Rechenformel eben laenger als 255 Zeichen wird.
HINWEIS: Ein aktivierter Filter wird vor dem Ausfuehren der Funktion deaktiviert!
Beachten Sie, dass das Kommazeichen ihrer Werte in der Datenbank dem Format
der Systemeinstellung des PSION (Einstellungen, Zahlenformat) entsprechen
muss!
Ein aktivierter Filter wird vor dem Ausfuehren der Funktion deaktiviert!

STATISTIK
Diese Funktion wertet ein von Ihnen gewaehltes Feld der geoeffneten Datenbank
aus. Es werden MINIMA, MAXIMA, MITTELWERT, STANDARDABWEICHUNG,
VARIANZ und SUMME berechnet. Nach Abschlusss der Berechnung bekommen
Sie einen Hinweis, wieviele Felder nicht beruecksichtigt werden konnten, weil Sie
keine gueltigen Zahlenwerte enthalten.
Hinweis: Ein aktivierter Filter wird deaktiviert.

HAEUFIGKEIT
Diese Funktion ermittelt die Haeufigkeit aller in einem Datensatzfeld vorkommenden
Feldinhalte und listet diese in einer PSION-WORD-Datei auf.
Beispiel:
Eine Adressdatenbank mit Staetdenamen im Feld "Stadt". Eine Haeufigkeitsfunktion
im Feld "Stadt" wuerde Ihnen Auskunft geben wie oft z.B. "Hamburg", "Muenchen",
"Leipzig" usw. in diesem Feld vorkommt. Sie erhalten die absolute Anzahl (n)
und den absoluten, sowie den relativen Prozentanteil an der Gesamtheit der
Datensaetze. Beim relativen Prozentanteil werden nicht ausgefuellte (leere)
Datensatzfelder aus der Prozentberechnung herausgenommen. Sie koennen diese
Funktion besonders gut fuer kleinere statistische Auswertungen benutzten.
Ausserdem koennen Sie mit dieser Funktion auf einfache Weise doppelte
Datensaetzen erkennen.
GRENZEN: Wie Sie vielleicht wissen kann eine PSION-WORD-Datei nur
den Umfang von ca. 40 Kilobyte betragen. Diese Beschraenkung gilt ebenso
fuer die Asuwertung Ihrer Datenbank mit der Funktion "Haeufigkeit".
HINWEIS: 
 Bei grossen Dateien kann vor dem Anzeigen der Ergebnisdatei
ein Hinweis auftreten: "Sie koennen diese Datei nicht bearbeiten ..."
Sie koennen diesen Hinweis ganz beruhigt uebergehen, fuer Ihre
Daten besteht keine Gefahr.
Ein aktivierter Filter wird deaktiviert.

BESONDERE PROFILE
Zwei Profileformen verhalten sich bei der Ausfuehrung grundsaetzlich
anders, als alle anderen Profile.
Dies sind die sogenannten "Nur-Filter-Profile".
Normalerweise kehrt das Programm nach einer Profilausfuehrung
auf die Systemebene des PSION zurueck, nachdem Sie ein Suchergebnis
angezeigt bekommen haben.
Die "Nur-Filter-Profile" zeigen Ihnen jedoch die Programmoberflaeche
von DQEPLUS und kehrt somit nicht zur Systemebene zurueck.
Die beiden besonderen Profilarten gestatten Ihnen daher in einer
aktuellen, vorselektierten Asuwahl der definierten Datenbank zu
suchen. Beachten Sie, dass der Filter jeweils neu erstellt wird,
womit Aenderungen in Ihrer gewaehlten Datenbank immer
beruecksichtigt werden.
"Nur-Filter-Profile" koennen Sie nur auf einem Weg erstellen:
Starten Sie das Programm duch Druecken von PSION-N von der
Systemoberflache und geben Sie einen Profilnamen an und waehlen
Sie Ihre abzufragende Datenbank. Sie muessen(!)  nun gleich im
Anschluss einen Filter aktivieren (siehe oben). Nun duerfen Sie
keine Such- oder andere Aktion durchfuehren, sondern umgehend
das Profil speichern. Ein "Nur-Filter-Profil" erkennen Sie daran,
dass in der Statusleiste nur ein "F" ohne Zusatz erscheint!
Falls Sie dennoch eine Suchaktion starten und dann das Profil
