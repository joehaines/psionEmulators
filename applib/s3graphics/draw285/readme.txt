Overview of DRAW
================
DRAW is the number one best-selling shareware bitmap editor for the Psion 
Series 3 range of palmtop computers. It allows picture (Psion PIC) files 
to be viewed, edited, and printed on your Psion. To help you create your
exciting images, it features real-time zoom; flood fill; user-defined 
fonts; undo; variable width lines; scroll bars; an INI file to remember 
your default settings; a clipboard and lots more. And by using a third
party app (FirePic), other non-Psion format image files like PCX and GIF 
can be imported and exported.

Please refer to the User Guide in WRD format for instructions.

Installation
============
DRAW is a fairly standard Psion application; just copy the files listed
below to your Psion, then install with Psion-I from the system screen
as normal. You'll probably find that your unzipping program has already 
created the directories for you, in which case your job is made 10x easier!
Just remember to NOT let PsiWin 'convert' any of these files, they're
already in Psion format! The best way to do this is to hold down the Control
key on the PC whle dragging and dropping with the mouse (see the PsiWin
help for more details).

  File (size)           Description             Destination
  ------------          ------------            ------------
  DRAW285.OPA           Main application        \APP\
  DRAW2HLP.RSC          Help resource file      \APP\DRAW2
  DRAW2.PAT             Fill pattern file       \APP\DRAW2
  EXAMPLE3.PIC          Optional sample bitmap  \PIC\
  README.TXT            This file!              \
  DRAW.WRD              The user guide          \WRD\

The following files may also be created by DRAW at some point:
  DRAW2.INI             Initialisation file     \OPD\
  DRAW2.REG             Registration file       \OPD\

You can delete all program files from previous versions of DRAW, or leave
them installed if you wish to run more than one version.

To uninstall DRAW, remove the above files, the \PIC subdirectory and any
DRAW files in the \OPD directory.
