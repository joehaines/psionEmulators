3.1a Qu'est ce que Graph+ ?

     Graph+ v2.0 est un traceur de courbes, comme on peut en
     trouver sur la plupart des calculatrices graphiques de poche.
     Il possede moult fonctions, que vous decouvrirez. Et surtout,
     il est rapide. Tres rapide.

3.1b Installation

     Vous devez avoir recu le programme avec les fichiers suivants:
        Nom         Taille (octets)
        Graph2.OPA  10171
        Graph2.RSC  4123
        Graph.TXT   Ce fichier

     Pour installer le programme:
       a. copiez le fichier Graph2.opa dans le repertoire \APP\ de
          n'importe quel disque (A, B ou Interne).
       b. copiez le fichier Graph2.rsc dans le repertoire \OPD\ de
          n'importe quel disque (A, B ou Interne), si vous
          voulez acceder a l'aide du programme
          (fichier faculltatif).
       c. Installez l'icone de l'application dans l'ecran systeme
          comme pour une autre application (Psion-I).
         
1.1c Utilisation

     Pour ceux qui n'aiment pas lire les modes d'emploi (et pour
     les autres, aussi, car il n'y en a pas encore... de manuel),
     voici ce que vous pouvez faire pour vous familiariser
     rapidement avec le logiciel:

       -Lancez le programme
       -Appuyez sur une touche, ou attendez quelques instants, le
        programme vous demande de rentrer le nombre d'equations.
        Tapez "2".
       -Un autre dialogue vous demande de rentrer les equation,
        tapez sin(x) sur la ligne "y1=", et cos(x) sur la ligne
        "y2=".
       -Le logiciel vous demande alors la couleur des courbes.
        Choisissez le gris pour la premiere, le noir pour la
        seconde.
       -Une boite de dialogue "Range" s'affiche. Remplissez les
        lignes ainsi: -Pi pout "Xmin", 2*Pi pour "Xmax", 1 pour
        "Xscl", laissez les dernieres lignes intactes.
       -Quand les courbes sont tracees, appuyez sur "Menu".
        Choisissez l'option "Automatique" du menu "Zoom", les
        valeurs de "Ymin" et "Ymax" sont modifiees pour que les
        courbes occupent tout l'ecran.
       -Utilisez les touches "Gauche" et "Droite" pour vous
        deplacer un peu le long de l'axe x'Ox.
       -Selectionnez l'option "Tracer" du menu "Graphe", les
        courbes sont entierement redessinees. Si vous appuyez
        sur "Esc" pendant le dessin d'une courbe, son trace est
        arrete, et la courbe suivante est dessinee.
       -Choisissez l'option "Plot" du menu "Graphe", vous pouvez
        alors deplacer un curseur en croix a l'ecran, l'abscisse
        et l'ordonee de celui-ci sont retournees. Appuyez sur
        "Entree" quand vous avez termine.
       -Enfin, selectionnez l'option "Boite" du menu "Zoom", vous
        pouvez alors, avec le curseur, choisir les limitez du zoom.

     Vous trouverez tout seul les autres fonctions du grapheur.

2.1a What is Graph+ ?

     Graph+ v2.0 is a mathematical function plotter, like those
     found on most of pocket graphic calculators.
     It has got a lot of functionalities, that you'll discover,
     and it's main performance is its speed.

2.1b Setup

     This file should have came with the following files:
        Name        Size(bytes)
        Graph2.OPA  10171
        Graph2.RSC  4123
        Graph.TXT   This file

     How to install the program:
       a. copy the file Graph2.opa into an \APP\ directory
          on any drive (A, B or Internal).
       b. copy the file Graph2.rsc into an \OPD\ directory
          on any drive (A, B or Internal), if you want to
          use the help inside of the program (this file is
          facultative).
       c. Install the application icon into the system screen
          like any other app (Psion-I).
         
2.1c Quick use

     For those who don't like reading big manuals (and for others
     too, because there isn't any manual yet...), here is what
     you can do in order to become familiar with this software:

       -Run the program
       -Push a key, you'll be prompted for the number of equations.
        Type in "2".
       -Another dialog box prompts you for the equations, enter
        sin(x) on the "y1=" line, and cos(x) on the "y2=" one.
       -You're then asked for the plotting color. Choose "black"
        for the first one, and "grey" for the second.
       -A "Range" dialog box appears. Fill in the lines like this:
        -Pi for "Xmin", 2*Pi for "Xmax", and leave the other
        lines like they are.
       -When the equations are plotted, push the "Menu" key.
        Choose "Automatic" in the "Zoom" menu, the "Ymin" and
        "Ymax" values are automatically modified in order to
        let the graph fit into the whole screen.
       -Use the Left and Right keys to move along the x'Ox axis.
       -Choose "Trace" in the "Graphe" menu, the equations are
        fully plotted. If you press Esc while one is plotted,
        the program stops its drawing and jumps to the next.
       -Choose "Plot" in the "Graph" menu, you can now move a
        cross-type cursor on the screen. Its coordinates are
        shown. Press Enter when you're bored.
       -Choose "Box" in the "Zoom" menu, you can now, with
        the cursor, select the corners of the region to be zoomed
        on.

     You'll find the other Graph+ functionalities on your own.
