LETMAIL is a mailing program for PSION.
It's purpose is to print automaticaly personalized letters, from a standard text file and from datas of a DBF file.

It had been designed on PSION 3a, but should run on 3c and would'nt on Siena.

I - Shareware :

LETMAIL is a shareware. It means that :
	- If, after a period of test, you decide to keep it, you have to contribute to the author (see "Shareware"  menu/settings).
	- You can freely distribute this software unmodified and including every files of the package.


II - Installation

6 files are in the LETMAIL package :
		- Letmail.opa
		- Letmail.rsc
		- Letmail.dat
Installation steps :
	1 - copy Letmail.opa in the APP\ (M:\APP\) directory
	2 - Create a sub-directory in APP\ : LMA\
	3 - Copy Letmail.rsc in the APP\LMA\ directory
	4 - Copy Letmail.dat in the APP\LMA\ directory
	5 - Install Letmail.opa  (Psion-I)


III - Using LETMAIL

III - 1 - General settings
Set up the printing port in the menu/settings/port.
III - 2 - The letter
Write and type your letter in the Word program on the Psion. You can personalized it with 9 fields : rub1 to rub9. To tell LETMAIL it's a personalized field, type it like that : <rub1> or <rub9>. Note that you can apply style to this fields.
Then, print your letter in a file on the disk (in printer config, change port to 'file' and choose a name).
III - 3 - The datas
LETMAIL works with data files of the Psion : .DBF.
III - 4 - Prints
Menu/Mailing/Settings : select the letter print file and the data file. then, tell LETMAIL the links between letter rubs and data fields.
Now, you can launch the printing process : Menu/Mailing/Print
III - 5 - Other
LETMAIL lets you give a name to your project and save it.


PS : you can choose language between English or French.
