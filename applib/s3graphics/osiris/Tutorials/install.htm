Installing Osiris

The Osiris application and support files are supplied inside the "Distrib" directory of the zip archive. They are already sorted into the correct directories so with most desktops you can just drag the enclosed "APP" and "OPL" directories onto your Psion directory display and everything should be transferred correctly.

If this is not the case with your computer, follow the instructions below to install everything in the right place. You may find the User Guide supplied with your machine helpful to carry out this.

  1. If the directory "\APP" does not exist on the device which you want to install Osiris on, use "Make directory" from the "Disk" menu in the System screen to create it (ensure the path is set to the root directory of the device).
  2. Copy the file "Osiris.opa" from the "Distrib\APP" directory of the zip archive into the "\APP" directory on your Psion.
  3. Using the "Make directory" option from the "Disk" menu in the System screen, create a directory called "OSIRIS" inside the "\APP" directory.
  4. The below files are found in the "Distrib\APP\OSIRIS" directory of the zip archive. Copy them into the "\APP\OSIRIS" directory on your Psion.
    • Bestfit.utl - Line of best fit utility
    • Cart.plg - Cartesian equations plugin
    • Dataplot.plg - Data analysis plugin
    • Ofit.utl - Line of best fit utility (forced through origin)
    • Oshelp.rsc - Osiris on-line help
    • Osiris.pic
    • Param.plg - Parametric equations plugin
    • Polar.plg - Polar equations plugin
    • Quadrat.utl - Quadratic equations utility
    • Scaprod.utl - Scalar product utility
    • Vecprod.utl - Vector product utility
  5. If the directory "\OPL" does not exist on the device which you want to install Osiris on, use "Make directory" from the "Disk" menu in the System screen to create it (ensure the path is set to the root directory of the device).
  6. Copy the "Utility.opl" from the "Distrib\OPL" directory of the zip archive into the "\OPL" directory on your Psion.
  7. If you use a Siena, the existing on-line help is too wide to be used on the smaller screen so an alternative file is provided in the directory "Siena" in the zip archive. This contains a file "Oshelp.rsc" which needs to be copied into the "\APP\OSIRIS" directory on your Psion, replacing the file already there.
  8. Choose "Install" from the "Apps" menu in the System Screen.
  9. Use the file selector to select the file "Osiris.opa" (it should already be in the "\APP" directory) and press Enter to install Osiris.
  10. Move to the Osiris icon and press Enter. After a short banner which lists the plugins available, you should see a pair of co-ordinate axes. Congratulations! You have installed Osiris correctly.

If you get an error message, you should ensure that all files have been copied across and are in the correct place. If you still have problems, please contact the author.
