CDs    V. 2.0 beta     20/5/96
------------------------------

A CD, CDI, Video CD and CD-ROM collection
manager. Lists your collection, borrow /
lend facility, favorite track, duration,
etc.

With compliments to Psion Germany for CDBase
which inspired me to write CDs (CDBase list
option was way too slow and did not allow
selection or escape; option for entry of
fragments is fantastic but my discspace is
too precious; same remark for listings of all
tracks per CD; I missed distinction between
kinds of media, etc. CDs is also smaller)
 
ZIP file should contain:
- CDs.opa (main application)
- discs.dbf (optional sample file)
- CDs.txt (this file)

Installation (on any drive):
N.B. if there is no \dat\ directory on the
destination drive, create it now (the
program won't do this for you!
Copy:
cds.opa ---> \app\
and optional sample file:
discs.dbf ---> \dat\ (non-flash)

This program is 100% freeware. You can
do with it whatever you like as long as
you agree that I am not to be held responsible
for any consequences related to the use
(or abuse) of it in any way.

If you like it, please let me know. Critical
remarks as well as suggestions would be
greatly appreciated. As CDs is freeware this
is also the only way for me to get some
feed-back on "public appreciation" (if any).

I think the use is quite easy. Note however
that the program, if it does not find a file
called "\dat\discs.dbf" it will create it
automatically (and prompt for drive letter).
