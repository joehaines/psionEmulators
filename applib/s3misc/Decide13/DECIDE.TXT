-OVERVIEW-

'Decide' is a SHAREWARE program for the Psion Series 3a/3c.

It is basically a DECISION MAKER with example uses being an
aid to deciding which car or house to buy, or prioritising a job list etc.
It will list up to 20 different 'Options', and apply scoring for up to 10
different 'factors'.
The options will be presented in order of strength.

-INSTALLATION-

The program was zipped with the relevant directory structure, but in
case this has not been re-created, please use the following.

DECIDE.OPA   - Main Program -  copy to any \APP directory
DECIDE.RSC   - Help File         -  copy to M:\DECIDE (see note below)

Install Software icon by using Psion-I from the S3a system screen.

Any data files will be stored in the M:\DECIDE directory.


-HELP FILE-

My recommendation is to install the help file, and if space is
at a premium - delete it when you are familiar with the software,
as I have not included any help text in this file.
