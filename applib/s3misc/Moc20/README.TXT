MoC                  Master of Ceremonies                by John Hind
---------------------------------------------------------------------
SUMMARY

Master of Ceremonies (MoC)  is an application for the PSION Series 3/
3a Computer to assist people who have to control any structured event
such as a conference, meeting, tutorial, television  programme etc.
It can also be used by individual presenters to keep their talk to
time and act as an electronic cue card.             MoC is Shareware.

---------------------------------------------------------------------
FEATURE LIST

* Full PSION Series3 application. Installs as icon on System Screen.

* User definable schedules made up of headings and time slots.

* Plan schedule based on relative time or fixed start or end times.

* Show start and end times for whole schedule and for current time
  slot. Show text for current and next time slots or heading.

* During event, show countdown timer for running time slot,
  estimated schedule finish time and over-run or under-run.

* Show analogue or digital clock, according to system setting.

* Slots and headings may be changed, moved, deleted, added and
  copied, singly or in marked blocks.

* Future part of schedule may be changed while schedule is running.

* Find text in headings or time slots and find time slot at a given
  time.

* Use template schedules for standard events.

* Copy headings and time slots between schedules.

* Three types of optional audible alarms.

* Log a schedule run to record actual durations of time slots.

* Print schedule via the "Word" application.

* Exchange data with other applications on PC, Mac or S3.

* Work in 24Hr clock or am/pm time according to system setting.

* Outline-based on-line user guide using the "Word" application.

Additional features on Series-3a Only

* Alarms may additionally be set to play back sound files, and/or
  animated graphics.

* Full advantage is taken of the higher screen resolution to
  improve the presentation and display more text in items.

INSTALLATION

To install MoC, all the above files must be located either on an SSD
or on a disk drive on a PC attached to the Series 3 machine via the
3-Link cable and MCLINK software. In either case, all the files must
be in the same directory.
1. Copy the MOCINST.OPL file into the \OPL directory in internal
memory.
2. Load this file into the Program application and translate using
PSION-T. Answer YES in the "Run program" dialog,
3. Press any key to bring up the Installation Options dialog.
4. Complete this dialog and press ENTER. The files for the selected
version will be installed into the correct directories.
5. At the system screen, select PSION-I to install the application
icon and pick the "MOC" application from whichever device you
installed it to.
6. You can now delete \OPL\MOCINST.OPL and \OPO\MOCINST.OPO.
7. To get started, I recommend you open the MOC or MOCA file in the
Word application at the same time as the EXAMPLE file in the MOC
application.
