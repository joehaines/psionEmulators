Shoplist: development history

1.00	First public release.

1.01	Allowed program to run on emulator in full screen mode.
	Bug relating to removal of categories/shops fixed.

1.02	Automatic compression of file on Checkout.
	Bug relating to commas in category and shop names fixed.

1.03	Greying of 'Pick' items added to 'Shop' fixed.

1.04	Aisle handling when store changed improved.

1.05	Default aisle and repeat/once-only purchase categories.
	Handling of leading and trailing spaces improved.

1.06	Each-trip purchase categories added.

1.07	Default store for each category.
	<Tab> dialog added for category/store changes.
	Diamond menu and hot keys for mode changes.
	Alpha keys allow fast jump to item.
	Home/End display updating improved.
	Help file upgraded.
	Zoom command upgraded with zoom in/out.
	Cosmetic improvements to menus and dialogs.
	Remove Category now allows item deletion.
	Items/Categories/Stores with no name blocked.
	File structure checked on Open; errors repaired.

1.08	File structure check/repair moved to optional module.
	Documentation distributed as wrapped 72-column text.

1.09	Discount upgraded to include "multibuy" discounts.
	Registration file explicitly stored on internal disk.

1.10	Added per item cash discounts to buy.
	Help clarified on default aisles.
	20 item limit on shopping list in unregistered version.

1.11	AutoList feature lists regularly-purchased items.
	File format changed: upgraded automatically.
	File format check modified to reflect new format.
	Find function enhanced to exclude mid-word matches.
