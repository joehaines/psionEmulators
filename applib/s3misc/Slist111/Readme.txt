ShopList 1.11

By Hugh Matthews, January 1997


ShopList is designed to make the process of shopping for groceries
simpler. As well as managing your shopping list, it provides a pick list
of regularly-purchased items, keeps track of prices, and learns the aisle
layout of your supermarket. ShopList can even automatically add items
which you purchase regularly to the shopping list.The list is subdivided
into categories. Each item belongs to a category, and contains the price,
quantity, store and aisle from the last time it was purchased. 

ShopList runs on the Psion S3A and S3C computers (all memory sizes, 
tested on UK and US versions). It will not run on the S3 or Siena. 


Installation 

Copy SLIST.OPA into any \APP directory. Create \APP\SLIST on the same
disk and copy into it SLISTHLP.RSC (the help file), SLISTCHK.OPO
(file check/repair routines) and SLISTUPG.OPO (file format upgrade).
SLISTHLP.RSC and SLISTCHK.OPO are both optional and can be omitted
to save space if desired. SLISTUPG.OPO can be deleted once all files
from previous versions have been opened for the first time. Install
SLIST.OPA from the system screen using Psion-I. When ShopList is 
first run, it will create a directory \LST on your internal disk in
which it stores list files. If you are upgrading from a previous
version it is strongly recommended that you make a backup of your 
list files before first opening/upgrading them using the new version. 
The contents of the help file are also contained in MANUAL.TXT in
plain ASCII format.
