Description:

	Plan is a project planning tool for the Psion Series 3a/3c/3mx
	and Siena. (A separate version is also available for the Series 5
	and Geofox One). Given a set of tasks, and resources working
	on those tasks, Plan will calculate the schedule for each
	task and the project as a whole, taking into consideration
	dependencies between tasks, resource work hours and holidays etc.

Contents of this package:

	EXAMPLE.RES 	- example resource file (optional)

Quick installation:

	1) If you have a copy of an earlier version of Plan,
	   back it up and remove it from the Psion.
	2) Copy PLAN.OPA to \APP\ on any drive.
	3) Create the directory PLAN below the APP directory where PLAN.OPA
	   has been installed.
	4) Create the \APP\PLAN\ directory.
	5) If on-line help is required then copy the file PLAN.HLP into
	   the \APP\PLAN\ directory.
	6) Install any of the optional plan modules by copying the
	   OPO files into the \APP\PLAN\ directory.
	7) Create the directory \PLN\ on the internal drive or a ram
 	   drive.
	8) Optionally copy EXAMPLE.PLN and EXAMPLE.RES into the \PLN\
	   directory.
	9)Install the PLAN.OPA using psion-i from Psion system screen.
	10)Refer to the user guide for further details.
