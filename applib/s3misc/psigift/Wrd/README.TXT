PsiGift
========
PsiGift will run on the Psion Series 3a and 3c palmtops.

Files and installation
======================
Changes.txt - changes made to program
Readme.txt - this file
PsiGiftA.dbf - Adults test questions file
PsiGiftK.dbf - Kids test questions file
PsiGift.opa - program file
PsiGift.rsc - help file (optional)
*.mgt - Test results file
PsiGift.ctl - setup control file
Setup.opo - file installation program

Using PsiWin and link:
Copy PsiGift.opa to \app\
Copy *.dbf to \app\psigift\
Copy *.mgt to \app\psigift\results\
Copy PsiGift.rsc to \app\psigift\
(The program will automatically create a \app\psigift\ directory the first
time it runs).
Copy *.txt to \wrd\text\ or any where else you want the readme file to be
(optional).

Using Setup.opo
Copy ALL the files to a temporary directory on your Psion e.g. \TEMP\
From the RunOpl program, press Tab and navigate to the temporary directory.
Select Setup.opo and follow the instruction.  Choose Psigift.ctl and the
program will copy all the files to the correct directories.
If you are in need of space choose the Gift512.ctl file and only the needed
files will be installed.
Psion Setup (c) is  written  by Jochen  Siegenthaler and  used  under
licence.

From System screen, press Psion-I to install PsiGift.

What PsiGift does
==================
PsiGift is a program that will help you determine your motivational gifts.
(For more in depth help, read on-line help).
