Trivia 1.0 for S3a/3c
---------------------

A collection of useless (and not so useless) facts and figures.

All public domain and completely free. Collected by Steve Litchfield
and others on the net. See http://3lib.ukonline.co.uk/ for more 
software.

A version is available for the Series 5 from the same place which also
features graphical items (e.g. semaphore, washing symbols etc)

To install, just put the .DBF file in any \DAT directory on your Psion.

Have fun!
