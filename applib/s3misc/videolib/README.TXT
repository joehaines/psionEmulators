Introduction
============

VideoLib is a program written for the Psion 3a/c 
to store and retrieve information about video 
recordings.

Full information on how to use VideoLib is included 
in the comprehensive help file and it is strongly 
recommended that each of the help sections are read 
thoroughly.

The key features of VideoLib are:

- Up to 9999 video tapes per library file 
  (registered version only).
- Up to 16 programs per video tape.
- Video tapes are always displayed in numeric order.
- Program slots are automatically opened and closed 
  as programs are added, moved and deleted.
- Intelligent handling of Standard and Long Play 
  recordings on the same tape.
- Comprehensive search facilities to locate 
  selected programs or free space available for 
  recording.
- Search report feature to export the search 
  results to an OPL Database.
- User selectable display of program information.
- User selectable program category list.
- Psion standard interface.


Installation
============

VideoLib comprises the following files:

    Video101.opa    (Program file)
    Video101.rsc    (Optional Help file)
    Example.lib     (Optional Example Library file)
    Videodat.als    (Optional Alias for Data)
    Videojbd.als    (Optional Alias for JBData)
    Videodat.ico    (Optional Icon for Aliases)
    Readme.txt      (This file)

To install, copy these files to the following 
locations:

    Video101.opa    Any Drive    \APP\
    Video101.rsc    Any Drive    \APP\VIDEOLIB\
    Example.lib     Any Drive*   \VIDEO\
    Videodat.als    Any Drive    \APP\
    Videojbd.als    Any Drive    \APP\
    Videodat.ico    Any Drive    \PIC\

* Library files will work from any drive but I 
  strongly suggest using either Internal or RAM 
  SSDs due to the number of file rewrites that 
  will occur during editing. New library files 
  will normally be created on the Internal drive.

Install the application on the system screen using 
Psion-I (or the equivalent on non-English language 
machines).

Install the alias on the system screen, if required 
using Psion-I (or the equivalent on non-English 
language machines).


Upgrading
=========

To upgrade VideoLib from an earlier version, 
uninstall the VideoLib icon from the system screen 
(Psion /) and delete all the files installed for 
the earlier version. Do not delete library files or 
any other files created by VideoLib.

Install VideoLib as described above. Library files 
created by earlier versions will be automatically 
updated when they are opened by VideoLib.

Background
==========
The ideas behind VideoLib came from a programme 
I wrote originally for the PC using the "Clipper" 
database application compiler. Unfortunately this 
became unusable on all new PCs and was not fully 
millennium compliant anyway.

I decided to write my own program because I already 
had a large database of videos and because I had 
clear ideas about what I wanted from a Psion 
programme, which none of the available video 
library managers met.
