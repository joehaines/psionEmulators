Description/Overview:
	FinCalc, was written to simplify mortgage
	calculations for just about any interest period/term compounds.  
	I added Annuity and Savings investments as well.
	This program will be continually modified and enhanced with 
	other financial calculations, programs, and options.

Changes since version 1.06:
	- Fixed a bug with LOAN Amortization crashing if the interest period
	  was set to Monthly
	- Changed all large numbers to Nice Numbers (with commas)
	- Added Refinance LOAN Option at any period
	- Added the ability to PrePay Principal in any period of the LOAN
	- After LOAN is calculated the appearance of the summary screen
	  changes.  Press MENU to see a list of options at that point.

Limitations:
	- Help is not available in this version
	- LOAN amortization is not enabled for viewing PrePay or ReFinance
	  periods, straight calc only (this is currently being worked on)
	- PrePay and ReFinance can not be done at the same time/calculation
	  (this is currently being worked on)

Install FinCalc:
	- Copy "fincalc.opa" to the \APP\ directory on any drive on the 3a
	- Install "fincalc.opa" using Psion-I from the System screen.
	- Fincalc will create FINCALC.INI in M:\OPD

Some Help:
	- Interest rates are entered in as normally stated. 
	  (Enter 8.5 for 8.5%  NOT  .085)
	- LOAN Amortization, from Mortgage result Screen press "Psion Z" to
	  get to the Amortization/Aging screen
