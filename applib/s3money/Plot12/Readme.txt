
             DPBank Plot v1.2 by Nick Dawkins.


 Plot is a utility  for users of the excellent DPBank v1.4
written by Daniel Pfund.

 Having just started using DPBank I missed having an
overall graphic view of my accounts. As I thought the 
program was so good in all other respects, I thought I'd
write my own program to plot an auto scaling  graph
of each account, as seen on most commercial programs.
The program has two main options. One, to display account
info in the form of account aaverages. And two, to display
a graph of the account which can be scrolled through
giving information on each transaction.

             Update from v1.0

v1.1 has a few more features than the previous version.

Accounts can now be selected from their actual names.
The program has optional password protection.
The graph can be scrolled through faster using Psion/cursors.
The program can work as a plug-in module in future versions of DPBank.
Esc key now exits the graph view.

v1.2

Bug fixed which now allows different account names to be loaded.
Different account groups can now be loaded from the menu.
Graph can now scale larger numbers (useful for foreign currencies).
Account Info average now works correctly.

 As I wrote this for myself, I have only released it as
freeware hoping other users might find it useful. I've
only tested it on my own accounts, and it works fine
with these. There are limitations though. It does not
work with very large numbers, so if you're really
rich, hard luck on you! Also there is an upper limit of
transactions that can be included on the graph due to
the screen size. This though, should not affect the 
average user.
