Version 1.3d
- added two export options in account display mode: export
  to spreadsheet and export to .pic file. See Help on "Export
  and print".
- at the bottom of the "All transactions/all accounts" screen,
  capital gains are now summed separately from dividends and
  other incomes.
 
Version 1.3c
- at the bottom of the "history of transaction" screen, capital
  gains are now summed separately from dividends and other
  incomes.
- it is now possible to "syncronize" the last quotes in Porfolio
  with the last records in history files (Psion-G): the latest
  records in each application are used to update the records
  in the other application.
- hot key: press Enter in transaction display mode, and the
  amount per unit is displayed (bottom right).
- hot key: press Shift+Enter in the account display screen,
  and the history of transactions on the highlighted share
  will be opened.

Version 1.3b
- the programme now comes in one file (no more .ovl)

Version 1.3a (bug fixing)
- bug fixed: "IRR" menu command now shown only when
  the calculation is actually possible.
- bug fixed: error on <Psion-U>.
- bug fixed: error on re-creation of an account, which had
  been previously deleted.
- bug fixed: now impossible to record a dividend in an empty
  account, or on a cash line.
  
Version 1.3
- transaction record updating/deleting has been totally
  changed. No more "transaction" option in "Housekeeping",
  but two menu options in transaction display mode: <Psion-K>
  to "Compress all records before a date" and  <Psion-U> to
  "Update/delete one single record". The effect of any change
  on the final position and average purchase cost is calculated
  instantly.
- when recording a past transaction in foreign currency, a
  specific exchange rate can now be used (different from the
  last in data base)
- one can now create/open/edit one  memo file for each
  account <Psion-+>.
- Internal Rate of Return (IRR) can be calculated, for the
  investment in one share in one account.
- change in the "detail of quotes" account display screen:
  date of last quote is now shown in the last column, instead 
  of net value of the line (now shown in the "capital gain"
  display mode only). In this display mode one can now update
  last quotes directly, without calling <Psion-Q>: press
  <Enter> to update the quote of the highlighted share.
- the name of shares deleted by "Housekeeping" are kept in
  a separate archive file, if they still exist in transaction record
  history files (no more "??" in the report)

Version 1.2
- it is now possible to record and display the history of the
  total Net value of each account (graph).
- two additional commands in the "Account" menu card:
  "Dividend/Expense" and "Cash transfer". A "Cash" option
  can now be switchd ON and OFF for each account separately
  (see corresp. Help sections).  The menu was redesigned
  accordingly: added a "Summaries" menu card.
- exchange rates can now be updated in the same window
  as quotes (Psion-Q command): currencies are at the bottom
  of the list of shares (Ctrl+PgDn)
- change in the selection mode for a share sale: the share
  selected is the one, which is highlighted in the account
  display screen when <Psion-S> is pressed (no more selection
  window, and no more"blank window bottom" bug, when there
  was more than 12 lines in the account...).
- the latest version of Plotuw8 is included (v.1.2c)
- automatic update of history graph: if the date of this update
  is equal to the date of the last record in file, the last record
  is updated (it was not the case before)
- added in "Preferences": proposed starting date for reports
  on transactions (either 1. Jan 1980 or 1. Jan current year).
  Note that this date can always be changed by <D>.
- Ctrl-PgDn/Ctrl-PgUp (bottom/top) now work in all windows.
- bug corrected: now every account opens with first line
  highlighted
- bug corrected: problem in sorting the base when updating
  several tickers in the table

Version 1.1
- new screen in "account display" mode, showing for each
  share: amount invested, potential capital gain/loss (in value
  and in percentage of investment), and net value of the line.
- the first screen displayed at startup can be specified in the
  "Preferences" menu.
- new screen: history of transactions in one account. The
  first "card" of the main menu has been changed accordingly
  ( <Psion> command keys changed). It is also possible to
  show all transactions in one account for one share only.
