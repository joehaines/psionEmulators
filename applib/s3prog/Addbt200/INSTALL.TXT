#Addbit 2.00 - OPL .PIC file bitmap#
#appending application.#
#February '97#

The requirements for v2.00:
     Psion 3a.
     20K of disk-space.
     11K of system memory.
*These are the start-up requirements,
they may change during run-time.

Updates from v1.05
     *No bitmap limit
     *Menus edited
     *Diamond views renamed
     *Scrollable view mode
     *Can now add to files already
      containing bitmaps
     *Help updated
     *No longer requires help.opo
     *.ins file now a .ini file that
      saves preferences
     *Status window now toggleable
     *Much faster bitmap appending
     *Some changes to keyboard controls

You will need the following files:

Addbit.opa - Application
Adbthlp.rsc - Help resource (Optional)
Install.txt - This file
*NEW* Addbit.opl - This is the source
                   code (Optional)

To install:

(If you installed a previous version,
first delete ALL the old files, and
then proceed as below.)

	Place ALL the files in the required
directory (eg APP).

	Install addbit.opa from the system
screen (Install from Apps menu or
Psion+I hotkey).

	Start Addbit with either the default
filename, or use Newfile from the File
menu on the system screen (or Psion+n).

	This will create a subdirectory called
\Addbit\ and move all the files (except
the opa) into it.  It will also create
\BIT\ in the root directory as the
program's main directory.

	Once the program has intalled, you can
remove \Addbit\ subdirectory, and all
the files contained if you need.  I
would recommend you keep the help
system until you are familiar with the
program.
