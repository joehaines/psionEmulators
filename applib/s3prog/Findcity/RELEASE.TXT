FindCity (Series 3 or 3a)

A tiny OPL program which searches the dialling information in the
World database via the WLD: device driver.  The user interface isn't
so great, but the program is intended mainly as a demonstration of
accessing this device driver.  The program is very slow because the
WLD: driver does not support direct lookup by dialling codes, so an
exhaustive search is required.

John Naylon.
