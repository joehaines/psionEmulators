 Installation:
 Windows
  PsiWin software can be used to install the application, simply drag and drop the (hold 
down CTRL on the keyboard so you JUST COPY) "APP" folder to the Psion drive of 
your choice.  Then choose "install" from the Apps menu in the System Screen.
 
 DOS
  Start the RCOM software and type the following:
   CD\NAGMAKER
   Naginst I: (That will install onto the Internal drive, or type L: for drive A, or R: for 
drive B)
  It will run a batch file that will install the full application to the drive of your choice. 
Then choose "install" from the Apps menu in the System Screen.
 
 Macintosh
  Using PsionLink, just drag and drop the "APP" folder to the Psion drive of your choice.  
Then choose "install" from the Apps menu in the System Screen.
 
 Application files:
NagMaker consists of several files:
\APP\NagMaker.opa     the application
\NAGTEMP\PSINAG.OPO    the plug in module you distribute with your app
