
LOG-IT! 6.03 Installation Instructions:

Directories needed for LOG-IT!
         \App
         \App\Logit
         \Dyl

þ Copy the Logit.opa file to any \App Directory
þ Copy the Pelican.lib, Logit.rzc to any \App\Logit Directory.
þ Copy the Scrprnx.dyl to any \Dyl directory.

Note: The Loghelp.rsc file from earlier versions can be deleted.

þ The Timelink.plg is a Banker Plugin, so if you aren't running Banker, you
  don't need to install it. If you are running Banker, copy the Timelink.plg
  file to any \app\Banker\plug directory.
