     ABOUT LOG-IT! / Getting Started                                   0-1
     ÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄ

     LOG-IT! times, tracks, and logs multiple events of all kinds.
     Billable events, such as international and long distance telephone
     calls, on-line computer services, time-charged consulting services
     (your attorney, for instance), and many more events can be tracked
     easily using up to six (6) simultaneously-running timers. Event/Client
     Database to store frequently-used names and their hourly billing rates.
     LOG-IT! now has a CountDown timer for those of you that are cooks.

     LOG-IT! can log entries to an unlimited number of log files,
     containing date, event, accrued time, billing rate, total charges,
     and comments.  Flexible billing times displayed in either the
     international "[00:00] Hours and Minutes Format" or in the popular
     "[02.30 Hrs] Fractional Hour Format" (used by attorneys, consultants,
     etc).  Entries can be easily posted to appropriate accounts in
     BANKER 2.0 for expense management or client billing using the
     supplied plug-in utility.  Log report printing to either printer or
     text file (readable by Psion Word) for editing later.

     But wait, there's more!  Pilots, business travellers, motor car rally
     enthusists, and anyone who requires "lap" or "leg" timing of their
     trips or road races will love LOG-IT!'s six (6) simultaneously-running
     timers.

     And, of course, everything that you would expect from a fine Pelican
     Product -- Pull-down menus, full Psion 3a interface, help screens,
     and of course Pelican's FREE TECHNICAL SUPPORT by telephone, fax, or
     international email from any where in the world!

     If you're a busy professional, you need LOG-IT!


     Getting Started
     ÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄ

     When you first start LOG-IT! you will see the six timer windows. Move
     between the six windows by pressing the left/right arrow keys. To
     start a new timer, just highlight the Timer window you want, and
     press Enter. A dialog will pop up that says "Start Timer x". (x is
     the number of the timer window.) Fill out the info and press Enter.
     You've started a timer running.

     When you're ready to stop the timer, highlight the timer window you
     want, and press the delete key. You have the option of adjusting the
     date, description, and hourly rate if you are logging the timer
     entry.

     COUNTDOWN TIMER                                                   1-8
     ÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄ
     Start New Timer - Choose type Countdown

     LOG-IT! now has a CountDown timer so that you can have a timer count
     down instead of tracking time. There is no menu command for starting
     a CountDown timer. You can start a CountDown timer by starting a timer
     in the normal way. When the new timer dialog comes up, choose "Timer Type"
     of "CountDown", and not "Normal". Choose a database item, or enter a
     new description. Press Enter. Next, choose the time for the timer, and
     the Sound you want to use. LOG-IT! will play the sound you choose when
     the time is up.

     Note that when you start a CountDown timer, a much bigger window opens
     up to display the amount of time left. You can press the menu key for
     options. Press Escape to minimize the big CountDown timer window. When
     viewing a CountDown timer in the smaller timer window, you can press the
     tab key to expand the timer window.

     as many items as needed.

     SET PREFERENCES         SECTION 4 - Special                       4-1
     ÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄ
     Psion<Q>

     The preferences dialog has a few options to set.

        ş Favorite View                                Timer,Log
        ş Allow More Than One Active Timer             Yes,No
        ş File to Open When Entering Log View          Default,Last Logged
        ş Prompt for filename when logging to file     Yes,No
        ş Add new Timers to Database Automatically     Yes,No

     ş The First option sets your favorite view, Timer or Log. This forces
     LOG-IT! to open your favorite view at startup.

     ş The Second option - "Allow More Than One Active Timer" lets you decide
     how many timers can be running simultaneously. When you choose to NOT
     allow more than one, LOG-IT! will pause all timers when you start a new
     timer, or resume a timer.

     ş The Third option lets you choose which Log file to open when going into
     the Log View. Choosing "Default" will tell LOG-IT! to always open the
     default log file. (Timerlog.log). If you choose "Last Logged", the last
     file that was logged to will be opened by default.

     ş Choose the Fourth option when you want the ability to save the timer entry
     to any log file. This is useful when you already have multiple logs
     created and want to save the timer entries directly to a certain log.

     If you don't choose "Yes", LOG-IT! will automatically save timer entries
     to the file called "Timerlog.log", which is the default log file.

     ş The Fifth option tells LOG-IT! whether or not to auto save new Timer
     info to the database. It does this when you start a new Timer. If
     you've got all of the items in your database that you want, whether
     entered manually, or automatically, set this to "No" and no more will
     be saved.

     ABOUT LOG VIEW           SECTION 5 - Log View                     5-1
     ÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄ

     The Log View is where you go to view your saved timer entries. When
     you choose to stop a timer, you have the option of logging the data
     to file. Choosing the "Log to file" option will save the data to the
     Log file. If you want to be prompted for a specific Log file when
     stopping timers, make sure you set this in the preferences. The option
     is called "Prompt for Filename When Logging to File". Set this to "Yes".
     This will force Logit to ask you for a specific file to save each timer
     to. If this is not set, Logit just saves timers to the default file called
     Timerlog.log

     After you've logged a timer, press the diamond key to open the Log View
     where you can view or print your saved timer entries. If a saved entry
     has comments attached, you will see the small flipped page icon to the
     left of the entry. Press the space bar to view the comments.

     Note that you can resize the status window when in the Log View by
     pressing Control<menu>. The "Start Time" field only shows when the status
     window is completely closed. There is not enough room for it otherwise.

     Note:  Special hotkey - Psion<spacebar> will open the default log file.
     This is helpful when you have a different log file, and want to jump back
     quickly.

     One of the more powerful features in the Log view is the ability to set
     a viewing filter. Choose "Set Filter", or Psion<F> to go to this option.
     From here you can tell Logit to display the total time and charges of
     the items meeting your criteria. You can set the view by date, or by item
     name. See the section on "Set Filter" for more on this.
