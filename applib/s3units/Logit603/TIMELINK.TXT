                      Timer Link Plugin for Banker 2.x
                            by Wolfgang Schirmer


Timer Link is a Plugin that works with Banker 2.x only. It provides support
for the LOG-IT! application from Pelican.  LOG-IT! is a Time tracking program
completely separate from Banker. However, through Banker's Plugins and
Timer Link, you can access the data in LOG-IT!, and bring it into Banker.



INSTALLATION:

_ Copy the Timelink.plg file into any \App\Banker\Plug directory on your S3a.
_ Run Banker
_ Open an Account (This Plugin won't work from the Account List View)
_ Press Psion<W> to bring up the Plugins menu
_ Choose Timelink, and press Enter
_ Select a LOG-IT! Log file to open, and press Enter
_ This brings up the Log. Select a Log entry (Enter) to save as a transaction
_ This brings up the New Transaction dialog

  From this point it works like Banker. Press Enter when you're done filling out
  the New Transaction information, and it is saved to your current open account.
  Your balance it adjusted.

_ After adding the new transaction you're asked if you want to delete the entry 
  from your LOG-IT! logfile.
