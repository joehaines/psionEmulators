***********************************

Installation:

Copy the met20eng.opa and met20eng.hlp file to any directory on your 3a and install the .opa in the system screen. You don't HAVE to copy the help file, if you want to save disk space. Both files have to be in the same directory.

***********************************
Program description:

Indispensable fully featured metronome for professional musicians (written by professional musician!)

Beeps in any tempo with two user-configurable pitches of variable lengths.

Also includes a tuner which accurately plays a note of any pitch and duration.

Settings are saved on exit.

On-screen visual display for silent use. 

Screen-off facility to reduce battery use.

Built-in help screens.

German version (MET20DEU.ZIP). 
English version (MET20ENG.ZIP).

The Author is a professional bassoon player and computer-freak from near Mainz in germany. I startet writing OPL-programs shortly after I bought my 3a in May 1994. Before that I had only rather little experience in QBASIC. The first metronome version was written in september 1994, with very basic functions and not exact at all. In the following year I did some improvements and gave the program to some friends. In summer 1995 I decided to distribute it as shareware, because there seem to be very many musicians out there using the 3a. But before that I had to make it a bit more user-friendly (online-help, menu) and write an english version. It took me hundrets of hours to make the program what it is today (the source code is now 33KB large). Version 2.0 is the first public release.

If you like the program or if you hate it, please let me know. I am very interested in your opinion. And: Please do register.
