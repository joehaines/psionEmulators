PIANO20.OPA
-----------

This is a playable, recording, mini-piano for the 3a.

Copy the file piano20.opa to any /APP/ directory on your
Psion 3a. Install from the system screen, using Psion-I.

When the program is first run it will create a /PNO/ directory
on your internal drive, and save its first file: piano.pno.


HOW DOES IT WORK?
-----------------

The piano keyboard is mapped to the top 3 rows of the Psion's
keyboard. Some notes are played using shift (or Caps Lock).

Press the diamond key to toggle the display of a keyboard template.

Press Tab to begin recording. This will always overwrite any
existing recording. Press Enter to stop recording and play it
back.

Esc will stop either recording or playback.

Use the file menu (Psion-N, Psion-A and Psion-O) to create new
files for recording, to save the current file under a new name,
or to open an existing file.

Press Psion-D to alter the duration (or "sustain") of the notes.

Press Psion-M to toggle the animation of the keys. Turning the
animation off will make the keyboard more responsive for fast
passages.

This version of Piano is not affected by the system screen sound
settings.

Pressing a note will now interrupt the previous note. To cut a
long note off, press any "silent" key, such as the space bar.

Press Help for Help.
