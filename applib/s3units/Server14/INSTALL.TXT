
Install the *.opa file into any \App directory

Install the .drv file into any \App\Aserver directory.

If you already have Sound OFF, you can copy the Sndoff.dbf file into the
\App\Aserver directory. Server 1.3 is backward compatible with
old SndOFF data files.

Note that the new Server 1.3 incorporates the Pelican Alarm Server, and
Sound Off in one program.
