
Whats New in Server 1.4 -

1. One bug fix - Server was choking bringing in day entries with large messages.


Whats New in Server 1.3 -

1. Server was removing old alarms without repeating the ones that were
   repeats. This has been fixed.

2. New Preference - "Turn Machine Off when Setting Sound" turns the machine off
   each time SoundOFF sets the sound. The tradeoff is that if you're using the
   machine when this happens, the machine will power down anyway, and you'll
   have to press On to turn the machine back on.

3. Added feature - Force Repeat under the Alarm Menu heading. This forces an
   alarm to repeat.
