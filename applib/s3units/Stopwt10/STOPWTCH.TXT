StopWatch v1.0 Jun 1996
=======================

Introduction
------------

StopWatch is a simple OPL program for the Psion S3a to time
events to a resolution of up to 10mS.  It behaves as a start/
stop stopwatch.  Up to the last 8 lap times can be displayed
on the screen as the clock is running.

StopWatch may be freely distributed.

Installation
------------

The distribution contains two versions of StopWatch: StopWatch.OPO and
StopWatch.OPA.

If you want StopWatch to appear with its own icon, copy StopWatch.OPA
to the \APP\ directory on any drive, and install it on the system
screen using Psion-I.

If you want StopWatch to appear under the RunOPL icon on the system
screen, copy StopWatch.OPO to the \OPO\ directory on any drive.

If you want on-line help, copy the help file STOPWTCH.RSC to the
\OPD\ directory on any Psion drive.


Operation
---------

Launch StopWatch by selecting its name under its own icon (StopWatch.OPA)
or the name "StopWatch" under the RunOPL icon (StopWatch.OPO) on the
system screen and pressing <Enter>.

The StopWatch screen features a window showing the current reading,
with several "buttons" under it to remind you of the keyboard
shortcuts to the most common operations.  The right-side of the
screen shows a table where any latched lap times are displayed.

Press Space to start the clock running.  Pressing Space again will
stop the clock.  A third press will zero the display and start the
clock running again.

While the clock is running, Enter will latch the current value into
the lap table, without stopping the clock.  Diamond toggles the
display between hh:mm:ss.ss and ssss.ss formats.

See the on-line help for more notes.
