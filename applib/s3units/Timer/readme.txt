Timer provides a large elapsed and countdown timer display. The time remaining is also displayed as a percentage and visually with a sliding bar. When used as a countdown timer, there is an optional alarm accompanied by a highly visible flashing display. Very handy during presentations, phone calls, etc. ZIP contains both 3a/3c (Timer.opa) and now Siena (Timers.opa) versions. Freeware from Pimlico Software.
