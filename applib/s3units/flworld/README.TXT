README for FlWorld.zip

The contents of this archive form a freeware application, "FlWorld",
for the Psion Series 3a/3c and Acorn Pocketbook II machines.

Before using this software, you should read the file FlWorld.txt fully,
which contains the conditions of use and important instructions.

Note: FlWorld was previously known as HexClock. Existing HexClock users may
use their old *.hcl setup files by moving them into \APP\FLWORLD\.

Thank you for using this software.
