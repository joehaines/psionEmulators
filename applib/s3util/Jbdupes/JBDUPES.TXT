                               JBDupes
                             Version 2.0
                           (c)JBSoft 1993-7

JBDupes is a program to identify Duplicate files and give the option
to delete selected files for the S3a & S3c.

Installation
------------
The program is run from any directory on the Psion - normally this
would be the \OPO\ directory but this is not mandatory.

Usage
-----
When initially started an option to select the SSD Drives to check is
given - more than one may be selected at a time and the drives
selected will all be searched at the same time so that duplicate files
on different drives will be found. Once this selection has happened
you are then given an option to include the filename extension in the
search otherwise only the filename will be used as a match.

The program will then make a list of all the files on the drives and
then do a sort on the found files before doing a comparison for
duplicates. The comparison only works on the filename and not on
contents.

After this correlation is made a list of files that meet the
comparison requirements is shown. At this stage various actions can be
taken.

Found list options
==================
Mark files  Space/Enter
----------
Files can be marked by pressing Space or Enter (Enter will move the
cursor down to the next line).

Movement
--------
To move up and down the list use the cursor keys in the normal way.

View data in Word  Shift-Psion-V
-----------------
It is possible to view a file using the Word utility by positioning
the cursor on the required file and pressing Shift-Psion-V - the Read
only attribute will be set before opening the file in Word so that
changes can't be made to the file.

View data in Hex viewer  Psion-V
-----------------------
This command enables the data to be shown in a Hex viewer.

File information   Psion-I
----------------
The size, date and time on the files can be gained using Psion-I -
this will give information on the currently highlighted file and the
next file.


File comparison  Psion-C
---------------
To compare the contents of the current and the next file use Psion-C -
this does a byte comparison and also takes into account the lengths of
the files.

N.B. The Psion-I and Psion-C options will only work on the highlighted
     file and the file following. If the cursor is on the last file of
     the list then the option does not work.

Delete marked files  Psion-D
-------------------
Once all files requiring deletion have been marked you can delete them
by using Psion-D. After the deletion has taken place you will remain
in the filelist. You may, if you wish, mark further files for deletion
at this point.

Exit Program  Psion-X
------------
To end the program use this key combination.

N.B. Once the program has been exited the selections made are lost and
     the whole process will have to be restarted as nothing is now
     saved to disk for later reloading (unlike with version 1).

Save List  Psion-S
---------
The duplicates list can be saved for viewing at a later time in Word
by using Psion-S - this will prompt for a filename, a path may also be
entered at this point. This list cannot be reloaded into JBDupes as
the format is changed when the save takes place.

Recoverable Information  Psion-H/Psion-M
-----------------------
The amount of space recoverable on the individual drives is shown
using Psion-H. The total space recoverable is shown with Psion-M -
both these methods only worked on the marked files.

Total number of files found  Psion-T
---------------------------
The total number of files found on the drives searched is shown using
this key combination.

There are limitations to this program due to memory constraints. These
are:

Maximums
________

     1000 Directories
