This program will allow you to make a screen dump to a printer.

It is therefore useful for printing out graphs in the spreadsheet.

TO USE THE PROGRAM:

Copy the OPO file onto the internal disk or an SSD in \OPO\

Start the OPO, and you will be returned to the system screen.

Now bring your graph, or anything else onto the screen, and press
CONTROL-SHIFT-PSION-S

A dialog will asked which type of printer you are using, and which type
of port it is attached to.

Now... just wait.  Printing can take a while, so you may like to use
other applications whilst you're waiting.  In fact, if you re-enter the
application you are printing from, you can even use that application as
well!
