               PsiOn - V2.2 - By Paul Hargreaves
               -----------------------------------

  This file is only of use if you are upgrading from a previous
  versions of PsiOn.
  New users please take the time to carefully read Psi-On.TXT.

  This file only contains information about the upgrade from version
  2.1 to version 2.2. 

  When upgrading from version to version of PsiOn, sometimes there are
  major functionality changes. The changes between 2.1 and 2.2 are
 
  Completely new pause mode. Now takes it's defaults from parameters
     rather than trying to work it out for you. It also allows you to
     to pause for several days at a time.
  Agenda control mode can now start your chosen agenda if it isn't
     running.
  Various minor dialog improvements.
  Psion-1 hotkey now works on the Siena.
  Arm Now hotkey dims the screen when Agenda is busy.
  Bug fixed going from Switched Off Time mode to Pause mode shouldn't
     change the default Switched Off Time.


  Points to note:
  1. The format of the settings file has changed. If you wish PsiOn to
     remember your old settings, there is another program which needs
     installing into the APP directory called Psi-OnUG.OPO. PsiOn can
     automatically delete this when it has been used.

  2. I've rewritten the Pause mode for the last time (honest!). You
     now have a menu option which allows you to choose the settings
     and Psion-P works from those every time. It is likely that your
     old setting will be lost. Please check this.

  3. The Agenda Control options have been moved around, and are now
     in two menus. You can also have PsiOn start your Agenda if you
     want.
