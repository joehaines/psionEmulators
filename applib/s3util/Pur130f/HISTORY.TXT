PUR history
_______________________________________________________________________________

  * indicates a bugfix
  + indicates a major change
  - indicates a minor change

V1.30F
  * fixed bug that crashed PUR if \WVE\ was not present
  + more comprehensive memory info screen
  + New option to automatically record to drive M: if the chosen SSD is not
    ready to take recordings
  + therefore all drives are scanned for memos and included in the list, those
    that are not on the current recording drive marked with an appropriate
    symbol
  + Changed registration method (key instead of module)
  - faster graphics!
  - adjustable minimum free space on internal drive
  - an icon shows the current recording drive
  - if you accidentally run into recording mode on power-up, you now can press
    the Psion-key to prevent recording and just switch on
  - progress bars are now shown while deleting multiple memos, playing and
    recording
  - Key ? tags all new files, key ! inverts tags, + tags and - untags current
    memo. END key now works.
  - memo length bar now relative to longest recorded memo
  - INI-File can be placed on any drive (A/B/M)
  - Automatic save of setup now optional; menu item to save setup immediately

V1.20F (June 27, 1996)
  * fixed a bug that prevented playing a memo when it was chosen from the
    system screen
  * fixed some bugs (sorting algorithm didn't work properly, ESC-check
    setting got 'lost' after leaving the dialog with ESC)
  - changed menu layout
  - added display of remaining time while recording
  - added menu item to manually update the memo list
  - changed header look
  - added status info (number of memos, sort order)
  - added option to change the look of the volume selectors

V1.11F (June 9, 1996)
  * fixed bug that crashed program if memo directory was not present at
    program start
  + no library file needed anymore!
  - added option to specify naming conventions
  - number keys now change sort order (registered users only)

V1.10F (May 24, 1996)
  * fixed problem with bar indicator (now relative to max. recording time)
  + changed application type to 2, to allow playing of memos directly from
    system screen
  + added row cursor and so improved selecting memos to play/delete
  + File date/time now shown in system-specific format
  + added recognition of 'new' memos and appropriate handling features
  + added on-line help
  + after adding so many features, made it shareware, registration allows
    access to the following (new) features:
  + files are sorted (order selectable)
  - Changed initial directory for power-up sound to \WVE\
  - Option to chose between internal power-up sounds and external file
  - New option "ESC-check delay"
  - Memory dialog (used space by memos / recording time available)
  - option to change how power-up sound playing is handled depending on how
    you switch on
  - added 'locking' feature

V1.05F (April 7, 1996)
  * fixed bug that BWB-Lib was not found when installed on a different drive
    than the main program file

V1.04F (April 3, 1996)
  * fixed bug with automatic screen update in coherence with some menu commands

V1.03F (March 31, 1996)
  * fixed bug with 'to background' function
  - added automatic screen update after foreground event

V1.02F
  + first official release
