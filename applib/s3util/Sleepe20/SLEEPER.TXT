[SECTION ONE]     ABOUT SLEEPER

Sleeper is a shareware application written for the Psion Series 3c, and
only for the backlit model. It won't run on non backlit models. The
function of the program is to more intelligently control the
backlighting on the S3c, and to provide a simple night clock.



[SECTION TWO]     INSTALLATION

To install Sleeper you only need to copy one file to your Psion.

    Sleeper.opa

. Copy this file into an \APP\ directory on any drive of your Psion.
. From the system screen, press Psion-I to install the Sleeper application.

CTL file: - The sleeper.ctl file is an installer file for use with PsiSetup,
Psion's new installer that comes with PsiMail. If you don't have PsiSetup,
this file is of no use.

[SECTION FOUR]     OVERVIEW OF PROGRAM FEATURES

Sleeper is a program that hopefully anticipates the kinds of ways most
users will use their backlighting. For example, it makes sense to use the
Psion as a night clock now that it has a backlight, but there are at least
three problems that come up immediately.

    1. What if sleeper (the clock) is not in the foreground?
    2. I can't find the Psion-space bar to turn the light on.
    3. I can't find the Psion-Off combination to turn it off.

Sleeper handles each one of these situations in it's preferences. First,
Sleeper is itself a clock. It displays the time, date, and week number. The
time can be displayed in analog or digital format.

Next, Sleeper has a preference that will bring itself foreground after a
certain hour at night. This guarantees that at night when you press the ON
key, Sleeper will be in the foregound.

Now that Sleeper is foreground, how about some light to see? No problem.
Sleeper automatically turns the backlight on so that YOU don't have to.

Ready to turn the light off and go back to sleep? Just press the space bar
and Sleeper will turn off the Psion.



[SECTION FIVE]     PERMANENT BACKLIGHTING

There may be times, like in the evening, that you want the S3c backlighting
to be on at all times, so that you don't constantly have to go to the
settings to change it back and forth. Sleeper handles this in the preferences
with an option called "Backlight always on - (During specific hours)"

Choosing this option lets you tell Sleeper that after a certain hour in the
day, or night, you want backlighting to be on at all times. This way if you
find that after 7:00 at night you typically need backlighting all the time,
just tell Sleeper to do this for you. When the specific hour arrives, Sleeper
will change your system settings to keep the backlight on.



[SECTION SIX]     BACKLIGHT ON AT POWERUP

Another convenience setting in Sleeper is the ability to set Sleeper to
turn your light on every time the machine is powered up. Alternatively, you
can tell it to only do this when permanent backlighting is On. For example,
if you have set Sleeper to turn permanent backlighting on after 8:00 at night,
this doesn't mean that the light will automatically come on when you turn the
machine on. You would still have to press the Psion-space keys to get the
light on. With this feature in Sleeper, you never need to turn on the light
when turning on your Psion.



[SECTION SEVEN]     BACKLIGHT ON IF EXTERNAL POWER ON

If you want the backlighting on when the AC (Mains) adapter is connected, set
this to "Yes" in the preferences. This wasn't working correctly in earlier
versions, but is working correct now. Note that the machine should be shut
off before pluggin in the power cable. When turning the machine back on
Sleeper will detect the presence of external power and change your backlight
settings to turn lighting on all the time. When you unplug the power cable,
Sleeper will set the backlight settings back to your normal settings.

Note: This feature only functions after registering



[SECTION EIGHT]     BRINGING SLEEPER FOREGROUND

Use this option to force Sleeper to the foreground after a certain time at
night. This option is made for using Sleeper as a night clock. This way
when you press the On key at night, Sleeper will always be in the foreground.



[SECTION NINE]     DEFAULT AUTO SWITCH OFF

This is used to tell Sleeper how to set back your normal backlight settings
when permanent backlighting is not on. The S3c doesn't remember your last
auto switch off amount, but Sleeper does, and therefore doesn't need to ask
you.



[SECTION TEN]       SPECIAL KEYS

    Enter           Toggles clock type
    Space bar       Turn machine off
    <->key          Hotkey for preferences
    Help key        Brings up this hotkey list.
    Psion shift-X   Exits with out warning

    Note: Press the help key while in the preferences dialog to bring up
    a reminder help screen about the various options.



[SECTION ELEVEN]     Special Help

While in the preferences, if you can't remember what each setting does, with
the preferences dialog open, press the Help key.



[SECTION TWELVE]     Troubleshooting conflicts

Sleeper no longer captures the OFF key, so it should not conflict with any
other programs.
