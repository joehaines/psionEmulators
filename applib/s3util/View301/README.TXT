FILENAME: Viewer.opa

INSTALLATION:

    Copy the viewer.opa file into any \App directory on your Psion.
    Press Psion-I from the system screen to install it.


ABOUT VIEWER:

Viewer.opa is a simple pic viewer for the S3a. It is a S3a application that
will display a filelist under it's icon on the system screen. Install it like
any other S3a app, using Psion<I>.

If you want it to use a directory other than \PIC, create an alias (new list)
from the system screen. (Psion-e)

Viewer will show all pic files in any \Pic directory. Highlight the pic file
you wish to view and press Enter. Press menu to view program options.

Viewer will auto detect the boundaries of the image.
