World Time v0.06B
=================

This utility displays 8 clocks for cities around the world, together
with a large clocks for the current home city. The times are
correctly set from information from the World database and the system
summertime settings

The program allows you to set one alarm for a time in another city,
useful if you arrange to phone somebody in another part of the world
at a certain time their local time

Copy Clocks.app into any \APP directory and install as usual

Menus:
------
Set alarm             - sets an alarm for a given time in a given city
Cancel alarm          - cancels the alarm, if it has been set
Set Preferences       - sets the clock type and sort order
Set clock             - sets a city for a given clock
Calculate             - lets you calculate home time for a given
			city time, or vice-versa

To change a clock city, select Psion-s. Select the title of the clock
you wish to remove and select the city to replace it with. You can
enter a title for the clock, useful for long city names. The title
will default to the city name

The clocks can be displayed in various orders: manual, alphabetical,
or by increasing or decreasing offset order

The clock type, sort order, cities and clock titles are stored in the
file \OPD\clocks.dat. This file will be created on the internal disk,
and can then be moved to any other disk. Remember that storing this
file on a Flash disk will use up extra disk space every time it is
rewritten
