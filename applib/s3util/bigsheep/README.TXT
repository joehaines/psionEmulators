*What is Big Sheep?
Big Sheep is a suite of small utilities for the Siena, which do stuff
missing from the Siena's ROM

*What's new?
v1.12
Creates prefs directory automatically.
Bug in lines on "Time Between" on S3x fixed.

v1.11
Bug fixes in Time Between/Add Time. Various S3x specific tweaks.

A whole 120 days (Worked out with Big Sheep) after v1.0 was released, came v1.1
v1.0 was badly programmed and badly designed. This version has had most of the bad bits replaced or removed. Graph is now an entirely seperate application.
It is also now Series 3a/c/mx compatible.

*What does it do?
REAL-TIME Unit Conversion (Area / Energy / Length / Mass / Pressure / Speed / Temperature / Volume), uses <25k disk space, Stopwatch, Countdown Timer, Tally Counter, Relative Alarm Setter, Picture Viewer, File Mover/Copier, Currency Converion, Number Base Conversion (Hex/Dec/Bin), Date/Time Addition, Name Days of Week, Calculates Days/Time between 2 dates/times, System Information, Graphical display of disk space, Battery Warnings, Configurable keys, No Psion key
required, Redo last action and on-line help.

Suggestions for extra features are welcome.

*Installation
Put BIGSHEEP.OPA into the \APP directory (You may have to create one).

Press Psion-I and select BIGSHEEP.OPA. A sheep icon should appear. 
Select it and press Enter.

*Upgrading from v1.0
Delete all Big Sheep related files, except bigsheep.cfg, register.bs, and Graph files. Then follow the instructions above.

*Quick instructions
(Read the on-line help for more info)

Press 'Menu' to display a full list of Big Sheep's functions.
The keyboard shortcuts do not need to be pressed in conjunction with the Psion key.

Press 'Space' to redo the last function.

Functions from the 'Calc' menu work a bit funny. They will first display 
a dialog. Enter the required info and press 'Enter'. The dialog will be 
reshown with the results attached to the bottom in bold. To exit the 
dialog either press 'Esc' or 'Enter' without changing any info. If info 
is changed, the dialog will be reshown with the results changed 
accordingly.

The disk and battery info is redrawn each time a key is pressed.

*Tech Stuff
Big Sheep requires 40-45k memory free.
