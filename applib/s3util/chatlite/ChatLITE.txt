1) Introduction

   Thank you for evaluating ChatLITE v1. 

ChatLITE is basically a "kid" brother of my FlagShip program CHATTER.
I wrote ChatLITE as a direct result of many CHATTER users requests to
have a program that simply records voice memos, and then plays them
all back in sequence - rather like a traditional Dictofone.
HENCE CHATLITE WAS BORN !!!

ChatLITE is an UNRESTRICTED shareware voice memo program which utilises
the Psion 3a/c's sound capabilities much better than the Psion's built    
in "SOUND" or "RECORD" applications. You will find the act of
recording and playing a voice memo is so much easier using ChatLITE,
as it requires only One-touch recording and playback.

ChatLITE will prove useful for those people who have to take quick 
notes here and there, but do not have the time to tap a written note 
away on the keyboard.
Instead they simply speak the note directly into the Psion, where it is
stored for later retrieval.

2) Installation

The files needed for ChatLITE to work are:
Chatlite.opa - Main application file
Chatlite.pic
Icon.pic 

Install all three of these files into the following directories on the
internal drive:

Chatlite.opa - to the \APP directory
Chatlite.pic - to the \Chatlite directory
Icon.pic - to the \Chatlite directory 
To install the program to the System screen, press Psion-I or go to
the APP Menu and select INSTALL

Once you are in the program, you can record all CHATs to either the 
Internal drive, or the A or B drives, by selecting the relevant drive 
letter in the "Record to Disk" option in the Setup configuration.

4) Using ChatLITE

   - Getting Started

Select the ChatLITE Icon on the System screen, and then press ENTER. An
initial configuration dialog will pop up asking you to select your
default record time, and to which disk you want to record to. Make your
choices, and then press ENTER. 

   - Main Screen

Your are now presented with the Main ChatLITE screen. On the right-hand
side is a "Duration Meter" which shows the seconds elapsed for record 
and playback operations. To the left of this there are two "Info 
Buttons". The top one shows the number of seconds left for record 
purposes. The Info Button below this one shows the number of CHATs in
memory at the current time. Then below all of this, are three BUTTONS.
Press the relevant one for the relevant operation.

   - Recording

To record a CHAT is very simple. Just hold the Psion with the 
microphone relatively close to your mouth and press the TAB key. The
Psion will then beep, signalling the start of the recording. Wait for
the beep to end, and then start talking. The Duration Meter will show 
how many seconds have elapsed. Once the default record time has been
reached, you will hear a slightly longer beep, signalling the end of
the recording. Immediatly after this, the two info buttons will update
themselves with the "Seconds of Recording left" and the "Number of
CHATs in memory".
Alternatively if you want to save space, just press the ESC key whilst
recording, and ChatLITE will stop the recording at that point.

   - Playing

To play a CHAT(s), simply press ENTER. ChatLITE will play all of the
available CHATs held in memory in CYCLE (ie: One after the other). It
will start by playing the most recent CHAT, and the play the remainder
from the "First" to the "Last". Again if you want to stop the Play back
process at any stage, press the ESC key.

   - Changing the Setup (Configuration)

The Change Configuration dialog give you choices on the length of 
record time, as well as which disk you want to record to. 
You must pick a record Time that suits your requirements. I find that 
3 Seconds is a nice time to start off with. Alternativeley you could 
set the record time to 0 seconds, and ChatLITE will determine the 
record time left on your disk, and then use this as the record time. 
Just remember to press the ESC key to stop recording.
The record to disk: option means that you can choose from the 
Internal, A or B drives as your main CHAT Disk. Please note that it
is impossible to record to a FLASH SSD, and if there are any problems
regarding the recording of CHATS to either the A or B Disks, ChatLITE
will automatically reset the default record disk to Internal.

   - Setting an Alarm

To set an alarm press Psion-A or select the "Set Alarm" option from the
special menu. You will be given the option to set the time/date/advance
time of the alarm, as well as adding a caption. 
To view or delete alarms you must go to the TIME application from the
system screen and do it from there.

Please note that if you set an alarm, and then subsequently delete the
CHAT, the alarm will not be deleted as well.

   - File Management Utilities

ChatLITE comes with its own File management utility - Delete.
To delete all CHAT files, press Psion-D or just D

To exit ChatLITE, select the option from the Special Menu, or press
Psion-X

   - Trouble-shooting

Recording Failed:
-Replace batteries - They may be too low for digital recording.
-Flash SSD - You may be trying to record to a flash SSD. This is
 impossible. Use the Special menu (Change Setup) to change to the 
 internal disk or a RAM SSD.

On playback, sections of the memo are silent:
-Replace batteries. Main Batteries are low.

Start of memo clipped:
-Wait a fraction of a second after the beep before you begin speaking.
 Watching the Duration Meter will also indicate when recording has
 started.
