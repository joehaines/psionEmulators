Installing and Uninstalling

Installing

To install Disk Copy, just copy DISKCOPY.OPA into any APP directory.

Next, go to where about in the system screen you want to install Disk Copy, and press Psion and I. Scroll left or right until you get to Diskcopy.opa and press Enter.

Uninstalling

To uninstall, remove the icon, by selecting it, and pressing Psion and /. Then delete the DISKCOPY.OPA file from the APP directory.
