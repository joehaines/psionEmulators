
 ReadMe for Disk Copy 1.1


Introduction
============

Disk Copy is a utility which copies either the Internal disk, or the
contents of an SSD, to a file on either a remote computer, the
Internal disk or another SSD.


Uses
====

Because Disk Copy copies the entire disk, including the File
Allocation Table (FAT) and every single byte of data, you can use
Disk Copy to restore accidently deleted files.

There is a special part of the disk called a file allocation table,
which stores the filenames of all the files, and where about they are
stored on the drive. When you delete a file, this file allocation
table (FAT) is changed slightly, but the data remains on the drive.
If you are act quickly, and you are luckly, no other files will write
over your data, and you can run Disk Copy and copy the contents of
your disk on to a file on an attached PC. Then you can use a hex
editor to search for parts of the file and copy them out.

This also works for Flash and RAM SSDs.


Installing
==========

To install Disk Copy, just copy DISKCOPY.OPA into any APP directory.

Next, go to where about in the system screen you want to install Disk
Copy, and press Psion and I. Scroll left or right until you get to
Diskcopy.opa and press Enter.



Uninstalling
============

To uninstall, remove the icon, by selecting it, and pressing Psion
and /. Then delete the DISKCOPY.OPA file from the APP directory.
