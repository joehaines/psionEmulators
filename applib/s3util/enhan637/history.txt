Alarm Enhancer, Recent History


Version 6.37, April, 1999

Whilst idling in background, the program destroys its windows to save
memory.  This leaves a memory overhead of 11k.

Alarm Killer can be configured for 3 periods rather than just for the
whole day.

The Alarm Killer has been modified to better handle the situation when
an alarm has been snoozed in the Time application.

Modification to the alarm killer timer to increase accuracy.

Change to the configuration program Alarm Killer dialog to retain new
settings when periods dialog called.

------------

Version 6.23, February, 1999

Technical Changes

The procedures for gathering the alarm information from the Time
application have been re-written to better handle both the problem of
task switching and alarms changing whilst Enhancer is reading the
alarms, and the Pason application's rapid on-then-off behaviour.
