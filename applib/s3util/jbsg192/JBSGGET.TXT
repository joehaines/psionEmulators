JBSGGet is a small program that works in conjunction with JBStopGo to
inhibit the stopping of selected applications. It should be run after
JBStopGo has closed down all the running applications.

The first set of options are

     1. Delete
     2. Add
     3. View

Delete allows the deletion from the database of files that previously
had been selected to keep running after JBStopGo has run in its
closedown mode.

Add allows files to be added to the database. Any files so selected
will not be closed down.

View allows the selected files to be shown in order that a decision
can be made on future actions.

The way the program works is that a database of the selected programs
is made using the data created by JBStopGo. In the future, when
JBStopGo is run, this database is compared with the running program
selected for closedown and, if there is a match, the program is
skipped and not closed down.

Two files are used in the running of JBSGGet:

     1. APOPEN.DAT - The file created and used by JBStopGo
     2. JBSGIGN.DAT - The database of files to ignore

These files are stored in the root directory of the Internal drive.
Whilst APOPEN.DAT may be deleted once JBStopGo has reopened the
applications, any deletion of JBSGIGN.DAT will mean that all currently
running files will be closed regardless of whether they had previously
been selected to continue running or not.
