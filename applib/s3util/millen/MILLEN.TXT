
MILLENNIUM CLOCK for the Series 3a/c/mx
by Mike Panchaud

This program will display the number of days, hours, minutes and seconds to or from almost any date and time as a continuous count down display.

Default values are for the next millenium on Jan 1 2000. The date and time can be changed and the ticking sound turned off by pressing the MENU key. When the time has passed, the display counts upwards.

Note: auto switch off is DISABLED when running, even when in the back ground so exit using escape when not required.


Installation
Only one tiny file is needed. Copy Millen.opa to any \APP directory and use Psion I from the system screen to install as normal. The MM (Roman numerals for 2000!) icon should appear.
