บAbout Recycle Bin                             2.1บ
ศอออออออออออออออออออออออออออออออออออออออออออออออออผ

Recycle Bin is a recoverable trashcan for the Psion
Series 3a/c/mx.

It is similar in many respects to the Windows 95
Recycle Bin. All files that are recycled are sent
to a temporary directory on the internal disk.

Recycle Bin is shareware. Please refer to the
section on Registration.

Reverse translation/engineering of Recycle Bin is
strictly forbidden.

บInstallation                                  2.2บ
ศอออออออออออออออออออออออออออออออออออออออออออออออออผ

You can install Recycle Bin by using PsiWin or by
using the automatic installation program supplied.


Automatic installation
======================
  
1.  Run RCOM or PsiWin 2 (or Winlink and enable
    server mode)
  

2.  Copy SETUP.APP and SETUP.INI to
    M:\APP\SETUP.APP. Install SETUP.APP to the
    System Screen. You can delete these files
    when you have installed the program.

3.  Run SETUP.APP and select the source directory
    where the Recycle Bin setup files are located.
  
    e.g. REM::A:\RECBIN\  (Your PC floppy drive)

4.  Press ENTER and follow the instructions.


Using PsiWin or Winlink
=======================

1.  All files must be installed on the Internal
    disk.

2.  Copy the following files

    Source          Dest.

    RECBIN.OPA ---> \APP\
    EMPTY.OPA ----> \APP\
    RECABOUT.PIC -> \APP\RECBIN\
    RECBIN.DYL ---> \APP\RECBIN\
    RECBIN.RSC ---> \APP\RECBIN\
    RECEXCLM.PIC -> \APP\RECBIN\
    RECEXPLR.PIC -> \APP\RECBIN\
    RECFULL.PIC --> \APP\RECBIN\
    RECICN.PIC ---> \APP\RECBIN\
    RECLIST.DYL --> \APP\RECBIN\
    RECREM.PIC ---> \APP\RECBIN\
    RECREST.PIC --> \APP\RECBIN\
    RECRET.PIC ---> \APP\RECBIN\
    RECSET.PIC ---> \APP\RECBIN\
    RECSTOP.PIC --> \APP\RECBIN\
    RECWARN.PIC --> \APP\RECBIN\
    RECYCLE.PIC --> \APP\RECBIN\
    EMPTY.WAV ----> \WVE\
    RESTORE.WVE --> \WVE\

    RECBIN.RIF MUST NOT BE COPIED OR REDISTRIBUTED

                                
Install RECBIN.OPA to the System Screen. Also
install EMPTY.OPA if you want to empty the Recycle
Bin from the System Screen.

บMenu options (via Meu key)                    3.2บ
ศอออออออออออออออออออออออออออออออออออออออออออออออออผ

TO BIN
======

  Recycle file
  ============

  To send a file to the Recycle Bin use
  the Recycle file option from the menu.


  Delete file
  ===========

  To delete a file FOREVER use the Delete
  file option from the menu.


FROM BIN
========

  Empty Recycle Bin
  =================

  This option will remove all files from
  the Recycle Bin forever and remove the
  M:\RECYCLED directory.

  
  Explore Recycle Bin
  ===================

  If you want to find out what files are
  in the Recycle Bin and where they came
  from you can 'Explore' the bin.

  Files that are displayed in italics
  already exist. If you were to restore these
  files, they would write over the other
  files.
  

  Restore file
  ============

  This option will restore all of the files
  in the Recycle Bin to their original
  positions.
  
  If a directory where some of the files
  came from does not exist it will be
  created.

  
  Remove file
  ===========
  
  'Remove file' sends a file from the
  Recycle Bin to a selected directory.
  
  If the 'Discard file' line is set to 'Yes'
  then the file will just be deleted from
  the Recycle Bin.


SPECIAL
=======
  
  About
  =====

  About displays copyright info etc.

  
  Set Preferences
  ===============

  To customise the Recycle Bin choose
  Set Preferences from the menu.

    Confirm file 'Delete'?
    ======================
    
    Use this to always ask before deleting
    or discarding a file.

    Always ask before emptying?
    ===========================
    
    Use this to confirm emptying the
    Recycle Bin.
    
    Play action sounds?
    ===================
    
    Choose YES to play associated wave files
    to EMPTY and RESTORE operations.
    
    Choose NO to disable sound effects
    
    Choose DEFAULT BEEPS to beep when
    EMPTYING and RESTORING the Recycle Bin.
    
    If a file does not exist no sound will
    be played for that action. This is
    useful for disabling one sound effect
    only.
    
    Set Recycle Bin max. size
    =========================
    
    To allocate a set amount of disk space
    to the Recycle Bin choose YES. This
    will make sure you can only place a
    certain number of files in the Recycle
    Bin at one time. It does NOT reserve
    disk space for the Recycle Bin.
    
    Registered users can set this to 'No'
    
    Max. Recycle Bin size
    =====================
    
    Set the amount of disk space you want
    to allocate to the Recycle Bin. This
    will only work if the previous option
    has been set to yes.
    
    Registered users can allocate more than
    100Kb to the Recycle Bin.
  
  
  Exit and empty
  ==============

  This will empty the Recycle Bin and exit
  No confirmation box will be displayed.

  Exit
  ====

  This will exit Recycle Bin

บUsing the Recycle Bin from the System Screen  3.3บ
ศอออออออออออออออออออออออออออออออออออออออออออออออออผ

You can send a file to the Recycle Bin from the
System Screen. To do so move on to the Recycle Bin
icon and select the file you want to erase, in the
same way you would open a Word file.
You cannot send a list of tagged files to the
Recycle Bin.

To delete a file without sending it to the Recycle
Bin you can still use the DELETE FILE option from
the System Screen.

** NEVER ** delete the M:\OPD\RECYCLED.BIN file.
This file holds the information about the files
contained in the Recycle Bin.

If you erase it, the Recycle Bin will think that it
is empty although in fact it is not.

** NEVER ** remove the M:\RECYCLED directory.
