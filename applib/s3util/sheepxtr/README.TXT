*What is it?
Sheep Extras is a collection of small applications in a single file, 
including a file manager, a picture viewer, a graphical battery monitor, 
a stopwatch, a countdown timer, lots of other things and a few games.

*Installation
Put SHEEPXTR.OPA into the \APP directory (You may have to create one).

Press Psion-I and select SheepXtr.OPA. A sheep icon should appear. 
Select it and press Enter.

Ignore the Plus directory until you register. 
When you do, copy the contents of its \APP directory to your \APP directory. Numbers.pic is the Roman font for Sheep Clock, and can be deleted if necessary. Currency.odb is an example currency file. You can also create your own from Sheep Measure, or use it as a starting point. 

*Quick Instructions
** PLEASE look at the online help and menus in each application.
** You will discover lots of new features that you wouldn't otherwise find.

Select an application by navigating the card system. It works in a very 
similar way to the menu system in built in applications. Press Enter to 
run it. Look at the online help if you are having trouble. Also try freeing some memory.

Battery - Set the preferences to change the graph behind 'mAh used'. Bars behind 'On Batteries' and 'On External' represent the percentage of time the Psion has been switched on.
Disk - To accelerate navigation significantly, disable 'Calc dir sizes' in the preferences. Copying and moving files is done using a clipboard style system, similar to Windows 95.
Pic - Displays Psion .pic files. Use Graphic Convertor (Macintosh), or WinPic (PC) to create these.
Task - To exit an application, press Enter to switch to it and exit it manually. You will be automatically brought back to Sheep Task.
Alarm - Use it to set alarms a certain number of minutes in the future, rather than at a fixed point in time.
