TZone

Overview

TZone maintains summer times for all Psion defined
time zones (local, European, Northern and Southern),
and can be used to control the local timezone
in any country.


Installation

The following files should be copied onto your
system :

\opo\tzone.opo
\opd\tztab.dbf
\txt\tzone.txt   [this file, optional]

Data and program files can be placed on any disk.

For a full installation, with PsiWin just drag
the whole directory structure across to the
root directory of the psion, or you can use
PsiZip to extract all files from the zip file
in the root directory.


Using TZone

Startup TZone using the Run-OPL icon.

TZone may be used in one of two modes.

 - It can run continuously, in which case it will
   check for timezone changes whenever the Psion
   is turned on, and when the date changes.

 - Using programs such as AutoRun, it can be
   started once a day when the checks are performed.
   (See 'stop' definition line description below.)


TZTAB File Format

This is a standard tztab file, as found on
many UNIX systems, with the following additions :

 - Definitions have been added for the standard
   Psion zones (European, Northern, Southern).
   These entries are used to maintain the summer
   times for the respective zones as seen in Time.
 
 - A 'default' defintion line which should be
   uncommented so that GmtBst does not prompt
   for your local time zone.

 - A 'stop' definition line which may be
   uncommented to automatically terminate
   TZone after processing. This is used when
   TZone is started automatically every day
   by programs such as AutoRun.
   
 AutoRun
   If AutoRun is being used to invoke TZone, the
   following definition record should be used :

     Name: Tzone
     Program: m:\opo\gmtbst.opo
     Action: Start
     When: Always,Once
