INTRODUCTION

Ths is an application to make it easy to update the Owner Information
display with contact information as you travel around. The program
is pretty simple to use and context sensitive help is available in
all menus and dialogs.

INSTALLATION

To install the application, simply copy the file USERINFO.OPA to
the \APP directory and the USERINFO.RSC (the help file) to the \OPD
directory. These files can be installed on any drive. Then use the
Apps/Install command from the system screen to install the icon
for the aplication.

DATA FILE

The program creates a data file called USERINFO.ODB in the \OPD
directory of the internal drive. After this has been created, you
may copy it to any other drive if you wish.
