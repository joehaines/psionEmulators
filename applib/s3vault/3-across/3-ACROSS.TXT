3-Across Crossword Puzzle
By Martin Newham
CIX mail: mjnehwam

Just a short doc to let you know the back ground & how to work the program.

The program was my first major 'project' for the Psion 3, the basic frame
for a 'self generating' cross word program has been written.

As it stands the program will display 2 windows one with the 'clues' and the
other with the puzzle board. You can flip between them using either the
TAB key or Psion (P)-X.

Currently there is only 1 hard coded X-word, but I had ideas to get the
program to generate new Xwords it self.. mail me if your interested.

Keys & Options

MENU            Obvious

FILE
----
(P)-N           New game/clear board        
(P)-S           Save (not an installed option)
(P)-L           Load    "              "
(P)-P           Print   "              "
(A)-A           About. Tell you version & name
(P)-Q           Quits game

VIEW
----
(P)-X           Shows Puzzle Board
(P)-C           Shows Clue window (bug here, use TAB key)
(P)-D           Deselect clues
                        
      Note: when on the puzzle board, you can
            delect a line by using the up/down keys
            pressing ENTER will select ALL the across
            and down clues for that puzzle board line
            only. (P)-D returns you to the full clue
            list.
                        
(P)-V           View mini-preview of Puzzle board

OPTIONS
-------
(P)-H           Help level      None - Lets you type anything
                                Some - Only lets you type correct Ans.
                                Lots - Fills in a letter randomly
(P)-Y           Print options   (Not installed)
(P)-B           Beeps switched on/off beeps
