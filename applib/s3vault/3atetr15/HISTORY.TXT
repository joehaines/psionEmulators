    5 Nov. 94 v1.0 First public release.

   30 Sep. 95 v1.5 Second public release.
      - "Many-games" crash bug fixed
          Tetris crashed if more than 3 games were played without exiting. It
          was due a bitmap left opened after having used it. Fixed.
      - Two-keys "bug" fixed
          Some users made me notice than  on  the highest levels of the game,
          pressing left or right gave a double move instead of a single  one.
          Fixed, but you have to be very fast!
      - Different game backgrounds
          I  have added different backgrounds that will be loaded randomly at
          the start of the game.
      - Lines to next levels window added
          Now  you  can  see how much lines you have to complete to go to the
          next level
      - Many nag screens removed by request of users
          I received a  lot  of  messages  telling  me  that the starting nag
          screens were too annoying. I left only one at the very start  of  a
          game and one every 2 minutes.
      - Help system improved with Jezar's method
          Now  the  help  system is not interpreted but uses the S3a built-in
          help system.
      - High Score and Help options added in the menus
          A small adding.
      - Challenge Mode
          See TOURNAME.TXT for details.
      - OPL Protection added
          Now the program has been protected with my own OPL Protect program.
          Is it available as  a  shareware.  Please  contact me if you should
          need further information.
      - AICA Sound Compressor routines added
          The meaning of this is in the game documentation.
