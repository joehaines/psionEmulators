3User SCRIPTs History
---------------------

    
Version 2.0 17-February-1996
----------- ----------------

Features
--------

* Added retrieval of recent online charges report.
* Additional switches allow retrieval of each file to be controlled,
  e.g. Files1, Files2, Files3, Bbc1, Bbc2 etc.
* Another script file written by the user can be chained, and controlled
  by a switch, e.g. Internet scripts. 
* Updated to work with new Compuserve menu structures, specifically PAO
  UK-TV menu and Radio summaries.
* Longer timeouts introduced. This will help with slower Compuserve nodes.
* Now searches for scripts on all drives, not just default drive, in the
  order A:, B:, M:
* Readme.txt expanded.
* 3USETUP.OPA setup program for easier setting of switches, and checks 
  that required scripts have been installed.
* Online Guide, guides new users through an online session.   



Version 1.1 04-September-1995
----------- -----------------

Features
--------
    
* Retrieval of online address book, forum files and UK-TV listings.
    
    
Problems
--------
    
* Not very configurable.
* Intolerant of slow Compuserve nodes.
* Readme.txt not very clear - some users have difficulties installing and
                              configuring the scripts
* January 1996 - Compuserve change some menu structures used by the scripts.
