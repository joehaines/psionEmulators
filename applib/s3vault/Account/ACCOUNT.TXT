The Account Program
-------------------

This is an other Account program with a difference.  I have included a WHATIF 
function, this allows you to see how much money there will be left at the end 
of the month (a God send for me).

I have included in this file, under the section Other Functions, a selection 
notes about this program.  You will find the same information and more in the 
help from within the program.

Quick Installation:
-------------------
Install by create a sub-directory ACCOUNT to the directory app on the disk 
you want your to keep your accounts (note the files that are stored in this 
directory are continually updated and therefore a RAM disk or internal disk 
are the most appropriate)  Into the app directory of this disk copy the 
account.hlp file.
Copy the program Account.opa and sys$help.opo into the app directory on the 
required disk (this can be different to the disk used to store the account 
files and could be a flash disk as this files are not changed during use).

Any disk
	\app\account.opa
	\app\sys$help.opo

RAM or Internal disk
	\app\account.hlp
	\app\account\

Other Functions
---------------
Debit
Used to record money removed from your account.
Credit
Used to record money added into your account.
Transfer
This used to transfer money between accounts. 
Edit
Entries can be edited.
Delete
Entries can be deleted.
Standing Order
This menu is for the control of Standing Order and Direct Debits associated 
with this Account.
      New   Edit   Delete   Help
Display-All
This displays all the transactions in table form.
Display-From Item
This displays all the transactions in table form from the selected item Number.
Display-Last 10
This displays the last 10 transactions in table form.
Display-Find Entry
This displays all the transactions that satisfy the search sting within
the Description field.
Password
This is used to change the Password, switch the Password On/Off and to
enter in the registration code.
What If
Here the program produces a temporary Account file and from the Account's 
current balance all the outstanding current month's standing orders are 
removed and the new balance is displayed with a WhatIf label, this will be 
the balance of this at the end of the month.  Amounts can be Debited and 
Credited without affecting the account file.
Reconciliation
This routine is used to mark transaction that have appeared on your
Bank Statement.
File Sort
This routine sorts the account file into date order.
Tidy
This removes all the old entries that have appeared on the Bank statement
up to the selected date.
New Accounts
New accounts can be opened by selecting, form the system screen  
Menu-File-New-(Enter in the file name which will be come the Account name) 
or by using the File-New from the Programs Main Menu.
Opening Accounts
Other Accounts can be opened from within this program. 
Deleting Accounts
Removing old accounts.
