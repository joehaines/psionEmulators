			     Agendax.app
			Instructions for use

1. Using the 3-Link, copy the file 'agendax.app' into a '\APP' directory on any Series 3 device.

2. Quit any Agenda file currently in use.

3. At the System screen, position the highlight under the Agenda icon.

4. Press <Psion><Y>. A window will appear asking you to confirm that you wish to remove the Agenda icon. Press <Y> to do so.

5. Press <Psion><I> to install an application. Navigate to the file called 'Agendax' on the appropriate device and press enter.

6. The Agenda icon will reappear. The application can now be used in the same manner as the old Agenda application.

You may occasionally see, when invoking the Agenda application, the word 'Agendax' appear on the screen momentarily. This is entirely normal.
