------                  [From an original idea by H.Nickol]

APHONE allows you to control your answerphone remotely, without the need
to remember which number controls which function.  (Requires Series3a)

Simply copy the APHONE.OPO and APHONE.DAT into the \OPO\ directory of your
internal disk, or on an SSD. Make an \INI\ directory on your internal disk.

Now start APHONE under the RunOPO icon.

You will need to supply the telephone number of your answerphone, the
remote access code, and the type of answerphone that you have.

Currently supported models are:

                        Panasonic KX-T3400H
                        Panasonic KX-T2727BS
                        Panasonic KX-T1445BS
                        Albrecht II

If you have another model of answerphone, then select 'Unlisted'.  You will
then have to supply (at a later stage) the codes that you use to retrieve
your messages.

Each time you start APHONE, you will have to enter your Access Code.  You
can then dial the number using the Series3a, or skip this option.

If you have specified a code which will 'interrupt' the message text, then
you now have the option to send this code, or to re-dial the number.

Next you can send the access code to your answerphone.

Finally, you may select to hear all messages, new messages, or to
skip this option.

The main program then consists of a menu, with the options available
on standard answerphones.  You can edit the sounds assigned to each
option by changing the 'Settings'.
