ASCII Version 2.50F
_______________________________________________________________________________

ASCII shows a table of all 256 characters available on the Psion Series 3a, 3c
and Siena in all 13 built-in fonts (of course just one at a time) and all fonts
on the ROM:: device, optional in bold (inclusive-)or italics style.

ASCII acts as bring server, i. e. you can bring (Psion-B on English, Psion-J on
German machines) the selected character (or a string of characters) into other
applications that support this (Agenda, Word, Data, Sheet, ...).
Explore ASCII's menu 'Copy buffer' to work with character strings.

Note that only the charcter code and not the visual representation can be
brought into other applications. What the brought character will look like
depends on the current font used by the client application, not the font
selected in ASCII!

Note also, that usually applications do not support the visual use of
characters with ordinal value below 32dec (20hex, space). If they do, this is
the exception, not the rule. For example, the telephone character (5) can be
used in several applications whereas character 13 can not (you'll get a
carriage return, not a down pointing arrow - or whatever).

To install ASCII simply copy the file to your Psion as follows:
  \APP\ASCII.OPA

Note: You do not need my library file "\OPD\BWB-LIB.OVL" any more, please
      delete it if you had a previous version installed.
