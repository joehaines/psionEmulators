ASCII Table
-----------

name:     asciitab.opa
size:     1222 bytes
author:		Andrew Pepper (apepper@cix)

Description
-----------

asciitab displays an ascii table on the Psion 3a. Control characters 
(below 32) are excluded but the extended character set (above 127) is
included.

Use
---

To display the table select the ASCII table icon. 

By default, the display shows the character codes in decimal. This can
be changed to hexadecimal by typing the `h' key. The valid buttons are 
shown at the top of the display.

To leave the application press <psion>X or X.

Restrictions
------------

The program only runs on a 3a.

Bugs
----

The close square bracket (code 93 or 0x5d) has the top line missing(!), 
this seems to be a bug in the Psion font.
