AUKT.ZIP
The Randonneur's Friend
Freeware
V 4.2

AUKT calculates timing controls for long distance cycle rides held under the
International Regulations of Les Randonneurs Mondiaux. All distances are allowed
for with both intermediate control distaces and for the finish control. The
differences in regulations between Brevet Randonneurs Mondiaux and those of
Audax United Kingdom are allowed for as well as for the introductory rides known
as "Brevet Populaire".

The altitude points scoring scheme of Audax UK, (Audax Altitude Award - AAA)
can be calculated. The code for this was kindly provided by Francis Cooke of AUK.


There are three files:

AUKT.OPA - Install in /APP directory on any disk
WESSEX.PIC - Optional, but intall in /PIC directory on any disk
README.TXR - This file

Install AUKT.OPA by using PSION-I
