Banker 2.0 Installation Notes
-----------------------------

This document explains how to install Banker from a non SSD disk. Please read
this document before proceeding. If you received Banker on an SSD, you can
run Banker directly from the SSD by leaving it in one of the two SSD slots in
your Series 3a, or by copying the complete contents of the Banker SSD to
another Solid State Disk.

Banker 2.0 comes with installation procedures to use with Psions Rcom
software, and Mclink. (Rcom is the replacement for Mclink)

MacIntosh users should refer to the file location list in this document for
manually copying files.

File for Installing with Rcom:
        ş Install.bat   Installs to any Psion S3a disk

Files for Installing with Mclink on a PC:
	ş Installm.mcl	Installs to Internal Disk
	ş Installa.mcl	Installs to Disk A
	ş Installb.mcl	Installs to Disk B



INSTALLING WITH RCOM:
---------------------

1. Create a Banker directory on your PC.
2. Copy the Banker 2.0 files to the Banker directory.
3. Run Rcom
4. From the Banker directory, type in Install I:  ( or Install R: or
   Install L: ) based on which directory you want banker installed to. This
   assumes you are using R: and L: to refer to Disk A and Disk B on your S3a.
5. Exit Rcom
6. Upgrading? On your Series 3a, uninstall your old Banker icon. Do this by
   highlighting the icon, and press Psion</>. This is the hot key for removing
   an application. This has nothing to do with copying files. It only removes
   the icon from the system screen.
7. Next on the 3a press Psion<I> to Install application. Change the Disk
   selector to the drive where your new Banker is installed. (A,B, or Internal)
8. Position the file selector to Banker_a.opa, and press Enter. You should now
   see the new Banker icon on the system screen.



INSTALLING WITH MCLINK
----------------------

1. Create a Banker directory on your PC.
2. Copy the Banker 2.0 files to the Banker directory.
3. Run Mclink
4. Use the appropriate above installation procedure based on    
   which Disk you want to install Banker to.
   For example: Installing Banker to an SSD in A, you would type in
   @installa.mcl  (You must include the @ symbol) This is  
   assuming you are already running Mclink. If you have not  
   established a connection, the installer wont work. This
   has nothing to do with Banker. Consult your 3Link manual.
5. The install procedure will copy the Banker files to their 
   appropriate directories.
6. When the files are all copied, you're finished.
7. Exit Mclink
8. Upgrading? On your Series 3a, uninstall your old Banker icon. Do this by
   highlighting the icon, and press Psion</>. This is the hot key 
   for Removing an application. This has nothing to do with 
   copying files. It only removes the icon from the system screen.
9. Next on the 3a press Psion<I> to Install application. Change 
   the Disk selector to the drive where your new Banker is 
   installed. (A,B, or Internal)
10.Position the file selector to Banker_a.opa, and press Enter.
   You should now see the new Banker icon on the system 
   screen.

2. Copy the Banker 2.0 files from the floppy disk to your PC or other desktop.

GETTING STARTED WITH BANKER 2.0

Once installed use the help file for a quick reference to new functions. Look
over the menu options to get acquainted with the new features in Banker 2.0

Use the diamond key to switch between the different views in Banker.

There are some special keys in Banker that are not referenced on the menu, but
this is the exception. The <-> minus key is the hot key for the preferences.

        Ctrl<D> = Balance by Data
        Ctrl<B> = Show Current Balance/Cleared/Outstanding
        Ctrl<E> = Use alternate "Enter Data" dialog (Opposite of preferences)


ABOUT GROUPS

It is helpful when starting Banker 2.0 to understand Groups and how they work.
When you open a Banker file from the system screen, you are opening a Banker
Group, not an Account. A Banker Group, not to be confused with a Psion Group,
is a list of Accounts. You create this list by adding new accounts within the
Group. You can also insert Accounts, which means that you can bring in your
existing Accounts from Banker 1.0 if you're upgrading.


CUSTOM CATEGORIES

Quicken users should start out by importing their category list from Quicken,
and then importing it into Banker. You must have at least one account created
first, so...

        1. Create an account
        2. Export Categories only from Quicken (File menu/Export)
        3. Copy the category qif file that you just created to the \Bank
           directory on your Psion.
        4. Start Banker if it's not running.
        5. Open an account in Banker
        6. Choose "Quicken Options", or press the <Q> hotkey.
        7. Choose "Import" and then "Import Categories".
        8. Find the category qif file you copied to your Psion.
        9. Choose a name for you new Banker category list. (maybe Quicken.cat)
       10. Press Enter to start importing your Quicken categories.
       11. Go back to the account list view. (Psion Shift<A>)
       12. Press Psion<U> on each account, and update the category list to be
           used, changing it to use your new Quicken category list.
