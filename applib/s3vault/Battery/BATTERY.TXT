		BATTERY Wallpapered by Graham Linsky

This is more a demonstration of Windows style
"Wallpaper". The Wallpaper serves some useful
perpose since it gives the batteries some work
to do prior to checking the voltage. The core
program is the work of ROWAN PRIOR of Psion
Tech Suport I did make some slight changes to
get the voltages to read somthing like
accurate (must be a S3 - S3a thing).

INSTALLATION:
only one file to install in an \app\ directory
on any drive and use Psion-I to install on the
system screen.the program uses its own icon to
"paper" using the the system outlined in
