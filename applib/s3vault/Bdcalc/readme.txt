Installation of BDCALC

Simply copy the file bdcalc.opa to any \app directory on your Psion 3a and install it as you would any other application (Psion I).

The program is very straight forward and requires a latitude and longitude to be entered in decimal format, i.e. N5712.3 W00212.3 etc. The results ar great circle tracks and distances. They have been checked by a British Airways 747 Pilot, and appear to be very accurate.
