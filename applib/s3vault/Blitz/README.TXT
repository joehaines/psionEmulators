How to install blitz on an S3a
------------------------------

To install Blitz copy BLITZ.OPA to the \APP directory on any drive. On the
Same drive make a directory \APP\BLITZ and copy the following files into
that directory:
BUILDING.PIC, BACKGND1.PIC, BACKGND2.PIC, BACKGND3.PIC, TITLE.PIC
Finally install the Blitz icon to the system screen using Install
app (PSION-I).

Three additional backgrounds: ANDBCKD1.PIC - ANDBCKD3.PIC can be used by
renaming one of them as CUSTBGND.PIC

A batch file which runs under RCOM is included which will copy all files
for you. Just type BLZRCOM for further help.

Blitz
-----

The aim of the game is to bomb all of the buildings (which are empty and
derelict of course) to the ground. Your little plane gets progressively
lower and if you don't bomb quick enough you'll crash into one of the
buildings. You can only drop one bomb at a time.
