BOOKS 1.2, 26/01/97 (S3A/C only)
================================

Books is what it says: a book collection manager.
Apart from regular titles and authors it also includes
a.o. ISBN and price, which will also allow representatives
to carry their most essential info on their psion.

Installation
------------

The file JBSortB.IMG should be placed under the \APP\ or the \IMG\
directory of any drive. In the latter case, you may rename it to
SYS$JBST.IMG if you don't want the module to appear under the
run-IMG icon. If you feel you don't need sorting, just don't install
this module at all. Don't install it either if you have it running
already for another program (under the a.m. conditions).

Only the OPA file is required and can be placed anywhere
(normally under the \APP\ directory).
If you want Help you should create a directory \BOOKS\ directly
under the root and place the BOOKS.RSC file there.
After installing and first running the program you should confirm
this disk-choice when asked.
