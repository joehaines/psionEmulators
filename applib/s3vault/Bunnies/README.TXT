How to install Bunnies on an S3a
--------------------------------

To install BUNNIES copy BUNNIES.OPA to the \APP directory on any drive. On
the same drive make a directory \APP\BUNNIES and copy the following files
into that directory:
BUN1.PIC, BUN2.PIC, BUN3.PIC, BUN$.PIC, BUNNIES.LEV
Finally install the Bunnies icon to the system screen using Install
app (PSION-I)

A batch file which runs under RCOM is included which will copy all files
for you. Type BUNIRCOM for more help.

Bunnies
-------

Bunnies is a platform game in the style of Manic Miner, Jet Set Willy, etc
Guide Hoppy the Rabbit around each level collecting all of the
carrots. Move to the Exit Arrow when it appears to move to the next
level. Avoid the snails and other nasties if you want Hoppy to
survive. Hoppy has three lives. If you get past level one there is a
retry option which will give you another chance to complete a failed level.
You can only retry a level once. Bunnies has ten levels
Use O,P,Space to move left and right and to jump. Use keys in
combination to jump left and right. O,P,Space are not the only keys
so experiment and find the most comfortable keys for you.
