BUSDAT - Business Database Program - Psion 3a
=============================================

BUSDAT is a simple database program to keep your contact information
in, the program allows data to be kept and viewed in a fixed format
database. Dialling and label printing is available if registered.

INSTALLATION
============

(Please read the disclaimer in this document).

Copy the BUSDAT.OPA file to any \APP directory and install from the
main system screen by pressing PSION-I.

Copy the BUSDAT.RSC file to the m:\opd\ directory if you want on-line help.

Typically BUSDAT uses 20k of memory to run, my copy has 600 data
entries in it.

The program makes:-
?:\dat\busdat.dat           The datafile (initially on M:)
m:\app\busdat\busdat.cfg    The configuration file
m:\app\busdat\busdat.reg    The registration file

If you use MCLINK you can auto install the program. Start the link and
enter @insta.scr to install the program on drive a
enter @instm.scr to install the program on drive m.
The help file in both cases is put on drive M, you can delete
busdat.rsc if you want to save space on your psion and you don't
want the on-line help. You can add this file again later if you want help.

LABELS
======

BUSDAT will print address labels, the program is set up for
tractor feed labels, one across, and 8 labels vertically per
page. (Registered Version!).

REGISTRATION
============

BUSDAT is shareware - if you like the program and continue to use it
after 30 days please register it. Registration details are given
on the HELP screen in the program.

HELP is available from the program by pressing HELP, a list of key
functions is available from the menu key.

If you have less than 20 entries the program will work in registered mode!

You can register BusDat on-line on compuserve, to do this use
GO SWREG to enter the registration system and look for product
ID=10141.
