This is a Small Calculator Program.


  File Location :-

	Calc.opa  in \APP
	digigame.opo in \OPO

  Which emulate the Casio MG-660, have a classic digits game.

	Key assignment :-

	[PSION]+[G] : Game.
	[PSION]+[E] : other module.
	[PSION]+[X] : Exit Program.
	[Space]/[ESC] : Clear.
	[A]		: add into memory.
	[D]		: deduct from memory.
	[C]		: Clear Memory.
	[R]		: Recall Memory.
	[,]		: Negative Number.

  Hope you will enjoy.
