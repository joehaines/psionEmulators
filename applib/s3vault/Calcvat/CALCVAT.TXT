				
				CALCVAT FOR PSION 3A
				====================


INFORMATION
===========

CalcVat is a simple to use VAT calculator for the Psion series 3a machine. The Program
is freeware, and will work on any version of the 3a. The program maybe freely distributed 
to anyone for private use only. It is not available for use by companies.

INSTALLATION
============

Yhere are three files to CalcVat. CalcVat.opa, CalcVat.pic, and this file CalcVat.txt.
The files should be installed in the following directories which you may have to create.

	CalcVat.opa	installed to \APP
	
	CalcVat.pic	installed to \OPD

	CalcVat.txt	text file, will need converting to wrd file if put on 3a. This file 
			should not be required on the 3a.

After copying files to 3a, use Psion install from main menu to install icon and program.


THE PROGRAM
===========

Very easy to use. Select the VAT value you want to use before the calculations. % sign is
not needed. VAT value can be changed during the program if required. VAT value, unless changed
will be retained in memory during the life of the program. Help file is available. Two types 
of calculation are available.

Calculate a value including VAT

Calculate a value without VAT
