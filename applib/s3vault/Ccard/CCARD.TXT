CCard v1.0

This application shows whether a Credit Card number is valid by calculating the
Modulo-10 Check-Digit checksum. However it does NOT indicate whether an account
number is valid - only whether the number itself passes an internal check digit
test. It is also quite possible for invalid numbers to generate correct check
digit calculations.
The following cards are supported: VISA, Eurocard/Mastercard, American Express.
I have only been able to test the program on VISA and Mastercard, so I would be
greatful if you report any experiences with Amex cards to me.

Installation: Copy the file CCard.OPO to any \OPO directory. Then select CCard
from the list under the RunOpl icon to start the program.
