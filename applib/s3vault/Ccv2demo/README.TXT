CallCalc V2.0 Installation instructions
---------------------------------------

The files should UnZip into the correct directories. They should be installed
as follows:-

File            Location
----            --------
CCDEMO.OPA      \APP directory on any drive
CCV2DEMO.RSC    \OPD\CALLCALC on any drive
FRQNAMES.ODB    \OPD\CALLCALC on your default drive
RATES.ODB       \OPD\CALLCALC on any drive

When first started, a file named CCLOG.DBF will be created on a drive
of your choice. This should be your defeault drive.

The on-line Help should be sufficient to enable you to make full use of the
program.
