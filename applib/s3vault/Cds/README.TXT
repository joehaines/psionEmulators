CDs v.2.2, 01 jan. 1997
=======================

New:
- sorting routine JBSortB now replaced older and unreliable
  sorting method
  
Installation:
- place the OPA-file anywhere under \APP\ and install as usual
- if you plan to use the fast sorting method (strongly advised)
  you should place the file JBSORTB.IMG either under \APP\ or
  \IMG\ on any drive. In the latter case you may rename it to
  SYS$JBST.IMG if you don't want it to appear under the Run-IMG
  icon.
  Of course if you are already using JBSortB under any other program
  you don't need to install it at all, as long as it can be found
  under a.m. conditions.
