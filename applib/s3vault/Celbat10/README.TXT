A Database of Button Cell Batteries and look-up program for the Series 3a
=========================================================================

The program allows the user to look up a button cell type and the equivalents
produced by different manufacturers.

CUSTOMISED REGISTRATION FILE
============================
DO NOT DISTRIBUTE THE CUSTOM REGISTRATION FILE CALLED CELBAT.REG

Installation (SEE DISCLAIMER)
============
Copy the following files to the given locations:
celbat.opa  m:\app\        or drive a:
*.dat       m:\app\celbat\
celbat.reg  m:\app\celbat\  GENERATED BY THE PROGRAM DURING REGISTRATION

Install the application from the system screen using the Psion-I command.

Deletion
========
Delete the opa file and the two datafiles.
Delete the reg file.
