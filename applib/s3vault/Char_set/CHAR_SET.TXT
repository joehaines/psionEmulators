Documentation for Char_Set for the Series 3a
============================================

This program is shareware, so please share it with other Psion-owner!

The Program
-----------

This is a simple program that displays the Psion character set in a matrix
form on the screen.

Installation
------------

This application program can be loaded on any disk, in any directory.

The program is run by installing it into any menu using the 
Apps - Install (Psion-I) option and then selecting it.

Operation
---------

First the dialog box requests which font type you wish to be display.

Next is the display.

Pressing any key will return to the dialog box.  The last option is Exit.
or you can exit by pressing Esc.
