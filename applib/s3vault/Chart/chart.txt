Chart Version 1.1
=================

Simple Charts and Diagrams

A picture is worth one thousand words! Simple charts and diagrams can rapidly
convey information. If you want to communicate structure, logical 
relationships, or organization, the Chart application can help. It lets you
sketch out a chart on your Psion 3a. You can save, restore and edit this 
information as required. When you need hard copy, or integration of the
resulting information into other documents, transfer the compact Chart file 
to a Windows 3.n platform, and print or combine with other programs using 
the supplied Windows utility. The process is as straightforward as backing 
up your Psion.


Installation
============

Copy CHART.OPA to the APP directory of your internal drive using your
preferred transfer protocol. There are no further files to be copied. Install
the application with Psion-I. When you first run Chart a directory will be
created on your internal drive \CHT\, as a preferred location for Chart
files, which are given the extension .CHT by Chart.

Basic Use
=========

Adding Boxes
============

Move the cursor about the screen using the arrow keys. Use of the Psion key
amplifies the effect of these keys. Insert a new box using Enter or Psion-L.
This will provide a dialogue box with fields for text and the style of box
required. You can enter multiple lines within one box by incorporating '\'
characters to delineate line ends. The following styles are supported:

                    Box    No_Box    Shadow    Diamond


Changing Boxes
==============

Move the cursor to the selected box and press Enter or Psion-C. A dialogue
box of the current attributes for the selected box is displayed. Any changes
are immediately imposed on the diagram.


Deleting Boxes
==============

Move the cursor to the selected box and press Delete or Psion-D. The
selected box is removed from the diagram.


Connecting Boxes
================

To connect two boxes move the cursor to the centre of the first box, press
and hold Shift, and move the cursor to the second box. Whilst still holding
Shift press Enter. The connection will be made.


Disconnecting Boxes
===================

To disconnect two boxes move the cursor to the centre of the first box,
press and hold Shift, and move the cursor to the second box. Whilst still
holding Shift press Enter. Chart will disconnect the two boxes. This is the
same procedure as connecting two boxes (Chart recognizes that a connection
already exists and deletes this existing connection).


Moving Boxes
============

To move a box, move the cursor to that box. Press and hold Shift, and whilst
holding down Shift, move the cursor to the new position. The box will be
moved to the new cursor position.


Displaying Arrows
=================

You can highlight the direction in which connections have been made using the
display of arrows. This is toggled under Special, Psion-R.


Installing the WinChart Windows Utility
=======================================

WINCHART.EXE should be copied to a convenient location on your Windows
machine. Use 'Drag-and-Drop' in the File Manager to add the WINCHART.EXE 
to a convenient (or new) Program Group in the Program Manager. WINCHART is 
started by double clicking on its icon. Chart files can be opened, printed 
and cut and paste using the standard Windows protocols.
