Chess Clock for the Psion 3/3a
------------------------------

With this program you can use your Psion as a chess clock. Using the menu
you setup the players names, the time limit, and number of moves to be made 
within the time limit. When 'Start' is selected, player 1's clock will begin
to count down to the time limit. Pressing the spacebar freezes player 1's
clock, and starts player 2's, which counts down until the spacebar is pressed,
when player 2's clock freezes and player 1's restarts, and so on. When one
players time is up an alarm sounds.

You will need to inhibit Auto Switch Off from the System/Control menu, or
your Psion may switch itself off while the clock is running. 

The clock 'beeps' when the spacebar is pressed, to provide positive audible 
feedback in the heat of battle, but if this is distracting it can be inhibited
using the System/Control/Sounds menu item.

This is version 1.0. Please let me know if you find any bugs!

Installation Instructions
-------------------------

CCLOCK3.OPA is for the Psion 3. (It will work on the 3A in emulation mode.)
CCLOCK3A.OPA is for the Psion 3A.
CCLOCK.PIC is the icon file for Psion 3 and 3A.

Copy CCLOCK.PIC and either CCLOCK3.OPA or CCLOCK3A.OPA to the \APP\ 
directory on the appropriate drive (usually 'Internal'). Make one if 
necessary by simply including it in the To file:Name field in the Copy file
dialogue. 

Install the application from the System/Apps/Install menu item, and select
the .opa file in the Install dialogue. Select the new icon and press enter
to start the application.
