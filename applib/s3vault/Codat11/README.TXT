Database Passowrd (v1.1)                  Psion GmbH 1994 (GT)
=================

1. This program works only on Series3a, not on Series3!

2. To install, copy the file CODAT.APP into the \APP\ Directory.

3. To encrypt a database file, start CODAT with a new filename, which
   matches that of the database file.  This file will then be used.

4. When opening an existing CODAT-file, the file must be decrypted.  This
   can take a few moments, BUT YOU DO NOT NEED TO WATE.  As soon as the
   process is finished, the first record will be displayed, regardless of
   where you were.

5. When closing a file, the file must be encrypted.  This can also take a
   while, but again, YOU DO NOT NEED TO WAIT.  Press SYSTEM, and you can
   work in other applications whilst this is going on.
