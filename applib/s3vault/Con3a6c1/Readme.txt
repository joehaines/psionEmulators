CONVERT  Version 6c1

UNZIPPING:

Apple Mac Users:
Mac users have reported difficulty in unzipping this file. it unzips, but when you try to run the program you get a "String too long" error message. To avoid this, re-unzip it, but first turn OFF the "By default, smart-strip linefeeds from text files" option in the Miscellaneous Prefs dialog box under the File/Preferences/Miscellaneous menu.


INSTALLATION:

ENGLISH  (Deutsch folgt. Français suive)

IMPORTANT

Users of older versions can keep the following files:

"memory.odb" (NOT "mem.odb")
"pick.odb"

Registered users MUST keep "convreg.ini"
but cannot use their old "user.odb" file.

1. Copy the following files to an \APP\ directory on any drive:

"con6c1.opa"
"english.ovl"
"table.ovl"   (optional - clothing tables)
"reg6c1.ovl"  (optional - non-registered users only. Deletes itself on registration)

2. Create a new directory \OPD\CONVERT\ on the Internal or RAM disk
     ---NOT FLASH---   and copy the following files:

"currency.opd"
"memory.opd"
"pick.opd"

(Registered users only)

"usemem.odb"
"convreg.ini"

3. Install the file "con6c1.opa" from the system screen (Psion "I")

4. Please copy "conv-eng.wrd" to a /WRD/ directory and read for full instructions


FRANCAIS

IMPORTANT:

Utilisateurs enregistres - n'effacez pas le fichier "convreg.ini". Touts autres fichiers ne marcheraient pas avec le version Francais.

Pour l'installer, proceder comme suit :

1. Copiez les fichiers suivants dans le repertoire \APP\ de n'importe-quel lecteur :
"con6c1.opa"
"francais.ovl"
"table.ovl"  (facultatif - taille des vetements)
"reg6c1.ovl" (nouveaux utilisateurs non enregistres seulement - disparait a l'enregistrement).

2. Creez un repertoire \OPD\CONVERT sur le disque interne ou sur un SSD RAM (pas sur un SSD FLASH) et copiez-y les fichiers suivants :

"monnaie.odb"
"memoire.odb"
"choix.odb"

(Utilisateurs enregistres seulement)

"utilise.odb"
"convreg.ini"

3. Vous devez ensuite installer l'application de l'ecran systeme. (Psion "I")

4.Copiez le fichier "conv-fra.wrd" a un repertoire \WRD\ et consultez pour les instructions complete.


DEUTSCH

WICHTIG:

Registrierte Anwender - löschen Sie nicht Datei "convreg.ini". Alle andere alten Dateien  von Convert sind nicht mit dem deutsches Version nicht vereinbar.

Installiert wird es wie folgt:

1. Kopieren Sie folgende Dateien in die angegebenen Verzeichnisse auf ein beliebiges Laufwerk.

\APP\con6c1.opa
\APP\deutsch.ovl
\APP\table.ovl    (optional - Kleidertabellen)
\APP\reg6c1.opa   (optional - benötigt für Registrierung)

2. Kopieren Sie folgende Dateien in die angegebenen Verzeichnisse auf das interne oder ein RAM-Laufwerk - kein FLASH-SSD !

\OPD\CONVERT\memorien.odb
\OPD\CONVERT\waehrung.odb
\OPD\CONVERT\wahl.odb

(wenn registriert)

\OPD\CONVERT\benutzer.odb
\OPD\CONVERT\convreg.ini

Wenn Sie nicht genau wissen, wie das gemacht wird, lesen Sie bitte im PSION Benutzerhandbuch unter "Dateien und Disks" nach.

Als nächstes müssen Sie die Applikation installieren. Gehen Sie dazu auf den Systembildschirm und plazieren Sie den Cursor unter dem Symbol, auf dessen linker Seite der "Conversion Calculator" erscheinen soll. Wählen Sie nun aus dem Hauptmenü "Applikation" den Befehl "Installieren". Nun sollte, bei richtig angegebener Disk, "Con6c1.opa" angezeigt werden; wenn nicht, einfach die "Pfeil nach rechts"-Taste betätigen, bis es erscheint. Wenn es nicht erscheint, bedeutet dies, daß Sie diese Datei nicht in ein "APP"-Verzeichnis kopiert haben.

Nun sollten Sie  das Convert-Symbol auf dem Systembildschirm sehen können. Plazieren Sie den Cursor auf der Bezeichnung "Konvert" und drücken Sie ENTER.

Tip: Mit der Funktion "Taste belegen" aus dem System-Menü "Applikation" können Sie "Convert" die Tastenkombination "Strg+Rechner" zuordnen; dann können Sie aus anderen Applikationen heraus jederzeit zu "Convert" überwechseln.

Bitte sehen Sie Datei "conv-deu.wrd" für vollen Unterrichten
