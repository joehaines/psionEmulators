Corvette is a simple slide show and is freeware.
To install it you will have to copy the file "corvette.opl" to the \opl\ directory on your internal drive and all the pic files to any \opd\ directory. If you copy the pic files on your internal drive, then simply translate the opl file using "program" the 
file "corvette.opo" will be added to your \opo\directory to be run under "run  opl". Press psion esc to exit. If you copy the ".pic" files to another drive (A or B) you will have to modify the source before translating: ("A:\opd\...") or ("B:\opd\...").
