CPD Ledger (- Version 1.0    by Andrew Leonard



INSTALLATION INSTRUCTIONS

Unzip the files and then follow these instructions


1.       On the internal drive create a directory called "CPD"

2.       Then load the following files to the "CPD" directory

          Cpdi.pic
          Details.odb
          Mlform.wrd
          Records.odb
          Regform.wrd

3.       If you have a directory named "APP" on the internal drive, load the file "CPD.App"                      into it. If not create a directory called "APP" and copy the "CPD.App" file into it.
