Overview of program
-------------------

CrosWord is a program for the Psion Series 3a family of computers which
allows you to create, edit and play crossword type puzzles.

The user can select words and clues from a standard Psion .DBF database
file, which can be edited by the user so they can add their own words
as desired. The puzzles produced by the program can be copied to allow
you to share them with other users. If you create any puzzles you would
like to share with others, please send them to me (see Contact Information
above). I wish to build up a collection of puzzles that I can distribute
to users, thereby increasing the enjoyability of the program.

I've left most of the program un-crippled so you can appreciate the
functionality of the program . The only exception is that any changes made
to existing or newly created puzzles will not be saved, but you can still
see the editing features in action.

Installation
------------

The files should be installed to the same directories they UnZip to, i.e.:-

File            Location			Size (bytes)	Purpose
----            --------			----			-------

CSWTRIAL.APP    \APP                19327    		The program
BLOCK.PIC       \CROSWORD           60			    File used by program
CROSHELP.RSC    \CROSWORD           2327		    Help file
DEMO1.CWD       \CROSWORD\GAMES		3338	        Demo game
DEMO2.CWD		\CROSWORD\GAMES		3785			Demo game
WORDCLUE.DBF	\DAT				2995			Word/Clue database

These files can be held on any drive. It is best to place the games in
your default drive, as this is where the program first looks for them,
but any drive will do. Games should also be placed on RAM, i.e. a RAM SSD
or Internal memory, as the files do change during the course of playing.
