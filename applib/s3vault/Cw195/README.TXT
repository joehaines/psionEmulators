Installation
------------

The files should be installed to the same directories they UnZip to, i.e.:-

File            Location
----            --------

CSWTRIAL.APP    \APP                    (The program)
BLOCK.PIC       \CROSWORD               (File used by program)
CROSHELP.RSC    \CROSWORD               (Help file)
*.CWD           \CROSWORD\GAMES         (Demo games)

These files can be held on any drive. It is best to place the games in
your default drive, as this is where the program first looks for them,
but any drive will do. Games should also be placed on RAM, i.e. a RAM SSD
or Internal memory, as the files do change during the course of playing.
