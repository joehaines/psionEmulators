This is a text version of the help file, if you choose to delete the help to save space, this file gives everything the help file does.  See the History section (at the end) for changes to this version. 

Installation:
Windows
	PsiWin software can be used to install the application, simply drag and drop the (hold down CTRL on the keyboard so you JUST COPY) "APP" folder to the Psion drive of your choice.  Then choose "install" from the Apps menu in the System Screen.

DOS
	Start the RCOM software and type the following:
	To install to your internal disk type:
		CD\CYCLE
		BIKEINST I:
	To install to a SSD in drive A type:
		CD\CYCLE
		BIKEINST L:
	To install to a SSD in drive B type:
		CD\CYCLE
		BIKEINST B:

	It will run a batch file that will install the application to the drive of your choice. Then choose "install" from the Apps menu in the System Screen.

Macintosh
	Using PsionLink, just drag and drop the "APP" folder to the Psion drive of your choice.  Then choose "install" from the Apps menu in the System Screen.

Application files:

Rider details
This is where you store your initial details. Cycle calc lets you track one rider's information.  If there is a rider already entered, you will see those details.  Note that you MUST enter initial details or you will not be able to log properly.  User info is stored in the file "\app\bike\User.odb" if you ever need to change your details, delete that file.


Set preferences
This is where you choose to use the background graphic and/or the Stats computer graphic.  Version 2 has goneto a modular approach, you can have the program very compact or fancier.
This choice doesn't change the apps' function, just it's appearance.
Upon registering you will be sent backgrounds to choose from!


Timer
As the Psion is a pocket sized unit it makes the perfect tool to log your riding.  The timer is nice in that the Psion doesn't need to be on in order to time your rides.
Just press enter, turn the Psion off, and go riding.
The time will show as the default time when you log your ride.


Logging
Cycle calc lets you keep track of various info, and produce reports from your rides.  You can track the date, (press TAB for a pop-up calendar),mileage,time (if you use the timer that time will be the default),weight weather,and a notes field.


Statistics
New for version 2 is the new stats computer.  It lets you see your weight loss/gain or your total distance ridden.
To choose "Weight":
press "W"
To choose "Distance":
press "D"
To exit the stats computer just press the "ESC" key.  Please note that as the weight statistics depend on your rider details, you can't get stats if you haven't entered your initial rider details.


Exporting
Why export?  Even though you can get quick stats from within Cycle Calc, the export command goes quite a bit further.
You can export the data to a text file and take advantage of the Copy and Bring features of the 3a.
Once you have exported the data, open the file up,  use the shift and arrow keys to highlight the info.  Press the System Touch Pad and press Enter on the Sheet app.  
Choose "Bring" from the edit menu. You can now highlight a column using the shift and arrow keys, press the diamond key,and you'll have a graph of your data.  To make more complex graphs, refer to the 3a's user guide.
