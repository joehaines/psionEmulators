DATAFILE
========

Have you ever found yourself frustrated at not being able to
Sort DATA records, or wanting to swop the order of DATA fields?
Well here's a Freeware program which should deal with most of
your problems!

The DATAFILE program was written to be used alongside PSION's
DATA application.

It provides many useful data field and record manipulation
functions which are not available in DATA and can also list
eight records at a time on the screen.

Because it complements DATA, it uses the \DAT\ directory and
has .dbf as the default file extension.

In this version records are limited to eight fields of 255
characters, adequate for most small applications.

Install the program from your \APP\ directory next to DATA on
the System screen and learn what it will do by running it on
a duplicated file of data.

I hope that you find it as useful as I have.
