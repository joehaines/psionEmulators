"Dbf" V1.2 for PSION Serie 3a
*****************************

Introduction
============
"Dbf" is a database browser with "fast" sorting functions.
Several display modes are implemented:

- Index Display   (several records)
- Record Display  (just one record)
- Field Display   (just a field in a record)   

Recordscrolling, search functions, and fast positioning within a database
are supported. A "fast" sort function with a maximum of 3 fields, within    
field 1-5, in ascending or descending order is implemented too. Of course
the field labels are shown!

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

What's new in Version 1.2
==========================
- "Dbf" supports now also database structures, which are designed with
  more than one line within a field. This means, you didn't use just
  SHIFT-RETURN to produce more than one line within a field.

What's new in Version 1.1
==========================
- Now online help is available.
- For a few internal tables, storage will be allocated dynamically,   
  depending on the amount of records in the database. This will reduce the 
  basic storage amount, and will enable "Dbf" to handle database files with 
  more records.
- The language can be switched dynamically between english and german.
- An icon for Serie 3a is now integrated.

Installation
============
1. Create a directory called "DBF" of the root, on any drive.
2. The following files should be copied into \DBF:

   - dbf.opa
   - dbfdeu.hlp
   - dbfeng.hlp
   - dbfmod01.opo
   - dbfmod02.opo
   - dbfmod03.opo
   - sys$help.opo

3. From the system menu press PSION-I to install dbf.opa (it will be
   found in directory \DBF\, see 2.).

Help for Menu Items
===================
File     : - open       / PSION-o (open a existing database file)
Sort     : - Sort file  / PSION-s (max. 3-levels, within fields 1-5, 
                                   ascending / descending)
Special  : - Labels     / PSION-b (concerns record display mode)     
             on / off  
           - German     / PSION-l (switch between english/german)
           - About      / PSION-i (Info about "Dbf")
           - Exit       / PSION-x (Exit)

Keys used in the different Display Modes
========================================
After opening a file (by menu within "Dbf" or by system screen), you are 
in the Index Display mode (several records). From this mode you can reach
the Record Display mode (one record), or the Field Display mode (1 field    
of a record).

Keys used in index display mode:             

   Up-Arrow      Navigation within database file records
   Down-Arrow          "
   Page-Up             "
   Page-Down           "
   Pos1                "
   End                 "
   a..z          Positioning within database on record x, referring to the
                 1st letter of field 1 of a record. (just try it!)        
   A..Z          Positioning within database on record x, referring to the
                 2nd letter of field 1 of a record, starting on current  
                 position (1st letter of field 1, should not change).
   Esc           Switch between search mode and display mode    
   Enter         Switch to record display mode of current record
   Right-Arrow   Switch to field display mode of current record

Keys used in record display mode: 

   Up-Arrow      up within record display         
   Down-Arrow    down          "
   ,             left          "
   .             right         "
   Tab           page info display window on/off  
   Esc           Switch back to index display mode

Keys used in field display mode:

   Right-Arrow   display next field to the right side of the current
   Left-Arrow    display     "      "   "  left   "       "     "    /
                 or back to the index display mode
   Up-Arrow      up within field display mode   
   Down-Arrow    down         "
   ,             left         "
   .             right        "
   Esc           Switch back to the index display mode
