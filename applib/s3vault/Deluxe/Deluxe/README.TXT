README.TXT DataDeLuxe Public DemoVersion V1.0	12-12-94 
========================================================

Intended purpose
----------------
This is a public demoversion of DataDeLuxe which may be spread to all
Psion users who want to get a feeling of how DataDeLuxe works.

Installation of the software
----------------------------
Copy \APP\DELUXE.APP to any drive on your Series S3a, the choose the
INSTALL item in the INSTALL pulldown menu, choose DELUXE.APP in the dialog 
and press <enter>. DataDeLuxe is now installed on your machine.

Limitations of the DemoVersion:
-------------------------------
- This is only a TESTversion, to find and remove all bugs which are reported 
  by our Betatesters or other persons.
- This version will only work on a SERIES 3A.
- A build in timer will prevent using this version for longer than 1 month.
- You cannot open files which contain more than 30 records.
- This version will work in English only.
- Features which aren't working in this version :
	- Logs
	- Deleting records
	- Printing
	- Help
