README.TXT DataDeLuxe Upgrade Kit V2.5 
Intended purpose:
	This version upgrades your 2.01 version of DataDeLuxe to the new 2.5 version.
Installation:
Requires: 	
- This floppy disk.
	- Your original DataDeLuxe SSD.
	- Another RAM or FLASH SSD if you own an OTP version (see later).
	- A DOS PC.
	
OTP or FLASH DataDeLuxe?
There are 2 different kinds of DataDeLuxe SSDs, there are FLASH type SSDs and OTP type SSDs.  Flash SSDs can be overwritten with a new version of DataDeLuxe, so you won't need a extra SSD to upgrade. If you have an OTP, you cannot overwrite any data, and you'll have to install the upgrade to another SSD.
If your SSD has a 'Write protect' switch at the side, then it is a FLASH. You can also put the original SSD in your S3a, goto system, press TAB and choosethe correct slot with the left-right arrows. If the dialog says FLASH, it's obviously a FLASH, if it says ROM, then it is an OTP.

Upgrading a FLASH DataDeLuxe SSD.

1. Copy all files which are on the original DataDeLuxe SSD to your PC.
NOTE! Be sure to copy ALL files, if you lose some, you will not be able to upgrade your flash!
		
Files:		\APP\DATADELUXE.APP
		\APP\LOGVIEW.ALS 			(optional)
		\APP\DELUXE\DATADELUXE\DELUXE02.RZC
		\APP\DELUXE\DATADELUXE\DELUXE03.RZC
		\APP\DELUXE\DATADELUXE\DELUXE19.RZC
		\APP\DELUXE\DATADELUXE\INSTALL.BIN
		\APP\DELUXE\DATADELUXE\DELUXE.BIN
		\IMG\INSTADDL.IMG
		\PIC\P&S.PIC

2. Reformat the DataDeLuxe SSD using your Psion S3a.
NOTE! Put the write protect switch to WRITE (switch to the middle of the SSD).


3. Copy all files on this disk in the directory \DDL25 to the SSD.
NOTE! Do not create the \DDL25 dir on your flash!

4. Copy the 2 .BIN files you copied from the original SSD earlier on back to
the SSD.
	Files:
		\APP\DELUXE\DATADELUXE\INSTALL.BIN
		\APP\DELUXE\DATADELUXE\DELUXE.BIN

5. Write protect your SSD (put the switch in the direction of the SSD
connector), and startup the new version of DataDeLuxe. If you want to install a valid version to another SSD, you must use INSTADDL under the RunImg icon of you system screen.


Upgrading when you own an OTP DataDeLuxe SSD.

1. Use the INSTADDL program on the OTP, which appears under the RunImg icon in the system screen, to install DataDeLuxe on the extra SSD.

2. Replace following files on the extra SSD with the ones on this disk:

On the SSD:  		replaced by the files       On this floppy
---------------		    		       -------------------
\APP\DATADELUXE.APP		       	       \DDL25\APP\DATADELUXE.APP
\APP\DELUXE\DATADELUXE\DELUXE02.RZC     \DDL25\APP\DELUXE\DATADELUXE\DELUXE02.RZC
\APP\DELUXE\DATADELUXE\DELUXE03.RZC     \DDL25\APP\DELUXE\DATADELUXE\DELUXE03.RZC
\APP\DELUXE\DATADELUXE\DELUXE19.RZC     \DDL25\APP\DELUXE\DATADELUXE\DELUXE19.RZC

3. Remove the OTP from your Psion S3a, and startup the new version of DataDeLuxe.
