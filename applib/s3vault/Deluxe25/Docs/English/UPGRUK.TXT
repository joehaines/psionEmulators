DataDeLuxe 2.5
General:
DataDeLuxe V2.5 is not merely an upgrade - many things in this program have been changed. We have rewritten the entire User Interface (GUI), so that maximum speed and excellent graphic representation are guaranteed. All known bugs that were present in the previous version have also been taken out. The program is now more economical too in how much memory of your Psion 3a it reserves for its own use. Indeed, the amount of required memory has been cut to 70 kB (instead of 105 kB!)
Copy protection feature:
DataDeLuxe V2.5 is copy-protected, but that has been conceived in a very flexible way. To make a legitimate version, follow the following steps. ONLY take these steps if you wish to install DataDeLuxe on another SSD than the one which the program came on. You don't have to take ANY special steps if you intend to work with the original SSD. It is NOT possible to use DataDeLuxe running from the internal memory!

Installation:
	- Put the original SSD in a slot.
	- Put the other SSD in a slot.
	- Go to the System menu, and look for the RunImg icon.
	- Click and select the program 'INSTADDL' by pressing enter.
 	- Follow the directions.
	- Remove the original SSD.

The INSTADDL program puts the file Deluxe.bin on your SSD. This file contains a number, peculiar to the SSD on which it was installed. This file is verified on loading up the program. As long as this file stays on the same SSD, DataDeLuxe will always start up. But if you make a copy of this file and of DataDeLuxe on another SSD, DataDeLuxe won't start up. Even if you reformatted your Flash and put back all the files, DataDeLuxe will still work, without needing to re-install any part of it.
With your original DataDeLuxe SSD you can, of course, make as many legitimate installations as you like.
Card:
Menu options:
Save as/Merge: A rearrangement of the options, the layout is identical to the one in 'Data', except that DDL has the Copy All/Copy Selected option only.

Bring: Works faultlessly and brings text from every standard app.

	Set tabs: one can now set the width of the tabulator.

Zoom in - Zoom out: The 'Zoom out' button is now available as on all standard applications.


Print - Print Preview: Now, with Print Preview, you're able to see, in the document window, how it will look when it's printed, and check it's formatted the way you want. Information on how the entire printing system works can be found in the user's guide (p. 203 - 221).
User interface:
'Find:' window - Info window: The find and info windows have been made a whole lot smaller, so that there is now more room available for data in the Record window. When using the info screen, these 2 screens move up, so that the size of the active window on the screen is maximized.

Status window: This screen indicates which mode DataDeLuxe is in, and is a new feature on the 2.5 version. In record view the following messages may appear in this window:
	- Find: we are currently in the standard search mode.
	- Enter: a new record is being entered.
	- Update: a record is being modified.
	- Titles: the titles are being modified.

Card window: This window has been optimized considerably. The window now works faster than in the past. All the keys are supported (page up/down, shift-arrows, Dial, Psion Shift-Dial, Ctrl-Tab, etc., ...) and function in a standard way. The graphic representation of the labels is now exactly like that on the standard Data application. Several Shift-Enters are possible per field.

Dialling: The dialling system has been worked out in detail. Much more information can be found on this in the user's guide of your Psion 3a (p. 197 - 203). DataDeLuxe's dialling system utilizes the dialling settings which you've pre-set in the System screen and also takes the settings in the World application into account (= present address). Use Psion-Shift-Ctrl-Help to indicate, after each telephone number, in which country it is. In that way the dialling option will always select the correct international dialling code.

Card Browse: If you are currently in a 'find:' window, you can browse through the card box using the up and down arrow keys. The left and right arrow keys are next used to scroll across the 'find:' window. Operate the up and down arrow keys as under the heading 'Table'.
Table:
General: 
The most striking thing about the Table View is that the table is now in the same window as that of Record View. The 'find:' window, info window and status window are still in the frame when switching between Card and Table.
Menu options:
The 'Select Menu card': The pull down options, formerly only available in the Card window, can now be used working from the Table window. The logical search function can be used working from this menu.
User interface:
Left/right scrolling: It is now possible to scroll horizontally through the table, using the left and right arrow keys. This means you can see view more columns than the standard width of your screen.

Cursor 'Find': If you're currently in a 'sorted' or 'selected, sorted' mode, you can find a card by typing in the first few letters of the field. The Table window does, however, need to be highlighted. You then see the 'find:' text appear in the 'Find:' window.

Status window: This screen indicates which mode DataDeLuxe is in, and is new in version 2.5. In Table View this window indicates which mode the Table is in.
	- All: All cards.
	- Sort: All cards in a sorted order.
	- Select: Selected cards only.
	- Sel. Sort: Selected cards in a sorted order.

Info window: Use Ctrl-Menu to make the info-screen on the right side of the display bigger or smaller. This wasn't possible in V2.0.

Select: Besides hitting the space bar once to choose a card, you can now do this with a new feature: press the Shift key with the up or down arrow key.
