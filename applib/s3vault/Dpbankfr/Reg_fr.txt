DPBank n'est PAS gratuit!  Si vous appreciez ce programme et/ou vous
l'utilisez encore apres 30 jours, vous etes pries de vous enregistrer.

Le programme est du vrai shareware (par oposition au "crippleware") et
il fonctionne completement.

Si vous utilisez ce programme regulierement, veuillez svp considerer
l'enregistrement car c'est la seule incitation pour me donner envie de
continuer a maintenir ce programme. DPBank a deja pris des centaines
d'heures de mon temps pour programmer, maintenir et tester.

L'enregistrement est tres simple: vous m'envoyez un peu d'argent et vous
recevez un code qui va permettre d'enlever l'ecran de rappel de
shareware. Le code est entre directement dans la version actuelle de
DPBank, il n'y a donc pas besoin d'autre chose. Veuillez simplement
remplir le formulaire a la fin de ce fichier.

Le code que vous recevrez sera compatible avec les version futures de
DPBank.
