Shareware
=========
DPBank is not free. If you like it and/or still use it after 30
days, you are required to pay the shareware fee listed below.

The program is real shareware (as opposed to crippleware) as it is
completely functional.

If you use this program often, please consider registering as this
is the only incentive for me to continue maitaining this program.
DPBank has already taken hundreds of hours of my time to program,
maintain and test.

Registration is very simple: you send me some money and you will
get a code that will remove the shareware reminder. The code is
entered directly into your actual version of DPBank so you don't
need another version. Just fill out the form at the end of this
file.

The code you receive will be compatible with any future version of
DPBank.
