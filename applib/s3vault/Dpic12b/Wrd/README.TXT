DataPic! 

DataPic! came about because I got totally fed up with trying to find a 
particular slide amongst all of my others. I had been using a Slide 
Storage Page System of the type which is capable of holding 20 35mm slides 
to a page. (either in a binder or in a filing cabinet). If you use this 
method of storing your 35mm slides this OPA may be of use to you, if not 
then it is doubtful.

What does it do?
DataPic! allows you to build up a database of all your slides, each 
record can contain a title, description, date taken, any other relevant 
information. Once this is entered you must decide on a category under 
which that image should be filed. When you have chosen, the OPA will give 
that Image an ID code and place it in the first available opening of a page 
designated with that category.

You can use any of three modes (diamond key) in  DataPic! Edit Mode allows 
you to edit previously entered information and to enter new records. Page 
Mode Shows a Page View and allows you to see exactly where you image is. 
Image View shows the image records with all information. There is a basic 
help utility.

DataPic! utilizes John Boyce's excellent jbsort.img for speedy sorting by a 
choice of criteria.

DataPic! can also utilize other programs which you may have installed. 
If Psizip (copyright Serge Shestopalov 100526.1317@compuserve.com) is 
installed, when opening and closing DataPic! it will use Psizip to compress 
and encrypt your files to save memory space.
If Reppoc (Copyright Berthold Daum 100026.3365@compuserve.com)is installed, 
DataPic! will use it for printing purposes as it allows more control over 
Printing than my meagre OPL skills do. 
If Reppoc is not installed, Printing is to a wrd file which is then opened 
for editing prior to printing.
