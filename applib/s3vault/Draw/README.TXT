It is my simple draw program.

        All object files can be place any drive.

Edit command.

        arrow key for move cursor.
        Control key while move, move ten dots.
        Shift key while move, draw a dot.
        0 key for black color.
        1 key for grey color.
        2 key for while color.
        B key for draw box.
        C key for draw fill box.
        O key for draw circle.
        Q key for draw fill circle.
        L key for draw a line.
        J key for draw a spot dots.
        * key for copy rectangle.
        + key for insert a bitmap file.
        Z key for draw a border (gBorder $201)
        X key for draw a 3D border (gXBorder 1,$201)
        T key for draw a text.
        W key for zoom window.
        Space bar key for clear screen.
        Esc key for back to menu.
