Elements
========

by Martin Budden
martinjb@cix

Elements displays the periodic table of the elements.  Hitting enter
on an element displays the properties of that element.  Arrow down
and hit enter on Compounds to display data on the compounds of that
element (left and right arrows will then change the compound).

All the data was entered by hand (on several long train journeys) so
there are probably mistakes, please let me know if you spot any.

If anyone could supply chemical data in a machine readable format
then I'd be grateful.

To install it put ELEMENTS.OPO in the \OPO directory on any drive;
put all the other files (except ELEMENTS.TXT) into the \OPO\ELEMENTS
directory on the same drive (you will have to create this directory).

Any ideas for an icon would be appreciated.


Menu
----

Units
Changes the temperature units (Celcius, Kelvin or Fahrenheit).

Compounds
Show the compounds of the highlighted element. For carbon the
compounds are grouped.

Show rare earths
Toggles the display of the rare earth elements.

Exit"
