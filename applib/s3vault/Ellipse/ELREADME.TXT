
Ellipsoid Polygons Readme file

To run it:

1. Copy Ellipse.OPL into the OPL directory on any
drive with PSIwin or other application

2. Go into the OPL editor and load "Ellipse"

3. Hit psion-T to translate it

4. Press Y to run it.

5. From now on Ellipse will appear in the RUNopl application

Cool Things to Try:
for these, have all other settings as default.

1. Number of sides = 4
   X rep = 3

2. Number of sides = 2
   X Bowl = yes
   X rep = 3

3. X rep = 2

4. Space between Lines = 0.02
   X Bowl = yes
   Y Bowl = yes
   X rep = 3
   Y rep = 4

5. In the defXY procedure, mess about with the equations replace the X = sin(...... with X = tan(......
