Expenses
========

What is expenses ?

I just recently bought the Psion 3a, one thing that I missed was a program
in which I could keep track of my expenses during trips, so with the 
programming manual in the hand I started programing.

What can expense do ?

This program can keep track of your expenses, it will store the following
information:

    - Price
    - Currency
    - Type of payment (Guilders, dollars, pounds, etc.)
    - Date

It can hold eight different currencies and eight sorts of payments.
It will also automatically make the conversion from another currency
to the base currency, so that all your expenses will be shown in one
currency.

All the currencies and rates and types of payment can be user defined.

How to install ?

You can install the program by copying the EXPENSES.OPA into your \APP
directory, after this you need to create a directory \EXP in the root
directory.

After adding the application in the main menu with "Install application"
you can start the program.

Note:

The expenses program will automatically create a first database called
expenses, if this does not happen you can always create a database manually
by starting the expenses program, select utilities, select create datafile,
type the name of the new datafile, exit the program by typing a few times 
the escape key and start it again.

If you first start the program it will initialise with the default 
programmed values, these settings can be changes any time from within the
utilities menu.

So far the "manual" just try it, if you don't like it erase it, if you like
it use it (this is what it's written for)

I've included the source code so that you won't have to reverse engineer the
