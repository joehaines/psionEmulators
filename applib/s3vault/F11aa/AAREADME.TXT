Version

F11aa V1.10
Requires F11 V3.10 or later.

Description
-----------
F11aa is an address assistant for the F11 typing aid for PSION S3a.
It allows easy creation of address blocks in letters, or of fax cover sheets.

Installation and Documentation
------------------------------
English version: Please see F11aa.wrd (PSION-WORD format)
German version: Please see F11aa_g.wrd (PSION-WORD format)

F11aa is implemented as a OPL-subprogram for F11. Make sure
you have installed the RepPoc/KMAC/OPL-interface for F11 (F11rep.opa).
