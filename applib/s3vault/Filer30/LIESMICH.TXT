Filer 3.00
==========
Filer ist ein Dateiverwaltungsprogramm fuer den Psion Serie 3a. Sie koennen
Ihre Dateien in einem oder zwei Fenster in einem von vier Modi darstellen -
Laufwerke: zeigt Liste aller verfuegbaren Laufwerke und deren Verzeichnisse graphisch dar
Dateien: laesst Sie durch die Dateien und Verzeichnisse jedes Laufwerkes navigieren
Suche: durchsucht den Inhalt eines Lauwerkes nach einer angegebenen Spezifikation
Inhalt: stellt den Inhalt einer Datei dar
Sie koennen die Dateien und Verzeichnisse dann kopieren, verschieben, loeschen,
deren Attribute oder das Aenderungsdatum modifizieren, Unterverzeichnisse
anlegen und loeschen, Verzeichnisse sortieren, Applikationen starten.


INSTALLATION
============
Um Filer zu installieren, kopieren Sie die folgenden Dateien in die jeweiligen 
Verzeichnisse:

	Filer.app	79.472 Byte	\App		Application
        Filer.03        12.164 Byte     \App\Filer      Deutsche Resource
	Viewer.dyl	 6.032 Byte	\App\Filer	Hex/Text Betrachter
	Shell.dyl	 4.496 Byte	\App\Filer	Shell Modul
	Undel.dyl	 1.504 Byte	\App\Filer	Berechnung des Verbrauchten Platz
	Unzip.dyl	 1.840 Byte	\App\Filer	Unzip Modul Schnittstelle
	View_pic.dyl	 1.664 Byte	\App\Filer	Bildbetrachter
	View_dbf.dyl	 2.048 Byte	\App\Filer	Datenbankbetrachter
	View_wve.dyl	   768 Byte	\App\Filer	Klangbetrachter

Anschliessend kann die Applikation ueber 'Installieren' aus dem Menue
'Applikation' installiert werden.


Benuetzung
==========
Die Applikation startet ueblicherweise in der Laufwerksansicht. Waehlen Sie ein
Laufwerk mit ENTER aus, damit wird fuer dieses Laufwerk eine Dateiansicht
generiert. Navigieren Sie dann durch diese Liste mittels ENTER und ESC.
Eine Applikation kann entweder mit ENTER aktiviert werden oder durch Auswahl
einer zugeordneten Datei (wenn vorher im Erweiterungseditor definiert).


Laufwerke
---------
Die Laufwerke sind nach ihrem Laufwerksbuchstaben sortiert, lokale Laufwerke vor
fernten Laufwerke.
'Kopieren'      Kopiere alle (oder nur die geänderten) Dateien eines ausgewaehlten
                Laufwerkes in ein bestimmtes Verzeichnis.
'Umbenennen'    Vergibt fuer eine Disk einen neuen Namen.
'Formattieren'  Formattiert eine Disk.
'Ausblenden'    Wenn eines der Laufwerke aus der Liste nicht zugreifbar ist (z.B.
                weil keine Disk eingelegt ist), kann ein wiederholter vergeblicher
                Leseversuch vermieden werden.
'Verbrauchter Platz' Ermittelt den von geloeschten bzw. geaenderten Dateien verbrauchten
                und mit einer Neuformattierung wiedergewinnbaren Platz auf einer Flash SSD.

'Umbenennen'    Vergibt einen neuen Namen fuer ein Verzeichnis.
'Erstellen'     Erstellt ein neues Verzeichnis.
'Loeschen'      Entfernt ein Verzeichnis.
'Komprimieren'  Komprimiert/Expandiert ein Verzeichnis.
'Alle Expandieren' Expandiert alle Unterverzeichnisse.
'Oeffnen'       Oeffnet eine Dateiansicht fuer ein ausgewaehltes Verzeichnis in einem
                zweiten Fenster.
'Beschreibung'  Aendert eine zusaetzliche Beschreibung fuer ein Verzeichnis

Dateien
-------
Navigieren Sie durch die Dateien und Verzeichnisse mittels der Cursortasten,
ENTER und ESC, markieren Sie diese mit der LEERTASTE oder +, loeschen Sie die
Markierung mit -.
'Kopieren'      Kopieren Sie den Inhalt eines Verzeichnisses, Dateien oder eine
                Anzahl markierter Dateien und/oder Verzeichnisse auf ein
                beliebiges Unterverzeichnis.
'Verschieben'   Funktioniert wie 'Kopieren', loescht jedoch die
                Originaldateien/verzeichnisse.
'Loeschen'      Loescht Dateien und Verzeichnisse.
'Umbenennen'    Vergibt fuer Dateien bzw. Verzeichnisse neue Bezeichnungen.
'Attribute'     Aendert die Attribute einer Datei.
'Datum'         Aendert das Aenderungsdatum bzw. die Aenderungszeit.
'Markieren'     Waehlt eine Anzahl von Dateien und/oder Verzeichnisse mittels
                einer Maskenspezifikation und/oder eines Aenderungsdatumsbereiches aus.
'Beschreibung'  Ermoeglicht die zusaetzliche Angabe einer maximal 64stelligen
                Dateibeschreibung
'Erstellen'     Erstellt ein Verzeichnis innerhalb eines Pfades.
'Loeschen'      Enfernt ein Verzeichnis.
'Sortieren'     Spezifiziert ein Sortierkriterium, nach Name, Groesse, Datum,
                Zeit, Erweiterung entweder aufsteigend oder absteigend.
'Neu lesen'     Liest das aktuelle Verzeichnis neu ein.
'Pfad'          Spezifiziert eine neue Maske und/oder einen kompletten Pfad.

Suche
-----
Das Ergebnis eines Dateisuche kann wie eine normale Dateiliste (ohne
Verzeichnisse) behandelt werden.

Baum
----
'Umbennen'      Vergibt fuer ein Verzeichnis einen neuen Namen.
'Erstellen'     Erstellt innerhalb des aktuellen Pfades ein neues Verzeichnis.
'Loeschen'      Entfernt den ausgewaehlten Eintrag.
'Komprimieren'  Komprimiert den ausgewaehlten Teilbaum (was nur moeglich ist,
                wenn es entsprechende Unterverzeichnisse gibt, was durch ein '-'
                Symbol gekennzeichnet ist).
'Expandieren'   Expandiert einen Teilbaum (wenn der ausgewaehlte Eintrag mit
                einem '+' Symbol gekennzeichnet ist).
'Oeffnen'       Oeffnet eine Dateiansicht basierend auf dem ausgewaehlten
                Verzeichnis/Pfad.

Erweiterungseditor
------------------
Ueber den Erweiterungseditor kann jeder Erweiterung eine Applikation zugeordnet
werden, die dann durch ENTER aktiviert werden kann. Wenn also ein Eintrag 'CHS'
verknuepft ist mit einer Applikation 'A:\APP\CHESS.APP', und eine Datei
'Game.chs' mit ENTER ausgewaehlt wird, wird die Applikation 'Chess.app' mit
dieser Datei gestartet.
Wenn Sie mit der Auswahl einer "unverknuepften" Datei ENTER druecken, erhalten
Sie den Dialog zur Erstellung einer Verknuepfung automatisch.
'Einfuegen'     Fuegt eine neue Erweiterung in die Datenbank ein.
'Aendern'       Aendert den ausgewaehlten Eintrag.
'Loeschen'      Entfernt den ausgewaehlten Eintrag.

Entpacken von Dateien
---------------------
Filer unterstuetzt auch das Entpacken von Dateien mittels des Programmes
'Unzip.img', welches z.B. ueber das Palmtop Forum in der CompuServe bezogen
werden kann. Kopieren Sie die Applikation einfach in ein \Run oder ein \App
Unterverzeichnis wie vorgesehen, und starten Sie dann das Entpacken durch
simple Auswahl einer '.zip' Datei und Druck auf ENTER.

Beachten Sie auch die Verfuegbarkeit der kontextsensitiven Hilfe!
