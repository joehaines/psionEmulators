Golf Caddie v2.00
This program is a great score/stats keeper for your golf game.
You can key in a score card and keep score using the Psion.  Player
statistics, running scores, yardage, handicap etc are all stored,
including a full stats generator.

Installation Notes:
The following is a breakdown of each file included in this ZIP file.
Please note that when you unzip this file use the -d parameter to
retain the directory structure!

\readme.txt             This file.
\gc.pic                 Golf Caddie Icon (Use this if you want to create
                        your own Group to contain all 3 programs)
\app\gc.opa             Golf Caddie Program.
\app\gcstat.opa         Stats Package for Golf Caddie.
\app\gced.opa           Golf Course Editor Program.
\app\gc.hlp             Complete help file for Golf Caddie.
\app\gc\walden.crs      A Demonstration Course File. 
\app\gc\walden.pic      Graphics file for demo course.
\app\gc\demo.plr        Example stats file.

Installation Procedure:
Copy all files to the Psion (except readme.txt and gc.pic) while 
retaining the directory structure.

Installing the Golf Caddie Group: (optional)
From the system screen press Psion-G.  Create a group and use the
gc.pic as the icon.  Install each program into the open group (see below)

Installation of Software.
From the system screen press Psion-I.  Select the proper program (ie gc.opa).
Press Enter.  Repeat for each OPA program.
