README.TXT: Overview instructions for Geni 1.51
===============================================

Program:    Geni
Version:    1.51
Date:       1st February 1998
Platforms:  Psion 3a/3c/Siena and Acorn Pocketbook II
Programmer: Martin N Dunstan (mnd@dcs.st-and.ac.uk)
Designer:   Vivienne S Dunstan (vd001@post.almac.co.uk)
Home page:  http://www-theory.dcs.st-and.ac.uk/~mnd/export/geni/
Status:     Shareware (see REGISTER.TXT for more details)
Notes:      This program WILL NOT run on the Psion 5, the old
            Psion 3 or the Workabout Series.

Geni is a fully-fledged genealogical database browser for the Psion
Series 3 palmtop computers. It is designed to be a portable companion
to your desktop genealogy program and will allow you to carry your
family tree around with you in a compact and easily accessible format.
Since Geni was intended to be used with large databases (those
containing more than 5000 individuals and families) it should be 
quick and responsive whatever size of database you have. Indeed Geni
is quicker than the authors' desktop genealogy program!

You are allowed to use Geni to browse to 50 individuals (that is 50
different people or the same person 50 times!) before you must
register your copy. If you do not do so Geni will stop working except
to allow you to register and to read the online help. Once registered
Geni will return to full functionality and you won't be nagged every
time you start the program. Upgrades to future versions are completely
free and so is technical assistance.

If you currently using an earlier version of Geni please read the
UPGRADE.TXT file which explains how to upgrade to this version without
losing all your registration details. Otherwise refer to the
INSTALL.TXT file which gives precise instructions on how to install
Geni onto your Psion. Please read it carefully. If you are still stuck 
you should refer to the manuals which came with your Psion and PsiWin 
(if appropriate) to see if they can help. If all this fails please 
don't hesitate to contact the programmer (mnd@dcs.st-and.ac.uk).

Once you have installed Geni you should read the TUTORIAL.TXT file for
a brief "hands on" introduction to Geni and then the manual MANUAL.TXT. 
For information on future plans for Geni, see the file FUTURE.TXT.

FINALLY: please drop in on the Geni home page now and again for news,
answers to frequently asked questions and other helpful tidbits.
