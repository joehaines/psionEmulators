To Install
==========

1. Copy file GIFVIEW.APP  into the \APP\ directory
2. From the system screen menu, select Apps/Install (Psion + I),
   and select GIFVIEW.APP.
3. Create directory \GIFS any drive (M:,A:,B:), ang copy to this
   directory your .GIF files.
