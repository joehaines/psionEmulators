HALON OPA PROGRAM FOR THE PSION 3A

Please keep in mind that this is only my third program  written for
a Psion.

HALON will (I hope) state a phrase from the movie 2001 "Good evening
dave, everything is running smoothly" in the voice of the H.A.L. 2000
computer.

To install just copy hal.wve to m:\wve
                copy halon.opa to m:\app
Through the Psion system menu install the application.

Once executed it will display a screen to inform you to leave Halon
running and press the system icon button to return to normal Psion
operations.   Now whenever the Psion is turned on you will receive
the above message.

To kill Halon, highlite the running application and press delete.

I hope everyone with a P3a enjoys this.
