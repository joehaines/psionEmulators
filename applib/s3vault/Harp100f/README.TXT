1. FILES

The ZIP-file should contain the following files:

     HARP.OPA
     HARP.HLP
     HARP.FON
     README.TXT



2. INSTALLATION

Copy HARP.OPA to the \APP directory of any drive
Create a directory HARP in \APP
Copy HARP.HLP and HARP.FON to \APP\HARP
Install harp on the system screen with Psion-I
