HAUNTED HOUSE ...
... is an 'adventure' game written for and tested on the 
Psion Series 3a palmtop. As it is written in OPL, it should work
on Series 3c also. It also runs with the Psion emulator software
on a PC, but some graphical events are processed with a different
velocity.


INSTALLATION

Haunted House comes as a ZIP file. If unzipped you'll find

     HH.APP
     F.OPO
     I.OPO
     M.OPO
     R.OPO
     V.OPO
     HH.PIC
     OBJECTS.PIC
     HHREADME.TXT (this file)
     HHLIES!.TXT (German HHREADME.TXT)

You have to put the files on your Psion this way (ask Psion 
manual for help):

(Be sure to have at least about 95 k free memory on a local 
drive for the program, about 73k on INTERN for the running 
program and 1200 bytes on INTERN for registration and score 
files.)

Make a directory HH in the main path on any local drive (INTERN,
A or B - RAM, or FLASH will work, too).

Copy  HH.APP,  all *.OPO,  HH.PIC and  OBJECTS.PIC to that 
directory.

Install application by PSION-I (change 'DISK' to proper drive, 
use TAB-key to select \HH\HH.APP as 'FILE: NAME'). That's it.

While running  the program generates additional small files: 
HAND1.PIC, HAND2.PIC, HAND3.PIC, HAND4.PIC, BOX.PIC. 
They are put into the HH directoy you created. The
automatically generated files SCORE.BIN and REGDAT.BIN  are 
always placed on LOC::INTERN:\HH


DEINSTALLATION

Remove Haunted House icon by PSION-/  (differs in different 
language versions, see manual!)
Delete all directories \HH on any drive.
It is as simple as that. And this was the reason I decided
to keep all files in \HH and not to spread them to \PIC,
\OPO and \APP and so on.


PLAYING Haunted House

All the information you need is in the game.  Start the game and
begin with the HELP button, then try out the MENU key.

One hint: try to act naturally, the puzzles are not that absurd.
