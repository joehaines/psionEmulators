Some holidays can be added as repeating entries.
Menu option to mark only non-repeatable holidays.

FR.HOL by Denis Casanova

* V2.0

Church in Wales holy days by the Revd Ian Day.

Major version number changed due to new directory for holiday files.
Holiday files and help file are put in directory \HOL\ to be easy to
install and remove - just move or delete the whole directory.
HOL is now an .OPA with an icon.
Repeating entries can be made to repeat forever (as before) or until
the end year.
Dates are shown in the format selected in the Time application.
Adapted to Siena (tested on the emulator). Some dialog prompts are
different on the 3a and Siena. Some error messages can get truncated.
Increased maximum number of entries to 101.
The program uses less memory in all normal cases.
Added mors dag and fars dag to SE.HOL.

* 2.1C

Changed version number in the program to 2.1 (forgot to do that for the
2.1 release).
Small changes to HEBREW.HOL and UK.HOL.

I have finally decided on how to use version numbers. Released versions
of the OPA will have numbers such as 2.1, 2.2. The ZIP-file will have the
same version number as base, with a letter added if any other file than
the OPA has been changed. HOL021C.ZIP contains the same OPA as HOL021
but with changed HOL files.
