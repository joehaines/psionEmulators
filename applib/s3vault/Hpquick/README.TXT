Hpquick v1.0

This is a modification to the original source code for PASON4 for the Psion.  It was modified so as to suit my needs - I was not interested in a password protector that would enable my password at regular intervals, nor one that would enable the password x minutes after switch off.  What I wanted was one that would enable me to easily turn on the password when I was going to be leaving the Psion, yet to be able to turn the Psion off without enabling the password should I be working at my desk, so that when I turned it on again it would be ready to use.

Hence HPQUICK.  The keys are simple:

PSION + OFF (Normal off key) - Turns off Psion and ACTIVATES password

PSION + CTRL + 2 - Turns off Psion without password

PSION + CTRL + 3 - Exits HPQUICK wherever you are

There - it is that simple!  It may take a little getting used to the strange new method of deciding how to turn the Psion off, but I soon got used to it.  It has saved me a massive amount of time when I would otherwise be entering passwords.

You will not that I have included the source code - feel free to modify it if need be.
