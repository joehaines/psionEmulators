   on the system screen.

   The current version of HTML viewer, has the following features :-
   1.  You can interrupt or scroll the display while the page is processing...
   2.  Supports Image GIF, PSION's PIC & transparent GIF & animated GIF...
   3.  Supports HTML special character...
   4.  Supports mostly text formatting tags...
   5.  Supports hyperlink tags...
   6.  Supports Remark Tag and Meta Tag...
   7.  Supports Background, Text Colour and background image...
   8.  Supports Background Sound <BGSOUND> {MSIE extension}....
   9.  Supports Blink Tag {Netscape extension}...
   10. Supports TABLE tags...
   11. Supports FORM tags...
       Form inputting supported.
   12. Additional Pull-down Menu Selection....
   13. Supports Launch Application Program for specific file extensions.
       (only .WRD, .SPR, .DBF *Editable)
   14. Supports nearly-unlimited lengths of HTML document, limited to RAM Size...
   15. The ability to Find text within a document.
   16. Supports Document width more than PSION Screen width.
   17. Additional Pointing cursor for faster select Hyperlink.

   All "GIF" files will be convert into "PIC" files before display, and this
   conversion process is a background job for each "GIF" file. After
   conversion, the "PIC" file will be stored into a
   "LOC::M:\WWW\CACHE\" directory.

   Basically, you need to free up LOTS of memory to handle these files.

   The future versions of HTML Viewer will hopefully have the following
   features :-

    1.  Long file name support
    2.  JPG file support
    3.  A WYSIWYG HTML Editor
    4.  Frames support
    5.  Internet access.
