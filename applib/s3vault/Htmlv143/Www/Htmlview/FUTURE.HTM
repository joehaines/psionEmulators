Future Versions

Future versions of HTML Viewer have the following features planned:-

  1. Support Java Applet.
  2. Support VBScript & JavaScript.
  3. Support On-line browsing. (another software)
  4. Support for JPG files.
  5. Support for long file names.
  6. A WYSIWYG HTML Editor. (same software)
  7. Support for the Frame tag. (Maybe)
Future versions of HTML Viewer will be shareware!
