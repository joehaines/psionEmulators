• File Menu
    • Open File, open a HTML, TXT, GIF, PIC, WVE file.
    • New File, create a blank HTML, and you can edit in view document source function.
    • Exit, exit HTML Viewer, on exit it will clean up memory and save user settings.
  • Edit Menu
    • Find Text, Find the text matched. (case ignored)
    • Find Next, Find next matched. (case ignored)
  • View Menu
    • Refresh, re-display the current screen.
    • Reload, reload the current file.
    • Document Source, Display the HTML source code.
    • Zoom in, enlarge font size.
    • Zoom out, reduce font size.
  • Go Menu
    • Back, open the previous file.
    • Stop Loading, stop the current file loading process.
    • History, open the history list and select the one you need, which is up to 8 history file.
  • Options Menu
    • Fonts, Change default font face
    • Applications, Change View Source Application
    • Launcher, Edit the Launch Helper Applications
    • Set preferences, Change memory usage percentage & system setting.
    • Cache, clear the cache directory, change cache directory location and maximun size
  • Help Menu
    • Guide, Show a quick-reference guide for keyboard usage.
    • About, about this program.
    • Registration, register this software.
