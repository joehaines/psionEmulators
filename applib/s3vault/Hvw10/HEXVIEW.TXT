HEXVIEW 1.0
===========
HexView 1.0 is a fast and compact hex browser for the Psion S3a.

INSTALLATION:
-------------
* Copy the file hexview.opa file to any \app directory
* Install the application by using the install menu item or shortcut from 
  within the system screen.

USAGE:
------
Select a file from the system screen. This app uses two view modes 
(selected by the diamond key):
* In the browsing mode, you can scroll and page through the file by the
  cursor keys
* In the field viewing mode, you can switch between hex and ascii values
  by the tab key
By pressing <ctrl><menu> the output format can be changed.
