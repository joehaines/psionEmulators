IconInst.opa 1.0 is for the Psion Series 3a only.

IconInst.opa 1.0 is a small application to make the Install.opo from Psion
GmbH a bit easier to use. It creates the Script.cfg file required by
Install.opo.

If you are unfarmiliar with the Install.opo application being referred to ,
it is an application that will Auto Install applications to the system screen
after a reset. This works on the S3a only.

IconInst.opa does not do everything that the script can do. It merely
gets a list from left to right and install these apps. I'm working on an
update to handle the complete scripting language.

Installation:

Copy Install.opo to any \opo directory.
Copy IconInst.opa to any \app directory.

After a reset, run IconInst.opa to reconfigure your system screen icons.
