Using:

Copy Extract.opa into any \APP directory and install. Copy the
Icons.all file into any \PIC directory (or any directory of your
choice) and run the application. Select the Icons.all file from
the file selector that appears, and you can then select one of
the icons which will be displayed. The icons will scroll if the
cursor is moved off the top or bottom of the screen. Save the
selected icon using Psion-s or the menu.
