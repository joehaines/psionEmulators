IconVu 1.00 (Freeware)

This tiny utility displays all icons (up to 250 files) in a directory
(initially \PIC\) on the screen. Runs only on S3a.

To install, copy file ICONVU.OPA into any APP-directory and use
PSION-I in the system-menu to create a new entry in any group.

IconVu only reads bitmap-files and does not write any file
to the "disk".
