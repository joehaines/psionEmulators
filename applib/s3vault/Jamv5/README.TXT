Introduction
------------

JAM is an application which gives a Monthly View for PSION 3A Agenda Files.


Installation
------------

Copy JAMV5.OPA to your \APP\ directory and install in the usual way by pressing< PSION>< I>.
Copy  JAM5.WRD to the \WRD\ directory. 
JAM5.WRD can be deleted if not required.

New in Version 5.....

RUNMACRO.OPL and JAM.MCR are examples for use with the 
NEWCRON and MACRO SYSTEM Applications written by Stefan Radig and Tom Dolbilin respectively.

They are NOT required to use JAM. 

(Please read JAMV5.WRD for further details)

Please note that NEWCRON and MACRO SYSTEM applications are NOT supported by 
the Author of JAM so use them at your own risk.

Getting Started
---------------

Launch JAM by selecting one of your  AGENDA files listed below the JAM  Icon and press ENTER. 
Do NOT delete these files - They are the very same files which appear under the AGENDA Icon! 
Press return at any registration dialogues that may appear. 
Press <HELP> for details of special Keys.

Changes Made for Version 5.0 January 1996
-----------------------------------------
Added modifiactions to facilitate use with MACRO SYSTEM. 
Changed behaviour of JAM after adding Entries.
JAM now only prompts to re-sort the file rather than re-processing the AGENDA File.

Changes Made for Version 4.0a November 1995 (limited release)
-------------------------------------------------------------
Fixed minor bug where crossed our or deleted repeating "Monthly Days"
entries were still displayed in JAM.

Changes made for Version 4.0 October 1995
-----------------------------------------

1.General Optimisation of the code for speed with rewrite of some of the internal algorithms for determining crossed out entries.

2.Added ability to optionally read Untimed Entries.

3.Added ability to add Untimed Entries.

4.Overlaps are now shown as small white boxes!

5.Changed to a New Icon !

6.Changed method of registration.There is now no need for an additional module (JAMREG3.OPO) for registered users.

7.Find is much faster

8.Text display when using + Key is now faster.

9.Flashing Cursor.

10.Cursor movement is now faster.

11.To keep the size of the temporary files small only the first 
40 characters of entry text is saved.
JAM only displays the first 40 characters of a long Agenda Entry.

What you get when you register

Automatically set  the time format to am/pm or 24 hour. 
The settings set in the Formats option of TIME application will be used.
