Overview
--------
This small program alters the way the backlight times out. Normally it
times out when the appropriate time has passed regardless of whether
the machine is being used or not. The program changes this so that it
is related to the last time a key was pressed (in a similar way to
that of the switch off timeout).

The information is taken from how the System has been set to operate
and, in the case of mains being present and the machine set to not
switch off if mains is used, the backlight will also stay on until
manually switched off.

The manual switch on and off of the backlight is not affected but, if
the program is running when the light is switched on, it will then
timeout dependent on the keyboard usage rather than time alone.

Installation
------------
The program can be placed anywhere convenient on your Psion but it
will require running using RunOPL or something similar to JBLaunch.

Once started it can be closed on the System screen by highlighting the
running program name and pressing Delete. If you press Enter then you
will be taken to a blank screen and exit can be caused by pressing
Escape.

There is no setup to be done and no other files are created when using
the program however, for it to work correctly, the program must be
running otherwise the machine will revert to its normal mode of
operation.
