Game of Kapara for Psion 3
Freeware ('as is', 'no warranty', etc..)
by Tal Dayan, tal@netcom.com
Version 1.0, December 10 92

===================================

Kapara (I invented the name, don't know the 'official' name) is a two 
player game.  
In this implementation of Kapara for Psion 3, you play against the 
computer.  

Installation
1. Copy kapara.opa to \app directory of the Psion 3.
2. Install it as application using the <psion>-I key in
   the system screen.

Activation
1. In the system screen, highlight the 'Kapara' pseudo document
   name and press Enter.

Rules
1. The game is played on a 2 by 8 board.
2. Your pieces are marked with 'U', the computer pieces are marked
   with '3'.
3. The computer always makes the first move, this puts the computer
   in disadvantage and enable you to win.
4. Each piece can move any (non zero) number of squares to the left
   or to the right.  A piece can not move vertically.
5. A piece can not be moved over an opponent piece.
6. Each player, in his turn, must make exactly one valid move.
7. A player which can not make a valid move (in his turn) lose.

Keys
1. arrow keys - move cursor (the square marker).
2. Escape - abort the game.
3. space or Enter - make a move to the current cursor location.

Hints
1. The computer plays a perfect moves.
2. The player who makes the first move (the computer) is in disadvantage
   state.  By playing perfect moves, the other player (i.e. You) can
   always move.
3. Since the computer plays best moves. making a single bad move
   will enable the computer to win.
