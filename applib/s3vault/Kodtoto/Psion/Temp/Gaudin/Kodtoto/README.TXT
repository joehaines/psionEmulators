General documentation for Jacques Gaudin's applications



INSTALLATION

Jacques Gaudin provides his softwares "pre-installed" (that is each file
in the relevant directory or sub-directory). You should therefore unzip
with the "...... option"... then just transfer the directories, install,
and enjoy. (I know, if you read, you unzipped already... well, do it
again then)
if you can only unzip "untidily", then:
All softwares :   .wrd in \WRD   .app in \APP   .hlp in \OPD
Iko3a:            .iko in \IKO   .pic in \OPD
Libiko:           .pic in \OPD
Trac3a:           .tra in \TRAC
Vek:              .vek in \VEK

Jacques GAUDIN always makes sure his opas can be transferred in ANY
directory on ANY disk, files in \OPD on ANY disk, and dedicated
directories (\IKO, \VEK ...) on ANY disk. (I, at the moment I write,
successfully holds Dklic.opa on the A: and Dklic.hlp on the B:)


OTHER SOFTWARES available from Jacques GAUDIN (as of now !)

DKLIC offers some of the options you would like as extra in standard DATA
application. It lets you search your data bases in a list mode, can sort,
can write a reduced base as result of a search, lets you add a new field.

IKO3A is a fully featured Icon Editor. It's main point is handling black
AND grey (yes, AND, not OR. If you think of an object being first drawn in
BOTH colours, then you "slide" the grey plane down and right a couple of
pixels, you will instantly get a shade. That works wonder with letters !-)

KARACTER is a pack of 3 tools for programmers. One gives you the character
map of the S3a in different fonts. The second lets you try any key
combination then gives you decimal and hexadecimal code. The third lets
you try a text of your choice in any font and style at any position on
the screen, then returns the OPL you can include in your program.

KODTOTO is an encryption program you can use on absolutely any file, not
just those from WORD and SPREADSHEET.

LIBICO now comes with Iko3a. It lets you create Icon Libraries from
individual icons. Iko3a on the other side can import a single icon from
libraries.

REP3A pilots any DTMF driven answering machine.

TRAC3A is a very elaborate graph plotter. It deal both with "y=f(x)" and
"x=f(u);y=g(u)" functions. It lets you chose the scales and origins and
will display co-ordinates of any chosen point. Trac3a includes a database
for the functions and options you want to keep for further use.

VEK is a vectorial drawing application. Storing vectorial drawings uses
far less memory than storing bitmaps ! Vek documentation provides OPL
example on how to read and display Vek pictures in your own programs.
Hopefully the applications you'll provide in the future will take less
disk space.

VISUPLUS reads and displays normal pic files, or any single plane of
multi-pic files, can even associate one file as black and another as
grey. Images so extracted can be zoomed (handy if they come from a S3)
and saved as new pics. V+ also features a new version of COPECR, which
renames screen.pic as soon as created, so you can do many hard copies
in a row.

They'll all be uploaded at Imperial... as soon as I translated the
respecting documentation, but you can get the all lot from Jacques
himself.


JACQUES CAN ALSO PROVIDE

A set of macros (using Tom Dolbylin's Macro System) that can be used
with the PC Emulator to reset all the keys according to your actual 
keyboard. This is useful to all those who have no QWERTY keyboard,
as Emulator does not check PC config, making it a real pain for non
Anglo-Americans using AZERTY, QWERTZ etc.

A set of batches that can be used with MCLINK for automatic backups.
As Jacques did not have RCOM at that time, he managed almost the
same using MCLINK, a proper mclink.pif and his set of .bat.
The choice of still using MCLINK rather than RCOM or even WINLINK3 
is dictated by the GREATEST feature of MCLINK ; it lets the S3 read
the PC. (Real shameful mistake they dropped that with RCOM !)

ABOUT MYSELF {:-)

I haven't had the guts yet to release any of my poor production.
(though I call myself an IT technician, jumping from Cobol to OPL is
a world of difference) I felt I had a moral duty to contribute to the
well being of Series 3 community.   So...

Recently I played with a game called SOLO (from "official" games pack
nø 3, yeah) on the 3a, and, surprise, it came in supposed French (on
the "French" S3 it used to come in English !!!) and it was rather that like
that sort of language you find in Chinese gadgets documentation, including
an awfoul lote ov speeling misteacks.

The most ridiculous was original "Cheat used once! - Cheat used 'n' times!"
you would get each time you used the Cheat option, had been translated
"trichez 1 fois! - Vous voulez tricher 'n' temps!".
Back translated, it would mean "you must cheat 1 time! - You're willing to
cheat 'n' beats (as musical tempo) or 'n' weathers (as meteo forecasts)"

I thought this was really bad for the image of what I proudly consider
a real COMPUTER.   So...

I decided my English (still far from perfect) was good enough to propose
myself as a translator from English to French. There was so much UK sofs!
Of course unless some one's willing to pay, I will only accept to do the
work if I have some feeling for the application (does not mean I have
personal use of the app, just that it brings something new, it seems
reliable, and ergonomy is good enough). But when I decide to do it, I'll
do my best, including tests, to avoid the sort of rubbish I've mentioned.

Oeuf Corse English not being my mother tongue, it was a kind of a challenge
having a go at French to English, but I decided Jacque's stuff was really
worth it. Then forgive me if I left some wrong spellings, or if some of
my sentences sound crooked to you Island's natives.
