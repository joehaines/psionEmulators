1. Installation:
================
If you have unzipped the ZIP file with the `recreate directory'
option (`-d' with PKUNZIP) then you can simply copy the files
across.  If you cannot `recreate directory', here are the
details of where the files must go.

(a) Copy LANDMINE.OPA to the \APP\ directory on your
		Psion (on any drive).  Copy MINEDATA.PIC to the
		\OPD\ directory on your Psion (on any drive).
(b) In the Psion System Screen, press Psion-I or select
	`Install' from the `Apps' menu.  Choose LANDMINE.OPA
	as the filename and press Enter.  The LandMine icon
	will appear on the system screen. Press Enter on it to
	play the game.

Please see the help screens for playing instructions.

Note:
-----
	LandMine will create a small file on the Internal drive to
	store the most recent settings.
