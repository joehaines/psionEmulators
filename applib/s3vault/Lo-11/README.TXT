Lights Off - for the Psion Series 3a/c - V 1.1 released 05th MAR 97.

Lights Off is a fiendish puzzle game with 200 levels & high quality speech.

To install it copy LIGHTS.OPA into the APP directory on any device, then
create a directory on any device called PSITECHA, if you have any of my other
programs, then use your existing PSITECHA directory, you may only have 1
psitecha directory. If when later copying files your Psion reports that the
file already exists, select 'overwrite'.

If you dont know how to create the directorys, instructions follow:-

Press the SYSTEM button

Press the MENU key

Under 'Disk' select 'Make directory' and press Enter

Next to 'Name' type APP

Select the disk you wish to use, 'Internal, A or B' and press Enter

Now use the same method to create a directory called PSITECHA, this time typing
PSITECHA next to 'Name' instead of APP

The PSITECHA directory does not need to be on the same disk as the APP directory

For a full istallation (130k), copy all the remaining files except this one into
the PSITECHA directory.

For a small installation (49k), copy as above, except for  LV.SDN, 01.SDN to
20.SDN, 30.SDN, 40.SDN, 50.SDN.

For a minimum installation (18k), as above, but do not copy any files ending
with .SDN.

Once the files have been copied, press SYSTEM, then MENU, then select INSTAll,
select LIGHTS.OPA and press ENTER. An icon will then appear for LIGHTS OFF,
select this to begin the game. Instructions on how to play are in the game,
just press the Help key, once the program has started.
