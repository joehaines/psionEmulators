To install the LanguageWorks shareware
from floppy disk, copy all files into
a directory \LW\ on an external, or the
internal disk (SSD).

Using the application INSTALL option
( via the system screen menu ), locate
file LW.OPA in the \LW\ directory.

Once installed correctly, the ICON for
LanguageWorks will appear.

Instructions
============

All options are accessed via the main
menu. To return to the menu at any time
press the MENU key.

Menu options are self explanatory.

Within the dictionary or phrasebook,
press HELP for more help.

LanguageWorks Features
======================

* Support for 5 European languages
  ( 3 for shareware version )
  
* On-line dictionary giving singulars
  and plurals.

* Dynamic phrasebook which allows
  complex phrases to be constructed.  
  
* Ability to translate TO and FROM any
  of the supported languages.
