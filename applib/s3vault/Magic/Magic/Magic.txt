Introduction
------------

"Magic" is a cool little magic trick program for your Psion 3c.  When
you run it, it shows you six playing cards and asks you to just think
of one.  Then, you press the Space bar and the Psion makes your chosen
card vanish from the rest!  Amazing!  :)



Installation
------------

(1) Create a directory called "Magic" inside the "App" directory of
any disk of your Psion 3c.  The program does not write to this disk
when running, so you can safely install it to a Flash SSD if desired.

(2) Put the two image files ("magic1.pic" and "magic2.pic") inside
this "Magic" directory.

(3) Put the "Magic.opa" file inside the "App" directory of the disk
you chose.

(4) Install the program icon by pressing Psion-I at the System Screen.



Using The Program
-----------------

Very simple: Upon execution, you are told to think of any card and
press the Space bar.  Be amazed!  :)  When the trick is done, you can
only quit the program and NOT do it again without re-running it.  This
is to help stop people asking to see the trick over and over (which
they will).  Just tell them that each time you run it the batteries
get drained a bit due to the screen flashing effect.  :)
