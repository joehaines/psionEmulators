Mancala 1.0  (April 1997)      -=-  S3A 
---------------------------------------
This is my first attempt at creating a PSION game.  Actually, this is
my first OPL program that really does something...

I think it is not that bad for a first application.  If you want, just
drop me an email telling what you think of it, or any suggestions to
improve the game; I would really appreciate.

The help file gives all instruction necessary to learn how to play.

I would like to thank Frederic Botton for his patience and
all the help he gave me when I was lost...
He is the author of a couple great games for the PSION (Greedy,
Mille-Bornes, Memory)  You should take a look at them!!!
His home page is
     http://ourworld.compuserve.com/homepages/FBotton/psion.htm
His latest one, Greedy was released not too long ago.  I followed it's
development in the last phase, and that's what gave me the urge to try
to create something myself in OPL.

Installation
------------
-Copy the Mancala.opa file in your APP directory
-Create a subdirectory called Mancala in your APP.
-Copy all the other files on that directory.
-Install the game using the PSION-I hot key.

Aditional files
---------------
The Mancala game will create a single file that holds the settings.
The file located in your  \OPD directory is called OKSoft.ini
If you remove the OKSoft.ini file, you will loose all the current 
settings, but it will recreate itself the next time you run the game.
                     
Known bugs
----------
The only known bug at this point is that if you play on the PSION Emulator
on the PC with sound on, it will hang.  This is because I simulate key clicks
with a BEEP -1,10 which the emulator does not like.  If someone has a better
way of simulating the key clicks, please let me know.

Although this program has been tested over a decent period of time, there
might still be some bugs in it.  If so, please send me an email and I will
correct it.
