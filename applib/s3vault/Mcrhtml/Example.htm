Psion's homesite

The macro will aid you in creating HTML documents on your Psion by inserting the tags for various HTML commands. It came about because i wanted to work on some web pages whilst away from my desktop m/c, and a macro seemed an appropriate way of inserting the basic tags to save me some typing. The tags for paragraphs, forced line breaks etc don't really need a macro since they are at most four characters long but i've left them in for completeness.

Since i released the macro i have recieved a fair amount of feedback regarding the macro's operation & the HTML language in general. Because of this i have re-written a most of what was initally an extremely simple if not crude macro, the result you have here is still being developed but hopefully i have created something a little more user friendly and that it aids you in some small way in learning / creating HTML documents.

As always if you have any comments regarding the macro or the HTML language in general please feel free to email them to me.
