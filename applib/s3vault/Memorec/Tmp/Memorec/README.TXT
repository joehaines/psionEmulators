1.1a Qu'est ce que MemoRec ?

     MemoRec est un programme qui permet d'enregistrer tres rapidement
     et facilement des fichiers WVE comme memos. Il les appelle automatiquement
     MemoXX.WVE, ou un autre nom si vous le desirez.
     L'avantage principal de MemoRec est sa tres petite taille (2347 octets).

1.1b Installation

     Vous devez avoir recu le programme avec les fichiers suivants:
        Nom           Taille (octets)
        MemoRec.OPA   2347
        README.TXT    Ce fichier
        
     Pour installer le programme:
       a. copiez le fichier MemoRec.opa dans le repertoire \APP\ de
          n'importe quel disque (A, B ou Interne).
       b. Installez l'icone de l'application dans l'ecran systeme
          comme pour une autre application (Psion-I).
          
1.1c Utilisation

     Le programme est aussi intuitif que possible. Avec "O", vous
     definissez les options:
       -Nom par defaut: si Memo, alors les fichiers crees seront MemoXX.WVE
       -Duree Max.: duree max. de chaque memo en secondes.
       -Disque: disque ou les fichiers crees iront.
     Pour enregistrer un memo, appuyez sur Psion et maintenez la
     touche enfoncee. Quand vous entendez un bip, vous pouvez commencer
     a parler. Quand vous avez fini de parler, lachez la touche Psion.
     Allez sous l'icone Magneto dans l'ecran systeme, et vous pouvez
     voir qu'un nouveau fichier a ete cree.

2.1a What is MemoRec ?

     L'avantage principal de MemoRec est sa tres petite taille (2347 octets).
     MemoRec is a program that allows quick and easy recording of WVE files
     as memos. These are automatically called MemoXX.WVE, or anything else
     you wish.
     Its main advantage is that MEmoRec is very small (2347 bytes).

2.1b Setup

     This file should have come with the following files:
        Name          Size(bytes)
        MemoRec.OPA   2347
        README.TXT    This file
        
     How to install the program:
       a. copy the file MemoRec.opa into an \APP\ directory
          on any drive (A, B or Internal).
       b. Install the application icon into the system screen
          like any other app (Psion-I).
          
2.1c Quick use

     The program was kept as intuitive as possible. Use "O", to
     set options:
       -Nom par defaut: if set to "Memo", the files created will be MemoXX.WVE
       -Duree Max.: max. lenght of each memo in seconds.
       -Disque: disk where the created files should go.
     To record a memo, push the Psion key and hold it down. When you hear
     a beep, you can start talking. When you are finished, stop holding
     the Psion key. Go under the Record icon, in the system screen, and
     watch the new file created.

     I'm sorry this program only speaks French, but here are
     the translations of the words used in it:
       -Enregister memo = Record a memo
       -Options = (goes without saying...)
       -Quitter = Exit
       -Place disponible = free space
       -Nom par defaut = Default name of the files created
       -Duree max. = Max lenght of the memos (secs.)
       -Disque = Disk
       -Confirmer = OK
       -Annuler = Cancel
