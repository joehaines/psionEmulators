
MILLENNIUM CLOCK  by Mike Panchaud

This program will display the number of days, hours, mins and seconds to or from almost any date and time. Default values are for the next millennium.

Note: auto switch of is DISABLED when running, even when in the back ground so exit using escape when not required.


Installation
Copy Mill7.opa to any \APP directory and use Psion I from the system screen to install as normal. The MM icon should appear.
