MoC                  Master of Ceremonies                by John Hind
---------------------------------------------------------------------
SUMMARY

Master of Ceremonies (MoC)  is an application for the PSION Series 3
Pocket Computer to assist people  who have to control any structured
event such as a conference, meeting, tutorial, television  programme
etc. It can also be used by individual presenters to keep their talk
to time and act as an electronic cue card.         MoC is Shareware.
---------------------------------------------------------------------
FEATURE LIST

* Full PSION Series3 application. Installs as icon on System Screen.

* User definable schedules made up of headings and time slots.

* Plan schedule based on relative time or fixed start or end times.

* Show start and end times for whole schedule and for current time
  slot. Show text for current and next time slots or heading.

* During event, show countdown timer for running time slot,
  estimated schedule finish time and over-run or under-run.

* Show analogue or digital clock, according to system setting.

* Slots and headings may be changed, moved, deleted, added and
  copied, singly or in marked blocks.

* Future part of schedule may be changed while schedule is running.

* Find text in headings or time slots and find time slot at a given
  time.

* Use template schedules for standard events.

* Copy headings and time slots between schedules.

* Three types of optional audible alarms.

* Log a schedule run to record actual durations of time slots.

* Print schedule via the "Word" application.

* Exchange data with other applications on PC, Mac or S3.

* Work in 24Hr clock or am/pm time according to system setting.

* Outline-based on-line user guide using the "Word" application.

INSTALLATION

Minimum Installation (Requires 20k bytes):

1. Copy the file MOC.OPA to the \APP directory on the Internal, A or
   B disk on the Series3.
2. Copy the files MOCLIB.OPO and FRAMELIB.OPO to the \OPO directory
   on the Internal, A or B disk on the Series3.
3. At the System screen, press Psion-I (Install application) and
   select the file "Moc.opa" from the disk you copied it to.

The MoC icon will appear. When you select this icon and press [Enter]
the application will start up with an empty schedule.

Example File (Requires additional 800 bytes):

1. Copy the file EXAMPLE.MOC to the \MOC directory on the Internal,
   A or B disk on the Series3.

"Example" will appear below the MoC icon and this schedule may be
used to try out MoC without first having to do any data entry.

On-line User Manual (Requires additional 14k bytes):

1. Copy the file MOC.WRD to the \WRD directory on the Internal, A or
   B disk on the Series3.

"Moc" will appear below the Word icon and you can use the on-line 
User Manual by highlighting it and pressing [Enter]. It is designed
for full screen width, so first hide the clock panel by pressing
[Control][Menu]. Use the "Word" key to toggle between headings
outline and full detail views. Because the Series3 is a multi-
tasking machine, you can quickly switch between the manual and
the application in a way that makes this on-line manual concept
practical.

Configuration Options:

See the file "TECHREF.TXT" for details of installing the
configuration options.
