Version 2.1a
- the import script, now version v.2b, has been changed
  to work with ReadCis 1.7
- to change the format for the input and display of exchange
  rates, one now has to press <Tab> twice
- the <diamond> key is now used to show the dates of last
  update and the currency strings.
- some cosmetic changes, and marginally higher speed in some
  parts. 

Version 2.1
- fonts were changed for better readability of the screen.
- the date of update can be set manually, in case the latest
  rate available is from a date prior to the date of input
  (default is still today, but one can enter any other date).
  Same change in "import from text file" mode, for when one has
  to import from an "old" text file.
- the default directory for import files is now /cis/library/,
  so that download can be checked from Readcis (v.1.6). The
  script has been modified accordingly.
- the rate update command (Psion-U) is now effective also when
  a selection of currencies is displayed.
- the registration process has been changed: registered users
  will now receive a code to enter in an appropriate dialog window.
