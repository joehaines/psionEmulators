Quick Start
===========
(If you don't like reading manuals)

This ReadMe file is a quick introduction to MPG, a freeware fuel
efficiency utility for the Psion Series 3. This file contains the
information needed to install MPG. Note that it will run on the
Psion Series 3a in S3 compatibility mode.

MPG allows the 'mpg' (miles per gallon, or metric equivalent)
efficiency of one or more vehicles to be calculated using a
database of odometer (milometer) readings, and the amount
of fuel added to a vehicle.

When run, MPG will create a \MPG subdirectory on your default
disk.


System Requirements
===================

MPG requires 7 KB of disk space at installation time. Plus about
2 KB per car per year (depending how often you fill the vehicle.)
When running, it needs about 15K of system memory.


Installation
============

The files in MPG11.ZIP are:

    File (size)           Description             Destination
    ----------------------------------------------------------
    MPG.OPA (7155)        Main application        \APP\
    MPG.WRD (7298)        User guide              \WRD\
    MPG.TXT (1583)        This file!              \WRD\


Further information
===================
For more info about MPG, refer to the user guide MPG.WRD Psion Word
format document.
