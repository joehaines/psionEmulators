This ZIP file holds an Agenda file holding main holidays
and notable days for 1997, 1998 and 1999.

To update your current Agenda file:- 

1)      copy the HOLS.AGN file to a suitable drive on your 
        Psion.

2)      Enter Psion-M for the MERGE menu.

3)      Select the required drive for the new file

4)      Select Hols and press <CR>

After merging the file HOLS.AGN can be deleted if required.
