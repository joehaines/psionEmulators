What are Plugins?
-----------------

Plugins are extra add-on programs that work with Notepad Deluxe. They are 
unique in that they show up on Notepad's menu, which makes them appear to
be part of Notepad. Plugins can do many different things. There is really
no limitation to what a plugin can do. Information about writing plugins 
is available freely on our web page. (Listed at the top of this file)


What are .ctl files?
--------------------

Some plugins include a file with an extension .ctl. These are installer
files that can be used with PsiSetup, the setup utility that ships with
some Psion programs. (On floppy) Therefore, you may or may not have this
PsiSetup program. If you don't, the ctl file is of no use.


Installing Plugins
-------------------

1. Copy the plugin file (with a .plg extension) to any \App\Npad\Plug directory.
2. In Notepad, press Psion-W to bring up a list of plugins.


User.plg
---------

Remember that one plugin can be named user.plg, and this plugin will be launched
when pressing shift-tab in Notepad Deluxe. However, your plugin must support this.
Most plugins are being rewritten to support this. To check, rename your most used
plugin to user.plg. Try pressing shift-tab. If it runs you know it supports this. 
Otherwise, rename it back to it's original name and it will work again.
