INSTALLATION:

In the oasis2.zip file you should have 8 files:

readme.txt - this file

oasis.opa - main program 

liam.pic }
noel.pic }
logo.pic } -- These files go in the same directory
oasis.pic}
gig.dat  }
disc.dat }

Copy the oasis.opa file to the 'OPA' directory on your psion.

Then Copy the other 6 files, excluding this readme file into the 'OPD' directory on your psion.

Hence:

oasis.opa  -  in OPA directory

liam.pic } - OPD directory
noel.pic } - OPD directory
logo.pic } - OPD directory
oasis.pic} - OPD directory
gig.dat  } - OPD directory
disc.dat } - OPD directory

If you don't have either an 'OPA' or a 'OPD' directory then using PsiWin, click on your Psion drive (usually called 'internal'). Go to 'File' on the menu and click on 'Create Directory' and then type in either 'OPA' or 'OPD'.


You'll then have to add the OASIS icon to the system screen so that you can run the program. To do this, go to the 'Apps' option on the menu and select the 'Install' option. This will then display the first file it sees in the OPA directory. If you can't see OASIS.OPA, then use the Cursor left and right keys to move through the files until you find it. 
If you don't find it then you haven't copied OASIS.OPA into the right directory, so get back to the beginning of this Installation chapter to double check.

RUNNING OASIS;

If when you click on the OASIS icon, you get an error message saying 'No System memory'. This means you don't have enough free memory on your Psion to run OASIS. You can free up more memory by deleting other files you don't need.


PROFILES:

This option gives a profile of every member of the OASIS group.


ALBUMS;

Having highlighted this option, you will get three other options:

Definitely Maybe
What's the Story
Be Here Now

These are all the albums the band have ever produced. Selecting one of these albums will take you to another menu displaying all the singles on that album. Select a single and your will be taken to a screen like this;

Fig 1.
        Rock 'n' Roll Star
	------------------
	No Comment

	   edit    enter
          { E }   {Enter}

The whole point of this is so that you can enter a comment on every single of every album for what you think of that particular song and possibly edit it at a lated date, or just view it.
If you haven't entered a comment then it will just say 'No Comment'.
To edit this, press (E)dit and type in your comment and press <ENTER> when you've finished. If you've pressed Edit and then changed your mind and you don't want to edit the comment, then press <Esc>.
To just view your comment and continue, press <ENTER> when you get to the screen as Fig 1.




BE HERE NOW REVIEW;

This is a review by myself of the most recent OASIS album, BE HERE NOW.



GUITAR TABS;

I've included the Guitar Tabs for five of Oasis's songs as transcribed by me from listening to their songs on CD.
Having selected a Song's Tabs, use <ENTER> to go to the next page and <Esc> to go to the previous page.


GIGOGRAPHY;

This is one of the grand features on OASIS. It has every Gig Oasis played at between 1991 and 1997 June 14. 
It begins in 1991, to move to the next Gig, press (N)ext and to go to the previous Gig, press (B)ack.
There is also a search facillity so that you can search for a Gig by name.
Press (F)ind and then enter the text to search for and press <ENTER>

DISCOGRAPHY;

This is similar to GIGOGRAPHY except there's no search facillity because there's not enough to search for.
It displays a few OASIS singles and the other tracks released on that single.
Use (N)ext to go to the next Single and (B)ack to go to the previous.
