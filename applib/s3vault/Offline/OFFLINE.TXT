INFORMATION.

Offline is a offline mail reader for Cix users. It allow view and
navigate in all messages downloaded presenting them in a ordered
fashion.


INSTALLATION.

Copy OFFLINE.OPA into a \APP directory on a A: B: or M: drive.
Then select 'install' from your APPS directory on your system screen
and select  'OFFLINE.OPA'.


USAGE.

Once you are in the program hit the menu button.
Just select what you want to do, press return and see!


MOVEMENT.

Up/Down keys scroll the message.
Right/Left moves of one message.


LISTING.

Select List from menu or press Psion-L, go to a message and press
Enter else press ESC and you remain where you are.


RELATED MESSAGE.

When a message is a note of another, selecting Related message or
pressing Psion-R you jump to the main message.


FIND.

Use Find or Psion-f. Fill up dialog box. Pressing Enter you jump to the
message that contain selected string. Psion-g or Again find next occurrency.
