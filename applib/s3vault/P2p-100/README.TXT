System Requirements
-------------------

PCX2PIC (the 16-bit version) will run on any PC with approximately 200K of
available DOS memory. PCX2PIC3 (the 32-bit version) requires an 80386 or
better processor.


Installation
------------

To install PCX2PIC, type d:INSTALL where d: is the drive (and, if
appropriate, the directory) which contains the install program, then follow
the on-screen prompts. After a successful installation, you may wish to add
the PCX2PIC installation directory to your PATH statement in the AUTOEXEC.BAT
file.

Once PCX2PIC is installed, view the file PCX2PIC.TXT, which contains the main
documentation and the FAQ's.

The file WHATSNEW.TXT describes the new features in this version.


Description of PCX2PIC
----------------------

PCX2PIC is a PCX to Psion PIC file converter. It allows PCX files to be
converted to black, grey or black and grey (2 plane) Psion PIC files. This
allows graphics to be drawn or processed on the PC rather than drawing them
on the Psion.
