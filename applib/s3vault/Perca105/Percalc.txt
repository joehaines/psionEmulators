INSTALLATION


Copy the file PerCalc.opa to any \app directory. Then install on the system screen using 
Psion-I. 


GETTING STARTED

The progarm runs in a loop until you press escape. This makes it idea for working on figures
that use repetive percentages. 

All you need to do is enter any two sets of figures and the progarm will calculate the 
remaining data.
