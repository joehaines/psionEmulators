Telephone Dialler
-----------------
This is really a Database to hold telephone numbers,
with the added ability to dial a telephone, via
a small circuit board interface between the Series 3 -
Comms Link and a telephone.
Most telephones can be modified to take it providing
they have a hands free facility. 
Parts of the program will be of no use, without 
the interface.
If anyone is interested in the automatic dialling
side of it, I could probably knock up more of the
Interfaces.

SETUP
-----
Copy file    TELE.PIC  To directory    M:\OPD\
Copy main program      PHONE.OPA  To directory  M:\APP\

Then From Main menu Install Application PHONE.OPA


TELEPHONE  DIALLER  SHORT CUT KEYS
----------------------------------

FROM  VIEW DIRECTORY
***********************

LEFT ARROW  = VIEW Next Record
RIGHT ARROW = VIEW Previous Record
UP ARROW    = SELECT Number to Dial
DOWN ARROW  = SELECT Number to Dial
TAB         = VIEW  Address
DELETE      = DELETE Current Record 
PSION + E   = EDIT  Record
PSION + I   = INPUI New Record
PSION + S   = SORT the Database 
PSION + F   = FIND Record 


FROM  VIEW ADDRESS
*********************
PSION + E   = Edit Address  Details
PSION + I   = Enter Address Details

NOTES
======
A Record cannot be DELETED when viewing the 
Address details
The Database is SORTED on the Feild holding the SURNAME
