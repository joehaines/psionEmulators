Palmtop Picasso - Readme File.
=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

Introduction.
=============
Thank you for trying Palmtop Picasso.  Please take the time to read this file.
Palmtop Picasso is a drawing program for the Psion Series 3a only.
It can be used for viewing pictures or for creating pictures from scratch.
There are many drawing tools to choose from, such as line, ellipse, box, etc.
as well as many editing tools, such as Rescale, Skew, Emboss, etc.
Getting good results, however, does require some patience.

Installation.
=============
In order to run Palmtop Picasso, you will need between 83-181K of free
disk space (depending on how many of the optional files are installed).
If you are short of disk space, see the following for details of the
files that are required/optional.

Whilst running, about 90k of system memory is required.
Please note, however, that the bigger the image, the more memory needed.

The following files should be contained in the PICASSO2.ZIP file.
Please install in the directories as shown.

File         Size  Directory       Comments
--------------------------------------------------------------------------
Picasso.opa  34935 \APP\           This is the main program (Required)
Misc.opo     23825 \APP\PICASSO2\  This is a support file   (Required)
Open.opo     24112 \APP\PICASSO2\  This is a support file   (Required)
Picasso.pak  31752 \APP\PICASSO2\  Support file             (Recommended)
Default.pas    594 \APP\PICASSO2\  Pattern details          (Recommended)
Ding.wve      5152 \APP\PICASSO2\  Sound File               (Optional)
Picasso.hlp  32529 \APP\PICASSO2\  Help file                (Optional)
Picasso.txt   5983 \WRD\           This file                (Optional)
Example.pic  19200 \PICASSO\PICS\  Example file             (Optional)
Courier.fon   2538 \APP\PICASSO2\  Example Font             (Optional)

The above directories can be created on any local disk (Internal, A, B).
Install the application as you would any other application.

When Palmtop Picasso is installed and run for the very first time,
several things happen.  They are not really important, but if you
want to know what happens see 'APPENDIX A' at the end of this file.

What's New in Version 2.
========================
There are several new additions to Palmtop Picasso,
There is now the ability to include animation's,
There is a built in Icon Designer,
Better support for the Psion emulator on a PC,
Gradiant backgrounds,
There is an very handy preview option (including the option to
preview a whole directory),
Importing is supported courtesy of Andrew Baldwins FirePic
conversion program,
and a few other changes that are probably not noticeable.

Using Palmtop Picasso.
======================
It takes a while to get to grips with how Palmtop Picasso works.
If you want Palmtop Picasso to do something, then it probably can.
Try looking in the help file, and if you can't find what you want,
feel free to contact me.
Just about everything you need to know is included in the help file,
so it's advisable to install it, even if it's just until you are familiar
with the way things works.

Bugs and unfinished code.
=========================
Palmtop Picasso does contain 'bugs' and there are also some features
that are unfinished.  This may at first seem unprofessional,
but Palmtop Picasso is an ongoing project and if I didn't release it
until it was perfect, then it would never see the light of day.
There should be a steady stream of new releases as various options are
completed and the bugs are fixed.
The majority of the bugs should crop up very rarely if at all, however,
should you find a bug, or should the program crash on you,
then by all means get in touch and let me know what happened.
it may be one that I'm unaware of.

Known bugs and unfinished code.
1) It is only possible to import one picture per session.
I don't know why this problem is occurring, but it should be fixed soon.

2) The Icon Designer doesn't currently have any menu options.
The Icon Designer will automatically detect if the file you are
loading/creating is an Icon and launch accordingly.

3) The help file is not completed due to size limitations.
This is a priority and should be fixed soon.

Palmtop Picasso does require a lot of memory to run,
especially if grey is include and/or the dimensions are large.
Problems may occur when trying to load/create such files.
This is unavoidable and the only recommended action
is to have as much memory free as possible.

Appendix A.
===========
When Palmtop Picasso is run for the first time, \APP\PICASSO2\ is created
on the internal drive.  This directory is used to hold various information,
such as all the preferences and settings for Palmtop Picasso.
You will also see a message saying that the cursors are being installed.
These will also be placed in the above directory.  It is quite safe to
move them to a different disk.
