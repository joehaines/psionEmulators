                PicPoc Version 2.1 - Release Notes
                -----------------------------------

Program Description:

Advanced painting tool for PSION Series 3 computers.

Includes features such as:
 Polyline, Rectangle, Rhomb, Ellipse, Text, Pen, Eraser, Fill,
 Spray, Lupe, Undo, Copy, Cut, Paste, adjustable pen, eraser,
 and spray size, different text fonts and styles, different and user
 definable fill patterns, scrolling in large bitmaps.

New in Version 2.1: 
        - A new shape: rhomb
        - Selectable and user definable shapes for pen, eraser and spray
        - The lupe has now a separate menu.
        - Pattern clusters can now be of any size.
          pattern height and size is a third of cluster height and width.
          This allows a lower pattern frequency.
        - Pressing the Shift key when using the cursor keys for scrolling
          tilts the cursor direction by 45 degrees against the clock. 
          This makes it easy to 
          draw diagonals, squares, "square" rhombs, and circles.
        - Definable background colour.
        - Insertion mode : set,delete,invert,replace.
        - Undo can be switched off (to save memory)

Installation
============


1. MacUsers only !!!
   If you received propoc on a floppy disc first convert the floppy to 
   Mac format (System Utilities).
   If you received propoc via an electronic network decompress it with
   ZIPIT (found on your network). The standard UNZIP will cause errors.

2. Connect your Series3 computer to your PC or Mac.
   Press PSION-L from the system screen to activate 3Link.

3. Set the cursor under the RunOPL-icon and press TAB.
   When the file selection screen appears, press TAB again.
   Specify under "Full path" the name of your floppy drive,
   e.g. REM::A:\ on a PC or   REM::label:  on a Mac.
   If you received propoc via an electronic network specify the folder
   where you unzipped propoc.ZIP.

4. Now select the file 3setup.opa. Press ENTER. 3setup now takes control.
   The screen goes blank for a few seconds. Don't panic.

5. Acknowledge the selected application "PicPoc" by pressing enter.

6. The file transfer is started. If PicPoc was installed before,
   SetUp will start a dialog asking you if you want to
     (Continue) = Overwrite existing version
     (Other drive) = Install on another drive
     (Options only) = Install option you did not install the first time.

7. SetUp asks you on which drive you want to install the system (PicPoc)
   and on which drive you usually keep your data.
   We recommend flash memory for the system and RAM for data.

8. SetUp will ask you about optional modules. You can decide to install
   them now, or you can leave it for later.
   
9. SetUp will give you instructions on how to proceed after the successful
   transfer.

Folder structure on the Series3/3a:

The application path is "PIC\"
The extension is PIC.

a:\app\picpoc.opa
a:\app\picpoc\piclan.opa
a:\app\picpoc\pattern?.pic
a:\app\picpoc\*.fon
a:\app\picpoc\shape?.pic
m:\pic\picpoc.pic


Requirements:

The installation routine informs of the size of each option. 
A full installation needs approximately 30k disk space.

When active, the system requires >11k of memory depending on 
the size of the bitmaps.
