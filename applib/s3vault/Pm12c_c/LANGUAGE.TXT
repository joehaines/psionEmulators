your favorite spreadsheet program.

variable names!). Then correct the wrong or untranslated strings and delete
completly those rows which are correct or mark the corrected rows (e.g. with
an 'X' in the right following cell).

After correcting please save the file again as tabulator separated ANSI
text file and send the (ZIP compressed) file to my CompuServe ID 100024,333
(Internet: '100024.333@compuserve.com') or upload it into my BBS.

Thank you.
