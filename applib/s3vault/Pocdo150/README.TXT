                PocDoc Version 1.5 - Release Notes
                ==================================

Program Description
-------------------

 PocDoc is an electronic diary for monitoring your health.
 You can monitor things like:
 blood glucose, cholesterol, weight, etc.

 Data can be displayed in months, weeks, days, hours, and average days.

 Dual charting lets you compare different data.

 Data can be printed to printers or into ASCII files.


 PocDoc can store emergency data and supports dialing.


Platforms
---------

 This program runs on PSION S3/S3a/S3c/Siena ACORN PocketBook I & II.

 PocDoc can also run on the S3a- or Siena-emulator with screen sizes up to 640x400.


Requirements
------------

 The installation routine informs of the size of each option.
 Depending on options 41-69k disk space are needed.

 When active, the system requires >12k of memory.

New in version 1.50
-------------------
- progress report
  can be activated for each diary.
  Shows changes since last entry and reference point after entry of data

- Calendar (menu function)
  documents important medical events.
  Can raise alarms.

New in version 1.45

New in version 1.40

  for a selected event or a specified time window.

New in version 1.33
-------------------
- Paper size in printer setup (PSION-Y)
- Landscape format for graph printing on some printers
- Multiple copies for printouts
- Printer timeout detected.

New in version 1.32
-------------------
- Margins for printing added (PSION-Y)

New in version 1.3
------------------

- Setup of dial constants has been removed.
  Instead the system settings are used.

- Improved user interface
  - Support for diamond key and status window (S3a only)
  - Settings for review, chart, dual chart are kept for next session.
  - All hotkeys can now be used without pressing the PSION key.

- Reset function in Review/Charts
- Tidy and Chart function avaliable from Review submenu.

- The print setup function has been integrated with the system print setup function.
  All selectable printers are supported (Canon, Epson, HP, IBM, Apple, Postscript).
  Please read the Printing section!

- New threshold value in diaries.
  Identifies recommended value that should not be execeeded
  under normal circumstances.
  The threshold value is displayed as a stronger line in charts.
  Values exceeding the threshold value are displayed italic in the review.

- Daynotes
  Daynotes are WORD-documents that are associated with specific days.
  They are created, changed, removed via the Review function, but they
  are independent from diaries.
  (A daynote for a certain day will appear in all diaries that have
   events on the day).
  Daynotes are not removed if events are deleted but it is possible to
  remove unreferenced daynotes with the Tidy function.

  When Shift-Enter or PSION-+ is pressed, WORD will be invoked to edit
  the daynote. If F11 is installed, F11 will be invoked instead of WORD
  for easy typing.

  Note: Each daynote will take at least 700 bytes of disk space.
        So a large number of daynotes can take a considerable amount
        of disk space.
