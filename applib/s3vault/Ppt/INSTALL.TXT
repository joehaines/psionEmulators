This file contains installation instructions for the Psion Phoneday Tools.

These instructions assume that you have the files comprising the Psion
Phoneday Tools on an SSD or the internal disk of your Series 3 or 3a
machine.

If you acquired the Tools on an SSD from Psion, place this SSD in one
of the drives on your machine and proceed with the appropriate set of
instructions below.  To have these applications available even when
this SSD is not in one of the drives, copy the files Phonefix.grp,
Phonefix.app, Wldfix.app and Convert.app to the internal drive before
installing.  See the "Files and Disks" chapter of your computer's
User Guide for information about copying files.

If you do not have the files on one or other of these media, for
instance if you acquired them from an online service, you will need
to copy them there before you proceed.  This can be accomplished by
using a 3-link cable and associated software.  The files should be
placed in the directory \APP of the destination disk.  For more
information, refer to the manual which came with your 3-link.


Series 3
========

  1.    Switch on the computer and go to the System screen.  Select
        the position where you want the icons for the Psion Phoneday
        Tools to be placed.

  2.    From the "Apps" menu, select "Install application" (Psion-I).

  3.    A dialog entitled "Install application" will appear.  Locate
        the file "Phonefix.app" using the top two file selector
        fields.

        For example, if this file is on the SSD in drive B, move to
        the Disk selector and press B.  Then move to the Name
        selector and press the left and right arrow keys until the
        name Phonefix.app appears between them, or press Tab and use
        the file selector (see the "Files and Disks" chapter of your
        Series 3 User Guide for more details) to locate this file.

        If the file is on the internal disk, there is no need to
        change the Disk selector, which defaults to Internal.

  4.    Press Enter.  A new icon will appear on the System screen
        with the title "phONEfix" underneath.

  5.    Repeat steps 2-4 for the files Wldfix.app and Convert.app.

        Alternatively, if you are comfortable with the file selector,
        you may tag all three files and install them simultaneously.
        Again, refer to the "Files and Disks" chapter of the User
        Guide for more information.

There should now be a total of three new icons on the System screen,
meaning that you have successfully installed the Psion Phoneday Tools.

The file Phoneday.grp is not relevant to the Series 3 installation
process and may be deleted.


Series 3a
=========

You may install the Tools in two ways on the Series 3a machine.  The
first is exactly as above.  The second is to install the Tools as a
new Group.  You may prefer to do this, as the Tools will in this case
only take up one icon position on the system screen.  To install in
this way, follow these instructions:

  1.    Switch on the computer and go to the System screen.  Select
        the position where you want the icon for the Psion Phoneday
        Tools group to be placed.

  2.    From the "Apps" menu, select "Install application" (Psion-I).

  3.    A dialog entitled "Install application" will appear.  Locate
        the file "Phonefix.grp" using the top two file selector
        fields.

        For example, if this file is on the SSD in drive B, move to
        the Disk selector and press B.  Then move to the Name
        selector and press the left and right arrow keys until the
        name Phonefix.grp appears between them, or press Tab and use
        the file selector (see the "Files and Disks" chapter of your
        Series 3a User Guide for more details) to locate this file.

        If the file is on the internal disk, there is no need to
        change the Disk selector, which defaults to Internal.

  4.    Press Enter.  A new icon will appear on the System screen
        with the names phONEfix, WLDfix and cONvert underneath it in
        slanted writing.  These are the three applications which you
        have now successfully installed.  Each application may be run
        by highlighting its particular name under the icon and
        pressing Enter.

        For more about Groups, see the chapter "The System screen" in
        your Series 3a User Guide.


In case of difficulty
=====================

If you experience problems with either of the above sets of instructions,
you should read thoroughly the chapters "Files and Disks" and "The System
Screen" in  your Series 3 or 3a User Guide.  These explain the concepts
behind applications and their installation.
