Psaros
Version 1.1
Copyright 1997 C. J. Willis

A program for tide prediction by the harmonic method using a user
modifible database of tide coefficients.


Psaros distribution contents:

Readme.txt		This file
Psaros.opa		The Psaros application
Tide.dbf		A database of tide coefficients
Psaros.ps		Program documentation in Postscript
Psaros.wrd		Program documentation in Psion Word format


Installation

1. Copy the Psaros.opa file to an APP directory on any disk;
2. Install the Psaros application using the <psion i> key combination;
3. Create a \PSAROS directory on any disk using the <psion +> key
combination;
4. Copy the Tide.dbf file to the newly created PSAROS directory;
5. Optionally copy the Psaros.wrd file to the WRD directory for
viewing and printing.

The Psaros application may now be run in the usual way.
