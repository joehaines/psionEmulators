Psetris
*******

Psetris is a copy of the Tetris game. The shapes originate 
from the left and scroll from left to right. As in the 
original when a line is completed from top to bottom it is 
removed. The further to the right the line is removed the 
higher the score. After every six lines completed the speed 
increases by one level, up to level 9. The Help key shows a 
list of the keys used in the game. Pressing Menu gives a 
standard menu.

P.S. the top speed seems to be better if the game is run 
from memory and not a disk.

Installation
************

Copy the "Pset11a.app" file into "\APP" directory on the 
Psion.

On the "System" screen use "Install application" in the
"Apps" menu.

Select "Pset11a.app", press the <Return> key and Psetris 
will be installed on your "System" screen.

When first run the program will create the file "Psetris.dat"
in a directory "\TET" on the default drive. This contains the
high scores.
