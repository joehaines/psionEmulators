Dialog Designer is a program which guides you through
the elements which make up an OPL dialog. When complete,
Dialog Designer writes the OPL code for you.

Dialog Designer is shareware and the public version
contains a cut down version of the functionality.
If this is not sufficient to give you a feel for
the features, please mail me.

Dialog Designer costs $20 to register and for that you
get:

 - a full-feature version of the program
 - technical help via email
 - free updates when new features are added
 - free updates when problems are fixed

To register, use GO SWREG on CompuServe using
ID 7895 to identify Dialog Designer.

The unregistered version does not support:

 - dXINPUT
 - dFLOAT
 - dDATE
 - dPOSITION

but is complete in every other way.

Install Dialog Designer by running Psion RCOM
and then typing INSTALL <Enter> for further
directions.
