PsiVault V1.02, Copyright Bill Belfield.
========================================

PsiVault is a secure database utility for the Psion 3a/3c. If
you are familiiar with the Data app on the 3a, there are certain
ommisions, password protection being one. Another is the secure
storage of data, you may be able to password protect your 3a,
but as soon as you back up your Psion to a PC, your data is
(potentially) accessable.

Psivault stores (optionally) data away in an encrypted format.
Even if your sensitive data is backed up to a PC, the text within
is illegible. Psivault accesses its data either in encrypted or raw
format, with no noticeable overhead in speed.

Additionally, there are varying levels of password protection to
secure the data within Psivault. My intention with Psivault is
that data can be distributed to say, other team members, and a 
"owner" or "supervisor" configures what a user can see,change etc
in the Psivault "book"

Version 1.02 of Psivault is, by default set up as a 8 field data
"book", the default settings is as a phone book. All fields are
configurable/nameable, and the field types are

	1 list field
	5 general purpose fields
	2 general purpose with optional hide/display attributes

The layout is a set format in Version 1.02, the layout is

	<listfield general1 general2	>
	<general3 general4		>
	<general hide/display 1		>
	<general hide/display 2		>
	<general 5			>

The default settings are

	<title forname/initials surname >
	<street town			>
	<fax number			>
	<notes				>
	<telephone number		>

for example

	MR BILL BELFIELD
	16 HAWTHORN WAY,MACCLESFIELD,CHESHIRE
	01625 xxxxxxxxx
	CREATOR OF PSIVAULT,GREAT SOFTWARE
	01625 615306


Psivault books can searched,sorted, entries can be added,deleted
edited etc. Security controls (only available after registration)
restrict operation (optionally) by setting of passwords.

The application is a fully featured Psion application, with Help,Menus and
utilizes the common application status window. The creation of multiple
books is only available to registered users.

Registration is from £10 for a single user registration, registered users
get PsiVault+ for free when programming and testing is completed.

To register, see the registration section in the online help

Additional service offered is the take on of corporate internal phone
directories or databases, full details on this service and registration
is detailed in the on-line help

To install Psivault, copy the following

	PSIVAULT.OPA 	to any \app directory

	SORT.IMG 	to m:\psivault\sort.img
	PRAT.RSC	to m:\psivault\prat.rsc

Other Psivault files are created as required, the default directory
for storing PsiVault files is any \psivault directory from the root,
ie a:\psivault or m:\psivault

Time&Motion

Keeps track of regular daily events, alerts you if you are late taking 
lunch or going home to the wife!!. Configure Time&Motion for your regular
work pattern,length of working day etc, then with 1 or 2 keypresses, track
events like meetings, phone calls etc. The motive for writing Time&Motion 
was to prove that I work longer than 37.5 hours standard time at work !!
