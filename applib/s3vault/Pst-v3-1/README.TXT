Installation
------------

Copy Pssst.app to the APP directory in your internal memory or a pak

make a directory called PSITECHA on your internal memory or pak (note: you may
only have one PSITECHA directory in the internal memory OR a pak)

copy all the remaining files (except this one) into the PSITECHA directory.

if you wish, any of the files ending with .SDN can be ommited, or deleted later
to save space, I recomend that you install them all to start with.

.SDN files starting with K are Kitten sounds, with C are chicken sounds, with B
are bird sounds, and with H are human sounds.

Press the System button, press Menu, and under APPS, select Install, select the
device that you copied Pssst.app, and select Pssst.app, then press Enter.

An icon should appear and the program is installed.
