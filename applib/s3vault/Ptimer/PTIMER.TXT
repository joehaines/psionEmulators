				
				PHOTO TIMER FOR PSION 3A
				====================


INFORMATION
===========

Photo Timer is a simple to use timer for the darkroom for the Psion series 3a machine. The 
Program is freeware, and will work on any version of the 3a. The program maybe freely 
distributed to anyone for private use only. It is not available for use by companies.

INSTALLATION
============

Yhere are three files to CalcVat. CalcVat.opa, CalcVat.pic, and this file CalcVat.txt.
The files should be installed in the following directories which you may have to create.

	ptimer.opa	installed to \APP
	
	timer.pic	installed to \OPD

	ptimer.txt	text file, will need converting to wrd file if put on 3a. This file 
			should not be required on the 3a.

After copying files to 3a, use Psion install from main menu to install icon and program.


THE PROGRAM
===========

Very easy to use. Simply enter the time values in whole seconds for each darkroom process you
are going to use, and then start the timer.
