PowerSound
----------


A program to play Psion .Wve files when the power lead
is inserted or removed.

Takes c8k of memory while running, and does not 
noticeably slow the machine while active.

Runs in the background, then plays user-defined sound
files when run.

Freely distributable - useless, but fun...




Installation

Install to \APP directory, either A:,B:,or I: drive

Press Psion-I from the system screen, and select the
PwrSound.opa file.



To Run

Run the program from the systm screen, as normal.

Select the files to play for Power in & out

Select Volume

Select the delay between system checks.
The program checks the status of the power line
periodically, and the delay between these checks
is input here, in units of 1/20th second.

A recommended value here is between 20-40, though
larger amounts may result in delays between the
power being inserted, and the sound file playing.



Ending the program

Select the highlighted filename on the system screen.
Press <Delete> to end the program execution, in the 
same way as for standard Psion software.
