Introduction.
#############


It is important to remember the concept behind ReadCIX, it was
never meant to be a full OLR such as Matrix or Telepathy,the
size limits imposed by the small memory would make this
impossible. Not from any limitations of OPL or the Series 3
itself, more the problems of fitting a large message base into
2Mb of RAM. ReadCIX was created to cater for the times when you
have not had time to read all the messages downloaded onto a
desktop PC or while you are away and would like to keep up to
date with messages and Mail.

There is no clever or complicated thread handling in ReadCIX,
all it tries to do is either take a previously downloaded
scratchpad or,  a scratchpad downloaded to the  Series3
automatically, and present the messages in a orderly  fashion.



History.
########


Version 1

ReadCIX v1 was written without the use of a Series 3
or any prior knowledge of OPL, the PC Emulator provided by
Psion was used in conjunction with a OPL guide book. It was
really a test version to see if the concept was viable and the
fact that the program actually worked is a tribute to Psion's
foresight in releasing the Emulator and the ease of programming
in OPL.



Version 1.5

A much improved version, Mail was handled in a
consistent way, the presentation of the message was tidied
up and the code was much more robust. There was also  a new
configuration menu to specify directories for scratchpads and
message files so Drives A and B and the REMote drives could be
used.



Version 2

This makes thing much easier as it allows the automated  downloading
of messages via the serial link and a modem. It also supports printing
to serial or parallel printers



Version 3

Still in the planning stage, will allow replies to
messages and Uploading to CIX.



Installation.
#############


You must create a directory off the root directory on the
internal M drive called \cix.



There are four files included in the Zip file:



          ReadCIX.opa : The program itself, copy to any APP
                        Directory.
          ReadCIX.fon : The message header font, copy to the
                        directory \cix on the M drive.
          ReadCIX.pic : The ICON file, copy to the \cix  directory on the
                        M drive.
          ReadCIX.txt : This text file.
          Readall.scr : The script for downloading all mail and messages
                        Copy to a \scr directory
          Readmal.scr  : The script for downloading mail only.
                        Copy to a \scr directory.

Psion-I will then install the program as described in the manual.


Operation.
##########


General.

ReadCIX allows you to browse a set of messages downloaded from CIX, either
by ReadCIX itself or transferred from another computer. It will arrange your
messages into conferences, and you can pick which conferences to read.
While viewing a message you may print the text or jot down notes such as a
reply.

First set up the options in the configure and printer options under the
special menu. If you intend using the built in Comms functions then the
correct connections to a modem must be made and the names file and scripts
set up as described below. Once a scratchpad has been downloaded use the
post option to create the individual message files for reading.

If space is limited on the Series 3 the scratchpad can be posted from a
remote drive using the serial link.

Here is a description of the menu options.

Message Files.
==============

Choose.

Select a conference to read. Whilst reading the following keys are in
effect.

                Esc- Return to Menu
                Help- Basic help text
                Enter- Show next page of message
                Up Arrow- Previous message
                Down Arrow- Next message
                Shift P-  Print message See also Configure
                Shift W- Write note See below

Delete.

Deletes all the message files.


Comms.
======


There are two options Script 1 and Script2. These options will run a user
defined script of the name and location defind in the configure option.

ReadCIX uses the standard Series3 Comms application to connect to CIX,
therefore there are a few things to setup outside ReadCIX before it can be
used. The Comms and Script application must be installed and the serial
link connected to a modem with the correct cables. You must have followed
the instructions in the serial link manual for connecting to CIX including
creating a Names file with the names cixuser,cixpassword and cixnumber
names if you intend to use the supplied scripts.

Finally, a script needs to be created and translated. This can be as simple
as the one supplied with the serial link or can be much more complicated.
There are two scripts supplied, one to download all mail and messages and
one to download just mail.

The supplied scripts will need to be modified before use to match your own
modem and should only be used as a guide.

When a script is selected from the menu, ReadCIX passes control to the
Comms application while the script is running. This allows you to monitor
the progress of the script and reply to any prompts. When the script has
finished, control returns to ReadCIX.


Posting.
========

Post Scratchpad.

This option will read through a downloaded scratchpad and post the messages
to the relevant file. ReadCIX uses the first eight characters of the
conference name as a file name. It will create a file for each new
conference. If ReadCIX finds a conference exist already, IT WILL DELETE THE
FILE before writing the new messages. This has been done to minimise the
amount of storage used. Therefore it is essential to make sure all messages
have been read before posting a new scratchpad. For the same reason a
conference cannot exist twice in the same scratchpad, this will not cause
an error, but the first set of messages will be overwritten by the second.

Delete Scratchpad.

Delete the downloaded scratchpad.


Special.
========

Configure.

This allows you to define the following.

                Path for Message files
                Path and name for scratchpad
                Path and name for user defined script files 1 and 2

Printer.

The printer setup menu allows you to specify a parallel or serial printer,
and if serial the settings for the serial port.

ReadCIX is shareware, you have a 20 day evaluation period. After this time

About.

Displays brief details of ReadCIX.


Exit.

Return to the system screen.



Writing notes.
==============

Whilst reading messages, Shift-W will switch to the word processor
application of the Series 3 to allow the writing of notes.
These notes can then be read later when replying to messages or creating
new messages. You will be asked if you require a new file or wish to use a
existing one.
