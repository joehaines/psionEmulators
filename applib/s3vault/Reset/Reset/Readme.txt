Basic Rules.
A grid of 100 buttons is displayed. Some of these are "Off" and some are "On".

Your task is to reset them all to "Off".

Easy you might say.

But here's the catch.

For every button whose status you change you affect 4 others surrounding it.

There are 3 starting levels. on completion of each grid the puzzle gets harder!!


Movement.
Use the cursor keys to guide yourself round the grid.
Press the Enter key to activate the button.

Winning.
The time it took you (in seconds) is displayed when you have reset all the buttons.

Press a key and the next level starts automatically.

Hit MENU at any time for more options.
