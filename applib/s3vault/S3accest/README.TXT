
This disk should contain the following applications :

ACCV1-04.OPA - Purchases and sales cash book accounting.
ESTV1-04.OPA - Estimating and invoicing.
HEXV1-02.OPA - File hex editor and viewer.
ICOV1-02.OPA - Application icon generator.
TIMER.OPA    - Count up/down timer and clock.
XZENON.OPA   - Tetris style game.
DEMO.OPA     - Graphical demo.

There are brief instructions for the first four applications in both text 
and Psion word format. The rest should be self explanatory.
Some of the applications have help available via the HELP key.
