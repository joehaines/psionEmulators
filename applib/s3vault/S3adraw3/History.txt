History of S3ADRAW
------------------

6 Sep 94  Version 1.0 written for personal use

27 Sep 94 Version 1.1 issued as Shareware.

05 Aug 95  Version 1.2 issued with the following changes:

a.	Icon/Zoom drawing speeded up by nearly 100%.
b.	A line added to the 'zooming' to show progress.
c.	File handling commands added to Icon menu.
d.	'Return to Viewer' option added to Icon screen.
e.	Default directory changed to \PIC, to match other Psion programs.
f.	Ctrl, Home, and End implemented on cursors.
g.	Individual modes for Text, Line, Box and Circle implemented.
h.	Cursor now always displayed in Editor mode.
i.	Different cursor styles implemented.
j.	Circles can now be drawn inside a box.
k.	In Copy mode, the area actually moves with the cursor.
l.	A 'Move' mode has been implemented.
m.	A multiple copy (Paste) mode has been implemented.
n.	Ellipse drawing now supported.
o.	The Info window is enhanced, and it's position is configurable.
p.	A freehand or 'Sketch' mode is implemented.
q.	Individual pixels can now be set from the editor screen.
r.	Pictures can be 'cropped' to change size.
s.	Filled circles and ellipses implemented.
t.	Line width now extends to circles and boxes.
u.	Dual-sized Status Window now implemented.
v.	Help extensively rewritten.

28 Dec 95  Version 1.3 issued with the following changes:

a.	General redesign of the program logic and user interface.
b.	Option to cancel a Zoom at any time during Zoom window drawing.
c.	Starting a new picture takes you directly to the editor.
d.	Sketch mode now uses the 'Line' mode settings.
e.	A Reference Grid option added.
f.	After a picture is imported, the location can be moved.
g.	Info Window now shows colour in use.
h.	Font & Style menu option combined.
i.	Error trapping of 'Low System Memory' and 'Disk Full' added.
j.	Extended character set added to Text Entry.
k.	An Export Area of screen option added.
