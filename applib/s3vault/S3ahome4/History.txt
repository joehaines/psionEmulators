HOME INVENTORY (S3A Only)
-------------------------

History:

08 Mar 95	Initial Issue of V1.0

08 Apr 95	Version 1.1 issued with the following enhancements:

	a.	Edit memo function implemented.
	b.	Improved error protection in case of low System memory.
	c.	Status Window switching implemented.
	d.	Diamond menu switching implemented.

12 Jul 95	Version 1.2 issued with the following enhancements:

	a.	Multiple Houses are now supported, with all the appropriate 
		File Commands.
	b.	Each House can have a 20-Character Title.
	c.	The Description Field has been extended to 25 Characters 
		and the	Serial No field extended to 20 Characters.  
	d.	Pressing the first letter of a Room or Category will now 
		take you straight to it.
	e.	Updating of the value of all items by a certain percentage, 
		to allow for inflation is now implemented. 
	f.	Each Item now has a 'Purchase Date' added to it.  
	g.	Items can now be shown by category.  
	h.	A Print function has been added.
	i.	A Password function has been implemented.
	j.	In the Item screen, the right/left arrows cycle through 
		rooms/categories.
	k.	Decimal places are configurable.
	l.	Currency Separator is configurable.

15 Dec 95	Version 1.3 issued with the following enhancements:

	a.	File Renamed to S3AHOME3.ZIP to reflect it's affinity with 
		S3ABANK.
	b.	A new Icon, compliments of Andy Waller.	
	c.	Increased capacity to 25 Rooms/Categories and 80 
		Items per Category/Room.
	d.	Allows for a decrease in value as well as inflation.
	e.	Allows you to update by categories.
	f.	Left/right cursor to cycle through houses.
	g.	Date format fully configurable.
	h.	Total number of Items per Room/Category now shown on Item 
		screen.
	i.	Adding a room puts it in at the cursor rather than at the 
		end.
	j.	Option to remove a room/category from the total value.
	k.	A 'Find Item' routine added.
	l.	Inter-House Moving and Copying now allowed.
	m.	Print function now includes date.

07 Jul 96	Version 1.4 issued with the following enhancements:

	a.	Proper Printing System, including PSIWIN support, implemented.
	b.	Proper Psion compatible Help system implemented.
	c.	Option to use Swiss Font.
	d.	Date Formats extended.
	e.	Move Room/Category Command now offers a destination position.
	f.	Alphabetical, Date and Value Sort routine added.
