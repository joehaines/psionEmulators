ANIMATE

	Animate is a simple program that enables a number  of .PIC files
 to be displayed in sequence, to create a pocket slide show or animation
 effect on the Psion Series 3.

	The program file "animate.opo" should be loaded into an \opo\ directory
and any files with the extension .PIC loaded into an \opd\ directory.

The delay between displaying each file can be changed between 0 and 20 seconds.

	A sequence of files must all have the same title, the first part of
 the file name, followed by a number, starting at "1" and numbered contiguously
 to the end of the sequence. The file extension can be any legal one but will
 normally be .PIC.
 e.g. a sequence of files with the title "test" would be :-
	test1.pic  test2.pic ---  test15.pic  etc. to the end of the sequence.

	To produce the best animation effect achievable by the Series 3 the
 delay should be set to "0". To produce a slide show where text has to be read
 a delay of 5 to 10 seconds would be more suitable.

	The program continuously cycles through the sequence until boredom
 sets in and "Q"  is pressed.

	I have included a couple of primitive sequences to give the idea :-
		"eye"  set the delay to "0".
		"sw"    set the delay to "5  seconds".
