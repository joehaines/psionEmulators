INSTALLATION :
==================

6 files are in the SAME's package :

	-  ReadMe.txt
	-  SAME.OPA
	-  SAME1.FON
	-  SAME2.FON
	-  SAME3.FON
	-  SAME.RSC

Installation steps :

	1 - Create a sub directory in APP\ : SAME\
	2 - Copy the files as indicated below :
		SAME.OPA	->	APP\SAME.OPA
		SAME1.FON	->	APP\SAME\SAME1.FON
		SAME2.FON	->	APP\SAME\SAME2.FON
		SAME3.FON	->	APP\SAME\SAME3.FON
		SAME.RSC	->	APP\SAME\SAME.RSC
	3 - Install SAME.OPA (psion-I)
	4 - during the first use, 10 files will be created in the directory  APP\SAME\



USING SAME :
===============

During the game, have a look at HELP and MENU.

SAME is a shareware. It means that :
	- If, after a period of test, you decide to keep it, you have to contributr to the author (see "About" in HELP).
	- You can freely distribute this software unmodified and including every files of the package.


CHANGES V1 -> V2 :
======================

	* Bug fixed in Top scores.
	* You now can choose the language using in the  game between English and French.
	* Preferences are saved on the disk.
	* Registers users of SAME v1 will freely receive a code for SAME v2.

enjoy.

INSTALLATION :
==================

Le package SAME est composé de 6 fichiers :

	-  ReadMe.txt
	-  SAME.OPA
	-  SAME1.FON
	-  SAME2.FON
	-  SAME3.FON
	-  SAME.RSC

Procédure d'installation :

	1 - Créer un sous-répertoire dans APP\ : SAME\
	2 - Copier les fichiers comme suit :
		SAME.OPA	->	APP\SAME.OPA
		SAME1.FON	->	APP\SAME\SAME1.FON
		SAME2.FON	->	APP\SAME\SAME2.FON
		SAME3.FON	->	APP\SAME\SAME3.FON
		SAME.RSC	->	APP\SAME\SAME.RSC
	3 - Installer l'application (psion-I) SAME.OPA
	4 - Lors du premier lancement, 10 fichiers seront créés dans le répertoire APP\SAME\



UTILISATION :
===============

Une fois SAME lancé, appuyez sur les touches AIDE ou/et MENU.
SAME est un logiciel diffusé suivant le mode shareware. Cela signifie que :
	- si, après une période d'essai, vous désirez le conserver vos devez payer une contribution à l'auteur (voir "généralités" dans l'AIDE)
	- vous pouvez diffuser largement ce logiciel, à condition que tous les fichiers de ce package soient présents et non modifiés.
