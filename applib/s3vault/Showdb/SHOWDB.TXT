SHOWDB by Ned Robinson

SHOWDB is my first OPL program.  It allows any dbf file to be viewed in a
browse-like manner, showing the first 2 fields of the database.  After 
you specify the dbf file to view, you can scroll through the display.  

The following keys are used for navigation:

Down-Arrow      Down one record
Up-Arrow        Up one record
Psion-down      One screen down
Psion-up        One screen up
Psion-Home      First Record
Psion-End       Last Record

Psion-F         Finds the first record matching your test.  You can insert 
                wildcards into the search string.
Psion-G         Finds next Record
Psion-R         Finds previous Record

Psion-O         Open a new file
Psion-S         Setup the column spacing for the current file

Enter           Displays the first 5 lines of the datafile
Menu            Displays a menu

The default column spacing is set for 23 and 14.  This works fine with my
datafile that has the following format:
        
        Robinson,Ned...........(212) 555-1212

However, you can always press Psion-S and change these settings.  A future
version will allow these settings to be saved.

For example, I also have a "Dates" file that I set to 10 and 27.
        05/19.....My Birthday
