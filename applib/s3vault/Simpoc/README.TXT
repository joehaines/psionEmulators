		SimPoc Version 1.01 - Release Notes
		-----------------------------------

Program Description:

A typical spreadsheet program for the PSION Series 3 computer.
Includes features such as:
 
 Save as text, Merge in, Save as template, Print,
 Insert, Copy, Delete, Edit, Revert,
 Jump, Find, Find again,
 Bar, Pie, Graph,
 Recalculation counter, All CALC functions in formulas,
 Operations over cell arrays, invocation of OPL programs,
 invocation of formulas from OPL programs.

 26x39 cells, fast scrolling and evaluation due to techniques
 such as lazy evaluation and result caching.
 Recognition of cyclic definitions.


Applications:

Usual spreadsheet applications. 

Installation:

You may want to use the file SPINSTAL. First change the drive letters to your requirements,
then call under MCLINK "@SPINSTAL". Then install the application via PSION-I.


Content of this disc:

Modules:       simpoc.opa, sgraph.opa, rsset.opa

Spreadsheets:  holiday.spd

Documentation: readme.txt, simpoc.wrd, spinstal, spreg.txt



Requirements:

The system requires about 18k of disk space, the manual about 8k.
When active, the system requires 38k of memory.

Other products:

HyperPoc is a card oriented hypertext an hypermedia system.
Cards are organised in stacks (files). Cards may be superimposed with backgrounds.
Cards and backgrounds can contain a variety of objects, such as:
  application, bitmap (animated), card link, clock, expainer, hotTab, icon (animated),
  keyword, music (planned), phone number, polyline, rectangle, text.
Functions include:
  Invocation of Series 3 applications, several navigation functions, phone dialling, 
  alarms (planned).
Comes with 30 icons. Version 1.01 is freeware.

A good complementing product for HyperPoc is PicPoc. PicPoc is a fully fledged paint program.
It allows to create icons and bitmaps up to a size of 640x400 pixels. It includes the usual
tools including spray and fill patterns (even custom fill patterns). Freeware.
