                SokoBan V1.3

Install the file sokoban.opa in any \app directory and original.dbf
and extra.dbf in any \app\sokoban directory.

The object of the game is to push the objects to the shaded gray area, but
be careful not to create `deadlock': you may only push one blob at a time
and you can't pull.

Sokoban contains 3 level sets: The levels in original.dbf are the 50
original levels from the 1984 Dos version of Sokoban and are
generally of much higher quality than the levels in extra.dbf.
More.dbf contains a collection of quite hard levels.

Thanks to Jean-Pierre Kent for pointing our errors in my Original
implementation.

If you've been playing eairler versions of Sokoban you may like to
reply levels 15, 16, 29, 37, 48 and 50 which have been fully
