1. How to install Solitaire 3 on S3a/c
======================================

To install, copy SOL3.OPA to the \APP directory on any drive. On the
same drive make a directory \APP\SOL and copy the following remaining
files into it.

To add an icon to the system screen, press PSION-I on the system screen
and select SOL3 using the cursor keys and ENTER.


2. Playing Solitaire 3
======================
To start a new game select "new" from the "Game" menu.

To start play move any Aces from the seven row stacks to the four spaces
(known as the suit stacks) at the right of the screen using the cursor
keys to move the pointer and ENTER to pick up / drop cards.

The row stacks may be built up by moving cards either from the deck 
on the left of the screen or from other stacks. On the row stacks, 
cards are stacked in decending order, alternating between black and red 
suits.

If a row stack has no cards in it a King may be used to start a new stack.

On the suit stacks, cards are stacked in ascending order of the same suit 
starting with an Ace.

Pressing ENTER on the deck deals more cards into view which can then be 
placed on the stacks. Once all cards have been dealt the deck is turned 
over again.

Tapping a covered card in the row stacks will reveal the face if the card 
is the last in the stack.

Holding down the shift key whilst selecting a card will attempt to move it 
to a valid position in the suit stacks.

The object of the game is to place all the cards on the suit stacks.",


3. Game Preferences
===================
The perferences menu item allows the following options to be set. Note 
that any changes made will not take effect until a new game is started.

Player Initials          The initials of the player to be entered into 
                         the highscore table.
Number of Cards to Draw  This can be set to either 1 or 3 and indicates 
                         how many cards are dealt when the deck is tapped. 
                         Selecting 1 gives a much easier game but scores 
                         less.
Scoring                  This offers three different types of scoring, 
                         Standard, Vegas and None. See the entry on scoring 
                         for details.
Timed Game               If this item is checked 2 points are deducted from 
                         the score for every 10 seconds spent playing the game.
                         The clock will still be displayed during non-timed 
                         games but no points deducted.
                         Note: Preferences are saved between sessions.


4. Scoring
==========
Two different types of scoring are available (See game preferences entry):
Note: Highscores are only recorded for Standard scoring when Solitaire is 
acheved. Vegas high scores are always recorded.

Standard Scoring
  * Moving a card to a suit stack	scores 10 points.
  * Moving a card from the deck to a row stack earns 5 points.
  * Turning over a card in a row stack earns 5 points.
  * Moving a card from a suit	stack back to the row stacks loses 15 points.
  * If the "Draw 3" option is selected, 20 points are lost each time the 
    deck is turned over, after the third time.
  * If the "Draw 1" option is selected, 100 points are lost each time the 
    deck is turned over.
  * In timed games, 2 points are lost every 10 seconds of play and a speed 
    bonus is awarded at the end of the game.

Vegas Scoring
  * The game starts with a debt of $52.
  * $5 is won for each card placed on a suit stack.
  * The aim is to end the game with a profit.",


5. Numbered Games
=================
Numbered games allow any of thirty thousand games to be played at any time.
To start a numbered game select "Numbered Game" from the "Game" menu. In the 
dialog enter the number of the game required and select "Ok".
