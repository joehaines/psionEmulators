        What is JareWare?     The underlying principles at JareWare
        -----------------     are to create simple programs that
                              perform a specific task well, and to
                              produce high quality software that makes
                              life easier.  Isn't that what computers
                              are supposed to do, anyway?


        What is SmartTip?     SmartTip is a restaurant tip calculator
        -----------------     for the Psion Series 3a.  Whole sections
                              of etiquette books discuss tipping;
                              SmartTip makes tipping easier!  SmartTip
                              is more than an electronic version of
                              those plastic tipping cards.  SmartTip
                              is fully customizable, and will even
                              round your bill to the nearest unit
                              (nickel, dime, quarter) for you.

        Setting Up SmartTip   SmartTip keeps setup information in a
        -------------------   file called JAREWARE.OPD.  This file
                              must reside in the OPD directory.
                              Using SmartTip, you'll be able to adjust
                              and modify these settings to meet your
                              needs.

                              Here are the default settings for
                              SmartTip:
                              Text      Tip
                              --------- ---
             Service1:        Poor       0%
             Service2:        Good      15%
             Service3:        Excellent 20%

             Default Service: Good

             Round to:        25


        Using SmartTip        Simply run SmartTip.  Press <Enter> to
        --------------        advance past the start up screen
                              (when you register SmartTip, the start
                              up screen disappears!).  You'll next be
                              presented with the following screen:
                     +--------------------SmartTip------------------------+
                     |                                                    |
                     |     Bill:    0                                     |
                     |     Service: Good                                  |
                     |                                                    |
                     +----------------------------------------------------+
                              Enter the amount of your bill.  If you
                              press <Enter>, your tip will be
                              calculated based on 'Good' service
                              (15%).  If you want to calculate the tip
                              based on another type of service, press
                              <Tab> after entering the amount.  The
                              'Service' field displays arrows on
                              either side of 'Good'.  You may press
                              <Tab> again, and a list of choices will
                              appear.  Select the appropriate choice
                              and press <Enter>.  Press <Enter> once
                              more to calculate the tip.  You'll see
                              the following screen:

                     |  Rounded Tip/Total:  3.44/27.00                    |
                     |                                                    |

                              Pressing <Enter> will allow you to
                              calculate another tip or modify
                              SmartTip's settings.  Pressing <Esc>
                              will exit you from SmartTip.

                              If you pressed <Enter>, you'd see the
                              following options:
                              +------------------------------+
                              |   File   |   Help   |        |
                              | Setup    | Register |--------+
                              | Calc Tip | About    |
                              | Exit     |----------+
                              +----------+
                              You may select any of these options by
                              navigating the menu or by pressing the
                              associated <Psion><key> combination.

             Setup            This option will allow you to change any
                              of the default settings.  After
                              selecting this option, the following
                              screen will display:
                     +------------------Modify Setup----------------------+
                     |                                                    |
                     |  Service1:             Poor(0%)                    |
                     |  Service2:            Good(15%)                    |
                     |  Service3:       Excellent(20%)                    |
                     |  Default:                  Good                    |
                     |  Round to:                   25                    |
                     |                                                    |
                     +----------------------------------------------------+
                              Use the arrow keys to highlight the item
                              you wish to change and press <Enter>.  A
                              screen will display to allow you to
                              modify the value you selected.  Make the
                              desired change and press <Enter> to save
                              the change or <Esc> to cancel.

             Calc Tip         This selection will allow you to
