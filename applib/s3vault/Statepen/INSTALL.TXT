Statepen.zip
============

UK State Pension Calculator - Installation

Information about the program in included in the enclosed .wrd 
file. To install:

1. Copy statepen.opa to any \APP\ directory
2. Copy bee.pic to m:\pic\
3. Copy membdef.dbf to any \SERPS\ directory (optional)
4. Copy serpsdef.dbf to any \SERPS\ directory (optional but 
strongly advisable)
5. Do what you want with Statepen.wrd. It provides help 
and information about the program.

Enjoy it!
