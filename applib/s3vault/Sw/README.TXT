To install 
==========

Create a directory on the internal drive called m:\app\sw
	(From the system screen Press :<Psion><Plus>)	

Copy the Two files (SW.OPA & SW.PIC) to this directory

Install the SW Icon Using the <Psion><I> Keys.

At the "File:Name" Prompt press <Tab>

Use the arrow keys to select the "\app\sw" Directory and 
press <Enter>

Highlight "Sw.opa" and press <Enter>

Finally select a Position for the Icon and press <Enter>

The Program is now ready to run.

(I only have an Internal Disk and so have never tested the Program 
 on any other Drive. I don't know of any thing in the code to 
 prevent the 'OPA' from being installed in any location. I would be 
 Interested to hear how (if) it run on Drive A: or B:)


Background
===========

This program was developed using the Built-in OPL Language.
It is based on the internal time tick and not the system Clock.

There are a few shortcoming's in the program which I may fix 
given sufficient demand.

1	The StopWatch will not work with the power off.

2	The Auto-Off will not work while the Program is active.
