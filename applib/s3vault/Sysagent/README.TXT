SysAgent II (c) Richard Riley 1997
----------------------------------

System setup utility -
	multiple configurations
	sleep mode
	on-line help

INSTALLATION

If you want the files already in their correct directory structure,
unzip the compressed file with the "-d" option (pkunzip -d ?????.zip)
so that the directories appear correctly.  Otherwise:

File:			Destination:		Description:
README.TXT					this file
SYSAGENT.OPA		\app			main program
SYSAGENT.RSC		\app\sysagent		help file
BACKGND.PIC		\app\sysagent		wallpaper

The help file is optional but I *strongly* recommend
that you include it - it contains important information
as well as plenty of help.

The wallpaper is just a little 12x12 bitmap.
