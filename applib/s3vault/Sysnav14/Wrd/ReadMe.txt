(2) DESCRIPTION

Systematic Navigation is a Psion 5/3 solution for astronomical
and coastal navigation.  The combination of the versatile
hand-held Psion Series 5/3 personal organiser and Systematic's
easy-to-use application software will assist you with a
wide range of navigational tasks.

The object of the manual is to help you get the most out of
the application.  The manual provides background on the use
of Systematic Navigation and the methods used in its
formulation.  It also provides in a portable, convenient form
all the data you need for astronomical navigation and sight
planning.

Systematic Navigation solves all the problems of calculating
hour angles declination and sight reduction in astronomical
navigation or trigonometry in coastal situations.  It is
totally automated and removes the need for a pocket calculator,
almanac or sight tables and provides:

1.  Position fixes for up to ten sights
2.  Rise and set including transits and moon phases
3.  Star Identification from angle and bearing
4.  Almanac calculations - hour angles, altitude and azimuth
5.  Solve course
6.  Destination
7.  Estimated position
8.  Course to steer
9.  Great Circle or Rhumb-line headings
10. Horizontal sextant
11. Vertical sextant for distance-off calculations
12. True and apparent wind and speed

See the word documentation for a full description of each of
the modules with explanation and examples.

(3) PSION 5 INSTALLATION

The system requirements are about 250k free space and PKUNZIP.  

1 Start Windows.

2 Insert the Systematic Navigation disk in drive A.

3 Make a directory on the PC called c:\system\apps\sysnav.

4 In the Windows File Manager, choose Run from the File Menu.

5 Windows displays the Run dialog box.

6 Type c:\[pkzip location]\pkunzip -d a:\SysNavXX
					c:\system\apps\sysnav.

7 Note the spaces in the command and the use of the '-d' switch.

8 Choose OK.

9 The system should 'unzip' the file to c:\system\apps\sysnav
and its sub-directories.

10 You should have files in both c:\system\apps\sysnav and the
new sub-directories c:\system\apps\sysnav\fls and c: ..\dat.

11 Using PsiWin, copy (not convert) the directory structure on
the internal disk of your Psion.  The application file SysNav
should be in the sysnav sub-directory while the 'dat' and 'txt'
files should be in ..\sysnav\dat.  The non-word files such as
database and module files should be in ..\sysnav\fls.

12 Copy the manual and ReadMe file to \word on the Psion.

13 Take a back-up copy of the application.  If you ever
experience any problems, re-copy your back-up disk.

14 The application should now be visible after pressing 'Extras'
on the Psion screen.

15 To start Systematic Navigation, select the icon. A 
registration check and then a copyright box appears. Press 
'Enter' to accept and the application displays an options box.

16 See the manual SysNavXX for further details.  This will be
in two parts A and B.

This is a list of all the files together with their target
directories:

Directory: c:\system\apps\sysnav\
SysNav		Main application file with its icon

Directory: ..\sysnav\fls
Apps		Applications 1

Star9195	Stars data 91-95

962911.txt	Example results print-out

The format is year/month/day/hour

Directory: c:\word
ReadMe		Read Me information file
SysNavXA	Part A of manual
SysNavXB	Part B of manual

(3) PSION 3 INSTALLATION

The system requirements are about 250k free space and PKUNZIP.  

1 Start Windows.

2 Insert the Systematic Navigation disk in drive A.

3 Make a directory on the PC called c:\app.

4 In the Windows File Manager, choose Run from the File Menu.

5 Windows displays the Run dialog box.

6 Type c:\[pkzip location]\pkunzip -d  a:\SysNavXX  c:\app.

7 Note the spaces in the command and the use of the '-d' switch.

8 Choose OK

9 The system should 'unzip' the file to c:\app and its
sub-directories.

10 You should have files in both c:\app and the new
sub-directories c:\app\fls and c:\app\dat.

11 Using PsiWin, replicate the directory structure on the
internal disk of your Psion.  The application file
SysNav.opa should be in the apps directory while the 'dat'
and 'txt' files should be in \app\dat.  The non-word files
such as data and module files should be in \app\fls. Copy
the manual and ReadMe file to \wrd on the Psion.

12 Take a back-up copy of the application.  If you ever
experience any problems, re-copy your back-up disk.

13 Install Systematic Navigation on the Psion using Menu,
Apps, Install (see Psion manual page 256).

14 To start Systematic Navigation, select the icon.
A registration check and then a copyright box appears.
Press 'Enter' to accept and the application displays an
options box.

15 See the manual SysNavXX.wrd (doc) for further details.

This is a list of all the files together with their target
