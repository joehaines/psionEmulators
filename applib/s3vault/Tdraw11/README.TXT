1.1b Installation

     Vous devez avoir recu le programme avec les fichiers suivants:
        Nom           Taille (octets)
        T_DRAW.OPA    5201
        T_DRAW.RSC    4292
        SOURIS.PIC    56
        SOURIS2.PIC   56
        README.TXT    Ce fichier
        
     Pour installer le programme:
       a. copiez le fichier T_Draw.opa dans le repertoire \APP\ de
          n'importe quel disque (A, B ou Interne).
       b. creez un repertoire \TDRAW\ dans le repertoire \APP\, de maniere
          a avoir: \APP\TDRAW\ et copiez-y:
          SOURIS.PIC
          SOURIS2.PIC
       c. copiez le fichier d'aide en anglais optionel T_DRAW.RSC
          dans \OPD\
       d. Installez l'icone de l'application dans l'ecran systeme
          comme pour une autre application (Psion-I).

2.1 Setup

     This file should have come with the following files:
        Name          Size(bytes)
        T_DRAW.OPA    5201
        T_DRAW.RSC    4292
        SOURIS.PIC    56
        SOURIS2.PIC   56
        README.TXT    This file
        
     How to install the program:
       a. copy the file T_Draw.opa into an \APP\ directory
          on any drive (A, B or Internal).
       b. create a sub-directory \TDRAW\ into \APP\, so
          that you have \APP\TDRAW\, and copy into it:
          SOURIS.PIC
          SOURIS2.PIC
       c. copy the optional English help file T_DRAW.RSC into \OPD\
       d. Install the application icon into the system screen
          like any other app (Psion-I).
