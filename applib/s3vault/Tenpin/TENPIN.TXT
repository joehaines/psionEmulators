Introduction:

  This program allows you to create and
  maintain a set of databases in which
  you can record your league scores.
  It allows you to review each of your
  league performances through the season.
  Provides current Average, Handicap and
  season best data.
  Facilities are included to allow for 
  different handicap rules for each 
  database.
  A handicap calculator is also included
  for the start of a new season or to
  figure the Handicap of reserve players.
  
Inventory:

  \app\tenpin.opa
  \pic\tenpin.pic
  \opd\tenpin.rsc
  \pin\sample.dbf
  tenpin.txt (this file)
  \pin\sample.ini (created 1 per data file
                 option info stored here)

Installation:

  Unzip Tenpin.zip and load it into the
  directories as shown above.
  Install on the system screen in the normal
  way (Psion & I).
  To run the program simply select from
  the list under the tenpin icon on the
  system screen.
  You can if you wish store your data in a 
  directory other than \pin\.  Create the 
  desired directory and load your data files.
  Create a new list for the tenpin application
  using create new list from the system
  screen.
  The sample database was created using the
  data application.  This was done just to
  provide labels if your interested in the
  database format.
  You can do this for your files or just
  let the tenpin application take care of
  everthing.
