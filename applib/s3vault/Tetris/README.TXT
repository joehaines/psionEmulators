Tetris for PSION Series 3a
--------------------------

This is the newest and by far the best Tetris game for the PSION
Series 3a. For those who do not know the basics of the Tetris
game, see Tetris Game Basics at the end of this file.

When you start the game, you can choose between Game A and Game B.
Use the Right and/or Left key to select the game you want to play
and ENTER. When selecting game B, the screen will be partially
filled with blocks, which are positioned at random.
After selecting the game type, you are invited to select the Game
Level. Use the Right and/or Left key to select the game level and
ENTER. The higher the level, the higher the speed of the blocks.
In case of game B you also must select the 'height' to which level
the screen will be filled.

While playing the game, on the left side of the screen you can
follow the score and the number of filled lines. One full line
increases the score by 40*(1+Level). A double line increases the
score by 100*(1+Level). A Triple line increases the score by
300*(1+Level). A tetris (4 filled lines with one block) increases
the score by 1200*(1+Level). When a block falls while you were
keeping the Arrow Right Key pressed (increased speed) this will
also give extra points.


Control Keys
------------

TAB-key :	rotate the block counter clockwise
Arrow Up :	move block up
Arrow Down :	move block down
Arrow Right :	Increase falling speed while key is pressed
Help-Key :	Open 'Psion Tetris Help' window
Esc-Key :	Stop game
Enter-Key :	Pause Game (Enter again to continue)
S-Key :		Switch sound on or off

While in Pause :
  TAB-key :	Game Statistics (TAB to close statistics window)
  H-key :	High Scores (TAB to close high scores window)
		  High Scores are available only when registered
  Arrow Up :	Increase game level
  Arrow Down :	Decrease game level
  Esc-Key :	Stop Game
  Help-Key :	Open 'Psion Tetris Help' window
  S-Key :	Switch sound on or off
  

It is advised while playing the game, to hold your PSION in both
hands using the left thumb for the TAB key to rotate the blocks,
and the right thumb for the Up and Down keys to move the block
upwards or downwards, and the Right key to increase the speed of
the current block.


Install the game
----------------

The game has following files :
  Tetris.Opa
  Tetris.Pic
  Tetris-1.Pic
  Tetris-2.Pic
  Tetris-3.Pic
  Tetris-4.Pic
  Tetris-5.Pic
  Tetris-1.Wve

Copy the Tetris.Opa file into the APP directory on any drive
(Internal, A or B). Create a sub-directory called 'Tetris' in
the APP directory on any drive. Copy all other above files into
this new directory.

Install Tetris.Opa on your system screen.


How to register ?
-----------------
When you play the game without having registered, the program
will continue to show you the register screens. You also will
have no access to the high scores. If you want to register, just
follow the instructions on the screen. It is important that you
inform us about the user name which you want to register.
After entering the Registration Code and the User Name, Tetris
will create the file Tetris.Opd in the OPD directory of your
internal drive. You can move this file into the OPD directory
on the A or the B drive. As Tetris uses this file to store the
high scores, it is adivised not to put the file on a Flash Memory
Disk.

Tetris Game Basics
------------------
The purpose of the game is to build full vertical lines by
rotating and/or moving the blocks up and down while they are
'falling' to the right. You will score points for each full line
you build. In case you can complete 2, 3 or even 4 lines with one
single block, the score will be higher. When a full line is built,
it will be cleared from the screen, and the other blocks will
shift to the right. The game is automatically stopped in case the
screen is filled with blocks and there is no space left for new
blocks.
