

--------------------------------------
Timecalc v2.01 for the Psion Series 3a
--------------------------------------

TIMECALC for the Psion Series 3a is a
Time and Timecode calculator with a very
friendly user interface. This version
operates at framerates of 25 or 30, but
simple calculations in hours, minutes
and seconds are perfectly possible.

To install Timecalc, copy the files
TIMECALC.OPA and TCALC.PIC to any APP
directory on the Series 3a.

Select the APPS menu from the system
screen of the PSION and choose install.

From the dialog that follows, select the
disk to which the files were copied, then
use the left/right cursor keys to display
the TIMECALC.APP file.

Press ENTER. The TIMECALC icon will then
be installed on the system screen and can
be run in the usual way.

An intuitive menu and helpscreen are
included in the program.
