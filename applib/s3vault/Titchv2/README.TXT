Introduction
------------
TITCH V2.0 is a vector based Drawing and Mind Mapping application for the Psion 3a which give  disk space savings of around 2000% compared with the more usual bitmap (.PIC) based applications.

TITCH drawings can be hyperlinked to other drawings or any file created using the built in Psion applications. Hyperlinks can also include a search string! 

Full details are in the TITCH.WRD document. 

TITCH.RTF is the same as the WRD Document but can be opened by your PC or Macintosh word processor.

Installing
----------

1.Back up your data.

2.Copy TITCHV2.OPA to M:\APP\ ( or B:\APP\ or A:\APP\) and install it from the System Screen.

3.Create a sub-directory \APP\TITCH\ and copy UP08.FON, DOWN08.FON and TITCH.HLP to it. This step can be omitted if you do not want online help or vertical fonts.

4.Please Read the rest of this manual!

Note for version 1 users:

Delete TITCH.HLP from \OPD\ and TITCHV1.opa from \APP\

Changes from Version 1
----------------------

1.	You can now insert hyperlinks which will launch a file using the built in psion applications. Valid file types are Agenda, Data, Sheet, Word, Text, OPL and OPO. These links can also contain search text.

2.	The need to use two modes (Draw and Update) has been removed. 
	
	To launch linked files you now toggle between hyperlinks using the <Space> key  or position cursor over the link and press <Enter>. 
	
	To edit objects  toggle between them using  <Tab>.

3.	Lines can now be moved !!

4.	The diamond key now launches an edit filter dialogue which removes the need to toggle through all types of object when,  for instance, you wish to only move boxes.

5.	When using <Space> or <Tab> to move between objects the <Shift> key reverses the direction. 

6.	Text and Links can now be edited. 

7.	Swiss text style added.

8.	8 point Vertical text ( up and down) added.
