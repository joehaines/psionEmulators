New in Taskman 4.03

   . Support for launching aliases
   . Launchs.als is an alias of the Launcher application that will launch
     alias files from the system screen.


New in Taskman 4.0

   . New Unlimited application list for launching. The list now comes
     up immediately (on spacebar), so it makes launching faster.
   . Faster scrolling
   . Application list for launching is auto sorted now.
       . Raised limit to 150 applications on launch list.
       . ROM applications are now added from a specific list of ROM apps.
         This way it is impossible to add files from the ROM that are not
         launchable applications. (This caused some problems)
   . Help key active on some dialogs
   . New preference: "Get new list when coming foreground". Sometimes
     you exit a program, and then go directly to Taskman, and the app
     name still shows on TM's list. This preference forces a redraw
     when bringing TM foreground.
   . Added new help system
   . Fixed a bug in launching using a data file in a different directory
     from the default directory.
   . Added definable hotkey for bringing Taskman foreground. Use psion<h>
     to set it. Pressing Del<Enter> removes the hotkey.
   . Launcher.opa - separate launcher works well with taskman. Shows all
       .app files under it's icon, and Launcha.als shows all .opa files
       under it's icon. Pressing Enter on a file under the Launcher icon
       will launch that particular application. The icon won't stay bold
       to show you that it's running. Use Taskman to see what is running.
