   TTF2FSC is very simple to use. First of all copy these files  in  a  clean
   directory  (e.g. C:\FSC). Then, if you are good enough, start your Windows
   and create a Program Manager Icon  for  TTF2FSC. If you are not, just type
   TTF2FSC and press your enter key; Windows will be loaded and FFT2FSC  will
   automatically start.

   In  order  TTF2FSC  to  start, remember you will need to have a file named
   VBRUN300.DLL in your Windows directory; it is the run-time library you can
   easily  find  on  InterNet,  or  on  a  shareware CD-ROM or in every PSION
   software library, because other Windows software (PSION or not) needs it.
   
   To create a Series-3(a) font file you only need to select a font file from
   the font list you will see. Then, choose the right size (it can not  exeed
   72 points in the registered version, 16 in the shareware version). Now you
   can  look  at the big font example box to have an idea of the true size of
   your font. By default, TTF2FSC converts all character set (0-255); you can
   override this  default  by  clicking  on  the  "Choose  output characters"
   button. A big window will be displayed, and you can activate or deactivate
   the 6 preset buttons or click on every one of the character set button  to
   add  or  delete  the  characters  you  need/don't need from the conversion
   table.  The  preset  buttons  are  self-explaining:  uppercase, lowercase,
   numbers,  punctuation,  unprintable  (range  0-31)  and   remaining   (the
   characters  not  contained in the other 5 buttons). This is an easy way to
   quick select the characters you want to be converted.
   
   Choose "Start font conversion" button, select  your  output  file  (output
   will  go  in  the  directory  containing  TTF2FSC.EXE  only)  and, after a
   "little" brainstorming, TTF2FSC will create your FSC file.
   
   Unregistered  users  will  be  quitted  from TTF2FSC after one conversion.
   Registered users can convert as many fonts as they want in one session.
