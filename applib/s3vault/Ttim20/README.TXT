TelTimer is made to show you how much money you spend on your telephone.

If you want to install the english version, please use the files called
"TELTM20E.*", if you prefer the german version use the "TELTM20D.*" files.
IMPORTANT: You have to rename the above mentioned files to "TELTIMER.*", 
otherwise the presence of the help file will not be recognized by the program.

Install as follows:
\APP\TELTIMER.OPA
\APP\TELTIMER\TELTIMER.HLP
\APP\TELTIMER\TRF\*.TRF

... and read all the chapters of the provided online help. The helpfile is
optional an can be deleted afterwards.

Note: The supplied *.TRF files contain the current (01.01.96) german telephone
      charges provided as examples, however if you are in Germany they should
      give correct results!

Any comments on this english version will be appreciated (e. g. more suitable
expressions for menutexts, help file, etc.)!
