			       Units Version 2.1
		   Units of measure conversion for Psion 3a.

This new version includes optional pricing for all conversions.
To install put the following files in the \directories\ on any disk;

\app\units.opa
\opd\units.dbf

The values are British, but if you want to change them, use the psion database
program to edit the units.dbf file.
