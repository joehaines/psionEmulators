About Utilites
-----------------
Utilites is a large collection of apps, tools and utilites all in a small
package.

Some features include a full screen sized digital clock, a battery monitor,
System resources monitor, ability to launch all built in applications at the
press of a button, a timer, a stopwatch, the ability to change an
applications icon to name just a few.

Installing Utilites
----------------------
To install Utilites just put;

Utilites.app into any top level \APP\ directory
           \-(aplication file important).

Utilites.rsc into any top level \OPD\ directory
           \-(help file important gives usage instructions for all
functions and registering info).

Then install Utilites.app in the usual way, i.e. Psion -I
