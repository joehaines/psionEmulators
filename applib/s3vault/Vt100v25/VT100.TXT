New Features in v2.5
--------------------

Version 2.5 includes a buffer large enough to take the contents of
a page of text. This makes using VT100 quicker, and means that if you
have incorrectly set the handshaking (which many people do) it is less
likely that you will overflow the buffer.


The VT100 Emulator
------------------

The Psion Serial Link (RS232) includes a built-in application called 'Comms'
which allows users to dial in to the simplest form of on-line systems.

The Widget Software VT100 emulator allows users to log on to the many other on-
line systems which use the more sophisticated VT100 standard. Many databases
or company email systems require VT100 emulation from all terminals.

If you would like to log on to a computer system which requires VT100, using
your Psion Series 3a, please try out this free demonstration version of our
software.


Technical details 
----------------- 

VT100 provides an 80 column by 24 line full-screen emulation of the DEC  
VT-100 terminal. VT100 is designed to complement the built-in 'Comms'  
app, and many of the menu options and hot-keys will be familiar if you  
have used 'Comms'. 
 
VT100 supports most of the features of the real terminal, including: 
* forward and reverse scrolling
* highlighting 
* underline 
* inverse video,  
* graphic box characters 
* keypad emulation 
* insert/overwrite mode 
* autowrap, 
* Delete and Enter key mapping 
* full serial port and handshake configuration
* clear screen and reset terminal 
* tab settings 
* full cursor movement 
* line and block erase
* xmodem and ymodem file transfer protocols
* scalable fonts, allowing you to view either the full screen or a virtual
  window on the screen 

In addition, VT100 allows you to save the current terminal settings  
between sessions, log incoming data to a file, pause the screen, and get  
help on the various options.

How we deliver to you
--------------------- 

We always send you a full copy of the program on 3.5 inch floppy disk
plus a product manual. It fits into a medium sized envelope which we will
mail to you anywhere in the world.

We can also deliver the file VT100.APP to you through the Internet.
In order to travel through the Internet, we send you the file uuencoded
as a mail message.

If you order from us by email, we will send you what looks like a very
strange message in reply. It will consist entirely of ASCII characters,
but in a form which makes no sense to the reader.

Save this mail message to disk on your PC. Call the file VT100.uue.
Then, using the file UUDECODE.EXE which is in the same zip file as these
instructions type

The file you received through the Internet mail will be reconstructed
into a file called VT100.APP which will replace the file VT100SLO.APP
you got with this zip file.

This will get you started while the floppy disk and manual are 
still travelling through the world's postal services.
