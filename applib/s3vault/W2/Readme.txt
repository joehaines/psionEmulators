W2 - A Day/Night Moving Map

W2 is a development of the World application that allows you
to see the time at all points on the map.

The shaded area is night-time, and the rest of the map is 
daylight.

Try junmping to various dates over a year to see how the
pattern changes with the seasons.

* Getting Started

Place the two files: 
  W2.opa
  W2.rsc (optional help file)
into an \app\ directory on any disk. 

Use Psion-I on the system screen to install and you are 
ready to go.
