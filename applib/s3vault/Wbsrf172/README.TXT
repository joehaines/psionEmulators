1.1a Qu'est ce que WebSurf ?

     C'est une application qui vous permet de lire les fichiers
     au format HTML. Vous pourrez ainsi surfer sur le web dans le
     metro...
     Notez que cette application ne permet pas encore de se connecter
     a Internet, mais juste de lire les fichiers hors ligne.
     WebSurf peut parler anglais, francais, italien, norvegien,
     suedois ou allemand.

     Pour installer le programme:
       a. copiez le fichier WebSurf.opa dans le repertoire \APP\ de
          n'importe quel disque (A, B ou Interne).
       b. creez un repertoire \WEBSURF\ dans le repertoire \APP\
          et copiez-y WEBSURF.PIC.
       c. creez un repertoire \WWW\ et copiez-y MANUAL.HTM et
          WEBSURF.PIC. creez un repertoire \WWW\CACHE\ sur le
          disque interne.
       d. create un repertoire \MANUAL\ dans le repertoire \WWW\
          et copiez-y *.HTM et *.PIC et *.WRD (en fait, tous les
          fichiers restant).
       e. Installez l'icone de l'application dans l'ecran systeme
          comme pour une autre application (Psion-I).
       f. selectionnez le fichier MANUAL sous l'icone de WebSurf
          et... c'est parti!

1.1c Mise a jour

     Si vous utilisiez WebSurf avant, recopiez tous les
     fichiers ci-dessus par-dessus les anciens. Ensuite,
     creez un repertoire \WWW\CACHE\ sur le disque
     interne.

1.1d Utilisation

     La liste des fichiers *.htm contenus dans le repertoire \WWW\
     apparait sous l'icone du programme. L'utilisation est la
     meme que pour le traitement de texte.
     Il est vivement conseille de lire la documentation, qui est
     au format HTML, soit avec WebSurf, soit avec un Browser HTML
     comme Netscape. C'est le fichier MANUAL.HTM.

1.2a Comment s'enregistrer

     Qu'est-ce qu'un shareware ?
     ---------------------------
     C'est une application que vous pouvez utiliser gratuitement,
     ce qui vous permet de l'evaluer. Lorsque vous pensez que le
     programme correspond a vos besoins, vous vous enregistrez pour
     montrer a l'auteur que vous appreciez son travail.
     En vous enregistrant, vous pouvez de plus a voir acces a
     toutes les fonctions du programme.

     Pourquoi est-ce que je m'enregistrerai ?
     ----------------------------------------
     J'ai travaille de nombreuses heures sur ce programme, et je
     continue a en passer. C'est pourquoi j'ai choisi de distribuer
     WebSurf comme un shareware.

     Si vous vous enregistrez, vous aurez les avantages suivants:
      - Vous recevrez un code d'enregistrement qui vous premettra
        d'utiliser toutes les fonctions du programme, et qui enlevera
        les ecrans de rappel d'enregistrement ;
      - Vous recevrez automatiquement toutes les nouvelles versions
        de WebSurf si vous m'avez donne votre adresse email ;
      - Vous pourrez demander des ameliorations de WebSurf, et vos
        suggestions seront les premieres a etre prises en compte ;
      - Vous pouvez demander la traduction de WebSurf dans votre
        langue si ce n'est pas encore le cas ;
      - Vous serez bien entendu un utilisateur enregistre pour
        toute nouvelle version de WebSurf.

     Qui plus est, ceci m'aidera quand je serai vire de mon lycee
     parce que le temps que j'ai passe sur Websurf, je ne l'ai
     pas utilise a faire mes devoirs!

     Comment puis-je m'enregistrer ?
     -------------------------------
     L'enregistrement est tres simple. Il suffit de m'envoyer
     12 livres anglaises, 100 FF ou $20, avec votre
     nom complet, votre adresse email ou "papier", ainsi que le
     numero de la version que vous utilisez.
     Vous pouvez utiliser de la monnaie, des mandats postaux, ou
     des cheques ou Eurocheques en FF. N'utilisez pas de cheques
     pour une autre monnaie que le FF SVP.
     Mon adresse:

     code. C'est tout. WebSurf sera enregistre pour vous. Pas
     besoin de reinstaller quoi que ce soit.

2.2b A propos des image GIF

     WebSurf v1.7 et suivantes sont capables de lire les
     images au format GIF, grace a uen librairie en C de
     Serge. Elle est pleinement fonctionnelle, mais Serge
     a fait en sorte qu'elle ne marche plus apres le 31
     decembre 1996. Cependant, une nouvelle version de WebSurf
     sortira entre-temps, vous evitant de vous inquieter a
     propos de cette limitation.

     A shareware is an application you can freely use, so that you can

     I spent many hours working on this program, and I still do.
     That's why I turned WebSurf into a shareware application.

2.2b About GIF decoding

     WebSurf v1.7 and up handle GIF pictures, using Serge
     Shestopalov's C library. It is fully working, but
     Serge made it to work until December 31, 1996, and stop
     then. However, a new version of WebSurf will include a
     newer version of the library, and it will go out before
     this date.
