What is WebSurf supposed to do?

WebSurf is an off-line HTML file viewer, that is, you can download Internet World Wide Web files on your little Series 3a, and look at them when you are in the bus, or edit and check your Web page while on holidays! For example, HTML file is a link, because it is shown as inverted text, and you can follow it by pressing TAB.
