Known HTML elements

Here are the commands that WebSurf recognises. Please check this list if WebSurf has problems processing an HTML page. The HTML tags are followed by their attributes WebSurf can handle.

  • A ... /A
    • NAME=...
    • HREF=...
  • ADDRESS
  • B ... /B
  • BGSOUND
    • SRC=...
    • LOOP=...
  • BODY ... /BODY
  • BR
  • CENTER ... /CENTER
  • CITE ... /CITE
  • CODE ... /CODE
  • DD
  • DIR
  • DL ... /DL
  • DT
  • EM ... /EM
  • H1 ... /H1, H2 ... /H2, H3 ... /H3, H4 ... /H4, H5 ... /H5, H6 ... /H6
    • ALIGN=LEFT/RIGHT/CENTER
  • HEAD
  • HR
    • SIZE=...
    • NOSHADE
  • HTML ... /HTML
  • I ... /I
  • IMG
    • SRC=...
    • ALT=...
  • MENU ... /MENU
  • KBD ... /KBD
  • LH
  • LI
  • OL ... /OL
    • CONTINUE
    • TYPE=a/A/i/I/1
    • START=...
  • P ... /P
    • ALIGN=LEFT/RIGHT/CENTER
  • PRE
  • SAMP ... /SAMP
  • STRONG ... /STRONG
  • TABLE ... /TABLE
    • BORDER
    • BORDER=...
  • TD ... /TD
  • TH ... /TH
  • TITLE ... /TITLE
  • TR ... /TR
  • TT ... /TT
  • U ... /U
  • UL ... /UL
    • PLAIN
  • VAR ... /VAR

And special characters such as é or ©
