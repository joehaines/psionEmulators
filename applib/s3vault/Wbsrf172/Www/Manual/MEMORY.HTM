WebSurf and your memory

You may have noticed that WebSurf is a memory eater. This is due to the fact that it uses a growing window to decode the HTML file. Version 1.2 of WebSurf didn't cope nicely with this problem, but the problem is solved since.
You can choose which percentage of the already loaded file should be deleted (from the screen, not the real file !) when you decide to view more of the document, but don't have enough memory. To modify this, choose Preferences in the Special menu.
If you are viewing a big page (like the one listing WebSurf commands...), then using a smaller font will eat less memory. You just have to zoom out.
