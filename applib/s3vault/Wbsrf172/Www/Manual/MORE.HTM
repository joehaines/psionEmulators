More about WebSurf

That's fun because each time I think WebSurf is far better than anything I was dreaming of when I started writing it. And each time I keep on improving it.

This little project started in December, when I started writing my own Web page. I didn't like writing it on my PC because I was used to my Series 3a. But there was only one application to test the page on the S3a itself: HTML Viewer. I started using it, but it soon became very limited, and I thought it wouldn't be hard to write an nicer application.

For now, I can say I made a least a hundred times better than what I wanted to do. And I'm very happy to see many users are considering it as a nice application.

That's why I'll keep improving WebSurf over and over, always and always...
