Other WebSurf features

  1. Auto detection of your Series 3a language. WebSurf can speak:
    • English
    • French
    • German
    • Italian
    • Norwegian
    • German
    • Gaeilge (Irish)

    If your language is unknown, then English will automatically be selected. You can change it with the "Preferences" dialog ;
  2. Links to any Series 3a file. For example, this word is linked to a sound file ;
  3. Sizeable loading indicator, proportional to the size of the document loaded ;
  4. Clever memory management: when the program runs out of memory, you are asked whether you want to stop loading or forget the top of the page (and continue). If you decide to stop, you can continue after, by selecting Continue in the Loading menu;
  5. WebSurf supports and understand most HTML 0, 1 and 2 specifications, excepted FORM elements, and some HTML 3 specifications like TABLES.
