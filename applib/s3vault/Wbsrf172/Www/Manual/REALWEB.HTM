How to download real Web pages

Your first question now might be: "I've got the address (URL) of a page on the Web, but how can I obtain it on my Series 3a ?".

There are many ways to do this:

  • Download a page with the browser of a desktop computer (e.g. Netscape) ;
  • Have the file automatically sent to you via email.

I am going to explain how you can receive a file via email.

What you need is an email access. Even with your Series 3a. Then you write to an Agora server and ask it to send you a page. Let's suppose, for example, that you want to see the page located on:

http://www.server/file.html

Just send a letter to

agora@info.lanic.utexas.edu

without any subject, and only write in the body of the letter (avoid any signature):

source http://www.server/file.html

(be careful to leave only one space between source and the file name)
That's it. Decode the page and copy it to your Series 3a, e.g. m:\www\file.htm.

Now you can run WebSurf on your fresh Web page !

Note: If you want to be sent something else than an html file from the Agora server, then use the command send, for example:

send http://www.server/file.gif

Important note: if you can obtain pages with other methods, please let the Agora server use for people less fortunated than you, because overloaded Agora servers may go off since they are ran most of the time by kind-hearted volunteers.
