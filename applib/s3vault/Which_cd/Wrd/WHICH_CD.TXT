Which CD
========
Which CD is a freeware program that I wrote in a day!

It catalogues your music collection and suggests albums to
listen to depending on your mood.

For more information see the online instructions/information.

As far as I know, it should work on a Psion series 3a and 3c and
Psion Siena (I'm not sure about Siena, let me know !).


Installation
============
Move the "Which_cd.opa"" file to your "APP\" directory and the
"Sam&col.pic" file to your "OPD\" directory.

Install Which CD on the system screen by pressing Psion-I and
selecting "Which_cd.opa"
