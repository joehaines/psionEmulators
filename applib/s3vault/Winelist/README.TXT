WineList for Psion Series 3/3a

WineList produces a report of the User Entries in the Hugh Johnson's
Wine Guide database.

The report can be to the screen, the serial or parallel ports, or to a
file. In the case of output to file, you can select whether to produce
a Paragraph or Line file. Paragraph files can usefully be read into
the Word Application for reformatting or to apply different fonts/effects
which can then be output to your printer in the normal way. Winelist's
reports to the Serial and Parallel ports produce plain 80 column
ASCII text.

NB. WineList reports only the User Entries in the Database, that is, 
data you have input yourself. It is NOT able to print information from
the Hugh Johnson Wine Guide Database.


INSTALLATION.

The program is provided in two versions, WINLIS3.OPO and WINLIS3A.OPO, which
are for the Series 3 and Series 3a respectively. Copy the appropriate one
to your \OPO directory. Copy WINEFIX.DAT to the \WINE directory which
should already contain the WINE???.DAT files from the Wine Guide application.
Winelist is able to use databases on any of drives M, A and B and will prompt
you to choose should it find more than one available. Note that in order to
use multiple drives you must copy WINEFIX.DAT to each \WINE directory.
