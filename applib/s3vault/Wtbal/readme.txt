PROGRAM INSTALLATION

If you are installing the software onto flash disk,
It is strongly recomended that all but the program file
Ucofg.OPA is copied to the memory disk, as they are
frequently updated and will eventually fill up the flash disk.

1. Make a directory on your 'M' drive called 'CofG'

2. Copy the files listed below into that directory:-

   Aircraft.DAT
   Weights.DAT
   CofG.INI
   Wtbal.PIC

3. Copy the file 'Ucofg.opa' into your '\APP' directory.
4. Select 'APPS'from the psion main menu and select 'Intstall'
   Navigate the file box to select 'Cofg.opa'.
