Introduction:
-------------
XfFrame is an application builder for use with XfAde

Installation:
-------------

Put XfFrame.OPA into an \APP\ directory on any drive.
Put XfFrame.RSC into an \APP\XFILES\ directoryt on any drive.
Put all the OPP/OPH files into an \OPP\INCLUDE\LIB\ directory on ant drive.
Install on the SYSTEM screen using <Psion-I> as per normal.
Please see the on-line help for usage instructions.
