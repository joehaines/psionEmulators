Introduction:
-------------
The Icon Library System.
The system comprises 2 programs XfIComp and XfILib.
XfIComp searches through a specified directory and compiles all of the
48x48 bitmaps into a much larger bitmap (30 icons to a page) and saves
it to a specified directory.
XfILib loads these files and allows you to select an icon to save back
to its original state.

Installation:
-------------
Put XfIComp.OPA and XfILib.opa into an \APP\ directory on any drive.
Put the example Library (Optional) into an \ICO\ directory on a
non-Flash device.
Install on the SYSTEM screen using <Psion-I> as per normal.
Please see the on-line help for usage instructions.
