Introduction:
-------------
XfJot is a small notepad type program for taking quick notes.

Installation:
-------------

Put XfJot.OPA into an \APP\ directory on any drive.
Install on the SYSTEM screen using <Psion-I> as per normal.
Please see the on-line help for usage instructions.
