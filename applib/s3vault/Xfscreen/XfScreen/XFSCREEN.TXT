Introduction:
-------------
XfScreen is a Screen designer for OPL.  It allows you to draw 
screens, play around with the layout as much as you like and
then save it to an OPL program. The facility to save the screen
(or just a bit of it) as a bitmap is also available.


Installation:
-------------
Put XfScreen.OPA into an \APP\ directory on any drive.
Put all other files into an \APP\XFILES\ directoryt on any drive.
Install on the SYSTEM screen using <Psion-I> as per normal.
Please see the on-line help for usage instructions.
