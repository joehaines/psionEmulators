SCP$ZMDM.DYL                                  Psion Software plc 2/11/96
============

Contained within this archive is a patch version of the Zmodem protocol 
library for the S3c. If you have an early (V5.20F) S3c and wish to use 
the Zmodem protocol from comms scripts then you should copy this file 
to a \IMG directory on your machine. 

From the script it will be available as "ZMDM" with the "Receive" and
"Transmit" commands.

It may be distributed more widely (e.g. Compuserve, Internet) but
this readme file should accompany it.
