Installation Instructions
=========================
You will first need to unzip the aahotel.zip file using pkunzip or similar.
Make sure you use the -d option to retain the original directory structure of
the files.  All the unzipped files will then need to be copied to one of your
disks on your Psion machine.  You must ensure that all the files are kept
together on the one disk otherwise the application may fail to work.

For reference, the guide.app file sits under the APP\ directory and the aa.gde
and places.dat files sit under the APP\GUIDE\ directory.
Once copied you can install the application as usual by using ^I (Apps/Install)
from the System screen.
