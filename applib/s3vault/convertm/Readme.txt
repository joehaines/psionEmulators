ABOUT Convert'M
---------------

Convert'M is a program that will convert loads
of different types of measurements. Including
length, volume, area and weight plus typeography,
pressure, power and time. Its best to look at
the program.

INSTALLATION
------------

To install this game put the following objects
in the following places:

convert.opa -------> M:\APP\
CONVERTM\ ----------> M:\APP\

To put it simpler, put the convert.opa file and
the ConvertM folder in the APP directory on your
psion.
