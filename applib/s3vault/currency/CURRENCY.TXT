                         Currency - Converter
                         --------------------
This is the simplest/easiest currency converter you will find !

Define your own currency symbols, and update the exchange rates yourself.

Installation
------------
Just copy the Currency.opa file into the \APP\ directory, and install it
on the system screen in the normal way. That's all there is too it !

Using the Currency Converter
----------------------------
Press Esc to bring up the menu which allows you to change the
Currency symbols and the Exchange rates.

Set the "Base" currency to your own for example, and simply enter the
values for the other currencies. I use the FT (Financial Times) 
Exchange Cross Rates - hence the icon !

I don't know why I'm telling you all this ... it's so easy just use the
Esc key to swop backwards and forwards ! - have a go !

The Currency symbols are set to default values, as are the
Exchange rates. 
These were set in 1st November 1994 (the date the program was written) 

I've left these default values to encourage you enter the up-to-date
rates, and therefore start using the program as it was intended.
