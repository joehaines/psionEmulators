Installation
------------

Firstly unzip the Degrad10.zip file (You should have done this by now). The zip file should 
contain this readme file and a directory called opo. 

All you have to do is copy the directory into the root directory of your Psion.
Alternatively you could do it the manual way and copy the Degrads.opo file into the opo
directory on your Psion.

When this is done you should see a file called "Degrads" appear underneath the RunOPL icon on
your Psion's System screen.

Possible installation problems
------------------------------

-> You do not have an opo directory.
 Solution - 1. From the system screen go to either the "World" icon or the "Spell" icon, but
               do not press enter (This ensures that you end up in your Psions root directory).
            2. Then press TAB (You should be in your Psions root directory)
            3. Then press MENU. Move to "Directory" and select "Make Directory".
            4. In the make directory dialog that comes up type in "OPO". Then press Enter.

-> RunOpl is not installed.
 Solution - 1. From the system screen press menu and go to "Apps". Then select "Install
               Standard". Press Enter.
            2. On the "Application" line of the dialog press the right arrow key until "RunOpl"
               appears (If it does not appear you must have RunOpl already installed). Then 
               press Enter.
