Euro-Convertor for Psion 3a/3c/3mx

Features of the convertor are :

	- 2 currencies on screen (ex : BEF and Euro)
	- number of decimals can be set for both currencies (0-9)
	- conversion rate can be set freely
	- calculation done while entering value
	- switching between both currencies
	- result of Currency1>Currency2 conversion can be reused for Currency2>Currency1 conversion
	  (useful for price-setting calculations)
	- Rounding difference between Currency1>Currency2 conversion and the Currency2-result reconverted 	  towards Currency1 is always shown (useful for IT- system Euro-testing)

Installation :

	- copy the EuroConv.Opo file into the OPO directory of your Psion
