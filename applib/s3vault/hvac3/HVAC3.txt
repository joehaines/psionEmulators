HVAC/Building Services and Architectural Software by Silverglance Software
==========================================================================

Software for the Psion Series 3a, 3c and 3mx
============================================

Having unzipped the file HVAC3.ZIP, the following files will be present:


Blowpip3.EXE        Pipe and pump calculations
Fanfare3.EXE        Duct and Fan calculations
Utopia3.EXE         U-value and condensation calculatoins
Vertigo3.EXE        Unit conversions

Double-click on each file to unzip the program files, and read the accompanying
installation notes, eg. Blowpipe.TXT etc.
