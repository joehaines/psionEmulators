So, what about InternetTime? 
InternetTime is a new way to define what time it is, regardless
of where in the world you are. SWATCH made it up, so for questions 
se www.swatch.com 

How to install InternetTime?
Simple! Copy the I-TIME.OPA file to a directory called app on
your psion 3a. Install the icon by pressing psion-i on the main-
screen and select i-time.
