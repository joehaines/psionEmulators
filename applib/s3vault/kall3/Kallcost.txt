            Written for the Psion Series 3a and 3c  (Dec 1997)


To run KallCost, the files must be located in the
following directories:


\APP\ directory must contain:
==============================

KALLCOST.DAT		(Call rates data file)
KALLCOST.APP		(Main program)
KALLCOST.PRG		(Program for KallCost Log routine)
KALLCOST.HLP		(Help file for KallCost - optional)




A small file, KALL3.INI will be created into M:\KALL\ - If the directory
does not exist, it will be created. If KALL2.INI is deleted, it will be
re-created with default settings.



Updating files
==============

The file KALL3.NEW is used to update the KALLCOST.DAT file. Future updates are
made using this file. This is designed to allow users to selectively update
rates without overwriting existing rates. If you have not customised the
rates in any way, it is safe to copy KALLCOST.DAT over the top of your existing
copy. If you have your own customised rates/service providers, then use the
Import option, making sure that KALL3.NEW is in either the \APP\ or the 
\KALL\ directory on your M: drive.
