Micropwr ( Series 3 version )
Micropwa ( Series 3a version )

Copy the appropriate file to your \APP\ directory and then use Psion+I
to install it on the system screen . 

When Micropwa ( or Micropwr ) is started you will be asked for the type
of power reading to take ( old JIS or new IEC ) once this is selected 
follow the onscreen prompts . After the final results are shown , press
Enter to return to the type of power test prompt , pressing Esc here 
will exit the program .
