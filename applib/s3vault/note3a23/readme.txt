USING NOTE3a23 (PSION S3A).

You need these 4 files:
note3a23.opa
noteicon.pic
pointer.pic
author.mbp

Installation:
-------------
1. Create M:\MARKPAD directory - this is where notepad stores 
the sheets.
2. If you don't already have m:\PIC directory, create it now.
 The notepad icon is stored here.
3. Place note3a23.opa in M:\APP directory.
4. place Noteicon.pic in M:\PIC directory.
5. place author.mbp in M:\MARKPAD directory.
6. place pointer.pic in M:\OPD directory.
7. Go to the SYSTEM screen. Use left & right arrow keys to hilite
 Agenda (don't press enter).
8. Press psion-I (Install). Choose Name: Note3a23.opa, Disk: Internal,
 Position: Current & press Enter. The Notepad icon should appear to
 the left of Agenda icon.
9. press psion-A (Assign button to 'note3a23'). Use left & right
 arrow keys until 'Control+Agenda' is shown. Press Enter now.


Using the program:
------------------

It's simple to use! Just type in text & press ENTER.

The Idea is that you have 'virtual' sheets of note paper, which will
 shrink & grow to hold all of your entries. Initially, there will be
 horizontal lines drawn between each entry. You can remove them by
 pressing psion-u. The title of the default sheet of paper is
 'Notes'. You can create your own blank sheets by pressing psion-n.
 Enter the sheet title & a description / explaination for the sheet
 overview function. Sheet overview / list (psion-l) shows you all the
 sheet titles & your description for each sheet. If you create more
 than one sheet, open one of them by pressing psion-o. It's fairly
 intuitive.

Edit an entry by moving the cursor to this entry & press TAB to bring
 up the edit box.

Create a new entry by moving the cursor to the bottom line (New Entry
 Line) & type away. Psion, Control arrow keys & escape are all as
 you'd expect.

To delete an entry, move the cursor to that line & press 'delete'.
 The line will be stored on a 'clipboard', so you can use INSERT
 (psion-i) if you've made a mistake. You can insert this onto any
 sheet. You can bypass this backup feature by holding down the
 CONTROL key while you press delete, and whatever was on the
 clipboard will remain unchanged.

This is all you need to know. However there are 2 other features I've
 found useful, which need a little explaination:
1)The idea of Anchors.
Initially the entries are stored one after another and that's it. New
 entries are added to the bottom of the page. If you want the entries
 to stay in the same order & insert new entries at a specific place,
 press psion-a (anchors ON). This gives each entry an anchor number.
 Press psion-c (convert entries to..) & choose 'L' (Numbered list).
 You can choose the number for the first entry (maybe you want to
 insert entries before the first one), and choose the gap between
 entries (1,2,3,4,5.... upto 10,20,30,40,50....).
You can change the anchor numbers at any time. Anchor numbers will
 be shown with the text when anchors are on.

2) Sound files.
You can embed soundfiles in entries by using '<<' and '>>' as
 delimiters. Eg 'ahoo.wve' will play if your entry reads:
........(text here)...<<ahoo>>....(more text)...
if ahoo.wve is in the directory M:\WVE. Sounds recorded by the psion
 in the usual way will automatically be stored here.
To play the soundfile, move the cursor to that line & press psion-p.
