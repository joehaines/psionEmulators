PsiPhone
========
PsiPhone will run on the Psion Series 3a and 3c palmtops.

Files and installation
======================
Changes.txt - changes made to program
Readme.txt - this file
PsiPhone.dbf - Country and PrimeCall rates file
PsiPhone.opa - program file
PsiPhone.rsc - help file

Copy PsiPhone.opa
Copy PsiPhone.dbf to \app\psiphone\
Copy PsiPhone.rsc to \app\psiphone\
(The program will automatically create a \app\psiphone\ directory the first time it runs).
Copy *.txt to \wrd\text\ or any directory you choose.

From System screen, press Psion-I to install PsiPhone.

What PsiPhone does
==================
PsiPhone is a phone uitility to calculate the cost of your calls dialling from South Africa.
PsiPhone will calculate the cost of your international, national, local and cellphone calls.
