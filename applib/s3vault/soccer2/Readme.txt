SOCCER LEAGUES  by G R Nicholls

1. Installation

To Install place SOCCER.OPA into the APPS directory of your Psion 3c.
Place The DIV directory also into the APPS directory.
Place the soccer.hlp file into this DIV directory.

The program uses the DIV directory to store any of the files that it uses.

Install the application from the system screen as normal using PSION-I.

Run the Program and us the online help to understand how the program functions.
