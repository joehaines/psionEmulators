building societies converting to banks,

much wider.  For this reason stox has been
developed to allow you to easily follow
the performance of your investments.

Stox is a freeware prgram that allows you
to track the performance of a portfolio of
shares.  It also allows a performance graph
to be displayed showing an individual stocks
history.

Installation
============

1) Copy the file stox.opa to an APP directory
2) Copy the file stox.rsc to a \STOX directory on the internal drive
3) Install using <Psion-I>, then select stox.opa
4) Press ENTER

Upgrade
=======
To upgrade from version 1.1 to version 1.2 follow the installation
procedure above, after deleting the old version of stox.opa from
your APP directory.
All files are compatible.

History
=======

Version 1.00
------------
This is the first release of Stox

Version 1.10
------------
A small screen updated bug has been fixed. The following enhancements
have also been made :-

a) The exit key is now Psion-X to match other psion applications
b) The graph procedure has been changed to ask for a date range so
   that it is possible to keep a larger amount of price data and
   just display the relevant section.

Version 1.20
------------
A few updates from users were incorporated:-

a) When entering an updated price the default entry line is
   now price instead of holding to save tabbing down to the
   next line each time.
b) An infinite loop when graphing under certain conditions
   has been removed.
c) The graphing routine has been tidied up.
