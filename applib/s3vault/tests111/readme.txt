Installation
------------

The easy way:
~~~~~~~~~~~~~

Firstly unzip the tests.zip file (You should have done this by now). The zip file 
should contain this readme file and two directories. One directory is called APP 
and the other is called TST. All you have to do is copy these two directories into 
the root directory of your Psion. Then you need to go to your Psion's system screen
and press Psion-I (Install). From here you can install Testlern. Then you need
to repeat the Psion-I process for Testmake. When installed you should see underneath 
the two icons 4 files that are examples which I have created over the last few years
(I have been using the program for quite a while).

The other way:
~~~~~~~~~~~~~~

Alternatively you can do the above manually by copying the following files into 
their respective places (you will have to create a directory called TST):

                       Destination
File Name           directory on Psion               Description
---------           ------------------               -----------
Testmake.opa             \app
Testlern.opa             \app
Fredic.odb*              \tst                 2000+ word French dictionary
Gerdic.odb*              \tst                 2000+ word German dictionary
Internet.odb*            \tst                 Database of a few Psion and F1 racing Web sites
Physics.odb*             \tst                 Useful Physics equations (GCSE Level)
    * These files are optional example files.

When these files have been copied across you just need to install Testmake 
and Testlern onto your system screen as explained above. You should see any 
example tests you installed appear under both icons.

Some Notes on Some of the Functions
-----------------------------------

Open CSV
~~~~~~~~
This function can open Comma Separated Value documents created by Excel. There are two things
to note about this however. Firstly there can only be 100 characters between commas, any more
will not appear in the test file produced. Secondly, only 4 fields are saved. Therefore
anything that appears after the 4th comma on a line will be lost.

Sorry about these limitations, however I had to do this to conform with the rest of the program!

"Learn it!" and "Edit it!"
~~~~~~~~~~~~~~~~~~~~~~~~~~
These functions will only work if the Testmake.opa and Testlern.opa files are in the app 
directory, as explained above. Therefore I would avoid renaming the two files.
