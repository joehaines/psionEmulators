Installation 
-------------
First create an subdirectory - '\DAT\VOC' 
Install following files manually:

\APP\VE.OPA
\OPD\VE.RSC
\DAT\VOC\IMAGE.dbf

Optional
\DAT\VOC\AWS001.DBF         Advanced Vocabulary Part 1  
\DAT\VOC\AWS002.DBF         Advanced Vocabulary Part 2 
\DAT\VOC\AWS002.DBF         Advanced Vocabulary Part 3
        \.....              are in working
\DAT\VOC\PSIWB.DBF          Primary least Vocabulary, about 1400 entries
\DAT\VOC\PSIWWB.DBF         Scientific Vocabulary, about 400 entries but
                            not complete

Use Psion+I on the system screen to install the application.

Full help should be avaliable online, simply press "HELP" on the Psion
It would be very pleasent if someone uses this program and also creates	
some vocabularies.
