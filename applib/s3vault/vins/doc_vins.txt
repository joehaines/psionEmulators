(French : Traduction française : voir plus bas)


Generalities :
==============

VINS is a software about wine and wine-cellar management. 'VINS' means wines in french.

A large part of VINS are databases. Hereafter, you'll find their descriptions :

	* A database of APPELLATIONS : more than 550 appellations are included (every french 'AOC' and 'AOVDQS' for instance ...) :

		- Appellation name
		- Country
		- Région
		- Vinification : red, white or rosy
		- Wine type :
			- Red wines :
				- Light and supple
				- Corpulent and fruity
				- Generous but tender
				- Steady and powerfull
				- Effervescent
				- Sweet
			- White wines :
				- Light and fruity
				- Dry
				- Corpulent
				- Soft
				- Effervescent
				- Sweet
			- Rosy wines :
				- Light
				- Corpulent and fruity
				- Effervescent
				- Sweet
		- Grapes
		- Apogee mini and maxi (in year)

This database is updatable by user and it's possible to add some new appellations.

	* A database of VINTAGE with a quality cotation for each region, since year 1950.

	* A database of FOODS AND WINES divided in 5 parts :

		- Desserts
		- Starters
		- Cheeses
		- Vegetables
		- Sea & river products
		- Meats
for a total of more than 110 recipes. For each one, VINS is able to give you a main choice and an alternative one (interesting for small cellar ...)

	* A database CELLAR with your own wines. You can register and manage :
		- Every fields of the APPELLATION database, copied directly from this base when creating a new wine in the  CELLAR
		- Wine name
		- Year
		- Rank
		- Quantity
		- Bottle size
		- Location
		- 2 'others' for users needs

The apogee of wines are recalculated automaticaly, from standard apogee for the appellation and vintage quality.



How to use ?
=============

There is 2 differents modes in VINS :
	* CELLAR : to manage your cellar
	* WINE BASE : to work with the APPELLATION database.

The navigation is the same in the 2 modes :
	* Arrows <- and -> to go from a wine to another
	* psion + arrows : the same, but by step of 5
	* In the CELLAR mode, Arrows up and down to see the second part of the screen
	* To perform a rapid search on appellation name or wine name, just type directly a few letters : the first wine found with this string will be shown. To erase the search string : escape or wait 10 secondes.
	* In the right of the screen, some informations are given :
		- The current mode
		- The status of the selection : full or partial
		- N° wine / total wines
	* Dialogs : use 'escape' to go to the previous dialog
	* After a search, you'll have only a selection of the required wines. You can navigate through the selection in the same way as with the complete file. To return to the full file,  'Menu / Use / All wines'.


Menus of the CELLAR mode :
	* Mode :
		- Wine base : to change mode
	* Edit :
		- Add
		- update
		- Delete
		- Print : (not available yet)
	* Management :
		- Drink (-1) : quantity = quantity-1 for the selected wine
		- Not-drink (+1) : quantity = quantity+1 (for a bottle took in the cellar and finaly not opened)
		- Statistics : informations about your cellar, by region, by vinification and type. Very usefull.
	* Use :
		- All wines : to select the entire file
		- Search
		- Food & wines : select a recipe and VINS will suggest you a wine (for home or for restaurant ...)
		- Service : some tips about service : temperature, delay after opening, ...
	* Special :
		- Settings : to choose your language : French, English or Deutch
		- Quit
		- Shareware : everything you should know  abour registering this wonderfull software !


Menus of the WINE BASE mode :
	* Mode :
		- Cellar :  to change mode
	* Edit :
		- Add
		- Update : In case of modification, every wines in the cellar with this appellation will be updated.
	* Use :
		- All wines : to select the entire file
		- Search
		- Food & wines : select a recipe and VINS will suggest you a wine (for home or for restaurant ...)
		- Service : some tips about service : temperature, delay after opening, ...
		- Vintage : give you the quality of a desired year for the current appellation.
	* Special :
		- Settings : to choose your language : French, English or German
		- Quit
		- Shareware : everything you should know  abour registering this wonderfull software !

VINS Version 2.0


Présentation & fonctionnalités :
=========================

VINS est un logiciel sur le vin et la gestion d'une cave à vins.

VINS comprend de nombreuses bases de données pour son fonctionnement, en voici la description : 

	* Une BASE DES APPELLATIONS : plus de 550 appellations (toutes les AOC et AOVDQS françaises pour le moment ...) avec les caractéristiques suivantes :
		- nom de l'appellation
		- pays
		- région
		- Vinification : rouge, blanc ou rosé
		- type de vin (caractéristique classique de l'appellation) : 
			- Vins rouges :
				- Léger et souple
				- Corpulent et fruité
				- Généreux mais tendre
				- Ferme et puissant
				- Effervescent
				- Doux
			- Vins blancs :
				- Léger et fruité
				- Sec
				- Corpulent
				- Moelleux
				- Effervescent
				- Doux
			- Vins rosés :
				- Léger
				- Corpulent et fruité
				- Effervescent
				- Doux
		- Cépages de l'appellation
		- Apogée mini
		- Apogée maxi
Cette base est modifiable par l'utilisateur et il est possible de rajouter des vins (français ou étrangers)

	* Une base MILLESIMES qui comprend une cotation qualité des années de 1950 à 1995 région par région.

	* Une base METS & VINS divisée en 5 types de mets :
		- Desserts
		- Entrées
		- Fromages
		- Légumes
		- Produits mer & rivière
		- Viandes
avec pour chaque type des divisions et sous-divisions pour plusieurs centaines de préparations culinaires. Pour chacune de ces préparations, la base propose un (ou des) vin  principal et un (ou des) vin alternatif (utile si votre cave est réduite ...).

	* Une base CAVE qui comprend vos propres vins. Les caractéristiques suivantes peuvent être gérées :
		- Toutes les caratéristiques de l'appellation extraite de la BASE DES APPELLATIONS (nom appellation, vinification, ...)
		- Nom du vin
		- Année
		- Cru
		- Quantité
		- Taille bouteille
		- Emplacement
		- 2 champs utilisateurs
L'apogée des vins de la cave est recalculée en fonction de l'apogée propre à l'appellation et de la qualité du millésime.


Utilisation :
=========

VINS comporte 2 modes :
	* CAVE A VINS : pour gérer votre cave
	* GENERIQUE : accès à la base complète des appellations, utile au restaurant par exemple.

La navigation est similaire dans les 2 modes :
	* Les flèches  <- et ->  permettent de passer d'une fiche à l'autre
	* Touche psion et flèches  <- et -> idem, mais de 5 en 5
	* Dans le mode CAVE, les flèches haut/bas permettent de visualiser les 2 parties de la fiche.
	* Pour une recherche rapide sur l'appellation ou le nom du vin vous pouvez taper directement au clavier quelques lettres : la première fiche comportant cette chaine de caractère sera affichée. Escape permet d'effacer la chaine de recherche pour en retaper une autre. Elle s'efface également automatiquement au bout de 10 secondes d'inactivités.
	* Le bord droit de l'écran présente des indications sur :
		- le mode en-cours
		- l'exhaustivité de la sélection (partiel ou complet)
		- le numéro de la fiche et le nombre total de fiche.
		- eventuellement d'autres indications de contexte (saisie, ...)
	* De manière générale, la touche escape utilisée dans les dialogues de saisie ou de choix, permet de remonter au niveau supérieur.
	* A l'issue d'une recherche ou de l'utilisation de la fonction 'Mets & vins' par exemple, l'affichage présente une sélection du fichier. Il est possible d'y naviguer de la même manière que dans le fichier complet. Pour revenir au fichier complet, faire Menu/Utilisation/Tous les vins:

Menus du mode CAVE A VINS :
	* Mode :
		- Générique : changement de mode
	* Edition :
		- Saisir
		- Modifier
		- Supprimer
		- Imprimer (cette fonction n'est pas encore disponible)
	* Gestion :
		- Boire (-1) : Décrémente le stock du vin en-cours d'1 unité
		- Non-bu (+1) : Incrémente le stock du vin en-cours d'1 unité (bouteille sortie de cave et finalement non-ouverte par exemple)
		- Statistique : Présente un état complet de la cave, par région, par vinification, par type de vin, en nombre de vin et nombre de bouteille. Très utile pour gérer votre cave qualitativement et quantitativement.
	* Utilisation :
		- Tous les vins : revient au fichier complet
		- Recherche : pour une recherche multi-critères dans la base
		- Mets & vins : vous propose de choisir un met et vous suggère les vins d'accompagnement de votre cave.
		- Service : pour le vin en cours, conseils de service.
	* Spécial : 
		- Quitter : quitte VINS et effectue une compression de la cave.
	
Menus du mode GENERIQUE :
	* Mode :
		- Cave à vins : changement de mode
	* Edition :
		- Saisir
		- Modifier : En cas de modification des caractéristiques d'une appellation, tous les vins de la cave dans cette appellation sont automatiquement mis à jour.
		(rem : il est impossible de supprimer dans ce mode)
	* Utilisation :
		- Tous les vins : revient au fichier complet
		- Recherche : pour une recherche multi-critères dans la base
		- Mets & vins : vous propose de choisir un met et vous suggère les vins d'accompagnement dans la région choisie.
		- Service : pour le vin en cours, conseils de service.
		-Millésime : pour le vin en cours, qualité d'un millésime donné
	* Spécial : 
		- Quitter : quitte VINS et effectue une compression de la cave.
	


Divers :
=======

* De nombreuses appellations existent en plusieurs vinifications et éventuellement  plusieurs types de vin peuvent exister pour une même appellation et vinification. Par exemple, dans l'appellation GAILLAC, il existe du rouge, du rosé et 2 types de blancs : Moelleux et Sec.

* Les données incluses dans VINS sont fournies sans garanties d'aucunes sortes. Si vous constatez des erreurs, merci de m'en faire part pour que je les corrige.
