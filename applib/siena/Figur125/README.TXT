This readme file covers installation for:
FigureIT for Series 3a/3c and Siena 

Installation:
        These instructions assume you have PsiWin (or Psion Link for MacOS)
and are able to transfer files between your Siena and PC.

Once you have unzipped this file, you will find three different directories
that are named:

\FULL3A\
\FULLSIEN\
\BOTHLITE\

These directories contain different install options which are:

\FULL3A\        Full installation of FigureIT for the Series 3a/3c (about 50k)
\FULLSIEN\      Full installation of FigureIT for Siena (about 40k)
\BOTHLITE\      A "Lite" installation of FigureIT (about 30k) for BOTH
Siena and the Series 3a/3c


To install one of these, simply do the following:
1. Start PsiWin and establish a connection
2. Find this folder on your hard disk
3. Open the installation folder you want (FULL3A for example)
4. Inside you will find an APP folder, drag and drop (hold down the 
CONTROL key to do a straight COPY) that APP folder to the
   Internal drive's root directory of your Series 3a/3c or Siena.
   You can also choose to install to an SSD if you own a Series 3a/3c
   Mac owners should simply drag and drop, holding down control isn't needed
5. In the System Screen, choose "Install" from the Apps Menu.
6. Choose FIGUREIT.OPA and press enter.

For instructions on how to use the app, just press the help key on your Psion.
