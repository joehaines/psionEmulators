Siena PsioCollect v1.0

Introduction
------------
PsioCollect is record collectors database. It is a fully functional
shareware application for all Siena users and a must for all music enthusiasts.
It has a very attractive graphical interface and is very easy to use. There are
many attractive features and useful tools in the application which adds to its appeal.

Program Information 
-------------------
Any number of files can be created and maintained and each file has a 1000 record limit
in order to save on memory. Records can be maintained in a number os different ways. New records
can be inputted, existing records maintained/deleted or 'Jumped to'. The file can also be completely
cleared out. You can interrogate the database in a number of ways getting to any part of the database
very quickly to find the information you require. Is is also possible to enter a string containing any
part of an existing database field and each instance of the 'entered string' will be repeated until the 
desired information is found. 

There are many ways to enhance the look of the database enhancing the presentation of its data giving it
a 'Personal Feel'. Password protection can be attached to files also giving greater security of your precious
data. Sorting the database is very easy to do and makes searcing through the file trying to find your data
so much quicker and easier. You can generate a 'WORD' compatible file containing all of your database
information to be printed out in report form.

HOT KEYS
--------
For those of you that are not aware of what these are they are keys which - when pressed - take you to the heart 
of the action. So if when reading through the help files you find that if you press Psion-S you can sort the database
you will find that it will do just that ! I suggest you try looking at the help files to find useful information on any
function you need.

Installation of the software
----------------------------
The ZIP file 'COLLECT.ZIP' will contain three other files. The executable
program file 'COLLECT.OPA' needs to be copied onto the \APP directory of your Siena.

The files 'ALBUM.PIC' and 'SINGLE.PIC' need to be copied onto the \PIC directory of 
your Siena.

Finally go the APPS part of the main system menu, select 'Install' for COLLECT.OPA
 
If you have any difficulties please let us know.
