1. Installation:
================
If you have unzipped the ZIP file
with the `recreate directory' option
(`-d' with PKUNZIP) then you can
simply copy the files across.  For a
partial installation, or if you
cannot `recreate directory', here are
the details of where the files must
go.

(a) Copy PSITRISS.OPA to the \APP\
		directory on your Psion (on any
		drive).
(b) Make a directory \PSITRIS\ on
		your Psion (on any drive).
(c)
	(i) Copy all the other files you
			want into this directory:

	BLOCKS.PIC			Essential.
	GRIDBACK.PIC		Essential.
	PSITRIS.INI			Essential.
	GAME.DAT				Essential.
	INTROS.PIC			Optional (opening
														screen).

	(ii) Optionally, make a directory
			\PSITRIS\BKG\ on any drive and
			copy any of the remaining PIC
			files to it.  These are used
			as backgrounds in the game, but
			you may use your own PIC files
			if you like or have a simple
			greyscale background.
			
			"(none).pic" is an empty file
			which takes up no space on disk
			and can be selected if you are
			using a greyscale background.


(d) In the Psion System Screen, press
		Psion-I or select `Install' from
		the `Apps' menu.  Choose
		PSITRISS.OPA as the filename and
    press Enter.  The Psitris icon
    will appear on the system screen.
    Press Enter on it to play the
    game.

2. Instructions:
================
If you have ever played Tetris, you
will know what to do, but for those
of you who haven't, the idea is
simple.  You are given a grid on
which you must place a series of
blocks of different shapes and sizes
which the computer gives you (they
are random, I promise).  You must do
your best to fit them in as neatly
as possible as they fall down.  If
you make a complete line of blocks
across the grid, they will be
destroyed (this is called a line).
The aim of the game is to prevent
the blocks reaching the top of the
screen.  If they do, your game is
over.  To help you, the next block
is shown to the right of the grid
(although this can be turned off for
the brave and skilful).

3. Keys:
========
(a) At start:
	Menu			- Show a list of options:
	Psion-N		- Start a new game.
	Psion-H		- Show high score table.
	Psion-A		- Show Game info.
	Psion-R		- Register game
							(shareware only), see
							section 6.
	Psion-X		- Exit game.

(b) In game:
	Left arrow	- Move the block one
								square to the left.
	Right arrow	- Move the block one
								square to the right.
	Down arrow	- Pull the block down
								faster.
	Enter				- Toggle preview next
								block On/Off.
	Space				- Spin block
								(clockwise).
	Delete			- Let the block fall
								down (once this has
								been pressed, the
								block cannot be
								stopped, moved or
								spun).
	Menu				- Show a list of
								options:
	Psion-P			- Pause the game.
	Psion-H			- Show high score table.
	Psion-E			- End current game
	Psion-X			- Exit the game

4. New game options:
====================
(a) Game type:
	(i) Lines - play until a given
			number of lines is achieved
			(or the game is over).
	(ii) Points - play until the game
				is over
(b) Level (Game type lines only)
	Level:		Lines to make:
	------		--------------
	0						15
	1						20
	2						25
	3						30
	4						35
	5						40
	6						45
	7						50
	8						55
	9						60
(c) High - places random incomplete
		lines at the bottom of the grid
		(to get in your way)
	High:		No. of incomplete lines:
	-----		------------------------
	0					0
	1					2
	2					4
	3					6
	4					8
	5					10
	6					12
(d) Background - Choose a PIC file
		for the background or set the
		last line of the dialog to one of
		the greyscale options.  The
		greyscale options all look
		similar to this:
			B þ°²°°°þ W
		Where `B' means black and `W'
		means white.

7. History:
===========
Version 1.01b		-Pre release version,
		with lots of bugs.  Hmmm...we'll
		say no more about that :-)
Version 1.3			-First released
		version.  Took up lots of memory,
		with little tolerance of what
		drive the files were on (mainly
		because I only have the RAM
		drive).  No error trapping and
		no help system.  Did not respond
		to system requests to shut down.
Version 1.7b		-Beta of version 2.01,
		with a few bugs.
Version 2.01a/c	-Drive and error
		tolerant, has a help system.
		Works with much less disk access
		(which tends to drain the
		batteries), uses the cache and is
		generally much more efficient.
		New graphics, with the
		opportunity of using your own PIC
		files.  It also has an `Exit'
		option from within the game and
		will pause if it is put in the
		background.  Will respond to
		system requests, even when the
		"Paused" dialog is displayed. 
		Has many other minor bug fixes.
Version 2.01s		-As 2.01a/c except it
		is for the Siena.  It has no
		sound files or help system but is
		otherwise identical.
