QuickAlarm Version 1.40F
-------------------------------------------------------------------------------

QuickAlarm is for you, if you
 - wanted to make a 5-minute-tea and it became a ten minute brew,
 - left your car at the parking meter and had to get it back from
   the police,
 - took a short nap and got waken up by your boss,
 - boiled a 3-minute-egg which became like concrete,
 - ...
and all that, because you just did not set an alarm, 'cause for that you would
have had to press (at least) one key too much (you lazy one)! (For me it was
the tea which made me write this program...)

With QuickAlarm you specify in advance the time left until an alarm will ring,
the sound which will be played and a message up to 64 characters. Each alarm
specified will show up underneath the QuickAlarm icon. All you have to do to
set the alarm is place the cursor on the desired item and press enter. A small
beep sequence will tell you that the alarm has been set (you may check it in
TIME). You can specify whether you want these beeps to be loud, quiet or not
hearable at all ;-).
To cancel an alarm use TIME.
Specify a new one pressing Psion-N on the file list. Delete an alarm
specification using the system screen (delete file). If you specify "00:00:00"
as time interval you will be asked to enter a time when setting the alarm. You
then even may chose between absolute time (e. g. quarter past three) or
relative time (e. g. 16 minutes from now) and may change the default message
text and the confirmation beeps.
Good practice may be to use beeps for totally predefined alarms and no beeps
for those which ask you for the time (specified duration of 00:00:00).

To install the English version of QuickAlarm copy the files to your Psion as
follows:
 \APP\QUICKALM.OPA
 \APP\QUICKALM\ENGLISH.LNG
 \ALM\*.QAL                      (optional, the supplied files are examples)

I recommend to install QuickAlarm so that it can be easily accessed:
either set Ctrl-Time to point to QuickAlarm or install it as the first
or last item in system screen (what I did).

If you prefer to install QuickAlarm in a different language, please copy the
*.LNG file of your choice instead of ENGLISH.LNG into the given directory.
If no file for your language is supplied, this is because no one has been
found to do the translation work yet! In this case it will be most appreciated
if you would just send me the translated file TRANSLAT.TXT. It would be even
better, if you could supply a translation of this file (README.TXT) as well!
