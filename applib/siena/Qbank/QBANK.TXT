
 ======================== Q-Bank v1.x (Shareware) ================= Aug '97


 WHAT IS IT?
 =======================================================================
 
	If you want a small bank account program (less than 10K) that runs in
	the background and allows you to enter, edit and delete bank
	transactions, then this should do the job.

	All Transactions are displayed in a scrolling display and can be
	fully edited.

	I've included an example data file to give you an idea of how it
	works. 



 QUICK INSTALL
 =======================================================================

	Copy the following files to your Psion's internal disk:

		I:\APP\QBANK.OPA	(essential)
		I:\OPD\QBANK.OPD	(optional example file - recommended)

	(If the second file is not found, a new one is created). 

	Then from the main system screen, press PSION I to install 'QBANK'.



 FEATURES
 =======================================================================
 - FULL EDITING
   	Any entry (past/future/present) can be fully edited.  If the date is
    	changed, the transaction will be moved to the correct position in the
    	file.
 - NO TIME LIMITS
    	Transactions can have any date and will be inserted in the correct 
    	position in the file.
 - FULL DATE
    	Day AND date are displayed along with the transaction details, to aid
	clarity.
 - BACKGROUND BUTTON
    	Pressing the escape key will send the program to the background.
 - PASSWORD (Optional)
    	Everytime the Psion is switched on, the program will require a
	password to operate.
 - SMALL MEMORY
    	The whole program is less than 10K, and requires @17K of memory to run.
 - FIND and PURGE functions.
 - INTELLIGENT SORTING
 - AUTO FILE DEFRAGMENTATION

 NOTES
 =======================================================================
 - PASSWORD PROTECTION
     a) The password function stops a quick look from someone who shouldn't.
	But it should not be relied upon for secure protection from
	prying eyes due to the 'open' nature of data files.
	
	Use the Psion's main system password for complete security.

     b) Everytime the Psion is switched on, QBank will require a 
	password (if activated) to be accessed, thus protecting your data.

	This feature will *NOT* be invoked if the menu, or any dialog is 
	displayed at the time of turning the machine off.
	This is due to a limitation in OPL which I cant seem to work around.

     c) Exiting and restarting the program will not affect the password.

 - 'EXIT ALL APPLICATIONS'
	If using PsiWin or the system menu option to 'Exit all applications',
   	QBank will not closedown if the menu or a dialog is displayed.
   
 - PROGRAM SPEED
  	Program speed (sorting) is not necessarily dependent on the number of
	transactions, but mainly on the time between the 1st and last 
	transactions - a gap of more than a year should be avoided.

	Use the Purge function to avoid this.

 - NEW TRANSACTIONS and SORTING
	New entries will not invoke file sorting IF the date of the transaction
	is later than the last entry in the file.
