INSTALLATION:
=============

Copy all the files ending in .OPA to the APP directory, if you do not have an
APP directory, create one as follows...

Press the SYSTEM button

Press the MENU key

Under 'Disk' select 'Make directory' and press Enter

Next to 'Name' type APP

Now use the same method to create a directory called PSITECHS, this time typing
PSITECHS next to 'Name' instead of APP.

When you have created these directorys and copied the .OPA files to the APP
directory, copy the remaining files except this one, to the PSITECHS directory.

Then press the SYSTEM button on your Siena, press Menu, go to the APPS menu and
select Install. Choose the one of the programs and press Enter, An icon will now
be created, select this to run the game. Repeat the process for each of the
games.
