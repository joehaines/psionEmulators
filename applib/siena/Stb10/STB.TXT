Requires Psion Siena or Series 3a or 3c.

STB is a new version of the old Pub favourite "Shut The Box", using
the Psion's abilities to add sound and graphics, plus do all the
counting for you!

It's an educational tool for children as it requires them to do quick
mental arithmetic to operate the game. It's also fun to play for adults,
who will appreciate more of the strategic and risk-taking elements.

Although STB is shareware, you'll notice that there are no nag or
begging screens and that nothing whatsoever is crippled. This is because
I trust you to evaluate the game honestly and pay up if you or your
children do like it. Psion users are, on the whole, an honest breed!

What registration *does* get you is your name on the background screen
and a clear conscience that you're helping support future development
of STB and other quality Psion shareware software.

For playing instructions and rules, please read the on-line help screens
that are built into the game!

Installation.
----------------------------
[Siena users: note that the two .WVE sound effects files are not used on
the Siena, and can be left off]

If you don't use PsiWin on a PC:
  Assuming you *did* use -d with PKUNZIP etc. and now have all the files
  in their original directory structure; with the link on between the
  Psion and the desk-top machine, go to the Psion keyboard. Position the
  cursor on the system screen on Time and press Psion-C. The 'Copy Files'
  dialog will appear with the root directory selected. Change the second
  line to point to the appropriate directory on the desk-top. Change the
  third line to be "\", i.e. a single backslash. Change the fourth line
  to be the disk you want to install STB onto. Set the fifth line
  ("include subdirectories") to read "Yes". Your Psion will then copy
  over the directory tree in one go to the appropriate disk.

If you use PsiWin:
  (i) If you correctly unzipped STB with its orginal directory
      structure, then simply drag and drop this directory tree onto one of
      your Psion's disk root directories. Note: dragging and dropping
      whole directory trees so that they end up in the right place is not
      trivial and you may wish to read the manual and/or practice first!!

  (ii) If you've got all the STB files in the same directory, you're
      definitely going to have to do it all manually, but at least you
      can do it all with 'drag and drop'! You'll need to create the
      \APP\ and the \APP\STB\ directories by hand on your Psion using
      the 'Create Directory' menu command. Put the .OPA file in \APP\
      and all other files in \APP\STB\

  TIP: - when you drag and drop, remember to hold the <Control> key down
  throughout the operation. This forces PsiWin to just copy the file(s)
  and not try to do any fancy conversions!

If you put all the STB files on a Series 3a or 3c, you can expect to use
up 25k of disk space.
