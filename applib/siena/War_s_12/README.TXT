INSTALLATION (requires 37k)
============

Copy WAR_S.APP into the APP directory in your Siena's internal memory,
(if you do not have the directory M:\APP\, see instrucions below to create one).

Next create the directory M:\PSITECHS\.

If you dont know how to create the directorys, instructions follow:-

Press the SYSTEM button

Press the MENU key

Under 'Disk' select 'Make directory' and press Enter

Next to 'Name' type APP

Now use the same method to create a directory called PSITECHS, this time typing
PSITECHS next to 'Name' instead of APP

Copy all the remaining files except this one (README.TXT) into the PSITECHS
directory.

Once the files have been copied, press SYSTEM, then MENU, then select INSTALL,
select WAR_S.APP and press ENTER. An icon for WAR will then appear, select this
to begin the game. Instructions on how to play are in the game, just press the
Help key once the program has started.
