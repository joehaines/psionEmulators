PsioYahtzee v1.0

Introduction
------------
PsioYahtzee is the Siena version of the dice favourite. It is a fully functional
shareware application for all Siena users and a must for all games enthusiasts
It has a very attractive graphical interface and is very addictive to play. There are
many attractive features in the application which adds to its appeal.

Updates
-------
Program updates appear on the website as the new software is released. My 'Siena' Site can 
be found at 'http://www.geocities.com/SiliconValley/Pines/9147/'

Installation of the software
----------------------------
The ZIP file 'YAHTZEE.ZIP' will contain nineteen other files. The executable
program file 'YAHTZEE.OPA' needs to be copied onto the \APP directory of your Siena.

The files with extension *.PIC (18 in total) need to be copied onto the \PIC directory of 
your Siena. Please check to make sure that none are missing.

Finally go the APPS part of the main system menu, select 'Install' for YAHTZEE.OPA
 
If you have any difficulties please let us know.
