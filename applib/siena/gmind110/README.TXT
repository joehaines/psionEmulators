
              gMIND v1.10
            _______________

  gMIND is a freeware Master Mind game for the Psion 3a/c/mx/Siena. 

_______Installation

  When installing gMIND, copy the files to the following locations on any 
drive:
    \APP\GMIND\GMIND.FON
    \APP\GMIND\GMIND.PIC
    \APP\GMIND.OPA

  gMIND will store its settings in the file GMIND.G, in the \OPD\ directory 
on the internal drive. This file is automatically created the first time 
gMIND is run.

_______The game

  gMIND is based upon the well-known game Master Mind, which is a logic game 
for two players. One player is the "Codemaster", and composes a random 
combination of four pegs, chosen from six different colours. The 
"Codebreaker" will then try to guess the code by trying different 
combinations on the board. The codemaster will place key pegs on the board, 
depending on how many correct pegs there are.

  -  A black key peg tells you that one of your pegs is of correct colour 
     and in the right position.
  -  A white key peg tells you that one of your pegs is of correct colour, 
     but in a wrong position.
  -  The placement of the key pegs has no connection to the placement of the 
     ordinary playing pegs.

  In gMIND, your Psion is the Codemaster, while you are the Codebreaker. 
Game difficulty can be varied. The simplest game does not allow equal 
colours, while the hardest allow both equal colours and empty positions 
(which is equivalent to having seven colours).

    Game Variant                      Possible combinations
---------------------------------------------------------------
  no equal colours, no empty spaces           360
  no equal colours, empty spaces              840
  equal colours, no empty spaces             1296
  equal colours, empty spaces                2401

_______Preferences

  Equal colours        Allow/disallow equal colours. 
                       Default setting is 'yes'.
  Empty positions      Allow/disallow empty positions. 
                       Default setting is 'no'.
  Pegs                 Choose the set of pegs used; grey hues
                       ("colours") or symbols. Tip: Symbols might
                       be easier to see in low-light conditions 
                       (if you don't have a backlit Psion).
                       Default setting is 'grey hues'.
  Move marker          Set this to no if you don't want the marker to
                       automatically move to the next position after
                       the peg is set.
                       Default setting is 'yes'.

_______Keys
  
  Left/right arrow      Choose position
  Up/down arrow         Choose colour
  Escape                Erase line
  Delete                Erase peg
  Space                 Set peg
  Enter                 Finish line
  s                     Sets same colour as on previous line
  Psion-n               New game
  Psion-h               Hint
  Psion-q               Set preferences
  Psion-d               Reset preferences to default
  Psion-x               Exit gMIND

_______Requirements

  gMIND is intended to run on a Psion 3a/c/mx/Siena. It has been developed 
on my 3c, and has been found to work on the 3a and Siena emulators.

  gMIND needs approximately 12K for installation and around 40K free system 
memory to run.

_______Troubleshooting

  If you get "out of memory"-messages, try freeing up system memory by 
deleting some files you don't need or closing open applications. gMIND 
requires around 40K of free system memory.

  I you get error messages concerning the configuration file, try deleting 
it (this will restore the game to default settings). The file ("gmind.g") is 
found in the \OPD\ directory of your internal drive. If this doesn't help, 
try freeing up more disk space.
