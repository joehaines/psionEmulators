>What is it?
Q-Calc is a very advanced intelligent scientific calculator with many built in utilities and statistics functions.

>New since v1.1
Hotlist - Stores up to 10 of your most commonly used expressions
Matrix calculator - with multiplication, inversion, addition and more
Statistics - New features: Unbiased standard deviation,  minimum and maximum, plus sorting, tidying and text import/export
Entering data into Statistics is now much easier
Binary and Hexadecimal modes
Boolean logic operations: and, or, not, xor
New gradientutility - Enter 2 coordinates and it will give the gradient and y=mx+c formula
Square root, e^x, 10^x and y^x all now work as normal functions and do not need closing brackets, eg just type 23**2+3 to enter 23<SUP>2</SUP>+3
Now flash firendly
Engineering mode
Some parts are now written in C
Loads of little improvements, adjustments and bug fixes

>Installation
-If you know what you're doing:
Follow the normal installation procedure. All files should be placed in the same directory on the psion as they appear in the ZIP archive. Press help from within Q-Calc for the user guide.

-If you don't:
Create a directory called App in the root directory of your disk. Within this create a directory called QCalc.

Copy Q-calc.opa to \App\. Copy QC.DYL, QMATRIX.DLL and QCALC.HLP to \App\QCalc\

Press Psion-I and select Q-Calc.OPA. A calculator icon should appear. Select it and press Enter.

Press help from within Q-Calc for the user guide.
