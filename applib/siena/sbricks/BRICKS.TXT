Welcome to Bricks, the only Siena breakout game. 

Requirements:
A Psion Siena palmtop.
45K for installing the game
~70K for running the game

Installation:
Place the bricks.opa file anywhere.
Place the bricks.lvl, bricks.hlp, bricks.pic and ball.pic files in
an \APP\BRICKS\ subdirectory on drive M.

Install bricks.opa in the usual way.

Note: the distribution ZIP file has the correct directory structure.

Starting the game:
When you first start Bricks, you will see the title screen, offering a
choice of various options. For full details, consult the on line help,
available by pressing Menu and selecting Help.

Help:
Help is available in the game. Press menu during gameplay to access it.

Q&A:
How come the ball hits a brick, but the two either side go?
Too boring to explain fully, but it involves the bricks being 10 pixels
wide, and the ball being 11 wide. If I reduxe the size of the ball, then
bricks get removed too easily.
