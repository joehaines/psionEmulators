*What is it?
Sheep Tetris is a clone of the classic Atari arcade game, Tetris. If you're not familiar with it, it involves navigating falling blocks to complete rows which, when filled, disappear.

*Installation
Copy SheepTet.opa to the \app directory (You might need to create one) on  any drive. Press Psion-I and select SheepTet.opa. The first time you run it, a small highscore file will be created in \opd on the default drive.

*Controls
Turn the Psion sideways, so that the Esc key is at the top. Siena users should use 4 to rotate the piece clockwise, 1 and 7 to move it  left and right. Series 3a/3c users should use H, B and U instead. Press Space to drop it.

*Gameplay
A random block will fall from the top of the screen. Move it around and rotate it (see 'Controls' above). To save time, you can drop it with the Space bar, or just let it fall. The idea of the game is to create full rows from the falling shapes. When you do, it will disappear, and whatever is above will move down. If a piece lands partly above the top of the screen, the game is over.
