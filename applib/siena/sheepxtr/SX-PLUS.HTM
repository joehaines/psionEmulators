Registering Sheep Extras

What do I get?

For just £5 you get all this:

  • The nag screens will no longer appear, so it loads much more quickly.
  • 4 extra programs:

Sheep Clock

A large configurable clock readable from accross a room. It can also act as a screen saver. It has 3 different views (Time, Seconds, Date). There is also a choice of font, and almost every other aspect is configurable

Sheep Counter

For counting things. Four differents counters are available simultaneously, plus a total and average. It can be really handy for almost anything. There are hotkeys for each counter and it is easy to reset, and numbers can be copied to the other applications

Sheep Jotter

A note taker. Notes can be quickly viewed or added to with minimal keypresses. It has search facilities and date stamping.

Notes can be copied to other applications.

Sheep Measure

The easiest and fastest unit and currency convertor available.

Type in the number and the unit (eg "123cm"), and the program will automatically recognise the unit and size and then display it in most other units. It requires much fewer keypresses than any other conversion system. The currency section is fully editable and can be set up for any currency.

What do I do when I get the code?

Run Sheep Extras, and select "Register". Enter your supplied name and code, and press Enter. To take advantage of the extra features, you will need to restart Sheep Extras.

To use the Plus pack, copy the contents of \PLUS\APP directory to the \APP directory on your Psion. Numbers.pic is the Roman font for Sheep Clock, and can be deleted if necessary. Currency.odb is an example currency file. You can also create your own from Sheep Measure, or use it as a starting point. Put it in \OPD.
