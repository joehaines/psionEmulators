HOW TO INSTALL YAHTSIENA
========================
Obtain the following files from Yahtsiena.zip:

	YAHTSI.OPA	put this in your \APP directory
	YAHTSI.ENA	put this in your \OPD directory
	YAHTSI.ICO	put this in your \OPD directory

(if you dont have an \OPD directory, create one using the menu options within the
file viewer)

Finally Use the INSTALL APP command from the main INSTALL menu and select the YAHTSI.OPA file.  Your Yahtsiena Icon should now be on your Siena Desktop.
