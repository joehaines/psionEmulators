Using the Abiword word processor.



AbiWord is the word processing program. It has many of the editing and formatting features that you would expect from a fully featured word processor and many text formatting features e.g. alignment and font settings can be applied to individual paragraphs or defined as a paragraph style. AbiWord can also export a file as text, as a web page (HTML), in Word format or as a Rich Text Format file (suffix .rtf) for users who wish to preserve formatting information. AbiWord's native file format is the AbiWord (.abw) or the GZipped AbiWord file (.zabw).

To select AbiWord, either tap on the AbiWord button bar with the stylus or tap on the AbiWord icon on the desktop.
