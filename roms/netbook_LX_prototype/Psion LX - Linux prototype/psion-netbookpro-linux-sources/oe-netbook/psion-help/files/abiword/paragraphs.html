Formatting paragraphs.



Many formatting and spacing options can be applied to blocks of text. A block of text can be a single word, a line or a paragraph. A group of paragraphs is a section. Select Insert Break from the Insert Menu to choose the appropriate break.

  • To apply formatting to an entire paragraph, e.g. to change the horizontal alignment, place the cursor within the text of the paragraph using the pen or arrow keys before selecting one of the alignment buttons on the formatting toolbar. To apply formatting to a number of paragraphs, make sure that the highlight covers at least part of each paragraph. You don't need to highlight all the text in the paragraphs you want to format.

Alignment changes the horizontal position of paragraphs on the page. You may wish to align the text left or right with the appropriate margin, centre a title, or justify text to align both edges with the margins.

Note: Margins are set as part of the file's page setup.
