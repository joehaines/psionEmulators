Using styles.



A style is a collection of formatting options which can be applied to a whole paragraph using a single command or keypress. AbiWord has a range of built-in styles including Normal, Heading 1, Heading 2 and Heading 3.

  • To apply a built-in style: select the paragraph(s), the pull down menu on the Formatting Toolbar and select the style you want, e.g. Heading 1.

Defining styles.



In addition to the built-in styles, you can create and modify styles of your own or import a pre-existing style from another location on our system. Styles are saved with the file, so each Abiword file can have different style settings.

  1. Select Create and Modify by tapping on the Format Menu and clicking Style. You can then click on each pre-defined style in order to see a description of its features before modifying or creating a new style.
  2. Press the Format button, select your new style and then modify text and as you wish.


You cannot delete or rename AbiWord's built-in styles, but you can modify their settings for the current file. The build-in styles in other files will not be affected
