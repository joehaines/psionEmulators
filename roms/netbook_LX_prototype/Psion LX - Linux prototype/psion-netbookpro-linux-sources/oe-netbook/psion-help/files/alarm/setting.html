Setting an Alarm.



To set an Alarm, tap the Alarm icon on the Psion LX button bar and choose the Alarm... option. The Set Alarm dialog box appears allowing the user to:

  1. Make an alarm active.
  2. Specify whether the alarm sounds on a specific date or on a weekly basis.

To set the alarm for a specific date:

  • Toggle the Alarm active button on.
  • Set the time and date from the pull-down menus in the Set alarm dialog box.
  • Click OK.

To set a weekly, repeating alarm:

  1. Toggle the Alarm active button on.
  2. Set the time.
  3. Select a button corresponding to the weekday on which you would like the alarm to sound.
  4. Click OK.
