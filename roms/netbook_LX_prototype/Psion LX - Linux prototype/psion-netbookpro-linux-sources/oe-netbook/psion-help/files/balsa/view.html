Viewing an email



To view an email:

  1. Select the message you want to read and tap on it or press Enter.
  2. Once you've read the message you can:
    • Reply to or forward the message by using the Reply and Forward button on the menu bar or the commands on the Message menu.
    • Move to another file within that particular mail box by using the arrow keys.

A paperclip symbol indicates that the email has an attachment.
