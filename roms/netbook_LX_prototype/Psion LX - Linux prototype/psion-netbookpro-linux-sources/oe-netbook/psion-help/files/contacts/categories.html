Adding Categories.



If the current categories are not suitable for the information you wish to search for, you can add and remove a category.

To add a category:

  1. Select a Contact and tap on the Edit button.
  2. Select the About tab from the Edit Contact dialog box and click on the Categories button.
  3. Tap the Create New Category button beside the Trash Can and give the new category a name before clicking OK and Save.
  4. Click on the toggle button to activate or deactivate the Category.
