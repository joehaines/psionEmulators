Filesystem introduction.



The filesystem is made up of files and folders or directories. The top level folder is called the root directory and contains all of the files that are pertinent to your system. Each file within this system is allotted a name and a "path" on the basis of where it lies in relation to the root folder. Thus a sample file---letter.txt---may be found at /home/user/My Documents where the forward slash / before home denotes root.

All of the files which you create will be stored within the /My Documents directory. The /My Documents directory can also contain directories as well as files. Linux on the Psion LX uses many other directories for other purposes but these should be left alone unless you are an experienced Linux user. The /home directory contains /home directories for every account on your system.

See section [Create a user] for information on adding other accounts to the system.

Important: Users of windows PCs should note that the Psion LX does not use drive letters e.g. C for the hard disk.

Important: The Psion LX filesystem is case-sensitive and therefore distinguishes between letter.txt and LETTER.txt.
