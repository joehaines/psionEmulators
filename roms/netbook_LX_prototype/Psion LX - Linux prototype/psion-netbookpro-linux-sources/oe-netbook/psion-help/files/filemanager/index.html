Using the filemanager.



Psion LX uses the File Manager to manage the files and directories which you have created on your system.

To open the Filemanager window, tap on the File Manager icon on the Programs screen. The Filemanager window is divided into two parts:

  1. The part to the left of the Filemanager window---the Directory Browser---lists all the users' directories and icons associated with that directory.
  2. The part to the right of the Filemanager window---the File Browser---lists files.

The Directory Browser and File Browser can both be turned on or off by selecting the appropriate button from the Settings menu on the Filemanager menu bar. Files are normally presented within the File browser by icon, name, size and the date of the last change to the file's contents. File details can be omitted in favour of a view of the file's icon by tapping the Icon View button on the Filemanager button bar.

Files are only visible if you open the directory containing them.

Note: Directories can also be nested inside a directory so that one directory contains another
