Using bookmarks



You can "bookmark" pages you wish to return to later.

To add a bookmark for the current page:

Tap the Bookmarks menu on the Toolbar and select Bookmark This Page. You can then rename the page and save it to a folder.

To go to a bookmarked page:

  1. Tap the button on the Toolbar, or select Bookmark manager.
  2. Select the bookmark from the appropriate folder or select the bookmark from the Bookmark toolbar if you have saved it to the bookmarks toolbar folder.

You can organise bookmarks using folders, in much the same way as you manage files with the File Manager.

To organise your bookmarks:

  • Select Manage Bookmarks from the Bookmarks menu and rename, move, delete your bookmarks or create new Bookmark folders.
  • To go to a bookmarked page, select the bookmark from the appropriate folder.

  • To export your bookmarks as HTML save your bookmarks as an HTML file so that you can use them as a home page, or transfer them to a Web browser on another machine.

    To do this:

    Select the Export option from the File menu in the Bookmarks Manager window. Enter a name and location for the file. Ensure the file is saved as type .html, htm, shtml or xhtml.
