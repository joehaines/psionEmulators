Finding text on a Web page



You can search for characters, a word or a phrase on a Web page you have opened.

To do this:

  • Select the Find in This Page button from the Edit menu.
  • Enter the text you want to search for and tap OK.

You can use the following search options:

  • Direction: use the Up and Down radio buttons to search up or down from the point you selected on the Web page.
  • Match case: use this option to only find text which exactly matches the case of the letters you entered.
  • Wrap: use this option to take account of word wrapping across a line.
