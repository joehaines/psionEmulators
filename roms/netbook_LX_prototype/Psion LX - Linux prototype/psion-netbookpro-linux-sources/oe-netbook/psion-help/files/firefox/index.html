Using the Firefox web browser.



Mozilla Firefox is the Internet World Wide Web browser. Use it to:

  • Connect to the Internet and view Web pages.
  • View locally stored Web pages and graphics files.
  • Download files, e.g. additional programs for your Psion LX from web sites.

Read Chapter [:Connecting to the internet] before reading the rest of this chapter.
