Saving Web pages.



You can save a Web page to your Psion LX so that you can view it again without having to connect to the Internet.

To save the current page:

  • Select Save Page as from the File menu. Give the file a name and location and tap OK.


Mozilla Firefox allows the user to save:

  • the complete web page.
  • web page, HTML only for viewing the web page without images.
  • as a text file so that the HTML can be viewed in Text Editor or vi.

You can copy the text on a page and paste it into another program, e.g. AbiWord.

To do this:

  1. Drag the pen across the area of text you want to copy, or use Select all on the Edit menu to highlight all the text on a page.
  2. Select Copy on the Edit menu, then move to the program you want to place the text into and use the Paste command.

To save an image displayed on a Web page:

  • Select the image by tapping on it.
  • Select the Save image as command from the Menu which appears, enter a filename and location and tap OK.
