Create a user account and set a password for your account.



It is important that you create a user account where your Psion LX will be used by more than one person. To create a user account:

  1. Select User Manager from the Control Panel.
  2. Select the Add User Button.
  3. Type a User Name in the appropriate field.
  4. Select a password by clicking on the Set Button. You will then need to enter and confirm your password.
  5. Select a Home directory. This directory is named after the user name of its owner.
  6. Leave the shell on the default. See Chapter [The Shell] for further information about shells.
