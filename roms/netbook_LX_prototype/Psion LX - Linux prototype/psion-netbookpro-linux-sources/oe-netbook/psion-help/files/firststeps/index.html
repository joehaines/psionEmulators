First steps with your netbook LX.



When you first switch on the Psion LX, you will see the Psion LX desktop. The desktop allows the user to configure the Psion LX and to organise files and folders.

The Psion LX desktop has a button bar or panel across the bottom of the screen from which you can access a program with a stylus tap. A selector appears along the right side of the screen allowing the user to choose between three screens:

  1. Today - information about appointments and email.
  2. Programs - lists all available programs.
  3. Tasks - a selection of everyday activities.

The Desk button on the button bar can also be used to move between screens. The Docs button can be used to browse files in the My Documents folder and to create new folders.

When you switch on the Psion LX for the first time it's a good idea to:

  1. Create a user account and set a password for your account.
  2. Set the current date and time so that you can use the Calendar program and set Alarms.
  3. Enter owner information so that your Psion LX can be returned if you loose it.
