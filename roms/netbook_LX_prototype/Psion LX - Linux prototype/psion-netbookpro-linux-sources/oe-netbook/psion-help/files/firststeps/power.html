Power Management.



The Psion LX is powered by a lithium-ion rechargeable battery pack. The Psion LX will warn you when the main battery charge is low.

Note: How long your batteries last will depend upon how you use your Psion LX. The Psion LX will use considerably more battery power when you have the brightness turned up, are using files stored on a memory card, or are using infrared or a communications card.


You can take steps to help prolong your battery's life:

  • Turn the screen brightness down (go to Control Panel/Screen Setup).
  • Set Auto sleep from Control Panel/Sleep Configuration.
  • Use files on the internal storage instead of a memory card, as the Psion LX requires more power to write to the memory card. The Psion LX can be powered from AC when connected to the AC adaptor. When the Psion LX is powered from AC, it will also charge the battery pack.
