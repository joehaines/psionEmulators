Set the Time and Date.



  1. Select Time and Date Setup from the Control Panel.
  2. Set the Time Zone, click on OK .
  3. Set the desired date and time values.
  4. Click the OK button in Time and Date Setup to save your changes.

Time and Date Setup may also be accessed from the Alarm application which is available on the panel.

  1. Click on the Alarm icon and select the Set the time option.
  2. Set the time, date and activate your changes as above.

Note: It is also possible to set the time from a Network but an internet connection will be needed (see Chapter [Setting up internet] )
