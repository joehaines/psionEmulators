Entering information.



To enter information in a cell, select it and start typing. You will see the information you are entering on the input line. The first character you type tells Gnumeric what kind of information the cell will contain. Gnumeric recognises five data types:

  1. Text: To enter text, simply type it in. If your text element begins with a number - e.g. 24 Longton Road - but you want it to be seen by Gnumeric as text, type a single quotation mark before the number.
  2. Number: Gnumeric will recognise numbers, currency values, dates and times.
  3. Formula: To enter a formula for a calculation, begin with a =. For example, to make a given cell display the sum of the contents of cells B1 and B2, type =B1+B2 in the cell where you wish the answer to appear.
  4. Boolean: A statement which can be either TRUE or FALSE. An advanced option for users who wish to construct logical statements.
  5. Error: An error value is shown where Gnumeric cannot calculate a formula.

Moving Cell Contents



You can move a cell's contents by:

  • Selecting the cells before copying, cutting and pasting to the desired location with the buttons on the Formatting Toolbar. To select a new location for the cell block, select one cell to paste to which will be the top left cell of your original cell block.

Note: Select Paste Special from the Edit Menu. Paste Special can selectively Paste a cell's format, contents or calculated contents to the desired location.
