Modem Dialler: Gkdial



Before you can use your email account and surf the web, you need to connect to the internet.

  • Activate Gkdial--- the modem dialler---by tapping on its icon on the Programs screen.
  • Select the Add option from the Connection Menu and fill in the Connection Properties dialog box using the information supplied by your ISP.
  • Test the connection by tapping Gkdial's Connect! button.
  • To disconnect, tap the Disconnect! button.

If connection is successful, Gkdial will report that you are Connected and give an input and output reading in bits/second.

You can reconfigure and add additional accounts by accessing the Add button from the Connection menu.

If you have configured Gkdial to work with more than one ISP, select your chosen ISP from the main Gkdial window.

General and Interface preferences can be fine-tuned from the Settings menu e.g. Tap on the Settings menu, select the General tab and select the "Retry if connection quits when dialling" option.
