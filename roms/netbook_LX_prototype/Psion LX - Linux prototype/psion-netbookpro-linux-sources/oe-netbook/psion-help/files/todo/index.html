Using the todo list.



You can use a To-do list to note down tasks or items you want to remember.

To activate To-do list, tap on the To-do list icon which is available from the Programs screen.

You will then see the To-do list window. To enter a new item in the list, click on the new item button on the Menu bar. A New item window will appear allowing you to:

  1. summarise the list element e.g. pick up the children from school.
  2. select the Due box to assign a date to the list element.
  3. record whether you are in the process of or have abandoned, completed or not started your task.
  4. record the task priority e.g. high, standard or low.
  5. give a more detailed description of your task to supplement the task summary.

The To-do list window will list all of the items which you have created.

When you have entered all the necessary information, tap on Save and the new item will appear in the To-do list window.
To edit an existing item, tap on the summary of the item in the To-do list window and the Edit to-do item window will appear allowing you to edit the information.
You can use the Paste command to insert text copied in other programs straight in as a To-do list entry. For example, copy some text in AbiWord using the Copy command, move to the Edit to-do item window and Paste into the appropriate field.
