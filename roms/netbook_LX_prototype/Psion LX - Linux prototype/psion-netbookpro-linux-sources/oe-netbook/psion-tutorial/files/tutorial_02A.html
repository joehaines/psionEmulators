Similarities and differences to PCs (2)

There is just one [X] button in the top right of the screen - not two. Where a program can have more than one file open, then this [X] button just closes the currently displayed file. If there is only one file left open, though, clicking this button closes that file and the program too.

The Psion LX uses the 'Albany' and 'Thorndale' fonts, which seamlessly replace 'Arial'™ and 'Times New Roman'™.

The main applications feature Zoom hotkeys - Ctrl+plus and Ctrl+minus make the text bigger or smaller.

Finally, one difference you may be very pleased to know: as a PC user you may well be used to the unpleasantness of viruses, repeated security updates, and unwanted pop-ups taking over your Web browser. These are almost unheard of on Linux systems like the Psion LX.
