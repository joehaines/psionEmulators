Files and folders on The Psion LX

As on a PC, you can find and open your documents and files in two ways:

  • you can go to the relevant program first, and then either click the 'Open' icon on the toolbar, or choose 'Open' from the 'File' menu.
  • or you can go to the File Manager program (it has its own button, entitled 'Docs', towards the bottom left of the screen).

    All of your documents and other files live in a "My Documents" folder.

    You can also create further folders inside "My Documents", if you want to organise your files further.

    As you may notice from the File Manager program, the 'My Documents' folder is actually inside some other folders - specifically, it is at /home//My Documents (where "" is actually the current user name.) And you can, if you wish, navigate around and use different folders, but this is not particularly advisable unless you know what you're doing, because:
  • Linux does use quite a few other folders for its own purposes, which you shouldn't interfere with, and
  • The entire software platform, including all of the programs and also the software that links to PCs and networks, is set up to look in 'My Documents'.

    Finally, as you may have noticed from the examples above, some small differences from the PC:
  • there are no drive letters, like "C:".
  • when you see a long 'pathname' for a folder or file, the various folder names it contains are separated by a '/' symbol, not a '\'.
