Web

The Web browser will be familiar to anybody who has used a modern Web browser like Mozilla™ or Opera™, or even an older Web browser like Internet Explorer™.

It has toolbar buttons for Back, Forward, Reload, Stop, and Home, like all common browsers.

These are followed by a box where you can type in the address of a web site to go to, before pressing Enter to go there.

A separate box lets you type things to search for, which are sent straight to Google, without you having to browse to "www.google.com".

The Back and Forward icons each have a small arrow on the end of them; if you click that, a list drops down of the various sites that you can currently go Back or Forward to.

'Bookmarks' are what are called 'Favorites' in Microsoft Internet Explorer.

Like other modern browsers, this web browser has "tabbed browsing", which means that rather than opening a separate version of the whole program for each new window, you can select a "New Tab" instead, and then the new windows appear inside the one Web browser, with little tabs that you can click on to change between them instantly.

Also like other modern browsers, it stops 'popup windows' from annoying you, while allowing you to set your Preferences so that on those sites where you do need to allow popup windows, you can.
