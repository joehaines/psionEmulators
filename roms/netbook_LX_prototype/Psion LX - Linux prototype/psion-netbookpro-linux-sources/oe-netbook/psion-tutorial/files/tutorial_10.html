Sheet

The operation of Sheet should be very familiar to users of Microsoft Excel (or other PC spreadsheet programs). Some differences:
  • The ability to change row height by clicking on the junctions between the row numbers on the left of the screen has been removed. This makes it much easier, on a touchscreen, to select one or more rows, without accidentally changing row heights. If you do need to change row heights, do a click&hold, and you'll see a command on the menu that is then displayed.
  • The touchscreen does make it slightly trickier to select the Fill control - the little box in the bottom righthand corner of the cell pointer.
  • Some of the more esoteric menu commands and mouse actions have been left out.
