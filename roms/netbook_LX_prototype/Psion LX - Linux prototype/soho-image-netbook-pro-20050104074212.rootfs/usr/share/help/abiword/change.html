Changing the appearance of text.



You can highlight text then apply formatting to it, or select a format to use and then start typing:

  • Press the button for bold text, for italics or for underlined text.
  • Press the button again to remove the effect.
  • Select a font from the pull down menu on the formatting toolbar. The Psion LX uses Albany and Thorndale fonts as replacements for Arial and Times New Roman. Use the pull down menu to the right of the font box to change the size of text. The default is 12pt. You can apply any of these effects and underline, strike through (cross out) and change the text colour using the Font command on the Format menu.
