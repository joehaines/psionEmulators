Finding & replacing text.



You can search through an entire file for a particular word or phrase and replace it with a different one.

  • To find text select the command from the Edit menu and type in the text that you want to find. You can make the search case sensitive, search for the whole word or do a "reverse find" which will search from the current position to the end of the file.
  • To find and replace text select the Replace command from the Edit menu. Type the text that you want to find and the text that you want to replace it with. You can replace a single occurrence of the chosen text, or all occurrences from this point onwards.
