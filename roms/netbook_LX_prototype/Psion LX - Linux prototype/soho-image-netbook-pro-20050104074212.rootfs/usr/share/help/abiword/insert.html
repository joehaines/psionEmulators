Information from other programs.



You can add pictures, graphs, spreadsheets and sounds to your AbiWord files by inserting information created by the other Psion LX programs. When a piece of information is inserted, it is known as an object.

Inserting an object.



  • To insert a sketch: tap the Insert Picture button on the Standard Toolbar or select the command from the Insert menu and select the picture.
  • To insert a table or graph: tap the Insert Graph button in the Toolbar or select the command from the Insert menu. A copy of the Sheet program will open. AbiWord displays the inserted Gnumeric object as a graph or a spreadsheet, depending on the view displayed when you close the copy of Gnumeric.
  • To insert a sound or other object: select the Other object command, and select from the programs which support this feature.

When you have inserted a sketch, table or graph you can select it, then use the pen to drag one of the ``handles'' to resize it. You can also format an object to resize it.

You can also use the Format object command to display an object as an icon of the program that created it to save space on screen. To set a preference so that objects are always displayed as icons when first created, use Object preferences on the Tools menu.

Important: Note that inserting objects into a file causes a considerable increase in file size.
