You can use the Alarm program to set the time and to set, display and manage alarms.

Alarm is available from the Psion LX button bar.

  1. To use Alarm to set the time, tap on the Alarm icon on the Psion LX button bar and choose the Set the time option from the menu. The Time and Date Setup window appears. To set the time and date, follow the instructions in section [Set the Time]

You can use Alarm to set alarms that will ring even when your Psion LX is switched off, e.g. a repeating wake-up alarm that will ring each day you work, and once only alarms to remind you of appointments.
