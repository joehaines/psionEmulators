Attaching files to messages



You can send files with emails, e.g. an AbiWord or Gnumeric document, by adding them as ``attachments''.

To add an attachment to a message you are writing:

  • Tap the Attachments button on the Toolbar. An Attach file dialog box will appear from which you can select the file.

When you attach files to the message they are displayed on the Attachments line below the Subject line. Messages which contain attachments are displayed beside a paperclip symbol. If you have received a message containing an attachment, you can view the file or save a copy of the file to disk. You can view attached Microsoft Word documents by opening them in AbiWord. Gnumeric can import Excel files.

To view or save an attachment:

  1. Open the message containing the file you want to view.
  2. Tap the Attachment icon and open:
    • the complete message.
    • the text only.
    • the image, table, sketch etc.
