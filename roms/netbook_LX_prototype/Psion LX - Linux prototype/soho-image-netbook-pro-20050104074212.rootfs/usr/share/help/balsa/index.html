Using the Balsa email client.



Balsa is a fully-featured email client. It is:

  • Higly configurable.
  • integrates well with Contacts.

When you first tap on the Balsa button which is available from the Psion LX panel and the Programs screen, Balsa activates a setup wizard which prompts you for the information which it will need to correctly collect and send email.

Using the information provided by your ISP, complete each screen. If you make a mistake, tap the back button.

Tap on the Apply button when you have configured your account and the main Balsa window will open.
