Calculator modes.



The calculator has two "modes": Basic and Scientific (go to View on the Menu and select the Mode you require).

  • The Basic Mode is a desktop calculator with the usual arithmetical functions. Use this calculator for general arithmetical calculations, percentages and square roots.
  • The Scientific Mode is a scientific calculator. Use this for more advanced calculations, including those that involve trigonometry or logarithms.

Selecting the Buttons option (available from View) allows the user to toggle on or off those calculator keys which deal with functions, logic or the standard arithmetical operations. The Calculator menu provides three sub-menus from which the user can choose to alter the number base, the angle units or the notation mode.

Galculator can use:

  • decimal, hexadecimal, octal and binary bases.
  • angles measured in degrees, radians or gradians.
  • algebraic, reverse Polish or formula entry notation.
