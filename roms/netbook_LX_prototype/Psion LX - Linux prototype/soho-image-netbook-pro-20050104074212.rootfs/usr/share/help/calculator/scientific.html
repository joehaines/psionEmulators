Scientific Calculations.



To perform a calculation in the Scientific mode, use the number, operator, function and logic buttons to enter your calculation. Performing a calculation is dependent upon the notation mode which you select:

  • Algebraic mode: allows the user to perform calculations using algebraic operators.
  • Reverse Polish notation mode: allows the user to place operands before the operators.
  • Formula mode: the user can use the algebraic operators and functions of algebraic mode but can also enter an expression in the formula entry field.

Function arguments should generally be enclosed in brackets e.g. cos(2) . The exception is where the user has created ``user defined functions''. These functions can be called by pressing the fun button in scientific mode.

To create a user defined function, select Preferences from the Edit menu and click on the Functions tab.

Give the user defined function a name, a variable and an expression e.g. abs(x)=sqrt(x^{2}) Galculator shows the formula in red if it has been entered incorrectly.
