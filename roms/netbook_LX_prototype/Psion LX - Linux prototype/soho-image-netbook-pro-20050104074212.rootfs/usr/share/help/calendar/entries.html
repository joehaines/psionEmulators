Changing and deleting entries.



To delete an entry, tap on that entry and delete the text within the Calendar Edit event dialog box.

Repeating entries.



You can set an entry to repeat automatically, e.g. a monthly meeting.

  1. Move the cursor to the entry and tap and hold the stylus against the screen to activate the Calendar New event dialog.
  2. Click on the Recurrence tab and set up the repeat type as appropriate, e.g. Daily, Monthly, Weekly.


The repeated entry symbol will appear beside the entry in the scheduler.
