Using the text editor.



Text Editor is invaluable for creating text files which can be used by many applications both on the Psion LX and on a PC. Microsoft Word and AbiWord read text files.

To use Text Editor:

  • Tap on the program's icon on the Program Screen. A Text Editor page will open and you can begin to type.
  • Tap the Open button to choose a file from the Open File dialog which you have already created.

Text Editor offers copy and paste facilities (both available from the application's button bar) which can be useful for copying and pasting information into other applications e.g. AbiWord. A Search and Search and Replace facility is also available from the button bar.

A context sensitive menu can be activated by pressing and holding the stylus against the screen. The menu allows the user to Select All, Cut, Copy, Paste and Delete information.

To exit Text Editor, tap on Quit.
