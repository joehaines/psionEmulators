Creating new directories.



You might want to create some directories for work projects and others for home use. For example, you may create a directory called House for files relating to work on your house, and create another directory within the House directory called Letters for AbiWord files of correspondence. Using directories in this way will also make your files easier to find.

To create a new directory:

  1. Move to the directory in which you wish to create the new directory.
  2. Select the Create Directory command File menu. A Question dialog box appears prompting you for a directory name. Type in the directory name.

Note: If you use Psion LX files with a PC, you may wish to create directories that match equivalent directories on your PC. This will make transferring files between the Psion LX and PC easier.
