Moving around.



To move a file or directory from one location to another:

  1. Highlight the file or directory to select it.
  2. Select the Move command from the context sensitive menu. This appears if you tap and hold the stylus against the screen over the file/directory which you have selected. A Move to directory dialog box appears allowing you to move through the list of directories. Click on the directory which will be the intended location for your file/directory. Press OK to move the file/directory to its new location.

To copy a file or directory from one location to another:

  1. Highlight the file or directory to select it.
  2. Select the Copy command from the context sensitive menu. The file/directory will be copied to the Psion LX clipboard. Move to the directory where you want to place your file/directory and select Paste from the context sensitive menu. The file will appear in its new location.

To delete a file:

  1. Highlight the file to select it.
  2. Select the Delete command from the context sensitive menu. A Confirm dialog box will appear asking you to either Cancel or Delete.

To rename a file or directory:

  1. Highlight the file to select it.
  2. Select Rename from the context sensitive menu and rename the file by typing a filename in the text field of the Rename file dialog box. Tap OK.
