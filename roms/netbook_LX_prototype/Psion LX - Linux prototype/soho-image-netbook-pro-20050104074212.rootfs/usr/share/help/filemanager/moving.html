Moving around.



To move to a file within a directory:

  1. Double tap on the directory containing the file.
  2. Highlight the directory with a single stylus tap and use the Forward arrow on the Filemanager menu bar.

To move back to a listing of directories:

  1. Tap the Back button.

To move above the current directory `A' to the directory containing directory `A':

  1. Tap the Up button on the Filemanager menu bar.

If there are more files in the directory than can be displayed on screen, scroll the screen using the left and right arrow keys.

To move to the /My Documents directory, tap on the My Docs button on the Filemanager menu bar.


Browsing directories.



A quick way to find a file is to enter the path to the file in the text field below the Filemanager button bar. This can be done by using the pull down menu to the right of the text field to select the path you require. Scroll down the list of path names by using the arrow keys and press Enter, tap the path name for the file you require or press the Go! button.
