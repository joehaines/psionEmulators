Opening files and directories.



To open a file:

  • Double tap on the file after locating it within Filemanager. Filemanager will activate an Open with... dialog box which contains a pull down menu. Select the appropriate application and click OK.
  • Open an application e.g. AbiWord for opening AbiWord and Microsoft Word documents and select Open from the File menu. Locate the file's location within the directory structure and click OK.

To open a directory:

  • Tap it twice.

To close the current directory:

  • tap on the Up button on the Filemanager menu bar.
