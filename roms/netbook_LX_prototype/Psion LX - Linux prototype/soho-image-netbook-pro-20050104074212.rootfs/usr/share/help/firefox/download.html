Download manager



The Download Manager is accessible from the Tools menu. Firefox allows the user to:

  1. Pause and resume downloads by clicking on the appropriate link beside the download entry.
  2. Cancel a download via the Cancel link.
  3. Retry where a previous download has been unsucessful.
  4. Open the folder containing the saved file with the Show link.

Note: Many archive file formats you can download from the Internet may not be recognised by your Psion LX, e.g. files with the .ZIP filename extension. If these archives contain software for your Psion LX, you may need to use a PC to extract files from these archives before you can install them on your Psion LX.
