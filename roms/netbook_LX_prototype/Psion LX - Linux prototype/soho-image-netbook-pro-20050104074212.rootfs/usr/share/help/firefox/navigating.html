Navigating the web



To start a connection and open a Web page:

  1. Connect your Psion LX and modem to a telephone line.
  2. Connect to the internet with the modem dialler Gkdial.
  3. Mozilla displays the Mozilla home page by default. To view another page, move the cursor to the location bar below the main menu, delete the web page address (URL) and type in the web page you want.
  4. Press Enter.

To stop loading a page:

  • Tap the Stop loading this page button on the Toolbar.

To close a connection:

  • Select Disconnect from the Gkdial window.

Warning! If you press Gkdial's Disconnect button while other programs, such as Balsa, are busy using the connection, you risk losing information in them. To avoid this, make sure no programs are transferring information to or from the Internet when you disconnect.

To follow a link:

  • Hypertext links (links to other pages) are underlined.
  • Move the cursor to the link you want, the cursor arrow symbol changes to a pointing finger and tap on the link in order to load the page. Alternatively, use the Tab key to highlight different links on a page in turn, then press Enter to open the highlighted link.

To navigate between pages:

  • Use the go forward one page and go back one page buttons on the toolbar to move back and forward between the pages you have already viewed.
  • The Backward button, the Forward button and the location bar have drop-down menus attached allowing you to go to a specific page.
