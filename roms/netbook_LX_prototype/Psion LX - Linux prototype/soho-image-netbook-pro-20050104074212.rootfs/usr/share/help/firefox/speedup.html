Increasing speed.



To increase the speed with which Firefox displays a page:

  • Turn the Load Images option off.
  • Increase Firefox's cache size.

Loading images



Web pages containing images may take longer to open than text only pages. To reduce the time it takes to open a page, you can set Mozilla Firefox so that it does not load images.

To do this:

  • select the Downloads option from the Tools menu, tap the Preferences button, click on the Web Features tab and turn the Load Images button off. Click OK.

Increase the cache size



Firefox can store your favourite web pages on your hard disk. This saves the time which it takes to display the image but reduces the size of free space available on your hard disk.

To do this:

  • select the Downloads option from the Tools menu, tap the Preferences button, click the Privacy tab and set the size of cache you require. You can also clear the cache completely.
