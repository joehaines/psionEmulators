The instant messenger Gaim.



The Instant Messenger client program on the Psion LX is available by tapping the Instant Messenger button on the Programs screen. Tapping on the icon activates Gaim.

Gaim is an instant messaging (IM) client program allowing users to chat in "real time".

Gaim offers the user:

  1. Access to a number of chat networks; you don't need a different piece of software to chat on a particular network.
  2. Access to multiple accounts on those networks which means that you can chat to friends and colleagues without worrying about the network which they are using.
  3. Other network features supported by Gaim include:
    • buddy pounces: notification of an important event e.g. when a specific friend colleague or buddy signs on or offline.
    • email notification: notification when you have new messages.
