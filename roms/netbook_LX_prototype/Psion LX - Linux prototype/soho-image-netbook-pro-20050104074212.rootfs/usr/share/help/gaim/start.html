Getting started.



Before you can use Gaim, you need to:

  1. Set up your internet connection by configuring the modem dialling software Gkdial. See Section [sec:Modem-Dialler:-Gkdial]

  2. Create a web based email account with the network of your choice.

    Examples include:

    • *IRC.
    • *AOL Instant Messenger.
    • *Yahoo Chat
    • *MSN Messenger
