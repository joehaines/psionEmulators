Using the gallery.



Image Gallery allows the user to view images either in isolation or as a slide show. Image Gallery is available from the Programs screen. After tapping on the application's icon, the Gallery window opens. To open an image file, tap the Open button on the Gallery button bar. Select the directory containing the image which you want to view from the Select directory dialog box and click OK. A list of images---with a thumbnail of the image, image dimension, size and date of last modification---will be displayed in the Gallery window.

To view an image:

  • Tap on the thumbnail image. The image will appear in the Gallery window.

The user can either close the image by clicking the Close image button or move to the next or a previous image by clicking the appropriate button.

A series of Zoom options are available below the Gallery window.

The user can:

  • Zoom in
  • Zoom out
  • Zoom 1:1
  • Zoom to Fit
  • Rotate the image clockwise
  • Toggle to Full Screen

To view a slide show

  • Click the Slideshow button on the Gallery button bar.

A GPE-Gallery dialog box will appear allowing the user to set a delay between each slide show image in seconds. Toggle to the required value and click Start.

Image Gallery will show each image until it is deactivated by pressing the black cross in the top left corner of the Slide show screen.

To quit the application, click on the Quit button.
