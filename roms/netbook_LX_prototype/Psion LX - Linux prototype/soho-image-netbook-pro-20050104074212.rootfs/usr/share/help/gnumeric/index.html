Gnumeric spreadsheet.



Gnumeric is a fully-featured spreadsheet program allowing the user to present and manipulate data, graph data and import non-numerical information. Its operation and functionality should be familiar to users of MS Excel and other dedicated spreadsheets. Gnumeric can open files from Excel, Lotus 1-2-3 and can save files as Excel, HTML, and for advanced users, as LaTeX. Gnumeric's default file format is Gnumeric XML and files of this type have the suffix .gnumeric.

Tap the Sheet button on the panel to activate Gnumeric, open Gnumeric by double tapping a spreadsheet file or open from the terminal by typing gnumeric &.
