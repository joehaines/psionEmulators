Main gnumeric window.



You can use Gnumeric to create worksheets, and use the PC Connectivity software supplied with Psion LX to transfer worksheets to your PC.

The Gnumeric window is characterised by a number of features:

  • A Menu Bar with access to Gnumeric's functionality via a series of menus.
  • The Standard toolbar which allows access to common functions via a number of buttons.
  • The Format toolbar for activating formatting instructions.
  • An Object toolbar for access to objects typically associated with spreadsheets e.g. frames, check boxes etc.
  • The Data Entry Area for entering data into a particular part of the spreadsheet.
  • The Cell Grid Area - built from a series of rectangular boxes or cells.
  • The Information Area - below the Cell Grid - which tells the user what Gnumeric is currently doing.
