Using help.



Using the help system is very easy, if you are familiar with a standard web browser. The main window consists of two parts:

  1. The top part with the back, forward and help index buttons.
  2. The main window where the help will be displayed.

You can just select the topic you need by clicking on the underlined blue text. This displays the help you requested. If you want to go back to a previous page you can press the back button. To return to the page you were viewing previously, you press the forward button. Pressing the home button will bring you back to the help index.
