Using the sketch pad.



You can use Sketch Book to produce pictures, including maps, freehand sketches, invitations etc.

Sketch Book is available from the Programs screen.

You can start straight away, by drawing freehand with the pen on the screen. However, you may want to change the "pen" before you begin to draw.

You can select:

  • The pen size e.g. small, medium, large or extra large.
  • The pen colour. The default is black.

If you make a mistake, an eraser is available from the menu bar.

To save, go to File and tap on Save. When the file has been saved, Sketch Book will list your file with a name corresponding to the date and time of its creation. To see a thumbnail sketch without opening the file, tap on the View button on the icon bar.

A scroll facility is available allowing you to move between your sketches by tapping the previous or next buttons.

Images drawn with Sketch Book can also be used by other applications like AbiWord.

To import a Sketch Book image into AbiWord, start AbiWord, place the cursor on the part of the AbiWord page where you want the picture to appear and select the Picture option from the Insert Menu.
Select the folder where you have saved the file and click on the file you require.
A preview of the picture will be displayed as a thumbnail.

Click OK to insert the picture at the insertion point.

The image can be printed as a part of an AbiWord document.
