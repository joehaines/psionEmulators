Using Totem, the media player .



When you start the media player by tapping on the media player icon, a typical media player screen will appear.

On top you will see a menu, at the bottom some buttons.

  • a skip back button
  • a play/pause button
  • a skip forward button
  • a playlist button
  • a bar indicating how much of the current file has been played
  • a volume bar, with a mute button at one side and a maximum volume level button

You can open a file by using the file menu, or pressing the playlist button. If you use the file open menu option, the file will start to play automatically. Otherwise you will be adding files to the playlist. After pressing the play button, all the files in the playlist will be played one by one.

Pressing the skip forward or skip backward buttons will skip to the next or previous file in the playlist.
