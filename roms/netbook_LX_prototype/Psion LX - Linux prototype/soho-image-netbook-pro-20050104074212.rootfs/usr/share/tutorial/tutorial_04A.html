Using the Touchscreen (2)

For users who are more oriented towards the keyboard than the touchscreen:

  • note that you can select any menu by holding down the Alt key and pressing the underlined letter in the menu title - for example, it will be Alt+F for the "File" menu. You can then select an individual command from the menu by typing the letter that is underlined in the name of the command.
  • alternatively, the most common commands have the same simple hotkeys as on a PC - Ctrl+O for "Open", say.
  • also, whenever a command displays a "dialog box" on the screen, you can move between the various elements of that dialog box by pressing the Tab key. (This is also a Windows standard keypress.) You will also generally find that the Enter key will confirm a dialog, as if you had pressed the "OK" button onscreen, while pressing the Esc key is like pressing the "Cancel" button on a dialog.
