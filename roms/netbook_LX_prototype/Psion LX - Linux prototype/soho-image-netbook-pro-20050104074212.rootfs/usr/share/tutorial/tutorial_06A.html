Exchanging files with your PC (2)

There may be some places where certain types of information do not come across perfectly, because of the different capabilities of the programs on the different computers.

Another reason, in the case of Microsoft Word, is the complexity of its "file format", which is proprietary to Microsoft. If you do have any problems with a particular file, you may find it worth opening the file in Microsoft Word and using 'Save as' to save the file in the "Rich Text Format (RTF)". The word processor on the Psion LX can open RTF files too, and RTF is an international open standard that is easier for other programs to understand and open.

Note also that when the Psion LX Word program saves a file in Microsoft Word format - i.e. a ".doc" file - if you then open it in Microsoft Word on a PC, it will ask you whether you want to convert it from "Rich Text Format (RTF)". The reason is that, despite it being a ".doc" file, it really contains RTF inside, as that is a much better format to use for transfer between devices.
